## 읽는 순서

1. [도커 핵심 이론](../docker/dockertheory.md)에서 컨테이너 개념을 확인한다.
2. CLD-K8S-001-MP로 로컬 클러스터를 만든다.
3. [쿠버네티스 클러스터 구축](kubernetes/README.md)의 문서를 순서대로 따른다.

## 이 영역이 다루는 것

컨테이너를 여러 노드에 배치하고 관리하는 쿠버네티스(Kubernetes)의 로컬 설치와 클러스터 구축 문서 그룹이다. 도커 컨테이너 개념을 아는 입문자가 로컬 Kind 클러스터에서 시작해 하위 그룹의 구축·운영 문서로 넘어가는 순서를 전제로 한다.

## 핵심 용어

- 클러스터: 컨트롤 플레인과 워커 노드의 집합
- Pod: 쿠버네티스의 최소 배포 단위
- Kind: 도커 컨테이너를 노드로 쓰는 로컬 클러스터 도구
- kubectl: 클러스터를 조작하는 명령줄 도구

## 선수 지식

- 도커 이미지와 컨테이너
- 리눅스 명령줄 기초
