## 이 영역이 다루는 것

프라이빗 클라우드는 한 조직이 자체 서버 자원 위에 가상화 계층을 올려 운영하는 클라우드다. 이 그룹은 VMware vSphere 기반 구성을 다룬다. 서버·네트워크 기본 개념을 아는 입문자가 퍼블릭 클라우드와 비교하며 읽는 것을 전제로 한다.

## 핵심 용어

- ESXi: 물리 서버에 설치하는 하이퍼바이저
- vCenter Server: 여러 ESXi 호스트를 중앙에서 관리하는 서버
- VM: 하이퍼바이저 위에서 동작하는 가상 머신
- vSwitch: 가상 머신 사이와 외부 네트워크를 잇는 가상 스위치
- VMFS: ESXi가 쓰는 데이터스토어 파일 시스템

## 선수 지식

- 가상화와 하이퍼바이저의 개념
- 기본 네트워크(IP, 서브넷)
