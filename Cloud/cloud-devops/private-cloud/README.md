# 프라이빗 클라우드 (Private Cloud)

한 조직 안에서 쓰는 프라이빗 클라우드 문서 그룹이다. 문서 번호(Task ID)는 `CLD-PVC-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| CLD-PVC-001-DO | 개념 | [VMware 기반 프라이빗 클라우드 구축](vmwareprivatecloud.md) | ESXi, vCenter Server, VM, vSwitch, VMFS의 역할과 구축 순서를 이해한다 |

## 읽는 순서

1. CLD-PVC-001-DO로 구성 요소를 이해한다.
2. 퍼블릭 클라우드와의 비교는 [AWS 주요 서비스 정리](../aws/aws_services.md)(CLD-AWS-002-DO)를 본다.
