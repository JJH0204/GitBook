## 1. 목적

[도커 핵심 이론](dockertheory.md)(CLD-DKR-002-DO)은 `docker network` 명령 이름만 나열한다. 이 문서는 컨테이너가 어떤 네트워크에 붙는지, 서로 이름으로 찾는 방법, 호스트 포트를 여는 방법을 정리한다.

## 2. 구성 요소

### 2.1 네트워크 드라이버

| 번호 | 드라이버 | 설명 | 용도 |
|---|---|---|---|
| 1 | `bridge` | 호스트 안에 가상 스위치(브리지)를 만들어 컨테이너를 연결한다. 기본값이다 | 한 호스트의 컨테이너끼리 통신 |
| 2 | `host` | 컨테이너가 호스트의 네트워크를 그대로 쓴다. 포트 게시가 필요 없다 | 네트워크 격리가 필요 없을 때 |
| 3 | `none` | 네트워크 인터페이스가 루프백뿐이다 | 네트워크를 완전히 끊을 때 |
| 4 | `overlay` | 여러 도커 호스트를 하나의 네트워크로 묶는다 | 도커 스웜 등 다중 호스트 |
| 5 | `macvlan` | 컨테이너에 물리 네트워크의 MAC 주소를 준다 | 컨테이너를 LAN의 독립 기기처럼 보이게 할 때 |

### 2.2 기본 브리지와 사용자 정의 브리지

| 항목 | 기본 브리지(`bridge`) | 사용자 정의 브리지 |
|---|---|---|
| 생성 | 도커가 설치할 때 만든다 | `docker network create <네트워크명>` |
| 컨테이너 이름으로 접속 | 안 된다 (IP 주소로만 접속) | 된다. 내장 DNS가 컨테이너 이름을 IP로 바꾼다 |
| 격리 | 네트워크를 지정하지 않은 컨테이너가 모두 같은 브리지에 붙는다 | 같은 네트워크에 붙은 컨테이너끼리만 통신한다 |

여러 컨테이너가 서로 통신해야 하면 사용자 정의 브리지를 만든다.

### 2.3 포트 게시(`-p`)

| 번호 | 형식 | 의미 |
|---|---|---|
| 1 | `-p 8080:80` | 호스트의 모든 인터페이스 8080번을 컨테이너 80번으로 전달한다 |
| 2 | `-p 127.0.0.1:8080:80` | 호스트의 루프백에서만 8080번을 연다. 같은 LAN의 다른 기기는 접속할 수 없다 |
| 3 | `-P` | 이미지가 `EXPOSE`한 포트를 호스트의 임의 포트에 연결한다 |

`EXPOSE`는 이미지가 쓰는 포트를 문서로 알리는 표시이며, 그 자체로 호스트 포트를 열지 않는다.

## 3. 동작 원리

1. 같은 사용자 정의 브리지에 붙은 컨테이너끼리는 포트를 게시하지 않아도 컨테이너 포트로 직접 통신한다.
2. 호스트 밖에서 컨테이너에 접속하려면 `-p`로 포트를 게시한다. 도커가 호스트의 방화벽 규칙(iptables 또는 nftables)에 전달 규칙을 추가한다.
3. 컨테이너가 외부로 나갈 때는 호스트 주소로 주소 변환(NAT)된다.
4. 사용자 정의 브리지에서 컨테이너 `db`는 같은 네트워크의 다른 컨테이너에서 이름 `db`로 찾을 수 있다.

```bash
docker network create app-net
docker run -d --name db --network app-net -e MARIADB_ROOT_PASSWORD=<비밀번호> mariadb:11
docker run -d --name web --network app-net -p 127.0.0.1:8080:80 nginx:stable
docker network inspect app-net
```

{% hint style="warning" %}
CAUTION: 게시한 포트는 `ufw` 같은 호스트 방화벽 설정을 우회해 열릴 수 있다. 도커가 별도 방화벽 규칙을 넣기 때문이다. 외부에 열지 않을 서비스는 `-p 127.0.0.1:...` 형식으로 게시하거나 게시하지 않는다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 브리지(Bridge) | 호스트 안의 가상 스위치 |
| 포트 게시(Publish) | 호스트 포트를 컨테이너 포트에 연결하는 것 |
| NAT | Network Address Translation. 주소 변환 |
| 내장 DNS | 사용자 정의 네트워크에서 컨테이너 이름을 IP로 바꾸는 도커의 이름 해석 |
