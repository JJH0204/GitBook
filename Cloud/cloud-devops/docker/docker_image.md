## 1. 목적

도커 이미지는 컨테이너를 만들기 위한 읽기 전용 템플릿이다. 이 문서는 이미지의 구성, 만드는 방법, 태그의 의미를 정리한다.

## 2. 구성 요소

| 번호 | 항목 | 설명 | 비고 |
|---|---|---|---|
| 1 | 파일 시스템 | 컨테이너가 쓸 파일과 디렉터리를 담는다 | 레이어 단위로 쌓인다 |
| 2 | 환경 변수 | 컨테이너 안에서 쓸 변수(`ENV`)를 담는다 | |
| 3 | 실행 명령 | 컨테이너가 시작될 때 실행할 명령(`CMD`, `ENTRYPOINT`)을 담는다 | |
| 4 | 태그(Tag) | 같은 이미지 이름 아래에서 버전이나 별칭을 구분하는 이름이다 | 예: `ubuntu:22.04` |

이미지는 두 가지 방법으로 얻는다.

| 번호 | 방법 | 설명 |
|---|---|---|
| 1 | 직접 빌드 | [Dockerfile](dockerfile.md)(CLD-DKR-010-REF)을 작성하고 빌드한다. 절차는 [도커 이미지 빌드](docker_build.md)(CLD-DKR-009-MP)를 따른다 |
| 2 | 내려받기 | 다른 사람이 만든 이미지를 레지스트리에서 받는다. 절차는 [도커 허브 활용 가이드](docker_hub.md)(CLD-DKR-015-MP)를 따른다 |

## 3. 동작 원리

1. 이미지는 `이름:태그` 형식으로 가리킨다. 태그를 생략하면 `latest`가 적용된다.
2. 하나의 이미지에 태그를 여러 개 붙일 수 있다. 태그는 별명과 같다.
3. 컨테이너를 만들 때 이미지가 로컬에 없으면 레지스트리에서 내려받는다.

{% hint style="warning" %}
CAUTION: `latest`는 "가장 최신 버전"을 보장하는 태그가 아니라 태그를 생략했을 때 쓰는 기본 이름일 뿐이다. 시간이 지나 가리키는 내용이 바뀔 수 있으므로 재현이 필요한 환경에서는 `ubuntu:22.04`처럼 버전을 명시한다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 이미지(Image) | 컨테이너 생성용 읽기 전용 템플릿 |
| 태그(Tag) | 이미지 버전 또는 별칭 이름 |
| 레이어(Layer) | 이미지를 구성하는 변경 단위 |
| 레지스트리(Registry) | 이미지 저장·배포 서버 |
