## 1. 보안 점검

| 번호 | 점검 항목 | 기준 | 합격 |
|---|---|---|---|
| 1 | 루트 사용자 MFA | 루트 사용자에 다중 인증이 켜져 있다 | [ ] |
| 2 | 루트 액세스 키 | 루트 사용자의 액세스 키가 없다 | [ ] |
| 3 | 일상 작업 계정 | 일상 작업은 IAM 사용자 또는 역할로 한다. 루트로 하지 않는다 | [ ] |
| 4 | 최소 권한 | 정책이 필요한 작업과 리소스로 한정돼 있다. 전체 권한(`*`)을 쓰지 않는다 | [ ] |
| 5 | IAM 사용자 MFA | 콘솔 로그인이 가능한 사용자에게 MFA가 켜져 있다 | [ ] |
| 6 | 액세스 키 관리 | 쓰지 않는 키를 삭제한다. 키를 코드·문서·저장소에 쓰지 않는다 | [ ] |
| 7 | 보안 그룹 | 22(SSH), 3389(RDP) 포트를 `0.0.0.0/0`에 열지 않는다. 내 IP 등으로 제한한다 | [ ] |
| 8 | 저장소 공개 | S3 버킷의 퍼블릭 액세스 차단이 켜져 있다. 공개가 필요한 버킷은 목록에 기록돼 있다 | [ ] |
| 9 | 활동 기록 | API 활동 기록 서비스(CloudTrail)가 켜져 있다 | [ ] |

## 2. 비용 점검

| 번호 | 점검 항목 | 기준 | 합격 |
|---|---|---|---|
| 1 | 예산 알림 | 예산(Budgets) 또는 청구 알림이 설정돼 있다 | [ ] |
| 2 | 실행 중 인스턴스 | 쓰지 않는 EC2 인스턴스가 없다 | [ ] |
| 3 | 중지된 인스턴스의 디스크 | 중지한 인스턴스의 EBS 볼륨은 요금이 계속 부과된다. 필요 없으면 인스턴스와 볼륨을 삭제한다 | [ ] |
| 4 | 탄력적 IP | 연결되지 않은 탄력적 IP가 없다 | [ ] |
| 5 | NAT 게이트웨이 | 쓰지 않는 NAT 게이트웨이가 없다. 시간당 요금이 부과된다 | [ ] |
| 6 | 로드 밸런서·DB | 쓰지 않는 로드 밸런서, RDS 인스턴스, 스냅숏이 없다 | [ ] |
| 7 | 리전 확인 | 실습한 리전별로 위 항목을 모두 확인했다. 다른 리전의 리소스도 과금된다 | [ ] |

{% hint style="danger" %}
WARNING: 액세스 키나 비밀 키가 노출됐다면 즉시 해당 키를 비활성화하고 삭제한 뒤 새 키를 만든다. 노출된 키로 다른 사람이 리소스를 만들어 요금이 발생할 수 있다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 리소스를 삭제하면 복구되지 않는다. 삭제 전에 필요한 데이터를 백업한다.
{% endhint %}
