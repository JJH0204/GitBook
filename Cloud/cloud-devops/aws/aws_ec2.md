# AWS EC2 가이드 (EC2)

* 저장소
* iso
* 이름 설정
* 소프트웨어 선택
* 이미지 정보
* 사양 설정 가능
* (필수) 로그인에 사용되는 키 생성 또는 이미 생성된 키 등록
* 권장X
* s3 스트로지에 저장하는 것을 권장
* 비밀번호 작성
* 파일이름.pem 으로 저장
* EC2 장치가 연결된 네트워크 설정/보안그룹(방화벽) 설정 가능
* 다음 설정으로 생성할 VM 개수
* 요금 부가 정보
* 인스턴스 시작
* 저장 공간 설정
* 머신삭제조건
* 암호화 설정
* 초당처리속도
* 장치에 할당된 IP (동적)
* 그 외 설정들
* IP 설정하면 비용 발생\
  (연습할 때는 생성 만하고 사용은 x)
* 설정한 비밀번호 입력
* 사용자 이름 입력
* 연결 정보 입력
* 머신 사용량 모니터링 가능
