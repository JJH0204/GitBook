## 1. 목적

S3(Simple Storage Service)는 파일을 객체(object)로 저장하는 서비스다. 디스크처럼 마운트해 쓰는 파일 시스템이 아니라 HTTP API로 객체를 올리고 내려받는다. 정적 파일, 백업, 로그, 데이터 보관에 쓴다. 공개 설정 실수가 데이터 유출로 이어지는 대표 서비스이므로 접근 제어를 중심으로 이해한다.

## 2. 구성 요소

| 번호 | 요소 | 설명 |
|---|---|---|
| 1 | 버킷(Bucket) | 객체를 담는 최상위 컨테이너. 이름은 전체 AWS에서 유일해야 하고, 리전을 지정해 만든다 |
| 2 | 객체(Object) | 데이터와 메타데이터. 하나의 크기는 최대 5TB다 |
| 3 | 키(Key) | 버킷 안에서 객체를 식별하는 이름. `logs/2026/app.log`처럼 `/`를 써도 실제 폴더 구조는 아니고 이름의 일부다 |
| 4 | 스토리지 클래스 | 접근 빈도에 따른 저장 등급과 요금 (Standard, Standard-IA, Glacier 계열 등) |
| 5 | 수명 주기 규칙 | 일정 기간 뒤 다른 클래스로 옮기거나 삭제하는 규칙 |

## 3. 접근 제어

| 번호 | 수단 | 설명 |
|---|---|---|
| 1 | IAM 정책 | 사용자·역할에 붙여 어떤 버킷·객체에 무엇을 할 수 있는지 정한다 |
| 2 | 버킷 정책 | 버킷에 붙는 정책. 다른 계정이나 서비스에 접근을 허용할 때 쓴다 |
| 3 | 퍼블릭 액세스 차단(Block Public Access) | 계정이나 버킷 단위로 공개 설정을 막는 안전장치 |
| 4 | 미리 서명된 URL(presigned URL) | 제한된 시간 동안만 특정 객체에 접근하게 하는 URL |
| 5 | ACL | 오래된 객체별 권한 방식. 새 버킷에서는 Object Ownership 기본 설정으로 ACL이 비활성이다 |

{% hint style="danger" %}
WARNING: 버킷 또는 객체를 인터넷에 공개하면 누구나 읽을 수 있다. 정적 웹사이트처럼 의도한 경우가 아니면 퍼블릭 액세스 차단을 켠 상태로 둔다. 공개 전에 담긴 객체에 개인 정보와 비밀 값이 없는지 확인한다.
{% endhint %}

## 4. 데이터 보호 기능

| 기능 | 설명 | 주의 |
|---|---|---|
| 버전 관리(Versioning) | 같은 키를 덮어써도 이전 버전을 남긴다. 삭제하면 삭제 표시만 붙는다 | 이전 버전도 저장 요금이 든다 |
| 서버 측 암호화 | 저장 시 암호화한다. 새 객체에는 기본으로 SSE-S3가 적용된다 | 키를 직접 관리하려면 KMS(SSE-KMS)를 설정한다 |
| 전송 암호화 | HTTPS로만 접근하도록 버킷 정책에서 강제할 수 있다 | |
| 복제(Replication) | 객체를 다른 버킷·리전에 복사한다 | 버전 관리가 필요하다 |
| 액세스 로그·이벤트 | 누가 접근했는지 기록하거나 객체 변화에 이벤트를 보낸다 | 로그 버킷은 별도로 둔다 |

S3는 객체를 쓴 직후 읽거나 목록을 조회해도 최신 상태가 보이는 강한 일관성(strong consistency)을 제공한다.

## 5. 주요 CLI 명령 (AWS CLI)

| 명령 | 설명 |
|---|---|
| `aws s3 ls` | 버킷 목록 |
| `aws s3 ls s3://<버킷명>/<접두사>/` | 객체 목록 |
| `aws s3 cp <로컬파일> s3://<버킷명>/<키>` | 업로드 |
| `aws s3 sync <로컬폴더> s3://<버킷명>/<접두사>/` | 폴더를 동기화한다 |
| `aws s3 presign s3://<버킷명>/<키> --expires-in 600` | 600초 동안 유효한 미리 서명된 URL을 만든다 |
| `aws s3api get-public-access-block --bucket <버킷명>` | 퍼블릭 액세스 차단 설정을 본다 |

{% hint style="warning" %}
CAUTION: `aws s3 rm --recursive`, `aws s3 sync --delete`, `aws s3 rb --force`는 객체를 삭제한다. 버전 관리가 꺼져 있으면 복구할 수 없다. 실행 전에 `--dryrun` 옵션으로 대상을 확인한다.
{% endhint %}

## 6. 약어·용어

| 용어 | 뜻 |
|---|---|
| 객체 저장소 | 파일을 키로 식별해 API로 다루는 저장 방식 |
| SSE | Server-Side Encryption. 서버 측 암호화 |
| KMS | Key Management Service. 암호 키 관리 서비스 |
| IA | Infrequent Access. 자주 접근하지 않는 데이터용 등급 |
