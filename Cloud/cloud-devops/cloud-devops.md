# 클라우드 및 DevOps 개요

클라우드와 DevOps 문서를 그룹별로 나눠 안내한다. 문서 번호(Task ID)는 `CLD-<그룹>-<번호>-<유형>` 형식이다. 유형은 D&O(개념), MP(절차), REF(표)로 나뉜다.

## 그룹 목록

| 그룹 | 폴더 | 내용 |
|---|---|---|
| AWS | [aws/](aws/README.md) | AWS 구성도, 주요 서비스, EC2 인스턴스 생성 |
| Docker | [docker/](docker/README.md) | 컨테이너, 이미지, 도커 허브, Compose |
| Kubernetes | [kubernetes/](kubernetes/README.md) | 클러스터 구축, 대시보드, EKS |
| CI/CD · DevSecOps | [ci-cd-devsecops/](ci-cd-devsecops/README.md) | DevSecOps 개념, Jenkins 파이프라인 |
| 프라이빗 클라우드 | [private-cloud/](private-cloud/README.md) | VMware 기반 구축 |
| 이론·과제 | [theory-assignments/](theory-assignments/README.md) | 클라우드 이론, 보안 시스템 관리 과제 |

## 읽는 순서

1. AWS 그룹에서 계정, IAM, 주요 서비스 개념을 본다.
2. Docker 그룹에서 컨테이너 기본을 익힌다.
3. Kubernetes와 CI/CD 그룹으로 이어간다.
