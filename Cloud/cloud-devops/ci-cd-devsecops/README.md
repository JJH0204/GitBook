# CI/CD 및 DevSecOps

CI/CD 파이프라인과 DevSecOps(개발 단계에 보안 점검을 넣는 방식)를 다룬다. 문서 번호(Task ID)는 `CLD-CIC-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| CLD-CIC-001-DO | D&O | [DevSecOps 파이프라인 개요](devsecops-overview.md) | 파이프라인 구성 요소와 흐름을 이해한다 |
| CLD-CIC-002-MP | 절차 | [Jenkins CI/CD 파이프라인](jenkins.md) | Jenkins 파이프라인과 SonarQube 연동을 설정한다 |

## 읽는 순서

1. CLD-CIC-001-DO로 구성 요소를 파악한다.
2. CLD-CIC-002-MP를 수행한다.
