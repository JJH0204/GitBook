# [생성형 AI] 클라우드 이론 및 실습 과제

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (허브) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (하위 문서 제목과 용도만 정리했으며 실행하지 않았다) |

클라우드 컴퓨팅의 기본 개념과, 컨테이너와 쿠버네티스로 서비스를 구축할 때의 개념을 정리한다. 문서 번호(Task ID)는 `CLD-THY-<번호>-<유형>` 형식이다. 유형은 DO(개념)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| CLD-THY-001-DO | 개념 | [클라우드 컴퓨팅 핵심 이론](cloudtheory.md) | 서비스 모델, 배포 방식, 공유 책임 모델을 이해한다 |
| CLD-THY-002-DO | 개념 | [클라우드 보안 시스템 관리 실습 과제](cloudsecuritysystemmanagementassignment.md) | 컨테이너 FTP 서버, 쿠버네티스 클러스터, 접근 제어, 모니터링의 개념을 이해한다 |

## 읽는 순서

1. CLD-THY-001-DO로 클라우드의 기본 개념을 익힌다.
2. CLD-THY-002-DO로 컨테이너와 쿠버네티스 기반 서비스의 구성 개념을 익힌다.
3. 실제 절차는 [도커 (Docker)](../docker/README.md)와 [쿠버네티스 (Kubernetes)](../kubernetes/README.md) 문서를 따른다.

## 이 영역이 다루는 것

클라우드 컴퓨팅의 서비스 모델과 배포 방식, 컨테이너·쿠버네티스 기반 서비스 구성을 개념 위주로 정리한 그룹이다. 실습에 들어가기 전에 용어와 구조를 잡으려는 입문자가 먼저 읽는다.

## 핵심 용어

- IaaS / PaaS / SaaS: 클라우드 서비스 모델
- 공유 책임 모델: 제공자와 사용자가 보안 책임을 나누는 방식
- 컨테이너, 쿠버네티스: 서비스 배포·운영 단위와 오케스트레이션 도구

## 선수 지식

- 서버, 네트워크, 가상화의 기본 개념
