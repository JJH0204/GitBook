## 읽는 순서

1. 리눅스 기초가 없으면 리눅스 기초 대시보드를 먼저 본다.
2. 클라우드 및 DevOps 개요와 클라우드 이론으로 개념을 잡는다.
3. 도커, 쿠버네티스, AWS, CI/CD 그룹 순으로 실습한다.

## 핵심 용어

- 컨테이너: 애플리케이션과 실행 환경을 묶어 격리해 실행하는 단위
- 오케스트레이션: 여러 컨테이너의 배치와 운영을 자동화하는 것
- CI/CD: 빌드, 테스트, 배포를 자동화하는 흐름
