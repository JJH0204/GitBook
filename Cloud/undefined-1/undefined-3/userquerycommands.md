# UserQueryCommands

| 명령어      | 설명                                                  |  옵션 |    사용 방법    | 예제        |
| -------- | --------------------------------------------------- | :-: | :---------: | --------- |
| `users`  | 현재 로그인 한 사용자 이름 출력                                  |     |   `users`   |           |
| `who`    | 현재 로그인 한 사용자 조회 — `users` 보다 더 상세한 정보               |     |    `who`    |           |
| `w`      | 현재 로그인 한 사용자 정보 출력 — `who` 보다 더 상세한 정보              |     |     `w`     |           |
| `id`     | 사용자 계정의 uid, gid, group을 확인. uid는 1000번부터 저장(루트는 0) |     | `id '사용자명'` | `id root` |
| `groups` | 사용자 계정이 속한 그룹 확인. 현재 생성된 그룹은 `/etc/group` 파일에서 확인   |     |   `groups`  |           |
