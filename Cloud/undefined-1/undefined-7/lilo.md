# LILO

{% hint style="info" %}
LILO, Linux Loader는 리눅스 운영 시스템을 위한 초기 부트 로더 중 하나입니다.\
시스템의 전원이 켜지고 나서 운영 체제가 로드되기 전에 가장 먼저 실행되는 소프트웨어로, 다른 운영 체제를 선택하고 로드할 수 있는 메뉴를 제공하는 역할을 합니다.
{% endhint %}

### 특징과 작동 방식

{% stepper %}
{% step %}
### 다중 부팅 지원

* LILO는 여러 운영 체제를 설치한 멀티부팅 환경에서 선택적으로 부팅할 운영 체제를 선택할 수 있게 해줍니다.
* 이를 통해 사용자는 리눅스, 윈도우즈, 그 외 다른 운영 체제 간 부팅이 가능해집니다.
{% endstep %}

{% step %}
### 설정 파일

* LILO 설정은 '[ /etc/lilo.conf ](/broken/pages/ecea9b8bb7cbd89892b186e6f2ee43e2158a009d)' 파일에 저장됩니다.
* 부팅 관련 설정(로드할 커널 이미지, 부팅 옵션, 타임아웃 설정 등)을 지정할 수 있습니다.
{% endstep %}

{% step %}
### 부팅 메뉴

* LILO는 부팅 시 화면에 메뉴를 제공하여 사용자가 원하는 운영 체제를 선택할 수 있도록 합니다.
* 설정 파일에서 타임아웃이 지정되어 있다면, 지정된 시간 이후 기본 운영 체제가 자동으로 부팅됩니다.
{% endstep %}

{% step %}
### 제한 사항

* 설치할 때 설정한 커널 이미지 위치에 대한 물리적인 주소 정보를 사용합니다.
* 커널이나 중요 파일들의 위치가 변경될 경우 LILO는 새로운 설정 정보로 업데이트되어야 합니다.
* 또한 부팅 가능한 최대 영역이 하드 드라이브의 처음 1024 실린더로 제한됩니다.
{% endstep %}
{% endstepper %}

* LILO는 사용이 줄었으며 최근에는 GRUB(GRand Unified Bootloader) 같은 현대적이고 유연한 부트 로더들이 널리 사용됩니다.
* 주로 구식 시스템 또는 특수 목적으로 구성된 환경에서 LILO가 사용됩니다.
