| 문서 | Task ID | 용도 |

## 두 개념 비교

| 항목 | `virtual` 메서드 | `abstract` 메서드 |
|---|---|---|
| 본문 | 기본 구현이 있다 | 본문이 없다(`;`로 끝난다) |
| 자식의 재정의 | 선택이다(`override`) | 비추상 자식 클래스는 반드시 `override`로 구현한다 |
| 선언 가능한 클래스 | 일반 클래스와 추상 클래스 | 추상 클래스 안에서만 |
| 호출 시 선택 기준 | 객체의 실제 타입(런타임) | 객체의 실제 타입(런타임) |

## 읽는 순서

1. PRG-CSH-001-DO로 `virtual`, `override`, `new` 숨기기를 구분한다.
2. PRG-CSH-002-DO로 `abstract`가 재정의를 강제하는 방식을 읽는다.
3. C와 C++ 문서는 [C 및 C++ (C & C++)](../../c-and-c++/README.md)에 있다.
