# C# 언어 (C#)

이 폴더는 C# 언어 노트의 그룹 소개다. 폴더 이름은 `c`이지만 내용은 C 언어가 아니라 C#이다. C 언어와 C++ 문서는 [C 및 C++ (C & C++)](../c-and-c++/README.md)에 있다.

{% hint style="info" %}
NOTE: 폴더 이름 `c`는 C#의 `#`를 경로에 쓸 수 없어 붙은 이름이다. C# 문서는 하위 폴더 `csharp/`에 있다.
{% endhint %}
