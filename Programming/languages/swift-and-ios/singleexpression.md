## 1. 정의

단일 표현식(single expression)은 값을 계산하는 식 하나로 이뤄진 본문이다. 본문이 단일 표현식이면 `return`을 생략할 수 있고 그 식의 값이 반환된다. 이 규칙은 클로저에 먼저 도입되었고, Swift 5.1부터 함수·계산 프로퍼티 본문에도 적용된다.

## 2. 구성 요소

| 대상 | `return` 생략 | 시작 버전 |
|---|---|---|
| 클로저 | 가능 | 초기부터 |
| 함수, 메서드 | 가능 | Swift 5.1 |
| 계산 프로퍼티 `get` | 가능 | Swift 5.1 |
| `if`, `switch` 식 | 가능(각 분기가 단일 표현식) | Swift 5.9 |

## 3. 동작 원리

1. 본문에 문장이 하나뿐이고 그것이 식이면 컴파일러가 그 값을 반환값으로 본다.
2. 식의 타입이 선언된 반환 타입과 같아야 한다.

## 4. 예제 코드

```swift
/* // 축약 전 클로저
 * let add: (Int, Int) -> Int = { (a, b) in
 *     return a + b
 * }
 */

// 축약 후 클로저
let add: (Int, Int) -> Int = { $0 + $1 }
print(add(3, 4))
```

함수 본문에서도 같은 규칙이 적용된다.

```swift
func square(_ n: Int) -> Int { n * n }   // Swift 5.1 이상

let x = 3
let y = 5
let result = (x > y) ? x : y    // 조건 연산자도 단일 표현식이다
```

## 5. 코드 설명

| 위치 | 설명 |
|---|---|
| `{ $0 + $1 }` | 타입이 변수 선언 `(Int, Int) -> Int`에서 정해지므로 추론된다 |
| `square` | 본문이 `n * n` 하나라 `return`을 생략했다 |
| `(x > y) ? x : y` | 조건이 참이면 `x`, 아니면 `y`다. 원본에서 정의되지 않았던 `x`, `y`를 선언했다 |

## 6. 한계·주의

- 본문에 문장이 둘 이상이면 `return`을 써야 한다.
- 단순한 연산에서 가독성을 높이는 용도이며, 복잡한 식을 한 줄로 쓰면 오히려 읽기 어렵다.
