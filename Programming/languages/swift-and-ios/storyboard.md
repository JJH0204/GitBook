## 1. 정의

스토리보드(Storyboard)는 앱의 화면(씬, scene)과 화면 사이 전환을 시각적으로 구성하는 Xcode Interface Builder의 파일 형식(`.storyboard`)이다. UIKit 기반 UI를 드래그 앤 드롭으로 만들 수 있다. 내부는 XML이다.

## 2. 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 씬 (scene) | 뷰 컨트롤러 하나와 그 화면 |
| 세그 (segue) | 씬 사이 전환 |
| 초기 뷰 컨트롤러 (Initial View Controller) | 앱이 처음 보여 주는 씬 |
| `@IBOutlet`, `@IBAction` | 스토리보드의 뷰와 코드를 연결한다 |
| Auto Layout | 제약 조건으로 화면 크기에 맞춰 배치한다 |

## 3. 동작 원리

1. 스토리보드에서 뷰를 배치하고 제약 조건을 설정한다.
2. 뷰를 코드의 `@IBOutlet`(참조) 또는 `@IBAction`(이벤트)에 연결한다.
3. 앱 실행 시 스토리보드가 로드되어 뷰 컨트롤러와 뷰 인스턴스가 만들어지고 연결이 복원된다.

## 4. 장점과 단점

| 구분 | 항목 | 설명 |
|---|---|---|
| 장점 | 시각적 도구 | Interface Builder로 컴포넌트를 눈으로 보며 배치한다 |
| 장점 | 멀티 스크린 관리 | 한 스토리보드에서 여러 화면과 전환을 설정한다 |
| 장점 | 즉각적인 피드백 | UI 변경을 바로 확인한다 |
| 단점 | 복잡한 프로젝트의 한계 | 화면이 많아지면 파일이 무거워지고 관리가 어렵다 |
| 단점 | 협업 문제 | 소스 코드 관리 시스템에서 병합 충돌이 나기 쉽다 |
| 단점 | 런타임 오류 | 연결 오류(예: 지워진 `@IBOutlet` 연결)는 컴파일이 아니라 실행 시 발견된다 |
