## 1. 정의

클래스는 참조 타입이고 구조체는 값 타입이다. 둘 다 프로퍼티, 메서드, 이니셜라이저, 프로토콜 채택을 지원하며 가장 큰 차이는 복사 방식이다. 각각의 상세는 [구조체](struct.md), [클래스 개념](classconcepts.md)에 있다.

## 2. 구성 요소

| 특성 | Class | Struct |
|---|---|---|
| 타입 | 참조 타입 (Reference Type) | 값 타입 (Value Type) |
| 상속 | 가능 | 불가 |
| 인스턴스 | 하나의 인스턴스를 여러 참조가 공유 | 각 변수가 독립적인 복사본 |
| 이니셜라이저 | 멤버와이즈 이니셜라이저 없음. 모든 프로퍼티에 기본값이 있으면 `init()`을 제공 | 멤버와이즈 이니셜라이저 자동 제공(기본값 유무와 무관) |
| 소멸자 | `deinit` 사용 가능 | 없음 |
| ARC | 대상이다 | 구조체 자체는 아니다. 클래스 참조를 멤버로 가지면 그 참조는 ARC로 관리된다 |
| 복사 시 | 참조가 복사된다 | 인스턴스 전체가 복사된다 |
| 메서드에서 프로퍼티 변경 | `mutating` 불필요 | `mutating` 필요 |
| 동일성 비교 | `===`(같은 인스턴스인지) | 해당 없음(값 비교는 `==`, `Equatable` 필요) |
| `let` 선언의 의미 | 참조가 상수다. 프로퍼티(`var`)는 바꿀 수 있다 | 인스턴스 전체가 상수다. 프로퍼티를 바꿀 수 없다 |
| 프로토콜 채택 | 가능 | 가능 |
| 예시 | `UIViewController`, `UIView` | `CGPoint`, `CGSize` |

## 3. 동작 원리

### 3-1. 복사 동작

```swift
struct PointS { var x = 0 }
class PointC { var x = 0 }

var s1 = PointS()
var s2 = s1          // 복사
s2.x = 5
print(s1.x)          // 0

let c1 = PointC()
let c2 = c1          // 참조 복사
c2.x = 5
print(c1.x)          // 5
print(c1 === c2)     // true
```

### 3-2. 이니셜라이저

구조체는 기본값 유무와 상관없이 멤버와이즈 이니셜라이저를 자동 제공한다. 기본값이 있는 프로퍼티는 인자를 생략할 수 있다. 구조체 본문에 사용자 정의 `init`을 만들면 멤버와이즈 이니셜라이저는 사라진다.

### 3-3. 메모리

클래스 인스턴스는 ARC가 관리한다. 구조체는 ARC 대상이 아니지만, 구조체 안의 클래스 참조 프로퍼티는 참조 횟수가 관리된다.

### 3-4. 메서드 변경

클래스 메서드는 인스턴스 프로퍼티를 바로 바꿀 수 있다. 구조체 메서드는 `mutating`이 필요하다.

## 4. 선택 기준

| 상황 | 선택 |
|---|---|
| 데이터가 단순하고 복사 의미가 자연스럽다 | 구조체 |
| 불변성·스레드 안전이 중요하다 | 구조체 |
| 상속이 필요하거나 여러 곳에서 같은 인스턴스를 공유해야 한다 | 클래스 |
| 정체성(identity)이 있는 객체(`deinit` 정리 필요) | 클래스 |
| Objective-C와 연동한다 | 클래스(`NSObject`) |

{% hint style="info" %}
NOTE: 표준 라이브러리의 `Array`, `String` 등은 구조체이며 값 의미를 유지하면서 쓰기 시점에 복사하는 방식(copy-on-write)으로 성능을 확보한다.
{% endhint %}
