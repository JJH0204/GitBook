## 이 그룹이 다루는 것

Swift에서 사용자 정의 타입을 만드는 세 방법인 구조체, 클래스, 열거형을 다룬다. 핵심 질문은 값 타입과 참조 타입의 차이다. Swift 기본 문법(변수, 함수, 옵셔널)을 익힌 뒤 읽는다.

## 선수 지식과 핵심 용어

* 값 타입: 대입하거나 함수에 전달할 때 값이 복사된다. 구조체와 열거형이 해당한다.
* 참조 타입: 대입할 때 같은 인스턴스를 가리킨다. 클래스가 해당한다.
* 멤버와이즈 이니셜라이저: 구조체가 저장 프로퍼티를 매개변수로 받는 이니셜라이저를 자동으로 갖는 기능.
* ARC(Automatic Reference Counting): 클래스 인스턴스의 참조 수를 세어 메모리를 자동 해제하는 방식.
* 연관값(associated value): 열거형 케이스에 붙이는 값.
