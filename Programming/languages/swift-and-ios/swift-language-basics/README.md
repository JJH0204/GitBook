# Swift 언어 기초 (Basics)

Swift의 사용자 정의 타입(구조체, 클래스, 열거형)을 정리한다. 문서 번호(Task ID)는 `PRG-SWF-<번호>-<유형>` 형식이며 상위 그룹 [Swift 및 iOS](../README.md)와 번호를 이어 쓴다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-SWF-012-DO | D&O + 예제 | [구조체](struct.md) | 값 타입과 멤버와이즈 이니셜라이저를 파악한다 |
| PRG-SWF-013-DO | D&O + 예제 | [클래스 개념](classconcepts.md) | 참조 타입, 상속, ARC를 파악한다 |
| PRG-SWF-014-DO | D&O | [클래스 대 구조체 비교](classvsstructdifference.md) | 둘의 차이와 선택 기준을 파악한다 |
| PRG-SWF-015-DO | D&O + 예제 | [열거형](enumerationtype.md) | 케이스, 연관값, 원시값을 파악한다 |

## 읽는 순서

1. PRG-SWF-012-DO와 PRG-SWF-013-DO를 읽는다.
2. PRG-SWF-014-DO로 둘을 비교한다.
3. PRG-SWF-015-DO를 읽는다.
