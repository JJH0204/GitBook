## 주요 기능 표

| 기능 | 한 줄 설명 | 상세 문서 |
|---|---|---|
| 옵셔널 (Optionals) | 값이 없을 수 있는 경우(`nil`)를 타입으로 표현해 안전하게 처리한다 | [옵셔널](optionals.md) |
| 클로저 (Closures) | 이름 없는 함수를 값으로 정의한다. 콜백을 간결하게 쓴다 | [클로저](closures.md) |
| 프로토콜 (Protocol) | 메서드, 프로퍼티, 기타 요구사항의 묶음이다. 클래스, 구조체, 열거형이 채택해 구현한다 | [Swift 프로토콜](swift_protocol.md) |
| 제네릭 (Generics) | 타입을 매개변수로 두어 코드 중복을 줄이고 타입 안전을 유지한다 | 별도 문서 없음 |

{% hint style="info" %}
NOTE: 원본의 "프로토콜" 링크가 네트워크 프로토콜 글을 가리켰다는 진단이 있었다. 현재 링크는 Swift 프로토콜 문서([swift_protocol.md](swift_protocol.md))를 가리킨다. 원본의 채팅체 문장과 깨진 서식(`**제네릭 프로그래밍****(Generics)**`)을 정리했다.
{% endhint %}
