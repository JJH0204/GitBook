## 1. 정의

포인터(pointer)는 다른 변수의 메모리 주소를 값으로 가지는 변수다. `int *p`는 "`int`의 주소를 저장하는 변수"다.

## 2. 구성 요소

| 요소 | 문법 | 역할 |
|---|---|---|
| 주소 연산자 | `&n` | 변수 `n`의 주소를 얻는다 |
| 포인터 선언 | `int *p = &n;` | `n`의 주소를 `p`에 저장한다 |
| 역참조 | `*p` | `p`가 가리키는 위치의 값을 읽거나 쓴다 |
| 널 포인터 | `NULL` | 어떤 객체도 가리키지 않는다. 역참조하면 UB다 |

## 3. 동작 원리

```
n          pointer_to_n
+----+     +--------+
| 11 | <---| &n     |
+----+     +--------+
```

`n++`로 `n`이 11이 되면 `*pointer_to_n`도 11이다. 둘이 같은 메모리를 보기 때문이다.

## 4. 예제 코드

{% code title="pointers.c" %}
```c
//pointers.c
#include <stdio.h>

int main(void)
{
    int n = 10;

    /* your code goes here */
    int * pointer_to_n = &n;
    n++;

    /* testing code */
    if (pointer_to_n != &n)
        return 1;
    if (*pointer_to_n != 11)
        return 1;

    printf("Done!\n");
    return 0;
}
```
{% endcode %}

## 5. 코드 설명

1. `n`을 10으로 초기화한다.
2. `pointer_to_n`에 `n`의 주소를 저장한다.
3. `n++`로 `n`이 11이 된다.
4. `pointer_to_n != &n`이 거짓이므로 첫 검사를 통과한다.
5. `*pointer_to_n`은 11이므로 두 번째 검사도 통과해 `Done!`을 출력한다.

## 6. 한계·주의

* 초기화하지 않은 포인터(와일드 포인터)를 역참조하면 UB다. 선언할 때 `NULL` 또는 유효한 주소로 초기화한다.
* 지역 변수의 주소를 함수 밖으로 반환하면, 함수 종료 후 그 주소는 유효하지 않다(해제 후 사용과 같은 UB).
* 선언 `int * p, q;`에서 `q`는 포인터가 아니라 `int`다. 포인터 변수는 하나씩 선언한다.
