# C 및 C++ (C & C++)

C 언어와 C++ 언어 학습 노트의 그룹 소개다. C# 문서는 이 폴더가 아니라 [C# 언어 (C#)](../c/README.md)에 있다.

문서 번호(Task ID)는 `PRG-LNG-<번호>-<유형>` 형식이다. 이 폴더 바로 아래 문서는 `LNG`, `advanced-c/` 문서는 `ADC` 그룹이다.

## 문서 목록

| 위치 | 문서 | 용도 |
|---|---|---|
| 이 폴더 | [C/C++ 학습 개요](ccppintro.md) | 학습 주제와 폴더 구성을 확인한다 |
| `setup/` | [C/C++ 개발 환경 설정](setup/README.md) | 개발 환경을 설정한다 |
| `c-fundamentals/` | [C 언어 기초 (C Fundamentals)](c-fundamentals/README.md) | 변수, 조건문, 반복문, 함수, 배열, 문자열을 학습한다 |
| `data-structures-c/` | [C 자료구조 (Data Structures)](data-structures-c/README.md) | 구조체와 공용체를 학습한다 |
| `pointers-and-memory/` | [포인터와 메모리 (Pointers)](pointers-and-memory/README.md) | 포인터와 동적 메모리 할당을 학습한다 |
| `advanced-c/` | [C 언어 고급 (Advanced C)](advanced-c/README.md) | 함수 포인터, 제네릭 프로그래밍, 비트마스크, `memset` 경고를 학습한다 |
| `build-and-tooling/` | [빌드 및 도구 (Build & Tools)](build-and-tooling/README.md) | 전처리, 컴파일, CMake를 학습한다 |
| `c++-track/` | [C++ 과정 (C++ Track)](c++-track/README.md) | C++ 문법과 형변환을 학습한다 |
