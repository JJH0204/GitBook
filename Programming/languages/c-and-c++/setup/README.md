# [생성형 AI] C/C++ 개발 환경 설정

C/C++ 코드를 작성하고 컴파일하기 위한 개발 환경 설정 절차와 학습 순서를 정리한다. 문서 번호(Task ID)는 `PRG-CST-<번호>-<유형>` 형식이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (환경 설정 절차를 실행하지 않았다. 하위 문서의 내용을 요약했다) |

## 이 그룹은 무엇인가

C/C++ 코드를 작성하려면 컴파일러와 편집기가 필요하다. 이 그룹은 VS Code와 컴파일러를 설치하는 절차(MP)와, C 언어를 어떤 순서로 학습할지 정리한 로드맵(REF)을 둔다. 처음 시작하는 사람은 환경 설정을 먼저 끝낸 뒤 로드맵을 본다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-CST-001-MP | 절차 | [VS Code C/C++ 환경 설정](intro.md) | Windows(MinGW-w64) 또는 macOS에서 컴파일러와 VS Code를 설치한다 |
| PRG-CST-002-REF | 표 | [C 언어 학습 로드맵 및 메모](clanguage.md) | C 학습 주제 순서와 관련 문서 위치를 확인한다 |

## 읽는 순서

1. PRG-CST-001-MP로 환경을 설정한다.
2. PRG-CST-002-REF에서 학습 주제를 고른다.
3. 코드 학습은 [C 언어 기초](../c-fundamentals/README.md)부터 시작한다.

## 핵심 용어

| 용어 | 뜻 |
|---|---|
| 컴파일러 | 소스 코드를 실행 파일로 번역하는 프로그램(예: MinGW-w64의 gcc, macOS의 clang) |
| 편집기·IDE | 코드를 작성하는 도구(예: VS Code) |
| 빌드 | 컴파일과 링크를 거쳐 실행 파일을 만드는 과정 |
