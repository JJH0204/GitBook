## 이 그룹이 다루는 것

C에는 클래스가 없고 여러 값을 묶는 방법으로 구조체(`struct`)와 공용체(`union`)를 쓴다. 이 그룹은 두 자료형의 정의, 멤버 접근, 메모리 배치 차이를 다룬다. 입문자는 C 기본 문법(변수, 배열, 포인터)을 익힌 뒤 읽는다.

## 선수 지식과 핵심 용어

* 선수 지식: C의 기본 자료형, 배열, 포인터.
* 구조체(`struct`): 서로 다른 자료형의 멤버를 하나로 묶고, 멤버마다 별도 메모리를 갖는다.
* 공용체(`union`): 모든 멤버가 같은 메모리를 공유하며 크기는 가장 큰 멤버 기준이다.
* `typedef`: 기존 자료형에 새 이름을 붙이는 선언.
* 멤버 접근 연산자: 변수에는 `.`, 포인터에는 `->`를 쓴다.
