# C 자료구조 (Data Structures)

C 언어의 사용자 정의 자료형인 구조체와 공용체를 정리한 그룹이다. 문서 번호(Task ID)는 `PRG-DSC-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-DSC-001-DO | D&O + 예제 | [구조체 (Structures)](structures.md) | `typedef struct` 정의와 멤버 접근을 이해한다 |
| PRG-DSC-002-DO | D&O + 예제 | [공용체 상세 (Unions)](unions_kr.md) | 메모리를 공유하는 공용체와 태그된 유니언을 이해한다 |

## 읽는 순서

1. PRG-DSC-001-DO로 구조체를 익힌다.
2. PRG-DSC-002-DO에서 구조체와 공용체를 결합하는 방법을 본다.
