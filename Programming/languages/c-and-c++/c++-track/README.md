# [생성형 AI] C++ 과정 (C++ Track)

C 언어 학습 이후 C++로 넘어가며 정리하는 그룹이다. 문서 번호(Task ID)는 `PRG-CPP-<번호>-<유형>` 형식이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (C++ 컴파일러로 실행하지 않았다. 하위 문서의 내용을 요약했다) |

## 이 그룹은 무엇인가

C 언어 문법을 학습한 뒤 C++로 넘어갈 때 참고하는 노트 모음이다. C++는 C의 문법을 대부분 포함하면서 클래스, 참조, 템플릿, 표준 라이브러리를 더한 언어이다. 문서 수는 적고 작성 예정 주제가 [C++ 문법 및 기본 개념 (C++)](c++.md)에 정리되어 있다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-CPP-001-REF | REF | [C++ 문법 및 기본 개념 (C++)](c++.md) | 기본 자료형 크기를 찾고 작성 예정 주제를 확인한다 |
| PRG-CPP-002-DO | D&O + 예제 | [형변환 (Type Cast)](type-cast.md) | 암시적·명시적 형변환과 C++ 캐스트 4종을 이해한다 |

## 읽는 순서

1. PRG-CPP-001-REF로 자료형을 확인한다.
2. PRG-CPP-002-DO로 형변환을 익힌다.
