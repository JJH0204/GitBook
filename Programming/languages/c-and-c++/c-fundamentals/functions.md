## 1. 정의

함수는 이름을 붙인 코드 묶음이다. 입력(매개변수)을 받아 일을 하고 값을 반환할 수 있다.

## 2. 구성 요소

| 요소 | 예 | 역할 |
|---|---|---|
| 반환 형식 | `void`, `int` | 함수가 돌려주는 값의 형식. `void`는 반환 값이 없다 |
| 함수 이름 | `print_big` | 호출할 때 쓰는 이름 |
| 매개변수 | `int number` | 호출 시 전달받는 값. 값이 복사되어 전달된다(값에 의한 전달) |
| 본문 | `{ ... }` | 실행할 코드 |
| 호출 | `print_big(array[i]);` | 인자를 넘겨 함수를 실행한다 |

## 3. 예제 코드

{% code title="functions.c" %}
```c
//functions.c
#include <stdio.h>

void print_big(int number)
{
    if (number > 10)
    {
        printf("%d is big\n", number);
    }
}

int main(void)
{
    int array[] = {1, 11, 2, 22, 3, 33};
    int i;
    for (i = 0; i < 6; i++)
    {
        print_big(array[i]);
    }
    return 0;
}
```
{% endcode %}

## 4. 코드 설명

1. `print_big`은 `number`가 10보다 크면 `<값> is big`을 출력한다. 반환 값은 없다.
2. `main`은 6개 요소 배열을 순회하며 각 값을 `print_big`에 넘긴다.
3. 예상 출력: `11 is big`, `22 is big`, `33 is big`을 한 줄씩.
4. 매개변수 `number`는 인자의 복사본이다. 함수 안에서 바꿔도 호출한 쪽 변수는 변하지 않는다. 호출한 쪽 값을 바꾸려면 포인터를 넘긴다. [참조에 의한 전달](../pointers-and-memory/function-arguments-by-reference.md)을 본다.

## 5. 한계·주의

* 함수는 호출보다 먼저 정의하거나 선언(프로토타입)해야 한다. C99부터 선언 없는 함수 호출(암시적 선언)은 허용되지 않는다.
* 인자가 없는 함수는 `void f(void)`로 쓴다. `void f()`는 C에서 "인자 정보 없음"이다.
