## 1. 목적

Python은 시스템 자동화와 데이터 분석에 널리 쓰이는 범용 언어다. 이 문서는 문법을 외우기 전에 알아야 할 실행 방식과 언어 특성을 정리한다. 설치·환경 설정은 [Python 개발 환경 및 문법](python.md)(PRG-PYT-002-REF)을 본다.

## 2. 구성 요소

| 특성 | 내용 |
|---|---|
| 실행 방식 | 별도의 빌드 단계 없이 `python 파일.py`로 실행한다. 단, 기본 구현체 CPython은 소스를 바이트코드로 컴파일한 뒤 가상 머신이 실행한다 |
| 바이트코드 캐시 | 모듈을 `import`하면 컴파일 결과를 `__pycache__/*.pyc`에 저장해 다음 실행에 재사용한다 |
| 타입 | 동적 타입이다. 변수에 타입을 선언하지 않고 값(객체)이 타입을 가진다. 타입 힌트(`x: int`)는 실행에 강제되지 않는다 |
| 블록 | 중괄호 대신 들여쓰기로 블록을 구분한다 |
| 메모리 | 참조 카운팅과 순환 참조 수집기(가비지 컬렉터)로 자동 관리한다 |
| GIL | CPython은 전역 인터프리터 락(Global Interpreter Lock)으로 한 시점에 하나의 스레드만 파이썬 바이트코드를 실행한다 |

## 3. 동작 원리

1. 소스 파일(`.py`)을 읽는다.
2. CPython이 소스를 바이트코드로 컴파일한다.
3. 가상 머신이 바이트코드를 한 명령씩 실행한다.

{% hint style="info" %}
NOTE: GIL 때문에 CPU를 많이 쓰는 작업은 스레드로 빨라지지 않는다. 이 경우 `multiprocessing`을 쓴다. 입출력 대기가 많은 작업은 스레드나 `asyncio`로 이득을 본다. GIL을 끌 수 있는 빌드(free-threaded)는 Python 3.13부터 실험적으로 제공된다.
{% endhint %}

## 4. 최소 문법 예

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

if __name__ == "__main__":
    print(greet("Python"))
```

* `def`로 함수를 정의하고 본문은 4칸 들여쓴다.
* `f"..."`는 문자열 안에 식을 넣는 f-string(Python 3.6 이상)이다.
* `if __name__ == "__main__":`은 파일을 직접 실행할 때만 아래 블록을 실행한다.
