## 이 그룹에서 다루는 범위

| 주제 | 상태 | 요점 |
|---|---|---|
| 실행 모델 | 작성됨 (PRG-PHP-001-DO) | 서버가 `.php` 파일을 PHP 인터프리터에 넘기고, `<?php ... ?>` 안의 코드만 실행한다. 태그 밖 텍스트는 그대로 출력된다 |
| 설정 | 작성됨 (PRG-PHP-001-DO) | 설정은 `php.ini`에 있고, `disable_functions`로 함수 실행을 막는다 |
| 변수, 배열, 함수, 클래스 | 미작성 | 이 환경에서 코드를 실행해 확인할 수 없어 보류했다 |
| 웹 입력 처리와 보안 | 미작성 | 사용자 입력 검증과 방어 관점의 정리가 필요하다 |

## 읽는 순서

1. PRG-PHP-001-DO로 실행 모델과 `phpinfo()`의 위험을 읽는다.
2. 웹의 요청·응답 구조는 [웹 기술 (Web Technologies)](../../cs_basics/web_technologies/README.md)에서 확인한다.
