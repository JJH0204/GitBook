## 1. 정의

자료구조(data structure)는 효율적인 접근과 수정을 위한 자료의 조직, 관리, 저장 체계다. 데이터 값의 모임, 데이터 사이의 관계, 데이터에 적용할 수 있는 함수나 명령을 포함한다.

* 자료구조 선택은 메모리 사용 효율과 알고리즘 성능에 직접 영향을 준다.
* 자료구조는 프로그램 설계 초기에 고려한다. 접근·삽입·삭제 패턴이 이미 정해져 있으면 그에 맞는 자료구조를 먼저 정할 수 있다.

{% hint style="info" %}
NOTE: 자료구조는 추상 자료형(ADT, Abstract Data Type)과 구현으로 나눠 볼 수 있다. ADT는 어떤 연산을 제공하는지(예: 스택의 push, pop)를 정하고, 구현은 그 연산을 배열이나 연결 리스트로 만드는 방법이다. 같은 ADT도 구현에 따라 복잡도가 달라진다.
{% endhint %}

## 2. 구성 요소: 자료구조의 종류

| 구조 | 설명 | 요소 |
|---|---|---|
| 단순 | 값 하나를 표현하는 기본 자료형 | 정수, 실수, 문자, 문자열 |
| 선형 | 요소가 한 줄로 순서를 이루는 구조. 이전·다음 요소가 최대 하나씩 있다 | 리스트, 연결 리스트, 스택, 큐, 덱 |
| 비선형 | 요소가 계층 또는 망 형태로 연결돼 한 요소에 여러 요소가 이어질 수 있다 | 트리, 그래프 |
| 파일 구조 | 파일에 저장하는 방식 | 순차 파일, 색인 파일, 직접 파일 |

* 원본 표에 있던 "알고리즘 포함 여부" 열은 구분 기준이 되지 않아 삭제했다.
* 선형 구조는 [선형 자료구조 개요 (Linear)](datastructuresalgorithms/lineardatastructureoverview.md), 비선형 구조는 [비선형 자료구조 (Non-linear)](../data-structures/non-linear-data-structure.md)(PRG-DST-002-DO)에서 다룬다.

## 3. 동작 원리: 자료구조의 선택

효율적인 알고리즘을 위해 자료구조를 알맞게 고른다. 다음 질문으로 후보를 줄인다.

| 질문 | 알맞은 구조의 예 |
|---|---|
| 인덱스로 자주 접근하는가 | 배열 (접근 O(1)) |
| 맨 앞이나 중간에 삽입·삭제가 잦은가 | 연결 리스트 (위치를 알면 O(1)) |
| 가장 최근에 넣은 것을 먼저 꺼내는가 | 스택 (LIFO) |
| 먼저 넣은 것을 먼저 꺼내는가 | 큐 (FIFO) |
| 계층 관계를 표현하는가 | 트리 |
| 임의의 관계(네트워크)를 표현하는가 | 그래프 |
| 키로 빠르게 찾는가 | 해시 테이블(평균 O(1)), 이진 탐색 트리(평균 O(log n)) |
| 최솟값·최댓값을 반복해서 꺼내는가 | 힙 |

선택 후에는 [알고리즘 개요 (Algorithm)](algorithmoverview.md)(PRG-OVW-001-DO)의 복잡도 표기로 연산 비용을 비교한다.
