## 1. 정의

알고리즘(algorithm)은 어떤 문제를 해결하기 위한 일련의 절차를 공식화해 표현한 것이다. 주어진 문제를 컴퓨터로 해결하는 데 쓴다.

## 2. 알고리즘의 조건

| 조건 | 내용 |
|---|---|
| 입력 | 0개 이상의 외부 입력이 있다 |
| 출력 | 1개 이상의 출력이 있다 |
| 명확성 | 각 명령은 모호하지 않고 명확하다 |
| 유한성 | 일정한 시간 안에 반드시 종료된다 |
| 유효성 | 모든 명령은 컴퓨터에서 수행할 수 있다. 모든 과정이 명백하게 실행 가능하다 |

## 3. 알고리즘의 생성 단계

1. 설계: 상향식 또는 하향식으로 설계한다.
2. 표현: 자연어, 순서도, 의사코드, 프로그래밍 언어 중 하나로 표현한다.
3. 정확성: 타당한 입력이 주어졌을 때 유한 시간 안에 계산을 마치고 올바른 결과를 출력하는지 확인한다.
4. 효율성: 저장 공간과 연산 수행의 효율을 확인한다.

## 4. 알고리즘의 표현 방법

### 4-1. 자연어

* 사람의 언어로 쓴다. 표현하기 가장 쉽지만 모호해지기 쉽다.

### 4-2. 순서도(flowchart)

* 약속된 기호를 박스와 연결선으로 그려 표현한 도표다.
* 프로그램의 설계도 역할을 한다.
* 이해와 추적이 쉬워 오류를 찾기 쉽다.
* 국제 표준(ISO 5807)이 있다.

| 심벌 모양 | 이름 | 의미 |
|---|---|---|
| 타원(양 끝이 둥근 사각형) | 시작/끝 | 순서도의 시작과 끝 |
| 직사각형 | 처리 | 지정된 동작, 연산, 값, 데이터의 이동 등 모든 처리 과정 |
| 마름모 | 판단 | 주어진 조건을 비교한 뒤 조건에 따라 왼쪽 또는 오른쪽으로 흐름이 나뉜다 |
| 평행사변형 | 입력/출력 | 일반적인 입력과 출력 |
| 원 | 연결자 | 흐름이 다른 곳으로 연결되거나 다른 곳에서 연결되는 입구 |
| 아래가 물결 모양인 사각형 | 프린트(문서) | 프린터를 통한 출력 |
| 화살표 | 흐름선 | 명령의 흐름. 화살표 방향 순서로 진행한다 |

### 4-3. 의사코드(pseudo code)

* 수도코드라고도 한다.
* 알고리즘이나 자료구조를 표현할 때 쓴다.
* 특정 언어 문법 없이 코드를 흉내 내어 사고의 흐름을 간결하게 전달한다.

### 4-4. 프로그래밍 언어

* C, C++, Python 등으로 표현한다. 컴퓨터가 수행할 수 있는 명령의 집합이다.
* 언어마다 문법과 사용법이 달라 학습이 필요하다.

## 5. 유용한 알고리즘 4가지

| 종류 | 설명 | 대표 알고리즘 |
|---|---|---|
| 정렬 | 원소를 일정한 순서로 나열한다. 다른 알고리즘(예: 이진 탐색)의 전제가 되기도 한다 | 버블, 선택, 삽입, 쉘, 힙, 기수, 외부 정렬 |
| 탐색 | 데이터를 효율적으로 찾는다 | 순차 탐색, 이진 탐색, 레드 블랙 트리 |
| 그래프 | 정점(vertex)과 간선(edge)으로 표현한다. 정점은 다양한 자료구조로, 간선은 정점 사이의 인접 관계로 표현한다 | 순회(DFS, BFS), 최소 신장 트리(프림, 크러스컬), 최단 경로(다익스트라, 벨만-포드) |
| 문자열 검색 | 문자열 안에서 특정 단어를 빠르게 찾는다 | 카프-라빈, KMP, 보이어-무어 |

그래프 알고리즘은 목적에 따라 나뉜다. 프림과 크러스컬은 최소 신장 트리 알고리즘이고, 다익스트라는 최단 경로 알고리즘이다. 이들은 순회(DFS, BFS)가 아니다.

관련 문서는 [선택 정렬 (Selection Sort)](../algorithms/selection-sort.md)(PRG-ALG-001-DO), [깊이 우선 탐색 (DFS)](../algorithms/depthfirstsearch.md)(PRG-ALG-002-DO)다.

## 6. 문제 해결 방식에 따른 알고리즘

### 6-1. 분할정복(divide and conquer)

* 입력을 나누어 같은 알고리즘을 적용해 해를 구하고, 그 해들을 합쳐 원래 문제의 해를 얻는다.
* 부분문제(분할된 입력에 대한 문제)와 부분해(부분문제의 해)로 부른다.
* 더 이상 나눌 수 없을 때까지 분할한다.
* 합병 정렬과 퀵 정렬이 대표적이다.

### 6-2. 그리디(greedy)

* 최적화 문제에서 각 단계마다 그 순간 가장 좋아 보이는 선택을 하는 방법이다. 욕심쟁이 방법, 탐욕 알고리즘이라고도 한다.
* 단순하다. 다만 항상 최적해를 보장하지 않으며 문제가 특정 성질을 가질 때만 쓸 수 있다.

### 6-3. 동적 계획법(dynamic programming)

* 동적 프로그래밍이라고도 한다.
* 문제가 중복되는 부분문제와 최적 부분 구조를 가질 때 쓴다. 부분문제의 해를 저장해 다시 계산하지 않는다.
* 구현 방식은 두 가지다. 메모이제이션(memoization, top-down)은 재귀하며 결과를 저장한다. 타뷸레이션(tabulation, bottom-up)은 작은 부분문제부터 표를 채운다.

## 7. 어려운 문제를 다루는 알고리즘

NP-완전(NP-complete) 문제는 다음 세 조건을 모두 만족하는 알고리즘이 알려져 있지 않다. 일반적으로 존재하지 않을 것으로 믿는다(P ≠ NP 가정).

* 다항식 시간에 해를 찾는다.
* 모든 입력에 대해 해를 찾는다.
* 최적해를 찾는다.

### 7-1. 근사 알고리즘

* 최적해를 포기하고, 다항식 시간에 모든 입력에 대해 해를 찾는 알고리즘이다.
* 최적해 대신 근사해를 찾으므로 근사 비율과 함께 결과를 제시해야 한다.
* 여행자 문제(TSP), 정점 커버 문제, 통 채우기 문제, 작업 스케줄링 문제 등을 다룬다.

### 7-2. 해 탐색 알고리즘

* NP-완전 문제의 해를 탐색한다.
* 백트래킹, 분기 한정, 모의 담금질 기법 등이 있다.

{% hint style="info" %}
NOTE: 근사, 백트래킹, 분기 한정은 인공지능 알고리즘이 아니다. NP-완전 문제와 최적화 문제의 해법이다. 원본은 이들을 "인공지능 알고리즘" 아래에 분류했으나 정정했다.
{% endhint %}

## 8. 학습 알고리즘

* 기계학습(머신러닝)이라고도 한다. 경험(데이터)을 통해 성능을 자동으로 개선한다.
* 인공 신경망이 대표적이다.

## 9. 복잡도 분석

알고리즘의 효율은 입력 크기 n에 대한 시간(연산 횟수)과 공간(메모리)의 증가율로 비교한다. 빠른 쪽에서 느린 쪽 순서는 다음과 같다.

| 표기 | 이름 | 예 |
|---|---|---|
| O(1) | 상수 | 배열 인덱스 접근 |
| O(log n) | 로그 | 이진 탐색 |
| O(n) | 선형 | 순차 탐색 |
| O(n log n) | 선형 로그 | 합병 정렬, 힙 정렬, 퀵 정렬(평균) |
| O(n²) | 제곱 | 버블, 선택, 삽입 정렬 |
| O(2ⁿ) | 지수 | 부분집합을 모두 나열하는 완전 탐색 |
