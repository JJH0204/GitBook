## 1. 정의

버블 정렬은 인접한 두 요소를 비교해 순서가 맞지 않으면 교환하는 과정을 반복하는 비교 기반 정렬이다. 한 번 훑을 때마다 가장 큰(또는 작은) 요소가 거품이 떠오르듯 구간의 끝으로 이동해 이런 이름이 붙었다. 이해하기 쉽지만 큰 입력에는 쓰지 않는다.

## 2. 동작 원리

1. 첫 번째 요소와 두 번째 요소를 비교해, 앞이 더 크면 교환한다.
2. 한 칸 뒤로 이동해 인접한 두 요소를 같은 방식으로 비교·교환한다.
3. 구간의 끝까지 반복한다. 가장 큰 요소가 구간의 맨 끝에 놓인다.
4. 맨 끝 요소를 제외한 나머지 구간에 1~3을 반복한다.
5. 한 번 훑는 동안 교환이 한 번도 없으면 정렬이 끝난 것이므로 종료한다(교환 없음 검사).

`{64, 25, 12, 22, 11}`의 진행 과정이다. `|` 오른쪽이 확정된 구간이다.

| 패스 | 비교 횟수 | 패스 종료 후 배열 | 교환 횟수 |
|---|---|---|---|
| 시작 | - | `64 25 12 22 11` | - |
| 1 | 4 | `25 12 22 11 \| 64` | 4 |
| 2 | 3 | `12 22 11 \| 25 64` | 3 |
| 3 | 2 | `12 11 \| 22 25 64` | 1 |
| 4 | 1 | `11 \| 12 22 25 64` | 1 |

총 비교 10회, 총 교환 9회다. 교환 횟수는 입력의 역전 쌍(앞이 뒤보다 큰 쌍) 수와 같다.

## 3. 복잡도와 성질

| 항목 | 값 | 비고 |
|---|---|---|
| 시간(최선) | O(n) | 이미 정렬돼 있으면 한 번 훑고 교환이 없어 종료한다. 교환 없음 검사가 있을 때만이다 |
| 시간(평균) | O(n²) | |
| 시간(최악) | O(n²) | 역순 입력. 비교 n(n−1)/2회 |
| 공간 | O(1) | 제자리(in-place) 정렬 |
| 안정성 | 안정 | 값이 같은 요소는 교환하지 않는다(`>` 비교) |

{% hint style="info" %}
NOTE: 교환 없음 검사가 없는 버블 정렬은 최선도 O(n²)다. 최선 O(n)은 검사를 넣은 변형의 값이다. 안정성은 비교를 `>`로 할 때 성립한다. `>=`로 바꾸면 같은 값도 교환해 불안정해진다.
{% endhint %}

일반적으로 삽입 정렬, 퀵 정렬 등이 더 빠르다. 비교표는 [정렬 알고리즘 비교 (Sort)](sortalgorithmoverview.md)를 따른다.

## 4. 예제 코드 (C)

{% code title="bubble_sort.c" %}
```c
#include <stdio.h>

void bubbleSort(int arr[], int n) {
	int i, j, temp;
	int swapped;

	for (i = 0; i < n - 1; i++) {
		swapped = 0;

		for (j = 0; j < n - i - 1; j++) {
			if (arr[j] > arr[j + 1]) {
				temp = arr[j];
				arr[j] = arr[j + 1];
				arr[j + 1] = temp;
				swapped = 1;
			}
		}

		if (swapped == 0) {
			break;
		}
	}
}

void printArr(int arr[], int n) {
	for (int i = 0; i < n; i++) {
		printf("%d ", arr[i]);
	}
	printf("\n");
}

int main(void) {
	int arr[] = {64, 25, 12, 22, 11};
	int n = sizeof(arr) / sizeof(arr[0]);

	printf("pre-sort: ");
	printArr(arr, n);

	bubbleSort(arr, n);

	printf("post-sort: ");
	printArr(arr, n);
	return 0;
}
```
{% endcode %}

출력 예:

```
pre-sort: 64 25 12 22 11 
post-sort: 11 12 22 25 64 
```

## 5. 코드 설명

| 위치 | 설명 |
|---|---|
| `for (i = 0; i < n - 1; i++)` | 바깥 반복. 패스 수를 센다. 최대 `n - 1`패스면 정렬이 끝난다 |
| `swapped = 0` | 패스마다 교환 여부를 초기화한다 |
| `j < n - i - 1` | 안쪽 반복의 끝. `i`번 패스를 마치면 뒤쪽 `i`개가 확정되므로 그 부분은 비교하지 않는다. `arr[j + 1]`이 배열 범위를 넘지 않게 하는 상한이기도 하다 |
| `arr[j] > arr[j + 1]` | 앞이 더 클 때만 교환한다. 같은 값은 교환하지 않아 안정성이 유지된다 |
| `if (swapped == 0) break;` | 교환 없음 검사. 이 줄이 최선 O(n)을 만든다 |
| `int main(void)` | 인자가 없음을 명시한 시그니처다. 원본의 `int main()`은 C에서 인자 개수를 지정하지 않은 선언이다 |
| `for (int i = 0; ...)` | 반복문 안의 변수 선언은 C99 이상에서 가능하다 |

## 6. 응용과 한계

### 6-1. 양방향 버블 정렬 (shaker sort)

한 번의 반복에서 오른쪽으로 훑어 가장 큰 요소를 끝으로, 왼쪽으로 훑어 가장 작은 요소를 앞으로 보낸다. 작은 값이 배열 끝에 있을 때 일반 버블 정렬은 한 패스에 한 칸씩만 앞으로 이동하는데, 양방향은 한 번에 끝까지 이동한다.

{% code title="shaker_sort.c" %}
```c
void shakerSort(int arr[], int n) {
	int left = 0, right = n - 1;
	int swapped, temp;

	do {
		swapped = 0;

		for (int i = left; i < right; i++) {
			if (arr[i] > arr[i + 1]) {
				temp = arr[i];
				arr[i] = arr[i + 1];
				arr[i + 1] = temp;
				swapped = 1;
			}
		}
		right--;

		for (int i = right; i > left; i--) {
			if (arr[i] < arr[i - 1]) {
				temp = arr[i];
				arr[i] = arr[i - 1];
				arr[i - 1] = temp;
				swapped = 1;
			}
		}
		left++;
	} while (swapped);
}
```
{% endcode %}

{% hint style="info" %}
NOTE: shaker sort는 일부 입력에서 비교 횟수를 줄이지만 최악 시간 복잡도는 O(n²)로 같다. 안정성도 유지된다.
{% endhint %}

### 6-2. 한계

* 평균·최악이 O(n²)이므로 n이 큰 입력에는 쓰지 않는다.
* 요소를 인접한 위치로만 옮기므로 이동 횟수가 많다. 같은 O(n²)인 선택 정렬은 교환이 최대 n−1회다.

## 7. 약어·용어

| 용어 | 뜻 |
|---|---|
| 패스(pass) | 배열을 한 번 훑는 반복 |
| 역전 쌍(inversion) | 앞 요소가 뒤 요소보다 큰 요소 쌍. 버블 정렬의 교환 횟수와 같다 |
| 제자리 정렬(in-place sort) | 상수 크기의 추가 메모리만 쓰는 정렬 |
| 안정 정렬(stable sort) | 값이 같은 요소의 원래 순서가 유지되는 정렬 |
