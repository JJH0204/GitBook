## 1. 정의

정렬(sort)은 요소를 정해진 순서(오름차순 또는 내림차순)로 재배열하는 일이다. 알고리즘은 세 가지 기준으로 비교한다.

* 시간 복잡도: 입력 크기 n에 따라 비교·이동 횟수가 늘어나는 정도
* 추가 메모리: 입력 배열 외에 쓰는 공간. O(1)이면 제자리(in-place) 정렬이다
* 안정성: 값이 같은 요소의 원래 순서가 정렬 후에도 유지되는지 여부

## 2. 비교표

n은 요소 수, k는 값의 범위(계수 정렬) 또는 한 자리의 기수 크기(기수 정렬), d는 자릿수다.

| 정렬 알고리즘 | 최선 | 평균 | 최악 | 추가 메모리 | 안정성 | 특징 |
|---|---|---|---|---|---|---|
| 선택 정렬 | O(n²) | O(n²) | O(n²) | O(1) | 불안정 | 교환 횟수가 최대 n−1로 적다. 입력과 무관하게 느리다 |
| 버블 정렬 | O(n) | O(n²) | O(n²) | O(1) | 안정 | 인접 요소를 비교한다. 최선 O(n)은 교환 없음 검사를 넣은 경우다 |
| 삽입 정렬 | O(n) | O(n²) | O(n²) | O(1) | 안정 | 거의 정렬된 입력에서 빠르다. 입력이 작을 때 실전에서 쓴다 |
| 쉘 정렬 | 간격 수열에 따라 다름 | 간격 수열에 따라 다름 | 간격 수열에 따라 다름 | O(1) | 불안정 | 삽입 정렬을 간격을 줄여 가며 적용한다. 원래 간격(n/2, n/4, …)의 최악은 O(n²)다 |
| 퀵 정렬 | O(n log n) | O(n log n) | O(n²) | O(log n) (평균 재귀 깊이) | 불안정 | 평균이 가장 빠른 편이다. 피벗이 한쪽으로 치우치면 최악이 된다 |
| 병합 정렬 | O(n log n) | O(n log n) | O(n log n) | O(n) (배열) | 안정 | 입력과 무관하게 일정하다. 배열 기준으로 추가 공간이 필요하다 |
| 힙 정렬 | O(n log n) | O(n log n) | O(n log n) | O(1) | 불안정 | 최악도 O(n log n)이며 제자리 정렬이다. 캐시 효율은 낮은 편이다 |
| 계수 정렬 | O(n + k) | O(n + k) | O(n + k) | O(n + k) | 안정(표준 구현) | 비교하지 않는다. 값의 범위 k가 작은 정수에만 쓴다 |
| 기수 정렬 (LSD) | O(d(n + k)) | O(d(n + k)) | O(d(n + k)) | O(n + k) | 안정 | 자릿수별로 안정 정렬을 반복한다. 정수·고정 길이 문자열에 쓴다 |

## 3. 읽는 방법

* 선택·버블·삽입·쉘·퀵·병합·힙 정렬은 요소끼리 비교하는 비교 기반 정렬이다. 비교 기반 정렬은 최악의 경우 Ω(n log n)번 비교가 필요하다. 이 하한을 넘는 계수·기수 정렬은 비교하지 않고 값의 구조(범위, 자릿수)를 쓴다.
* 안정성이 필요한 경우는 여러 키를 차례로 정렬할 때다. 예를 들어 이름순으로 정렬한 뒤 학년순으로 정렬하면, 안정 정렬만 같은 학년 안에서 이름순을 유지한다.
* 표의 선택·버블·삽입 정렬은 O(n²)이므로 n이 큰 입력에는 쓰지 않는다.

{% hint style="info" %}
NOTE: 퀵 정렬의 추가 메모리 O(log n)은 재귀 호출 깊이가 평균일 때의 값이다. 최악의 입력에서는 재귀 깊이가 O(n)이 된다. 작은 쪽 구간을 먼저 재귀하면 O(log n)으로 제한할 수 있다.
{% endhint %}

## 4. 표준 라이브러리와의 관계

라이브러리 정렬은 위 알고리즘을 섞어 쓴다. 안정성 여부는 호출 전에 확인한다.

| 환경 | 함수 | 안정성 | 비고 |
|---|---|---|---|
| C# | `Array.Sort`, `List<T>.Sort` | 불안정 | 퀵·힙·삽입 정렬을 섞은 introsort로 알려져 있다 |
| C# (LINQ) | `OrderBy` | 안정 | 같은 키는 원래 순서를 유지한다 |

## 6. 약어·용어

| 용어 | 뜻 |
|---|---|
| 제자리 정렬(in-place sort) | 입력 크기와 무관한 상수 크기의 추가 메모리만 쓰는 정렬 |
| 안정 정렬(stable sort) | 값이 같은 요소의 원래 순서가 유지되는 정렬 |
| 비교 기반 정렬 | 요소끼리 비교해서 순서를 정하는 정렬 |
| introsort | 퀵 정렬로 시작해 재귀가 깊어지면 힙 정렬로 바꾸는 혼합 정렬 |
