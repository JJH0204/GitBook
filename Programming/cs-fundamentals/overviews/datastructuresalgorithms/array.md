## 1. 정의

배열(array)은 같은 자료형의 변수 여러 개를 연속된 메모리에 한꺼번에 선언한 구조다. 개별 변수를 따로 선언하면 같은 역할의 변수가 늘어날수록 관리가 어렵다. 배열은 이름 하나와 인덱스로 요소를 구분해 이 문제를 해결한다.

```c
// 자료형 배열이름[배열크기];
int grade[10];
```

* 인덱스는 0부터 시작한다. 크기가 N인 배열의 유효한 인덱스는 0부터 N−1까지다.
* 로컬 배열을 초기화하지 않으면 요소 값은 정해지지 않은 값(쓰레기 값)이다.

{% hint style="danger" %}
WARNING: C는 배열의 범위를 검사하지 않는다. 유효 범위 밖의 인덱스(`grade[10]`, `grade[-1]`)로 읽거나 쓰면 정의되지 않은 동작(UB, Undefined Behavior)이다. 오류가 나지 않고 지나가거나, 다른 변수가 덮어써지거나, 나중에 엉뚱한 곳에서 비정상 종료할 수 있다. 인덱스는 직접 검사한다.
{% endhint %}

## 2. 구성 요소

### 2-1. 배열 ADT

ADT(Abstract Data Type)는 구현 방식과 무관하게 객체와 연산만 정의한 것이다.

| 항목 | 내용 |
|---|---|
| 객체 | `<인덱스, 값>` 쌍의 집합 |
| `create(size)` | `size`개의 요소를 저장할 수 있는 배열을 만든다 |
| `get(A, i)` | 배열 `A`의 `i`번째 요소를 반환한다 |
| `set(A, i, v)` | 배열 `A`의 `i`번째 위치에 값 `v`를 저장한다 |

### 2-2. 1차원 배열

```c
int list[6];
```

| list\[0] | list\[1] | list\[2] | list\[3] | list\[4] | list\[5] |
| --- | --- | --- | --- | --- | --- |
| list | list + sizeof(int) | list + 2 \* sizeof(int) | list + 3 \* sizeof(int) | list + 4 \* sizeof(int) | list + 5 \* sizeof(int) |

표의 둘째 행은 각 요소의 바이트 단위 주소(시작 주소에서의 거리)다. 요소 하나의 크기는 `sizeof(int)`(보통 4바이트)다.

### 2-3. 2차원 배열

```c
int list[3][5];
```

|    | 0열 | 1열 | 2열 | 3열 | 4열 |
| --- | --- | --- | --- | --- | --- |
| 0행 | list\[0]\[0] | list\[0]\[1] | list\[0]\[2] | list\[0]\[3] | list\[0]\[4] |
| 1행 | list\[1]\[0] | list\[1]\[1] | list\[1]\[2] | list\[1]\[3] | list\[1]\[4] |
| 2행 | list\[2]\[0] | list\[2]\[1] | list\[2]\[2] | list\[2]\[3] | list\[2]\[4] |

## 3. 동작 원리

배열의 요소는 연속된 메모리에 놓이므로, 시작 주소와 인덱스만으로 주소를 계산한다. 이 계산이 한 번이라 인덱스 접근은 배열 크기와 무관하게 O(1)이다.

| 배열 | 요소 주소 |
|---|---|
| 1차원 `a[N]` | `a`의 주소 + `i` × `sizeof(요소)` |
| 2차원 `b[R][C]` | `b`의 주소 + (`i` × `C` + `j`) × `sizeof(요소)` |

2차원 배열은 행 단위로 이어 붙여 저장한다(행 우선, row-major). `list[3][5]`는 `list[0][0..4]`, `list[1][0..4]`, `list[2][0..4]` 순으로 연속된 15칸이다. 이 때문에 안쪽 반복을 열 인덱스로 돌려야 메모리를 순서대로 읽는다.

| 연산 | 시간 복잡도 |
|---|---|
| 인덱스 접근·수정 | O(1) |
| 값 탐색 | O(n) |
| 중간 삽입·삭제 | O(n) (뒤 요소를 이동한다) |

크기는 선언 시 고정된다. 연산별 비교는 [선형 자료구조 개요 (Linear)](lineardatastructureoverview.md)를 따른다.

## 4. 응용

* 다항식 표현: 차수를 인덱스로, 계수를 값으로 저장한다.
* 행렬 표현: 0이 많은 희소 행렬은 [희소 행렬 (Sparse Matrix)](../../data-structures/set-sparse-matrix.md)의 방식으로 저장 공간을 줄인다.

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| 인덱스(index) | 배열 요소의 위치 번호. C에서 0부터 센다 |
| ADT | 연산과 객체만 정의한 추상 자료형 |
| UB | 언어 표준이 결과를 정하지 않은 동작 |
| 행 우선(row-major) | 2차원 배열을 행 단위로 연속 저장하는 방식 |
