## 1. 정의

탐색(search)은 배열, 연결 리스트, 트리, 그래프 같은 자료구조에서 조건에 맞는 값이나 경로를 찾는 알고리즘이다. 알고리즘은 자료구조의 형태와 정렬 여부에 따라 달라진다.

## 2. 비교표

n은 요소 수, V는 정점 수, E는 간선 수다. 시간 복잡도는 최선 / 평균 / 최악 순이다.

| 탐색 알고리즘 | 대상 | 전제 조건 | 시간 복잡도 | 특징 |
|---|---|---|---|---|
| 선형 탐색 (Linear Search) | 배열, 리스트 | 없음 | O(1) / O(n) / O(n) | 처음부터 하나씩 비교한다. 단순하지만 느리다 |
| 이진 탐색 (Binary Search) | 배열 | 정렬돼 있고 인덱스로 임의 접근이 가능해야 한다 | O(1) / O(log n) / O(log n) | 구간을 절반씩 줄인다 |
| 해시 탐색 (Hashing) | 해시 테이블 | 해시 함수와 충돌 처리 | O(1) / O(1) / O(n) | 평균이 가장 빠르다. 충돌이 몰리면 최악 O(n)이다 |
| 이진 탐색 트리 탐색 (BST Search) | 이진 탐색 트리 | 트리 자체가 정렬 구조다(별도 정렬 불필요) | O(1) / O(log n) / O(n) | 최선은 찾는 값이 루트일 때다. 한쪽으로 치우친 트리는 최악 O(n)이다 |
| 균형 이진 탐색 트리 탐색 (AVL, 레드-블랙) | 균형 트리 | 균형을 유지한다 | O(1) / O(log n) / O(log n) | 높이가 O(log n)으로 보장된다 |
| 깊이 우선 탐색 (DFS) | 그래프, 트리 | 없음 | O(V + E) | 인접 리스트 기준. 스택(또는 재귀)으로 한 경로를 끝까지 따라간다 |
| 너비 우선 탐색 (BFS) | 그래프, 트리 | 없음 | O(V + E) | 인접 리스트 기준. 큐로 가까운 정점부터 방문한다. 가중치 없는 그래프의 최단 경로(간선 수)를 구한다 |
| 다익스트라 (Dijkstra) | 가중 그래프 | 간선 가중치가 모두 0 이상이다 | O((V + E) log V) | 우선순위 큐(이진 힙) 기준. 한 정점에서 다른 모든 정점까지의 최단 경로를 구한다 |

## 3. 선택 기준

| 조건 | 선택 |
|---|---|
| 데이터가 정렬돼 있지 않고 한 번만 찾는다 | 선형 탐색. 정렬 비용 O(n log n)이 탐색 한 번의 비용보다 크다 |
| 정렬된 배열에서 여러 번 찾는다 | 이진 탐색 |
| 키로 값을 빠르게 찾고 순서가 필요 없다 | 해시 테이블 |
| 삽입·삭제와 순서 있는 탐색을 함께 한다 | 균형 이진 탐색 트리 |
| 연결 관계를 따라 도달 가능 여부를 본다 | DFS 또는 BFS |
| 가중치가 있는 최단 경로를 구한다 | 다익스트라(가중치 0 이상) |

{% hint style="info" %}
NOTE: 이진 탐색의 O(log n)은 인덱스 접근이 O(1)인 배열을 전제로 한다. 연결 리스트에서는 중간 요소에 가는 데 O(n)이 들므로 이진 탐색의 이점이 없다.
{% endhint %}
