# 자료구조 및 알고리즘 모음

정렬·탐색 알고리즘의 비교표와 선형 자료구조의 개요를 정리한다. 문서 번호(Task ID)는 `PRG-DSA-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념·원리)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-DSA-001-DO | 개념 | [정렬 알고리즘 비교 (Sort)](sortalgorithmoverview.md) | 정렬 알고리즘의 복잡도, 공간, 안정성을 비교한다 |
| PRG-DSA-002-DO | 개념 | [탐색 알고리즘 개요 (Search)](searchalgorithmoverview.md) | 탐색 알고리즘의 전제 조건과 복잡도를 비교한다 |
| PRG-DSA-003-DO | 개념 | [선형 자료구조 개요 (Linear)](lineardatastructureoverview.md) | 배열, 연결 리스트, 스택, 큐, 덱의 연산 복잡도를 비교한다 |
| PRG-DSA-004-DO | 개념 | [배열 자료구조 (Array)](array.md) | 배열의 메모리 배치, 주소 계산, 경계 규칙을 확인한다 |
| PRG-DSA-005-DO | 개념 | [버블 정렬 (Bubble Sort)](bubble-sort.md) | 버블 정렬의 원리, 복잡도, C 구현을 확인한다 |
