## 1. 정의

힙(heap)은 완전 이진 트리이면서 **힙 속성**을 만족하는 구조다. 최소 힙은 모든 노드가 자식보다 작거나 같고, 최대 힙은 모든 노드가 자식보다 크거나 같다. 따라서 루트가 항상 최솟값(최소 힙) 또는 최댓값(최대 힙)이다. 형제 노드 사이에는 순서 규칙이 없다.

## 2. 배열 표현

완전 이진 트리는 빈 칸 없이 위에서 아래, 왼쪽에서 오른쪽 순서로 채워지므로 배열에 그대로 담을 수 있다. 0부터 시작하는 인덱스 `i`에 대해 다음이 성립한다.

| 관계 | 인덱스 |
|---|---|
| 부모 | `(i - 1) / 2` (정수 나눗셈) |
| 왼쪽 자식 | `2i + 1` |
| 오른쪽 자식 | `2i + 2` |

예제에서 5, 3, 8, 1, 9, 2, 7을 순서대로 넣은 최소 힙의 배열은 `1 3 2 5 9 8 7`이다(실행 결과 참고).

## 3. 연산 원리

* **삽입(push)**: 배열 끝에 넣고, 부모보다 작으면 부모와 자리를 바꾸며 위로 올린다(sift-up). 높이만큼만 올라가므로 O(log n)이다.
* **최솟값 삭제(pop)**: 루트를 꺼내고 배열의 마지막 요소를 루트로 옮긴 뒤, 더 작은 자식과 바꾸며 아래로 내린다(sift-down). O(log n)이다.
* **루트 조회(peek)**: `a[0]`을 읽는다. O(1)이다.

| 연산 | 시간 복잡도 |
|---|---|
| 루트 조회 | O(1) |
| 삽입 | O(log n) |
| 루트 삭제 | O(log n) |
| 임의 값 탐색 | O(n) |
| 빈 배열에서 힙 만들기(heapify) | O(n) |

## 4. 예제 코드 (C, 최소 힙)

{% code title="heap.c" %}
```c
#include <stdio.h>

#define MAX 16

typedef struct { int a[MAX]; int n; } MinHeap;

static void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }

int push(MinHeap *h, int v) {
	if (h->n == MAX) return 0;
	int i = h->n++;
	h->a[i] = v;
	while (i > 0 && h->a[(i - 1) / 2] > h->a[i]) {   /* 부모보다 작으면 위로 */
		swap(&h->a[(i - 1) / 2], &h->a[i]);
		i = (i - 1) / 2;
	}
	return 1;
}

int pop(MinHeap *h, int *out) {
	if (h->n == 0) return 0;
	*out = h->a[0];
	h->a[0] = h->a[--h->n];                           /* 마지막 요소를 루트로 */
	int i = 0;
	for (;;) {
		int l = 2 * i + 1, r = 2 * i + 2, m = i;
		if (l < h->n && h->a[l] < h->a[m]) m = l;
		if (r < h->n && h->a[r] < h->a[m]) m = r;
		if (m == i) break;
		swap(&h->a[i], &h->a[m]);
		i = m;
	}
	return 1;
}

int main(void) {
	MinHeap h = {{0}, 0};
	int in[] = {5, 3, 8, 1, 9, 2, 7};
	for (int i = 0; i < 7; i++) push(&h, in[i]);
	printf("array:");
	for (int i = 0; i < h.n; i++) printf(" %d", h.a[i]);
	printf("\npop order:");
	int v;
	while (pop(&h, &v)) printf(" %d", v);
	printf("\n");
	return 0;
}
```
{% endcode %}

실행 결과:

```
array: 1 3 2 5 9 8 7
pop order: 1 2 3 5 7 8 9
```

`pop`을 끝까지 반복하면 오름차순으로 나온다. 이 성질을 이용한 정렬이 [힙 정렬](../algorithms/heap-sort.md)이다.

| 위치 | 설명 |
|---|---|
| `push`의 `while` | 부모가 더 크면 교환하고 부모 위치로 올라간다 |
| `pop`의 `h->a[0] = h->a[--h->n]` | 개수를 줄이면서 마지막 요소를 루트로 옮긴다. `n`이 1일 때는 자기 자신을 복사하고 반복문에서 바로 끝난다 |
| `l < h->n`, `r < h->n` | 자식이 배열 범위 안인지 확인한 뒤에만 비교한다 |
| `MAX` 검사 | 고정 크기 배열이므로 가득 차면 삽입을 거부한다 |

## 5. 우선순위 큐와의 관계

우선순위 큐(priority queue)는 "가장 높은 우선순위의 요소를 꺼낸다"는 **추상 자료형**이고, 이진 힙은 이를 구현하는 가장 흔한 방법이다. 우선순위 큐는 [다익스트라 알고리즘](../algorithms/dijkstra.md)과 작업 스케줄링에 쓴다. 일반 [큐](queue.md)는 들어온 순서대로, 우선순위 큐는 우선순위 순서대로 나온다.

## 6. 한계와 주의

* 힙은 정렬된 구조가 아니다. 루트만 최솟값이 보장되고 나머지는 부모-자식 관계만 지켜지므로, 배열을 앞에서부터 읽어도 오름차순이 아니다(`1 3 2 5 9 8 7`).
* 같은 우선순위 요소를 넣은 순서대로 꺼낸다는 안정성이 없다.
* 이진 탐색 트리와 달리 임의 값 탐색과 정렬 순회에는 맞지 않는다.
