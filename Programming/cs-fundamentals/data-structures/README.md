# 자료구조 (Data Structures)

자료구조의 개념, 복잡도, C 구현 예제를 정리한다. 문서 번호(Task ID)는 `PRG-DST-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념·원리 + 예제 코드)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-DST-001-DO | 개념 | [이진 트리 (Binary Tree)](binarytrees_kr.md) | 이진 트리의 용어, 종류, 포인터 구현, 순회를 확인한다 |
| PRG-DST-002-DO | 개념 | [비선형 자료구조 (Non-linear)](non-linear-data-structure.md) | 트리·그래프·힙의 분류와 표현 방법을 확인한다 |
| PRG-DST-003-DO | 개념 | [스택 (Stack)](stack.md) | 스택의 정의와 구현 문서 위치를 확인한다 |
| PRG-DST-004-DO | 개념 | [희소 행렬 (Sparse Matrix)](set-sparse-matrix.md) | 희소 행렬의 저장 방식과 전치를 확인한다 |
| PRG-DST-005-DO | 개념 | [연결 리스트 상세 (Linked List)](linkedlists_kr.md) | 연결 리스트의 구조와 C 구현을 확인한다 |
