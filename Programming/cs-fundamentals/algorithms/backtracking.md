## 1. 원리

백트래킹(backtracking)은 해를 한 단계씩 만들어 가다가, 조건에 어긋나는 시점에 그 선택을 취소하고 이전 단계로 돌아와 다른 선택을 시도하는 탐색 기법이다. 가능한 모든 경우를 나열하되, 가망 없는 가지를 일찍 잘라(가지치기, pruning) 탐색량을 줄인다. 상태 공간을 깊이 우선으로 탐색하는 방식이다.

N-Queens 문제는 N×N 체스판에 퀸 N개를 서로 공격하지 못하게(같은 행·열·대각선에 놓이지 않게) 배치하는 문제다.

1. 한 행에 퀸을 하나씩 놓는다. 행 `r`에 놓을 열 `c`를 0부터 시도한다.
2. `safe(r, c)`로 앞 행의 퀸과 같은 열이거나 같은 대각선인지 검사한다.
3. 안전하면 `col[r] = c`로 두고 다음 행(`r + 1`)으로 재귀한다.
4. 어느 열에도 놓을 수 없으면 반환해 이전 행으로 돌아간다(역추적).
5. `r == N`이면 해를 하나 찾은 것이다.

## 2. 단계별 추적

N = 4에서 `col[r]`은 r행 퀸의 열이다. 퀸을 놓을 수 있는지에 따른 진행 과정이다.

| 시도 | 결과 |
|---|---|
| 0행 0열 | 1행은 2열 또는 3열이 가능하다 |
| 0행 0열, 1행 2열 | 2행에 놓을 열이 없다. 1행으로 돌아간다 |
| 0행 0열, 1행 3열 | 2행은 1열만 가능하나 3행에 놓을 열이 없다. 0행으로 돌아간다 |
| 0행 1열, 1행 3열, 2행 0열 | 3행 2열에 놓을 수 있다. 해 1: `1 3 0 2` |
| 0행 2열, ... | 해 2: `2 0 3 1` |

0행 0열로 시작하면 해가 없고, 해는 모두 2개다.

## 3. 예제 코드 (C)

{% code title="n_queens.c" %}
```c
#include <stdio.h>
#include <stdlib.h>

#define N 4

int col[N]; /* col[r] = r행 퀸의 열 */
int count = 0;

int safe(int r, int c) {
	for (int i = 0; i < r; i++) {
		if (col[i] == c || abs(col[i] - c) == r - i) return 0;
	}
	return 1;
}

void solve(int r) {
	if (r == N) {
		count++;
		printf("solution %d:", count);
		for (int i = 0; i < N; i++) printf(" %d", col[i]);
		printf("\n");
		return;
	}
	for (int c = 0; c < N; c++) {
		if (safe(r, c)) {
			col[r] = c;
			solve(r + 1);
		}
	}
}

int main(void) {
	solve(0);
	printf("total = %d\n", count);
	return 0;
}
```
{% endcode %}

출력 예:

```
solution 1: 1 3 0 2
solution 2: 2 0 3 1
total = 2
```

| 위치 | 설명 |
|---|---|
| `col[N]` | 행마다 퀸이 놓인 열. 행마다 퀸이 하나이므로 행 충돌은 검사할 필요가 없다 |
| `col[i] == c` | 같은 열 충돌 |
| `abs(col[i] - c) == r - i` | 같은 대각선 충돌. 열 차이와 행 차이가 같으면 대각선이다 |
| `col[r] = c` 후 `solve(r + 1)` | 선택 후 다음 단계로 간다. 같은 `col[r]`을 다음 `c`가 덮어쓰므로 별도의 취소 코드가 필요 없다 |
| `#include <stdlib.h>` | `abs`를 쓰기 위해 필요하다 |

## 4. 복잡도

| 항목 | 값 | 비고 |
|---|---|---|
| 시간(최악) | 지수 시간 | 가지치기로 N^N보다 훨씬 줄지만 N이 커지면 해의 수와 탐색량이 빠르게 늘어난다 |
| 공간 | O(N) | `col` 배열과 재귀 깊이 |
| 해의 수 | N=4: 2, N=6: 4, N=8: 92 | N=8의 92는 널리 알려진 값이다(이 문서의 코드는 N=4만 실행해 확인했다) |

## 5. 안정성과 한계

* 최악 시간이 지수적이다. 가지치기가 잘 될수록 빠르지만 입력에 따라 보장되지 않는다.
* 해의 개수를 세거나 모든 해를 구해야 하는 문제(순열, 부분집합, 스도쿠, 미로 경로)에 적합하다.
* 최적값만 필요하고 부분 문제가 겹친다면 동적 계획법이 더 낫다.
* 재귀가 깊으면 호출 스택이 넘칠 수 있다. N-Queens는 깊이가 N이므로 문제가 되지 않는다.
* 전역 변수(`col`, `count`)를 쓰는 코드는 예제용이다. 재사용하려면 인자로 넘긴다.
