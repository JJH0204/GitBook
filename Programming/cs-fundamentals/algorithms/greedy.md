## 1. 원리

탐욕법(greedy algorithm)은 각 단계에서 그 시점에 가장 좋아 보이는 선택을 하고, 한 번 한 선택은 되돌리지 않는 기법이다. 지역적 최선의 선택이 전체 최적해로 이어지는 문제에서만 정확하다.

동전 거스름돈 문제는 금액을 가장 적은 개수의 동전으로 만드는 문제다.

1. 동전을 큰 것부터 차례로 본다.
2. 현재 동전으로 만들 수 있는 최대 개수(`amount / coin`)를 쓴다.
3. 남은 금액(`amount % coin`)으로 다음 동전을 본다.
4. 남은 금액이 0이 되면 끝난다.

## 2. 단계별 추적

1260원을 500, 100, 50, 10원 동전으로 만드는 과정이다.

| 동전 | 사용 개수 | 남은 금액 |
|---|---|---|
| (시작) | - | 1260 |
| 500 | 2 | 260 |
| 100 | 2 | 60 |
| 50 | 1 | 10 |
| 10 | 1 | 0 |

동전은 모두 6개다.

## 3. 예제 코드 (C)

{% code title="greedy_coins.c" %}
```c
#include <stdio.h>

/* 동전 종류가 큰 것부터 정렬돼 있다. 가장 큰 동전부터 최대한 쓴다 */
int main(void) {
	int coins[] = {500, 100, 50, 10};
	int n = sizeof(coins) / sizeof(coins[0]);
	int amount = 1260, count = 0;

	for (int i = 0; i < n; i++) {
		int use = amount / coins[i];
		amount %= coins[i];
		count += use;
		printf("%d x %d\n", coins[i], use);
	}
	printf("coins = %d, remain = %d\n", count, amount);
	return 0;
}
```
{% endcode %}

출력 예:

```
500 x 2
100 x 2
50 x 1
10 x 1
coins = 6, remain = 0
```

| 위치 | 설명 |
|---|---|
| `coins[] = {500, 100, 50, 10}` | 큰 동전부터 정렬돼 있다. 정렬 순서가 알고리즘의 전제다 |
| `amount / coins[i]` | 현재 동전을 쓸 수 있는 최대 개수 |
| `amount %= coins[i]` | 사용한 금액을 뺀 나머지 |
| 마지막 `remain` 출력 | 0이 아니면 동전 조합으로 만들 수 없는 금액이다 |

## 4. 복잡도

| 항목 | 값 | 비고 |
|---|---|---|
| 시간 | O(k) | k는 동전 종류 수(정렬돼 있다고 가정) |
| 공간 | O(1) | |

일반적으로 탐욕 알고리즘의 시간은 선택 기준을 위한 정렬 비용(O(n log n))이 지배하는 경우가 많다.

## 5. 안정성과 한계

* 탐욕 선택이 최적이 아닌 입력이 있다. 동전이 `{1, 3, 4}`이고 금액이 6이면 탐욕법은 4 + 1 + 1(3개)을 고르지만 최적은 3 + 3(2개)이다.
* 위 예제의 500, 100, 50, 10원처럼 각 동전이 다음으로 작은 동전의 배수이면 탐욕법이 최적이다. 이 조건이 없으면 동적 계획법을 쓴다.
* 탐욕법이 최적임은 문제마다 증명해야 한다. 최소 신장 트리(크루스칼·프림), 다익스트라가 탐욕법으로 최적해를 구하는 대표 사례로 알려져 있다.
* 한 번 한 선택을 되돌리지 않으므로 선택이 막다른 길이 되면 복구할 수 없다.
