## 1. 원리

너비 우선 탐색(Breadth-First Search, BFS)은 시작 정점에서 가까운 정점부터 차례로 방문하는 그래프 탐색이다. 방문할 정점을 큐(queue, 먼저 넣은 것을 먼저 꺼내는 자료구조)에 넣어 관리한다.

1. 시작 정점의 거리를 0으로 하고 큐에 넣는다.
2. 큐에서 정점 `v`를 꺼내 방문한다.
3. `v`에 인접한 정점 중 아직 거리가 정해지지 않은 정점 `w`마다 `dist[w] = dist[v] + 1`로 정하고 큐에 넣는다.
4. 큐가 빌 때까지 2~3을 반복한다.

정점을 큐에 넣을 때 거리를 정해 두므로 같은 정점이 큐에 두 번 들어가지 않는다. 시작 정점에서 가까운 정점이 항상 먼저 큐에서 나온다.

## 2. 단계별 추적

무방향 그래프(간선 0-1, 0-2, 1-3, 2-4, 3-5, 4-5)에서 정점 0부터 시작한 진행 과정이다.

| 꺼낸 정점 | 새로 큐에 넣은 정점 | 큐 상태(꺼낸 뒤) |
|---|---|---|
| (시작) | 0 | `0` |
| 0 | 1, 2 | `1 2` |
| 1 | 3 | `2 3` |
| 2 | 4 | `3 4` |
| 3 | 5 | `4 5` |
| 4 | 없음(5는 이미 큐에 들어감) | `5` |
| 5 | 없음 | 비어 있음 |

방문 거리는 정점 0이 0, 정점 1·2가 1, 정점 3·4가 2, 정점 5가 3이다.

## 3. 예제 코드 (C)

{% code title="bfs.c" %}
```c
#include <stdio.h>

#define V 6

int main(void) {
	/* 인접 행렬. 간선: 0-1, 0-2, 1-3, 2-4, 3-5, 4-5 (무방향) */
	int adj[V][V] = {0};
	int edges[][2] = {{0, 1}, {0, 2}, {1, 3}, {2, 4}, {3, 5}, {4, 5}};
	for (int e = 0; e < 6; e++) {
		adj[edges[e][0]][edges[e][1]] = 1;
		adj[edges[e][1]][edges[e][0]] = 1;
	}

	int dist[V], queue[V], head = 0, tail = 0;
	for (int i = 0; i < V; i++) dist[i] = -1;

	dist[0] = 0;
	queue[tail++] = 0;

	while (head < tail) {
		int v = queue[head++];
		printf("visit %d (dist %d)\n", v, dist[v]);

		for (int w = 0; w < V; w++) {
			if (adj[v][w] && dist[w] == -1) {
				dist[w] = dist[v] + 1;
				queue[tail++] = w;
			}
		}
	}
	return 0;
}
```
{% endcode %}

출력 예:

```
visit 0 (dist 0)
visit 1 (dist 1)
visit 2 (dist 1)
visit 3 (dist 2)
visit 4 (dist 2)
visit 5 (dist 3)
```

| 위치 | 설명 |
|---|---|
| `adj[V][V]` | 인접 행렬. `adj[a][b] == 1`이면 a와 b가 이어져 있다 |
| `dist[w] == -1` | 거리가 -1이면 아직 발견하지 않은 정점이다. 방문 표시 배열의 역할도 한다 |
| `queue[V]`, `head`, `tail` | 배열로 만든 큐. 정점은 한 번씩만 들어가므로 크기 V면 충분하다 |

## 4. 복잡도

| 표현 방식 | 시간 | 공간 |
|---|---|---|
| 인접 리스트 | O(V + E) | O(V) |
| 인접 행렬 | O(V²) | O(V) (행렬 자체 제외) |

V는 정점 수, E는 간선 수다. 이 문서의 코드는 인접 행렬을 쓰므로 O(V²)이다.

## 5. 안정성과 한계

* 모든 간선의 가중치가 같은(가중치 없는) 그래프에서 시작 정점으로부터의 최단 거리(간선 수 기준)를 구한다. BFS가 정점을 거리 순으로 꺼내기 때문이다.
* 간선마다 가중치가 다르면 BFS의 거리는 최단 경로가 아니다. 이 경우 다익스트라를 쓴다.
* 한 층에 걸린 정점을 큐에 모두 담아야 하므로, 폭이 넓은 그래프에서는 DFS보다 메모리를 많이 쓸 수 있다.
* 시작 정점에서 닿지 않는 정점은 `dist`가 -1로 남는다. 연결 요소를 모두 방문하려면 모든 정점에 대해 시작을 반복한다.
