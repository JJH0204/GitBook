## 1. 정의

깊이 우선 탐색(Depth-First Search, DFS)은 트리나 그래프에서 한 방향으로 갈 수 있는 끝까지 내려간 뒤, 더 갈 곳이 없으면 직전 정점으로 되돌아와(역추적, backtracking) 다른 방향을 탐색하는 알고리즘이다. 모든 정점을 방문할 때까지 반복한다.

* DFS는 완전 이진 트리 전용이 아니다. 임의의 트리와 그래프에 쓴다.
* 전위·중위·후위 순회는 DFS를 이진 트리에 적용했을 때 방문 순서를 구분한 이름이다. 순회 코드는 [이진 트리 (Binary Tree)](../data-structures/binarytrees_kr.md)(PRG-DST-001-DO) 3.1절을 참조한다.

## 2. 구성 요소

| 요소 | 역할 |
|---|---|
| 호출 스택 또는 명시적 스택 | 되돌아갈 정점을 기억한다 |
| 방문 표시(`visited`) 배열 | 그래프에서 같은 정점을 두 번 방문하지 않게 한다. 트리는 사이클이 없어 필요 없다 |
| 인접 정보 | 정점에서 이어진 다음 정점을 찾는다(인접 리스트 또는 인접 행렬) |

## 3. 동작 원리

재귀 방식의 의사코드다.

```
DFS(v):
    visited[v] = true
    visit(v)
    for each w in 인접한 정점(v):
        if not visited[w]:
            DFS(w)
```

스택 방식의 의사코드다.

```
push(시작 정점)
while 스택이 비어 있지 않다:
    v = pop()
    if visited[v]: continue
    visited[v] = true
    visit(v)
    for each w in 인접한 정점(v):
        if not visited[w]: push(w)
```

{% hint style="info" %}
NOTE: 스택 방식은 인접 정점을 밀어 넣는 순서의 역순으로 방문한다. 같은 그래프라도 재귀 방식과 방문 순서가 다를 수 있다.
{% endhint %}

### 3-1. 이진 트리의 세 가지 방문 순서

| 순회 | 순서 | 주요 용도 |
|---|---|---|
| 전위(Pre-order) | 루트 → 왼쪽 → 오른쪽 | 트리 복사, 표현식 트리의 전위 표기 |
| 중위(In-order) | 왼쪽 → 루트 → 오른쪽 | 이진 검색 트리를 오름차순으로 방문 |
| 후위(Post-order) | 왼쪽 → 오른쪽 → 루트 | 트리 삭제(자식 먼저 해제), 표현식 트리 평가 |

## 4. 복잡도

| 표현 방식 | 시간 | 공간(자료구조 제외) |
|---|---|---|
| 인접 리스트 | O(V + E) | 스택 깊이 최대 O(V) |
| 인접 행렬 | O(V²) | 스택 깊이 최대 O(V) |
| 이진 트리 | O(n) | 스택 깊이 = 트리 높이. 한쪽으로 치우친 트리는 O(n) |

V는 정점 수, E는 간선 수, n은 노드 수다.

## 5. 활용과 한계

* 미로 찾기처럼 가능한 경로를 끝까지 따라가는 문제에 쓴다.
* 그래프의 사이클 탐지, 두 정점 사이의 경로 찾기, 연결 요소 구하기에 쓴다.
* DFS가 처음 찾은 경로는 최단 경로가 아닐 수 있다. 최단 경로(간선 수 기준)는 너비 우선 탐색(BFS)으로 구한다.
* 재귀 방식은 깊이가 매우 큰 입력에서 호출 스택이 넘칠 수 있다. 이때는 명시적 스택을 쓴다.

## 6. 약어·용어

| 용어 | 뜻 |
|---|---|
| DFS | Depth-First Search. 깊이 우선 탐색 |
| BFS | Breadth-First Search. 너비 우선 탐색. 큐를 쓰며 가까운 정점부터 방문한다 |
| 역추적(backtracking) | 더 갈 곳이 없을 때 직전 정점으로 되돌아오는 동작 |
