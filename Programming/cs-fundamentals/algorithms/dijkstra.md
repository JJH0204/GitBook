## 1. 원리

다익스트라(Dijkstra) 알고리즘은 간선 가중치가 모두 0 이상인 그래프에서 한 시작 정점으로부터 다른 모든 정점까지의 최단 경로 길이를 구한다. 현재까지 알려진 거리가 가장 짧은 정점을 하나씩 확정하고, 그 정점을 거쳐 가는 경로로 이웃의 거리를 갱신(완화, relaxation)한다.

1. 시작 정점의 거리를 0, 나머지를 무한대(코드에서는 `INF`)로 둔다.
2. 아직 확정되지 않은 정점 중 거리가 가장 작은 정점 `u`를 고른다.
3. `u`를 확정한다.
4. `u`에서 나가는 간선 `u→v`마다 `dist[u] + w(u, v)`가 `dist[v]`보다 작으면 `dist[v]`를 갱신한다.
5. 확정되지 않은 정점이 없거나 남은 정점이 모두 `INF`일 때까지 2~4를 반복한다.

## 2. 단계별 추적

방향 그래프에서 정점 0부터 시작한 진행 과정이다. 간선은 0→1(10), 0→2(3), 1→2(1), 1→3(2), 2→1(4), 2→3(8), 2→4(2), 3→4(7), 4→3(9)이고 `∞`는 `INF`를 뜻한다.

| 확정한 정점 | dist[0] | dist[1] | dist[2] | dist[3] | dist[4] |
|---|---|---|---|---|---|
| (시작) | 0 | ∞ | ∞ | ∞ | ∞ |
| 0 | 0 | 10 | 3 | ∞ | ∞ |
| 2 (거리 3) | 0 | 7 | 3 | 11 | 5 |
| 4 (거리 5) | 0 | 7 | 3 | 11 | 5 |
| 1 (거리 7) | 0 | 7 | 3 | 9 | 5 |
| 3 (거리 9) | 0 | 7 | 3 | 9 | 5 |

정점 1의 거리는 직접 간선(10)보다 정점 2를 거치는 경로(3 + 4 = 7)가 짧아 갱신됐다.

## 3. 예제 코드 (C)

{% code title="dijkstra.c" %}
```c
#include <stdio.h>

#define V 5
#define INF 1000000000

int main(void) {
	/* 가중치 인접 행렬. 0은 간선 없음. 방향 그래프 */
	int w[V][V] = {
		{0, 10, 3, 0, 0},
		{0, 0, 1, 2, 0},
		{0, 4, 0, 8, 2},
		{0, 0, 0, 0, 7},
		{0, 0, 0, 9, 0}
	};
	int dist[V], done[V] = {0};

	for (int i = 0; i < V; i++) dist[i] = INF;
	dist[0] = 0;

	for (int iter = 0; iter < V; iter++) {
		int u = -1;
		for (int i = 0; i < V; i++) {
			if (!done[i] && (u == -1 || dist[i] < dist[u])) u = i;
		}
		if (dist[u] == INF) break;
		done[u] = 1;

		for (int v = 0; v < V; v++) {
			if (w[u][v] > 0 && dist[u] + w[u][v] < dist[v]) {
				dist[v] = dist[u] + w[u][v];
			}
		}
		printf("fix %d (dist %d)\n", u, dist[u]);
	}
	for (int i = 0; i < V; i++) printf("dist[%d] = %d\n", i, dist[i]);
	return 0;
}
```
{% endcode %}

출력 예:

```
fix 0 (dist 0)
fix 2 (dist 3)
fix 4 (dist 5)
fix 1 (dist 7)
fix 3 (dist 9)
dist[0] = 0
dist[1] = 7
dist[2] = 3
dist[3] = 9
dist[4] = 5
```

| 위치 | 설명 |
|---|---|
| `w[V][V]` | 가중치 인접 행렬. 0은 간선 없음을 뜻하므로 가중치 0인 간선은 표현하지 못한다 |
| `INF 1000000000` | 무한대 대용. `dist[u] + w`가 `int`를 넘지 않도록 `INT_MAX`를 쓰지 않았다 |
| `done[]` | 확정된 정점 표시 |
| `if (dist[u] == INF) break` | 시작 정점에서 닿지 않는 정점이 남았을 때 반복을 끝낸다 |
| `dist[u] + w[u][v] < dist[v]` | 완화 조건. 더 짧은 경로를 찾으면 갱신한다 |

이 코드는 경로 자체가 아니라 거리만 구한다. 경로를 복원하려면 갱신할 때 `prev[v] = u`를 함께 저장한다.

## 4. 복잡도

| 구현 | 시간 | 비고 |
|---|---|---|
| 배열로 최솟값 탐색(이 문서의 코드) | O(V²) | 인접 행렬과 함께 쓰며 간선이 많은 그래프에 적합하다 |
| 이진 힙(우선순위 큐) | O((V + E) log V) | 인접 리스트와 함께 쓰며 간선이 적은 그래프에 적합하다 |

공간은 거리·확정 배열로 O(V)다(그래프 표현 제외).

## 5. 안정성과 한계

* 음수 가중치 간선이 있으면 정확하지 않다. 정점을 확정한 뒤 더 짧은 경로가 나올 수 있기 때문이다. 음수 간선에는 벨만-포드(Bellman-Ford) 알고리즘을 쓴다.
* 가중치가 없거나 모두 같은 그래프는 BFS로 충분하다.
* 한 시작 정점에 대한 결과다. 모든 정점 쌍의 최단 거리는 다른 알고리즘(플로이드-워셜 등)을 쓴다.
* 매 단계 가장 가까운 정점을 확정하는 방식이므로 탐욕법의 한 사례로 설명되기도 한다.
