## 1. 원리

퀵 정렬은 피벗(pivot) 하나를 골라 피벗보다 작은 요소는 앞쪽, 큰 요소는 뒤쪽으로 나누고(분할), 나뉜 두 구간을 각각 재귀로 정렬하는 분할 정복 정렬이다. 분할이 끝나면 피벗은 최종 위치에 놓인다.

이 문서의 코드는 마지막 요소를 피벗으로 쓰는 Lomuto 분할을 사용한다.

1. 구간의 마지막 요소 `arr[hi]`를 피벗으로 정한다.
2. `j`로 구간을 훑으며 피벗 이하인 요소를 앞쪽 영역(`lo`부터 `i`까지)으로 모은다.
3. 훑기가 끝나면 `arr[i + 1]`과 피벗을 교환한다. 피벗의 위치가 `i + 1`로 확정된다.
4. 피벗 왼쪽 구간과 오른쪽 구간을 각각 재귀로 정렬한다.

## 2. 단계별 추적

`{8, 3, 7, 1, 5, 9, 2}`의 진행 과정이다. 각 줄은 한 번의 분할 결과다.

| 구간 | 피벗 | 분할 후 배열 | 피벗 확정 위치 |
|---|---|---|---|
| 0..6 | 2 | `1 2 7 8 5 9 3` | 1 |
| 2..6 | 3 | `1 2 3 8 5 9 7` | 2 |
| 3..6 | 7 | `1 2 3 5 7 9 8` | 4 |
| 5..6 | 8 | `1 2 3 5 7 8 9` | 5 |

길이 1인 구간(0..0, 3..3)은 분할 없이 끝난다.

## 3. 예제 코드 (C)

{% code title="quick_sort.c" %}
```c
#include <stdio.h>

void swap(int *a, int *b) {
	int t = *a;
	*a = *b;
	*b = t;
}

/* Lomuto 분할: 마지막 요소를 피벗으로 쓰고 피벗의 최종 위치를 반환한다 */
int partition(int arr[], int lo, int hi) {
	int pivot = arr[hi];
	int i = lo - 1;

	for (int j = lo; j < hi; j++) {
		if (arr[j] <= pivot) {
			i++;
			swap(&arr[i], &arr[j]);
		}
	}
	swap(&arr[i + 1], &arr[hi]);
	return i + 1;
}

void quickSort(int arr[], int lo, int hi) {
	if (lo >= hi) return;

	int p = partition(arr, lo, hi);
	quickSort(arr, lo, p - 1);
	quickSort(arr, p + 1, hi);
}

int main(void) {
	int arr[] = {8, 3, 7, 1, 5, 9, 2};
	int n = sizeof(arr) / sizeof(arr[0]);

	quickSort(arr, 0, n - 1);
	for (int i = 0; i < n; i++) {
		printf("%d ", arr[i]);
	}
	printf("\n");
	return 0;
}
```
{% endcode %}

출력 예:

```
1 2 3 5 7 8 9 
```

| 위치 | 설명 |
|---|---|
| `int i = lo - 1` | 피벗 이하 영역의 마지막 인덱스. 처음에는 영역이 비어 있다 |
| `arr[j] <= pivot` | 피벗 이하인 요소를 만나면 `i`를 늘리고 앞쪽 영역 끝과 교환한다 |
| `swap(&arr[i + 1], &arr[hi])` | 피벗을 두 영역 사이로 옮긴다 |
| `if (lo >= hi) return` | 길이 0 또는 1인 구간은 끝낸다 |

교환은 멀리 떨어진 요소끼리 일어나므로 같은 값의 원래 순서가 바뀔 수 있다.

## 4. 복잡도

| 항목 | 값 | 비고 |
|---|---|---|
| 시간(최선) | O(n log n) | 분할이 매번 균형에 가까울 때 |
| 시간(평균) | O(n log n) | |
| 시간(최악) | O(n²) | 분할이 매번 한쪽으로 치우칠 때. 이 코드에서는 이미 정렬된 입력이 해당한다 |
| 공간 | O(log n) 평균 | 재귀 호출 깊이. 최악에는 O(n)이다 |
| 안정성 | 불안정 | 분할 중 교환 때문이다 |

## 5. 안정성과 한계

* 마지막 요소를 피벗으로 쓰면 이미 정렬된 입력(오름차순·내림차순)이 최악 O(n²)이 된다. 분할마다 피벗이 구간의 최솟값 또는 최댓값이 되기 때문이다.
* 완화 방법으로 피벗을 무작위로 고르거나, 처음·가운데·끝 요소의 중앙값(median-of-three)을 쓴다. 이 문서의 코드는 적용하지 않았다.
* 작은 쪽 구간을 먼저 재귀하면 호출 깊이를 O(log n)으로 제한할 수 있다.
* 불안정 정렬이다. 여러 키로 연속 정렬할 때는 안정 정렬(병합 정렬)을 쓴다.
* 평균적으로 빠르다고 알려져 있으나 실제 속도는 구현·입력·환경에 따라 달라진다.
