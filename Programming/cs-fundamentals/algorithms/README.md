# 알고리즘 (Algorithms)

개별 알고리즘의 원리, 복잡도, C 예제를 정리한다. 문서 번호(Task ID)는 `PRG-ALG-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념·원리)다. 제목이 `[생성형 AI]`로 시작하는 문서(PRG-ALG-003~012)는 생성형 AI가 작성한 초안이며 사람 검토 전이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-ALG-001-DO | 개념 | [선택 정렬 (Selection Sort)](selection-sort.md) | 선택 정렬의 원리, 복잡도, 불안정성을 확인한다 |
| PRG-ALG-002-DO | 개념 | [깊이 우선 탐색 (DFS)](depthfirstsearch.md) | 트리·그래프 DFS의 원리와 복잡도를 확인한다 |
| PRG-ALG-003-DO | 개념 | [[생성형 AI] 삽입 정렬 (Insertion Sort)](insertion-sort.md) | 삽입 정렬의 원리, 복잡도, 안정성을 확인한다 |
| PRG-ALG-004-DO | 개념 | [[생성형 AI] 병합 정렬 (Merge Sort)](merge-sort.md) | 분할 정복 정렬과 O(n log n) 복잡도를 확인한다 |
| PRG-ALG-005-DO | 개념 | [[생성형 AI] 퀵 정렬 (Quick Sort)](quick-sort.md) | 분할 원리와 최악 입력을 확인한다 |
| PRG-ALG-006-DO | 개념 | [[생성형 AI] 힙 정렬 (Heap Sort)](heap-sort.md) | 최대 힙을 이용한 제자리 정렬을 확인한다 |
| PRG-ALG-007-DO | 개념 | [[생성형 AI] 이진 탐색 (Binary Search)](binary-search.md) | 정렬된 배열의 이진 탐색과 경계 처리를 확인한다 |
| PRG-ALG-008-DO | 개념 | [[생성형 AI] 너비 우선 탐색 (BFS)](breadth-first-search.md) | 큐를 쓰는 BFS와 최단 거리를 확인한다 |
| PRG-ALG-009-DO | 개념 | [[생성형 AI] 다익스트라 최단 경로 (Dijkstra)](dijkstra.md) | 가중치 그래프의 최단 경로 알고리즘을 확인한다 |
| PRG-ALG-010-DO | 개념 | [[생성형 AI] 동적 계획법 (Dynamic Programming)](dynamic-programming.md) | 피보나치·배낭 문제로 DP 원리를 확인한다 |
| PRG-ALG-011-DO | 개념 | [[생성형 AI] 탐욕법 (Greedy)](greedy.md) | 탐욕 선택의 조건과 한계를 확인한다 |
| PRG-ALG-012-DO | 개념 | [[생성형 AI] 백트래킹 (Backtracking)](backtracking.md) | N-Queens로 백트래킹 원리를 확인한다 |
