# 알고리즘 (Algorithms)

개별 알고리즘의 원리, 복잡도, C 예제를 정리한다. 문서 번호(Task ID)는 `PRG-ALG-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념·원리)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-ALG-001-DO | 개념 | [선택 정렬 (Selection Sort)](selection-sort.md) | 선택 정렬의 원리, 복잡도, 불안정성을 확인한다 |
| PRG-ALG-002-DO | 개념 | [깊이 우선 탐색 (DFS)](depthfirstsearch.md) | 트리·그래프 DFS의 원리와 복잡도를 확인한다 |
