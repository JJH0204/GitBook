# [생성형 AI] 프로그래머스 문제 풀이

프로그래머스(Programmers) 코딩 테스트 문제의 풀이 노트를 모아 둔다. 문서 번호(Task ID)는 `PRG-PPR-<번호>-<유형>` 형식이다.

{% hint style="info" %}
NOTE: 이 그룹의 문서는 문제문과 채점 데이터를 옮기지 않고 접근 방법, 복잡도, 코드를 정리한다. 문제는 프로그래머스 사이트에서 제목으로 찾는다. 코드는 읽고 정정한 것이며 이 환경에서 컴파일·실행하지 않았다.
{% endhint %}

## 이 그룹은 무엇인가

코딩 테스트 문제를 풀며 정리한 노트이다. 각 풀이는 접근 방법, 복잡도, 코드 순으로 구성된다. 현재는 레벨 1만 있고 5문제를 담았다. 사용 언어는 C++이다.
