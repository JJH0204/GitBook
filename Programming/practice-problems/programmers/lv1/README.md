## 이 그룹이 다루는 것

프로그래머스 레벨 1 문제의 풀이 접근과 C++ 코드를 모았다. 문제문과 채점 데이터는 싣지 않고, 외부 문제 링크와 접근 방법, 복잡도, 코드를 기록한다. 레벨 1은 구현·시뮬레이션 유형이 많아 입출력과 문자열·배열 처리 연습에 적합하다.

## 읽는 방법

1. 문제 링크에서 문제를 먼저 읽고 직접 풀어 본다.
2. 각 문서의 접근 방법과 복잡도를 비교한다.
3. 코드의 경계 조건(시각 올림, 월 단위 계산, 동점 처리 등)을 확인한다.

## 선수 지식과 핵심 용어

* 선수 지식: C++ 기본 문법, `vector`와 `string` 사용법.
* 시뮬레이션: 문제에 적힌 규칙을 그대로 코드로 옮겨 상태를 갱신하는 풀이 방식.
* 시간 복잡도: 입력 크기에 따라 연산 횟수가 늘어나는 정도(O 표기).
