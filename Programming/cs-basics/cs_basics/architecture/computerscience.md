# 컴퓨터 과학 개론 (CS)

{% hint style="info" %}
\*\*컴퓨터 과학(Computer Science)\*\*은 컴퓨터를 이용한 모든 작업과 그 기반 이론을 연구하는 학문\
이는 코딩뿐만 아니라 계산 이론, 알고리즘, 소프트웨어 설계, 네트워크 등 광범위한 영역을 포함한다
{% endhint %}

* 진법
* 비트와 바이트
* 비트 연산
* 인코딩, 디코딩
* 운영체제(OS)
* 아키텍쳐
* [메모리 레이아웃(Memory Layout)](../os_memory/memory-management/memorylayout.md)
