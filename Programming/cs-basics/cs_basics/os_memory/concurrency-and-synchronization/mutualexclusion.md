# 상호 배제 (Mutual Exclusion)

## 상호 배제(Mutual Exclusion)란?

* 두 개 이상의 프로세스(또는 스레드)가 동시에 하나의 임계 구역(Critical Section)에 들어가는 것을 방지하는 원칙
* 한 번에 오직 하나의 프로세스만 공유 자원(메모리, 파일, 디바이스 등)을 사용하게 하는 것을 의미
* 동시 접근으로 인한 데이터 손상, 예측 불가능한 결과, 보안 문제, 시스템 오류 등을 방지한다.

## 임계 구역 문제의 해결 요건

임계 구역 문제를 해결하는 알고리즘은 다음 3가지를 만족해야 한다. ([임계 구역](criticalsection.md)과 같은 내용이다.)

* 상호 배제(Mutual Exclusion): 임계 구역에는 한 번에 하나의 프로세스만 들어갈 수 있다.
* 진행(Progress): 임계 구역이 비어 있으면, 들어가려는 프로세스들 가운데서 다음 진입자를 유한 시간 안에 정해야 한다. 임계 구역 밖에서 실행 중인 프로세스는 이 결정에 관여하지 않는다.
* 한정 대기(Bounded Waiting): 어떤 프로세스가 진입을 요청한 뒤 다른 프로세스가 먼저 들어갈 수 있는 횟수에 상한이 있어야 한다(무한정 밀리지 않는다).

{% hint style="warning" %}
교착 상태(deadlock)의 4가지 필요 조건(상호 배제, 점유 대기, 비선점, 순환 대기. Coffman 조건)과는 다른 개념이다.
{% endhint %}
