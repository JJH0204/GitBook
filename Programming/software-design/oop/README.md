# 객체지향 프로그래밍 (OOP)

객체지향 프로그래밍의 핵심 개념과 설계 품질 척도(응집도, 결합도)를 정리한 그룹이다. 문서 번호(Task ID)는 `PRG-OOP-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-OOP-001-DO | D&O | [객체지향 핵심 개념 (OOP)](objectorientedprogramming.md) | 객체, 캡슐화, 상속, 다형성, 추상화를 이해한다 |
| PRG-OOP-002-DO | D&O | [OOP 대 POP 비교 (OOP vs POP)](oopvspopcomparison.md) | 클래스 기반과 프로토콜 기반 설계의 장단점을 비교한다 |
| PRG-OOP-003-DO | D&O + 예제 | [결합도 (Coupling)](coupling.md) | 모듈 간 의존 정도의 여섯 단계를 이해한다 |
| PRG-OOP-004-DO | D&O + 예제 | [응집도 (Cohesion)](cohesion.md) | 모듈 내부 연관 정도의 일곱 단계를 이해한다 |

## 읽는 순서

1. PRG-OOP-001-DO로 기본 개념을 익힌다.
2. PRG-OOP-003-DO와 PRG-OOP-004-DO로 "응집도는 높게, 결합도는 낮게"라는 설계 방향을 익힌다.
3. PRG-OOP-002-DO는 Swift를 다룰 때 읽는다.
4. 설계 원칙은 [SOLID 원칙 (SOLID)](../solid/README.md)로 이어진다.
