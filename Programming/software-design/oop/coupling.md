## 1. 정의

결합도(coupling)는 모듈(클래스, 함수, 컴포넌트) 사이의 의존 정도다. 한 모듈이 다른 모듈에 얼마나 강하게 연결돼 있는지를 나타낸다.

- 결합도가 낮을수록 한 모듈을 바꿔도 다른 모듈에 영향이 적어 유지보수가 쉽다.
- 결합도가 높을수록 의존이 강해 수정이 어렵다.

{% hint style="info" %}
NOTE: 이상적인 설계는 높은 응집도와 낮은 결합도를 가진다. 응집도는 높게, 결합도는 낮게 만든다. 응집도는 [응집도 (Cohesion)](cohesion.md)를 본다.
{% endhint %}

## 2. 구성 요소

### 2.1 결합도 수준 비교

| 수준 | 특징 | 장점 | 단점 |
|---|---|---|---|
| 높은 결합도 (Tight Coupling) | 모듈 간 의존이 강하다 | 단순한 구조에서 성능 최적화가 가능하다 | 변경이 다른 모듈로 번진다 |
| 낮은 결합도 (Loose Coupling) | 모듈 간 의존이 약하다 | 유지보수와 재사용이 쉽다 | 추상 계층이 늘어 초기 설계가 복잡해질 수 있다 |

### 2.2 결합도 유형 (강한 순서)

| 순서 | 유형 | 설명 | 강도 |
|---|---|---|---|
| 1 | 내용 결합 (Content Coupling) | 한 모듈이 다른 모듈의 내부 데이터나 로직을 직접 참조한다 | 가장 강하다 |
| 2 | 공통 결합 (Common Coupling) | 여러 모듈이 같은 전역 변수를 공유한다 | 높다 |
| 3 | 외부 결합 (External Coupling) | 모듈이 외부 환경(DB, 파일, 하드웨어 등)에 의존한다 | 높다 |
| 4 | 제어 결합 (Control Coupling) | 한 모듈이 다른 모듈의 실행 흐름을 제어하는 값(flag)을 넘긴다 | 중간이다 |
| 5 | 스탬프 결합 (Stamp Coupling) | 레코드·구조체 전체를 넘기지만 그중 일부 필드만 쓴다 | 낮다 |
| 6 | 자료 결합 (Data Coupling) | 필요한 값만 인자로 주고받는다. 일부 값만 넘기는 경우가 여기에 속한다 | 가장 낮다 |

{% hint style="info" %}
NOTE: 지향점은 자료 결합이다. 모듈 사이에 꼭 필요한 값만 주고받는다.
{% endhint %}

## 3. 동작 원리

같은 기능을 결합도 유형별로 표현한 예다.

```c
#include <stdio.h>

struct User { char name[32]; int age; char email[64]; };

/* 공통 결합: 전역 변수를 공유한다 */
int g_total;
void addToTotal(int v) { g_total += v; }

/* 제어 결합: flag로 호출된 함수의 동작을 고른다 */
void print(int value, int asHex) {
    if (asHex) printf("%x\n", value);
    else       printf("%d\n", value);
}

/* 스탬프 결합: 구조체 전체를 받지만 name만 쓴다 */
void greetStamp(const struct User *u) { printf("안녕하세요, %s\n", u->name); }

/* 자료 결합: 필요한 값만 받는다 */
void greetData(const char *name) { printf("안녕하세요, %s\n", name); }
```

결합도를 낮추는 방법은 다음과 같다.

1. 전역 변수 대신 인자와 반환값으로 데이터를 전달한다.
2. flag로 분기하는 함수를 동작별 함수로 나눈다.
3. 구체 클래스 대신 인터페이스에 의존한다([DIP](../solid/dipdependencyinversionprinciple.md)).
4. 구체 객체를 직접 만들지 않고 생성자로 받는다(의존성 주입).
5. 모듈 간 직접 호출 대신 이벤트(옵저버 패턴 등)로 알린다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 모듈 | 함수, 클래스, 파일, 컴포넌트처럼 독립적으로 다루는 단위 |
| 의존성 주입 | 모듈이 필요한 객체를 스스로 만들지 않고 외부에서 받는 방식 |
| 싱글턴 | 전역에서 접근하는 단일 인스턴스. 공통 결합에 가까운 위험이 있다 |

Unity 등 게임 엔진에서 `FindObjectOfType` 같은 전역 검색과 싱글턴 남용은 공통 결합에 가까워 변경 영향 범위를 넓힌다.
