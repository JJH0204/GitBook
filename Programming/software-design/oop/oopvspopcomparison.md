# OOP 대 POP 비교 (OOP vs POP)

## 1. 정의

여기서 POP는 Swift의 프로토콜 지향 프로그래밍(Protocol-Oriented Programming)이다. 절차 지향 프로그래밍(procedural programming)과 다르다. 두 방식은 우열이 아니라 트레이드오프(맞바꿈) 관계다. 문제의 성격에 따라 알맞은 쪽이 다르다.

## 2. 구성 요소

| 특성 | [객체지향 프로그래밍 (OOP)](README.md) | [프로토콜 지향 프로그래밍 (POP)](../../languages/swift-and-ios/protocolorientedprogramming.md) | 공통점 |
|---|---|---|---|
| 기반 | 클래스 기반. 데이터와 함수를 객체로 묶는다 | 프로토콜 기반. 타입이 제공해야 할 기능의 계약을 정의한다 | 코드를 논리적 단위로 구조화한다 |
| 타입 | 주로 참조 타입(클래스) | 값 타입(구조체, 열거형)과 참조 타입(클래스) 모두 채택할 수 있다 | 타입 기반으로 설계한다 |
| 상속 | 클래스 간 단일 상속(Swift 기준) | 구조체·열거형에는 클래스 상속이 없다. 대신 한 타입이 여러 프로토콜을 채택하고, 프로토콜끼리 상속(확장)할 수 있다 | 재사용과 확장을 지원한다 |
| 다형성 | 하위 클래스, 추상 클래스, 인터페이스를 통해 제공한다 | 프로토콜 타입을 통해 제공한다 | 호출하는 쪽이 구체 타입에 덜 의존한다 |
| 캡슐화 | 클래스 내부에 상태를 숨긴다 | 프로토콜은 인터페이스만 노출하고 구현은 채택한 타입이 숨긴다 | 내부 구현을 숨긴다 |
| 확장 | 상속과 오버라이딩 | 프로토콜 확장(extension)으로 기본 구현을 제공한다 | 기능을 쉽게 추가한다 |
| 메모리 관리 | 클래스 인스턴스는 참조 카운팅(ARC)으로 관리한다 | 구조체·열거형은 값 타입으로 복사된다. 저장 위치(스택·힙)는 컴파일러가 정하며 항상 스택이라고 보장되지 않는다. 클래스를 채택하면 ARC를 쓴다 | 메모리 관리가 자동이다 |

## 3. 동작 원리: 트레이드오프

### 3.1 OOP(클래스 상속)와 POP(프로토콜 조합)

| 관점 | OOP(클래스 상속) | POP(프로토콜 조합) |
|---|---|---|
| 코드 재사용 | 상위 클래스에 공통 구현을 둔다 | 프로토콜 확장에 기본 구현을 둔다 |
| 결합도 | 하위 클래스가 상위 구현에 묶인다 | 계약에만 의존해 결합이 느슨하다 |
| 상태 공유 | 참조 타입이라 공유가 쉽다. 예기치 않은 변경이 생길 수 있다 | 값 타입이면 복사본이라 변경이 격리된다. 공유가 필요하면 별도 설계가 필요하다 |
| 동적 동작 | 오버라이딩과 가상 호출이 익숙하다 | 프로토콜 확장의 기본 구현은 정적으로 결정되는 경우가 있어 주의가 필요하다 |
| 학습 비용 | 개념이 널리 알려져 있다 | Swift 특유의 규칙(연관 타입, 제네릭 제약)을 익혀야 한다 |
| 적합한 경우 | 같은 상태와 생명주기를 공유하는 계층 구조 | 능력(capability) 단위로 조합하는 설계 |

### 3.2 OOP와 절차 지향

| 관점 | OOP | 절차 지향 |
|---|---|---|
| 구조 | 데이터와 동작을 객체로 묶는다 | 데이터와 함수를 분리하고 함수 호출 순서로 구성한다 |
| 변경 대응 | 새 타입 추가가 쉽다 | 새 동작(함수) 추가가 쉽다 |
| 단순성 | 작은 문제에는 클래스 구조가 과할 수 있다 | 작은 문제에는 직관적이다 |
| 규모 | 큰 시스템에서 경계를 나누기 쉽다 | 큰 시스템에서는 전역 상태 관리가 어려워질 수 있다 |
| 성능 | 가상 호출과 객체 할당 비용이 있을 수 있다 | 데이터 배치를 직접 통제하기 쉽다 |

어느 한쪽이 열등한 것이 아니다. 같은 프로그램 안에서 혼합해 쓰는 경우가 많다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| POP | Protocol-Oriented Programming. Swift의 프로토콜 중심 설계 방식 |
| ARC | Automatic Reference Counting. 참조 횟수로 메모리를 관리하는 방식 |
| 값 타입 | 대입할 때 값이 복사되는 타입(Swift의 `struct`, `enum`) |
| 참조 타입 | 대입할 때 같은 객체를 가리키는 타입(Swift의 `class`) |
