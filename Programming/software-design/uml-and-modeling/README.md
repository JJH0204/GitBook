# UML 및 모델링 (UML)

UML(통합 모델링 언어)의 다이어그램 종류, 모델 개념, 클래스 사이의 관계를 정리한 그룹이다. 문서 번호(Task ID)는 `PRG-UML-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-UML-001-DO | D&O | [UML 다이어그램 개요](umldiagramoverview.md) | 14종 다이어그램을 구조/행위로 분류해 확인한다 |
| PRG-UML-002-DO | D&O | [UML 모델링 개요](umlmodeloverview.md) | UML 모델 개념과 개발 단계별 활용을 이해한다 |
| PRG-UML-003-DO | D&O + 예제 | [UML 관계 개요 (Relationships)](uml/umlrelationshipsoverview.md) | 관계 6종의 기호와 의미를 구분한다 |

## 읽는 순서

1. PRG-UML-002-DO로 UML 모델의 개념을 본다.
2. PRG-UML-001-DO로 다이어그램 종류를 본다.
3. PRG-UML-003-DO로 클래스 다이어그램의 관계를 본다.
4. 럼바우 OMT와의 관계는 [럼바우 OOA 개요 (Rumbaugh)](../architecture-and-patterns/rumbaughooaoverview.md)에서 확인한다.
