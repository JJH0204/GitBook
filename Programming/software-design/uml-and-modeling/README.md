## 이 그룹이 다루는 것

UML은 소프트웨어의 구조와 동작을 그림으로 표현하는 표준 표기법이다. 이 그룹은 모델 개념, 다이어그램 14종의 분류, 클래스 사이 관계 기호를 다룬다. 설계 문서를 읽거나 쓰는 입문자를 대상으로 한다.

## 선수 지식과 핵심 용어

* 선수 지식: 객체지향의 기본 개념(클래스, 객체, 상속).
* 모델: 시스템의 일부 측면을 단순화해 표현한 것.
* 구조 다이어그램: 시스템의 정적 구성(클래스, 컴포넌트 등)을 보인다. 행위 다이어그램: 시간에 따른 동작(시퀀스, 상태 등)을 보인다.
* 연관, 집합, 합성, 일반화, 실체화, 의존: 클래스 다이어그램의 관계 6종.
