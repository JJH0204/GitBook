# [생성형 AI] UML 관계 및 다이어그램

클래스 다이어그램의 관계를 다루는 하위 그룹이다. 문서 번호는 `PRG-UML-<번호>-<유형>` 형식이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (하위 문서의 표를 요약했으며 도구로 다이어그램을 그려 확인하지 않았다) |

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-UML-003-DO | D&O + 예제 | [UML 관계 개요 (Relationships)](umlrelationshipsoverview.md) | 연관, 집합, 합성, 일반화, 실체화, 의존의 기호와 의미를 구분한다 |

## 관계 6종 한눈에 보기

| 관계 | 선 모양 | 한 줄 의미 |
|---|---|---|
| 연관 | 실선 | 한 클래스가 다른 클래스를 필드로 가진다 |
| 집합 | 전체 쪽 속이 빈 마름모 | 부분이 독립적으로 존재하는 전체-부분 |
| 합성 | 전체 쪽 속이 찬 마름모 | 부분이 전체와 수명을 함께하는 전체-부분 |
| 일반화 | 실선 + 속이 빈 삼각형 | 상속(is-a) |
| 실체화 | 점선 + 속이 빈 삼각형 | 인터페이스 구현 |
| 의존 | 점선 + 열린 화살표 | 일시적 사용 |

상위 그룹의 다이어그램 분류는 [UML 다이어그램 개요](../umldiagramoverview.md)에서 확인한다.
