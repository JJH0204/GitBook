# [생성형 AI] 럼바우 분석 모델 (Rumbaugh)

럼바우 객체지향 분석(OMT)의 세 모델 중 동적 모델과 기능 모델을 담은 하위 그룹이다. 객체 모델은 상위 폴더의 [객체 모델 (Object Model)](../object-model.md)에 있다. 문서 번호는 `PRG-ARP-<번호>-<유형>` 형식이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (하위 문서의 내용을 요약했다) |

## 이 그룹은 무엇인가

럼바우 OMT(Object Modeling Technique)는 시스템을 객체 모델, 동적 모델, 기능 모델 세 관점으로 분석한다. 이 그룹은 그중 동적 모델과 기능 모델을 다룬다. 읽는 순서는 개요, 객체 모델, 동적 모델, 기능 모델이다.

| 모델 | 관점 | 대표 표기 |
|---|---|---|
| 객체 모델 | 정적 구조(객체, 속성, 관계) | 객체 다이어그램 |
| 동적 모델 | 시간에 따른 상태 변화 | 상태 다이어그램 |
| 기능 모델 | 데이터 변환과 흐름 | 데이터 흐름도(DFD) |

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-ARP-003-DO | D&O | [동적 모델 (Dynamic Model)](dynamic-model.md) | 상태, 이벤트, 전이를 이해한다 |
| PRG-ARP-004-DO | D&O | [기능 모델 (Functional Model)](functional-model.md) | 데이터 흐름도 표기를 이해한다 |

전체 비교는 [럼바우 OOA 개요 (Rumbaugh)](../rumbaughooaoverview.md)에서 확인한다.

## 핵심 용어

| 용어 | 뜻 |
|---|---|
| 상태(state) | 객체가 특정 시점에 가지는 조건 |
| 이벤트(event) | 상태 전이를 일으키는 사건 |
| 전이(transition) | 한 상태에서 다른 상태로 바뀌는 것 |
| 프로세스·데이터 저장소 | 데이터 흐름도의 구성 요소 |
