# 럼바우 분석 모델 (Rumbaugh)

럼바우 객체지향 분석(OMT)의 세 모델 중 동적 모델과 기능 모델을 담은 하위 그룹이다. 객체 모델은 상위 폴더의 [객체 모델 (Object Model)](../object-model.md)에 있다. 문서 번호는 `PRG-ARP-<번호>-<유형>` 형식이다.

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-ARP-003-DO | D&O | [동적 모델 (Dynamic Model)](dynamic-model.md) | 상태, 이벤트, 전이를 이해한다 |
| PRG-ARP-004-DO | D&O | [기능 모델 (Functional Model)](functional-model.md) | 데이터 흐름도 표기를 이해한다 |

전체 비교는 [럼바우 OOA 개요 (Rumbaugh)](../rumbaughooaoverview.md)에서 확인한다.
