## 1. 목적

여러 부품(장치)이 하나의 컴퓨터로 동작하려면 기본 설계가 있어야 한다. 이 설계를 컴퓨터 구조(Computer Architecture)라고 한다. 하드웨어는 이 설계에 맞춰 개발하고 조립한다. 컴퓨터 구조는 컴퓨터가 효율적으로 동작하도록 하드웨어와 소프트웨어의 기능을 고안하고 구성하는 방법이다. 기능 구조 설계, 명령어 집합 구조, 마이크로아키텍처, 기타 하드웨어 및 컴퓨팅 방법 설계를 포함한다.

## 2. 구성 요소

| 구성 요소 | 설명 | 예 |
|---|---|---|
| 기능 구조 | CPU, 메모리, 입출력 장치를 어떻게 나누고 연결하는지에 대한 설계 | [폰 노이만 구조](vonneumannarchitecture.md), [버스](bus.md) |
| 명령어 집합 구조 (ISA) | CPU 명령어에 대한 설계. 소프트웨어가 보는 규격이다 | [x86-64, ARM 등](instructionsetarchitecture.md) |
| 마이크로아키텍처 | CPU의 하드웨어적 설계. 같은 ISA를 다른 방식으로 구현할 수 있다 | 파이프라인, 캐시, 분기 예측 |
| 하드웨어 및 컴퓨팅 방법론 | 장치 간 데이터 이동, 병렬 처리 등 | DMA |

### 2.1 ISA와 마이크로아키텍처

ISA는 프로그램이 의존하는 약속이고, 마이크로아키텍처는 그 약속을 회로로 지키는 방법이다. Intel과 AMD의 CPU는 x86-64라는 같은 ISA를 구현하지만 내부 마이크로아키텍처는 서로 다르다.

### 2.2 직접 메모리 접근 (DMA)

DMA(Direct Memory Access)는 입출력 장치가 CPU의 개입 없이 메모리와 데이터를 주고받는 방식이다. CPU는 전송을 시작하도록 설정하고, 전송이 끝나면 인터럽트로 통지를 받는다. 이로써 CPU가 데이터를 한 바이트씩 복사하지 않아도 된다.

## 3. 동작 원리

1. 프로그램은 ISA로 정의된 명령어로 표현된다.
2. CPU는 마이크로아키텍처의 방식으로 명령어를 해석하고 실행한다.
3. CPU는 버스를 통해 메모리와 입출력 장치에 접근한다.
4. 대량 전송은 DMA 컨트롤러가 CPU 대신 수행한다.
