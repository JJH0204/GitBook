## 1. 목적

명령어 집합 구조(Instruction Set Architecture, ISA)는 CPU가 해석하는 명령어의 집합과 그 규격(레지스터, 데이터 형식, 주소 지정 방식)이다. 프로그램 코드는 기계어로 작성되어 있고, 프로그램을 실행하면 CPU가 이 명령어를 읽고 처리한다. 모든 컴퓨터가 같은 수준의 연산 능력을 요구하지 않고 컴퓨팅 환경도 다양하므로 여러 ISA가 개발되어 쓰인다.

## 2. 구성 요소

### 2.1 대표 ISA

| ISA | 설명 | 주 사용처 |
|---|---|---|
| x86 (IA-32), x86-64 (x64) | CISC 계열. x86-64는 IA-32의 64비트 확장이다. [PRG-ARC-012-DO](x8664architecture.md) 참조 | PC, 서버 |
| ARM | RISC 계열. 32비트 ARM과 64비트 AArch64가 있다 | 스마트폰, 태블릿, 임베디드, 일부 PC·서버 |
| MIPS | RISC 계열 | 임베디드, 교육용 |
| AVR | 8비트 RISC 마이크로컨트롤러 ISA. 하버드 구조다 | 소형 임베디드(예: Arduino 일부 보드) |

{% hint style="info" %}
NOTE: ARM은 Android·iOS 기기와 모바일 대상 게임 빌드(예: Unity)에서 자주 마주친다. 이 표의 분류(CISC/RISC)는 교재 수준의 구분이다.
{% endhint %}

### 2.2 n비트 아키텍처

| 항목 | 설명 |
|---|---|
| 의미 | "64비트", "32비트"는 CPU가 한 번에 처리하는 데이터(레지스터·정수 연산)의 폭을 가리킨다 |
| WORD | 컴퓨터과학에서 CPU가 자연스럽게 다루는 데이터 단위를 WORD라 한다. 크기는 CPU 설계에 따라 다르다 |
| x86·Windows의 WORD | x86 어셈블리와 Windows API에서 WORD는 관례적으로 16비트, DWORD는 32비트, QWORD는 64비트다. 일반적 의미와 다르므로 문맥을 확인한다 |

### 2.3 주소 공간

| 아키텍처 | 이론상 가상 주소 공간 | 실제 사용 |
|---|---|---|
| 32비트 | 2^32 바이트 = 4 GiB | 4 GiB(프로세스 주소 공간) |
| x86-64 | 2^64 바이트 = 16 EiB | 48비트 가상 주소(256 TiB)가 일반적이다. 5단계 페이징을 켜면 57비트(128 PiB)까지 쓴다 |

현대 PC가 64비트 CPU를 쓰는 이유 중 하나는 32비트의 4 GiB 주소 공간 한계다. 많은 메모리를 쓰는 소프트웨어나 고사양 게임이 이 한계에 부딪힐 수 있다.

## 3. 동작 원리

1. 컴파일러가 소스 코드를 대상 ISA의 기계어로 번역한다.
2. 대상 ISA가 다른 CPU에서는 그 기계어를 실행할 수 없다(예: x86-64용 실행 파일은 ARM CPU에서 직접 실행되지 않는다).
3. 같은 ISA를 구현한 CPU는 내부 설계(마이크로아키텍처)가 달라도 같은 기계어를 실행한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| ISA | Instruction Set Architecture. 명령어 집합 구조 |
| IA-32 | Intel Architecture 32-bit. 32비트 x86 |
| CISC / RISC | Complex / Reduced Instruction Set Computer |
| EiB / TiB | 2^60 / 2^40 바이트 |
