## 1. 목적

근대 컴퓨터는 연산과 제어를 위해 CPU를, 저장을 위해 [기억장치(Memory)](../os_memory/memory-management/memory.md)를 쓰고, 장치 간 데이터와 제어 신호 교환에 [버스(Bus)](bus.md)를 쓴다. 이 구성의 기본 모델이 폰 노이만 구조다.

### 2.1 프로그램 내장 방식

폰 노이만 구조는 명령어(프로그램)와 데이터를 같은 메모리에 저장한다. 프로그램을 메모리에서 바꿀 수 있으므로 하드웨어를 바꾸지 않고 다른 작업을 실행할 수 있다.

### 2.2 폰 노이만 병목

명령어와 데이터가 같은 메모리와 버스를 쓰므로 CPU가 둘을 동시에 읽을 수 없다. CPU 속도가 메모리 속도보다 훨씬 빨라 메모리 접근이 전체 성능을 제한한다. 이를 폰 노이만 병목이라 한다.

### 2.3 하버드 구조와 비교

| 항목 | 폰 노이만 구조 | 하버드 구조 |
|---|---|---|
| 명령어·데이터 메모리 | 하나 | 분리 |
| 동시 접근 | 불가 | 가능 |
| 사용 예 | 범용 컴퓨터 | 마이크로컨트롤러(예: AVR) 등 |

현대 범용 CPU는 대부분 L1 캐시를 명령어용과 데이터용으로 나누어 두는 수정 하버드 구조의 성격을 함께 가진다.

## 3. 동작 원리

{% hint style="info" %}
CPU 안에 다른 저장장치가 왜 필요한가

CPU의 빠른 연산 속도로 인해 주기억장치 또는 보조기억장치만 사용하면 병목 현상이 발생한다. 따라서 CPU는 데이터 교환 속도를 단축하기 위해 "캐시"라는 저장장치를 내부에 갖게 되었다.
{% endhint %}

1. CPU가 필요한 명령어와 데이터를 메모리에서 읽는다. 자주 쓰는 데이터는 캐시에 둔다.
2. 연산 결과를 메모리 또는 레지스터에 쓴다.
3. 이 모든 이동은 버스를 통해 이루어진다.
