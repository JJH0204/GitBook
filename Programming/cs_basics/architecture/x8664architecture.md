## 1. 목적

1999년 AMD가 인텔의 32비트 아키텍처 IA-32를 64비트로 확장한 AMD64 아키텍처를 발표했다. 이후 인텔 등 여러 회사가 이를 기반으로 서로 다른 이름의 아키텍처를 발표했고, 더 범용적이고 중립적인 명칭 x86-64가 쓰이게 되었다. 현재 대다수 개인용 PC가 x86-64 CPU를 쓴다. 이 문서는 x86-64의 레지스터와 호출 규약을 정리한다.

## 2. 구성 요소

레지스터는 CPU 내부의 저장장치로, CPU가 빠르게 접근한다. 산술 연산에 필요한 데이터나 주소를 저장하고 참조하는 데 쓴다.

### 2.1 범용 레지스터

범용 레지스터는 16개이며 각각 8바이트(64비트)를 저장한다. 부호 없는 정수 기준으로 2^64 − 1까지 표현한다.

| 이름 | 전통적 이름 | 주 용도 | 비고 |
|---|---|---|---|
| rax | accumulator | 함수의 반환 값, 곱셈·나눗셈 | |
| rbx | base | 전통적 용도는 거의 없음 | 두 호출 규약 모두 호출 대상이 보존해야 하는 레지스터다 |
| rcx | counter | 반복 횟수(`rep`, `loop`), 시프트 횟수(`cl`) | 아래 호출 규약 절 참조 |
| rdx | data | 곱셈·나눗셈의 상위 값 | 호출 규약에서 인자 전달에 쓰인다 |
| rsi | source index | 문자열·메모리 복사의 원본 포인터 | System V에서 둘째 정수 인자 |
| rdi | destination index | 문자열·메모리 복사의 목적지 포인터 | System V에서 첫째 정수 인자 |
| rsp | stack pointer | 스택의 현재 위치(꼭대기) | |
| rbp | base pointer | 스택 프레임의 기준 포인터(프레임 포인터 없이 컴파일하면 범용으로 쓰임) | |
| r8 ~ r15 | | 특정 용도 없음(호출 규약에서 인자·보존용) | |

{% hint style="info" %}
NOTE: 원본은 rbx와 rdx를 "x64에서는 주된 용도 없음"이라 적었다. rdx는 곱셈·나눗셈에 쓰이고 두 호출 규약 모두에서 인자 레지스터이므로 단순화를 고쳤다.
{% endhint %}

### 2.2 하위 레지스터 이름

| 64비트 | 하위 32비트 | 하위 16비트 | 하위 8비트 |
|---|---|---|---|
| rax | eax | ax | al |
| rbx | ebx | bx | bl |
| rcx | ecx | cx | cl |
| rdx | edx | dx | dl |
| rsi | esi | si | sil |
| rdi | edi | di | dil |
| rbp | ebp | bp | bpl |
| rsp | esp | sp | spl |
| r8 ~ r15 | r8d ~ r15d | r8w ~ r15w | r8b ~ r15b |

* IA-32의 레지스터 이름(eax, ebx, ecx, edx, esi, edi, esp, ebp)은 호환을 위해 x86-64에서도 그대로 쓴다. 이 이름은 대응하는 64비트 레지스터의 하위 32비트를 가리킨다. 예: eax는 rax의 하위 32비트.
* 과거 16비트 아키텍처(IA-16)와의 호환을 위해 ax, bx, cx, dx, si, di, sp, bp는 각각 eax, ebx, ecx, edx, esi, edi, esp, ebp의 하위 16비트를 가리킨다.
* 32비트 하위 레지스터에 값을 쓰면 상위 32비트는 0으로 채워진다. 16비트·8비트 하위 레지스터에 쓰면 나머지 비트는 유지된다.
* ah, bh, ch, dh는 ax, bx, cx, dx의 상위 8비트다.

{% hint style="info" %}
NOTE: 원본의 "edc"는 오타라 edx로 고쳤다. 하위 레지스터 표와 쓰기 규칙은 원본에 없어 새로 추가했다.
{% endhint %}

### 2.3 세그먼트 레지스터

| 항목 | 설명 |
|---|---|
| 종류 | cs, ss, ds, es, fs, gs 6개 |
| 크기 | 각 16비트 |
| 64비트 모드 | cs, ss, ds, es의 세그먼트 기준 주소는 0으로 취급된다. 세그먼트로 메모리 영역을 나누지 않는다(플랫 메모리 모델) |
| fs, gs | 기준 주소가 유효하다. 운영체제가 용도를 정한다(Linux x86-64 사용자 공간은 fs를 스레드 로컬 저장소에, Windows x64는 gs를 스레드 환경 블록에 쓴다) |
| 과거 | 16비트 시절에는 접근 가능한 메모리 범위를 늘리는 데 쓰였다 |

{% hint style="info" %}
NOTE: 원본은 cs, ds, ss가 코드·데이터·스택 영역을 가리킨다고 설명했다. 64비트 모드에서는 이 세그먼트의 기준 주소가 무시되므로 위와 같이 고쳤다. 메모리 보호는 주로 페이징이 담당하고, cs는 현재 권한 수준(CPL)을 결정한다. 확인 필요.
{% endhint %}

### 2.4 명령어 포인터 레지스터

프로그램 코드는 기계어다. CPU가 다음에 실행할 코드의 위치를 가리키는 것이 명령어 포인터 레지스터다. x86-64에서는 `rip`이며 크기는 8바이트다. IA-32에서는 `eip`다. 데이터 주소를 `rip` 기준 상대 주소(`[rip + 오프셋]`)로 지정할 수 있다.

### 2.5 플래그 레지스터

RFLAGS는 64비트 크기이고 프로세서의 현재 상태를 담는다. 과거 16비트 플래그 레지스터가 확장된 것이다. 깃발을 올리고 내리는 것처럼 각 비트로 CPU의 상태를 표현한다.

| 플래그 | 의미 |
|---|---|
| CF (Carry Flag) | 부호 없는 수의 연산 결과가 비트 범위를 넘으면 설정된다 |
| ZF (Zero Flag) | 연산 결과가 0이면 설정된다 |
| SF (Sign Flag) | 연산 결과의 최상위 비트(부호 비트)가 1이면 설정된다 |
| OF (Overflow Flag) | 부호 있는 수의 연산 결과가 비트 범위를 넘으면 설정된다 |

{% hint style="info" %}
NOTE: 원본은 "64비트이므로 최대 64개 플래그를 사용할 수 있지만 실제로는 오른쪽 20여 개만 쓴다"고 적었다. RFLAGS의 상위 32비트는 예약되어 있고, 정의된 플래그는 하위 22비트 안에 있다. 이 문장은 그 점을 반영해 고쳤다. 정확한 비트 수는 확인 필요.
{% endhint %}

대소 비교의 원리는 다음과 같다. `cmp a, b`는 a − b를 계산해 결과는 버리고 플래그만 설정한다. 예를 들어 a=3, b=5이면 결과가 음수이므로 SF가 설정된다. 다만 대소 판정은 SF만으로 하지 않는다.

| 비교 | 조건 점프 예 | 사용 플래그 |
|---|---|---|
| 부호 있는 a < b | `jl` | SF ≠ OF |
| 부호 없는 a < b | `jb` | CF = 1 |
| 같음 | `je` | ZF = 1 |

## 3. 동작 원리: 호출 규약

함수 호출 시 인자와 반환 값을 어느 레지스터에 두는지는 운영체제별 ABI(호출 규약)가 정한다. x86-64에는 두 가지가 있다.

| 항목 | System V AMD64 ABI (Linux, macOS 등) | Microsoft x64 (Windows) |
|---|---|---|
| 정수·포인터 인자 | rdi, rsi, rdx, rcx, r8, r9 | rcx, rdx, r8, r9 |
| 실수 인자 | xmm0 ~ xmm7 | xmm0 ~ xmm3 (정수 인자와 위치를 공유한다) |
| 초과 인자 | 스택 | 스택 |
| 반환 값 | rax (128비트는 rdx:rax), 실수는 xmm0 | rax, 실수는 xmm0 |
| 호출 대상이 보존할 레지스터 | rbx, rbp, r12 ~ r15 | rbx, rbp, rdi, rsi, rsp, r12 ~ r15, xmm6 ~ xmm15 |
| 섀도 공간 | 없음 | 호출자가 스택에 32바이트를 확보한다 |
| 레드 존 | rsp 아래 128바이트를 쓸 수 있다 | 없음 |

Linux 시스템 호출(`syscall` 명령)은 이와 별개로 rax에 호출 번호를, rdi, rsi, rdx, r10, r8, r9에 인자를 둔다. 함수 호출 규약과 달리 넷째 인자가 rcx가 아니라 r10이다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| ABI | Application Binary Interface. 바이너리 수준의 호출 규약 |

| RFLAGS | 64비트 플래그 레지스터 |
