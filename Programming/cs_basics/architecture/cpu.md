## 1. 목적

CPU는 프로그램의 연산을 처리하고 시스템을 제어하는 컴퓨터의 두뇌다. 프로세스의 코드를 불러오고, 실행하고, 결과를 저장하는 일련의 과정이 CPU에서 일어난다.

## 2. 구성 요소

| 구성 요소 | 역할 |
|---|---|
| 산술논리장치 (ALU) | 산술·논리 연산을 처리한다 |
| 제어장치 (CU) | 명령어를 해석하고 CPU 각 부분을 제어한다 |
| 레지스터 | CPU에 필요한 데이터를 저장한다. [x86-64 레지스터](x8664architecture.md) 참조 |
| 캐시 | 메모리 접근 속도 차이를 줄이는 CPU 내부 저장장치. [폰 노이만 구조](vonneumannarchitecture.md) 참조 |

한 CPU 칩 안에 코어가 여러 개 있을 수 있다. 코어마다 ALU, 제어장치, 레지스터가 있고, 캐시는 코어별 캐시와 코어 간 공유 캐시로 나뉘는 경우가 많다.

## 3. 동작 원리

CPU는 명령어를 다음 순서로 반복 처리한다(명령어 사이클).

1. 인출(Fetch): 명령어 포인터(x86-64의 `rip`)가 가리키는 메모리에서 명령어를 읽는다.
2. 해독(Decode): 제어장치가 명령어의 종류와 피연산자를 해석한다.
3. 실행(Execute): ALU 등이 연산을 수행한다.
4. 기록(Write back): 결과를 레지스터 또는 메모리에 저장하고, 명령어 포인터를 다음 명령어로 옮긴다. 분기 명령어는 명령어 포인터를 다른 주소로 바꾼다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| CPU | Central Processing Unit. 중앙처리장치 |
| ALU | Arithmetic Logic Unit. 산술논리장치 |
| CU | Control Unit. 제어장치 |
