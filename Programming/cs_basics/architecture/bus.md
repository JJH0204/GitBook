## 1. 목적

버스(Bus)는 컴퓨터 부품과 부품 사이, 또는 컴퓨터와 컴퓨터 사이에 신호를 전송하는 통로다.

## 2. 구성 요소

| 버스 | 역할 | 방향 |
|---|---|---|
| 데이터 버스 (Data Bus) | 데이터가 이동한다 | 양방향 |
| 주소 버스 (Address Bus) | 읽거나 쓸 메모리·장치의 주소를 지정한다 | CPU에서 메모리·장치로 단방향 |
| 제어 버스 (Control Bus) | 읽기/쓰기 같은 제어 신호를 전달한다 | 신호에 따라 다름 |

{% hint style="info" %}
NOTE: 랜선이나 데이터 전송을 목적으로 하는 소프트웨어·프로토콜 버스 등도 "버스"라고 부른다.
{% endhint %}

## 3. 동작 원리

1. CPU가 주소 버스에 접근할 주소를 싣는다.
2. 제어 버스로 읽기 또는 쓰기 신호를 보낸다.
3. 데이터 버스로 데이터가 이동한다.

주소 버스가 n비트이고 바이트 단위로 주소를 매기면 접근할 수 있는 주소 공간은 2^n 바이트다. 예를 들어 32비트이면 2^32 바이트(4 GiB)다. 데이터 버스 폭은 한 번에 전달하는 데이터량에 영향을 준다.

{% hint style="info" %}
NOTE: 실제 x86-64 CPU는 64비트 전체가 아니라 더 적은 비트의 주소를 쓴다. 자세한 내용은 [PRG-ARC-010-DO](instructionsetarchitecture.md)에 있다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
