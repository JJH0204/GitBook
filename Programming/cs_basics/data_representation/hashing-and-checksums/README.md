# [생성형 AI] 해싱 및 체크섬 (Hashing)

해시 함수의 성질과 대표 알고리즘을 정리한다. 문서 번호(Task ID)는 `PRG-HSH-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념)이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (하위 문서의 내용을 요약했다) |

## 이 그룹은 무엇인가

해시 함수는 임의 길이의 입력을 고정 길이의 값으로 바꾸는 단방향 함수이다. 데이터 무결성 확인, 비밀번호 저장, 해시 테이블 등에 쓰인다. 이 그룹은 해시의 공통 성질과 대표 알고리즘 MD5를 다룬다. 선수 지식은 비트·바이트와 16진수 표기이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-HSH-001-DO | 개념 | [단방향 해싱](hashing.md) | 해시 성질, 체크섬과 암호학적 해시의 차이, 알고리즘별 출력 길이를 찾는다 |
| PRG-HSH-002-DO | 개념 | [MD5 해시 알고리즘](md5.md) | MD5의 동작과 보안 용도로 쓰지 않는 이유를 이해한다 |

## 읽는 순서

1. PRG-HSH-001-DO로 해시의 기본을 잡는다.
2. PRG-HSH-002-DO로 구체 알고리즘 하나를 읽는다.

## 핵심 용어

| 용어 | 뜻 |
|---|---|
| 해시 값(다이제스트) | 해시 함수의 고정 길이 출력 |
| 단방향성 | 해시 값에서 원래 입력을 복원할 수 없는 성질 |
| 충돌(collision) | 서로 다른 입력이 같은 해시 값을 갖는 경우 |
| 체크섬 | 전송·저장 중 오류를 검출하기 위한 값 |
