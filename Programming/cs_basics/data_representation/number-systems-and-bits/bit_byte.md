## 1. 목적

컴퓨터가 다루는 모든 데이터는 0과 1의 열이다. 이 문서는 그 열을 세는 기본 단위를 정리한다.

## 2. 구성 요소

| 단위 | 크기 | 설명 |
|---|---|---|
| 비트(bit) | 1비트 | 데이터의 최소 단위. 0 또는 1 |
| 니블(nibble) | 4비트 | 16진수 한 자리에 대응한다 |
| 바이트(byte) | 보통 8비트 | 메모리에서 주소를 지정할 수 있는 최소 단위 |
| 옥텟(octet) | 정확히 8비트 | 바이트 크기가 8비트가 아닌 기계와 구분할 때 쓴다(네트워크 표준 문서 등) |

현대 기계의 바이트는 8비트이지만 역사적으로 8비트가 아닌 기계도 있다. 8비트를 정확히 가리킬 때는 옥텟이라 한다.

### 2.1 값의 범위

n비트는 2^n가지 값을 표현한다.

| 크기 | 값의 개수 | 부호 없는 정수 범위 |
|---|---|---|
| 1비트 | 2 | 0 ~ 1 |
| 4비트(니블) | 16 | 0 ~ 15 (16진수 0 ~ F) |
| 8비트(1바이트) | 256 | 0 ~ 255 (16진수 00 ~ FF) |
| 16비트 | 65,536 | 0 ~ 65,535 |
| 32비트 | 4,294,967,296 | 0 ~ 4,294,967,295 |

부호 있는 정수 범위는 [2진법과 2의 보수](binary.md)를 본다.

### 2.2 용량 단위

| 표기 | 크기 | 기준 |
|---|---|---|
| KB (킬로바이트) | 1,000 바이트 | 국제단위계(SI) 10진 접두어 |
| MB, GB | 1,000^2, 1,000^3 바이트 | SI |
| KiB (키비바이트) | 1,024 바이트 | IEC 2진 접두어 (2^10) |
| MiB, GiB | 1,024^2, 1,024^3 바이트 | IEC |

운영체제와 제조사가 같은 "GB"를 다른 뜻으로 쓰는 경우가 있다. 저장 장치 표기는 대체로 SI(10진), 일부 운영체제 화면은 2진 값을 쓴다. 정확한 비교가 필요하면 KiB, MiB, GiB로 적는다.

## 3. 동작 원리

1바이트 = 2진수 8자리 = 16진수 2자리 = 8비트.

| 2진수 | 상위 니블 | 하위 니블 | 16진수 | 10진수 |
|---|---|---|---|---|
| 1010 1011 | 1010 | 1011 | AB | 171 |
| 1111 1111 | 1111 | 1111 | FF | 255 |

2바이트 이상의 데이터는 메모리에 연속으로 놓이며, 바이트가 놓이는 순서는 [바이트 순서](byte_ordering.md)에서 다룬다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| bit | binary digit. 2진 숫자 한 자리 |
| nibble | 4비트 묶음 |
| octet | 8비트 묶음 |
| KiB | kibibyte. 1,024 바이트 |
