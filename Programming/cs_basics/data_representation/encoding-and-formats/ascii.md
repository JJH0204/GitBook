## 작업 식별

| 확인 상태 | 미검증 (원본과 일반 지식을 정리한 것이며 표준 문서를 다시 확인하지 않았다) |

## 1. 목적

컴퓨터는 0과 1만 처리하므로 문자를 숫자로 대응시켜야 한다. 아스키 코드(American Standard Code for Information Interchange, ASCII)는 이 대응을 정한 미국 표준 문자 인코딩(character encoding)이다. 같은 코드를 쓰면 서로 다른 장치 사이에서 문자 데이터를 교환할 수 있다.

## 2. 구성 요소

### 2.1 구조

| 항목 | 내용 |
|---|---|
| 코드 폭 | 7비트. 2^7 = 128가지 문자(0~127)를 표현한다 |
| 저장 단위 | 문자 1개를 1바이트(8비트)에 저장한다 |
| 8번째 비트 | 과거에는 오류 검사용 패리티(parity) 비트로 썼다. 지금은 보통 0이다. 확장 코드 페이지(8비트 문자 집합)에서는 128~255번 문자 표현에 쓴다 |
| 아스키 값 | 문자에 대응하는 0~127의 10진수 값이다 |
| 제어 문자 | 0~31번과 127번이다. 화면에 출력되지 않는다 |
| 출력 가능 문자 | 32~126번이다. 공백(32번)을 포함한 95개다 |

## 3. 동작 원리

비트열을 8비트(1바이트)씩 끊어 각각 아스키 값으로 읽고, 표에서 문자를 찾는다.

비트열 `0b011000110110000101110100`는 24비트(3바이트)이므로 문자 3개로 읽는다.

| 비트 | 01100011 | 01100001 | 01110100 |
|---|---|---|---|
| 10진수 | 99 | 97 | 116 |
| 문자 | `c` | `a` | `t` |

→ 결과: 문자열 `cat`.

## 4. 한계와 관련 문서

* ASCII는 영문 알파벳, 숫자, 기호, 제어 문자만 포함한다. 한글 등 다른 언어 문자는 표현할 수 없다.
* 이 한계를 해결한 표준이 [유니코드 (PRG-ENC-003-DO)](unicode.md)이다. 유니코드의 처음 128개 문자(U+0000~U+007F)는 ASCII와 같다.
