## 1. 목적

텍스트 파일에서 줄이 끝났음을 나타내는 제어 문자의 구성을 설명한다.

## 2. 구성 요소

| 약어 | 이름 | ASCII 값 | 이스케이프 표기 | 동작 |
|---|---|---|---|---|
| CR | Carriage Return | 13 (0x0D) | `\r` | 커서를 현재 줄의 맨 앞으로 이동한다 |
| LF | Line Feed | 10 (0x0A) | `\n` | 커서를 다음 줄로 이동한다 |
| CRLF | CR + LF | 13 10 | `\r\n` | 두 문자를 이어 줄 끝을 나타낸다 |

| 환경 | 줄 끝 표현 |
|---|---|
| Windows | CRLF |
| Linux 등 유닉스 계열(현재의 macOS 포함) | LF |
| 이 규칙을 따르는 프로토콜 예 | HTTP 헤더는 줄 끝에 CRLF를 쓴다 ([HTTP](../../../../Network/protocols/http.md) 참조) |

{% hint style="info" %}
NOTE: 고전 Mac OS(9 이하)는 CR만 썼다. 원본에 없던 보충이며 확인 필요 항목에 적었다.
{% endhint %}

## 3. 동작 원리

Windows에서 만든 텍스트 파일을 줄 끝 처리가 다른 환경에서 열면 줄 끝에 `^M`(CR)이 보이거나 줄이 합쳐져 보일 수 있다. 줄 끝 문자는 파일 내용이므로 편집기나 도구가 변환해야 맞는다.
