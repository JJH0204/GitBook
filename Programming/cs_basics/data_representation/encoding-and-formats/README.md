# 인코딩 및 형식 (Encoding)

문자 인코딩, 이진-텍스트 인코딩, 줄 바꿈 표현을 정리한다. 문서 번호(Task ID)는 `PRG-ENC-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념)이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-ENC-001-DO | 개념 | [인코딩과 디코딩](encoding_decoding.md) | 인코딩, 암호화, 해시의 차이를 구분한다 |
| PRG-ENC-002-DO | 개념 | [아스키 코드](ascii.md) | ASCII 구조와 문자 표(32~126)를 찾는다 |
| PRG-ENC-003-DO | 개념 | [유니코드](unicode.md) | 코드 포인트와 UTF-8/16/32, 한글 인코딩을 이해한다 |
| PRG-ENC-004-DO | 개념 | [Base64 인코딩](base64.md) | 이진 데이터를 텍스트로 바꾸는 방식을 이해한다 |
| PRG-ENC-005-DO | 개념 | [개행 문자](crlf.md) | CR, LF, CRLF의 차이를 이해한다 |

## 읽는 순서

1. PRG-ENC-001-DO로 인코딩의 뜻을 잡는다.
2. PRG-ENC-002-DO, PRG-ENC-003-DO 순서로 문자 인코딩을 읽는다.
3. 필요하면 PRG-ENC-004-DO, PRG-ENC-005-DO를 읽는다.
