## 1. 정의

러닝 커브(learning curve, 학습 곡선)는 경험(시간, 반복 횟수)에 따른 학습 성과나 숙련도를 나타내는 곡선이다. 가로축은 경험이고 세로축은 성과다. 곡선이 가파르면 같은 경험으로 성과가 빨리 오른다는 뜻이다.

언어와 기술마다 난이도가 다르고 사람마다 배우는 속도가 다르므로, 누가 어떤 기술을 배우느냐에 따라 곡선이 달라진다.

## 2. 곡선의 읽기와 관용적 오용

| 표현 | 곡선 기준 의미 | 일상에서 쓰이는 뜻 |
|---|---|---|
| 러닝 커브가 가파르다 | 짧은 경험으로 숙련도가 빨리 오른다 (쉽게 배운다) | 초반에 한꺼번에 배울 것이 많아 어렵다는 뜻으로도 쓴다 |
| 러닝 커브가 완만하다 | 숙련도가 천천히 오른다 | 조금씩 배우면 되므로 부담이 적다는 뜻으로 쓴다 |
| 러닝 커브가 높다 | 곡선의 높이가 성과를 뜻하므로 많이 배웠다는 뜻이다 | 진입 장벽이 높아 배우기 어렵다는 뜻으로 쓴다 |

{% hint style="info" %}
NOTE: 일상에서는 "러닝 커브가 높다"를 "배우기 어렵다"로 쓴다. 곡선의 가로·세로축 기준과 맞지 않는 관용적 사용이다. 글에서 쓸 때는 "초반 학습 부담이 크다", "숙련까지 시간이 오래 걸린다"처럼 뜻을 직접 쓰면 오해가 줄어든다.
{% endhint %}
