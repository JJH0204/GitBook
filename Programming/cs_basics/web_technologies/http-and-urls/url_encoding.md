## 1. 목적

URL에는 허용된 문자만 쓸 수 있다. 알파벳 대소문자, 숫자, 일부 특수 문자만 그대로 쓴다. 허용되지 않는 문자나 구분자와 겹치는 문자는 `%` 뒤에 16진수 두 자리를 붙인 형태(퍼센트 인코딩)로 바꾼다. 이 변환을 URL 인코딩이라고 한다. 전송 중에 문자가 수정되거나 의도와 다르게 해석되는 것을 막는다.

## 2. 구성 요소

### 2.1 예약 문자

다음 문자는 URL에서 구분자로 쓰이는 예약 문자(reserved)다.

```
: / ? # [ ] @ ! $ & ' ( ) * + , ; = %
```

| 규칙 | 설명 |
|---|---|
| 구분자로 쓸 때 | 그대로 둔다. 예: 쿼리 시작의 `?`, 파라미터 구분의 `&` |
| 데이터로 쓸 때 | 인코딩한다. 예: 값 안의 `&`는 `%26` |

`%`는 인코딩 표기의 시작 문자이므로 위 목록에 함께 적었으며, 데이터로 쓸 때는 `%25`로 인코딩한다. 공백은 예약 문자가 아니며 URL에 그대로 쓸 수 없으므로 인코딩한다.

### 2.2 인코딩 방식

| 대상 | 인코딩 결과 |
|---|---|
| ASCII 문자 | `%` + 문자의 바이트 값 16진수 두 자리. 예: `,` → `%2C` |
| 공백 | URL 안에서는 `%20` |
| 한글 등 비-ASCII 문자 | 문자를 UTF-8 바이트로 바꾼 뒤 바이트마다 `%XX`. 예: `가` → `%EA%B0%80` |

### 2.3 공백의 `+` 표기

`+`가 공백을 뜻하는 경우는 폼 전송 방식인 `application/x-www-form-urlencoded`에 한정된다. URL 안에서 공백은 `%20`이다. 같은 `+` 문자가 URL 경로에서는 `+` 자체이므로 구현(폼 전송 여부)에 따라 구분해야 한다.

## 3. 동작 원리

예시 문자열을 인코딩한다.

```
Welcome, Dreamhack Beginners! :)
```

1. 문자열을 문자 단위로 나눈다.
2. 안전한 문자(알파벳, 숫자)는 그대로 둔다.
3. 공백과 예약 문자(`,` `!` `:` `)`)를 데이터로 쓰므로 `%XX`로 바꾼다.

```
Welcome%2C%20Dreamhack%20Beginners%21%20%3A%29
```

디코딩은 `%XX`를 해당 바이트로 되돌리는 역순이다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 퍼센트 인코딩 | `%` 뒤에 바이트 값 16진수를 붙이는 인코딩 |
| 예약 문자(reserved) | URL에서 구분자 역할을 하는 문자 |
| UTF-8 | 비-ASCII 문자를 1~4바이트로 표현하는 문자 인코딩 |
| `application/x-www-form-urlencoded` | HTML 폼 데이터를 전송할 때 쓰는 형식. 공백을 `+`로 쓴다 |
