# [생성형 AI] 웹 기술 (Web Technologies)

웹의 동작 구조, HTTP와 URL, 브라우저 개발자 도구를 다루는 하위 그룹의 목차다. 이 페이지는 목차이며 각 문서의 Task ID는 하위 그룹에서 정한다.

## 이 영역은 무엇인가

웹은 브라우저(클라이언트)가 HTTP로 서버에 요청하고 응답을 받아 화면에 그리는 구조이다. 이 영역은 그 구조를 세 그룹으로 나눠 정리한다. 웹 개발이나 웹 보안을 처음 공부하는 사람이 아래 순서로 읽는다.
