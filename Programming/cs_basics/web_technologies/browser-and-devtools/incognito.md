# 시크릿 모드 (Secret Browsing Mode)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | PRG-BRW-008-DO |
| 유형 | D&O (개념) |
| 목적 | 시크릿 모드가 저장하지 않는 항목과 쿠키 공유 범위를 설명한다 |
| 확인 상태 | 미검증 (원본과 일반 브라우저 지식을 정리했다. 원본의 시크릿 탭 쿠키 공유 정정을 보존했다) |
| 개정 | R1 (2026-11-18) |

## 1. 목적

시크릿 모드는 일반 창과 분리된 새 브라우저 세션을 만든다. 이 문서는 무엇이 저장되지 않는지, 쿠키를 어떻게 공유하는지를 설명한다.

## 2. 구성 요소

### 2.1 저장되지 않는 항목

시크릿 창을 모두 닫으면 다음 항목이 저장되지 않는다.

| 항목 |
|---|
| 방문 기록 |
| 쿠키 및 사이트 데이터 |
| 양식에 입력한 정보 |
| 웹사이트에 부여된 권한 |

### 2.2 쿠키 공유 범위

| 비교 대상 | 쿠키 공유 |
|---|---|
| 시크릿 탭과 일반 창 | 공유하지 않는다 |
| 같은 시크릿 세션의 탭끼리 | 공유한다 |
| 서로 다른 시크릿 창 | 브라우저에 따라 다르다. 미검증 |

### 2.3 단축키

| 환경 | 단축키 |
|---|---|
| Windows/Linux | Ctrl + Shift + N |
| macOS | Cmd(⌘) + Shift(⇧) + N |

{% hint style="info" %}
NOTE: 위 단축키는 크롬 계열 기준이다. 파이어폭스는 Ctrl + Shift + P(비공개 창)를 쓴다. 현재 화면과 다를 수 있다.
{% endhint %}

## 3. 동작 원리

일반 창의 쿠키 저장소와 시크릿 세션의 쿠키 저장소는 별개다. 그래서 같은 사이트에 일반 창과 시크릿 창으로 각각 다른 계정을 로그인할 수 있다. 다수의 계정으로 서비스를 점검할 때 유용하다.

{% hint style="warning" %}
CAUTION: 같은 시크릿 세션의 탭끼리는 쿠키를 공유하므로, 시크릿 탭 두 개로는 두 계정을 동시에 로그인할 수 없다. 여러 계정을 동시에 테스트하려면 일반 창과 시크릿 창을 나눠 쓰거나 별도 브라우저 프로필을 쓴다. 시크릿 창끼리의 쿠키 공유 여부는 브라우저마다 달라 크롬은 모든 시크릿 창이 한 세션을 공유한다(미검증).
{% endhint %}

시크릿 모드는 로컬에 기록이 남지 않게 할 뿐이다. 방문한 웹사이트, 네트워크 관리자, 인터넷 제공자에게는 접속 사실이 그대로 보인다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 세션(session) | 창을 열어서 닫을 때까지 이어지는 브라우저 사용 단위 |
| 쿠키(cookie) | 서버가 브라우저에 저장시키는 작은 데이터. [HTTP 쿠키 및 속성](../http-and-urls/cookie.md) 참조 |
