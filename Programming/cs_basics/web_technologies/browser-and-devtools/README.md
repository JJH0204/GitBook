# 브라우저 및 개발자 도구 (DevTools)

웹 브라우저가 주소를 화면으로 바꾸는 과정과, 브라우저 개발자 도구(DevTools)의 사용법을 정리한다. 문서 번호(Task ID)는 `PRG-BRW-<번호>-<유형>` 형식이다.

{% hint style="info" %}
NOTE: 개발자 도구의 메뉴 이름과 화면 배치는 브라우저와 버전마다 다르다. 이 그룹의 화면 설명은 크롬(Chrome) 계열 기준이며 현재 화면과 다를 수 있다. 모든 절차는 미검증이다.
{% endhint %}

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-BRW-001-DO | 개념 | [웹 브라우저 동작 원리 (Browser)](webbrowser.md) | 주소 입력부터 화면 출력까지의 순서를 이해한다 |
| PRG-BRW-002-DO | 개념 | [브라우저 개발자 도구 개요](browserdevtools.md) | 개발자 도구의 패널 구성과 페이지 소스 보기를 이해한다 |
| PRG-BRW-003-MP | 절차 | [요소 검사 도구 (Inspect)](inspect.md) | 화면의 요소에서 HTML 코드를 찾는다 |
| PRG-BRW-004-MP | 절차 | [개발자 도구 Elements 탭](elements.md) | HTML을 읽고 수정한다 |
| PRG-BRW-005-MP | 절차 | [개발자 도구 Application 탭](devtools_applicationtab.md) | 쿠키를 조회하고 수정한다 |
| PRG-BRW-006-MP | 절차 | [디바이스 툴바 반응형 테스트](devicetoolbar.md) | 화면 크기와 User-Agent를 바꿔 점검한다 |
| PRG-BRW-007-MP | 절차 | [개발자 도구 디버깅 (DevTools)](webdevelopertools.md) | Sources 탭에서 JavaScript를 디버깅한다 |
| PRG-BRW-008-DO | 개념 | [시크릿 모드 (Secret Browsing Mode)](incognito.md) | 시크릿 모드의 저장 범위와 세션 분리를 이해한다 |

## 읽는 순서

1. PRG-BRW-001-DO로 브라우저의 동작 순서를 본다.
2. PRG-BRW-002-DO로 개발자 도구의 구성을 본다.
3. 필요한 탭의 MP(003~007)를 연다.
4. 여러 계정을 동시에 점검하려면 PRG-BRW-008-DO를 본다.
