# CGI 인터페이스 (CGI)

## 1. 목적

CGI(Common Gateway Interface)는 웹 서버가 외부 프로그램을 실행해 동적 응답을 만들게 하는 표준 인터페이스다.

## 2. 구성 요소

| 구성 | 역할 |
|---|---|
| 웹 서버 | 요청을 받고 CGI 프로그램을 실행한다 |
| CGI 프로그램 | 요청 정보를 읽어 응답 내용을 출력한다 |
| 환경변수 | 요청 정보(메서드, 쿼리 문자열 등)를 전달한다 |
| 표준 입력 | 요청 바디를 전달한다 |
| 표준 출력 | 프로그램의 출력이 응답이 된다 |

## 3. 동작 원리

1. 클라이언트가 CGI 프로그램을 가리키는 URL로 요청한다.
2. 웹 서버가 CGI 프로그램을 새 프로세스로 실행한다.
3. 웹 서버가 요청 정보를 환경변수와 표준 입력으로 넘긴다.
4. 프로그램이 응답을 표준 출력으로 출력한다.
5. 웹 서버가 그 출력을 클라이언트에 응답한다.

{% hint style="info" %}
NOTE: 요청마다 프로세스를 새로 실행하므로 부하가 큰 서비스에서는 FastCGI나 모듈 방식을 쓴다. 이 문장은 원본에 없던 일반 지식이며 확인 필요.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| CGI | Common Gateway Interface |
