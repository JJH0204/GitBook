## 1. 목적

웹(World Wide Web, WWW)은 인터넷 기반 서비스 중 HTTP로 정보를 공유하는 서비스다. 인터넷에 접속할 수 있으면 시간과 장소에 관계없이 정보를 구하고 공유할 수 있다. 정보의 흐름이 거미줄(web) 같다 하여 이름이 붙었다. 초기 웹은 저장된 문서를 보여 주는 서비스였으나 현재는 금융, 쇼핑, 협업 같은 복잡한 서비스로 확장됐다.

## 2. 구성 요소

| 구성 | 역할 | 참조 |
|---|---|---|
| 웹 서버 | 정보를 제공하는 주체 | [웹 서버](webserver.md) |
| 웹 클라이언트 | 정보를 받는 이용자 측 프로그램(브라우저) | |
| 프론트엔드(Front-end) | 이용자에게 보이고 상호작용하는 클라이언트 측(HTML/CSS/JS) | [프론트엔드 기초](frontendbasics.md) |
| 백엔드(Back-end) | 요청을 받아 처리하는 서버 측 로직과 DB | |
| HTTP | 요청과 응답 형식을 정한 프로토콜 | [HTTP](../../../../Network/protocols/http.md) |
| HTTPS | HTTP를 암호화한 프로토콜 | [HTTPS](../../../../Network/protocols/https.md) |

오프라인에서 이뤄지던 상호작용이 웹 서비스로 옮겨지면서 처리·저장하는 데이터가 늘었다. 민감한 정보가 유출되거나 악용되지 않도록 보호하는 웹 보안의 중요성이 커졌다.

## 3. 동작 원리

1. 이용자가 브라우저로 웹 서버에 접속한다.
2. 브라우저가 이용자의 요청을 해석해 HTTP 형식으로 리소스를 요청한다.
3. 서버가 HTTP로 전달된 요청을 해석한다.
4. 서버가 요청에 맞는 동작(리소스 탐색, 연산 등)을 수행한다.
5. 서버가 이용자에게 보낼 리소스를 HTTP 형식으로 응답한다.
6. 브라우저가 응답받은 HTML, CSS, JS 같은 웹 리소스를 화면으로 그린다(렌더링).

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|

| 웹 리소스 | 웹에서 주고받는 HTML, CSS, JS, 이미지 같은 자원 |
| 렌더링 | 브라우저가 웹 리소스를 화면으로 그리는 과정 |
