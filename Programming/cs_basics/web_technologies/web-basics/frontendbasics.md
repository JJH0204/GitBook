# 프론트엔드 기초 (Front-end)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | PRG-WBB-002-DO |
| 유형 | D&O (개념) |
| 목적 | 프론트엔드의 범위와 백엔드와의 차이를 설명한다 |
| 확인 상태 | 미검증 (원본과 일반 웹 지식을 정리했다) |
| 개정 | R1 (2026-11-18) |

## 1. 목적

프론트엔드(Front-end)는 이용자에게 직접 보이고 상호작용하는 클라이언트 측 부분이다. [웹 리소스](../../../../Security/notes/webresource.md)(SEC-NOT-003-DO)로 구성된다.

## 2. 구성 요소

| 구성 | 역할 | 실행 위치 |
|---|---|---|
| HTML | 문서의 구조와 내용 | 브라우저 |
| CSS | 문서의 모양 | 브라우저 |
| JavaScript | 동작과 상호작용 | 브라우저 |
| 백엔드(비교) | 요청을 받아 처리하는 서버 측 로직과 DB | 서버 |

## 3. 동작 원리

1. 서버가 HTML, CSS, JavaScript를 응답으로 보낸다.
2. 브라우저가 HTML로 구조를 만들고 CSS로 모양을 입힌다.
3. 브라우저가 JavaScript를 실행해 이용자 입력에 반응한다.

HTML 문법은 [HTML 기초](html.md)(PRG-WBB-006-DO)를 본다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 프론트엔드 | 클라이언트 측 구성(HTML/CSS/JS) |
| 백엔드 | 서버 측 로직과 DB |
