# 실행 파일 및 링킹 (Executables)

라이브러리와 링크 방식, 실행 파일 형식(ELF), 링커와 로더의 동작을 정리한다. 문서 번호(Task ID)는 `PRG-EXL-<번호>-<유형>` 형식이다. 이 그룹의 문서는 모두 D&O(개념)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-EXL-001-DO | 개념 | [동적 링크 라이브러리](dll.md) | 정적·동적 링크와 DLL, 공유 라이브러리(.so)를 구분한다 |
| PRG-EXL-002-DO | 개념 | [ELF 바이너리 형식](elf.md) | ELF 구조와 PE와의 차이를 이해한다 |
| PRG-EXL-003-DO | 개념 | [링커와 로더](linking-and-loading.md) | 심볼 해결, 재배치, 로드 과정을 이해한다 |

## 읽는 순서

1. PRG-EXL-001-DO로 라이브러리와 링크 방식을 이해한다.
2. PRG-EXL-002-DO로 실행 파일의 구조를 읽는다.
3. PRG-EXL-003-DO로 링커와 로더가 하는 일을 읽는다.
