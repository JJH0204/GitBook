## 이 그룹이 다루는 것

소스 코드가 컴파일된 뒤 여러 목적 파일과 라이브러리가 하나의 실행 파일로 묶이고, 실행 시점에 운영체제가 메모리에 올리는 과정을 다룬다. 리눅스의 ELF와 윈도우의 PE 형식 차이, 정적 링크와 동적 링크의 차이를 비교하며 읽는다. 시스템 프로그래밍과 리버스 엔지니어링의 선수 지식이다.

## 선수 지식과 핵심 용어

* 선수 지식: C 컴파일 과정(전처리, 컴파일, 어셈블, 링크)의 대략적인 흐름.
* 목적 파일(object file): 컴파일 결과물로, 아직 실행할 수 없는 중간 산출물.
* 링커(linker): 목적 파일과 라이브러리를 합쳐 심볼 참조를 해결하는 도구.
* 로더(loader): 실행 파일을 메모리에 배치하고 실행을 시작하는 운영체제 구성 요소.
* 정적 링크: 라이브러리 코드를 실행 파일에 복사한다. 동적 링크: 실행 시점에 공유 라이브러리를 연결한다.
* ELF: 리눅스 등 유닉스 계열의 실행 파일 형식. PE: 윈도우의 실행 파일 형식.
