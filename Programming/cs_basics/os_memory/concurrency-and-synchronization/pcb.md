## 1. 목적

프로세스 제어 블록(Process Control Block, PCB)은 운영체제가 프로세스 하나의 상태 정보를 저장하는 자료구조다. 운영체제는 프로세스마다 PCB 하나를 커널의 저장 공간에 동적으로 할당해 관리한다.

## 2. 구성 요소

| 항목 | 설명 |
|---|---|
| 프로세스 식별자(PID) | 프로세스를 구분하는 번호. 부모 PID를 함께 두기도 한다 |
| 프로세스 상태 | 준비, 실행, 대기 등 |
| 프로그램 카운터, 레지스터 | 중단 시점의 CPU 컨텍스트 |
| 스케줄링 정보 | 우선순위, 스케줄링 큐 포인터 |
| 메모리 관리 정보 | 페이지 테이블 포인터, 메모리 영역 정보 |
| 입출력 상태 정보 | 열린 파일 목록, 할당된 장치 |
| 계정 정보 | 사용한 CPU 시간 등 |

Linux 커널에서 PCB에 해당하는 구조체는 `task_struct`다.

## 3. 동작 원리

컨텍스트 스위치 때 운영체제는 실행하던 프로세스의 PC와 레지스터를 그 프로세스의 PCB에 저장하고, 다음 프로세스의 PCB에서 값을 읽어 CPU에 복원한다. 프로세스의 상태 변화(준비, 실행, 대기)도 PCB의 상태 필드에 기록한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| PID | Process Identifier |
| PCB | Process Control Block |
