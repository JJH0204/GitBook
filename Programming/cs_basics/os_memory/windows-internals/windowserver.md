# Windows Server 내부 구조

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | PRG-WIN-003-REF |
| 유형 | REF (문서 목록) |
| 목적 | 서버 구축 관련 문서의 위치를 찾는다 |
| 확인 상태 | 미검증 |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 원본은 제목과 무관한 링크 카드(httpd, Web·FTP·DNS 서버, Samba)뿐이며 대부분 `file:///0903665/...` 형태의 깨진 로컬 경로였다. 제목과 달리 Windows Server 내부 구조 설명은 없다. 연결된 링크만 남기고 깨진 링크(FTP, Samba)는 평문 항목으로 정리했다. Windows Server 내부 구조 자체는 원본에 내용이 없어 새로 쓰지 않았다.
{% endhint %}
