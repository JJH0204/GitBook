## 1. 목적

기억장치는 컴퓨터가 동작하는 데 필요한 데이터를 저장한다. 용도에 따라 주기억장치와 보조기억장치로 나눈다. 이 문서는 둘의 역할과 속도·용량 차이를 정리한다.

## 2. 구성 요소

### 2.1 주기억장치와 보조기억장치

| 구분 | 용도 | 대표 예 | 전원이 꺼지면 |
|---|---|---|---|
| 주기억장치 | 프로그램 실행 중 필요한 데이터를 임시로 저장한다 | RAM(Random-Access Memory) | 내용이 사라진다(휘발성) |
| 보조기억장치 | 운영체제, 프로그램, 파일을 장기간 보관한다 | HDD(Hard Disk Drive), SSD(Solid State Drive) | 내용이 유지된다(비휘발성) |

CPU는 주기억장치의 데이터를 직접 읽고 쓴다. 보조기억장치의 프로그램은 실행 전에 주기억장치로 올려야 한다.

### 2.2 메모리 계층

위로 갈수록 빠르고 작고 비싸다. 아래로 갈수록 느리고 크고 싸다. 속도는 대략적인 자릿수이며 장치에 따라 다르다.

| 계층 | 예 | 대략적인 접근 시간 | 대략적인 용량 | 휘발성 |
|---|---|---|---|---|
| 레지스터 | CPU 내부 레지스터 | 1 ns 미만 | 수백 바이트 | 휘발 |
| 캐시 | L1, L2, L3 (SRAM) | 1 ~ 수십 ns | KB ~ 수십 MB | 휘발 |
| 주기억장치 | RAM (DRAM) | 수십 ~ 100 ns | GB 단위 | 휘발 |
| 보조기억장치 | SSD | 수십 ~ 수백 µs | 수백 GB ~ TB | 비휘발 |
| 보조기억장치 | HDD | 수 ms | TB 단위 | 비휘발 |

## 3. 동작 원리

1. 프로그램이 보조기억장치에 파일로 저장돼 있다.
2. 프로그램을 실행하면 운영체제가 코드와 데이터를 주기억장치에 올린다.
3. CPU는 자주 쓰는 데이터를 캐시에 복사해 두고 읽는다.
4. 연산 중인 값은 레지스터에 둔다.

메모리가 부족하면 운영체제가 주기억장치의 일부를 보조기억장치로 내보낸다. 이 방식은 [가상 메모리와 페이징](virtualmemory.md)에서 다룬다.

### 3.1 RAM의 종류

| 종류 | 특징 | 주 용도 |
|---|---|---|
| DRAM | 커패시터에 전하를 저장하며 주기적으로 갱신해야 한다. 집적도가 높고 싸다 | 주기억장치 |
| SRAM | 플립플롭으로 값을 유지하며 갱신이 필요 없다. 빠르지만 크고 비싸다 | 캐시 |
| ROM | 전원이 꺼져도 내용이 유지되는 읽기 중심 메모리다 | 펌웨어(BIOS/UEFI) |

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| RAM | Random-Access Memory. 임의 위치를 같은 속도로 읽고 쓰는 메모리 |
| ROM | Read-Only Memory |
| DRAM / SRAM | Dynamic / Static RAM |
| HDD / SSD | 자기 디스크 저장장치 / 플래시 메모리 저장장치 |
| 휘발성 | 전원이 꺼지면 내용이 사라지는 성질 |
