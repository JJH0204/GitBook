## 1. 목적

세그먼트는 물리 또는 가상 메모리를 용도별 구역으로 나눈 단위다. "세그먼트"는 두 가지 뜻으로 쓰이므로 구분한다.

| 뜻 | 설명 |
|---|---|
| 프로그램의 세그먼트 | 코드, 데이터, 스택, 힙처럼 프로그램을 논리 단위로 나눈 구역 |
| 세그멘테이션(segmentation) | 메모리 관리 기법. 프로그램을 가변 크기 세그먼트로 나눠 메모리에 배치한다 |

## 2. 구성 요소

| 세그먼트 | 역할 |
|---|---|
| 코드 세그먼트 | 실행할 기계어 코드를 담는다 |
| 데이터 세그먼트 | 전역·정적 변수를 담는다 |
| 스택 세그먼트 | 지역 변수, 함수 인자, 복귀 주소를 담는다 |
| 힙 세그먼트 | 실행 중 동적 할당한 데이터를 담는다 |

## 3. 동작 원리

### 3.1 세그멘테이션 기법

1. 프로그램을 코드, 데이터, 스택 등 논리 단위로 나눈다.
2. 각 세그먼트는 가변 크기이며 세그먼트 번호와 세그먼트 내 오프셋으로 주소를 지정한다.
3. 운영체제는 세그먼트 테이블(세그먼트별 시작 주소, 크기, 권한)로 논리 주소를 물리 주소로 바꾼다.
4. 오프셋이 세그먼트 크기를 넘거나 권한에 어긋나면 오류가 발생한다. 이 오류의 이름이 세그멘테이션 결함(segmentation fault)이다.

현대 x86-64 운영체제는 세그멘테이션 대신 페이징 중심으로 메모리를 보호한다. 그래도 "세그멘테이션 결함"이라는 이름은 남아 있다. 페이징과의 비교는 [가상 메모리와 페이징](virtualmemory.md)에서 다룬다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 세그먼트 테이블 | 세그먼트 번호별 시작 주소, 크기, 권한을 담은 표 |
| 오프셋 | 세그먼트 시작에서 떨어진 거리 |
| 세그멘테이션 결함 | 허용되지 않은 메모리 접근으로 발생하는 오류 |
