## 1. 목적

응용 프로그램의 실행과 시스템 자원 할당 같은 복잡한 관리는 사용자가 아니라 운영체제(Operating System, OS)가 한다. 사용자와 응용 프로그램은 하드웨어(CPU, 메모리, 입출력 장치)에 직접 접근하지 않고 운영체제를 통한다. 운영체제는 하드웨어와 응용 프로그램 사이의 중재자다.

| 계층 |
|---|
| 사용자, 응용 프로그램 |
| **운영체제** |
| 하드웨어 (CPU, 메모리, 입출력 장치 등) |

## 2. 구성 요소

### 2.1 운영체제가 하는 일

| 기능 | 내용 |
|---|---|
| CPU 스케줄링 | 실행 중인 프로그램(프로세스)에 CPU를 번갈아 할당하고 어느 프로세스에 줄지 정한다 |
| 메모리 관리 | 메모리 공간을 프로세스에 분배하고 사용을 관리한다([가상 메모리](virtualmemory.md)) |
| 입출력 관리 | 입출력 장치와 정보를 주고받는 과정을 관리한다 |
| 사용자 인터페이스 | 사용자가 명령을 내릴 수 있게 한다. 이 기능은 셸이 맡는다 |

### 2.2 커널과 셸

| 구성 | 역할 |
|---|---|
| 커널(Kernel) | 운영체제의 핵심. 하드웨어 관리를 실제로 수행한다. 부팅 시 메모리에 올라가 종료될 때까지 실행된다 |
| 셸(Shell) | 사용자와 커널 사이의 인터페이스. 명령을 해석해 커널에 요청하고 결과를 사용자에게 보여 준다 |

| 계층 |
|---|
| 사용자, 응용 프로그램 |
| **셸** |
| **커널** |
| 하드웨어 (CPU, 메모리, 입출력 장치 등) |

셸에 명령을 입력하면 셸이 해석해 커널에 요청하고, 커널이 하드웨어를 조작해 결과를 셸에 돌려주며, 셸이 사용자에게 출력한다. 공격 관점에서 원격 대상의 셸을 얻으면 명령으로 시스템을 제어할 수 있어 시스템 침투의 성공으로 여긴다.

### 2.3 사용자 모드와 커널 모드

| 모드 | 실행 주체 | 권한 |
|---|---|---|
| 사용자 모드 | 응용 프로그램 | 제한됨. 하드웨어와 다른 프로세스 메모리에 직접 접근할 수 없다 |
| 커널 모드 | 커널, 드라이버 | 전체 하드웨어와 메모리에 접근할 수 있다 |

응용 프로그램이 파일 읽기, 메모리 할당 같은 서비스가 필요하면 시스템 콜(system call)로 커널에 요청한다. 시스템 콜이 호출되면 CPU가 사용자 모드에서 커널 모드로 전환했다가 처리 후 되돌린다.

### 2.4 프로세스와 스레드

| 구분 | 설명 |
|---|---|
| 프로세스 | 실행 중인 프로그램. 독립된 가상 주소 공간을 가진다 |
| 스레드 | 프로세스 안의 실행 흐름. 같은 프로세스의 스레드는 코드·데이터·힙을 공유하고 스택과 레지스터는 따로 가진다 |

## 3. 동작 원리: 운영체제 종류

| 계열 | 개발 주체 | 특징 |
|---|---|---|
| Windows | 마이크로소프트 | 그래픽 사용자 인터페이스(GUI)를 제공한다. NT 계열 커널이며 UNIX와 별개 계통이다 |
| UNIX | 벨 연구소 | 현대 운영체제 설계의 원형이다. 사용자가 키보드로 입력하는 명령으로 조작하는 대화식 운영체제다 |
| Linux | 리누스 토발즈(Linus Torvalds)가 커널을 작성, 이후 오픈소스 커뮤니티 | 유닉스 계열(Unix-like) 커널이다. UNIX 소스 코드를 기반으로 하지 않는다. 명령줄(CLI) 중심으로 쓰이며 데스크톱 GUI 환경도 있다 |
| macOS | 애플 | 유닉스 계열이며 GUI 기반이다 |
| Android | 구글 | Linux 커널 기반 모바일 운영체제다 |
| iOS | 애플 | 모바일 운영체제이며 macOS와 같은 Darwin 계통이다 |

Linux 위의 배포판으로 Ubuntu, CentOS 등이 있다. Linux는 소스를 공개해 누구나 수정·재배포할 수 있다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| OS | Operating System |
| GUI / CLI | Graphical User Interface / Command-Line Interface |
| 시스템 콜 | 응용 프로그램이 커널 서비스를 요청하는 인터페이스 |
| 스케줄링 | CPU를 쓸 프로세스를 정하는 일 |
| Unix-like | UNIX와 비슷하게 설계된 운영체제 계통 |
