## 이 영역이 다루는 것

프로그래밍과 보안 학습의 바탕이 되는 컴퓨터 과학 개념을 다룬다. 컴퓨터가 무엇으로 이루어져 있는지(구조), 데이터를 어떻게 표현하는지(데이터 표현), 프로그램이 어떻게 실행되는지(운영체제와 메모리), 네트워크 위에서 어떻게 통신하는지(웹 기술) 순서로 읽는 것을 권장한다.

## 읽는 순서

1. 컴퓨터 구조로 CPU, 버스, 명령어 집합의 역할을 익힌다.
2. 데이터 표현으로 비트와 인코딩을 익힌다.
3. 운영체제와 메모리로 프로세스와 메모리 배치를 익힌다.
4. 웹 기술로 HTTP와 브라우저 동작을 익힌다.

## 선수 지식과 핵심 용어

* 선수 지식: 없음. 컴퓨터를 사용해 본 경험이면 충분하다.
* CPU: 명령어를 해석하고 실행하는 장치. 메모리: 실행 중인 프로그램과 데이터를 담는 장치.
* 프로세스: 실행 중인 프로그램의 인스턴스.
* 프로토콜: 통신 당사자가 지키는 약속된 규칙.
