# [생성형 AI] C 코드 조각 (C Snippets)

재사용하는 C 코드 조각을 모아 둔다. 문서 번호(Task ID)는 `PRG-REF-<번호>-<유형>` 형식이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (C 컴파일러로 실행하지 않았다. 하위 문서를 요약했다) |

## 이 그룹은 무엇인가

연결 리스트로 구현한 스택의 헤더와 소스를 가져다 쓸 수 있게 모아 둔 곳이다. 헤더(PRG-REF-001-REF)에서 함수 선언과 반환값 규약을 먼저 확인하고, 구현(PRG-REF-002-REF)을 읽는 순서를 권한다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-REF-001-REF | REF | [연결 스택 헤더 (MyStack.h)](mystack.h.md) | 스택 자료형, 함수 선언, 반환값 규약, `stack_*` 이름 대응을 확인한다 |
| PRG-REF-002-REF | REF | [연결 스택 구현 (MyStack.c)](mystack.c.md) | 스택 함수 구현과 정정 내역을 확인한다 |

{% hint style="info" %}
NOTE: 이 그룹의 코드는 읽고 정정한 것이며 이 환경에서 컴파일·실행하지 않았다. 스택 구현의 정본은 이 두 문서다. 스택의 개념은 [스택 (Stack)](../../cs-fundamentals/data-structures/stack.md)에 있다.
{% endhint %}
