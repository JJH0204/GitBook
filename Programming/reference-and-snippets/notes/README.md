# [생성형 AI] 개발 메모 (Notes)

짧은 개발 메모를 모아 둔다. 문서 번호(Task ID)는 `PRG-REF-<번호>-<유형>` 형식이며 [C 코드 조각](../c-snippets/README.md)과 번호를 이어 쓴다(001, 002는 C 코드 조각, 003부터 이 그룹).

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 README (안내) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (문서를 읽고 정리했으며 코드를 실행하지 않았다) |

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRG-REF-003-DO | 개념 | [헝가리안 표기법 (Hungarian)](hungariannotation.md) | 변수명 접두어 표기법의 두 갈래와 현재 쓰임을 확인한다 |

## 이 그룹에 넣는 기준

| 넣는 것 | 넣지 않는 것 |
|---|---|
| 한 주제를 한 쪽으로 끝내는 짧은 개념 메모(명명 규칙, 관례, 용어) | 코드 구현 전체(C 코드 조각 또는 자료구조 문서로 보낸다) |
| 실행 없이 읽어서 확인할 수 있는 내용 | 절차가 긴 설치·설정 문서(해당 언어 그룹으로 보낸다) |

새 메모는 다음 번호(PRG-REF-004)부터 이어 붙이고 위 문서 목록에 한 줄을 추가한다.
