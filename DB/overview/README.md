# 데이터베이스 개요 및 기초

데이터베이스의 기본 개념과 실습 데이터베이스 구성을 다룬다. 문서 번호(Task ID)는 `DB-OVW-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| DB-OVW-001-DO | 개념 | [데이터베이스 기초 (Database Basics)](databasebasics.md) | SQL 분류, CRUD, 그룹화, 인덱스, 조인 개념을 이해한다 |
| DB-OVW-002-DO | 개념 | [물리적 데이터 독립성](physicaldataindependence.md) | 물리적·논리적 데이터 독립성의 차이를 이해한다 |
| DB-OVW-003-MP | 절차 | [학생 실습 데이터베이스 생성](databasebasics-practice.md) | `school` 데이터베이스를 만들고 샘플 데이터를 적재한다 |
| DB-OVW-004-REF | 표 | [기본 조회 질의 예시](databasebasics-queries.md) | 그룹화, 정렬, 조인 질의를 찾아 쓴다 |

## 읽는 순서

1. DB-OVW-001-DO로 SQL 분류와 조회 개념을 읽는다.
2. DB-OVW-003-MP로 실습 데이터베이스를 만든다.
3. DB-OVW-004-REF의 질의를 실행한다.
4. DB-OVW-002-DO로 데이터 독립성을 읽는다.
