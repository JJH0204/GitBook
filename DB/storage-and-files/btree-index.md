## 1. 목적

인덱스는 전체 행을 읽지 않고 원하는 행을 찾게 하는 구조다. 대부분의 관계형 DBMS는 기본 인덱스로 B+트리를 쓴다. 파일 조직의 앞선 방식인 ISAM은 DB-STO-001-DO, 인덱스 종류 목록은 DB-DSN-007-DO를 따른다.

## 2. 구성 요소

| 구성 | 역할 |
|---|---|
| 루트 노드 | 탐색의 시작점. 하위 노드의 키 범위를 안내한다 |
| 내부 노드 | 키 범위로 하위 노드를 가리킨다 |
| 리프 노드 | 키와 행 위치(또는 행 자체)를 가진다. 리프끼리 연결되어 있어 범위 조회가 빠르다 |

| 항목 | 인덱스 없음 | B+트리 인덱스 |
|---|---|---|
| 한 값 찾기(`=`) | 전체 행 확인 | 루트에서 리프까지 몇 단계 |
| 범위 찾기(`BETWEEN`, `<`, `>`) | 전체 행 확인 | 시작 리프를 찾은 뒤 연결을 따라 읽기 |
| 정렬(`ORDER BY`) | 별도 정렬 | 인덱스 순서를 그대로 활용 가능 |
| 쓰기 비용 | 낮다 | 입력, 수정, 삭제 때 인덱스도 갱신해야 해서 높다 |

{% hint style="info" %}
NOTE: InnoDB는 기본 키 기준 클러스터형 인덱스에 행 자체를 저장한다. 보조 인덱스의 리프는 기본 키 값을 가지며, 보조 인덱스로 찾은 뒤 기본 키로 한 번 더 찾는다.
{% endhint %}

### 2.1 복합 인덱스와 최좌측 규칙

`t(a, b, c)`에 `CREATE INDEX idx_ab ON t(a, b);`를 만든 뒤 SQLite 3.46.1의 실행 계획 결과는 아래와 같다.

| 질의 조건 | 실행 계획 | 해석 |
|---|---|---|
| `WHERE a = 1` | `SEARCH ... USING INDEX idx_ab (a=?)` | 인덱스를 쓴다 |
| `WHERE a = 1 AND b = 2` | `SEARCH ... USING INDEX idx_ab (a=? AND b=?)` | 두 열 모두 쓴다 |
| `WHERE b = 2` | `SCAN t` | 첫 열이 없어 못 쓴다 |
| `WHERE a > 1 AND b = 2` | `SEARCH ... USING INDEX idx_ab (a>?)` | 범위 조건 뒤의 `b`는 탐색에 쓰이지 않는다 |
| `WHERE c = 3` | `SCAN t` | 인덱스에 없는 열이다 |
| `SELECT a, b ... WHERE a = 1` | `SEARCH ... USING COVERING INDEX idx_ab (a=?)` | 인덱스만으로 답하는 커버링 인덱스다 |

복합 인덱스는 왼쪽 열부터 순서대로 쓸 수 있다. 이를 최좌측 접두(leftmost prefix) 규칙이라 한다. SQLite와 MariaDB의 옵티마이저는 다르므로 MariaDB에서는 `EXPLAIN`으로 따로 확인한다.

## 3. 동작 원리

### 3.1 실행 계획 확인

| DBMS | 명령 | 주요 확인 항목 |
|---|---|---|
| MariaDB | `EXPLAIN SELECT ...;` | `type`(`ALL`이면 전체 읽기), `key`(사용한 인덱스), `rows`(추정 읽을 행 수) |
| SQLite | `EXPLAIN QUERY PLAN SELECT ...;` | `SEARCH`(인덱스 사용), `SCAN`(전체 읽기) |

### 3.2 인덱스가 효과 없는 경우

| 경우 | 이유 |
|---|---|
| 행이 몇십 개뿐인 테이블 | 전체 읽기가 더 싸다 |
| 값의 종류가 아주 적은 열(성별 등) | 인덱스로 거를 수 있는 행이 적다 |
| 열에 함수를 씌운 조건(`WHERE UPPER(name) = 'A'`) | 인덱스의 값과 직접 비교하지 못한다 |
| 쓰기가 매우 많은 테이블 | 인덱스 갱신 비용이 조회 이득보다 커진다 |

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 커버링 인덱스 | 질의에 필요한 열이 모두 인덱스에 있어 행을 읽지 않아도 되는 경우 |
| 클러스터형 인덱스 | 인덱스 순서가 행의 저장 순서와 같은 인덱스 |
| 카디널리티 | 열의 서로 다른 값의 수. 높을수록 인덱스 효과가 크다 |
