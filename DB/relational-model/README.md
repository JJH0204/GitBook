# 관계형 모델 이론

관계형 모델에서 데이터의 정확성을 지키는 규칙을 다룬다. 문서 번호(Task ID)는 `DB-REL-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| DB-REL-001-DO | 개념 | [데이터 무결성 규정 (Integrity)](integrity.md) | 개체·참조·도메인 무결성과 제약 조건을 이해한다 |

## 읽는 순서

1. DB-REL-001-DO를 읽는다.
2. 제약 조건을 정의하는 SQL 문법은 `sql` 폴더의 DDL 문서를 본다.
