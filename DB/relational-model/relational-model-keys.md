## 1. 목적

관계형 모델은 데이터를 릴레이션(relation)으로 표현한다. 행을 구별하는 방법은 키(key)가 정한다. 이 문서는 구조 용어와 키 종류를 한곳에 정리한다. 키를 제약 조건으로 지키는 방법은 DB-REL-001-DO를 따른다.

## 2. 구성 요소

### 2.1 릴레이션 구조 용어

| 이론 용어 | SQL에서의 이름 | 뜻 |
|---|---|---|
| 릴레이션(relation) | 테이블(table) | 속성과 튜플로 이뤄진 표 |
| 튜플(tuple) | 행(row) | 릴레이션의 한 줄. 사실 하나를 나타낸다 |
| 속성(attribute) | 열(column) | 튜플이 가진 항목 하나 |
| 도메인(domain) | 데이터 타입과 허용 값 | 한 속성이 가질 수 있는 값의 집합 |
| 차수(degree) | 열의 개수 | 속성의 수 |
| 카디널리티(cardinality) | 행의 개수 | 튜플의 수 |

{% hint style="info" %}
NOTE: 이론상 릴레이션은 튜플의 집합이라 같은 튜플이 없고 순서가 없다. SQL 테이블은 기본 키를 정하지 않으면 같은 행을 허용한다.
{% endhint %}

### 2.2 키의 종류

| 키 | 정의 | 조건 |
|---|---|---|
| 슈퍼키(super key) | 튜플을 유일하게 식별하는 속성의 집합 | 유일성 |
| 후보키(candidate key) | 슈퍼키 중 속성을 하나라도 빼면 유일성이 깨지는 최소 집합 | 유일성 + 최소성 |
| 기본 키(primary key, PK) | 후보키 중 설계자가 대표로 고른 키 | NULL 불가, 테이블당 하나 |
| 대체키(alternate key) | 후보키 중 기본 키로 고르지 않은 키 | SQL에서는 `UNIQUE`로 선언한다 |
| 복합키(composite key) | 속성 둘 이상으로 이뤄진 키 | 기본 키와 후보키 모두 복합일 수 있다 |
| 외래 키(foreign key, FK) | 다른 릴레이션(또는 같은 릴레이션)의 후보키를 참조하는 속성 | 값은 참조 대상에 있거나 NULL |

### 2.3 키의 포함 관계

| 순서 | 집합 | 설명 |
|---|---|---|
| 1 | 슈퍼키 | 가장 넓다. 학번과 이름을 함께 묶은 집합도 슈퍼키다 |
| 2 | 후보키 | 슈퍼키 중 최소인 것. 학번, 주민 번호 대용 식별자가 해당한다 |
| 3 | 기본 키 | 후보키 중 하나 |
| 4 | 대체키 | 후보키에서 기본 키를 뺀 나머지 |

## 3. 동작 원리

수강 신청 예로 확인한다. `student(sno, ssn, name, dept)`에서 `sno`와 `ssn`은 각각 학생을 하나로 정한다. 두 속성은 후보키다. `sno`를 기본 키로 고르면 `ssn`은 대체키다. `{sno, name}`은 슈퍼키지만 `name`을 빼도 유일하므로 후보키가 아니다.

```sql
CREATE TABLE student (
  sno  INTEGER PRIMARY KEY,
  ssn  TEXT UNIQUE NOT NULL,   -- 대체키
  name TEXT,
  dept TEXT
);
CREATE TABLE course (cno TEXT PRIMARY KEY, title TEXT);
CREATE TABLE enroll (
  sno   INTEGER REFERENCES student(sno),   -- 외래 키
  cno   TEXT    REFERENCES course(cno),    -- 외래 키
  grade TEXT,
  PRIMARY KEY (sno, cno)                   -- 복합 기본 키
);
```

| 시도 | 결과 | 위반한 규칙 |
|---|---|---|
| 같은 `(sno, cno)`를 다시 입력한다 | 거부된다 | 복합 기본 키의 유일성 |
| 없는 `sno`로 `enroll` 행을 입력한다 | 거부된다 | 외래 키(참조 무결성, 외래 키 검사를 켠 경우) |
| 이미 있는 `ssn`을 입력한다 | 거부된다 | 대체키(`UNIQUE`) |
| 다른 학생이 같은 과목을 신청한다 | 허용된다 | 위반 없음 |

{% hint style="warning" %}
CAUTION: SQLite는 외래 키 검사가 기본으로 꺼져 있어 `PRAGMA foreign_keys=ON;`을 실행해야 한다. MariaDB의 InnoDB는 기본으로 검사한다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| PK | Primary Key. 기본 키 |
| FK | Foreign Key. 외래 키 |
| 최소성 | 키에서 속성을 하나라도 빼면 유일성이 깨지는 성질 |
| 유일성 | 서로 다른 두 튜플이 같은 키 값을 갖지 않는 성질 |
