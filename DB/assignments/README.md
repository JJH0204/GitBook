# 실습 및 과제

SQL 조회 실습과 DB 보안 실습에서 쓰이는 개념을 정리한다. 문서 번호(Task ID)는 `DB-ASG-<번호>-<유형>` 형식이다. 유형은 DO(개념)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| DB-ASG-001-DO | 개념 | [데이터베이스 실습 과제](dbassignment.md) | 정렬, 집합, 조인, 집계, 중복 제거와 웹 SQL 인젝션 점검의 개념을 이해한다 |
| DB-ASG-002-DO | 개념 | [데이터베이스 보안 실습 과제](dbsecurityassignment.md) | 계정·권한 관리, 메모리 확인, 모니터링, 취약 환경 구성의 개념을 이해한다 |

## 읽는 순서

1. DB-ASG-001-DO로 조회 SQL과 SQL 인젝션의 개념을 익힌다.
2. DB-ASG-002-DO로 계정·권한과 운영 점검의 개념을 익힌다.
3. 명령 문법은 [DML](../sql/sql_dml.md), [DCL](../sql/sql_dcl.md), [MariaDB 기본 사용법](../operations/mariadb.md) 문서를 따른다.
