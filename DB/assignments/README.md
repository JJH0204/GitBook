# [생성형 AI] 실습 및 과제

SQL 조회 실습과 DB 보안 실습에서 쓰이는 개념을 정리한다. 문서 번호(Task ID)는 `DB-ASG-<번호>-<유형>` 형식이다. 유형은 DO(개념)다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

DB 학습 중 직접 조회 SQL을 써 보고 DB 보안 설정을 점검하는 실습 문서를 모은 그룹이다. SQL 기초 문법을 한 번 읽은 독자가 개념을 실습 관점으로 확인할 때 쓴다. 번호 순서(001 → 002)로 읽는다.

## 핵심 용어

- SELECT: 테이블에서 행을 조회하는 SQL 문
- JOIN: 둘 이상의 테이블을 키로 연결하는 연산
- 집계 함수: COUNT, SUM 등 여러 행을 하나의 값으로 줄이는 함수
- SQL 인젝션: 입력값이 SQL 문으로 해석되어 질의가 변조되는 취약점. 점검은 허가받은 환경에서만 한다
- 최소 권한: 계정에 필요한 권한만 부여하는 원칙

## 선수 지식

SQL 기초 문법(SELECT, WHERE), 관계형 데이터베이스의 테이블 개념.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| DB-ASG-001-DO | 개념 | [데이터베이스 실습 과제](dbassignment.md) | 정렬, 집합, 조인, 집계, 중복 제거와 웹 SQL 인젝션 점검의 개념을 이해한다 |
| DB-ASG-002-DO | 개념 | [데이터베이스 보안 실습 과제](dbsecurityassignment.md) | 계정·권한 관리, 메모리 확인, 모니터링, 취약 환경 구성의 개념을 이해한다 |

## 읽는 순서

1. DB-ASG-001-DO로 조회 SQL과 SQL 인젝션의 개념을 익힌다.
2. DB-ASG-002-DO로 계정·권한과 운영 점검의 개념을 익힌다.
3. 명령 문법은 [DML](../sql/sql_dml.md), [DCL](../sql/sql_dcl.md), [MariaDB 기본 사용법](../operations/mariadb.md) 문서를 따른다.
