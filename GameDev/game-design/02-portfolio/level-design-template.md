# 레벨 디자인 문서 템플릿

새 페이지 제목 양식: `[레벨명] 레벨 디자인 문서`

> 레벨 디자인 문서의 핵심은 **"왜 여기에 이걸 놓았나"**를 공간마다 설명하는 것이다. 배치 결과만 보여 주면 레벨 에디터 스크린샷과 다를 게 없다.

## 0. 개요

| 항목 | 내용 |
|---|---|
| 레벨의 목표 (플레이어 입장) | |
| 이 레벨이 가르치는 것 | (새 기믹, 새 적, 조작) |
| 예상 플레이 시간 | 첫 플레이 __분 / 숙련자 __분 |
| 전후 레벨과의 관계 | 앞에서 배운 것 → 여기서 변주 → 다음에서 시험 |
| 내 역할 | |

## 1. 탑뷰 맵

> 손그림, draw.io, Excalidraw 모두 괜찮다. 격자를 깔고 범례를 붙인다. 이미지는 페이지에 바로 붙여 넣는다.

(여기에 탑뷰 맵 이미지)

| 기호 | 의미 |
|---|---|
| ● 번호 | 구간 번호 (아래 표와 연결) |
| → 실선 | 핵심 동선 (클리어에 필요한 길) |
| ⇢ 점선 | 선택 동선 (보상, 비밀) |
| ★ | 랜드마크 / 시선 유도물 |
| ▲ | 적 배치 |
| ◆ | 기믹 |

## 4. 긴장과 이완 (난이도 곡선)

> 구간마다 긴장도를 1–5로 매긴다. 막대가 계속 높기만 하면 지치고, 계속 낮기만 하면 지루하다.

| 구간 | 이벤트 | 긴장도 | 그래프 | 의도 |
|---|---|---|---|---|
| ① | 시작, 안전 지대 | 1 | █ | 조작 확인, 목표 제시 |
| ② | 기믹 첫 등장 (안전한 곳에서) | 2 | ██ | |
| ③ | 첫 전투 | 3 | ███ | |
| ④ | 휴식 / 보상 | 1 | █ | |
| ⑤ | 기믹 + 전투 결합 | 4 | ████ | |
| ⑥ | 클라이맥스 | 5 | █████ | |
| ⑦ | 마무리 / 보상 | 2 | ██ | |

## 5. 기믹 배치 의도

> 기믹은 보통 **소개 → 연습 → 변주 → 시험** 순서로 놓는다. 단계를 건너뛴 곳이 있다면 이유를 적는다.

| 기믹 | 소개 (실패해도 안전) | 연습 (반복) | 변주 (다른 요소와 결합) | 시험 (실패 시 대가) |
|---|---|---|---|---|
| | 구간 | 구간 | 구간 | 구간 |
