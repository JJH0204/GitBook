## 3. 기능 평가표

> 코어 기여도와 비용은 같은 척도로 매긴다. 비용은 인일(1명이 1일 일한 양) 단위로 적는다.

| 기능 | 코어 기여 (1–5) | 비용 (인일) | 리스크 (상/중/하) | 판정 | 근거 |
|---|---|---|---|---|---|
| | | | | Keep / Cut / Later / Simplify | |

판정 기준:
- **Keep**: 코어 기여 4 이상
- **Simplify**: 코어 기여는 높지만 비용이 크다 → 축소판으로 만든다 (무엇을 덜어냈는지 적는다)
- **Later**: 코어 기여 2–3, 다음 마일스톤에서 재평가
- **Cut**: 코어 기여 1–2, 또는 리스크가 '상'인데 대안이 있음
