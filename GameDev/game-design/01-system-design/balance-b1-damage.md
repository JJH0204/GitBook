## 5. 절차

### A. 입력 셀과 공식 정의

| 셀 | 값 | 의미 |
|---|---|---|
| B1 | 200 | 공격력 (ATK) |
| B2 | 1000 | 체력 (HP) |
| B3 | 0.1 | 감산형 최소 데미지 비율 |

- **감산형**: `데미지 = MAX(ATK − DEF, ATK × 최소 비율)`
- **비율형**: $$D = ATK \times \dfrac{100}{100 + DEF}$$
- **감소율**: `1 − 데미지 ÷ ATK`
- **EHP (유효 체력)**: 비율형에서 같은 피해를 받을 때 실제로 버티는 체력. `HP × (100 + DEF) ÷ 100`

1. (5-A-01) B1~B3에 위 값을 입력하고 노란 배경을 칠한다. → 결과: 입력 셀 3개가 노란색이다.
2. (5-A-02) 5행에 헤더 `DEF | 감산형 | 비율형 | 감소율(%) | EHP`를 쓴다. → 결과: 헤더 5칸이 채워진다.
3. (5-A-03) A6부터 방어력을 0, 25, 50, … 500까지 25 간격으로 21행 채운다. → 결과: A6~A26에 0~500이 있다.
4. (5-A-04) B~E열에 각 공식을 입력하고 아래로 채운다. → 결과: 21행 모두 값이 계산된다.

### B. 과제

1. (5-B-01) 두 공식을 한 선 그래프에 그린다 (x축 = DEF). → 결과: 곡선 2개가 한 그래프에 있다.
2. (5-B-02) 두 곡선이 만나는 지점을 그래프에서 찾고, 식을 세워 증명한다. → 결과: 교차점 DEF 값이 식으로 도출된다.
3. (5-B-03) DEF 0 → 100과 DEF 400 → 500에서 각각 감소율 증가폭과 EHP 증가폭을 비교한다. → 결과: 구간별 증가폭 4개가 적힌다.
4. (5-B-04) 감산형 데미지가 최솟값(ATK의 10%)에 처음 닿는 DEF를 찾는다. → 결과: DEF 값 1개가 적힌다.
5. (5-B-05) 다단 히트를 비교한다. 데미지 180짜리 스킬을 "180 × 1타"와 "60 × 3타"로 만들었을 때, DEF 0 / 30 / 50에서 감산형 총 데미지를 계산한다. → 결과: 6개 값이 적힌다.
6. (5-B-06) 비율형의 100을 상수 K로 바꾼 `ATK × K ÷ (K + DEF)`에서 K = 50 + 10 × 공격자 레벨로 둔다. DEF 100인 적에게 레벨 1 / 10 / 30 공격자의 데미지를 계산한다. → 결과: 3개 값이 적힌다.

### C. 의도 문장과 말로 답하기

1. (5-C-01) AI 없이 다음 질문에 답한다.
   - "방어력은 수확 체감이라 후반엔 쓸모없다"는 주장을 EHP로 반박해 본다.
   - 감산형을 일부러 쓰고 싶은 게임은 어떤 게임인가? (힌트: "이 무기로는 저 갑옷을 못 뚫는다"가 재미인 게임)
   - 5-B-05의 결과는 다단 히트 스킬을 기획할 때 어떤 제약이 되는가?
2. (5-C-02) 의도 문장 3개를 쓴다. → 결과: 문장 3개가 시트 아래에 있다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |

| 1 | 아래 검산값 표와 시트를 대조한다 | 모든 행이 일치한다 | 소수점 첫째 자리까지 일치 |
| 2 | 5-B-02~5-B-06 답을 아래 값과 대조한다 | 일치한다 | 값이 같다 |

| 25 | 175 | 160 | 20% | 1,250 |
| 100 | 100 | 100 | 50% | 2,000 |
| 180 | 20 | 71.4 | 64.3% | 2,800 |
| 300 | 20 | 50 | 75% | 4,000 |
| 500 | 20 | 33.3 | 83.3% | 6,000 |

- 5-B-03: 감소율은 +50%p vs +3.3%p로 줄어들지만, EHP는 두 구간 모두 +1,000으로 같다.
- 5-B-04: DEF 180
- 5-B-05: DEF 30에서 1타 150 vs 3타 90, DEF 50에서 1타 130 vs 3타 30
