## 시트 기본기 (모든 실습 공통)

| 규칙 | 이유 |
|---|---|
| 입력 셀(노란 배경)과 수식 셀(흰 배경)을 색으로 구분한다 | 무엇을 바꿔도 되는지 한눈에 보인다 |
| 수식 안에 숫자를 직접 쓰지 않는다. `=200*100/(100+A6)` ✗ → `=$B$1*100/(100+A6)` ✓ | 튜닝값을 바꿀 때 수식을 고칠 필요가 없다 |
| 헤더에 단위를 쓴다: `쿨타임(초)`, `감소율(%)` | 초와 프레임, 0.3과 30%의 혼동을 막는다 |
| 그래프 제목은 "무엇과 무엇의 비교인가"로 쓴다: "방어력에 따른 받는 데미지: 감산형 vs 비율형" | 그래프가 질문에 답하게 된다 |
| 실습마다 마지막에 의도 문장 3개를 쓴다 | 이 훈련의 진짜 결과물이다 |

의도 문장 예시: "보스 처치 시간은 평균 로테이션 기준 90초로 잡았다. 필살기 쿨타임(45초)의 두 배라서 전투 중 필살기 타이밍을 고르는 순간이 최소 두 번 생긴다."
