# 역기획 연습 주제

> 아래 질문은 **답이 아니라 길잡이**다. 게임의 실제 수치나 규칙은 직접 플레이해서 관찰하고, 모르는 것은 추정으로 표시한다(템플릿 ④). 여기 없는 게임이라도 지금 즐겨 하는 게임이 가장 좋은 주제다.

## 주제 고르는 법

- **동사 하나 크기**로 자른다: 패링한다, 리롤한다, 강화한다, 도망친다.
- **25분 안에 상태 전이표까지 그릴 수 있는 크기**인지 본다. 상태가 6개를 넘으면 쪼갠다.
- **최근 2주 안에 직접 해 본 것**을 고른다. 기억이 흐린 시스템은 ④ 칸만 늘어난다.

난이도: ★ 상태 2–3개, 공식 1개 / ★★ 상태 4개 이상 또는 확률 판정 / ★★★ 여러 시스템이 맞물리거나 숨은 보정이 있음

## 전투·액션

| 주제 | 난이도 | 길잡이 질문 |
|---|---|---|
| 젠레스 존 제로: 패링(회피 반격)과 그로기 | ★★ | 그로기 게이지는 무엇으로 쌓이고 무엇으로 줄어드는가? 그로기 상태에서 플레이어에게 열리는 선택지는 '보상'인가 '전환'인가? 일반 몹과 보스의 차이를 테이블로 표현하면 어떤 컬럼이 필요한가? |
| 소울라이크 아무거나: 강인도·경직 | ★★ | 맞았을 때 경직되는 조건과 버티는 조건은? 공격 중 강인도는 평소와 같은가? 다단 히트는 강인도를 어떻게 깎는가? |
| 몬스터 헌터: 부위 파괴 | ★★★ | 부위별 내구도는 본체 체력과 독립인가? 파괴되면 무엇이 바뀌는가(행동, 보상, 약점)? 파괴 보상이 사냥 동선을 어떻게 바꾸는가? |
| 아무 액션 게임: 입력 버퍼와 캔슬 | ★★ | 동작 도중 누른 입력은 언제까지 기억되는가? 어떤 동작이 어떤 동작을 끊을 수 있는가? 표로 그리면 행과 열은 무엇인가? |

## RPG·전략

| 주제 | 난이도 | 길잡이 질문 |
|---|---|---|
| 다키스트 던전: 스트레스와 기벽(고난) 판정 | ★★ | 스트레스는 어떤 행동·사건으로 오르고 내리는가? 한계에 도달하면 무엇이 판정되고, 결과는 몇 갈래인가? 그 판정이 '파티 관리'라는 루프를 어떻게 강화하는가? |
| XCOM류: 명중률 표시와 판정 | ★★ | 화면에 표시된 확률과 실제 판정이 같다고 확신할 수 있는가? 다르다면 왜 다르게 만들까? 엄폐·고도·거리 보정은 더하기인가 곱하기인가? |
| 슬레이 더 스파이어류: 적 의도 표시 | ★ | 무엇을 공개하고 무엇을 숨기는가? 의도 표시가 없다면 덱 빌딩 판단이 어떻게 바뀌는가? |
| 파이어 엠블렘류: 성장률 | ★★ | 레벨업마다 능력치별로 독립 판정하는가? 성장 결과가 나쁠 때의 보정이 있는가? 어떻게 확인할 수 있는가? |

## 경제·성장·라이브

| 주제 | 난이도 | 길잡이 질문 |
|---|---|---|
| 아무 가챠 게임: 천장(보장) 시스템 | ★★ | 천장 카운트는 언제 초기화되고 언제 이월되는가? 확률 상승 구간이 있다면 실제 기대 횟수는? 배너가 바뀔 때 카운트는? |
| 오토배틀러: 상점 레벨별 등급 확률과 이자 | ★★★ | 레벨업과 리롤과 저축 중 무엇을 하게 만드는가? 이자 구간 경계가 플레이어 행동을 어떻게 바꾸는가? ([예시](reverse-design-example.md)와 비교해 볼 것) |
| 뱀파이어 서바이버즈류: 레벨업 선택지와 진화 조건 | ★★ | 선택지 후보는 어떻게 추려지는가? 이미 최대 레벨인 항목은? 진화 조건이 선택을 어떻게 비트는가? |
| 스타듀 밸리류: 호감도 | ★ | 무엇으로 오르고, 자연 감소가 있는가? 하루 상한이 있는가? 그 상한이 플레이 리듬을 어떻게 만드는가? |
| 로그라이트 메타 진행(영구 강화) | ★★ | 실패한 런의 보상이 다음 런 난이도를 얼마나 깎는가? 처음 몇 시간과 수십 시간 후의 체감 차이는? |
| 아무 게임: 일일 퀘스트·출석 | ★ | 하루를 놓치면 무엇을 잃는가? 복귀 유저 보정이 있는가? 그 설계는 접속을 '습관'으로 만드나 '의무'로 만드나? |

## 변형 훈련 (같은 시스템, 다른 조건)

한 번 역기획한 시스템을 일주일 뒤 아래 조건 중 하나로 다시 쓴다. 바뀌는 칸이 곧 그 시스템의 핵심 변수다.

- **모바일로 옮긴다면?** 터치 입력과 짧은 세션 길이
- **협동 멀티라면?** 상태를 누가 소유하는가, 동시 판정은?
- **난이도 모드를 3개 만든다면?** 어떤 컬럼이 난이도별로 나뉘는가
- **내 프로젝트에 넣는다면?** 코어 루프의 어디에 붙고 무엇과 충돌하는가
