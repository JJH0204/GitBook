# 애니메이션 (Animation)

캐릭터 애니메이션 기법을 정리한 그룹이다. 문서 번호(Task ID)는 `GMD-GPP-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| GMD-GPP-002-DO | D&O + 예제 | [역운동학 (IK)](ik/README.md) 하위의 [역운동학 원리와 활용](ik/ikinversekinematics.md) | FK와 IK의 차이, Unity의 IK 구현 방법을 이해한다 |
| GMD-GPP-003-DO | D&O + 예제 | [\[생성형 AI\] Animator 컨트롤러 기초](animator-state-machine.md) | 상태, 전이, 파라미터, 블렌드 트리와 스크립트 연동을 이해한다 |

## 이 그룹의 범위

캐릭터를 움직이는 두 축을 다룬다.

| 축 | 설명 | 문서 |
|---|---|---|
| 상태 머신 | 클립을 언제 재생할지 정한다. 파라미터와 전이 조건으로 제어한다 | GMD-GPP-003-DO |
| IK | 손발의 목표 위치에 맞춰 관절 회전을 계산한다 | GMD-GPP-002-DO |

## 읽는 순서

1. GMD-GPP-003-DO로 Animator 컨트롤러의 구조를 익힌다.
2. GMD-GPP-002-DO로 클립만으로 맞출 수 없는 손발 위치 보정 방법을 본다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (Unity에서 실행하지 않았다) |
| 개정 | R1 (2026-11-19) |
