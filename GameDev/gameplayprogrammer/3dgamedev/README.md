# 3D 게임 개발

3D 그래픽스 기초 개념을 정리한 그룹이다. 문서 번호(Task ID)는 `GMD-GPP-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| GMD-GPP-001-DO | D&O | [3D 게임 그래픽스 기초](gamegraphics.md) | 좌표 공간, 셰이딩, 렌더링 파이프라인 용어를 이해한다 |

관련 수학은 [벡터 기초와 연산 (Vector)](../../gamemath/vector.md)를 본다.

## 이 그룹의 범위

3D 게임 화면이 만들어지는 과정(좌표 공간, 셰이딩, 렌더링 파이프라인)의 용어를 정리한다. 수학은 게임 수학 그룹, 셰이더 구현은 툰 셰이더 노트를 본다.

| 알고 싶은 것 | 볼 곳 |
|---|---|
| 로컬, 월드 좌표 변환 | [\[생성형 AI\] 좌표 변환과 행렬(TRS)](../../gamemath/transform-matrix.md) |
| 회전 표현 | [\[생성형 AI\] 쿼터니언과 회전](../../gamemath/quaternion.md) |
| 렌더링 파이프라인 한 바퀴 | [Day 13 · 렌더링 파이프라인 한 바퀴](../../unity-csharp/day13-rendering-pipeline.md) |
| 셰이더 직접 작성 | [툰 셰이더 공부 노트](../../toon-shader-study/README.md) |
