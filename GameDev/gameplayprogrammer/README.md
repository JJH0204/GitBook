# 게임플레이 프로그래밍

게임플레이 프로그래머가 알아야 할 3D 그래픽스, 애니메이션, 셰이더 노트를 모은 그룹이다. 문서 번호(Task ID)는 `GMD-GPP-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| GMD-GPP-001-DO | D&O | [3D 게임 그래픽스 기초](3dgamedev/gamegraphics.md) | 좌표 공간, 셰이딩, 렌더링 파이프라인 용어를 이해한다 |
| GMD-GPP-002-DO | D&O + 예제 | [역운동학 원리와 활용 (IK)](animation/ik/ikinversekinematics.md) | FK와 IK의 차이, Unity의 IK 구현 방법을 이해한다 |
| GMD-GPP-003-DO | D&O + 예제 | [\[생성형 AI\] Animator 컨트롤러 기초](animation/animator-state-machine.md) | 상태, 전이, 파라미터, 블렌드 트리와 스크립트 연동을 이해한다 |
| — | — | [셰이더 그래프 (Shader Graph)](shadergraph/README.md) | 셰이더 노트 (별도 카드에서 정리) |
