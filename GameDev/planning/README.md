# [생성형 AI] 게임 기획 (Planning)

게임 기획 아이디어를 모은 그룹이다. 문서 번호(Task ID)는 `GMD-PLN-<번호>-<유형>` 형식이다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 범위 | 그룹 안내와 기획 메모를 정리하는 구조 틀만 보강했다 |
| 확인 상태 | 미검증 (일반적인 기획 문서 구성이며 외부 사실을 검증하지 않았다) |

## 문서 목록

| 폴더 | 용도 |
|---|---|
| [게임 아이디어 (Ideas)](ideas/README.md) | 타이쿤, 하이퍼 캐주얼 게임 기획 메모 |

{% hint style="info" %}
NOTE: 이 그룹의 문서는 작성자의 창작 아이디어 메모다. 문서는 구조만 정리하고 내용은 새로 만들지 않았다. 빈 질문은 각 문서 끝의 "내 말로 채우기"에서 작성자가 직접 채운다.
{% endhint %}

## 읽는 순서

1. [게임 아이디어 (Ideas)](ideas/README.md)에서 메모 3건을 훑는다.
2. 기획서 형식으로 발전시킬 때는 [게임 기획 내실 훈련장 (Game Design Drills)](../game-design/README.md)의 템플릿을 쓴다.

## 아이디어를 기획으로 옮길 때 쓰는 구조 틀

아래는 내용이 아니라 항목 틀이다. 칸은 작성자가 직접 채운다.

| 항목 | 채울 내용 | 비고 |
|---|---|---|
| 한 줄 요약 | 이 게임이 무엇인지 한 문장 | 미정이면 비워 둔다 |
| 핵심 재미 | 플레이어가 반복하는 행동과 보상 | 비어 있으면 아직 아이디어 단계다 |
| 대상 플레이어 | 누가, 어떤 상황에서 하는가 | 근거 자료가 있으면 출처를 적는다 |
| 핵심 루프 | 행동, 결과, 보상, 다음 행동의 순환 | 한 줄 화살표로 쓴다 |
| 참고 게임 | 비슷한 게임과 다른 점 | 외부 게임 사실은 확인 후 적는다 |
| 범위와 위험 | 만들 수 있는 크기인가, 가장 불확실한 부분은 무엇인가 | 프로토타입으로 검증할 항목을 고른다 |
