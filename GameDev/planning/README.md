# 게임 기획 (Planning)

게임 기획 아이디어를 모은 그룹이다. 문서 번호(Task ID)는 `GMD-PLN-<번호>-<유형>` 형식이다.

## 문서 목록

| 폴더 | 용도 |
|---|---|
| [게임 아이디어 (Ideas)](ideas/README.md) | 타이쿤, 하이퍼 캐주얼 게임 기획 메모 |

{% hint style="info" %}
NOTE: 이 그룹의 문서는 작성자의 창작 아이디어 메모다. 문서는 구조만 정리하고 내용은 새로 만들지 않았다. 빈 질문은 각 문서 끝의 "내 말로 채우기"에서 작성자가 직접 채운다.
{% endhint %}
