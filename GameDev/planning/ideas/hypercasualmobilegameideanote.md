## 3. Idea 1: 단군 신화를 소재로 한 캐주얼 게임

### 3-1. 소재가 되는 이야기

| 순서 | 장면 | 내용 |
|---|---|---|
| 1 | 하늘에서 내려온 환웅 | 환인의 아들 환웅이 인간 세계를 다스리려 한다. 환인의 허락을 받고 태백산(백두산) 신단수 아래로 내려온다. 풍백, 우사, 운사를 거느리고 인간 세상을 다스린다 |
| 2 | 곰과 호랑이의 시험 | 곰과 호랑이가 사람이 되고 싶다고 요청한다. 환웅이 쑥과 마늘을 주며 100일 동안 햇빛을 보지 않고 그것만 먹으면 사람이 된다고 한다. 호랑이는 포기하고 곰은 버텨 여인(웅녀)이 된다 |
| 3 | 단군 왕검의 탄생 | 웅녀가 외로움에 환웅에게 기도한다. 환웅과 결혼해 아들 단군 왕검을 낳는다 |
| 4 | 단군의 통치와 퇴위 | 단군 왕검이 고조선을 세워 통치한다 |

### 3-2. 구상 A: 전투 요소를 넣은 각색

이야기를 각색해 전투 요소를 넣는 구상이다.

| 항목 | 내용 |
|---|---|
| 갈등 | 중도 포기한 호랑이(부족)가 질투해 전쟁을 일으킨다. 환웅의 선택을 받은 웅녀(곰 부족)가 호랑이 부족과 싸운다 |
| 주인공 | 곰 부족의 장군. 환웅의 호위를 맡는다 |
| 목표 | 태어날 아들(단군)을 맞이하기 위해, 웅녀가 숨은 은신처로 안전하게 이동하도록 호위한다 |

### 3-3. 구상 B: 서바이벌 게임

핵심 질문: 쑥과 마늘을 먹으며 100일을 버텨 사람이 되는 것을 주제로 게임을 만들 수 없을까?

| 항목 | 내용 |
|---|---|
| 목표 | 동굴에서 100일 생존한다 |
| 자원 | 배고픔 게이지를 관리한다. 쑥과 마늘을 찾아 먹는다 |
| 배치 | 쑥과 마늘은 게임 시작 시 동굴 안 랜덤 위치에 놓인다. 동굴을 탐험해 찾는다 |
| 환웅(NPC) | 목적지로 이동한다 |
| 적 | 환웅을 목표로 공격 가능한 범위까지 이동해 공격한다 (뱀파이어 서바이벌 류 방식) |
| 종료 조건 | 환웅의 체력이 0 이하, 또는 플레이어의 체력이 0 이하 |
| 체력 리필 | 플레이어 체력은 난이도에 따라 n회 리필된다. 환웅이 신의 아들이라 치유 능력이 있다는 설정이다 |
