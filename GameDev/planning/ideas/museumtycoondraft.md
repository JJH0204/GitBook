# 박물관 타이쿤 기획 초안

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | GMD-PLN-002-DO |
| 유형 | D&O (기획 초안) |
| 목적 | 던전 탐험으로 얻은 유물을 박물관에 전시·판매하는 게임 구상을 정리한다 |
| 확인 상태 | 미검증 (작성자의 구상 메모이며 외부 사실을 검증하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 목적

던전에서 유물을 얻고, 그것을 박물관에 전시해 수익을 내고, 수익으로 다시 탐험을 준비하는 순환 구조를 정한다.

## 2. 구성 요소

### 키워드

| 분류 | 키워드 |
|---|---|
| 핵심 | 채굴, 유물/광물, 박물관, 관리, 자본, 장비 |
| 참고 게임 | 리썰 컴퍼니(Lethal Company), 문라이터(Moonlighter). 참고한 점은 미정 |
| 미정 질문 | 채굴을 어떻게 할까, 과금 요소를 넣을까, 보물·박물관 관리를 어떻게 할까 |
| 기술 요소 | 절차적 생성을 활용한 던전 랜덤 생성 |

### 던전

| 항목 | 내용 |
|---|---|
| 입장 | 플레이어가 원하는 난이도의 던전을 선택해 입장한다 |
| 난이도 차이 | 나타나는 함정과 보물의 종류가 달라진다 |
| 공통 | 모든 난이도에서 절차적 생성으로 미로 형태의 던전이 만들어진다 |
| 반출 | 전리품은 입장할 때 통과한 문으로 돌아와야 반출할 수 있다. 랜덤 생성되는 히든 탈출 루트로도 탈출할 수 있다 |
| 요소 | 생존, 전리품 획득 |

### 박물관

| 항목 | 내용 |
|---|---|
| 전시 | 던전에서 얻은 전리품을 박물관에 전시한다 |
| 개장 | 전시 후 "개장"을 하면 손님을 받는다 |
| 손님 수 | 전시 보물의 희귀도(또는 임의의 값)로 정한다 |
| 콜렉터 | 일부 손님은 전시품을 사려는 콜렉터다. 제시 금액을 보고 흥정한다 |

### 관리 시스템 (자본 투자)

| 항목 | 내용 |
|---|---|
| 자본 사용처 | 다음 탐험의 아이템 구매, 플레이어 능력치 강화 |
| 감정 능력 | 강화하면 발견한 보물의 희귀도(또는 임의의 값)의 평균이 오른다 |
| 던전 선택 | 자본으로 입장할 던전을 정한다. 어렵고 희귀한 보물이 나오는 던전은 높은 자본을 입장 조건으로 요구한다 |
| 지역 UI | 실제 세계지도 기준으로 지역을 고르는 UI를 제공하면 좋겠다. 컨셉에 따라 지도 컨셉을 다르게 구성할 수 있다 |

## 3. 동작 원리

1. 전리품을 박물관에 전시한다.
2. 박물관을 개장해 손님을 받고 입장료를 얻는다.
3. 손님 중 콜렉터가 나타난다.
4. 콜렉터가 제시한 금액을 흥정해 보물을 판매한다.
5. 판매 금액과 관람료를 얻는다.
6. 얻은 자본을 장비·능력치·던전 입장에 투자하고 1번으로 돌아간다 (자본 획득, 반복).

## 4. 테마·마케팅 아이디어

놀이터 흙만 파도 유물이 나온다고 알려진 "경주"를 테마로 하는 구상이다.

| 번호 | 가설 | 상태 |
|---|---|---|
| 1 | 한국적인 요소가 해외에서도 통할 것이다 | 근거 없음, 검증 필요 |
| 2 | 공공 지원 사업의 지원을 받을 여지가 있다 | 지원 조건 확인 필요 |
| 3 | 경주를 테마로 한 경영 시뮬레이션이라는 점이 홍보 키워드가 된다 | 검증 필요 |
| 4 | 공공 지원을 활용하면 홍보·마케팅 자본을 줄일 수 있다 | 검증 필요 |
