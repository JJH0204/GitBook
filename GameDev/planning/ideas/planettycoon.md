| 확인 상태 | 미검증 (작성자의 구상 메모이며 외부 사실을 검증하지 않았다) |

## 1. 목적

우주, 물리, 과학을 좋아하는 작성자의 관심에서 나온 구상이다(전문가 수준은 아니다). 우리 은하를 넘어 전 우주를 직접 구축할 수 있다면 어떤 느낌일지가 출발 질문이다.

| 항목 | 내용 |
|---|---|
| 핵심 구성 비율 | 과학 65% / 창의성 35% |
| 참고 게임 | SpaceEngine (<https://store.steampowered.com/app/314650/SpaceEngine/>) |

## 2. 구성 요소

| 요소 | 내용 |
|---|---|
| 원소 | 우주에 직접 조합해 넣는 재료 |
| 환경 | 실제 우주와 유사한 물리 환경 설정 |
| 랜덤 시드 | 행성 형태를 정하는 값 중 하나 |
| 행성 | 질량과 크기는 물리 법칙으로 결정된다 |
| 서버 등록 | 학술에 등록되지 않은 새 행성은 첫 발견자가 원하는 이름으로 등록한다 |
| 사용자 간 공유 | 행성 레시피 공유, 행성 공유·거래 |
| 전시 | 나만의 별자리나 행성계를 만들어 전시한다 (배경화면 엔진처럼) |

## 3. 동작 원리

게임 순환 구조는 다음과 같다.

1. 원소를 조합해 우주에 넣는다.
2. 질량과 크기가 물리 법칙으로 결정된다.
3. 행성의 생애에 따라 소멸할 때 새 원소가 생성된다.
4. 새로 얻은 원소로 다시 행성을 만든다.

행성의 형태 = 투입한 원소 재료 + 설정한 환경 + 랜덤 시드 값.

### 차이점 메모

원본의 "차이점은?" 항목이다. 비교 대상이 불분명해 원문 그대로 둔다.

1. 이미 만들어진 알려진 행성(지구, 화성 등)이나 학술지에 등록된 행성을 여행하는 것이 주 목적이다. 우리는 잘 알려진 행성들을 표현한다.
2. 시뮬레이터이므로 프로그램이 무겁다.

배경화면 엔진 기능을 구현하려면 프로그램이 가벼워야 한다. 위 2번과 부딪히는 점은 해결 방법을 정하지 않았다.

## 4. 수익화 아이디어

| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 원소 패키지 판매 | 일반 환경에서 만들기 어려운 원소(높은 주기 원소, 인공원소)를 패키지로 판매한다 |
| 2 | DLC 우주 환경 프리셋 | 환경에 따라 만들 수 있는 행성이 달라지므로 확장팩처럼 판매한다 |
| 3 | 유저 간 거래 재화 | 행성을 사고팔 수 있게 하고, 거래 시스템 이용에 지정 재화 구매를 요구한다 |
| 4 | 확장 프로그램 구독 | 배경화면 엔진 같은 서브 프로그램의 라이선스나 편의 기능을 구독으로 판매한다 |
