## Excalidraw Data

### Text Elements (내용)

* 벡터(Vector)란 무엇일까?
* 방향(Direction)과 크기(Magnitude)를 가진 값
* 2D = (x, y)
  * x
  * y
* 3D = (x, y, z)
  * x
  * y
  * z
* 공간에서 객체의 위치를 나타낼때 쓰인다.
* 예:

```csharp
transform.position = new Vector3(1, 2, 3);
```

* 벡터로 속도를 계산할 수 있다.
  * 속도 벡터
  * 두 위치 간 차이를 시간으로 나눈 값
* 예: 속도 계산

```
속도 v = (Δ위치) / Δ시간
       = ((3, 3) - (1, 2)) / 1초
       = (2, 1) [단위: 유닛/초]
```

* 구성 요소:
  * x = 2
  * y = 1
  * (예시 위치값들: 3, 3, 1, 2 등)
* 초당 (2,1) 속도로 (2,1) 방향으로 이동
* 용어 정리:
  * 속도: 크기
  * 속력: 크기+방향
  * %혼용 금지%
* 이 벡터를 매초 더하면 실제 위치가 그만큼 변한다는 의미
* 이동 벡터
  * 구성 예시:
    * x = 2
    * y = 1
  * 이동 벡터 = 방향 벡터(속도) \* 이동 시간
  * 이동: 현재 위치 + 이동 벡터
* 예:

```
movement = (2, 1) * 1

transform.position + movement 
= (1, 2) + (2, 1)
= (3, 3)
```

* 정규화
  * 벡터의 방향 값은 유지, 크기 값을 1로 만드는 계산
  * 얼마만큼(속도)를 가지는지 상관없이 방향을 전환하려고 할때 유용
