## 1. 정의

베지어 곡선은 제어점 여러 개로 정의하는 부드러운 곡선이다. 곡선은 첫 점에서 시작해 마지막 점에서 끝나며, 중간 제어점은 곡선이 끌려가는 방향을 정한다. 매개변수 `t`(0~1)로 곡선 위의 점을 구한다.

## 2. 구성 요소

| 종류 | 제어점 | 식 (`u = 1 - t`) |
|---|---|---|
| 2차 | P0, P1, P2 | `u²·P0 + 2ut·P1 + t²·P2` |
| 3차 | P0, P1, P2, P3 | `u³·P0 + 3u²t·P1 + 3ut²·P2 + t³·P3` |

계산 예 (3차, P0 = (0,0), P1 = (0,2), P2 = (4,2), P3 = (4,0), Python으로 확인):

| t | 위치 |
|---|---|
| 0 | (0, 0) |
| 0.25 | (0.625, 1.125) |
| 0.5 | (2.0, 1.5) |
| 0.75 | (3.375, 1.125) |
| 1 | (4, 0) |

## 3. 동작 원리

### 3.1 선형 보간의 반복

2차 곡선은 `Lerp(Lerp(P0, P1, t), Lerp(P1, P2, t), t)`와 같다. 인접한 점끼리 `Lerp`를 반복하는 방식(De Casteljau 알고리즘)이다. 식을 외우지 않아도 `Lerp`만으로 구현할 수 있다.

### 3.2 Unity 구현

Unity에는 베지어 곡선을 계산하는 내장 함수가 없다. 아래 함수를 직접 만든다.

```csharp
public static Vector3 Bezier3(Vector3 p0, Vector3 p1, Vector3 p2, Vector3 p3, float t)
{
    float u = 1f - t;
    return u * u * u * p0
         + 3f * u * u * t * p1
         + 3f * u * t * t * p2
         + t * t * t * p3;
}
```

```csharp
// 곡선을 따라 이동
float t = Mathf.Clamp01(elapsed / duration);
transform.position = Bezier3(p0, p1, p2, p3, t);
```

### 3.3 성질

| 성질 | 내용 |
|---|---|
| 끝점 통과 | 곡선은 P0와 마지막 점을 지난다. 중간 제어점은 지나지 않는다 |
| 시작 방향 | 3차에서 `t = 0`의 접선은 `3(P1 - P0)` 방향이다 |
| 볼록 껍질 | 곡선은 제어점들이 이루는 볼록 도형 안에 있다 |
| 속도 | `t`를 일정하게 올려도 곡선 위 속도는 일정하지 않다 |

{% hint style="warning" %}
CAUTION: `t`를 일정하게 올리면 제어점이 가까운 구간에서 느리고 먼 구간에서 빠르게 움직인다. 일정한 속도가 필요하면 곡선을 여러 점으로 나눠 길이를 누적한 뒤 거리 기준으로 `t`를 정해야 한다.
{% endhint %}

### 3.4 쓰임새

| 용도 | 방법 |
|---|---|
| 던지기·유도 투사체 | 시작점, 높은 중간점, 목표점의 2차 곡선 |
| 카메라 연출 경로 | 3차 곡선 여러 개를 이어 붙인다 |
| 아이템 획득 연출 | 위로 솟았다가 플레이어로 모이는 곡선 |

곡선을 이어 붙일 때는 앞 곡선의 마지막 제어점과 끝점, 뒤 곡선의 첫 점과 첫 제어점이 한 직선 위에 있어야 꺾임이 없다.
