## 1. 정의

`Random.value`는 호출마다 서로 무관한 값이 나와 흔들림에 쓰면 떨린다. 노이즈(noise)는 입력 좌표가 조금 변하면 출력도 조금만 변하는 의사 난수 함수다. 같은 입력에는 항상 같은 값이 나온다.

## 2. 구성 요소

| 종류 | 만드는 방법 | Unity |
|---|---|---|
| 값 노이즈(value noise) | 정수 격자점에 난수를 두고 그 사이를 보간한다 | 직접 구현 |
| 퍼린 노이즈(Perlin noise) | 격자점에 기울기(방향)를 두고 보간한다 | `Mathf.PerlinNoise(x, y)` |

## 3. 동작 원리

### 3.1 1차원 값 노이즈 (Python으로 확인)

정수 `i`마다 해시로 0~1 값 `h(i)`를 정하고, 사이는 smoothstep으로 보간한다.

```
value(x) = lerp(h(floor(x)), h(floor(x)+1), smoothstep(frac(x)))
```

예: 격자값이 `h(0) = 0.2345`, `h(1) = 0.759`, `h(2) = 0.9187`일 때

| x | 0 | 0.5 | 1 | 1.5 | 2 |
|---|---|---|---|---|---|
| value | 0.2345 | 0.4967 | 0.759 | 0.8388 | 0.9187 |

`x = 0.5`에서는 smoothstep이 0.5라서 두 격자값의 평균이다. 격자점에서는 격자값을 그대로 지난다.

### 3.2 Mathf.PerlinNoise

```csharp
float seed = Random.Range(0f, 1000f);        // 실행마다 다른 패턴을 원할 때 오프셋으로 쓴다
float n = Mathf.PerlinNoise(Time.time * 0.5f + seed, 0f);   // 대략 0~1
float shakeX = (n - 0.5f) * 2f * amplitude;                 // -amplitude~amplitude
```

| 항목 | 내용 |
|---|---|
| 입력 | 실수 좌표 2개. 1차원 노이즈는 한 축을 고정한다 |
| 출력 | 대략 0~1. 경계를 약간 넘을 수 있으므로 필요하면 `Mathf.Clamp01`로 제한한다 |
| 변화 속도 | 입력에 곱하는 값(주파수). 클수록 빨리 변한다 |
| 반복 | 좌표 범위가 매우 크면 정밀도 문제가 있을 수 있다. 확인 필요 |

{% hint style="warning" %}
CAUTION: `Mathf.PerlinNoise`는 `Random.InitState`의 영향을 받지 않는다. 재현 가능한 패턴은 시드 오프셋을 직접 저장해 입력에 더한다. 정수 좌표에서의 값은 일정하게 나오는 경향이 있으므로 `x * 0.1f` 같은 소수 배율을 곱해 쓴다(정확한 값은 확인 필요).
{% endhint %}

### 3.3 쓰임새

| 용도 | 방법 |
|---|---|
| 카메라 흔들림 | 시간에 따른 1차원 노이즈를 `x`, `y`에 각각 사용한다 |
| 지형 높이 | 2차원 노이즈를 격자 좌표에 곱해 높이로 쓴다 |
| 자연스러운 AI 배회 | 노이즈 값을 방향 각도로 쓴다 |
| 옥타브 합성 | 주파수를 2배, 진폭을 절반으로 한 노이즈를 여러 겹 더해 세부를 만든다 |
