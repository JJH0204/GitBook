## 1. 정의

A*(에이스타)는 시작점에서 목표점까지 최단 경로를 찾는 탐색 알고리즘이다. 각 칸의 우선순위를 `f = g + h`로 정해 가장 작은 칸부터 확장한다. 휴리스틱 `h`가 실제 거리를 넘지 않으면(허용 가능) 최단 경로를 보장한다. 일반 알고리즘 설명은 Programming 스페이스에서 다룰 수 있으며, 이 문서는 게임 격자 맥락만 다룬다.

## 2. 구성 요소

| 기호 | 뜻 |
|---|---|
| `g` | 시작점에서 이 칸까지 지금까지 든 비용 |
| `h` | 이 칸에서 목표까지 남은 비용의 추정(휴리스틱) |
| `f` | `g + h`. 우선순위 |
| 열린 목록 | 확장 후보. `f`가 가장 작은 칸을 먼저 꺼낸다(우선순위 큐) |
| 닫힌 집합 | 이미 확장한 칸 |

| 이동 방식 | 휴리스틱 `h` |
|---|---|
| 상하좌우 4방향 | 맨해튼 거리 `|dx| + |dy|` |
| 8방향(대각선 비용 √2) | 옥타일 거리 `max(dx,dy) + (√2 - 1) · min(dx,dy)` |

## 3. 동작 원리

### 3.1 순서

1. 시작 칸을 열린 목록에 넣는다(`g = 0`).
2. `f`가 가장 작은 칸을 꺼내 닫힌 집합에 넣는다.
3. 꺼낸 칸이 목표이면 부모 칸을 따라 거슬러 올라가 경로를 만든다.
4. 이웃 칸(벽 제외)마다 `g`를 계산하고, 이전 기록보다 작으면 부모와 `g`를 갱신해 열린 목록에 넣는다.
5. 열린 목록이 비면 경로가 없다.

### 3.2 Python 검증 코드

```python
import heapq
grid = ["S..#....",
        ".#.#.##.",
        ".#...#..",
        ".####.#.",
        "......#G"]
H, W = len(grid), len(grid[0])
for y, r in enumerate(grid):
    for x, c in enumerate(r):
        if c == "S": s = (x, y)
        if c == "G": g = (x, y)

def astar():
    openq = [(0, 0, s)]; gs = {s: 0}; came = {}; closed = set()
    while openq:
        f, gc, c = heapq.heappop(openq)
        if c in closed: continue
        closed.add(c)
        if c == g:
            path = [c]
            while c in came: c = came[c]; path.append(c)
            return gc, path[::-1]
        for dx, dy in ((1,0), (-1,0), (0,1), (0,-1)):
            n = (c[0]+dx, c[1]+dy)
            if 0 <= n[0] < W and 0 <= n[1] < H and grid[n[1]][n[0]] != "#":
                ng = gc + 1
                if ng < gs.get(n, 1e9):
                    gs[n] = ng; came[n] = c
                    heapq.heappush(openq, (ng + abs(n[0]-g[0]) + abs(n[1]-g[1]), ng, n))
    return None
```

위 지도에서 실행한 결과는 최단 비용 15(경로 칸 수 16)이다. `h`를 0으로 둔 경우(다익스트라)도 같은 15를 얻었다. 이 작은 지도에서 확장한 칸 수는 A*가 26, `h = 0`이 27로 차이가 작았다. 지도가 크고 목표가 한쪽으로 치우칠수록 A*의 이점이 커지지만, 이 지도에서는 확인하지 않았다.

### 3.3 Unity 적용 시 고려

| 항목 | 내용 |
|---|---|
| 우선순위 큐 | Unity의 .NET 프로필에는 `PriorityQueue<T>`가 없는 버전이 많다. 버전 확인 필요. 없으면 이진 힙을 직접 구현하거나 `SortedSet`을 쓴다 |
| 격자 좌표 | 월드 좌표를 `Mathf.FloorToInt(pos / cellSize)`로 격자 인덱스로 바꾼다 |
| 대각선 이동 | 모서리를 끼고 벽을 통과하지 않도록 두 인접 칸이 모두 비었는지 확인한다 |
| 성능 | 매 프레임이 아니라 목표가 바뀔 때만 계산한다. 긴 계산은 여러 프레임에 나눈다 |
| 3D 지형 | 격자를 직접 만들기보다 `NavMesh`를 쓰는 것이 일반적이다 |
