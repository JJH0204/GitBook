## 1. 정의

목표가 움직이면 현재 위치를 겨냥한 탄은 빗나간다. 선행 조준(lead targeting)은 탄이 도착할 시점의 목표 위치를 예측해 겨냥한다. 탄 속도가 일정하고 목표가 등속 직선 운동한다고 가정하면 해석적으로 푼다.

## 2. 구성 요소

| 기호 | 뜻 |
|---|---|
| `p` | 발사자 기준 목표의 상대 위치 |
| `v` | 목표의 속도 벡터 |
| `s` | 탄의 속력(스칼라) |
| `t` | 명중까지의 시간(구할 값) |

## 3. 동작 원리

### 3.1 식

시간 `t`에 목표는 `p + v·t`에 있다. 탄이 `t` 동안 날아간 거리는 `s·t`다. 둘이 만나는 조건은 `|p + v·t| = s·t`이다. 양변을 제곱하면 `t`의 이차방정식이 된다.

```
(v·v - s²) t² + 2 (p·v) t + (p·p) = 0
a = v·v - s²,  b = 2 (p·v),  c = p·p
```

| 조건 | 해석 |
|---|---|
| 판별식 `b² - 4ac < 0` | 해가 없다. 맞힐 수 없다 |
| 해가 모두 0 이하 | 맞힐 수 없다(탄이 목표보다 느리고 멀어지는 경우) |
| 양수 해가 있다 | 그중 작은 값이 가장 빠른 명중 시간이다 |
| `a ≈ 0` | 이차방정식이 아니라 `t = -c / b`로 푼다 |

### 3.2 계산 예 (Python으로 확인)

| 입력 | 결과 |
|---|---|
| 목표 위치 `p = (10, 0)`, 속도 `v = (0, 3)`, 탄 속력 `s = 5` | `t = 2.5` 초 |
| 조준점 `p + v·t` | (10, 7.5) |
| 탄 이동 거리 `s·t` / 목표까지 거리 | 12.5 / 12.5 (일치) |
| 목표 `p = (10, 0)`, 속도 `v = (3, 0)`, 탄 속력 `s = 2` | 해 없음(목표가 더 빠르게 도망간다) |

### 3.3 Unity 구현 (2D 평면, `x`와 `y` 사용)

```csharp
public static bool TryIntercept(Vector2 p, Vector2 v, float s, out float t)
{
    t = 0f;
    float a = Vector2.Dot(v, v) - s * s;
    float b = 2f * Vector2.Dot(p, v);
    float c = Vector2.Dot(p, p);

    if (Mathf.Abs(a) < 1e-6f)
    {
        if (Mathf.Abs(b) < 1e-6f) return false;
        t = -c / b;
        return t > 0f;
    }

    float d = b * b - 4f * a * c;
    if (d < 0f) return false;

    float sq = Mathf.Sqrt(d);
    float t1 = (-b + sq) / (2f * a);
    float t2 = (-b - sq) / (2f * a);
    t = float.MaxValue;
    if (t1 > 0f) t = Mathf.Min(t, t1);
    if (t2 > 0f) t = Mathf.Min(t, t2);
    return t != float.MaxValue;
}

// 사용: Vector2 aim = targetPos + targetVel * t;
```

3D에서는 `Vector3`와 `Vector3.Dot`로 같은 식을 쓴다.

### 3.4 한계

| 한계 | 대응 |
|---|---|
| 목표가 가속·방향 전환을 한다 | 매 프레임 다시 계산하거나 오차를 허용한다 |
| 중력을 받는 탄 | 위 식은 직선 탄만 다룬다. 포물선 탄은 별도 식이 필요하다 |
| 목표 속도 얻기 | `Rigidbody.velocity`(Unity 6에서는 `linearVelocity`)를 쓴다. 버전 확인 필요 |

{% hint style="info" %}
NOTE: 플레이어가 맞히기 어려운 적을 만들려면 일부러 예측에 오차를 더하는 것이 게임 디자인상 일반적이다. 오차 크기는 기획에서 정한다.
{% endhint %}
