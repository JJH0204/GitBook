# 삼각함수 기초 (Trigonometry)

게임을 구현하면서 좌표계에서 물체의 움직임을 구현해야 하는 상황이 필수로 등장하는데\
이때 이미 구현되어 있는 상용 툴(rigidbody 등)을 이용하면 물론 구현은 빠르지만 의도한 움직임을 구현하기 쉽지 않다.\
그렇기에 이번 기회에 제대로 삼각함수에 대해서 이해하고 직접 예제 코드로 움직임을 구현할 수 있도록 연습하자.

삼각함수 기초

* 사인(Sin), 코사인(Cos), 탄젠트(Tan) 라고 불리는 세 함수를 "삼각함수"라 한다.
* 각 함수가 무엇을 의미하는지, 서로 어떤 관계를 갖는지 이해하자.

a

b

c

a = 높이\
b = 밑변\
c = 빗변

각도(∠)

위와 같은 직각삼각형을 기준으로 각도(∠)에 대한 각 함수의 계산 식은 아래와 같다.

cos(∠) = (인접변) / (빗변)

sin(∠) = (맞은편변) / (빗변)

tan(∠) = (맞은편변) / (인접변)

(위 식들을 그림의 a, b, c에 대응하여 이해)

예제 1: 계산 과정

(아래 삼각형을 정삼각형이라 가정)

* 60°
* 60°
* 60°

삼각형의 모든 각을 더하면 180°가 되며 정삼각형은 모든 각이 정확하게 180° / 3 = 60° 이다.\
그리고 모든 변의 길이는 3으로 동일하다.

{% step %}
### 정삼각형을 반으로 나누기

정삼각형을 이등분하면 직각삼각형 2개가 생긴다.

* 빗변 = 3
* 밑변 = 1.5 (정삼각형의 한 변을 반으로 나눔)
* 높이 = ??
{% endstep %}

{% step %}
### 높이를 피타고라스로 구하기

높이는 "피타고라스의 정리"를 통해 구할 수 있다.

* 빗변^2 = 높이^2 + 밑변^2
* 3^2 = h^2 + 1.5^2
* h = √(9 - 2.25) = √6.75 = 2.59807621
{% endstep %}

{% step %}
### 삼각함수 값 계산

직각삼각형에서:

* 맞은편 변 = 높이 = 2.59807621
* 인접변 = 밑변 = 1.5
* 빗변 = 3

따라서:

* sin(60°) = 2.59807621 / 3
* cos(60°) = 1.5 / 3
* tan(60°) = 2.59807621 / 1.5
{% endstep %}
{% endstepper %}

이 계산의 결과는 각도값에 고정되어 있다.

## 게임에서 삼각함수 활용

2차원 공간에서 물체의 곡선 움직임을 어떻게 구현할까?

\_startPosition = transform.position; ^0N3giyOF\
객체의 시작 위치를 저장

Update 메서드는 매 프레임마다 반복 호출된다.

public float amplitude; // 출렁임 높이\
public float frequency; // 출렁임 속도

{% code title="예시: Unity C# (Update 메서드)" %}
```csharp
private Vector2 _startPosition;

    private void Update()
    {
        // 시간에 따라 출렁임 계산
        var x = Time.time * frequency;

        var sin = Mathf.Sin(x);

        var yOffset = sin * amplitude;

        transform.position = _startPosition + Vector2.up * yOffset;
    }
```
