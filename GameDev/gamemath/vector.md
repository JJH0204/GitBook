## 1. 정의

벡터(Vector)는 방향(Direction)과 크기(Magnitude)를 가진 값이다. 2D는 (x, y), 3D는 (x, y, z)로 쓴다. 게임에서는 객체의 위치를 나타낼 때도 쓴다.

```csharp
transform.position = new Vector3(1, 2, 3);
```

{% hint style="info" %}
NOTE: 속도와 속력은 다르다. 속도(velocity)는 크기와 방향을 가진 벡터다. 속력(speed)은 크기만 가진 스칼라이며 속도 벡터의 길이다. 두 용어를 섞어 쓰지 않는다.
{% endhint %}

## 2. 구성 요소

| 연산 | 식 | Unity | 쓰임 |
|---|---|---|---|
| 크기(길이) | \|v\| = √(x² + y² + z²) | `v.magnitude` | 거리, 속력 |
| 크기의 제곱 | x² + y² + z² | `v.sqrMagnitude` | 거리 비교 (제곱근 계산을 아낀다) |
| 정규화 | v / \|v\| | `v.normalized`, `Vector3.Normalize(v)` | 방향만 필요할 때 |
| 두 점 사이 거리 | \|b − a\| | `Vector3.Distance(a, b)` | 사거리 판정 |
| 내적 | a·b = \|a\|\|b\|cos θ = axbx + ayby + azbz | `Vector3.Dot(a, b)` | 앞/뒤 판정(부호), 빛 세기(N·L), 사잇각 |
| 외적 | a × b (a, b 모두에 수직인 벡터) | `Vector3.Cross(a, b)` | 면의 법선, 왼쪽/오른쪽 판정 |
| 크기 제한 | 크기가 최댓값을 넘으면 방향을 유지한 채 줄인다 | `Vector3.ClampMagnitude(v, max)` | 이동 입력의 크기를 1 이하로 묶기 |

## 3. 동작 원리

### 3.1 속도와 이동

속도 벡터는 두 위치의 차이를 시간으로 나눈 값이다.

```
속도 v = (Δ위치) / Δ시간
       = ((3, 3) - (1, 2)) / 1초
       = (2, 1)   [단위: 유닛/초]
```

이 속도로 1초 이동하면 위치가 (2, 1)만큼 변한다. 이동 벡터는 속도 벡터에 이동 시간을 곱한 값이다. 새 위치는 현재 위치에 이동 벡터를 더한 값이다.

```
movement = (2, 1) * 1

transform.position + movement
= (1, 2) + (2, 1)
= (3, 3)
```

### 3.2 정규화

정규화는 벡터의 방향을 유지하고 크기를 1로 만드는 계산이다. 크기와 상관없이 방향만 필요할 때 쓴다.

{% hint style="info" %}
NOTE: 크기가 0인 벡터를 정규화하면 Unity는 오류 없이 `(0, 0, 0)`을 돌려준다. 방향이 정의되지 않으므로 0 벡터 여부를 따로 확인해야 하는 경우가 있다.
{% endhint %}

### 3.3 내적

* 부호가 양수면 두 방향이 같은 쪽이다(사잇각 90° 미만).
* 0이면 수직이다(90°).
* 음수면 반대쪽이다(90° 초과).
* 두 벡터가 모두 단위 벡터면 내적은 cos θ와 같다. 사잇각은 `Mathf.Acos(dot)`(라디안)로 구한다.

### 3.4 외적

* 외적의 크기는 두 벡터가 만드는 평행사변형의 넓이다.
* 외적의 방향은 좌표계 손잡이를 따른다. Unity는 왼손 좌표계다.
* 순서를 바꾸면 부호가 반대가 된다. `Vector3.Cross(a, b) = -Vector3.Cross(b, a)`이다.

### 3.5 대각선 이동 함정

입력 (1, 1)의 크기는 √2 ≈ 1.41이다. 그대로 이동에 쓰면 대각선 이동이 41% 빠르다. 이동 입력은 정규화하거나 `Vector3.ClampMagnitude`로 크기를 1 이하로 묶는다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 스칼라(Scalar) | 방향이 없는 크기만 가진 값 |
| 단위 벡터 | 크기가 1인 벡터 |
| 법선(Normal) | 면에 수직인 단위 벡터 |
| N·L | 법선과 빛 방향의 내적. 빛 세기 계산에 쓴다 |
