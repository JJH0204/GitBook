# 벡터 기초와 연산 (Vector)

* 벡터(Vector)란 무엇일까?
* 방향(Direction)과 크기(Magnitude)를 가진 값
* 2D = (x, y), 3D = (x, y, z)
* 공간에서 객체의 위치를 나타낼때 쓰인다.
* 예:

```csharp
transform.position = new Vector3(1, 2, 3);
```

* 벡터로 속도를 계산할 수 있다.
  * 속도 벡터 = 두 위치 간 차이를 시간으로 나눈 값
* 예: 속도 계산

```
속도 v = (Δ위치) / Δ시간
       = ((3, 3) - (1, 2)) / 1초
       = (2, 1) [단위: 유닛/초]
```

* 초당 (2, 1)만큼, 즉 (2, 1) 방향으로 이동한다.
* 용어 정리 (혼용 금지):
  * 속도(velocity): 크기 + 방향. 벡터다.
  * 속력(speed): 크기만. 속도 벡터의 길이(스칼라)다.
* 이 벡터를 매초 더하면 실제 위치가 그만큼 변한다는 의미
* 이동 벡터 = 속도 벡터 × 이동 시간
* 이동: 현재 위치 + 이동 벡터
* 예:

```
movement = (2, 1) * 1

transform.position + movement 
= (1, 2) + (2, 1)
= (3, 3)
```

* 정규화
  * 벡터의 방향은 유지하고 크기를 1로 만드는 계산
  * 크기와 상관없이 방향만 필요할 때 유용하다

## 연산 정리

| 연산 | 식 | Unity | 쓰임 |
|---|---|---|---|
| 크기(길이) | \|v\| = √(x² + y² + z²) | `v.magnitude` | 거리, 속력 |
| 크기의 제곱 | x² + y² + z² | `v.sqrMagnitude` | 거리 비교 (제곱근 계산을 아낀다) |
| 정규화 | v / \|v\| | `v.normalized` | 방향만 필요할 때 |
| 두 점 사이 거리 | \|b − a\| | `Vector3.Distance(a, b)` | 사거리 판정 |
| 내적 | a·b = \|a\|\|b\|cos θ = axbx + ayby + azbz | `Vector3.Dot(a, b)` | 앞/뒤 판정(부호), 빛 세기(N·L), 사잇각 |
| 외적 | a × b (a, b 모두에 수직인 벡터) | `Vector3.Cross(a, b)` | 면의 법선, 왼쪽/오른쪽 판정 |

* 내적 부호: 양수면 두 방향이 같은 쪽(90° 미만), 0이면 수직, 음수면 반대쪽이다.
* 외적의 크기는 두 벡터가 만드는 평행사변형의 넓이다. 방향은 좌표계 손잡이를 따른다 (Unity는 왼손 좌표계).
* 대각선 이동 함정: 입력 (1, 1)의 크기는 √2 ≈ 1.41이라 그대로 쓰면 대각선이 41% 빨라진다. 이동 입력은 정규화하거나 `Vector3.ClampMagnitude`로 크기를 1 이하로 묶는다.
