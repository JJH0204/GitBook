# 자체 호스팅 개발 서버 (forge)

팀의 코드 저장소와 이슈 트래커를 가정용 데스크톱 한 대에 직접 구축해 운영한 프로젝트의 기록이다. 코드는 Gitea, 이슈와 프로젝트 관리는 Plane, 자동화는 Gitea Actions로 구성했다. 인터넷에는 아무 포트도 열지 않고 VPN(Tailscale) 안에서만 접근하게 했다. 문서 번호(Task ID)는 `PRJ-FSH-<번호>-<유형>` 형식이다.

{% hint style="info" %}
NOTE: 공개 저장소에 올리는 글이라 서버 주소, 계정, 포트 배치, 비밀 경로, 네트워크 식별자, 백업 설정 세부는 모두 뺐다. 구조와 결정, 겪은 문제, 배운 점만 적었다.
{% endhint %}
