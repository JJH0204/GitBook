# 만트라 아웃라인 툰 셰이더 병합

## 1. 목적

마키나 프로젝트에서 툰 셰이더와 아웃라인 셰이더를 하나로 병합한 작업의 기록이다. 이 페이지의 Task ID는 `PRJ-MSH-001-DO`이다.

{% hint style="warning" %}
WARNING: 원본에는 제목과 한 줄("텍스처 쿠디네이트", 텍스처 좌표의 오타로 보인다)만 있었다. 아래 항목 중 "원본에 없음, 확인 필요"로 표시한 것은 기록이 없는 내용이며, 추측으로 채우지 않았다.
{% endhint %}

## 2. 구성 요소

| 구성 요소 | 내용 |
|---|---|
| 툰 셰이더 | 원본에 없음, 확인 필요. 개념은 [툰 셰이더 스터디 Day 07](../../../../GameDev/toon-shader-study/day07-toon-steps.md)(툰 램프, 단계 음영) 참조 |
| 아웃라인 셰이더 | 원본에 없음, 확인 필요. 인버티드 헐(역면, 법선 확장) 방식인지 후처리 방식인지 기록이 없다. 개념은 [툰 셰이더 스터디 Day 12](../../../../GameDev/toon-shader-study/day12-outline-inverted-hull.md), 구현은 [툰 셰이더 실습 Day 13](../../../../GameDev/toon-shader-lab/day13-outline-pass.md) 참조 |
| 병합 방식 | 원본에 없음, 확인 필요 |
| 렌더 파이프라인 | 원본에 없음, 확인 필요 (Built-in, URP 중 무엇인지 기록이 없다) |
| 코드 | 원본에 없음 |

## 3. 동작 원리

원본에 없음, 확인 필요. 원본에 남은 단서는 텍스처 좌표(UV)를 다루는 항목이 있었다는 점뿐이다. 병합 전 구조, 병합 후 구조, 겪은 문제는 기록이 없다.

## 4. 약어·용어

| 용어 | 설명 |
|---|---|
| 툰 램프 | 조명 값을 몇 단계로 끊어 만화풍 음영을 만드는 방식 |
| 인버티드 헐 | 정점을 법선 방향으로 부풀린 뒷면만 한 번 더 그려 외곽선을 만드는 방식 |
| UV | 텍스처 좌표 |

## 5. 확인 필요

- 병합한 두 셰이더의 원본과 병합 결과 구조
- 사용한 렌더 파이프라인과 Unity 버전
- 병합 중 겪은 문제와 해결 방법
- 이 페이지를 유지할지 삭제할지 (사전 진단 메모는 내용 부족으로 삭제를 제안했다)
