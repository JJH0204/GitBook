# 최적화 (Optimization)

Machina 프로젝트에서 최적화와 마무리 작업 중 겪은 문제를 기록한다. 문서 번호(Task ID)는 `PRJ-MOP-<번호>-<유형>` 형식이다. 모바일 최적화 조사 자체는 연구 개발 그룹의 [모바일 최적화 연구 개발 (R&D)](../rnd/mobileoptimizationrnd.md)에 있다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRJ-MOP-001-TS | 문제 해결 | [입력 시스템 에러 해결 (Input System)](inputsystem-error.md) | 오랜만에 연 프로젝트에서 Input System 컴파일 오류가 난 원인과 해결을 확인한다 |
