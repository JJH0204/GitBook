# 몬스터 공격 패턴 기획

| 항목 | 내용 |
|---|---|
| Task ID | PRJ-MAI-003-DO |
| 유형 | D&O (기획) |
| 목적 | 몬스터 유형별 행동, 바리에이션, 기획 근거를 정리한다 |
| 확인 상태 | 미검증 (기획 메모이며 구현 상태를 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 몬스터 유형

### 1.1 원거리 몬스터: 솔저

| 항목 | 내용 |
|---|---|
| 행동 | 탄 발사 1회, 밀치기, 특수 사격 |
| 바리에이션 | 특수 사격 때 탄 종류: 일반, 슬로우, 중력 발생 |

### 1.2 근접 몬스터: 덩치

| 항목 | 내용 |
|---|---|
| 행동 | 주먹 휘두르기, 바닥 내려치기, 버프 스킬 사용 |
| 바리에이션(버프 스킬 유무) | 아군 피해 감소(장갑 강화), 아군 공격력 또는 이동 속도 강화(오버로드) |

### 1.3 비행 몬스터: 리퍼

| 항목 | 내용 |
|---|---|
| 행동 | 할퀴기, 자폭 |
| 피격 시 | 리퍼에게 피해를 받으면 n 시간 동안 받는 피해가 증가하는 디버프를 받는다 |
| 자폭 조건 | 체력이 임계치 미만이 되면 타겟을 향해 돌진한다 |
| 자폭 결과 | 타겟의 히트박스에 닿으면 체력이 0이 되어 죽는다 |

## 2. 회피 기동 노드

몬스터 기준 좌(또는 우)로 이동해 플레이어의 조준을 피하는 노드다.

{% hint style="warning" %}
CAUTION: 노드와 명령어는 임시로 구현한 상태이며 테스트가 필요하다.
{% endhint %}

## 3. 처치 우선순위

플레이어가 먼저 처치해야 하는 순서를 다음 기준으로 정했다.

| 기준 | 순서 |
|---|---|
| 유형 | 공중형 > 근접형 > 원거리형 |
| 거리 | 가까운 적 > 먼 적 |
| 역할 | 플레이어에게 디버프를 주는 적 > 같은 몬스터에게 버프를 주는 적 > 플레이어를 공격하는 적 |

## 4. 기획 근거

### 4.1 리퍼의 자폭이 어색하지 않은가

- 자폭해도 문제가 없다는 의견이 있다.
- 플레이어는 멀리서 외형을 보고 특징을 판단해 플레이를 정한다. 외형이 자폭할 것 같지 않은 몬스터가 자폭하면, 첫인상이 중요한 첫 회차 플레이어는 나쁜 경험을 할 수 있다.

### 4.2 자폭 대신 줄 수 있는 기술

| 번호 | 역할 | 효과 |
|---|---|---|
| 1 | 직접 피해 | 플레이어 체력에 직접 피해를 준다 |
| 2 | 이동 제한 | 몬스터가 사격하는 경로로 이동이 제한된다. 몬스터가 보지 못하는 사각지대에서 접근하거나 더 먼 거리에서 처치해야 한다 |
| 3 | 방벽 | 큰 덩치로 플레이어 시야에서 원거리 몬스터를 가려 공략 난이도를 높인다 |
| 4 | 강제 이동 | 플레이어를 추적하며 근접 공격을 시도해 플레이어를 임의의 공간으로 이동시킨다 |
| 5 | 아군 강화 | 일부 근접 몬스터가 같은 몬스터에게 버프를 준다. 난이도를 낮추려면 이 몬스터를 먼저 처치해야 한다 |

### 4.3 공중 몬스터(돌진)

- 공중에서 플레이어를 추적해 공격하는 몬스터다.
- 대부분의 공중 개체는 바닥 지형의 영향을 받지 않는다. 장애물을 넘고 지상 공격을 받지 않는 이점이 있어, 공략법이 따로 필요하다.

공중 몬스터가 기존 플레이와 다른 경험을 주는 방법으로 다음 설정을 추가했다.

| 번호 | 설정 | 효과 |
|---|---|---|
| 1 | 기본 상태에서 반투명과 사라짐을 반복한다 | 이때는 플레이어 공격에 피해를 받지 않는다. 시각 차이와 공략 방식의 차이를 만든다 |
| 2 | 플레이어에게 다가가 공격할 때 불투명해진다 | 시각 대비를 강조하고, 이때부터 피해를 받는다 |
| 3 | 강한 공격(돌진)일수록 시전 준비 시간이 길다 | 플레이어가 공격할 수 있는 시간이 길어진다. 강한 무기나 주변 기물을 써서 피해를 극대화하려 하지만, 피해를 주는 데 너무 집중하면 큰 피해를 받는다 |

## 5. 몬스터 스테이터스 계산 흐름

원본에는 다이어그램 라벨만 남아 있다. 연결 관계는 알 수 없어 라벨을 묶음으로만 적는다.

| 묶음 | 라벨 |
|---|---|
| 스탯 | Base Stats, Current Stats, Total Stats |
| 영향 요소 | Buff |
| 시점 | 몬스터 스폰, 몬스터 사망, Pooling 시 Init |

버프 메모는 다음과 같다.

- 아이템은 버프 ID를 가진다.
- 버프(디버프)는 지속 시간형과 즉발형이 있고, 버프 타입을 가진다.
