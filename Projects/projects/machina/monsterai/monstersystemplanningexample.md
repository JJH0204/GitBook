# 몬스터 시스템 기획 예시

<details>

<summary>몬스터란?</summary>

* 플레이어를 공격하는 던전에 구성요소 중 하나

</details>

<details>

<summary>피해를 입히는</summary>

</details>

<details>

<summary>피해란?</summary>

플레이어의 00에 영향을 주는 것을 의미

* HP
* SP(스피릿 포스)
* MS(이동 속도)
* AS(공격 속도)
* 플레이어 시야(카메라)
* 컨트롤 방해
* 등등...

</details>

{

이것을 몬스터라고 정의하는 것이 옳은가?\
시스템에서는 몬스터라 정의하지 않아도 된다.\
몬스터가 아니라 "던전 바이옴"이라고 정의하자.

몬스터 말고도 플레이어를 방해하는 던전내 오브젝트들이 존재한다.

몬스터라 정의하지 않으면 장애물 등과 몬스터를 어떻게 하나의 단어로 정의하지?

던전 바이옴은 열거형 타입으로 관리된다.

1: 이동형(몬스터)\
2: 고정형(장애물)\
바이옴의 타입이 새롭게 생길때마다 값을 추가하면 된다.

{
