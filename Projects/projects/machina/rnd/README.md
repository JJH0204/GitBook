# 연구 개발 (R&D)

Machina 개발 중 조사하고 설계한 기록이다. 문서 번호(Task ID)는 `PRJ-MRD-<번호>-<유형>` 형식이다. 팀원 이름은 "팀원 A"처럼 역할로 적는다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRJ-MRD-001-DO | 개념 | [모바일 조작계 구현 (SimpleInput)](mobilecontrolwithsimpleinputsystem.md) | 모바일 입력에 SimpleInput을 쓴 방법을 확인한다 |
| PRJ-MRD-002-DO | 개념 | [던전 시스템 구현 (Dungeon)](dungeonsystemimplementation.md) | 던전, 스테이지, 웨이브 구조와 설계 질문을 확인한다 |
| PRJ-MRD-003-DO | 개념 | [모바일 최적화 연구 개발 (R&D)](mobileoptimizationrnd.md) | 모바일 최적화 방침과 씬 구조를 확인한다 |
| PRJ-MRD-004-MP | 절차 | [Addressables 설정과 씬 로드](addressablessetup.md) | Addressables를 설치하고 씬을 등록해 로드한다 |
| PRJ-MRD-005-TS | 문제 해결 | [모바일 최적화 적용 중 문제 기록](mobileoptimizationissues.md) | 적용 중 나온 문제와 처리를 확인한다 |
| PRJ-MRD-006-DO | 개념 | [맵 동적 로딩 시스템 설계](mapdynamicloadingsystemdesign.md) | 스테이지 씬을 앞뒤로 로드·언로드하는 설계를 확인한다 |
| PRJ-MRD-007-DO | 개념 | [UI 옵서버 패턴 (Observer)](observerpatternforui.md) | 대사 UI에 옵서버 패턴을 적용한 코드를 확인한다 |
