# 배교자 APOSTATE (가제)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | PRJ-APO-001-DO |
| 유형 | D&O (프로젝트 개요) |
| 목적 | 배교자(APOSTATE) 프로젝트의 방향, 설계 원칙, 리스크를 기록한다 |
| 확인 상태 | 미검증 (원본 기록을 정리한 것이며 레포와 Drive 자료의 내용은 이 문서에 반영하지 않았다) |
| 개정 | R2 (2026-11-18) |

탑다운 건카타 액션 하드 로그라이크를 목표로 기획 중인 프로젝트의 기록이다. 현재는 원페이지 기획서 단계(초안)다.

{% hint style="info" %}
아직 발표하지 않은 프로젝트라 시스템 수치, 밸런스 값, 세부 시나리오는 적지 않았다. 방향과 설계 원칙, 판단 기준만 남긴다.
{% endhint %}

## 개요

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 건카타 액션 하드 로그라이크 |
| 플랫폼 | PC (Steam) |
| 아트 | 풀 도트(픽셀 아트) |
| 톤 | 피폐, 종교적, 느와르 |
| 상태 | 원페이지 기획서 초안(기획 단계) |
| 내 역할 | 기획 정리와 설계 방향 검토 |
| 관련 자료 | GitHub 레포와 Drive 자료가 있다(작성자 확인). 레포 주소와 Drive 위치는 이 문서에 적지 않았다. 비공개 레포라면 접근 권한이 필요하다. 확인 필요 |

{% hint style="info" %}
NOTE: 작성자는 이 프로젝트를 "탄 전투 RPG"로도 설명한다. 이 문서의 장르 표기(탑다운 건카타 액션 하드 로그라이크)와 같은 프로젝트의 다른 표현인지, 레포 현황에 맞춰 상태(원페이지 기획서 초안)를 갱신해야 하는지는 확인이 필요하다.
{% endhint %}

## 설계에서 정한 것

- **핵심 갈등을 시스템으로 만든다.** 주인공이 힘을 빌릴수록 대가를 치르는 구조를 시스템(능력 사용 → 누적 대가 → 반발)으로 직접 구현해, 이야기와 플레이가 같은 방향을 가리키게 한다.
- **자극적인 소재는 권하지 않는 방식으로 그린다.** 소재를 보상이 아니라 덫으로 표현하고, 사용 효과가 끝나면 반드시 불이익이 따르게 한다. 심의 자료에도 이 의도를 밝히는 것을 전제로 한다.
- **하드 로그라이크 원칙을 먼저 고정한다.** 영구 사망, 절차 생성, 시드 공개, 예고 동작이 있는 공정한 공격, 빠른 재시작. 영구 강화는 두지 않는다.
- **제작 순서.** 아트 리소스를 만들기 전에 도형만으로 만든 프로토타입에서 전투가 재미있는지부터 확인한다.
- **수치는 가안으로 둔다.** 초기값은 프로토타입에서 조정할 값으로 표시하고 확정하지 않는다.

## 리스크 정리

- 실존 종교를 소재로 한 묘사는 심의와 지역별 판매에서 문제가 될 수 있다. 가상의 만신전을 쓰고 실존 종교 상징의 쓰임을 신중히 정하는 방향을 검토한다.
- 연령 등급이 높게 나오는 요소가 핵심 시스템에 있으면 등급 경로와 스팀 성인 콘텐츠 설정을 미리 확인해야 한다. 이때 배운 등급 점검 방식은 [등급분류와 표시 의무](../dormireve-launch/rating-and-compliance.md)에 있다.

## 배운 점

- 레퍼런스를 나열하는 데서 끝내지 않고 "무엇을 가져오고 무엇을 바꾸는가"를 표로 정리하면 설계 결정이 빨라진다.
- 설계 문서에 "확인할 점"을 따로 두면 법적, 심의 리스크를 초기에 드러낼 수 있다.
