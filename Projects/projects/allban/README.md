# Allban

***

#### 사용툴

* 피그마: UI/UX 디자인 초안 작성
* Gemini: 구현 계획 및 기획
* 안티그래비티: 소스 코드 구현
* 플러터: 윈도우, 안드로이드 앱 빌드 및 배포

#### 사용 언어

* React: 피그마 UI/UX 초안 디자인
* Dart: 플러터(윈도우, 안드로이드 앱) 개발
