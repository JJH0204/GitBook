## 피드백 1차

* 레시피 영역과 실시간 주문현황 탭을 페이지로 구분해서 화면을 효율적으로 사용할 수 있도록 개선 필요
* 연결된 디바이스(태블릿, 안드로이드)의 설정으로 특정 타입 값이 적용된 매뉴에 강조효과 추가: 음식과 음료를 동시에 처리해야 할 경우 함께 일하는 동료끼리 서로의 작업이 어느 정도 진행되었는지 바로 이해할 수 있도록
* 식음료 매장(알바생이 자주 바뀌는 환경)을 B2B 타겟으로 설정해도 좋겠다.
* 타이머 알람을 TTS로 테이블 번호와 매뉴 이름이 스피커로 출력되도록 기능 추가
* 시스템 설정으로 다크모드를 설정하거나 끌 수 있도록 기능 추가
* 실시간 주문현황에 열거되는 주문 리스트를 오래된 순서대로 정렬되도록(큐) 수정
* 이미지 동기화 문제가 있다. (기능적 오류 확인: 네트워크 문제인지 코드 문제인지 확인 필요)
* 레시피 상세 보기 버튼 클릭 시 매뉴 이미지와 함께 레시피가 출력되도록 수정\
  (굳이 매뉴 리스트에 이미지를 출력할 필요가 없다)
