# 대시보드 실시간 로깅 및 가시성 개선

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | PRJ-ALB-006-DO |
| 유형 | D&O (설계 회고) |
| 목적 | 백그라운드 스니퍼의 상태를 볼 수 있게 만든 3단계 로깅 구조와 도입 계기를 설명한다 |
| 확인 상태 | 미검증 (원본 기록을 정리한 것이며 이 환경에서 실행하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 배경과 문제

파이썬 스니퍼가 백그라운드(Windows 서비스 또는 자식 프로세스)에서 돌면서, 패킷을 못 잡는 것인지, 코드가 죽은 것인지, 권한 문제인지 대시보드만으로는 알 수 없었다. 터미널, 텍스트 파일, 실시간 UI 로그를 연결해 어디서든 에러의 흔적을 찾게 설계했다.

## 2. 구성 요소

| 단계 | 방식 | 구현 | 가치 |
|---|---|---|---|
| 1. 실시간 터미널·표준 출력 | 파이썬을 `-u`(Unbuffered) 옵션으로 실행해 즉시 출력하고, Dart가 실시간으로 받는다 | Dart에서 `LineSplitter`를 써 바이너리 데이터가 섞여도 로그 문장이 깨지지 않게 한다 | 개발 중 즉시 피드백을 받는 가장 빠른 로깅 |
| 2. 로컬 텍스트 파일 | 파이썬과 Dart 서버 양쪽에서 `sniffer.log`, `server.log`에 시간순으로 기록한다 | Python은 `logging` 모듈의 `FileHandler`. Dart는 `logFile.writeAsStringSync(..., mode: FileMode.append)` | 대시보드를 껐거나 서버가 크래시했을 때 사후 분석(Post-mortem)을 하는 가장 확실한 기록 |
| 3. 대시보드 UI | 서버 관리자 화면에 로그 창을 두고 중요도(`[INFO]`, `[DEBUG]`, `[ERROR]`)별로 색을 구분한다 | 웹소켓 또는 내부 스트림으로 UI 위젯에 로그를 전달한다 | 현장 관리자가 정상 동작 여부를 한눈에 확인하는 UX의 핵심 |

## 3. 동작 원리

1. 스니퍼가 이벤트를 표준 출력과 `sniffer.log`에 동시에 남긴다.
2. Dart 서버가 표준 출력을 줄 단위로 받아 `server.log`와 대시보드 로그 창에 전달한다.
3. 장애가 나면 터미널 → 텍스트 파일 → 대시보드 순으로 흔적을 찾는다.

## 4. 로깅 개선의 결정적 사례

| 사례 | 증상 | 확인 과정 | 결론·조치 |
|---|---|---|---|
| 스니퍼 무반응 | 터미널 로그에는 "Sniffer Started"만 찍혔다 | 텍스트 파일 로그에서 `TsharkNotFound` 에러가 수백 번 찍힌 것을 발견했다 | 시스템 환경 변수(Path) 문제로 확인했다 |
| CPU 100% 점유 | 서버를 종료해도 CPU 사용률이 높았다 | 서버 종료 시 로그에 "Process Exit Code: null"이 찍힌 것을 보고 자식 프로세스가 정상 종료되지 않았다고 판단했다 | `taskkill /T` 명령을 도입했다. 상세는 [프로세스 통합 및 생명주기 관리 (Dart-Python)](dart-python.md)(PRJ-ALB-011-DO) 참조 |

## 5. 로깅 원칙

> 로깅은 단순히 `print`를 찍는 것이 아니라 "나중에 내가 이 코드를 모를 때 나에게 보내는 구조 신호"다.

| 번호 | 원칙 | 기준 |
|---|---|---|
| 1 | 시간(Timestamp) | 모든 로그에 밀리초 단위까지 시간을 기록한다 |
| 2 | 문맥(Context) | 에러 메시지와 함께 에러 발생 당시의 변수 값(예: `adapterGuid`)을 남긴다 |
| 3 | 구분(Leveling) | 불필요한 정보는 `DEBUG`, 시스템 장애는 `ERROR`로 구분해 로그 오염을 막는다 |

## 6. 약어·용어

| 용어 | 뜻 |
|---|---|
| Unbuffered(`-u`) | 파이썬 출력 버퍼를 끄고 즉시 내보내는 옵션 |
| Post-mortem | 장애 후 기록을 보고 원인을 분석하는 일 |
| `LineSplitter` | Dart에서 스트림을 줄 단위로 나누는 변환기 |
