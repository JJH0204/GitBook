# 임베디드 파이썬 환경 구축 (Python)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | PRJ-ALB-010-DO |
| 유형 | D&O (설계 회고) |
| 목적 | 파이썬이 없는 PC에서도 스니퍼가 동작하도록 임베디드 파이썬을 쓴 이유와 설정을 설명한다 |
| 적용 환경 | Windows, 파이썬 3.11(원본 예시), 의존성 `pyshark`, `requests` |
| 확인 상태 | 미검증 (원본 기록을 정리한 것이며 이 환경에서 실행하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 배경: 가상 환경(venv)의 한계

초기에는 `python -m venv`로 가상 환경을 만들어 의존성(`pyshark`, `requests`)을 관리했다.

| 문제 | 내용 |
|---|---|
| 배포 오버헤드 | 설치 대상 PC에 파이썬이 반드시 있어야 하고, 버전 불일치와 환경 변수(Path) 충돌 위험이 있다 |
| 사용자 부담 | "파이썬을 먼저 설치해 주세요"라는 요구는 주방 현장의 사용성을 크게 해친다 |
| 권한 이슈 | Windows 실행 정책(Execution Policy) 때문에 `activate.ps1` 실행이 막혀 초기 런타임 구성이 불안정하다 |

## 2. 구성 요소

파이썬을 시스템에 설치하지 않고, 프로그램 폴더 안에 전용 파이썬 엔진(임베디드 파이썬)을 넣는 방식을 택했다.

| 이점 | 내용 |
|---|---|
| Zero-Dependency | 사용자 PC의 파이썬 설치 여부와 관계없이 바로 실행된다 |
| 버전 격리 | 개발 때 검증한 특정 버전(3.11 등)을 그대로 배포해 "내 컴퓨터에서는 되는데 사용자 PC에서는 안 되는" 현상을 막는다 |
| 포터블 구조 | 폴더 복사만으로 실행 준비가 끝나 Inno Setup 패키징과 배포가 단순해진다 |

## 3. 핵심 설정

임베디드 파이썬은 보안 때문에 외부 라이브러리 참조가 막힌 최소 환경이다. 아래 세 가지를 조정했다.

| 번호 | 문제 | 해결 |
|---|---|---|
| 1 | 임베디드 엔진은 현재 폴더 밖의 라이브러리를 무시한다 | `python311._pth` 파일에서 `#import site` 주석을 제거한다. `Lib/site-packages`에 설치한 `pyshark` 등을 엔진이 읽는다 |
| 2 | 배포 후 설치 경로가 사용자마다 달라 상대 경로가 깨진다 | Dart 서버 코드에서 `Platform.resolvedExecutable`로 실행 파일의 실제 위치를 찾고, 그 아래 `python_runtime/python.exe`를 절대 경로로 호출하게 고친다 |
| 3 | 파이썬 로그가 Dart 대시보드에 실시간으로 안 나오고 종료 때 한꺼번에 나온다 | 파이썬 실행 옵션에 `-u`(Unbuffered)를 추가한다. 상세는 [스니퍼 실시간 출력 지연 해결](mysql/realtime-output-delay.md)(PRJ-ALB-009-TS) 참조 |

## 4. 배포 시나리오와 결과

1. 사용자가 `Allben_Setup.exe` 하나를 실행한다.
2. 설치 프로그램이 임베디드 파이썬과 에셋을 프로그램 폴더에 배치한다.
3. 파이썬을 설치하지 않고도 실시간 MySQL 패킷 스니핑이 동작한다.

모든 의존성 패키지가 한 폴더 안에 있어, 업데이트할 때 그 폴더만 교체하면 된다.

{% hint style="info" %}
NOTE: 배포 폴더 이름이 문서마다 다르다. 이 문서는 `python_runtime/python.exe`, [인스톨러 구축 및 배포 자동화 (Inno Setup)](inno-setup/README.md)(PRJ-ALB-012-REF)는 `python_runtime\`과 `python_assets\`, [스니퍼 실시간 출력 지연 해결](mysql/realtime-output-delay.md)의 코드는 `python_assets/python/python.exe`를 쓴다. 최종 구조는 확인이 필요하다. 설치 파일 이름 `Allben_Setup.exe`의 표기(Allben/Allban)도 확인이 필요하다.
{% endhint %}

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| venv | 파이썬 가상 환경 |
| Embeddable Python | 설치 없이 폴더에 풀어 쓰는 최소 파이썬 배포판 |
| `._pth` | 임베디드 파이썬의 모듈 검색 경로 설정 파일 |
| site-packages | 외부 패키지가 설치되는 폴더 |
| Execution Policy | PowerShell 스크립트 실행을 제한하는 Windows 정책 |
