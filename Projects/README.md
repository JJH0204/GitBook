# Welcome

여기는 작업 노트와 산출물을 모아두는 공간이야.

문서는 **프로젝트 진행상황** 기준으로 읽기 쉽게 정리했어. 보통 `계획 → 진행 → 결과/회고` 순서로 쌓여.

### 시작하기

1. 먼저 프로젝트를 고른다.
   * [Projects](/broken/spaces/waq6pKVMPSycfPHCcfCb/pages/XiU1YTRjpgjjZzhDojQ6)
2. 프로젝트 안에서 진행 단계에 맞는 문서를 찾는다.
   * 계획: 범위/목표/스펙/이슈 정리
   * 진행: 작업 로그, 의사결정, 실험 기록
   * 결과: 정리, 회고, 다음 액션
