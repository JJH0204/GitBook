# Maiden Dormireve 출시 준비와 마케팅

팀 프로젝트 Maiden Dormireve(히로인 중심 서브컬처 액션)의 스팀 출시 준비와 마케팅을 하며 정리한 기록이다. 문서에는 "무엇을 했고 무엇을 배웠는가"만 남긴다.

{% hint style="info" %}
아직 공개되지 않은 일정, 목표 수치, 금액, 가격, 계약과 정산 조건, 팀원 이름은 적지 않았다. 외부에 공개된 사실과 일반화한 교훈만 다룬다.
{% endhint %}

## 내 역할

기획 문서 정리와 운영 계획 작성, 스팀 상점 페이지와 디스코드 서버 설정, 홍보 전략 자료 조사를 맡았다.

## 전체에서 배운 것

- **포지셔닝을 먼저 정한다.** 같은 게임도 "슈터"로 팔 때와 "히로인 중심 서브컬처 액션"으로 팔 때 첫 화면, 채널, 후원 구조가 다 달라진다.
- **측정할 수 있게 만든 뒤에 올린다.** 링크에 UTM을 붙이지 않고 올린 게시물은 나중에 성과를 알 수 없다.
- **일정은 의존 관계로 본다.** 데모 빌드 승인이 상점, 펀딩, 커뮤니티 공지의 앞단이다. 한 곳이 밀리면 연쇄로 밀리므로 지연 시 대응을 미리 적어 둔다.
- **되돌릴 수 있게 설정한다.** 서버와 상점 설정은 이전 상태로 돌리는 방법을 문서에 같이 적었다.
