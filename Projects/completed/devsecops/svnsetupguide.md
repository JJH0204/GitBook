## 5. 절차

### A. SmartSVN 설치

1. (5-A-01) 설치 파일의 압축을 푼다.
2. (5-A-02) 실행 파일을 실행한다. → 결과: 설치 마법사가 열린다.
3. (5-A-03) 설치 화면에서 `Next`를 누른다. 설정은 기본값을 그대로 둔다.
4. (5-A-04) 라이선스 화면에서 맨 위 체크박스만 켜고 `Next`를 누른다. 무료 라이선스를 사용하므로 이 항목에 동의해도 된다.
5. (5-A-05) `OK`를 누른다. → 결과: SVN 서버와 연결하는 화면이 열린다.

### B. 서버 연결과 저장소 내려받기

1. (5-B-01) 서버 주소에 `svn://<SVN 서버 주소>/<저장소 이름>`을 입력하고 `Next`를 누른다.
2. (5-B-02) 관리자에게 받은 아이디와 비밀번호를 입력한다.
3. (5-B-03) 로그인 상태를 유지하려면 `Save password`를 켠다. 켜지 않으면 PC를 껐다 켤 때마다 다시 로그인해야 한다.
4. (5-B-04) `Next`를 누른다.
5. (5-B-05) `Check Out`을 누른다. → 결과: 서버 데이터를 받을 폴더를 고르는 화면이 열린다.
6. (5-B-06) 받을 로컬 폴더 경로를 선택한다.
7. (5-B-07) 내려받기가 끝날 때까지 기다린다. → 결과: 폴더와 파일에 초록색 체크 아이콘이 표시된다.

## 6. 기능 확인

|---|---|---|---|

## 7. 복구

1. (7-01) 내려받은 로컬 폴더를 삭제한다. 서버의 데이터는 지워지지 않는다.
2. (7-02) 저장한 비밀번호를 지우려면 SmartSVN의 저장 인증 정보를 삭제한다. 정확한 메뉴 위치는 원본에 없음, 확인 필요.
