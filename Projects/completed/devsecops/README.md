# 데브섹옵스 (DevSecOps)

DevSecOps 팀 프로젝트의 기록을 모은 그룹이다. 문서 번호(Task ID)는 `PRJ-DSO-<번호>-<유형>` 형식이다. 하위 그룹 노바 프로젝트는 [노바 프로젝트 (Nova)](nova/README.md)에 있다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| PRJ-DSO-001-DO | 개념 | [데브섹옵스 해킹대회 (DevSecOps)](devsecopshackingcompetition.md) | 의도된 취약점을 가진 웹 서비스 기획과 인프라 구상을 확인한다 |
| PRJ-DSO-002-REF | 표 | [Aurora 앱 구조 (Aurora)](auroraappstructure.md) | 프로젝트 구조, Docker 구성, 요청 흐름을 확인한다 |
| PRJ-DSO-003-DO | 개념 | [데브섹옵스 실무 세미나 (DevSecOps)](devsecopsengineerseminar.md) | 세미나에서 기록한 진로·직무 조언을 확인한다 |
| PRJ-DSO-004-REF | 표 | [데브옵스 환경 구성도 (DevOps)](devopsenvsetup.md) | 협업·빌드 자동화 환경 구성도를 확인한다 |
| PRJ-DSO-005-MP | 절차 | [SVN 설치 가이드 (SVN)](svnsetupguide.md) | SmartSVN 클라이언트를 설치하고 저장소를 내려받는다 |
| PRJ-DSO-006-DO | 개념 | [프로젝트 시나리오 (DevSecOps)](projectscenario.md) | 가상 외주 시나리오와 팀 역할 구성을 확인한다 |

## 읽는 순서

1. PRJ-DSO-006-DO로 시나리오와 팀 구성을 본다.
2. PRJ-DSO-001-DO와 PRJ-DSO-002-REF로 실습 대상 웹 서비스를 본다.
3. 노바 프로젝트 문서로 CI/CD와 인프라 구상을 본다.
