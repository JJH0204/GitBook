DevOps 분야는 신입을 뽑는 경우가 잘 없고 대부분 서버 개발자가 DevOps 직종으로 전향해서 일을 하는 경우가 많음.\
-> 협업 과정에서 서버에 대한 이해가 많이 필요하다고 판단된다.

나는 DevOps 직무에 적합할까?

* 적합하다는 것을 어떻게 정의하면 될까?
  * 잘할 수 있는지 / 무엇을 잘하는지 / 무엇을 못하는지 / 요구사항을 충족하는지를 판단해보자

DevOps 직무가 요구하는 능력

{% stepper %}
{% step %}
### 서버/네트워크 개념 이해 및 구축 능력

대다수의 DevOps 엔지니어는 서버 개발자 출신이기에 신입의 경우 서버 개발 지식을 대략적으로 이해하고 실제 구현 가능해야 함.
{% endstep %}

{% step %}
### 문제해결 능력

거의 모든 직종에 해당할 수 있지만, 대다수의 업무가 서버 개발과 연계되어 있다 보니 알고리즘 문제(코딩 테스트)를 해결할 수 있는 능력이 필요함.
{% endstep %}

{% step %}
### 서비스 개발 프로세스 이해도

DevOps 프로세스의 콘텐츠 개발 라이프사이클에 의해 직접 개발에 참여하지 않아도 개발과 운영 단계에서 일어날 수 있는 문제들에 대해 이해가 되어 있어야 업무 진행이 수월해짐.\
어떤 서비스인지도 중요함. 많은 소프트웨어 개발 회사가 앱 또는 웹을 개발하기 때문에 대부분의 DevOps 엔지니어는 Back-end 개발 소양을 키우는 추세임.\
게임과 같이 일반적인 웹/앱 개발과 다른 기술 스택을 요구하는 상황에서는 어떤 개발 소양을 참고하면 좋을지 확신하지 못함(참고 자료가 적음).
{% endstep %}
{% endstepper %}

나는 능력은 무엇일까?

{% stepper %}
{% step %}
### 게임 기획 업무로 얻은 자료 조사 및 분석 능력

어떤 개발 관련 업무를 하더라도 모든 서비스와 기능들을 암기하고 업무에 투입되지는 않음. 준비 과정에서 양질의 정보를 찾고 학습하는 과정이 필수임.\
기획을 하며 여러 분야의 전문가와 협업한 경험은 학습(이해)능력을 길러주었고, 얕고 넓은 지식 풀을 갖게 해줌.\
논리적으로 이해되지 않으면 자료(레퍼런스)를 찾아 이해될 때까지 탐구하는 습관이 있어 부족한 부분을 빠르게 채울 수 있음.
{% endstep %}

{% step %}
### 소프트웨어 개발 능력

기획 업무를 통해 어깨너머로 배운 게임 시스템 이해도 + 직접 프로젝트를 하면서 얻은 경험을 통해 간단한 응용 프로그램을 python, C++, C#으로 구현 가능.\
국비 수업 과제를 통해 프론트엔드 개발 능력과 서버 구축 능력을 습득함.\
시간 제약이 없다는 가정 하에 어떤 서비스든 구현이 가능하다는 자신감(생성형 AI + 구글링 기반).
{% endstep %}

{% step %}
### 습관적인 기록

기록하는 습관 덕분에 배운 것을 잊지 않음. 기록을 기반으로 정돈된 문어체(Word), 수식(Excel), 이미지 기반(PowerPoint) 등으로 문서화 가능.
{% endstep %}

{% step %}
### 말 솜씨

웅변 경험으로 인해 공개 발표나 협업 시 떨지 않음. 정리된 구어체로 대화 진행 가능(단점: 주변에서 재미없다는 평가를 받기도 함).
{% endstep %}
{% endstepper %}

나는 왜 DevOps 직무를 수행해야 할까?

{% stepper %}
{% step %}
### 직업적 선호도

어릴 적부터 기능을 설계·구현·구축하는 것에 관심이 많았음. 게임은 그 목표를 위해 설정한 수단 중 하나일 뿐이며, 게임이 아니더라도 무언가를 만들고 배포하고 서비스하는 일을 하며 살고 싶음.
{% endstep %}

{% step %}
### 게임 개발 관련 경험

게임 개발과 관련된 경험이 있어, 게임 회사(예: 이스트게임즈)의 DevOps 직무에 지원할 경우 업무 프로세스에 적응하는 데 큰 무리가 없을 것이라 판단함.
{% endstep %}
{% endstepper %}

질문(FAQ — 펼쳐보기)

<details>

<summary>이스트게임즈에 지원하는 타당한 이유? 감정적 호소가 필요할까?</summary>

지원 동기는 회사의 미션/가치와 본인의 목표(지원 동기 + 포부)를 연결해 감정적 요소 없이 논리적으로 표현하는 것이 바람직함. 회사가 추구하는 가치와 본인의 목표가 일치함을 보여주는 서사가 필요함.

</details>

<details>

<summary>감정적인 호소 없이 잘 표현할 수 있을까?</summary>

네. 감정 표현은 최소화하고, 구체적인 경험과 성과, 회사와의 가치 정렬(지원 동기 + 포부)을 중심으로 서술하면 됩니다.

</details>

<details>

<summary>미래에 퇴사할 것이라는 암시로 받아들여질까?</summary>

장기 목표로서 ‘자신만의 서비스 운영’ 등 미래 계획을 언급할 때는 회사에 기여할 의지와 해당 경험이 회사에 어떻게 긍정적으로 환원될지를 함께 제시하면 퇴사 의도로 오해받을 가능성을 줄일 수 있음.

</details>

<details>

<summary>DevOps와 더 직접적으로 연관된 기술이 부족하다. 문제는 없을까?</summary>

초기엔 부족할 수 있으나, 학습 능력(자료 조사·분석), 소프트웨어 개발 능력, 기록 습관 등은 빠르게 기술을 보완할 수 있는 강점임. 포지션 요구사항과 본인의 경험을 연결해 보완 계획(학습 로드맵)을 제시하면 문제를 완화할 수 있음.

</details>

DevOps 직무를 수행하면서 이루고 싶은 성취

{% stepper %}
{% step %}
### 장기 목표

먼 미래에 나만의 서비스를 운영하는 것을 목표로 함. 개발 프로세스의 A to Z에 관여하는 것을 목표로 하여 기술 스택을 쌓고 있으며, 긴 시간 동안 작은 목표들을 설정해 차근차근 달성할 계획임.
{% endstep %}

{% step %}
### 단기 목표

현재 고졸 상태로 인한 열등감이 있음. 취직하면 고졸 연봉 테이블이 적용될 것으로 예상되므로, 내년 또는 내후년의 연봉협상에서 대졸 학사 연봉 테이블을 적용받도록 할 것임.\
단, 일을 소홀히 하지 않고, 학사 학위와 동일 연차 대비 회사 내에서 최고의 대우를 받을 수 있도록 역량을 키울 계획임.
{% endstep %}
{% endstepper %}

1차 피드백

* 감정 100% out
* 수미상관 스토리텔링
* 지원동기 + 포부(목표) = 회사의 가치관과 유사함을 강조
* 부수적 능력(예: PM/기획적 성과)은 협업·커뮤니케이션 능력 강조 관점에서 정리
