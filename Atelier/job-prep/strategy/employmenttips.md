### 자기소개서: 항목별 포인트

* 지원동기 — 회사 관심도 : 회사의 인제상, 경험, 적성
* 성장과정 — IT 기술 역량 : 팀 프로젝트 소재 적극 활용, 문제해결 능력 위주 설명 권장
* 성격의 장단점 — 개발 관련 인성 : 예시 — "저는 결과 지향적으로 업무를 진행합니다. 과정이 어떻게 되든 무조건 목표하는 결과 이상의 업무 효율을..."
* 성장 가능성 : 회사 비전/인제상, 상세하게 기술하면 좋음
* 포트폴리오 경험 : 이슈 발생/해결 과정을 위주로 작성

### 두괄식 표현 설명

두괄식 표현은 핵심 내용을 가장 먼저 제시한 뒤, 이를 뒷받침하는 설명이나 세부 내용을 나열하는 방식입니다.\
간단한 예시:

* 두괄식 표현: “이 제품은 품질이 뛰어납니다. 그 이유는 고급 재료를 사용했고, 철저한 품질 관리를 거쳤기 때문입니다.”
  * (핵심: 품질이 뛰어나다 → 이유: 재료와 품질 관리)
* 미괄식 표현: “이 제품은 고급 재료를 사용하고 철저한 품질 관리를 거쳤습니다. 그래서 품질이 뛰어납니다.”
  * (이유: 재료와 품질 관리 → 결론: 품질이 뛰어나다)

#### 장점 (두괄식)

{% stepper %}
{% step %}
1. 이해가 빠름: 중요한 내용을 바로 알려줘서 듣거나 읽는 사람이 초반에 핵심을 알 수 있음.
{% endstep %}

{% step %}
2. 집중도를 높임: 처음에 중요한 걸 말하면 듣는 사람이 주제를 놓치지 않음.
{% endstep %}

{% step %}
3. 시간 절약: 핵심만 알고 싶은 사람에게 적합.
{% endstep %}
{% endstepper %}

#### 활용 상황

* 보고서나 발표에서 결론을 먼저 제시할 때
* 논리적으로 상대를 설득할 때
* 빠르게 정보를 전달해야 할 때
* 영어 표현: Top-down approach 또는 main idea first. 😊
