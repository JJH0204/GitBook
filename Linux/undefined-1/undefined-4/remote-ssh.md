# Remote SSH

{% stepper %}
{% step %}
### 상황

* 평소 로컬에서 코드 작업 → 커밋 → 서버 적용을 위해 pull → 수정 생기면 다시 커밋 → pull 하는 흐름이 번거로워서,
* VS Code로 원격(서버)에 직접 접속해 수정하는 방법을 사용하려고 함.
{% endstep %}

{% step %}
### 1. Remote - SSH 확장 설치

* VS Code에서 Remote - SSH 확장을 설치한다.
{% endstep %}

{% step %}
### 2. SSH 호스트 추가

* `Ctrl + Shift + P`를 눌러 커맨드 팔레트를 열고 `Remote-SSH: Add New ...`를 선택한다.
{% endstep %}

{% step %}
### 3. 접속할 장치 IP 입력

* 연결할 장치의 IP를 입력한 후 엔터를 누른다.
* 엔터를 한 번 더 눌러 완료한다.
{% endstep %}

{% step %}
### 4. Host 설정 파일 확인/수정

* Host 설정 파일이 생성되면 관련 메시지가 표시된다. 설정을 수정한다.
* 접속 정보를 "사용자이름@IP" 형태로 변경한다.
{% endstep %}

{% step %}
### 5. 새로고침 후 접속 시도

* 새로고침한 뒤 접속을 시도한다. 적절한 값을 선택하고 엔터를 누르면 접속을 시도한다.
{% endstep %}

{% step %}
### 6. 실패 시 로그 확인

* 접속이 실패하면 tar 서비스가 설치되어 있지 않거나 다른 문제일 수 있다. 로그를 확인한다.
* 예: 리눅스에 tar가 설치되어 있지 않아 설치하는 과정이 필요했다.
{% endstep %}

{% step %}
### 7. 문제 해결 후 재시도

* 문제가 해결되면 다시 접속을 시도한다.

&#x20;(성공 메시지)

* 하단 터미널에서 원하는 쉘이 활성화되면 접속 성공이다.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
* 커맨드 팔레트에서 입력할 명령(예: `Remote-SSH: Add New ...`)은 그대로 입력하세요.
* 이미지나 로그를 참고해 문제가 발생하면 해당 로그를 확인한 뒤 필요한 패키지(예: tar)를 설치하세요.
{% endhint %}
