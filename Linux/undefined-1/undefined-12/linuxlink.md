# LinuxLink

* Linux에서 링크는 파일 시스템 내에서 파일이나 디렉토리를 참조하는 방법을 제공하는 중요한 개념입니다.
* 링크는 크게 하드 링크(hard link)와 심볼릭 링크(symbolic link)로 나뉩니다.

#### 하드 링크 (Hard Links)

* 하드 링크는 동일한 파일에 대한 여러 참조를 생성합니다.
* 하드 링크는 원본 파일과 동일한 inode 번호를 공유하여 파일 시스템에서 동일한 데이터 블록을 가리킵니다.
* 이 때문에 원본 파일이 삭제되더라도 하드 링크를 통해 데이터에 접근할 수 있습니다.
* 단점: 하드 링크는 동일한 파일 시스템 내에서만 작동하며, 디렉토리에 대해서는 하드 링크를 생성할 수 없습니다.

{% code title="하드 링크 생성 (예)" %}
```bash
ln original_file hard_link
```
{% endcode %}

이 명령은 `original_file`의 하드 링크인 `hard_link`를 생성합니다.

#### 심볼릭 링크 (Symbolic Links)

* 심볼릭 링크는 파일이나 디렉토리에 대한 경로를 저장하는 특수 파일입니다.
* 심볼릭 링크는 원본 파일의 경로를 가리키므로, 원본 파일이 삭제되면 심볼릭 링크는 "깨진 링크(dangling link)"가 됩니다.
* 장점: 심볼릭 링크는 파일 시스템 간에 생성할 수 있으며, 디렉토리에도 링크를 생성할 수 있습니다.

{% code title="심볼릭 링크 생성 (예)" %}
```bash
ln -s original_file symbolic_link
```
{% endcode %}

이 명령은 `original_file`의 심볼릭 링크인 `symbolic_link`를 생성합니다.

{% hint style="info" %}
주요 차이점 요약

* 하드 링크: 동일한 파일 시스템 내에서만 작동, 동일한 inode 공유, 원본 파일이 삭제되어도 데이터 접근 가능.
* 심볼릭 링크: 경로를 저장, 파일 시스템 간 생성 가능, 원본 파일이 삭제되면 링크가 깨질 수 있음.
{% endhint %}

하드 링크와 심볼릭 링크는 파일 시스템의 유연성을 높여주며 다양한 응용에서 중요한 역할을 합니다. 자세한 내용은 다음 링크를 참고하세요:

* https://www.linux.org
* https://www.redhat.com
