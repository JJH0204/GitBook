# Archive

## 압축

확장자: .xz .bz2 .gz .zip 등등\
툴: xz, bzip2, gzip

{% code title="명령어" %}
```bash
xz 파일명          # 압축
xz -d 파일명.xz    # 압축 해제
```
{% endcode %}

{% hint style="info" %}
특징:

* 원본 파일이 남지 않는다.
* 압축이 꼭 용량이 줄어든다는 것은 아니다.
* 압축 툴에 따라 효율이 다르다.
{% endhint %}

## 아카이브

tar 명령어:

{% code title="tar 사용법" %}
```bash
tar [옵션] [아카이브이름] [파일 또는 디렉토리]
```
{% endcode %}

옵션:

* c : 아카이브를 만들어라
* f : 대상 파일을 지정
* x : 아카이브 해제
* v : 과정 출력
* J : 아카이브 후 .xz 압축(또는 압축 해제) 수행
* j : 아카이브 후 .bz2 압축(또는 압축 해제) 수행
* z : 아카이브 후 gzip 압축(또는 압축 해제) 수행

{% hint style="info" %}
특징:

* 원본 파일이 남는다. (재활용이 가능)
{% endhint %}

용도 및 주의사항:

* 다수의 파일을 한 번에 가져올 때 아카이브와 압축을 함께 사용하여 용량을 줄여 이동시킨다.
* 파일 명칭에 압축 확장자를 입력하지 않으면 다른 사용자가 무엇으로 압축했는지 알기 어렵다.
* 리눅스 배포판에 따라 xvf 옵션으로 아카이브와 압축을 동시에 한 파일을 해제할 수 있다(권장되는 방법은 아님).
* 가능하면 아카이브를 생성할 때 사용한 옵션을 그대로 사용해 해제한다. 예: cvf로 생성했으면 xvf로 해제.
* 백업(버전관리) 용도로 사용한다.
