# FileCommands

| 명령어     | 설명                                                                                                             | 옵션                                                                                                                                                                                          | 사용 방법                                                             | 예제                                                                                        |
| ------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `ls`    | 디렉토리에 저장된 하위 디렉토리와 파일 목록 출력                                                                                    | <p>- <code>-a</code>: 숨김 파일 포함 모두<br>- <code>-l</code>: 세부 정보를 리스트로 출력<br>- <code>-r</code>: 알파벳 역순으로 출력<br>- <code>-R</code>: 하위 경로와 그 안의 파일 표시</p>                                        | `ls '옵션' '디렉토리'`                                                  | `ls -al ./home`                                                                           |
| `cp`    | 파일 또는 디렉토리 복사                                                                                                  | <p>- <code>-b</code>: 복사 대상 파일이 존재할 경우 백업 파일을 만든다<br>- <code>-f</code>: 복사 대상 파일이 존재하는 경우 덮어쓴다<br>- <code>-i</code>: 복사 대상 파일이 존재하는 경우 덮어쓸 것인지 묻는다<br>- <code>-r</code>: 하위 디렉토리까지 복사한다</p> | `cp '옵션' '복사할 대상' '저장할 디렉토리'`                                     | `cp -i /etc/passwd /home/jaeho`                                                           |
| `rm`    | 파일/디렉토리 삭제                                                                                                     | <p>- <code>-f</code>: 강제 삭제<br>- <code>-i</code>: 삭제 시 묻는다.<br>- <code>-r</code>: 하위 디렉토리까지 삭제</p>                                                                                          | <p><code>rm '파일명'</code><br><code>rm '옵션' '디렉토리명'</code></p>      | `rm -rf admin`                                                                            |
| `mv`    | 파일/디렉토리 이동 또는 파일명 변경                                                                                           | <p>- <code>-b</code>: 대상 파일 백업 생성<br>- <code>-f</code>: 강제로 이동 또는 변경<br>- <code>-v</code>: 파일 이동 과정 표시</p>                                                                                  | `mv '옵션' '이동할 대상' '저장할 디렉토리'`                                     | `mv -v /etc/passwd /home/jaeho`                                                           |
| `touch` | <p>파일 크기가 0byte 인 빈 파일 생성<br>서버의 현재 시간으로 파일의 타임 스탬프를 변경</p>                                                    | <p>- <code>-a</code>: 접근 시간을 변경<br>- <code>-m</code>: 수정시간을 변경<br>- <code>-c</code>: 시스템 현재 시간으로 파일 시간 정보 수정<br>- <code>-r 파일a 파일b</code>: 파일a의 시간 정보를 파일b에 동일하게 적용</p>                     | <p><code>touch '파일명'</code><br><code>touch '파일a' '파일b'</code></p> | <p><code>touch /etc/passwd</code><br><code>touch /ect/passwd /home/jaeho/desc</code></p>  |
| `file`  | 파일의 종류 및 속성 값 출력                                                                                               | <p>- <code>-b</code>: 파일 유형만 표시<br>- <code>-f</code>: 파일 목록에 지정한 파일들에 대해서만 명령을 실행<br>- <code>-z</code>: 압축된 파일의 내용 출력<br>- <code>-i</code>: MIME 타입문자로 출력</p>                               | `file '옵션' '파일'`                                                  | `file -b /etc/passwd`                                                                     |
| `find`  | <p>주어진 조건의 파일 찾아서 경로 출력<br>-<a href="/broken/pages/ff66cfac08e0878e730418dcf8e74bda386554ea">find_time</a></p> | <p>- <code>-name</code>: 이름 기준<br>- <code>-user</code>: 사용자 이름 기준<br>- <code>-perm</code>: 권한 기준<br>- <code>-type</code>: 파일 유형 기준<br>- <code>-exec</code>: 검색된 파일에 수행할 명령어 지정</p>          | `find '옵션' '조건'`                                                  | <p><code>find -name desc</code><br><code>find / -name "\*.swp" -exec rm {} \\;</code></p> |
