# LILO 부트 로더

{% hint style="info" %}
LILO, Linux Loader는 리눅스 운영 시스템을 위한 초기 부트 로더 중 하나입니다.\
시스템의 전원이 켜지고 나서 운영 체제가 로드되기 전에 가장 먼저 실행되는 소프트웨어로, 다른 운영 체제를 선택하고 로드할 수 있는 메뉴를 제공하는 역할을 합니다.
{% endhint %}

### 특징과 작동 방식

{% stepper %}
{% step %}
### 다중 부팅 지원

* LILO는 여러 운영 체제를 설치한 멀티부팅 환경에서 선택적으로 부팅할 운영 체제를 선택할 수 있게 해줍니다.
* 이를 통해 사용자는 리눅스, 윈도우즈, 그 외 다른 운영 체제 간 부팅이 가능해집니다.
{% endstep %}

{% step %}
### 설정 파일

* LILO 설정은 ' /etc/lilo.conf ' 파일에 저장됩니다.
* 부팅 관련 설정(로드할 커널 이미지, 부팅 옵션, 타임아웃 설정 등)을 지정할 수 있습니다.
{% endstep %}

{% step %}
### 부팅 메뉴

* LILO는 부팅 시 화면에 메뉴를 제공하여 사용자가 원하는 운영 체제를 선택할 수 있도록 합니다.
* 설정 파일에서 타임아웃이 지정되어 있다면, 지정된 시간 이후 기본 운영 체제가 자동으로 부팅됩니다.
{% endstep %}

{% step %}
### 제한 사항

* 설치할 때 설정한 커널 이미지 위치에 대한 물리적인 주소 정보를 사용합니다.
* 커널이나 중요 파일들의 위치가 변경될 경우 LILO는 새로운 설정 정보로 업데이트되어야 합니다.
* 또한 부팅 가능한 최대 영역이 하드 드라이브의 처음 1024 실린더로 제한됩니다.
{% endstep %}
{% endstepper %}

* LILO는 사용이 줄었으며 최근에는 GRUB(GRand Unified Bootloader) 같은 현대적이고 유연한 부트 로더들이 널리 사용됩니다.
* 주로 구식 시스템 또는 특수 목적으로 구성된 환경에서 LILO가 사용됩니다.

## LILO 설정 파일 (lilo.conf)

{% hint style="info" %}
**리눅스 시스템에서 LILO(리눅스 로더) 부트 로더를 구성하기 위한 주요 설정 파일이다.**\
**시스템 부팅과 관련된 다양한 옵션들을 설정할 수 있다.**\
**사용자는 부팅 관련 세부 사항들을 정의하며, LILO에 의해 시스템이 어떻게 시작될지를 제어할 수 있다.**
{% endhint %}

### 주요 구성 요소

| 요소      | 설명                                                                                                                         |
| ------- | -------------------------------------------------------------------------------------------------------------------------- |
| boot    | <p>LILO가 설치될 장치를 지정<br><code>/dev/sda</code>: 첫 번째 SATA 드라이브를 MBR에 LILO를 설치하겠다는 의미</p>                                     |
| map     | <p>이 파일은 LILO가 운영 체제를 로드하는 데 사용하는 매핑 정보를 저장하고 있다.<br><code>/boot/map</code> 파일에 저장된다.</p>                                  |
| install | <p>LILO가 사용할 부트로더 코드의 위치를 지정<br>일반적으로 <code>/boot/boot.b</code>가 사용된다.</p>                                                 |
| prompt  | LILO가 부팅 시 부트 메뉴를 표시하도록 한다.                                                                                                |
| timeout | <p>사용자가 메뉴에서 선택을 하기 전에 대기할 시간을 1/10초 단위로 설정한다.<br>예: <code>50</code> -> 5초 대기 후 기본 설정으로 부팅</p>                             |
| default | 사용자가 아무 선택도 하지 않았을 때 기본적으로 로드할 운영체제를 지정                                                                                    |
| image   | <p>부팅 가능한 커널 이미지의 위치를 지정한다.<br>이 섹션은 <code>root</code>, <code>label</code>, <code>read-only</code> 같은 추가 옵션을 포함할 수 있다.</p> |
| other   | <p>리눅스가 아닌 다른 운영 체제를 부팅하는 옵션을 지정<br>이를 통해 LILO를 사용하여 다중 운영 체제를 관리할 수 있다.</p>                                               |
