## 1. 목적

LILO(Linux Loader)는 리눅스용 초기 부트 로더다. 전원을 켠 뒤 운영 체제가 로드되기 전에 가장 먼저 실행되는 소프트웨어이며, 부팅할 운영 체제를 선택하는 메뉴를 제공한다.

## 2. 구성 요소

### 2.1 설정 파일 `/etc/lilo.conf`

부팅 방식을 정의하는 주요 설정 파일이다. 로드할 커널 이미지, 부팅 옵션, 대기 시간을 지정한다.

| 요소 | 설명 |
|---|---|
| `boot` | LILO를 설치할 장치. 예: `/dev/sda`는 첫 번째 SATA 드라이브의 MBR에 설치한다는 뜻이다 |
| `map` | LILO가 운영 체제를 로드할 때 쓰는 매핑 정보 파일. `/boot/map`에 저장된다 |
| `install` | 부트로더 코드의 위치. 보통 `/boot/boot.b`다 |
| `prompt` | 부팅 시 부트 메뉴를 표시한다 |
| `timeout` | 사용자가 선택하기 전 대기 시간. 1/10초 단위다. 예: `50`은 5초 후 기본 항목으로 부팅한다 |
| `default` | 선택이 없을 때 기본으로 부팅할 항목 |
| `image` | 부팅할 커널 이미지의 위치. `root`, `label`, `read-only` 옵션을 포함할 수 있다 |
| `other` | 리눅스가 아닌 다른 운영 체제를 부팅하는 항목. 멀티부팅에 쓴다 |

### 2.2 특징과 제한

| 항목 | 내용 |
|---|---|
| 다중 부팅 | 리눅스, 윈도우 등 여러 운영 체제 중 하나를 고른다 |
| 부팅 메뉴 | 부팅 시 메뉴를 보이고 `timeout` 후 기본 항목으로 부팅한다 |
| 위치 정보 | 커널 이미지의 물리적 디스크 위치를 사용한다. 커널이나 중요 파일의 위치가 바뀌면 LILO를 다시 갱신해야 한다 |
| 영역 제한 | 부팅 가능한 영역이 디스크 처음 1024 실린더로 제한된다 |

## 3. 동작 원리

1. 전원을 켜면 BIOS가 디스크의 MBR(Master Boot Record)을 읽는다.
2. MBR의 LILO 코드가 `/boot/map`의 위치 정보로 커널 이미지를 찾는다.
3. `prompt`가 있으면 부트 메뉴를 표시하고 `timeout`만큼 기다린다.
4. 선택된 항목(없으면 `default`)의 커널을 메모리에 올려 실행한다.

{% hint style="danger" %}
WARNING: `/etc/lilo.conf`를 고친 뒤에는 `lilo` 명령으로 설정을 MBR에 다시 기록해야 반영된다. 설정이 틀린 채로 `lilo`를 실행하거나 `boot=`를 잘못 지정하면 부팅이 되지 않는다. 편집 전에 설정 파일을 백업하고(`cp /etc/lilo.conf /etc/lilo.conf.bak`), 복구 콘솔(설치 미디어 또는 rescue 부팅)을 확보한 뒤 작업한다. 이 문서는 설정 절차를 다루지 않는다.
{% endhint %}

## 4. 약어와 용어

| 용어 | 뜻 |
|---|---|
| LILO | Linux Loader |
| GRUB | GRand Unified Bootloader. LILO 이후 널리 쓰이는 부트 로더. 현재는 GRUB2 |
| MBR | Master Boot Record. 디스크 첫 섹터의 부트 영역 |
