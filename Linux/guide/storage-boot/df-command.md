# df 명령어 참조

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-STB-007-REF |
| 유형 | REF (명령 표) |
| 목적 | `df`의 주요 옵션과 출력 열을 찾아본다 |
| 확인 상태 | 미검증 (GNU coreutils `df`의 일반 지식과 원본 출력 예를 정리한 것이다) |
| 개정 | R1 (2026-11-18) |

`df`는 마운트된 파일 시스템의 디스크 사용량을 표시한다. 사용률 경보 스크립트는 [디스크 용량 확인 스크립트 (df)](df.md)(LNX-STB-006-MP)를 따른다.

## 1. 출력 열

| 열 | 뜻 |
|---|---|
| `Filesystem` | 장치 또는 파일 시스템 이름 |
| `1K-blocks` | 전체 크기(1 KiB 단위) |
| `Used` | 사용 중인 크기 |
| `Available` | 사용 가능한 크기 |
| `Use%` | 사용률 |
| `Mounted on` | 마운트 지점 |

원본 출력 예:

```
Filesystem          1K-blocks    Used Available Use% Mounted on
devtmpfs                 4096       0      4096   0% /dev
tmpfs                  909172       0    909172   0% /dev/shm
/dev/mapper/rl-root  17756160 2164480  15591680  13% /
/dev/sda1              983040  413228    569812  43% /boot
```

## 2. 주요 옵션

| 옵션 | 동작 |
|---|---|
| `-h` | 사람이 읽기 쉬운 단위(K, M, G)로 표시한다 |
| `-T` | 파일 시스템 형식 열을 추가한다 |
| `-i` | 블록 대신 inode 사용량을 표시한다 |
| `-t <형식>` | 지정한 파일 시스템 형식만 표시한다. 예: `df -t ext4` |
| `-x <형식>` | 지정한 형식을 제외한다. 예: `df -x tmpfs` |
| `<경로>` | 그 경로가 속한 파일 시스템만 표시한다. 예: `df /` |

## 3. 사용 예

| 목적 | 명령 |
|---|---|
| 읽기 쉬운 단위로 전체 보기 | `df -h` |
| 루트 사용률만 보기 | `df /` |
| inode 부족 확인 | `df -i` |
| 디렉터리별 사용량 (참고) | `du -sh <디렉터리>` |
