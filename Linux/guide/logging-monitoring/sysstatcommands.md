# sar·iostat 명령 참조 (sysstat)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-LOG-005-REF |
| 유형 | REF (명령 표) |
| 목적 | sysstat 패키지의 성능 통계 명령과 주요 옵션을 참조한다 |
| 확인 상태 | 미검증 (원본 페이지와 sysstat man 문서 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 이 문서는 원본 `sysstat.md`의 비어 있던 `iostate` 절(`iostat`의 오타)을 보충해 새로 만든 참조다. `iostat`, `mpstat`, `pidstat`, `sadf` 항목은 원본에 없던 내용이며 미검증이다. 설치는 LNX-LOG-004-MP를 따른다.
{% endhint %}

## 1. 명령 표

| 명령 | 설명 | 형식 | 주요 옵션 |
|---|---|---|---|
| `sar` | 시스템 활동 통계를 출력한다. 옵션이 없으면 CPU 사용률이다 | `sar [옵션] [<간격(초)> [<횟수>]]` | `-u`: CPU 사용률<br>`-r`: 메모리 사용률<br>`-q`: 실행 대기열과 부하 평균<br>`-d`: 블록 장치(디스크) 통계<br>`-n DEV`: 네트워크 인터페이스 통계<br>`-f <파일>`: 저장된 통계 파일을 읽는다<br>`-s <HH:MM:SS>` `-e <HH:MM:SS>`: 시작·종료 시각 |
| `iostat` | CPU와 디스크 입출력 통계를 출력한다 | `iostat [옵션] [<간격> [<횟수>]]` | `-x`: 확장 통계(`%util`, `await` 등)<br>`-d`: 디스크만<br>`-h`: 사람이 읽기 쉬운 단위 |
| `mpstat` | 코어별 CPU 통계를 출력한다 | `mpstat [-P ALL] [<간격> [<횟수>]]` | `-P ALL`: 모든 코어 |
| `pidstat` | 프로세스별 통계를 출력한다 | `pidstat [<간격> [<횟수>]]` | `-u`: CPU, `-r`: 메모리, `-d`: 디스크 |
| `sadf` | 저장된 통계를 다른 형식으로 변환한다 | `sadf [옵션] <파일>` | `-d`: 세미콜론 구분 텍스트(CSV 용도) |

`sar`의 간격과 횟수를 생략하면 오늘 저장된 통계 파일을 읽는다(`/var/log/sa/sa<일>`).

## 2. 사용 예

| 목적 | 명령 | 기대 결과 |
|---|---|---|
| CPU를 1초 간격으로 3회 측정 | `sar 1 3` | 측정 3줄과 `Average:` 줄이 출력된다 |
| 평균 줄만 보기 | `sar 1 3 \| grep Average` | `Average:` 한 줄만 출력된다 |
| 메모리 사용률 보기 | `sar -r 1 3` | `kbmemfree`, `%memused` 등이 출력된다 |
| 디스크 통계 보기 | `sar -d 1 3` | 장치별 `tps`, `%util`이 출력된다 |
| 오늘 저장된 CPU 통계 보기 | `sar -u` | 수집 시각별 CPU 사용률이 출력된다 |
| 특정 날짜 파일 읽기 | `sar -u -f /var/log/sa/sa<일>` | 해당 날의 통계가 출력된다 |
| 디스크 확장 통계 보기 | `iostat -x 1 3` | 장치별 `await`, `%util`이 출력된다 |
| 코어별 CPU 보기 | `mpstat -P ALL 1 3` | 코어마다 한 줄씩 출력된다 |

### `sar` CPU 열

| 열 | 뜻 |
|---|---|
| `%user` | 사용자 프로세스의 CPU 사용 비율 |
| `%nice` | `nice` 값을 조정한 프로세스의 사용 비율 |
| `%system` | 커널 사용 비율 |
| `%iowait` | 디스크 입출력을 기다리며 쉰 비율. 높으면 디스크가 병목일 수 있다 |
| `%steal` | 가상 환경에서 호스트가 CPU를 가져간 비율 |
| `%idle` | 쉬는 비율 |
