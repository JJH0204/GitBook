## 1. sed

`sed`는 입력을 한 줄씩 읽어 편집 명령을 적용하고 결과를 표준 출력으로 낸다. 원본 파일은 `-i`를 쓰지 않으면 바뀌지 않는다.

| 목적 | 명령 | 결과 |
|---|---|---|
| 치환(줄마다 첫 번째 일치) | `sed 's/seoul/SEOUL/' data.txt` | 각 줄의 `seoul`이 `SEOUL`로 바뀌어 출력된다 |
| 줄 전체의 모든 일치 치환 | `sed 's/a/A/g' data.txt` | `g` 플래그를 붙인다 |
| 특정 줄만 출력 | `sed -n '2p' data.txt` | `bob 25 busan` |
| 특정 줄 삭제 | `sed '2d' data.txt` | 2번째 줄을 뺀 나머지가 출력된다 |
| 패턴 이후 범위 출력 | `sed -n '/bob/,$p' data.txt` | `bob` 줄부터 끝까지 출력된다 |
| 확장 정규식과 묶음 참조 | `sed -E 's/([a-z]+) ([0-9]+)/\2 \1/' data.txt` | 이름과 나이의 순서가 바뀐다(`30 alice seoul`) |
| 파일을 직접 수정, 백업 보관 | `sed -i.bak 's/bob/dave/' d2.txt` | `d2.txt`가 수정되고 `d2.txt.bak`에 원본이 남는다 |

| 요소 | 뜻 |
|---|---|
| `-n` | 자동 출력을 끈다. `p` 명령과 함께 쓴다 |
| `-E` | 확장 정규식을 쓴다 |
| `-i[접미사]` | 파일을 직접 수정한다. 접미사를 주면 백업을 만든다 |
| `s/<패턴>/<바꿀 문자열>/[플래그]` | 치환. 플래그 `g`는 줄의 모든 일치 |
| `<번호>`, `$` | 줄 번호, 마지막 줄 |
| `p`, `d` | 출력, 삭제 |

{% hint style="warning" %}
CAUTION: `sed -i`는 파일을 되돌릴 수 없게 바꾼다. 접미사(`-i.bak`)를 주거나, 먼저 `-i` 없이 결과를 확인한다. `-i`의 접미사 문법은 BSD(macOS)와 달라 스크립트를 옮길 때 주의한다.
{% endhint %}

## 2. awk

`awk`는 줄을 필드로 나누어 `패턴 { 동작 }` 규칙을 적용한다. 기본 구분자는 공백이다.

| 목적 | 명령 | 결과 |
|---|---|---|
| 특정 열 출력 | `awk '{print $1}' data.txt` | `alice`, `bob`, `carol` |
| 조건에 맞는 줄 | `awk '$2>28' data.txt` | 나이가 28 초과인 줄(alice, carol) |
| 합계와 줄 수 | `awk '{s+=$2} END{print s, NR}' data.txt` | `96 3` |
| 구분자 지정 | `awk -F: '{print $1}' /etc/passwd` | 사용자 이름 열이 출력된다 |
| 값별 개수 집계 | `awk '{c[$3]++} END{for(k in c) print k,c[k]}' data.txt` | `seoul 2`, `busan 1`(순서는 정해져 있지 않다. 정렬하려면 `\| sort`) |
| 줄 번호 지정 | `awk 'NR==2{print $0}' data.txt` | `bob 25 busan` |
| 변수 전달 | `awk -v min=30 '$2>=min{print $1}' data.txt` | `alice`, `carol` |

| 내장 변수 | 뜻 |
|---|---|
| `$0`, `$1`, `$2`… | 줄 전체, 첫 번째 필드, 두 번째 필드… |
| `NR` | 현재까지 읽은 줄 수 |
| `NF` | 현재 줄의 필드 수 |
| `-F <구분자>` | 입력 필드 구분자 지정 |
| `BEGIN`, `END` | 입력 처리 전, 후에 한 번 실행하는 블록 |

## 3. 선택 기준

| 상황 | 도구 |
|---|---|
| 문자열을 찾아 바꾼다, 줄을 지운다 | `sed` |
| 열 단위로 뽑거나 계산한다, 집계한다 | `awk` |
| 단순히 열만 자른다 | `cut`([텍스트 파일 처리 명령어](textfilecommands.md)) |
| 명령 출력을 이어서 가공한다 | 파이프로 연결([입출력 리다이렉션과 파이프](redirect-pipe.md)) |
