## 1. 표준 스트림

| 이름 | 번호 | 기본 연결 | 설명 |
|---|---|---|---|
| 표준 입력(stdin) | 0 | 키보드 | 프로그램이 읽는 입력 |
| 표준 출력(stdout) | 1 | 화면 | 프로그램의 정상 출력 |
| 표준 오류(stderr) | 2 | 화면 | 프로그램의 오류 메시지 |

## 2. 리다이렉션

| 문법 | 동작 | 예 |
|---|---|---|
| `> <파일>` | 표준 출력을 파일에 쓴다. 파일이 있으면 내용을 지우고 쓴다 | `ls > list.txt` |
| `>> <파일>` | 표준 출력을 파일 끝에 덧붙인다 | `date >> list.txt` |
| `< <파일>` | 파일을 표준 입력으로 읽는다 | `wc -l < list.txt` |
| `2> <파일>` | 표준 오류를 파일에 쓴다 | `ls /없는경로 2> err.txt` |
| `2>&1` | 표준 오류를 표준 출력이 가는 곳으로 보낸다 | `<명령> > all.txt 2>&1` |
| `&> <파일>` | 표준 출력과 오류를 같은 파일에 쓴다(bash 문법) | `<명령> &> all.txt` |
| `> /dev/null` | 출력을 버린다 | `<명령> > /dev/null 2>&1` |

{% hint style="danger" %}
WARNING: `>`는 기존 파일 내용을 확인 없이 지운다. 중요한 파일 이름을 잘못 쓰면 내용이 사라진다. 덮어쓰기를 막으려면 `set -o noclobber`를 쓴다. 이 설정은 미검증이다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 리다이렉션은 왼쪽에서 오른쪽으로 처리된다. `<명령> 2>&1 > /dev/null`은 오류를 먼저 화면(현재 stdout)으로 복사한 뒤 stdout만 버리므로, 오류는 화면에 남는다. 둘 다 버리려면 `> /dev/null 2>&1` 순서로 쓴다. 이 동작은 실행해 확인했다(`ls /nonexist /tmp 2>&1 >/dev/null | head`가 오류만 출력했다).
{% endhint %}

## 3. 파이프와 관련 명령

| 문법·명령 | 동작 | 예 |
|---|---|---|
| `<명령1> \| <명령2>` | 명령1의 표준 출력을 명령2의 표준 입력으로 넘긴다. 표준 오류는 넘기지 않는다 | `ps -ef \| grep sshd` |
| `\|&` | 표준 출력과 오류를 모두 파이프로 넘긴다(bash 문법) | `<명령> \|& less` |
| `tee <파일>` | 표준 입력을 파일에 쓰면서 그대로 표준 출력에도 낸다 | `echo abc \| tee t.txt \| wc -c` → 4 |
| `tee -a <파일>` | 파일 끝에 덧붙인다 | `date \| tee -a log.txt` |
| `xargs <명령>` | 표준 입력의 항목을 명령의 인자로 넘긴다 | `find . -name '*.tmp' \| xargs ls -l` |
