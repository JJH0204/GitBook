## 1. 출력 명령

| 명령어 | 설명 | 형식 | 주요 옵션 | 예 |
|---|---|---|---|---|
| `cat` | 파일 내용을 출력한다 | `cat [옵션] <파일>` | `-n`: 모든 줄에 번호 (빈 줄 포함)<br>`-b`: 비어 있지 않은 줄에만 번호 | `cat /etc/passwd` |
| `head` | 파일의 앞부분을 출력한다 (기본 10줄) | `head [옵션] <파일>` | `-n <숫자>` 또는 `-<숫자>`: 앞에서 그 줄 수만큼 출력 | `head -n 3 /etc/passwd` |
| `tail` | 파일의 끝부분을 출력한다 (기본 10줄) | `tail [옵션] <파일>` | `-n <숫자>` 또는 `-<숫자>`: 뒤에서 그 줄 수만큼 출력<br>`-f`: 추가되는 내용을 계속 출력 (보충) | `tail -n 2 /etc/passwd` |
| `more` | 파일을 화면 단위로 끊어 출력한다 | `more [옵션] <파일>` | `-<숫자>`: 한 화면의 줄 수 | `more -20 <파일>` |
| `less` | 파일을 한 화면씩 앞뒤로 이동하며 본다 | `less <파일>` | `q`: 종료 | `less /var/log/syslog` |

## 2. 검색과 집계

| 명령어 | 설명 | 형식 | 주요 옵션 | 예 |
|---|---|---|---|---|
| `grep` | 파일에서 문자열 또는 정규 표현식과 일치하는 줄을 찾는다 | `grep [옵션] <패턴> <파일>` | `-n`: 줄 번호 함께 출력<br>`-i`: 대소문자 구분 안 함 (보충)<br>`-v`: 일치하지 않는 줄 출력 (보충)<br>`-E`: 확장 정규 표현식 사용 (보충) | `grep -n sys /etc/passwd`<br>`grep -E "root\|sys" /etc/passwd` |
| `wc` | 줄, 단어, 바이트 수를 센다 | `wc [옵션] <파일>` | `-l`: 줄 수<br>`-w`: 단어 수<br>`-c`: 바이트 수 | `wc -l /etc/passwd` |

{% hint style="info" %}
NOTE: 원본은 `wc -c`를 "알파벳 수"로 적었다. `-c`는 바이트 수이며 문자 수는 `-m`이다. 영문자만 있는 파일에서는 두 값이 같다. 정정했다. 미검증이다.
{% endhint %}

## 3. 정렬과 추출

| 명령어 | 설명 | 형식 | 주요 옵션 | 예 |
|---|---|---|---|---|
| `sort` | 명령 결과나 파일 내용을 정렬한다 (기본은 문자 순서) | `sort [옵션] <파일>` | `-r`: 역순<br>`-f`: 대소문자 구분 안 함<br>`-n`: 숫자 크기순 (보충)<br>`-u`: 중복 줄 제거 (보충)<br>`-t <구분자> -k <필드>`: 지정 필드 기준 (보충) | `sort -r /etc/passwd`<br>`sort -t: -k3 -n /etc/passwd` |
| `cut` | 줄에서 지정한 위치나 필드를 추출한다 | `cut <옵션> <파일>` | `-c <범위>`: 문자 위치 지정<br>`-d <구분자>`: 필드 구분자 지정 (보충)<br>`-f <필드>`: 추출할 필드 번호 (보충)<br>범위는 쉼표(`,`)나 하이픈(`-`)으로 지정 | `cut -c 1-5 /etc/passwd`<br>`cut -d: -f1 /etc/passwd` |
| `split` | 한 파일을 여러 파일로 나눈다 | `split [옵션] <파일>` | `-b <크기>`: 바이트 단위 분리<br>`-l <줄 수>`: 줄 수 단위 분리 | `split -l 10 /etc/passwd` |

{% hint style="info" %}
NOTE: `sort`는 기본이 문자 순서이므로 숫자를 `-n` 없이 정렬하면 `10`이 `2`보다 앞에 온다. `cut -d: -f1 /etc/passwd`는 계정 이름 열을 출력한다. 미검증이다.
{% endhint %}

{% hint style="warning" %}
CAUTION: `split`은 현재 디렉터리에 `xaa`, `xab` 같은 파일을 여러 개 만든다. 같은 이름의 파일이 있으면 덮어쓸 수 있으므로 빈 디렉터리에서 실행한다.
{% endhint %}
