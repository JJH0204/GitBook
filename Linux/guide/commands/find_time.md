# find 시간 옵션 및 파일 속성

| 항목 | 내용 |
|---|---|

| 유형 | REF (옵션 표) |
| 목적 | 파일의 세 가지 시간 속성과 `find`의 시간 조건(`-mtime`, `-mmin` 등)을 참조한다 |
| 확인 상태 | 미검증 (원본 페이지와 GNU findutils 문서 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다) |

## 1. 파일 시간 속성

| 속성 | 이름 | 갱신 시점 | 확인 명령 |
|---|---|---|---|
| atime | access time | 파일 내용을 읽었을 때 (`cat`, `vi` 등) | `ls -lu` |
| mtime | modification time | 파일 내용을 수정했을 때 | `ls -l` |
| ctime | change time | 파일의 메타데이터(권한, 소유자, 링크 수 등)나 내용이 바뀌었을 때 | `ls -lc` |

{% hint style="info" %}
NOTE: 대부분의 배포판은 `relatime` 마운트 옵션을 쓴다. 이때 atime은 읽을 때마다 갱신되지 않고 제한적으로 갱신된다. 또 ctime은 사용자가 직접 지정할 수 없고 내용이 바뀌어도 갱신된다. 이 설명은 미검증이다.
{% endhint %}

## 2. 시간 비교 방식

`find`는 시간 인자 `n`에 세 가지 형식을 쓴다.

| 형식 | 의미 |
|---|---|
| `-n` | 값이 n보다 작다 (n 단위 이내) |
| `n` | 값이 정확히 n이다 |
| `+n` | 값이 n보다 크다 (n 단위보다 이전) |

## 3. 옵션 표

`-mtime`은 24시간 단위로 센다. 현재 시각과 파일 시각의 차이를 24시간 단위로 환산할 때 소수점 이하는 버린다. `-mmin`은 분 단위로 센다.

| 조건 | 의미 | 예 |
|---|---|---|
| `-mtime -3` | 수정한 지 72시간 미만인 파일 | 최근 3일 이내 수정 |
| `-mtime 3` | 수정한 지 72시간 이상 96시간 미만인 파일 | 정확히 3일 전 하루 범위 |
| `-mtime +3` | 수정한 지 96시간 이상인 파일 | 4일 이상 지난 파일 |
| `-mmin -30` | 수정한 지 30분 미만인 파일 | 최근 30분 이내 수정 |
| `-mmin +30` | 수정한 지 30분을 넘은 파일 | 30분보다 오래 전 수정 |
| `-atime`, `-ctime` | `-mtime`과 같은 규칙으로 atime, ctime을 비교한다 | `-atime +7` |
| `-amin`, `-cmin` | `-mmin`과 같은 규칙으로 분 단위 비교한다 | `-cmin -10` |

{% hint style="info" %}
NOTE: 원본은 `-mtime +3`을 "3일 이전"으로 적었다. 소수점을 버리므로 `+3`은 4일(96시간) 이상 지난 파일이다. 이에 맞게 정정했다. `-mmin` 항목은 원본에 옵션 이름만 있어 위 표로 보충했다. 미검증이다.
{% endhint %}

## 4. 사용 예

| 목적 | 명령 |
|---|---|
| 현재 디렉터리에서 최근 3일 내 수정된 파일 찾기 | `find . -type f -mtime -3` |
| 30일 넘게 수정되지 않은 파일 찾기 | `find <디렉터리> -type f -mtime +30` |
| 최근 10분 내 수정된 파일 찾기 | `find <디렉터리> -type f -mmin -10` |

{% hint style="danger" %}
WARNING: `find ... -exec rm {} \;` 또는 `-delete`를 붙이면 조건에 맞는 파일이 복구 없이 삭제된다. 먼저 `-exec` 없이 실행해 목록을 확인한 뒤 붙인다.
{% endhint %}
