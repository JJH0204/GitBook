## 1. 명령 표

| 명령어 | 설명 | 형식 | 옵션 | 예 | 비고 |
|---|---|---|---|---|---|
| `cal` | 현재 달력을 출력한다 | `cal [옵션] [<년도>]` | `-j`: 1월 1일부터 센 날짜 수로 출력<br>`-y`: 올해 달력 출력 | `cal`<br>`cal -y` | 원본 예 `cal -y 2000`은 배포판에 따라 동작이 달라 `cal -y`로 바꿨다. 특정 연도는 `cal 2000` |
| `clear` | 터미널 화면을 지운다 | `clear` | 없음 | `clear` | |
| `strings` | 바이너리 파일 안의 출력 가능한 문자열을 추출한다 | `strings <파일>` | 없음 | `strings /bin/ls` | 보충. 원본 제목은 `string`이며 명령 이름은 `strings`다 |
| `base64` | 데이터를 Base64로 인코딩하거나 디코딩한다 | `base64 [옵션] [<파일>]` | `-d`: 디코딩 | `echo hello \| base64` | 보충 |
| `tr` | 표준 입력의 문자를 치환하거나 삭제한다 | `tr [옵션] <집합1> [<집합2>]` | `-d`: 집합1의 문자를 삭제 | `echo abc \| tr a-z A-Z` | 보충 |
| `mktemp` | 임시 파일을 만들고 그 경로를 출력한다 | `mktemp` | `-d`: 임시 디렉터리 생성 | `mktemp` | 보충 |
| `date` | 시스템의 날짜와 시간을 표시하거나 바꾼다 | `date [옵션] [+<형식>]` | 없음 | `date +%Y-%m-%d` | 보충. 시간 변경은 root 권한이 필요하다 |
| `tty` | 현재 단말기의 파일 경로를 출력한다 | `tty` | 없음 | `tty` | |
| `time` | 명령 실행에 걸린 시간을 측정해 출력한다 | `time <명령어>` | 없음 | `time cat /etc/passwd` | 출력 항목은 2절 |
| `wall` | 로그인한 모든 사용자의 터미널에 메시지를 보낸다 | `wall <문장>` | 없음 | `wall "점검을 시작한다"` | 3절 참조 |
| `write` | 지정한 사용자 한 명에게 메시지를 보낸다 | `write <사용자명>` | 없음 | `write <사용자명>` | 입력 후 메시지를 쓰고 `Ctrl + D`로 끝낸다 |
| `history` | 명령어 사용 기록을 출력한다 | `history [옵션]` | `-c`: 메모리의 기록 삭제 | `history` | 4절 참조 |
| `tree` | 디렉터리 계층 구조를 출력한다 | `tree [<디렉터리>]` | 없음 | `tree /etc` | 보충. 설치돼 있지 않을 수 있다 |
| `chmod` | 파일과 디렉터리의 권한을 바꾼다 | | | | 상세는 [파일 및 디렉터리 접근 권한](../accounts-permissions/permission.md) |
| `su` | 사용자를 전환한다 | `su - <사용자명>` | `-`: 대상 사용자의 로그인 셸로 전환한다 (홈 디렉터리에서 시작) | `su - <사용자명>` | |
| `exit` | 현재 셸에서 로그아웃한다 | `exit` | 없음 | `exit` | |

## 2. time 출력 항목

| 항목 | 의미 |
|---|---|
| `real` | 시작부터 종료까지 걸린 실제 경과 시간 |
| `user` | 프로세스가 사용자 영역에서 CPU를 쓴 시간 |
| `sys` | 프로세스가 커널 영역(시스템 호출)에서 CPU를 쓴 시간 |

## 3. wall과 write 사용 시 주의

{% hint style="warning" %}
CAUTION: `wall`은 로그인한 모든 사용자의 화면에 메시지를 띄운다. 운영 서버에서는 보낼 내용과 대상이 맞는지 확인한 뒤 실행한다.
{% endhint %}

## 4. history 동작

`history`는 현재 셸의 메모리에 있는 기록을 출력한다. 더 오래된 기록은 `~/.bash_history`에 있다. 이 파일에는 셸이 종료될 때 메모리의 기록이 저장된다.

{% hint style="warning" %}
CAUTION: `history -c`는 메모리의 기록을 지운다. 이 상태에서 셸을 종료하면 이번 세션의 기록이 `.bash_history`에 남지 않는다. 감사 기록이 필요한 환경에서는 사용하지 않는다.
{% endhint %}

{% hint style="info" %}
NOTE: 원본은 `.bash_history`가 "시스템 종료 때" 저장된다고 적었다. bash는 셸이 종료될 때 저장하므로 "셸 종료 때"로 정정했다. 미검증이다.
{% endhint %}
