# 리눅스 일반 개요

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-INT-003-DO |
| 유형 | D&O (개념·구조) |
| 목적 | 리눅스 학습 영역을 나누고 각 영역의 문서 위치를 안내한다 |
| 확인 상태 | 미검증 (원본 페이지의 목차 표를 정리한 것이며 직접 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 목적

리눅스 학습은 개요, 설치, 기본 명령어 세 영역으로 나뉜다. 이 문서는 영역별로 무엇을 다루는지와 해당 문서의 위치를 표로 정리한다.

## 3. 동작 원리

학습 순서는 다음과 같다.

1. 리눅스가 무엇인지 이해한다(영역 1).
2. 실습용 리눅스를 설치한다(영역 2).
3. 디스크와 부팅 구조를 이해한다(영역 3, 4).
4. 명령어로 파일과 계정을 다룬다(영역 5, 6).

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 파티션(partition) | 디스크를 논리적으로 나눈 영역 |
| 파일 시스템(file system) | 파티션에 파일을 저장·관리하는 방식 (예: ext4, xfs) |
| 부트 로더(boot loader, Boot Manager) | 부팅 때 커널을 메모리에 올리는 프로그램 (예: GRUB, LILO) |
