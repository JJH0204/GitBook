# 리눅스 설치 및 가상화

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-INT-002-MP |
| 목적 | Windows PC의 VirtualBox에 Rocky Linux 8.10 가상 머신을 만들고 설치한 뒤 Putty로 원격 접속한다 |
| 적용 대상 | 호스트: Windows PC, VirtualBox (버전은 원본에 없다). 게스트: Rocky Linux 8.10 Minimal ISO |
| 소요 시간 | 약 40분 (ISO 다운로드 시간 제외) |
| 확인 상태 | 미검증 (원본 페이지의 설치 흐름을 정리한 것이며 이 문서로 다시 설치해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 한 저장소(디스크)에는 보통 운영체제를 하나만 설치한다. Windows와 리눅스를 한 PC에서 쓰려면 둘 중 하나를 고르거나, Windows 안에서 VirtualBox 같은 가상화 프로그램으로 리눅스를 가상 머신에 설치한다. 이 문서는 후자를 다룬다. (한 디스크에 여러 OS를 나눠 설치하는 멀티 부팅도 가능하나 이 문서의 범위가 아니다.)
{% endhint %}

{% hint style="info" %}
NOTE: 원본은 CentOS Linux를 먼저 시도했으나 설치할 수 없었다고 적었다. CentOS Linux는 지원이 종료돼 이 문서는 Rocky Linux 8을 쓴다. 원본은 시험 출제 기준을 "RHEL / Rocky Linux 8, Ubuntu 18.04 이상"으로 적었다. 어느 시험인지 원본에 없어 확인이 필요하다.
{% endhint %}

## 2. 필요 장비와 자재

| 번호 | 이름 | 사양·버전 | 비고 |
|---|---|---|---|
| 1 | 호스트 PC | Windows, 가상화 지원 CPU | 가상화 기능이 켜져 있어야 한다 |
| 2 | VirtualBox | 설치 완료 상태 | 버전은 원본에 없다. 확인 필요 |
| 3 | ISO 파일 | Rocky Linux 8.10 Minimal ISO | X Window(GUI)가 없는 최소 설치 버전이다. 8.9가 제공되지 않아 8.10을 쓴다 |
| 4 | 여유 디스크 공간 | 가상 디스크 20 GB 이상 | 원본에 없던 예시값이다. 확인 필요 |
| 5 | Putty | 설치 완료 상태 | 구역 C에서 사용한다 |

## 3. 안전 사항

{% hint style="warning" %}
CAUTION: 가상 머신에 할당하는 메모리와 CPU는 호스트 PC에서 빼서 쓴다. 호스트 전체 메모리의 절반을 넘기지 않는다.
{% endhint %}

{% hint style="info" %}
NOTE: 구역 B의 5-B-04~5-B-05는 설치 대상 디스크를 고르고 지우는 단계다. WARNING은 해당 단계 바로 앞에 있다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | VirtualBox를 실행한다 | 관리자 창이 열린다. 이전에 만든 가상 머신이 있으면 목록에 보인다 |
| 2 | Rocky Linux 8.10 Minimal ISO를 내려받는다 | 파일 확장자가 `.iso`다 |
| 3 | 호스트 디스크 여유 공간을 확인한다 | 20 GB 이상이다 |
| 4 | 설치할 계정 정보를 정한다 | 사용자명 `<사용자명>`, 비밀번호 `<비밀번호>`를 메모해 둔다. 이 문서에 적지 않는다 |

## 5. 절차

### A. 가상 머신 생성

1. (5-A-01) VirtualBox에서 `새로 만들기`를 누른다. → 결과: 새 가상 머신 만들기 창이 열린다.
2. (5-A-02) 이름을 입력한다: `<가상 머신 이름>`
3. (5-A-03) 준비한 ISO 파일을 선택한다: Rocky Linux 8.10 Minimal ISO. → 결과: 종류와 버전이 Linux 계열로 인식된다.
4. (5-A-04) 메모리를 지정한다: 2048 MB 이상(예시값). → 결과: 호스트 메모리의 절반 이내다.
5. (5-A-05) 가상 하드 디스크를 만든다: 20 GB 이상(예시값). → 결과: 가상 디스크가 새로 만들어진다. 호스트의 물리 디스크를 직접 연결하지 않는다.
6. (5-A-06) 생성을 완료한다. → 결과: 가상 머신 목록에 새 항목이 보인다.

### B. OS 설치

1. (5-B-01) 목록에서 가상 머신을 선택하고 `시작`을 누른다. → 결과: 가상 머신이 구동되고 Rocky Linux 설치 화면이 나온다.
2. (5-B-02) 설치 언어를 선택한다.
3. (5-B-03) 설치 요약 화면에서 빨간 글씨로 강조된 항목을 확인한다. → 결과: 빨간 항목을 모두 설정하면 `설치 시작` 버튼이 활성화된다.

{% hint style="danger" %}
WARNING: 설치 대상 디스크의 내용은 모두 지워진다. 5-B-04에서 목록에 나오는 디스크가 5-A-05에서 만든 가상 디스크(20 GB 이상으로 지정한 크기)인지 확인한다. 호스트 PC의 물리 디스크를 가상 머신에 직접 연결했다면 그 디스크를 선택하지 않는다. 호스트 디스크를 잘못 선택하면 호스트의 데이터를 잃는다.
{% endhint %}

4. (5-B-04) `설치 대상`을 연다. → 결과: 디스크 목록이 보인다.
5. (5-B-05) 가상 디스크 하나만 선택하고 `완료`를 누른다. → 결과: 설치 요약 화면으로 돌아오고 `설치 대상`의 빨간 표시가 사라진다.
6. (5-B-06) root 비밀번호와 사용자 계정을 설정한다: `<사용자명>`, `<비밀번호>`. → 결과: 해당 항목의 빨간 표시가 사라진다.
7. (5-B-07) 호스트 이름은 변경하지 않는다. → 결과: 기본값이 유지된다.
8. (5-B-08) `설치 시작`을 누른다. → 결과: 설치 진행 막대가 나타난다.
9. (5-B-09) 설치가 끝날 때까지 기다린다. → 결과: `재부팅` 버튼이 나타난다.
10. (5-B-10) `재부팅`을 누른다. → 결과: 가상 머신이 재시작하고 로그인 프롬프트가 나온다.

{% hint style="info" %}
NOTE: OS 설치는 첫 실행에만 진행된다. 이후 실행에서는 설치된 시스템으로 부팅한다. 재부팅 후에도 설치 화면이 다시 나오면 가상 머신 설정에서 ISO를 제거한다.
{% endhint %}

{% hint style="info" %}
NOTE: 가상 머신 창 안에 마우스가 갇히면 호스트 키로 꺼낸다. 호스트 키는 VirtualBox 설정에서 편한 키로 바꿀 수 있다. 기본값은 오른쪽 Ctrl이다. 확인 필요
{% endhint %}

11. (5-B-11) `<사용자명>`과 `<비밀번호>`로 로그인한다. → 결과: 셸 프롬프트가 나타난다.

### C. 네트워크 설정과 원격 접속

원본은 "ssh, 인터넷, 포트를 열어서 서비스 가능하도록 설정한다"고만 적었다. 아래 단계는 VirtualBox 기본 NAT 네트워크 기준으로 보충한 것이며 확인이 필요하다.

1. (5-C-01) 가상 머신을 종료한다. 가상 머신 `설정 > 네트워크`를 연다.
2. (5-C-02) `고급 > 포트 포워딩`을 연다.
3. (5-C-03) 규칙을 추가한다: 프로토콜 TCP, 호스트 IP `127.0.0.1`, 호스트 포트 `<호스트 포트>`, 게스트 포트 `22`. → 결과: 규칙이 목록에 나타난다.
4. (5-C-04) 가상 머신을 시작하고 로그인한다.
5. (5-C-05) sshd 상태를 확인한다: `systemctl status sshd` → 결과: `active (running)`이 보인다. 아니면 `sudo systemctl enable --now sshd`를 실행한다.
6. (5-C-06) 호스트 PC에서 Putty를 연다. Host Name에 `127.0.0.1`, Port에 `<호스트 포트>`를 입력하고 `Open`을 누른다. → 결과: 보안 경고 후 로그인 프롬프트가 나온다.
7. (5-C-07) `<사용자명>`과 `<비밀번호>`로 로그인한다. → 결과: 가상 머신의 셸에 접속한다. 이 구성에서 Linux가 서버, Putty가 클라이언트다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | 가상 머신에서 `cat /etc/os-release` | Rocky Linux 8.10 정보가 나온다 | `NAME`에 `Rocky Linux`, `VERSION_ID`에 `8.10` |
| 2 | 가상 머신을 재시작한다 | 설치 화면 없이 로그인 프롬프트가 나온다 | 설치 화면이 다시 나오지 않는다 |
| 3 | Putty로 접속한다 | 로그인 프롬프트가 나온다 | 로그인에 성공한다 |

## 7. 복구

### 가상 머신 복사본 만들기

1. (7-01) 가상 머신을 종료한다.
2. (7-02) `파일 > 가상 시스템 내보내기`를 실행한다. → 결과: 내보내기 파일이 만들어진다.
3. (7-03) 복사본이 필요하면 `파일 > 가상 시스템 가져오기`로 불러온다.

가상 머신을 버리려면 VirtualBox에서 해당 가상 머신을 삭제한다. 호스트 PC의 다른 데이터에는 영향이 없다.
