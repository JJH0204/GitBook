## 1. 목적

리눅스는 운영체제의 핵심인 커널(kernel)의 이름이다. 1991년 리누스 토르발스(Linus Torvalds)가 개인 프로젝트로 시작했다. 유닉스(UNIX)의 소스 코드를 바탕으로 만든 것이 아니라, 유닉스와 비슷하게 동작하도록 처음부터 새로 쓴 커널이다. 이 문서는 리눅스의 정의, 특성, 역사, 철학과 라이선스를 정리한다.

## 2. 구성 요소

### 2.1 리눅스의 정의

| 번호 | 항목 | 내용 | 비고 |
|---|---|---|---|
| 1 | 정체 | 오픈 소스 커널이다. 지원 시스템 소프트웨어와 라이브러리를 함께 묶어 운영체제로 배포한다 | |
| 2 | 계통 | 유닉스 계열(Unix-like) 운영체제다 | 유닉스 소스를 쓰지 않았다 |
| 3 | 최초 공개 | 1991년 9월 17일 커널 0.01 버전이 공개됐다 | 원본은 이 날짜를 "개발일"로 적었다. 확인 필요 |
| 4 | 개발 언어 | 주로 C 언어, 일부 어셈블리어 | 원본은 "과거 어셈블리, 현재 C"로 적었다. 처음부터 C가 중심이었다. 확인 필요 |
| 5 | 이름 | GNU 소프트웨어와 결합한 시스템을 GNU/Linux라 부르기도 한다 | 이 이름은 자유 소프트웨어 재단(FSF) 쪽 입장이다 |
| 6 | 특성 | 이식성과 확장성이 우수하다 | |
| 7 | 이용 조건 | 누구나 제작·수정·배포할 수 있다. GNU GPL 등 라이선스 조건에 따라 상업·비상업 목적으로 이용할 수 있다 | |

### 2.2 배포판, 데스크톱 구성 요소

| 번호 | 분류 | 항목 | 설명 |
|---|---|---|---|
| 1 | 배포판 | 데비안(Debian), 페도라(Fedora), 우분투(Ubuntu) | 커널과 소프트웨어를 묶어 배포하는 단위다 |
| 2 | 상용 배포판 | 레드햇 엔터프라이즈 리눅스(RHEL) | 유료 지원을 제공한다 |
| 3 | 디스플레이 서버 | X11, 웨이랜드(Wayland) | 화면 출력을 담당하는 구성 요소다 |
| 4 | 데스크톱 환경 | 그놈(GNOME), KDE 플라스마 | 창과 메뉴를 제공하는 환경이다 |

{% hint style="info" %}
NOTE: 원본은 X11, 웨이랜드, 그놈, KDE 플라스마를 "데스크톱 배포판"으로 묶었다. 이들은 배포판이 아니라 데스크톱 구성 요소이므로 분류를 나눴다.
{% endhint %}

### 2.3 장점

| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 비용 | 비용 없이 다양한 배포판을 설치할 수 있다. 서버 운영에 필요한 소프트웨어와 라이브러리를 무료로 쓸 수 있다 |
| 2 | 개발 환경 | 프로그래밍 도구와 GNU 소프트웨어가 무료로 제공된다. 네트워크 서비스 도구가 풍부하다 |
| 3 | 하드웨어 | 지원하는 하드웨어가 많다 |
| 4 | 안정성·보안 | 안정성과 보안성이 높다는 평가를 받는다. 소스가 공개돼 많은 사람이 검토한다 |
| 5 | 백업·복구 | RAID, 로컬·인터넷 백업을 지원한다. ext3, ext4 등의 파일 시스템은 `fsck` 명령으로 복구할 수 있다 |
| 6 | 패치 | 빠른 패치가 가능하다 |

{% hint style="info" %}
NOTE: 원본의 "서버 운영체제 점유율 96.4%"는 출처와 조사 기준이 없어 삭제했다. 점유율은 조사 대상(웹 서버, 상위 사이트 등)과 시점에 따라 달라진다.
{% endhint %}

**리눅스가 무료인데 서버 비용을 내는 이유.** 숙련된 서버 관리자의 인건비와 유지 보수(업데이트, 컨설팅) 비용이 서버 비용에 포함되기 때문이다.

### 2.4 단점

| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 텍스트 모드 중심 | 처음에는 낯설고 복잡하다 |
| 2 | 극복 후의 이점 | 익숙해지면 GUI 방식(대표적으로 Windows)보다 편한 경우가 있다. 예: 한 줄 명령으로 여러 작업을 처리한다. 스크립트 파일로 시스템 작업을 자동화한다 |

### 2.6 철학과 라이선스

| 번호 | 항목 | 내용 | 비고 |
|---|---|---|---|
| 1 | GNU (GNU is Not UNIX) | 리처드 스톨먼이 FSF에서 진행·유지하는 운영체제 프로젝트다. 1983년에 시작했고 목표는 완전한 유닉스 호환 소프트웨어 시스템이다 | 이름이 자기 자신을 포함하는 재귀 약어다 |
| 2 | 자유 소프트웨어 재단 (FSF) | 1985년 스톨먼이 설립했다. 자유 소프트웨어의 네 가지 자유를 정의한다 | 아래 표 참조 |
| 3 | 오픈 소스 소프트웨어 | "자유 소프트웨어"라는 말이 "무료"로 오해되는 문제 때문에 대체 용어로 쓰이기 시작했다 | 1998년 오픈 소스 이니셔티브(OSI)가 널리 알렸다. 확인 필요 |
| 4 | GNU GPL | FSF가 만든 자유 소프트웨어 라이선스다. 1판 1989, 2판 1991, 3판 2007에 발표됐다. GPL 코드를 포함한 프로그램을 배포할 때 그 프로그램 전체를 GPL로 공개해야 한다. 유료 판매는 가능하나 소스 코드 공개가 필수다 | 리눅스 커널은 GPL 2판으로 배포된다 |
| 5 | GNU LGPL | GPL보다 조건이 완화된 라이선스다. LGPL 라이브러리를 링크해 쓰는 프로그램은 소스 공개 의무가 없다. 라이브러리 자체를 수정해 배포하면 수정분을 공개해야 한다 | |
| 6 | BSD | 소스 공개 의무가 없고 상업적 이용이 가능하다. 파생 소프트웨어에 같은 라이선스를 강제하지 않는다 | 원본은 OpenCV를 BSD 예로 적었다. 최근 버전의 OpenCV는 Apache 2.0이므로 예시를 삭제했다. 확인 필요 |
| 7 | 아파치 (Apache) | 아파치 소프트웨어 재단의 라이선스다. 2.0 판은 수정·재배포를 허용하고 특허 사용권을 명시한다 | 원본은 "저작권 양도/전송 허용"으로 적었다. 부정확해 정정했다. 확인 필요 |
| 8 | MIT | 조건이 매우 느슨한 라이선스다. 저작권 고지만 유지하면 된다. 적용 예: X Window System, jQuery, Node.js | |
| 9 | MPL | 모질라 공개 라이선스(Mozilla Public License)다. 수정한 파일 단위로 소스 공개 의무가 생긴다 | 원본은 "소스코드와 실행파일의 저작권을 분리"로 적었다. 부정확해 정정했다. 확인 필요 |

자유 소프트웨어의 네 가지 자유는 다음과 같다. 자유는 금전과 무관하므로 자유 소프트웨어를 유료로 판매해도 된다.

| 번호 | 자유 |
|---|---|
| 1 | 어떤 목적이든 원하는 대로 프로그램을 실행할 자유 |
| 2 | 프로그램 복제물을 무료 또는 유료로 재배포할 자유 |
| 3 | 필요에 따라 프로그램을 개작할 자유 |
| 4 | 개선한 프로그램을 공동체가 이익을 나눌 수 있게 배포할 자유 |

{% hint style="info" %}
NOTE: 원본은 네 가지 자유를 번호 없이 적었다. FSF 정의의 번호는 0~3이다.
{% endhint %}

## 3. 동작 원리

리눅스 시스템은 아래 계층으로 구성된다. GNU 소프트웨어와 리눅스 커널이 결합해 하나의 운영체제가 된다.

```
응용 프로그램, 데스크톱 환경 (GNOME, KDE 플라스마)
        |
GNU 소프트웨어 (셸, 컴파일러, 명령어)와 라이브러리
        |
리눅스 커널 (프로세스, 메모리, 장치, 파일 시스템 관리)
        |
하드웨어
```

1. 1983년 GNU 프로젝트가 유닉스 호환 소프트웨어를 만들기 시작했다. 커널은 완성하지 못한 상태였다.
2. 1991년 토르발스가 커널을 발표했다.
3. GNU 소프트웨어와 리눅스 커널이 결합해 사용 가능한 운영체제가 됐다.
4. 배포판이 이를 묶어 설치 가능한 형태로 제공한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 커널(kernel) | 하드웨어와 프로그램 사이에서 자원을 관리하는 운영체제의 핵심 |
| 배포판(distribution) | 커널, 소프트웨어, 설치 도구를 묶어 배포하는 단위 |
| GNU | GNU is Not UNIX. FSF의 운영체제 프로젝트 |
| FSF | Free Software Foundation. 자유 소프트웨어 재단 |
| GPL / LGPL | General Public License / Lesser General Public License |
| BSD | Berkeley Software Distribution. 유닉스 계열 OS와 라이선스의 이름 |
| RAID | 여러 디스크를 묶어 성능이나 안정성을 높이는 기술 |
| `fsck` | 파일 시스템 검사·복구 도구 |
