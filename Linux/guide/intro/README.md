# [생성형 AI] 개요 및 설치

리눅스가 무엇인지 정리하고, VirtualBox 가상 머신에 Rocky Linux를 설치하는 절차를 다룬다. 문서 번호(Task ID)는 `LNX-INT-<번호>-<유형>` 형식이다. 유형은 D&O(개념), MP(절차)다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

리눅스가 무엇인지 알고 실습 환경을 만드는 입문 그룹이다. 처음 배우는 독자는 일반 개요, 배경, 설치 순서로 읽는다.

## 핵심 용어

- 커널: 하드웨어를 관리하는 운영체제의 핵심
- 배포판: 커널에 도구를 더해 배포하는 형태(예: Rocky Linux)
- GNU, 오픈 소스 라이선스: 자유로운 사용과 배포를 규정하는 조건
- 가상 머신: 실제 PC 안에서 동작하는 가상 컴퓨터(VirtualBox)

## 선수 지식

PC의 기본 사용법. 가상화를 쓰려면 CPU 가상화 지원과 디스크 여유 공간이 필요하다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-INT-001-DO | 개념 | [리눅스 개요 및 역사](about_linux.md) | 리눅스의 정의, 역사, GNU와 라이선스를 이해한다 |
| LNX-INT-002-MP | 절차 | [리눅스 설치 및 가상화](install_linux.md) | VirtualBox에 Rocky Linux 8.10을 설치하고 원격 접속한다 |
| LNX-INT-003-DO | 개념 | [리눅스 일반 개요](linuxgeneral.md) | 리눅스 학습 영역과 해당 문서의 위치를 찾는다 |

## 읽는 순서

1. LNX-INT-003-DO로 전체 학습 영역을 확인한다.
2. LNX-INT-001-DO로 리눅스의 배경을 이해한다.
3. LNX-INT-002-MP로 실습 환경을 만든다.
