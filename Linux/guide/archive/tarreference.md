## 1. tar 형식

```bash
tar [옵션] <아카이브 파일> [<파일 또는 디렉터리>...]
```

## 2. tar 옵션

| 옵션 | 뜻 | 비고 |
|---|---|---|
| `c` | 아카이브를 만든다 (create) | `x`, `t`와 함께 쓰지 않는다 |
| `x` | 아카이브를 푼다 (extract) | 같은 이름의 기존 파일을 덮어쓴다 |
| `t` | 아카이브 내용을 나열한다 (list) | 풀기 전 점검용. 원본에 없던 옵션 |
| `f` | 대상 아카이브 파일을 지정한다 | 다음에 오는 인자가 파일 이름이므로 옵션 묶음의 맨 끝에 쓴다 |
| `v` | 처리 과정을 출력한다 (verbose) | |
| `J` | xz로 압축하거나 푼다 | 확장자 `.tar.xz` |
| `j` | bzip2로 압축하거나 푼다 | 확장자 `.tar.bz2` |
| `z` | gzip으로 압축하거나 푼다 | 확장자 `.tar.gz` |
| `-C <디렉터리>` | 지정한 디렉터리로 이동한 뒤 작업한다 | 풀 위치를 지정한다. 원본에 없던 옵션 |

## 3. 압축 도구 비교

| 도구 | 확장자 | 압축 | 해제 | 원본 유지 |
|---|---|---|---|---|
| `xz` | `.xz` | `xz <파일>` | `xz -d <파일>.xz` | 기본은 원본이 사라진다. `-k`로 유지한다 |
| `gzip` | `.gz` | `gzip <파일>` | `gzip -d <파일>.gz` | 기본은 원본이 사라진다. `-k`는 gzip 1.6 이상에서 쓴다 |
| `bzip2` | `.bz2` | `bzip2 <파일>` | `bzip2 -d <파일>.bz2` | 기본은 원본이 사라진다. `-k`로 유지한다 |

일반적으로 압축률은 `xz`, `bzip2`, `gzip` 순으로 높고 속도는 반대 순서로 빠르다. 파일 종류에 따라 결과가 다르다.

## 4. 사용 예

| 목적 | 명령 |
|---|---|
| gzip 아카이브 만들기 | `tar czvf backup.tar.gz <디렉터리>` |
| xz 아카이브 만들기 | `tar cJvf backup.tar.xz <디렉터리>` |
| 내용 나열 | `tar tf backup.tar.gz` |
| 현재 위치에 풀기 | `tar xzvf backup.tar.gz` |
| 지정 위치에 풀기 | `tar xzvf backup.tar.gz -C <대상 디렉터리>` |
