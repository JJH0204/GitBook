# 파일 아카이브 및 압축

파일을 묶고(아카이브) 줄이는(압축) 작업을 절차와 옵션 표로 정리한다. 문서 번호(Task ID)는 `LNX-ARC-<번호>-<유형>` 형식이다. 유형은 MP(절차), REF(표)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-ARC-001-MP | 절차 | [아카이브 및 파일 압축 (tar, xz)](archive.md) | tar로 묶고 xz, gzip, bzip2로 압축하고 푼다 |
| LNX-ARC-002-REF | 표 | [tar·압축 명령 옵션 표](tarreference.md) | tar 옵션과 압축 도구 차이를 참조한다 |

## 읽는 순서

1. LNX-ARC-001-MP로 묶고 압축하는 절차를 따라 한다.
2. LNX-ARC-002-REF로 옵션을 찾아 쓴다.
