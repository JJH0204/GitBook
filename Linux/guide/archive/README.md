# [생성형 AI] 파일 아카이브 및 압축

파일을 묶고(아카이브) 줄이는(압축) 작업을 절차와 옵션 표로 정리한다. 문서 번호(Task ID)는 `LNX-ARC-<번호>-<유형>` 형식이다. 유형은 MP(절차), REF(표)다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

여러 파일을 하나로 묶고 용량을 줄이는 방법을 다루는 그룹이다. 백업이나 파일 전달이 필요한 독자가 절차 문서를 따라 한 뒤 옵션 표로 세부 옵션을 찾는다.

## 핵심 용어

- 아카이브: 여러 파일을 하나의 파일로 묶는 것(tar)
- 압축: 파일 크기를 줄이는 것(gzip, bzip2, xz)
- tarball: tar로 묶은 파일(예: .tar.gz)
- 압축률과 속도는 도구마다 다르며 일반적으로 서로 상충한다

## 선수 지식

기본 셸 명령(cd, ls), 파일과 디렉터리 경로.
