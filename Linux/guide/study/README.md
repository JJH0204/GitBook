# [생성형 AI] 자격증 시험 준비

리눅스마스터 2급 시험의 범위와 기출 문제를 정리한다. 문서 번호(Task ID)는 `LNX-STU-<번호>-<유형>` 형식이다. 유형은 REF(표), INS(점검)다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

리눅스마스터 2급 자격증을 준비하는 독자를 위한 그룹이다. 시험 구성을 먼저 확인하고 기출 문제로 약한 영역을 찾는다.

## 핵심 용어

- 리눅스마스터: 한국에서 시행되는 리눅스 자격 시험
- 출제 영역: 시험이 다루는 과목 범위
- 기출 문제: 과거 시험 문제. 풀이 후 틀린 영역을 본문 문서로 복습한다

## 선수 지식

리눅스 기본 명령과 파일 시스템 개념. 최신 시험 일정과 응시 조건은 공식 사이트에서 확인한다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-STU-001-REF | 표 | [리눅스마스터 2급 시험 안내](linuxmasterlevel2.md) | 시험 구성과 출제 영역을 참조한다 |
| LNX-STU-002-INS | 점검 | [리눅스마스터 기출 문제 및 해설](linuxmasterexamprep.md) | 기출 문제를 풀고 정답을 확인한다 |

## 읽는 순서

1. LNX-STU-001-REF로 시험 구성과 출제 영역을 확인한다.
2. LNX-STU-002-INS로 기출 문제를 풀고 틀린 문제를 표시한다.
3. 시험 일정, 응시료, 접수 방법은 공식 사이트에서 확인한다.
