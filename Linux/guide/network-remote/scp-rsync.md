## 1. scp

| 명령어 | 설명 | 형식 | 주요 옵션 | 예 |
|---|---|---|---|---|
| `scp` | SSH로 파일을 복사한다 | `scp [옵션] <원본> <대상>` | `-r`: 디렉터리를 재귀 복사<br>`-P <포트>`: SSH 포트(대문자)<br>`-i <키 파일>`: 사용할 개인 키<br>`-p`: 수정 시각과 권한 유지<br>`-J <점프 호스트>`: 중계 호스트 경유<br>`-q`: 진행 표시 끔 | `scp ./a.txt <사용자>@<호스트>:/tmp/`<br>`scp -r <사용자>@<호스트>:<원격 디렉터리> ./` |

{% hint style="warning" %}
CAUTION: `scp`는 같은 이름의 대상 파일을 확인 없이 덮어쓴다. 또한 중단된 전송을 이어 받지 못한다. 큰 디렉터리나 반복 동기화에는 `rsync`를 쓴다.
{% endhint %}

## 2. rsync

`rsync`는 원본과 대상을 비교해 달라진 부분만 전송한다. 원격 전송은 기본적으로 SSH를 거친다.

| 명령어 | 설명 | 형식 | 주요 옵션 | 예 |
|---|---|---|---|---|
| `rsync` | 변경된 파일만 동기화한다 | `rsync [옵션] <원본> <대상>` | `-a`: 아카이브 모드(재귀, 권한, 시각, 심볼릭 링크, 소유자 유지. 소유자 변경은 root 권한 필요)<br>`-v`: 전송 파일 목록 출력<br>`-n`(`--dry-run`): 실제 전송 없이 결과만 출력<br>`-z`: 전송 중 압축<br>`--progress`: 진행률 출력<br>`--delete`: 원본에 없는 대상 파일을 삭제<br>`-e "ssh -p <포트>"`: SSH 옵션 지정<br>`--exclude=<패턴>`: 제외 | `rsync -avn ./src/ <사용자>@<호스트>:<경로>/` |

### 끝 슬래시(/)의 의미

원본 경로 끝의 `/` 유무에 따라 결과가 다르다(실행 확인).

| 원본 | 의미 | 대상 `dst/`에 생기는 것 |
|---|---|---|
| `src/` | `src` 안의 내용 | `dst/a.txt`, `dst/sub/b.txt` |
| `src` | `src` 디렉터리 자체 | `dst/src/a.txt`, `dst/src/sub/b.txt` |

### 안전하게 동기화하는 순서

1. `-n`을 붙여 모의 실행한다: `rsync -avn <원본>/ <대상>/` → 결과: 전송될 목록만 출력되고 변경은 없다.
2. 목록이 의도와 같은지 확인한다.
3. `-n`을 빼고 실행한다.

{% hint style="danger" %}
WARNING: `--delete`는 대상에서 원본에 없는 파일을 지운다. 원본과 대상을 바꿔 쓰거나 끝 슬래시를 잘못 쓰면 필요한 데이터가 삭제된다. 반드시 `-n`으로 `deleting <파일>` 줄을 먼저 확인한다(실행으로 `deleting` 표시를 확인했다).
{% endhint %}

## 3. 비교

| 항목 | scp | rsync |
|---|---|---|
| 변경분만 전송 | 아니오 | 예 |
| 전송 전 모의 실행 | 없다 | `-n` |
| 대상 정리 | 불가 | `--delete` |
| 용도 | 파일 몇 개를 한 번 복사 | 디렉터리 백업·반복 동기화 |
