# 스위치 및 라우터 원격 접속 설정

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-NRM-004-MP |
| 목적 | 스위치와 라우터의 VTY 라인에 비밀번호를 설정하고, 스위치에 관리 IP를 할당해 원격으로 접속한다 |

| 확인 상태 | 미검증 (원본 페이지를 정리한 것이며 장비에서 실행해 확인하지 않았다) |

## 3. 안전 사항

{% hint style="danger" %}
WARNING: `telnet`은 비밀번호와 모든 명령을 평문으로 전송한다. 같은 구간의 누구나 스니핑으로 비밀번호를 얻을 수 있다. 실습망이나 격리된 관리망에서만 쓴다. 가능하면 장비에서 SSH를 지원하도록 설정한다(이 문서의 범위 밖이다).
{% endhint %}

{% hint style="danger" %}
WARNING: 원격으로 접속한 상태에서 관리 IP나 VLAN 1 인터페이스를 바꾸면 접속이 끊긴다. 변경은 콘솔로 연결해 수행하고, 변경 전 `show running-config` 출력을 저장해 설정을 백업한다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | 장치에 콘솔로 접속한다 | 장치 프롬프트(`Switch>` 또는 `Router>`)가 보인다 |
| 2 | 현재 설정을 백업한다: `show running-config` | 출력을 파일로 저장한다 |

## 5. 절차

### A. 스위치·라우터 공통: VTY 로그인 설정

1. (5-A-01) 특권 모드로 진입한다: `enable` → 결과: 프롬프트가 `#`로 바뀐다.
2. (5-A-02) 전역 설정 모드로 진입한다: `configure terminal` (`conf t`) → 결과: 프롬프트가 `(config)#`가 된다.
3. (5-A-03) VTY 라인으로 이동한다: `line vty 0 4` → 결과: 프롬프트가 `(config-line)#`가 된다.
4. (5-A-04) 접속용 비밀번호를 설정한다: `password <암호>`
5. (5-A-05) 비밀번호 인증을 켠다: `login`
6. (5-A-06) 설정 모드를 빠져나온다: `exit`
7. (5-A-07) 설정을 저장한다: `do write memory` → 결과: `[OK]`가 출력된다.

### B. 스위치 전용: 관리 IP 할당

스위치에 IP를 할당하려면 VLAN 1 인터페이스에 지정한다.

1. (5-B-01) VLAN 1 인터페이스로 이동한다: `interface vlan 1` (`int vlan 1`)
2. (5-B-02) IP 주소와 서브넷 마스크를 설정한다: `ip address <IP 주소> <서브넷 마스크>`
3. (5-B-03) 인터페이스를 활성화한다: `no shutdown` → 결과: 인터페이스가 `up`으로 바뀐다는 로그가 나온다.
4. (5-B-04) 인터페이스 설정 모드를 빠져나온다: `exit`
5. (5-B-05) 외부와 통신하도록 게이트웨이를 설정한다: `ip default-gateway <게이트웨이>`
6. (5-B-06) 설정을 저장한다: `do write memory` → 결과: `[OK]`가 출력된다.

### C. 라우터

라우터는 인터페이스 기본 설정이 되어 있으면 추가 설정 없이 게이트웨이를 통해 접속할 수 있다. 5-A만 수행한다.

### D. 원격 접속

1. (5-D-01) 관리 PC에서 접속한다: `telnet <IP 주소>` → 결과: 비밀번호 입력 프롬프트가 나온다.
2. (5-D-02) 5-A-04의 비밀번호를 입력한다. → 결과: 장치 프롬프트(`>`)가 나온다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | 스위치에서 `show ip interface brief` | VLAN 1에 관리 IP가 보인다 | `Status`와 `Protocol`이 `up`이다 |
| 2 | 관리 PC에서 `ping <IP 주소>` | 응답이 온다 | 손실률 0% |
| 3 | 관리 PC에서 `telnet <IP 주소>` | 로그인된다 | 장치 프롬프트가 나온다 |

## 7. 복구

1. (7-01) 콘솔로 접속해 전역 설정 모드로 진입한다.
2. (7-02) VTY 설정을 지운다: `line vty 0 4` 후 `no password`, `no login`
3. (7-03) 관리 IP를 지운다: `interface vlan 1` 후 `no ip address`, `shutdown`
4. (7-04) 저장한다: `do write memory`
