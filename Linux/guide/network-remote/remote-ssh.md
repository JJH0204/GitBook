# VS Code 원격 SSH 연결

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-NRM-003-MP |
| 목적 | VS Code의 Remote - SSH 확장으로 서버에 직접 접속해 파일을 편집한다 |
| 적용 대상 | VS Code, Remote - SSH 확장, SSH 서버가 동작하는 Linux 서버 |
| 소요 시간 | 약 10분 |
| 확인 상태 | 미검증 (원본 페이지를 정리한 것이며 이 문서로 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 로컬에서 수정, 커밋, 서버에서 pull을 반복하는 흐름이 번거로울 때 서버를 직접 편집하는 방법이다. 서버의 파일이 바로 바뀌므로 운영 서버에서는 주의한다.
{% endhint %}

|---|---|---|---|

{% hint style="warning" %}
CAUTION: 서버에 접속한 상태의 저장은 서버 파일을 즉시 바꾼다. 서비스가 읽는 설정 파일은 저장 전에 백업한다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | 터미널에서 SSH 접속을 시험한다: `ssh <사용자명>@<IP 주소>` | 서버 셸 프롬프트가 나온다 |
| 2 | 서버에 `tar`가 있는지 확인한다: `tar --version` | 버전이 출력된다. 없으면 `dnf install -y tar`로 설치한다 |

## 5. 절차

### A. 확장 설치와 호스트 등록

1. (5-A-01) VS Code 확장 탭에서 `Remote - SSH`를 설치한다. → 결과: 설치 완료 표시가 나온다.
2. (5-A-02) `Ctrl + Shift + P`를 눌러 커맨드 팔레트를 연다.
3. (5-A-03) `Remote-SSH: Add New SSH Host...`를 선택한다. 커맨드 팔레트에서는 이 이름을 그대로 입력한다.
4. (5-A-04) 접속 명령을 입력한다: `ssh <사용자명>@<IP 주소>` 후 Enter를 누른다.
5. (5-A-05) 저장할 SSH 설정 파일을 선택하고 Enter를 누른다. → 결과: 호스트가 추가됐다는 메시지가 나온다.

### B. 접속

1. (5-B-01) 커맨드 팔레트에서 `Remote-SSH: Connect to Host...`를 선택한다.
2. (5-B-02) 등록한 호스트를 선택한다.
3. (5-B-03) 서버의 운영체제 종류를 물으면 `Linux`를 선택한다.
4. (5-B-04) 비밀번호를 물으면 입력한다. → 결과: 새 VS Code 창이 열리고 왼쪽 아래에 `SSH: <IP 주소>`가 표시된다.

### C. 접속 실패 시 조치

1. (5-C-01) `보기 > 출력`을 열고 `Remote - SSH` 로그를 선택해 오류를 확인한다.
2. (5-C-02) 서버에 `tar`가 없다는 오류이면 서버에서 `dnf install -y tar`를 실행한다.
3. (5-C-03) 5-B를 다시 수행한다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `터미널 > 새 터미널`을 연다 | 서버의 셸이 열린다 | `hostname` 출력이 서버 이름이다 |
| 2 | `파일 > 폴더 열기`로 서버 폴더를 연다 | 서버의 파일이 탐색기에 보인다 | 서버 경로의 파일 목록이 보인다 |

## 7. 복구

1. (7-01) 연결을 끊는다: 왼쪽 아래 `SSH: <IP 주소>`를 누르고 `원격 연결 닫기`를 선택한다.
2. (7-02) 등록한 호스트를 지운다: 5-A-05에서 선택한 SSH 설정 파일(`~/.ssh/config`)에서 해당 `Host` 블록을 삭제한다.
