## 1. 변수

| 항목 | 문법 | 비고 |
|---|---|---|
| 대입 | `name="value"` | `=` 앞뒤에 공백을 두지 않는다 |
| 참조 | `"${name}"` | 값에 공백이 있을 수 있으므로 항상 큰따옴표로 감싼다 |
| 삭제 | `unset name` | |
| 환경 변수 | `export name="value"` | 자식 프로세스에 전달한다 |
| 지역 변수 | `local name="value"` | 함수 안에서만 쓴다 |
| 이름 규칙 | 영문자·숫자·`_`, 숫자로 시작할 수 없다 | 대소문자를 구분한다 |
| 자료형 | 지정하지 않는다 | 값은 모두 문자열이며 연산할 때 숫자로 해석한다 |

### 매개 변수

`./test a b c d`로 실행하면 아래처럼 대입된다.

| 변수 | 뜻 | 위 예의 값 |
|---|---|---|
| `$0` | 스크립트 이름 | `./test` |
| `$1` ~ `$9`, `${10}` | 첫 번째, 두 번째 … 인자 | `a`, `b`, `c`, `d` |
| `$#` | 인자 개수 | `4` |
| `"$@"` | 인자 전체(각각 따로 따옴표 처리) | `a b c d` |
| `$?` | 직전 명령의 종료 코드 | |

```bash
#!/bin/bash
echo "${0}: ${1}-${2}-${3}"
```

`./date.sh 2024 9 23`을 실행하면 `./date.sh: 2024-9-23`이 출력된다.

## 2. 연산

| 방법 | 문법 | 예 | 결과 |
|---|---|---|---|
| 산술 확장 (권장) | `$(( ))` | `echo $(( ${1} + ${2} ))` | 합 |
| `let` | `let result=${1}+${2}` | `echo "$result"` | 합 |
| `expr` | `` `expr ${1} + ${2}` `` 또는 `$(expr ...)` | 곱셈은 `\*`로 쓴다 | 합 |

연산자는 `+ - * / %`이다. 나눗셈은 정수 몫만 구한다. `./oper.sh 10 5`에 `expr`을 쓰면 `Plus: 15`, `Minus: 5`, `Mul: 50`, `Div: 2`, `Rem: 0`이 나온다.

## 4. 조건문

### 대괄호의 종류

| 형식 | 종류 | 특징 |
|---|---|---|
| `[ 조건 ]` | 명령(`test`와 같다), POSIX | 대괄호 안쪽에 공백이 필요하다. 변수는 큰따옴표로 감싼다. 논리 결합은 `[ ] && [ ]`로 쓴다 |
| `[[ 조건 ]]` | bash 예약어 | 변수를 따옴표로 감싸지 않아도 단어 분리가 없다. 안에서 `&&`, `||`, 패턴 비교(`==`)를 쓴다. `sh`에서는 동작하지 않는다 |
| `(( 식 ))` | 산술 평가 | 숫자 비교(`>`, `<`, `==`)를 C 언어처럼 쓴다. 변수에 `$`를 붙이지 않아도 된다 |

### 검사 연산자 (`[ ]`, `[[ ]]`)

| 연산자 | 뜻 |
|---|---|
| `-f <경로>` | 일반 파일인가 |
| `-d <경로>` | 디렉터리인가 |
| `-e <경로>` | 존재하는가 (`-a`는 같은 뜻이나 권장하지 않는다) |
| `-z <문자열>` / `-n <문자열>` | 길이가 0인가 / 0이 아닌가 |
| `<숫자> -eq <숫자>` | 같다 |
| `-ne`, `-gt`, `-ge`, `-lt`, `-le` | 같지 않다, 크다, 크거나 같다, 작다, 작거나 같다 |
| `<문자열> = <문자열>` | 문자열이 같다 |
| `-a`, `-o` (`[ ]` 안) | AND, OR. 권장하지 않는다. `[ A ] && [ B ]`를 쓴다 |

### if

```bash
#!/bin/bash
if (( ${1} > 0 )); then
        echo $(( ${1} * ${2} ))
else
        echo $(( ${1} * -1 * ${2} ))
fi
```

`./if.sh 3 10`과 `./if.sh -3 10`은 모두 `30`을 출력한다.

```bash
#!/bin/bash
if [ "${1}" -lt "${2}" ]; then
        echo "small"
elif [ "${1}" -eq "${2}" ]; then
        echo "equal"
else
        echo "big"
fi
```

`./if.sh 5 4`는 `big`, `./if.sh 5 5`는 `equal`을 출력한다.

### 파일 크기 비교

```bash
#!/bin/bash
file1="${1}"
file2="${2}"

if [ -f "$file1" ] && [ -f "$file2" ]; then
        size1=$(stat -c%s "$file1")
        size2=$(stat -c%s "$file2")
        if [ "$size1" -gt 5 ] && [ "$size2" -lt 5 ]; then
                echo "True"
        else
                echo "False"
        fi
else
        echo "두 인자가 모두 일반 파일이어야 한다" >&2
        exit 1
fi
```

`stat -c%s <파일>`은 파일 크기를 바이트로 출력한다.

### case

```bash
#!/bin/bash
case "${1}" in
        "Linux")   echo "Linux" ;;
        "Windows") echo "Windows" ;;
        "Mac")     echo "MacOS" ;;
        *)         echo "unknown" ;;
esac
```

`./case.sh Mac`은 `MacOS`를 출력한다. `*)`는 어느 패턴과도 맞지 않을 때 실행한다.

## 5. 반복문

| 형식 | 예 | 출력 |
|---|---|---|
| C 스타일 `for` | `for ((i=0; i<4; i++)); do echo $i; done` | `0` `1` `2` `3` (줄마다) |
| 리스트 `for` | `for x in 1 2 3 4 5; do printf "%s" "$x"; done` | `12345` |
| 배열 `for` | `num=(1 2 3 4 5); for x in "${num[@]}"; do printf "%s" "$x"; done` | `12345` |
| `seq` | `for y in $(seq 1 5); do printf "%s" "$y"; done` | `12345` |
| 중괄호 범위 | `for z in {1..9}; do printf "%s" "$z"; done` | `123456789` |
| `while` | 조건이 참인 동안 반복한다 | 아래 예 |
| `until` | 조건이 거짓인 동안 반복한다 | 아래 예 |

`break`는 반복을 끝내고, `continue`는 다음 반복으로 넘어간다.

```bash
count=1
while [ "${count}" -le 5 ]; do
        printf "%s" "${count}"
        count=$(( count + 1 ))
done
# 출력: 12345

count=1
until [ "${count}" -gt 5 ]; do
        printf "%s" "${count}"
        count=$(( count + 1 ))
done
# 출력: 12345
```

## 6. 배열, 함수, 종료 코드

### 배열

| 작업 | 문법 | 예 (`array=("Linux" "Windows" "macOS" "Unix")`) |
|---|---|---|
| 선언 | `array=(값1 값2 ...)` | |
| 요소 참조 | `${array[<번호>]}` (번호는 0부터) | `${array[1]}` → `Windows` |
| 전체 출력 | `${array[@]}` 또는 `${array[*]}` | |
| 길이 | `${#array[@]}` | `4` |
| 일부 잘라내기 | `${array[@]:<시작>:<개수>}` | `${array[@]:1:3}` → `Windows macOS Unix` |
| 요소 삭제 | `unset 'array[3]'` | 번호 3 요소가 빠지고 다른 번호는 그대로다 |
| 배열 삭제 | `unset array` | |
| 번호 다시 매기기 | `array=("${array[@]}")` | 삭제 후 번호의 빈틈을 없앤다 |

배열은 1차원만 지원한다. 값이 `<제외할 값>`인 요소를 빼려면 반복문으로 새 배열을 만든다.

```bash
array=(1 2 3 4 5 6)
remove=3
new=()
for v in "${array[@]}"; do
        if [ "$v" != "$remove" ]; then
                new+=("$v")
        fi
done
echo "${new[@]}"
# 출력: 1 2 4 5 6
```

### 연관 배열 (딕셔너리, bash 4 이상)

```bash
declare -A map=([hello]='world' [long]='long string')
declare -p map
echo "map[hello]=${map[hello]}"
```

`declare -p`의 출력 순서는 정해져 있지 않다. 마지막 줄은 `map[hello]=world`다.

### 함수

```bash
#!/bin/bash
function _fun1()
{
        echo "func1"
        echo "${1}. ${2}"
}

function _main()
{
        echo "func_main()"
        _fun1 "hello" "world"
}

_main
```

출력은 `func_main()`, `func1`, `hello. world` 순서다. 함수는 호출하기 전에 정의해야 한다. 함수 안의 `$1`, `$2`는 함수에 넘긴 인자다.

### 쉘 종료 코드

| 코드 | 뜻 |
|:---:|---|
| 0 | 성공 |
| 1 | 일반적인 오류 |
| 2 | 쉘 내장 명령 사용 오류 |
| 126 | 명령을 찾았으나 실행할 수 없음 (실행 권한 없음) |
| 127 | 명령을 찾을 수 없음 |
| 128 | `exit`에 잘못된 인수를 줌 |
| 128+n | 시그널 n으로 종료 (예: 137 = `kill -9`) |
| 130 | Ctrl+C로 종료 (128+2) |

`echo $?`로 직전 명령의 종료 코드를 확인한다. 스크립트는 `exit <코드>`로 종료 코드를 정한다.

### 명령 치환

```bash
echo "I'm in $(pwd)"      # 백틱 `pwd`도 같은 뜻이나 $( )를 권장한다
echo "$(date)"
```

## 7. 정정한 내용

| 원본 | 정정 | 이유 |
|---|---|---|
| 셔뱅 줄에 주석을 붙임 | 주석을 다음 줄로 이동 | 같은 줄 주석은 인터프리터 인수로 넘어간다 |
| 환경 변수 예가 `:wq`와 출력을 한 코드 블록에 섞음 | 실행 순서를 [LNX-SCR-003-MP](shell-script-practice.md)로 옮김 | 스크립트 안의 `export`는 부모 쉘에 영향이 없다 |
| 파일 크기 예: `if "$size1" -gt 5`, `if \| "$size2"` | `[ ]`로 감싸고 구조를 바로잡음 | 문법 오류 |
| `let file1=${1}` | `file1="${1}"` | `let`은 산술용이다. 경로 문자열에 쓰면 오류다 |
| 배열 삭제 `${array[@]/$remove}` | 반복문으로 새 배열 생성 | 이 형식은 값을 지우는 것이 아니라 문자열의 일치 부분을 지운다. 빈 요소가 남고 `13`은 `1`이 된다 |
| 배열 순회 `for x in "${num[0]}"` | `"${num[@]}"` | 첫 요소만 순회했다 |
| `${array[@]:1:3}` 출력 예가 요소 4개 | 배열에 4개 요소를 둠 | 원본 배열은 3개라 예시 출력과 맞지 않았다 |
| `MaxOS` | `macOS` | 오타 |
| `until [ ${count} -le 10 ]` | `until [ "${count}" -gt 5 ]` | 앞선 `while` 뒤 `count`가 6이라 조건이 처음부터 참이어서 한 번도 실행되지 않았다 |
| 종료 코드 126 "스크립트 실행 x" | "실행 권한 없음" | 뜻을 명확히 함 |
