# cron 시간 문법 참조

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-SCR-008-REF |
| 유형 | REF (문법·표) |
| 목적 | crontab 줄의 시간 표기, 특수 문자, 예약어, 관련 명령을 찾아본다 |
| 확인 상태 | 미검증 (원본 페이지와 `crontab(5)` 문서 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 줄 형식

```
분 시 일 월 요일 <명령>              사용자 crontab (crontab -e)
분 시 일 월 요일 <사용자> <명령>     /etc/crontab, /etc/cron.d/*
```

| 필드 | 허용 값 |
|---|---|
| 분 | 0~59 |
| 시 | 0~23 |
| 일 | 1~31 |
| 월 | 1~12 또는 `jan`~`dec` |
| 요일 | 0~7 (0과 7 = 일요일, 1 = 월요일 … 6 = 토요일) 또는 `sun`~`sat` |

## 2. 특수 문자

| 문자 | 뜻 | 예 | 해석 |
|---|---|---|---|
| `*` | 모든 값 | `* * * * *` | 매분 |
| `,` | 나열 | `0,30 * * * *` | 매시 0분과 30분 |
| `-` | 범위 | `0 9-17 * * *` | 9시부터 17시까지 매시 정각 |
| `/` | 간격 | `*/10 * * * *` | 10분마다(0, 10, 20, 30, 40, 50분) |
| `%` | 줄바꿈으로 해석됨 | `date +\%F` | 명령 안에서는 `\%`로 쓴다 |

일과 요일 필드를 둘 다 `*`가 아닌 값으로 쓰면 둘 중 하나만 맞아도 실행한다(OR). 예를 들어 `0 0 1 * 1`은 매월 1일과 매주 월요일에 실행한다.

## 3. 예약어

`crontab(5)`(cronie)는 시간 필드 5개 대신 아래 예약어를 지원한다.

| 예약어 | 같은 뜻 |
|---|---|
| `@reboot` | 부팅 후 한 번 |
| `@hourly` | `0 * * * *` |
| `@daily` (`@midnight`) | `0 0 * * *` |
| `@weekly` | `0 0 * * 0` |
| `@monthly` | `0 0 1 * *` |
| `@yearly` (`@annually`) | `0 0 1 1 *` |

## 4. 예

| 줄 | 해석 |
|---|---|
| `0 0 1 * * /home/test.sh` | 매달 1일 00시 00분에 실행 |
| `5 3 1 1 * /home/test.sh` | 매년 1월 1일 03시 05분에 실행 |
| `*/5 * * * * <명령>` | 5분마다 |
| `30 2 * * 1-5 <명령>` | 평일(월~금) 02시 30분 |
| `0 */2 * * * <명령>` | 2시간마다 정각(0, 2, 4 … 22시) |
| `@reboot <명령>` | 부팅 후 한 번 |

시스템 crontab에서는 시간 필드 뒤에 사용자를 쓴다. 예: `0 0 1 * * root /home/test.sh`는 root 권한으로 실행한다.

### 줄 합치기 예

같은 명령을 10분 간격으로 여러 줄에 쓴 것은 `*/10` 한 줄로 합칠 수 있다.

```
10 * * * * root <명령>
20 * * * * root <명령>
30 * * * * root <명령>
40 * * * * root <명령>
50 * * * * root <명령>
00 * * * * root <명령>
```

위 여섯 줄은 아래 한 줄과 같다.

```
*/10 * * * * root <명령>
```

{% hint style="info" %}
NOTE: 원본 예시는 명령이 `run-parts /etc/cron.monthly`였다. 월간 디렉터리를 10분마다 실행하면 의도와 다르므로 `<명령>`으로 일반화했다.
{% endhint %}

## 5. 관련 명령

| 명령 | 동작 |
|---|---|
| `crontab -e` | 현재 사용자의 crontab을 편집한다 |
| `crontab -l` | 현재 사용자의 crontab을 출력한다 |
| `crontab -r` | 현재 사용자의 crontab을 확인 없이 전부 삭제한다 |
| `crontab -u <사용자> -l` | 다른 사용자의 crontab을 출력한다(root만) |
| `systemctl status crond` | cron 서비스 상태를 본다(Debian 계열은 `cron`) |
| `at <시각>` | 한 번만 실행할 작업을 예약한다(`atd` 필요) |
| `atq`, `atrm <번호>` | `at` 예약 목록을 보고 삭제한다 |

{% hint style="danger" %}
WARNING: `crontab -r`은 확인 없이 crontab 전체를 지운다. `-e`와 `-r`은 키가 가까워 잘못 입력하기 쉽다. 지우기 전에 `crontab -l > <백업 파일>`로 저장해 둔다.
{% endhint %}
