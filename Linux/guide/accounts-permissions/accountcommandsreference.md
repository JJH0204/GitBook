## 1. 사용자 명령

### useradd

사용자를 만든다. 형식: `useradd [옵션] <사용자명>`. 절차는 LNX-ACC-002-MP를 따른다.

| 옵션 | 뜻 |
|---|---|
| `-s <셸>` | 로그인 셸 지정 |
| `-d <경로>` | 홈 디렉터리 지정 |
| `-m` | 홈 디렉터리 생성 (RHEL 계열은 기본 생성) |
| `-e <YYYY-MM-DD>` | 계정 만료일 지정 |
| `-f <일수>` | 비밀번호 만료 후 계정이 비활성화되기까지의 유예 일수 |
| `-c "<설명>"` | 설명(주석) |
| `-G <그룹,...>` | 보조 그룹 지정 |
| `-g <그룹>` | 기본 그룹 지정 |
| `-u <UID>` | UID 지정 |

### usermod

사용자 정보를 바꾼다. 형식: `usermod [옵션] <사용자명>`. 절차는 LNX-ACC-004-MP를 따른다.

| 옵션 | 뜻 |
|---|---|
| `-d <경로>` | 홈 디렉터리 변경. `-m`을 함께 쓰면 기존 내용을 옮긴다 |
| `-g <그룹>` | 기본 그룹 변경 |
| `-G <그룹,...>` | 보조 그룹 목록을 지정한 값으로 **교체**한다 |
| `-aG <그룹,...>` | 보조 그룹을 기존 목록에 **추가**한다 |
| `-l <새 이름>` | 로그인 이름 변경 |
| `-L` / `-U` | 계정 잠금 / 잠금 해제 |

### userdel

계정을 삭제한다. 형식: `userdel [옵션] <사용자명>`.

| 옵션 | 뜻 |
|---|---|
| (없음) | `/etc/passwd`, `/etc/shadow`, `/etc/group`에서 계정을 지운다. 홈 디렉터리는 남는다 |
| `-r` | 홈 디렉터리와 메일 스풀도 지운다 |

### passwd

비밀번호를 설정하거나 바꾼다. 형식: `passwd [옵션] [<사용자명>]`.

| 옵션 | 뜻 |
|---|---|
| (없음) | 비밀번호를 설정한다 |
| `-S` | 상태를 표시한다 |
| `-l` | 계정을 잠근다 (shadow 비밀번호 필드 앞에 `!`를 붙인다) |
| `-u` | 잠금을 해제한다 |
| `-d` | 비밀번호를 지운다. 비밀번호 없이 로그인할 수 있게 되므로 쓰지 않는다 |

`passwd -S`의 상태 코드는 아래와 같다.

| 코드 | 뜻 |
|---|---|
| `PS` | 비밀번호가 설정돼 있다 |
| `NP` | 비밀번호가 없다 |
| `LK` | 잠겨 있다 |

### chage

비밀번호 만료 정보를 바꾼다. 형식: `chage [옵션] <사용자명>`. 절차는 LNX-ACC-013-MP를 따른다.

| 옵션 | 뜻 |
|---|---|
| `-l` | 현재 만료 정보를 표시한다 |
| `-d <값>` | 마지막 변경일. `0`이면 다음 로그인 때 변경을 강제한다. `YYYY-MM-DD`도 가능 |
| `-m <일수>` | 최소 사용 일수 |
| `-M <일수>` | 최대 사용 일수 |
| `-W <일수>` | 만료 경고 시작 일수 |
| `-I <일수>` | 만료 후 비활성화까지 유예 일수 |
| `-E <YYYY-MM-DD>` | 계정 만료일 |

### su

현재 로그인을 유지한 채 다른 사용자로 전환한다. switch user의 줄임말이다.

| 형식 | 뜻 |
|---|---|
| `su <사용자명>` | 환경 변수를 유지한 채 전환한다 |
| `su - <사용자명>` | 대상 사용자의 로그인 셸 환경으로 전환한다 (`-l`, `--login`과 같다) |
| `su -` | root로 전환한다 |

## 2. 그룹 명령

절차는 LNX-ACC-007-MP를 따른다.

| 명령 | 옵션 | 뜻 |
|---|---|---|
| `groupadd [-g <GID>] <그룹>` | `-g` | 그룹을 만든다. 결과는 `/etc/group`에서 확인한다 |
| `groupmod [옵션] <그룹>` | `-n <새 이름>` | 그룹 이름을 바꾼다 |
| | `-g <GID>` | GID를 바꾼다 |
| `groupdel <그룹>` | | 그룹을 삭제한다. 다른 사용자의 기본 그룹은 삭제할 수 없다 |
| `gpasswd [옵션] <그룹>` | (없음) | 그룹 비밀번호를 설정한다 |
| | `-a <사용자명>` | 구성원을 추가한다 |
| | `-d <사용자명>` | 구성원을 제거한다 |
