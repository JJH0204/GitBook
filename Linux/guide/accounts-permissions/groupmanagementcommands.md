# 그룹 관리 명령어 (groupadd)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-ACC-007-MP |
| 목적 | `groupadd`, `groupmod`, `gpasswd`, `groupdel`로 그룹을 만들고 구성원을 관리하고 삭제한다 |
| 적용 대상 | RHEL 계열 Linux (Rocky, AlmaLinux, CentOS Stream), root 권한 필요 |
| 소요 시간 | 약 10분 |
| 확인 상태 | 미검증 (원본 페이지와 man 문서 지식을 정리한 것이며 이 문서로 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 3. 안전 사항

{% hint style="danger" %}
WARNING: `groupdel`은 그 그룹이 소유한 파일을 정리하지 않는다. 삭제 후 해당 파일의 그룹은 번호(GID)만 남는다. 삭제 전에 `find / -group <그룹> 2>/dev/null`로 소유 파일을 확인한다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 어떤 사용자의 기본 그룹은 `groupdel`로 삭제할 수 없다. 오류가 나면 그 사용자를 먼저 삭제하거나 기본 그룹을 바꾼다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | root 권한을 확인한다: `id -u` | 출력이 `0`이다 |
| 2 | 만들 그룹 이름이 없는지 확인한다: `getent group <그룹>` | 출력이 없다 |

## 5. 절차

### A. 그룹 생성

1. (5-A-01) 그룹을 만든다: `groupadd <그룹>` → 결과: 출력 없이 끝난다. GID를 지정하려면 `groupadd -g <GID> <그룹>`을 쓴다.
2. (5-A-02) 등록을 확인한다: `getent group <그룹>` → 결과: `<그룹>:x:<GID>:` 한 줄이 출력된다.

### B. 구성원 추가와 제거

1. (5-B-01) 구성원을 추가한다: `gpasswd -a <사용자명> <그룹>` → 결과: `Adding user <사용자명> to group <그룹>`이 출력된다.
2. (5-B-02) 구성원을 확인한다: `getent group <그룹>` → 결과: 4번째 필드에 `<사용자명>`이 있다.
3. (5-B-03) 구성원을 제거한다(필요할 때만): `gpasswd -d <사용자명> <그룹>` → 결과: `Removing user <사용자명> from group <그룹>`이 출력된다.

{% hint style="info" %}
NOTE: 이미 로그인한 사용자에게는 그룹 변경이 바로 적용되지 않는다. 사용자가 다시 로그인해야 한다.
{% endhint %}

### C. 그룹 이름·GID 변경

1. (5-C-01) 이름을 바꾼다: `groupmod -n <새 그룹> <기존 그룹>` → 결과: 출력 없이 끝난다.
2. (5-C-02) GID를 바꾼다(필요할 때만): `groupmod -g <새 GID> <그룹>` → 결과: 출력 없이 끝난다. 이 그룹 소유 파일의 GID는 자동으로 바뀌지 않는다.

### D. 그룹 삭제

1. (5-D-01) 소유 파일을 확인한다: `find / -group <그룹> 2>/dev/null` → 결과: 목록이 출력된다. 목록이 있으면 `chgrp`로 다른 그룹에 넘긴다.
2. (5-D-02) 그룹을 삭제한다: `groupdel <그룹>` → 결과: 출력 없이 끝난다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `getent group <그룹>` (생성 후) | 그룹 한 줄이 나온다 | GID가 출력된다 |
| 2 | `id <사용자명>` (추가 후, 재로그인 뒤) | 그룹이 목록에 있다 | `groups=`에 `<그룹>`이 있다 |
| 3 | `getent group <그룹>` (삭제 후) | 출력이 없다 | 빈 출력 |

## 7. 복구

1. (7-01) 삭제한 그룹을 다시 만든다: `groupadd -g <기존 GID> <그룹>` → 결과: 기존 GID로 다시 등록된다. 기존 GID는 작업 전에 `getent group <그룹>`으로 적어 둔다.
2. (7-02) 구성원 목록은 5-B-01을 반복해 다시 추가한다.
