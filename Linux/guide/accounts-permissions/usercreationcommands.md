# 사용자 생성 명령어 (useradd)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-ACC-002-MP |
| 목적 | `useradd`로 사용자 계정을 만들고 `passwd`로 비밀번호를 설정한 뒤 `su`로 전환을 확인한다 |
| 적용 대상 | RHEL 계열 Linux (Rocky, AlmaLinux, CentOS Stream), root 권한 필요 |
| 소요 시간 | 약 5분 |
| 확인 상태 | 미검증 (원본 페이지와 man 문서 지식을 정리한 것이며 이 문서로 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 이 문서는 실습용 가상 환경을 전제로 한다. 운영 서버에서는 조직의 계정 생성 규정을 먼저 따른다.
{% endhint %}

| 번호 | 이름 | 사양 | 비고 |

## 3. 안전 사항

{% hint style="danger" %}
WARNING: `passwd -d <사용자명>`은 비밀번호를 지워 비밀번호 없이 로그인할 수 있게 한다. 이 문서의 절차에서는 쓰지 않는다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 비밀번호는 명령줄에 직접 쓰지 않는다. `passwd`가 묻는 프롬프트에 입력한다. 명령줄에 쓴 값은 셸 기록에 남는다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | root 권한을 확인한다: `id -u` | 출력이 `0`이다 (`sudo` 사용 시 `sudo id -u`) |
| 2 | 만들 계정이 없는지 확인한다: `id <사용자명>` | `no such user` 메시지가 나온다 |

## 5. 절차

### A. 계정 생성

1. (5-A-01) 계정을 만든다: `useradd <사용자명>` → 결과: 출력 없이 끝난다.
2. (5-A-02) 옵션이 필요하면 함께 지정한다. 예: `useradd -s /bin/bash -c "<설명>" -G <보조 그룹> <사용자명>` → 결과: 출력 없이 끝난다. 옵션 의미는 LNX-ACC-009-REF를 따른다.
3. (5-A-03) 등록을 확인한다: `grep <사용자명> /etc/passwd` → 결과: 해당 계정의 한 줄이 출력된다. 홈 디렉터리 필드는 `/home/<사용자명>`이다.

{% hint style="info" %}
NOTE: 홈 디렉터리 생성은 배포판마다 다르다. RHEL 계열은 `/etc/login.defs`의 `CREATE_HOME`이 기본 `yes`라 자동 생성한다. 생성되지 않으면 `-m` 옵션을 붙인다.
{% endhint %}

### B. 비밀번호 설정

1. (5-B-01) 비밀번호를 설정한다: `passwd <사용자명>` → 결과: `New password:` 프롬프트가 나온다.
2. (5-B-02) 비밀번호를 입력한다. 화면에는 표시되지 않는다.
3. (5-B-03) 같은 비밀번호를 다시 입력한다 → 결과: `passwd: all authentication tokens updated successfully.`가 나온다.
4. (5-B-04) 상태를 확인한다: `passwd -S <사용자명>` → 결과: 두 번째 필드가 `PS`다.

### C. 계정 전환 확인

1. (5-C-01) 계정으로 전환한다: `su - <사용자명>` → 결과: 비밀번호 입력을 요구한다.
2. (5-C-02) 5-B-02의 비밀번호를 입력한다 → 결과: 프롬프트의 사용자 이름이 바뀐다.
3. (5-C-03) 현재 계정을 확인한다: `whoami` → 결과: `<사용자명>`이 출력된다.
4. (5-C-04) 원래 계정으로 돌아온다: `exit` → 결과: 이전 프롬프트로 돌아온다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `id <사용자명>` | UID, GID, 그룹이 출력된다 | UID가 1000 이상이다 |
| 2 | `ls -ld /home/<사용자명>` | 홈 디렉터리가 있다 | 소유자가 `<사용자명>`이다 |
| 3 | `passwd -S <사용자명>` | 상태가 출력된다 | 두 번째 필드가 `PS`다 |
