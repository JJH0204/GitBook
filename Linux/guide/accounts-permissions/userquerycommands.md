# 사용자 조회 명령어 (who, w, id)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-ACC-003-REF |
| 유형 | REF (명령어 표) |
| 목적 | 로그인한 사용자와 계정의 UID·그룹을 조회하는 명령을 참조한다 |
| 적용 대상 | Linux 전반. 일반 사용자 권한으로 실행할 수 있다 |
| 확인 상태 | 미검증 (man 문서 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 로그인 사용자 조회

| 명령 | 출력 | 예 |
|---|---|---|
| `users` | 현재 로그인한 사용자 이름만 | `users` |
| `who` | 사용자, 터미널, 로그인 시각 | `who` |
| `w` | `who` 내용에 로그인 시간, 실행 중인 명령, 시스템 부하 | `w` |

세 명령은 `users` < `who` < `w` 순으로 정보가 많다.

## 2. 계정·그룹 조회

| 명령 | 출력 | 예 |
|---|---|---|
| `id [<사용자명>]` | UID, GID, 소속 그룹. 인자가 없으면 현재 사용자 | `id root` |
| `groups [<사용자명>]` | 소속 그룹 이름. 인자가 없으면 현재 사용자 | `groups <사용자명>` |

* `id root`의 UID는 0이다. RHEL 계열의 일반 계정 UID는 1000부터다.
* 시스템의 전체 그룹 목록은 `/etc/group`에서 확인한다. 구조는 LNX-ACC-006-DO를 따른다.

## 3. 사용 예

```
$ id <사용자명>
uid=1000(<사용자명>) gid=1000(<사용자명>) groups=1000(<사용자명>),10(wheel)
```

`groups=` 뒤의 첫 항목은 기본 그룹이고 나머지는 보조 그룹이다. 위 출력의 `wheel`은 RHEL 계열에서 `sudo` 사용을 허용하는 그룹이다.
