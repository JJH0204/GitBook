## 1. 목적

그룹은 여러 사용자에게 같은 파일 접근 권한을 한 번에 주는 단위다. `/etc/group`은 그룹 이름, 번호, 구성원을 저장한다.

## 2. 구성 요소

| 번호 | 이름 | 위치 | 역할 |
|---|---|---|---|
| 1 | `/etc/group` | `/etc` | 그룹 이름, GID, 구성원 목록을 저장한다 |
| 2 | `/etc/gshadow` | `/etc` | 그룹 비밀번호와 그룹 관리자 정보를 저장한다 |
| 3 | `/etc/skel` | `/etc` | 새 사용자의 홈 디렉터리에 복사할 파일 템플릿이다 |

### /etc/group 한 줄의 구조

```
<그룹이름>:x:1000:<구성원1>,<구성원2>
```

| 필드 | 값 | 뜻 |
|---|---|---|
| 1 | `<그룹이름>` | 그룹 이름 |
| 2 | `x` | 그룹 비밀번호 자리. 실제 값은 `/etc/gshadow`에 있다 |
| 3 | `1000` | GID(그룹 번호) |
| 4 | (공백 또는 쉼표 목록) | 이 그룹을 보조 그룹으로 쓰는 사용자. 기본 그룹으로 쓰는 사용자는 여기에 나오지 않고 `/etc/passwd`의 4번째 필드에 GID로 기록된다 |

## 3. 동작 원리

1. `useradd <사용자명>`을 실행한다. RHEL 계열은 사용자 이름과 같은 이름의 그룹을 함께 만든다.
2. 새 그룹이 `/etc/group`에 한 줄 추가되고 사용자의 기본 GID가 된다.
3. `-m` 옵션이 적용되면(RHEL 계열은 기본 적용) `/etc/skel`의 내용이 새 홈 디렉터리에 복사된다.
4. 보조 그룹은 `usermod -aG` 또는 `gpasswd -a`로 구성원 목록에 추가한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| GID | Group ID. 그룹 번호 |
| 기본 그룹 | 새로 만든 파일의 그룹이 되는 그룹. `/etc/passwd` 4번째 필드 |
| 보조 그룹 | 기본 그룹 외에 추가로 속한 그룹 |
| `/etc/skel` | skeleton. 홈 디렉터리 초기 파일 템플릿 |
