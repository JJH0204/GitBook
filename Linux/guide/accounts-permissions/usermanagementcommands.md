# 사용자 수정 및 삭제 명령어

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-ACC-004-MP |
| 목적 | `usermod`로 계정 정보를 바꾸고 `userdel`로 계정을 삭제한다 |
| 적용 대상 | RHEL 계열 Linux (Rocky, AlmaLinux, CentOS Stream), root 권한 필요 |
| 소요 시간 | 약 10분 |
| 확인 상태 | 미검증 (원본 페이지와 man 문서 지식을 정리한 것이며 이 문서로 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 이 절차는 실습용 가상 환경을 전제로 한다. 원본에 `usermode`로 적혀 있던 명령 이름은 `usermod`가 맞다.
{% endhint %}

## 2. 필요 장비와 자재

| 번호 | 이름 | 사양 | 비고 |
|---|---|---|---|
| 1 | Linux 터미널 | RHEL 계열 | |
| 2 | root 권한 | root 로그인 또는 `sudo` | `usermod`, `userdel`은 root만 실행할 수 있다 |
| 3 | 대상 계정 | 로그아웃 상태이고 실행 중인 프로세스가 없다 | `pgrep -u <사용자명>`의 출력이 비어 있어야 한다 |

## 3. 안전 사항

{% hint style="danger" %}
WARNING: `userdel -r`은 홈 디렉터리와 메일 스풀을 함께 삭제한다. 삭제한 파일은 복구할 수 없다. 5-B-02에서 백업을 먼저 만든다.
{% endhint %}

{% hint style="danger" %}
WARNING: `usermod -G <그룹>`은 `-a` 없이 쓰면 기존 보조 그룹을 모두 지우고 지정한 그룹으로 바꾼다. `wheel` 그룹이 빠지면 `sudo`를 쓸 수 없게 될 수 있다. 그룹을 추가할 때는 `-aG`를 쓴다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 계정 이름이나 홈 디렉터리를 바꾸는 중에는 그 계정이 로그인해 있으면 안 된다. 로그인 중이면 `usermod`가 오류를 낸다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | root 권한을 확인한다: `id -u` | 출력이 `0`이다 |
| 2 | 대상 계정이 있는지 확인한다: `id <사용자명>` | UID와 그룹이 출력된다 |
| 3 | 로그인 여부를 확인한다: `who` | 대상 계정이 목록에 없다 |

## 5. 절차

### A. 계정 정보 수정

1. (5-A-01) 보조 그룹을 추가한다: `usermod -aG <그룹> <사용자명>` → 결과: 출력 없이 끝난다.
2. (5-A-02) 기본 그룹을 바꾼다(필요할 때만): `usermod -g <그룹> <사용자명>` → 결과: 출력 없이 끝난다.
3. (5-A-03) 홈 디렉터리를 옮긴다(필요할 때만): `usermod -d <새 홈 경로> -m <사용자명>` → 결과: 기존 홈 내용이 새 경로로 이동한다.
4. (5-A-04) 로그인 이름을 바꾼다(필요할 때만): `usermod -l <새 이름> <기존 이름>` → 결과: 출력 없이 끝난다. 홈 디렉터리 이름과 그룹 이름은 바뀌지 않는다.
5. (5-A-05) 결과를 확인한다: `id <사용자명>` (이름을 바꿨다면 새 이름) → 결과: 바꾼 그룹이 반영돼 있다.

### B. 계정 삭제

1. (5-B-01) 삭제 대상의 프로세스가 없는지 확인한다: `pgrep -u <사용자명>` → 결과: 출력이 없다.
2. (5-B-02) 홈 디렉터리를 백업한다: `tar czf /root/<사용자명>-home.tar.gz /home/<사용자명>` → 결과: `/root/<사용자명>-home.tar.gz` 파일이 생긴다.
3. (5-B-03) 계정을 삭제한다. 홈 디렉터리를 남기려면 `userdel <사용자명>`, 함께 지우려면 `userdel -r <사용자명>`을 실행한다 → 결과: 출력 없이 끝난다.
4. (5-B-04) 삭제를 확인한다: `id <사용자명>` → 결과: `no such user`가 나온다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `id <사용자명>` (수정 후) | 바꾼 그룹이나 이름이 보인다 | 5-A에서 지정한 값과 같다 |
| 2 | `grep <사용자명> /etc/passwd` (삭제 후) | 출력이 없다 | 빈 출력 |
| 3 | `ls -d /home/<사용자명>` (`-r` 사용 시) | 디렉터리가 없다 | `No such file or directory` |

## 7. 복구

1. (7-01) 그룹을 잘못 바꿨다면 `usermod -G <원래 그룹 목록, 쉼표로 구분> <사용자명>`으로 되돌린다. 원래 목록은 작업 전 `id <사용자명>` 출력에서 확인한다.
2. (7-02) 삭제한 계정은 LNX-ACC-002-MP로 다시 만든다. 같은 UID로 만들려면 `useradd -u <UID> <사용자명>`을 쓴다.
3. (7-03) 홈 디렉터리를 복원한다: `tar xzf /root/<사용자명>-home.tar.gz -C /` 후 `chown -R <사용자명>: /home/<사용자명>`.
