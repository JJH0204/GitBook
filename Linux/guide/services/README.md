# [생성형 AI] 리눅스 서버 서비스

서버에서 동작하는 서비스의 개념과 보안 관리를 다룬다. 문서 번호(Task ID)는 `LNX-SVC-<번호>-<유형>` 형식이다. 유형은 D&O(개념), MP(절차)다. 이 폴더의 명령은 실습용 가상 환경(RHEL 계열 9)을 전제로 한다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

서버에서 동작하는 서비스의 개념과 보안 관리를 다루는 그룹이다. 서버 하드닝을 처음 하는 독자는 서비스 점검 절차를 먼저 따르고, 이어 NIS 같은 개념을 읽는다.

## 핵심 용어

- 서비스: 백그라운드에서 동작하는 프로세스(데몬)
- systemctl: 서비스를 시작, 중지, 비활성화하는 명령
- 공격 표면: 외부에서 접근 가능한 서비스와 포트의 총합. 불필요한 서비스를 줄이면 작아진다
- cron, at: 예약 작업 도구
- NIS: 계정 정보 등을 네트워크로 공유하는 서비스

## 선수 지식

systemctl 기본 사용, 계정과 권한 개념.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-SVC-001-DO | 개념 | [네트워크 정보 서비스 (NIS)](nis.md) | NIS의 구조와 보안 한계를 이해한다 |
| LNX-SVC-002-MP | 절차 | [불필요한 서비스 관리 및 비활성화](service-management.md) | 불필요한 서비스, autofs, cron, at를 점검하고 줄인다 |

## 읽는 순서

1. LNX-SVC-002-MP로 서버에서 동작하는 서비스를 점검하고 줄인다.
2. LNX-SVC-001-DO로 NIS를 쓰는 환경의 구조와 위험을 이해한다.
