## 1. 목적

프로그램은 시작할 때 환경 변수(environment variable)라는 이름-값 목록을 부모 프로세스에서 물려받는다. 명령을 어디서 찾을지(`PATH`), 홈 디렉터리(`HOME`), 언어 설정(`LANG`) 같은 값이 여기에 있다. 이 문서는 변수가 어떻게 전달되고 어디에 영구 설정하는지 설명한다.

## 2. 구성 요소

| 번호 | 구성 요소 | 역할 | 확인 명령 |
|---|---|---|---|
| 1 | 셸 변수 | 현재 셸 안에서만 보이는 변수. 자식 프로세스에 전달되지 않는다 | `X=1` 후 `sh -c 'echo "[$X]"'` → `[]` |
| 2 | 환경 변수 | `export`한 변수. 이후 실행하는 자식 프로세스에 전달된다 | `export X` 후 `sh -c 'echo "[$X]"'` → `[1]` |
| 3 | `PATH` | 명령 이름을 찾을 디렉터리 목록. `:`로 구분하며 앞에 있는 디렉터리가 먼저 검색된다 | `echo $PATH` |
| 4 | `HOME` | 현재 사용자의 홈 디렉터리 | `printenv HOME` |

| 명령 | 용도 |
|---|---|
| `env`, `printenv` | 환경 변수를 모두 출력한다. `printenv <이름>`은 값 하나를 출력한다 |
| `export <이름>=<값>` | 변수를 설정하고 환경 변수로 내보낸다 |
| `unset <이름>` | 변수를 지운다 |
| `type <명령>` | 명령이 셸 내장인지, 어느 경로의 파일인지 보여 준다 |

## 3. 동작 원리

1. 사용자가 `<명령>`을 입력한다.
2. 셸이 `PATH`의 디렉터리를 앞에서부터 차례로 검색해 같은 이름의 실행 파일을 찾는다. 내장 명령(`cd` 등)은 검색 없이 셸이 처리한다.
3. 셸이 자식 프로세스를 만들고, `export`한 변수만 복사해 준다.
4. 자식이 바꾼 변수는 부모 셸에 돌아오지 않는다.

### 영구 설정 위치(bash)

| 파일 | 읽히는 때 |
|---|---|
| `/etc/profile` | 로그인 셸 시작 시, 모든 사용자 |
| `~/.bash_profile`, `~/.bash_login`, `~/.profile` | 로그인 셸 시작 시, 이 순서로 처음 있는 파일 하나만 읽는다 |
| `~/.bashrc` | 로그인이 아닌 대화형 셸 시작 시 |

로그인 셸 여부는 `shopt login_shell`로 확인한다. 로그인 셸에서 `~/.bashrc`가 읽히게 하려면 `~/.bash_profile` 또는 `~/.profile`이 `~/.bashrc`를 불러오도록 되어 있어야 한다. 배포판 기본 파일이 대부분 그렇게 되어 있다. 변경한 설정은 새 셸을 열거나 `source ~/.bashrc`로 적용한다.

{% hint style="warning" %}
CAUTION: `PATH`를 `export PATH=<값>`으로 통째로 바꾸면 기존 항목이 사라져 `ls` 같은 명령을 찾지 못한다. 항목을 추가할 때는 `export PATH="$PATH:<디렉터리>"`처럼 기존 값을 포함한다. 현재 디렉터리(`.`)나 빈 항목을 `PATH` 앞쪽에 넣으면 의도하지 않은 파일이 실행될 수 있으므로 넣지 않는다.
{% endhint %}
