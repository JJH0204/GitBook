## 1. 파일과 종료 (마지막 행 모드)

| 명령 | 역할 |
|---|---|
| `vi <파일>` | 파일을 연다 (셸에서 입력) |
| `:w` | 저장한다 |
| `:q` | 종료한다. 변경이 있으면 거부한다 |
| `:wq`, `ZZ` | 저장하고 종료한다 |
| `:q!` | 저장하지 않고 강제 종료한다. 변경을 버린다 |

## 2. 삽입 모드 진입

| 키 | 역할 |
|---|---|
| `i` | 커서 앞에서 입력을 시작한다 (insert) |
| `a` | 커서 뒤에서 입력을 시작한다 (append) |
| `A` | 줄 끝에서 입력을 시작한다 |
| `Esc` | 삽입 모드에서 명령 모드로 돌아간다 |

## 3. 이동

| 키 | 역할 |
|---|---|
| `h`, `j`, `k`, `l` | 왼쪽, 아래, 위, 오른쪽으로 이동한다 |
| `gg` | 파일 맨 처음으로 이동한다 |
| `G` | 파일 맨 끝으로 이동한다 |
| `<번호>G`, `:<번호>` | 지정한 줄로 이동한다. 예: `40G`, `:10` |

## 4. 삭제·복사·붙여넣기

| 키 | 역할 |
|---|---|
| `x` | 커서 위치의 글자를 지운다 |
| `dw` | 단어를 지운다 |
| `dd` | 커서가 있는 줄을 지운다 |
| `<개수>dd` | 커서 줄부터 아래로 <개수>줄을 지운다. 예: `6dd` |
| `yy` | 커서 줄을 복사한다 |
| `<개수>yy` | 커서 줄부터 <개수>줄을 복사한다. 예: `5yy` |
| `p` | 커서 줄 아래에 붙여넣는다 |
| `P` | 커서 줄 위에 붙여넣는다 |
| `u` | 직전 변경을 취소한다 |

## 5. 검색과 치환

| 명령 | 역할 |
|---|---|
| `/<문자열>` | 아래 방향으로 검색한다 |
| `n` | 같은 방향으로 다음 결과로 이동한다 |
| `N` | 반대 방향으로 이동한다 |
| `:%s/<찾을 문자열>/<바꿀 문자열>/g` | 파일 전체에서 모두 바꾼다 |
| `:[범위]s/<패턴>/<치환>/[플래그]` | 범위를 지정해 바꾼다 |
