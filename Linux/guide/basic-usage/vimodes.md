## 1. 목적

`vi`는 유닉스·리눅스의 기본 텍스트 편집기다. 키 입력의 뜻이 **현재 모드**에 따라 달라진다. 같은 `i` 키가 명령 모드에서는 "삽입 모드로 전환"이고 삽입 모드에서는 글자 `i` 입력이다. 모드를 이해하면 대부분의 초보자 실수를 피한다.

## 2. 구성 요소

| 번호 | 모드 | 진입 방법 | 하는 일 | 나가는 방법 |
|---|---|---|---|---|
| 1 | 명령 모드 (Command mode) | `vi`를 열면 시작한다. 다른 모드에서 `Esc` | 커서 이동, 줄 삭제(`dd`), 줄 복사(`yy`) 같은 명령을 입력한다 | `i`, `a` 등으로 삽입 모드, `:`로 마지막 행 모드 |
| 2 | 삽입 모드 (Insert mode) | 명령 모드에서 `i`, `a`, `A` 등 | 글자를 입력한다 | `Esc` |
| 3 | 마지막 행 모드 (Last-line mode) | 명령 모드에서 `:` | 저장(`:w`), 종료(`:q`), 치환(`:%s/old/new/g`) 같은 명령을 입력한다 | `Enter`로 실행하거나 `Esc`로 취소 |

## 3. 동작 원리

```
          i, a, A          :
명령 모드 ----------> 삽입 모드      명령 모드 ----------> 마지막 행 모드
   ^      <----------                  ^      <----------
   |          Esc                      |      Enter 또는 Esc
```

1. `vi`를 열면 명령 모드로 시작한다.
2. 글자를 입력하려면 `i`로 삽입 모드에 들어간다. 화면 아래에 `-- INSERT --`가 보이면 삽입 모드다(vim 기준).
3. 입력을 마치면 `Esc`로 명령 모드로 돌아온다.
4. 저장·종료는 `:`를 입력해 마지막 행 모드에서 한다.
5. 어느 모드인지 모르겠으면 `Esc`를 두세 번 눌러 명령 모드로 돌아간다.

{% hint style="info" %}
NOTE: RHEL 계열에서 `vi`는 `vim-minimal` 패키지인 경우가 많다. 이 경우 일부 기능이 없고 표시 방식이 다를 수 있다. 미검증.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| vi | visual editor. 화면 편집기 |
| vim | Vi IMproved. vi 기능을 확장한 편집기 |
| 모드(mode) | 같은 키 입력이 다른 뜻을 갖게 하는 입력 상태 |
| `Esc` | 명령 모드로 돌아가는 키 |
