# 기본 사용법

리눅스를 처음 쓸 때 필요한 디렉터리 구조와 `vi` 편집기를 정리한다. 문서 번호(Task ID)는 `LNX-BAS-<번호>-<유형>` 형식이다. 유형은 D&O(개념), MP(절차), REF(표)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-BAS-001-DO | 개념 | [리눅스 기본 디렉터리 구조](linuxbasicdirectorydescription.md) | 주요 디렉터리의 위치와 역할을 이해한다 |
| LNX-BAS-002-DO | 개념 | [vi 편집 모드](vimodes.md) | 명령 모드와 삽입 모드의 차이를 이해한다 |
| LNX-BAS-003-MP | 절차 | [vi 편집기 사용법](vi.md) | 파일을 열고 편집해 저장하고 종료한다 |
| LNX-BAS-004-REF | 표 | [vi 명령 키 표](vireference.md) | 이동, 편집, 검색, 치환 키를 참조한다 |

## 읽는 순서

1. LNX-BAS-001-DO로 디렉터리 구조를 이해한다.
2. LNX-BAS-002-DO로 vi의 모드를 이해한다.
3. LNX-BAS-003-MP로 파일을 편집해 저장하고 종료한다.
4. LNX-BAS-004-REF로 키를 찾아 쓴다.
