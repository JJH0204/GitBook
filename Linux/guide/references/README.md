# [생성형 AI] 참고자료 및 링크

이 폴더는 리눅스 가이드의 참고 자료 그룹 소개다. 파일과 링크의 구조를 이해하는 데 필요한 보조 노트를 모았다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

링크 개념과 빌드 과정을 보충하는 참고 노트 그룹이다. 리눅스 파일 시스템이나 C 언어 빌드를 공부하다 막힌 독자가 필요한 항목만 골라 읽는다.

## 핵심 용어

- 하드 링크: 같은 inode를 가리키는 또 다른 이름
- 심볼릭 링크: 다른 경로를 가리키는 별도의 파일
- 링커: 목적 파일과 라이브러리를 이어 실행 파일을 만드는 도구
- 목적 파일: 컴파일 결과로 나오는 .o 파일

## 선수 지식

기본 셸 명령(ls, ln), C 언어 컴파일의 개략적 흐름.
