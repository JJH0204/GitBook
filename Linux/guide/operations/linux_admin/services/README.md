# 관리 서비스

리눅스 관리 서비스를 다루는 그룹이다. 문서 번호(Task ID)는 `LNX-LAS-<번호>-<유형>` 형식이며, 번호는 `security`, `system_mgmt`와 함께 센다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-LAS-004-MP | 절차 | [[생성형 AI] systemd 서비스 관리 (systemctl)](systemctl-service.md) | 서비스 상태를 확인하고 시작, 중지하고 자동 시작을 설정한다 |

제목이 `[생성형 AI]`로 시작하는 문서는 생성형 AI가 작성한 초안이며 사람 검토 전이다.

| 문서 | 용도 |
|---|---|

| [시스템 디스크 관리](../system_mgmt/README.md) | 디스크 파티션 관리 |
