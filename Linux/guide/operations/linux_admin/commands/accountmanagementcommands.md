## 1. 명령 표

| 명령어 | 설명 | 형식 | 옵션 | 예 |
|---|---|---|---|---|
| `alias` | 명령어에 별칭을 할당한다 | `alias <별칭>='<명령어>'` | 없음 | `alias c=cal` |
| `unalias` | 별칭을 해제한다 | `unalias [옵션] <별칭>` | `-a`: 설정된 모든 별칭을 해제한다 | `unalias c`<br>`unalias -a` |
| `which` | 명령어의 실행 파일 경로를 출력한다 | `which <명령어>` | 없음 | `which cal` |

## 2. 동작 설명

| 항목 | 설명 |
|---|---|
| `alias`만 입력 | 현재 셸에 설정된 별칭 목록을 출력한다 |
| 별칭의 유효 범위 | 현재 셸에서만 유효하다. 영구히 쓰려면 `~/.bashrc`에 적는다 |
| `which`의 검색 범위 | 환경변수 `$PATH`에 나열된 디렉터리에서만 찾는다 |
| `$PATH` | 실행 파일이 있는 디렉터리 위치 목록을 저장한 환경변수다 |

{% hint style="info" %}
NOTE: `which`는 셸 내장 명령이나 별칭을 실행 파일로 찾지 못할 수 있다. 이 설명은 미검증이다.
{% endhint %}
