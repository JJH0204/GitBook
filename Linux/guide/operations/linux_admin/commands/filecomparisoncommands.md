# 파일 비교 명령어 (diff, cmp, comm)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LNX-LAC-006-REF |
| 유형 | REF (명령 표) |
| 목적 | 두 파일을 행·바이트·줄 단위로 비교하는 명령을 참조한다 |
| 확인 상태 | 미검증 (원본 페이지와 diffutils 문서 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 명령 표

| 명령어 | 설명 | 형식 | 옵션 | 예 |
|---|---|---|---|---|
| `diff` | 두 파일을 행 단위로 비교해 다른 부분을 출력한다 | `diff [옵션] <파일1> <파일2>` | `-s`: 두 파일이 같을 때 같다고 알린다<br>`-i`: 대소문자를 구별하지 않는다<br>`-b`: 공백 문자 개수의 차이를 무시한다<br>`-w`: 모든 공백을 무시하고 비교한다<br>`-e`: `ed` 편집기용 스크립트를 만든다 | `diff -s <파일1> <파일2>` |
| `cmp` | 두 파일을 바이트 단위로 비교한다 | `cmp [옵션] <파일1> <파일2>` | `-b`: 다른 바이트를 출력한다<br>`-l`: 다른 모든 바이트의 위치와 값을 출력한다 | `cmp -b <파일1> <파일2>` |
| `comm` | 정렬된 두 파일을 줄 단위로 비교한다 | `comm [옵션] <파일1> <파일2>` | `-1`: 파일1에만 있는 줄을 출력에서 뺀다<br>`-2`: 파일2에만 있는 줄을 출력에서 뺀다<br>`-3`: 두 파일에 공통인 줄을 출력에서 뺀다 | `comm -12 <파일1> <파일2>` |

## 2. 사용 시 주의

| 항목 | 설명 |
|---|---|
| `comm`의 입력 | 두 파일이 정렬돼 있어야 정확하다. 정렬돼 있지 않으면 `sort <파일> > <정렬된 파일>`로 정렬한 뒤 비교한다 |
| `comm`의 출력 | 1열은 파일1에만 있는 줄, 2열은 파일2에만 있는 줄, 3열은 공통인 줄이다 |
| `comm -12` | 1열과 2열을 모두 빼므로 공통인 줄만 남는다 |
| `cmp`의 출력 | 같은 파일이면 아무것도 출력하지 않고, 다르면 처음 다른 위치를 알린다 |

{% hint style="warning" %}
CAUTION: `sort <파일> > <정렬된 파일>`의 `>`는 대상 파일을 덮어쓴다. 원본 파일 이름을 대상으로 쓰지 않는다.
{% endhint %}

{% hint style="info" %}
NOTE: 원본 예의 `diff -s bbb /etc/passwd`처럼 시스템 파일을 쓰지 않고 `<파일1>`, `<파일2>` 표기로 바꿨다. 옵션 설명은 GNU diffutils, coreutils 기준이며 미검증이다.
{% endhint %}
