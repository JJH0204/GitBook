## 1. 명령 표

| 명령어 | 설명 | 형식 | 옵션 | 예 |
|---|---|---|---|---|
| `pwd` | 현재 작업 디렉터리를 출력한다 | `pwd` | 없음 | `pwd` |
| `cd` | 디렉터리를 이동한다. 인자가 없으면 홈 디렉터리로 이동한다 | `cd <디렉터리 경로>` | 없음 | `cd /home/<사용자명>`<br>`cd ..` |
| `mkdir` | 새 디렉터리를 만든다 | `mkdir [옵션] <디렉터리 이름>` | `-p`: 경로 중 없는 디렉터리를 차례로 만든다 | `mkdir -p <상위>/<하위>` |
| `rmdir` | 비어 있는 디렉터리를 삭제한다 | `rmdir <디렉터리 이름>` | `-p`: 상위 디렉터리도 비면 함께 삭제한다 | `rmdir <디렉터리 이름>` |

## 2. 내용이 있는 디렉터리 삭제

`rmdir`은 비어 있는 디렉터리만 지운다. 내용이 있는 디렉터리는 `rm -r`을 쓴다([파일 조작 명령어](filecommands.md), LNX-LAC-007-REF).

{% hint style="danger" %}
WARNING: `rm -r <디렉터리>`는 하위 파일과 디렉터리를 모두 삭제하며 휴지통이 없어 복구할 수 없다. 실행 전에 `pwd`와 `ls`로 대상 경로를 확인한다.
{% endhint %}

{% hint style="info" %}
NOTE: 원본은 `rmdir`에 `-r`(하위 포함 삭제)과 `-f`(강제 삭제) 옵션이 있다고 적었다. `rmdir`에는 이 옵션이 없다. 해당 기능은 `rm -r`, `rm -f`의 것이므로 정정했다. 원본 예 `rmdir -f`도 삭제했고, 개인 경로 예(`/home/jaeho`)는 `<사용자명>`으로 일반화했다. 미검증이다.
{% endhint %}
