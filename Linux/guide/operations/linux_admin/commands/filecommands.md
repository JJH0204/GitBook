{% endhint %}

## 1. 명령 표

| 명령어 | 설명 | 형식 | 옵션 | 예 |
|---|---|---|---|---|
| `ls` | 디렉터리의 하위 디렉터리와 파일 목록을 출력한다 | `ls [옵션] [<디렉터리>]` | `-a`: 숨김 파일을 포함한다<br>`-l`: 세부 정보를 목록으로 출력한다<br>`-r`: 역순으로 출력한다<br>`-R`: 하위 경로와 그 안의 파일까지 출력한다 | `ls -al <디렉터리>` |
| `cp` | 파일 또는 디렉터리를 복사한다 | `cp [옵션] <원본> <대상>` | `-b`: 대상 파일이 있으면 백업 파일을 만든다<br>`-f`: 대상 파일을 열 수 없으면 지우고 다시 복사한다<br>`-i`: 대상 파일이 있으면 덮어쓸지 묻는다<br>`-r`: 하위 디렉터리까지 복사한다 | `cp -i <원본> <대상 디렉터리>` |
| `rm` | 파일 또는 디렉터리를 삭제한다 | `rm [옵션] <파일 또는 디렉터리>` | `-f`: 묻지 않고 삭제하며 없는 파일의 오류를 무시한다<br>`-i`: 삭제 전에 묻는다<br>`-r`: 하위 디렉터리까지 삭제한다 | `rm -i <파일>`<br>`rm -r <디렉터리>` |
| `mv` | 파일 또는 디렉터리를 이동하거나 이름을 바꾼다 | `mv [옵션] <원본> <대상>` | `-b`: 대상 파일의 백업을 만든다<br>`-f`: 덮어쓰기 전에 묻지 않는다<br>`-v`: 이동 과정을 출력한다 | `mv -v <원본> <대상 디렉터리>` |
| `touch` | 크기가 0바이트인 빈 파일을 만들거나 파일의 시간 정보를 현재 시각으로 바꾼다 | `touch [옵션] <파일>` | `-a`: 접근 시간만 바꾼다<br>`-m`: 수정 시간만 바꾼다<br>`-c`: 파일이 없어도 새로 만들지 않는다<br>`-r <기준 파일> <대상 파일>`: 기준 파일의 시간을 대상 파일에 적용한다 | `touch <파일>`<br>`touch -r <기준 파일> <대상 파일>` |
| `file` | 파일의 종류를 출력한다 | `file [옵션] <파일>` | `-b`: 파일 이름 없이 유형만 출력한다<br>`-f <목록 파일>`: 목록 파일에 적힌 파일들을 대상으로 한다<br>`-z`: 압축된 파일의 내용을 들여다본다<br>`-i`: MIME 형식으로 출력한다 | `file -b <파일>` |
| `find` | 조건에 맞는 파일을 찾아 경로를 출력한다 | `find <시작 경로> [조건]` | `-name`: 이름 기준<br>`-user`: 소유자 기준<br>`-perm`: 권한 기준<br>`-type`: 파일 유형 기준<br>`-exec <명령> {} \;`: 찾은 파일마다 명령을 실행한다 | `find <시작 경로> -name "<이름>"` |

## 2. rm 사용 예

| 목적 | 명령 |
|---|---|
| 확인하며 파일 삭제 | `rm -i <파일>` |
| 디렉터리와 하위 내용 삭제 (확인 없음) | `rm -rf <디렉터리>` |

{% hint style="danger" %}
WARNING: `rm -rf`는 확인 없이 하위 내용을 모두 삭제한다. 경로에 변수를 쓸 때 변수가 비어 있으면 의도하지 않은 경로가 지워질 수 있다. 처음에는 `rm -ri <디렉터리>`로 확인하며 지운다.
{% endhint %}

## 3. find 사용 예

| 목적 | 명령 |
|---|---|
| 이름으로 찾기 | `find <시작 경로> -name "<이름>"` |
| 찾은 `.swp` 파일 삭제 | `find <시작 경로> -name "*.swp" -exec rm {} \;` |

{% hint style="danger" %}
WARNING: `-exec rm`은 찾은 파일을 바로 지운다. 먼저 `-exec rm` 없이 `find <시작 경로> -name "*.swp"`만 실행해 목록을 확인한 뒤에 삭제한다. 원본 예의 시작 경로 `/`는 시스템 전체를 검색하므로 쓰지 않는다.
{% endhint %}

시간 조건(`-mtime`, `-mmin`)은 [find 시간 옵션 및 파일 속성](../../../commands/find_time.md)(LNX-CMD-006-REF)을 본다.

{% hint style="info" %}
NOTE: 원본은 `cp -f`를 "덮어쓴다"로, `touch -c`를 "시스템 현재 시간으로 수정"으로 적었다. 실제 `cp -f`는 대상을 열 수 없을 때 지우고 다시 복사하는 옵션이고, `touch -c`는 파일이 없을 때 새로 만들지 않는 옵션이다. 정정했다. `/etc/passwd` 같은 시스템 파일을 쓴 원본 예와 `/ect/passwd` 오타 예는 `<파일>` 표기로 바꿨다. 미검증이다.
{% endhint %}
