## 1. 목적

파이썬 가상환경은 프로젝트마다 독립된 파이썬 실행 환경을 만든다. 프로젝트별로 라이브러리 버전을 다르게 쓰거나 파이썬 버전을 다르게 쓸 수 있다. "커널"이라는 말은 문맥에 따라 두 가지를 가리키므로 구분해서 쓴다.

## 2. 구성 요소

| 번호 | 이름 | 역할 | 비고 |
|---|---|---|---|
| 1 | 가상환경 (virtual environment) | 프로젝트 전용 파이썬 실행 파일과 라이브러리 설치 위치를 따로 둔다 | `python3 -m venv <디렉터리>`로 만든다 |
| 2 | 운영체제 커널 | 프로세스, 메모리, 장치 등 하드웨어 자원을 관리하는 운영체제의 핵심이다 | 리눅스 커널. `uname -r`로 버전을 확인한다 |
| 3 | Jupyter 커널 | 노트북에서 작성한 코드를 실행하는 프로세스다. 어떤 파이썬 환경을 쓸지는 커널 설정이 정한다 | 가상환경을 노트북에서 쓰려면 그 환경을 커널로 등록한다 |

## 3. 동작 원리

1. 가상환경을 만들면 지정한 디렉터리에 파이썬 실행 파일 링크와 `site-packages` 디렉터리가 생긴다.
2. 활성화(`source <디렉터리>/bin/activate`)하면 셸의 `PATH` 앞에 그 디렉터리의 `bin`이 붙는다.
3. 이후 `python`, `pip`는 그 가상환경의 것이 실행되고 패키지는 그 가상환경 안에만 설치된다.
4. 노트북에서 같은 환경을 쓰려면 가상환경 안에서 `ipykernel`을 설치하고 커널로 등록한다.
5. 노트북은 등록된 커널 이름을 골라 그 가상환경의 파이썬으로 코드를 실행한다.

| 목적 | 명령 |
|---|---|
| 가상환경 만들기 | `python3 -m venv <디렉터리>` |
| 활성화 (Linux/macOS) | `source <디렉터리>/bin/activate` |
| 비활성화 | `deactivate` |
| 커널로 등록 | `python -m ipykernel install --user --name <커널 이름>` |
| 등록된 커널 목록 | `jupyter kernelspec list` |

## 4. 약어와 용어

| 용어 | 뜻 |
|---|---|
| venv | 파이썬 표준 라이브러리의 가상환경 모듈 |
| `PATH` | 셸이 실행 파일을 찾는 디렉터리 목록을 담은 환경변수 |
| `site-packages` | 파이썬이 설치한 패키지를 두는 디렉터리 |
| ipykernel | Jupyter가 파이썬 코드를 실행할 때 쓰는 커널 패키지 |
