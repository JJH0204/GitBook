# [생성형 AI] 시스템 디스크 관리

디스크를 식별하고 파티션을 만들고 지우는 문서를 모은 그룹이다. 문서 번호(Task ID)는 `LNX-LAS-<번호>-<유형>` 형식이다. 유형은 REF(표), MP(절차)다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

디스크를 식별하고 파티션을 다루는 그룹이다. 서버에 디스크를 추가하는 관리자가 명령과 제한을 먼저 확인한 뒤 실제 작업을 수행한다.

## 핵심 용어

- 파티션: 디스크를 논리적으로 나눈 영역
- fdisk: 파티션 테이블을 편집하는 명령
- MBR, GPT: 파티션 테이블 방식. 제한(디스크 크기, 파티션 수)이 다르다
- 장치 이름: /dev/sda처럼 디스크를 가리키는 파일

## 선수 지식

기본 셸 명령, root 권한 사용법. 파티션 삭제는 데이터 손실을 일으키므로 대상 디스크를 반드시 확인한다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-LAS-002-REF | 표 | [fdisk 파티션 관리 유틸리티](fdisk.md) | fdisk 명령과 파티션 제한을 참조한다 |
| LNX-LAS-003-MP | 절차 | [fdisk 파티션 생성과 삭제](fdisk-partition.md) | 대상 디스크를 확인하고 파티션을 만들고 지운다 |

## 읽는 순서

1. LNX-LAS-002-REF로 명령과 제한을 확인한다.
2. LNX-LAS-003-MP로 실제 작업을 수행한다.
