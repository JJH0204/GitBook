# 시스템 디스크 관리

디스크를 식별하고 파티션을 만들고 지우는 문서를 모은 그룹이다. 문서 번호(Task ID)는 `LNX-LAS-<번호>-<유형>` 형식이다. 유형은 REF(표), MP(절차)다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-LAS-002-REF | 표 | [fdisk 파티션 관리 유틸리티](fdisk.md) | fdisk 명령과 파티션 제한을 참조한다 |
| LNX-LAS-003-MP | 절차 | [fdisk 파티션 생성과 삭제](fdisk-partition.md) | 대상 디스크를 확인하고 파티션을 만들고 지운다 |

## 읽는 순서

1. LNX-LAS-002-REF로 명령과 제한을 확인한다.
2. LNX-LAS-003-MP로 실제 작업을 수행한다.
