# [생성형 AI] 리눅스 관리자 가이드

리눅스 관리자가 서버를 운영할 때 쓰는 명령어, 접근 제어, 서비스, 디스크 관리 문서를 모은 폴더이다. 아래 표에서 목적에 맞는 하위 폴더를 고른다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

관리자 업무를 영역별로 묶은 폴더다. 처음 서버를 맡은 관리자는 기본 명령어에서 시작하고, 접근 제어, 서비스, 디스크 관리 순으로 필요에 맞춰 이동한다.

## 핵심 용어

- ACL: 파일이나 네트워크 접근을 항목별로 허용 또는 거부하는 목록
- 서비스 관리: systemctl로 서비스를 제어하는 업무
- 파티션: 디스크를 나눈 영역
- 관리자 권한(root): 시스템 전체를 변경할 수 있는 권한

## 선수 지식

리눅스 기본 사용법, 셸과 파일 시스템 개념.
