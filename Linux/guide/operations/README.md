# 시스템 운영 및 관리

리눅스 서버 운영에 필요한 출제 범위, 패키지 관리 도구(RPM, DNF), 라우팅 프로토콜 재분배 절차, 관리자 가이드 묶음을 다룬다. 문서 번호(Task ID)는 `LNX-OPS-<번호>-<유형>` 형식이다. 유형은 REF(표·명령), MP(절차)다. 관리자 가이드 하위 폴더의 문서는 각 폴더 소개를 따른다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| LNX-OPS-001-REF | 표 | [리눅스 운영 관리 출제 기준](linuxopsandmanagement.md) | 운영 관리 시험 범위를 확인한다 |
| LNX-OPS-002-REF | 표 | [패키지 관리 도구 (RPM, DNF)](linuxpackagemanagementtool.md) | `rpm`, `dnf` 명령과 패치 갱신 명령을 찾는다 |
| LNX-OPS-003-MP | 절차 | [라우팅 프로토콜 재분배](redistribution.md) | RIP와 EIGRP 사이에 경로를 재분배한다 |
| (소개) | 목차 | [리눅스 관리자 가이드](linux_admin/README.md) | 기본 명령어, 접근 제어, 서비스, 디스크 관리 하위 문서를 찾는다 |

## 읽는 순서

1. LNX-OPS-001-REF로 운영 관리 범위를 확인한다.
2. LNX-OPS-002-REF로 패키지 설치·삭제·갱신 명령을 익힌다.
3. 관리자 가이드에서 필요한 하위 폴더를 고른다.
4. 라우터 연동이 필요하면 LNX-OPS-003-MP를 수행한다.
