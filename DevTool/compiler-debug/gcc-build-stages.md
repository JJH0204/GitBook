## 1. 목적

`gcc main.c -o app` 한 줄은 네 단계를 연달아 실행한다. 단계를 나눠 보면 오류 메시지가 어느 단계에서 나왔는지 구분할 수 있다. 오류 진단은 DEV-CMP-007-TS를 따른다.

## 2. 구성 요소

| 번호 | 단계 | gcc 옵션 | 입력 → 출력 | 하는 일 |
|---|---|---|---|---|
| 1 | 전처리 | `-E` | `.c` → `.i` | `#include`를 펼치고 `#define`, `#ifdef`를 처리한다 |
| 2 | 컴파일 | `-S` | `.c` → `.s` | C 코드를 어셈블리로 바꾼다 |
| 3 | 어셈블 | `-c` | `.c` → `.o` | 어셈블리를 기계어 목적 파일로 바꾼다 |
| 4 | 링크 | (옵션 없이 `.o`를 넘긴다) | `.o` → 실행 파일 | 목적 파일과 라이브러리를 이어 붙인다 |

## 3. 동작 원리

### 3.1 단계별 실행

```bash
gcc -E main.c -o main.i      # 전처리. 헤더가 펼쳐져 수백 줄이 된다
gcc -S main.c                # main.s 생성 (어셈블리 텍스트)
gcc -c main.c util.c         # main.o, util.o 생성
gcc main.o util.o -o app     # 링크
./app                        # 5 출력
```

`main.i`의 끝부분에는 `#include "util.h"`가 펼쳐진 선언과 `main` 본문이 남는다. 전처리 결과에서는 주석이 제거된다.

### 3.2 목적 파일의 심볼

`nm main.o`와 `nm util.o` 출력이다.

```text
                 U add          <- main.o: add는 정의가 없고 외부에서 와야 한다(Undefined)
0000000000000000 T main         <- main.o: main을 정의했다(Text 영역)
                 U printf
0000000000000000 T add          <- util.o: add를 정의했다
```

링커는 `U`(미정의)인 심볼을 다른 `.o`나 라이브러리의 `T`(정의)와 짝지어 준다. 짝이 없으면 `undefined reference`, 정의가 둘이면 `multiple definition` 오류가 난다.

### 3.3 자주 쓰는 옵션

| 옵션 | 뜻 | 확인한 동작 |
|---|---|---|
| `-o <파일>` | 출력 파일 이름 | |
| `-Wall -Wextra` | 흔한 실수에 대한 경고를 켠다 | 초기화하지 않은 변수 사용 시 `-Wuninitialized` 경고가 나왔다 |
| `-g` | 디버거용 디버그 정보를 넣는다 | 같은 소스에서 실행 파일이 16016바이트(옵션 없음)에서 17728바이트로 커졌고 `.debug_info` 섹션이 생겼다 |
| `-O0`, `-O2` | 최적화 수준 | 최적화하면 디버거에서 줄 이동이 소스와 다르게 보일 수 있다 |
| `-D<이름>` | 매크로를 정의한다 | `#ifdef DEBUG` 구간이 `-DDEBUG`를 줄 때만 실행됐다(`dbg` 출력) |
| `-I<폴더>` | 헤더 검색 폴더를 추가한다 | |
| `-fsanitize=address` | 실행 중 메모리 오류를 검출한다 | 힙 버퍼 범위를 넘어 쓰면 `heap-buffer-overflow`를 보고했다 |

{% hint style="info" %}
NOTE: GDB로 디버깅할 파일은 `-g`로 컴파일한다(DEV-CMP-003-MP). `-g` 없이 만든 실행 파일은 줄 번호와 변수 이름이 보이지 않는다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 목적 파일 (object file) | 컴파일은 끝났지만 링크 전인 `.o` 파일 |
| 링커 (linker) | 목적 파일을 이어 실행 파일을 만드는 도구. gcc가 내부에서 호출한다 |
| 심볼 (symbol) | 함수·전역 변수의 이름 |
| 번역 단위 | 전처리 후 하나의 `.c` 파일이 이루는 컴파일 단위 |
