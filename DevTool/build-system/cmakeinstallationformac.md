## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | 터미널을 연다 | 프롬프트가 나타난다 |
| 2 | Homebrew가 있는지 확인한다: `brew --version` | 버전 번호가 출력된다 |

## 5. 절차

### A. 설치

1. (5-A-01) 터미널에 아래 명령을 입력한다.

```bash
brew install cmake
```

→ 결과: 설치가 오류 없이 끝나고 프롬프트로 돌아온다.

### B. 설치 여부 확인

1. (5-B-01) 터미널에 아래 명령을 입력한다.

```bash
cmake --version
```

→ 결과: `cmake version <버전>` 형태로 버전이 출력된다.

## 6. 기능 확인

## 7. 복구

1. (7-01) CMake를 제거한다: `brew uninstall cmake` → 결과: 제거가 오류 없이 끝나고 `cmake --version`이 `command not found`를 출력한다.
