## 1. 문법 표

| 요소 | 입력 | 결과 |
|---|---|---|
| 제목 | `# 제목1`, `## 제목2`, `### 제목3` | 제목 1~3단계. `#` 뒤에 공백을 둔다 |
| 굵게 | `**굵게**` | **굵게** |
| 기울임 | `*기울임*` | *기울임* |
| 취소선 | `~~취소선~~` | ~~취소선~~ |
| 글머리 목록 | `* 항목` 또는 `- 항목` | 점 목록 |
| 번호 목록 | `1. 항목` | 번호 목록 |
| 하위 목록 | 앞에 공백 2칸 또는 4칸 | 한 단계 들여쓴 목록 |
| 작업 목록 | `- [ ] 할 일`, `- [x] 한 일` | 체크 상자 목록 |
| 인라인 코드 | `` `code` `` | `code` |
| 코드 블록 | 줄 앞뒤에 ```` ``` ````. 시작 줄 뒤에 언어 이름(`bash`, `python`)을 적는다 | 색이 입혀진 코드 |
| 링크 | `[표시 글자](https://example.com)` | 글자를 누르면 이동 |
| 이미지 | `![설명](이미지 파일 경로)` | 이미지 표시 |
| 인용 | `> 인용문` | 인용 블록 |
| 구분선 | `---` 또는 `***` | 가로선 |
| 표 | 아래 예 참고 | 표 |
| 줄바꿈 | 줄 끝에 공백 2칸 또는 `\` | 같은 문단 안 줄바꿈 |
| 기호 그대로 쓰기 | 앞에 `\` (예: `\*`) | `*` 글자 |

### 표 입력 예

```
| 이름 | 역할 |
|---|---|
| gdb | 디버거 |
| gcc | 컴파일러 |
```

### 링크 규칙

* 같은 저장소의 다른 문서는 상대 경로로 쓴다. 예: `[GDB](../compiler-debug/gdb.md)`.
* 외부 주소는 `https://`로 시작하는 전체 주소로 쓴다.
* `file:///` 같은 로컬 경로는 쓰지 않는다. 공개 문서에서 열리지 않는다.

### 이모지

이모지는 글자를 그대로 붙여 넣는다. `:smile:` 같은 단축 코드는 GitBook에서 동작하지 않을 수 있다. (미검증)
