# RunInTerminalSetup

{% stepper %}
{% step %}
### 설정 열기

메뉴바에서 `Code` > `Preferences` > `Settings` 선택
{% endstep %}

{% step %}
### 설정에서 검색

검색창에 `'run in terminal'` 검색
{% endstep %}

{% step %}
### 설정 활성화

`Code-runner: Run In Terminal` 활성화
{% endstep %}
{% endstepper %}

{% hint style="info" %}
맥북의 터미널에서 코드 동작의 결과를 확인할 수 있게 됩니다.
{% endhint %}
