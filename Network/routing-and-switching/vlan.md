## 1. 목적

VLAN(Virtual LAN)은 물리적으로 하나인 스위치 네트워크를 논리적으로 여러 네트워크로 나누는 기능이다. 같은 VLAN 안의 장치끼리만 브로드캐스트를 주고받는다. VLAN은 스위치의 기본 기능이다.

서로 다른 VLAN 사이의 통신은 라우터나 L3 스위치가 라우팅해야 한다.

## 2. 구성 요소

### 2.1 VLAN 구성 방식

| 번호 | 방식 | 기준 | 특징 |
|---|---|---|---|
| 1 | Switch Based (포트 기반) | 스위치 포트 | 포트마다 VLAN을 지정한다. 가장 널리 쓴다. 자세한 내용은 [Switch Based](../../Linux/guide/network-remote/switch-based.md) 문서를 본다 |
| 2 | MAC Based | 장치의 MAC 주소 | 이동이 잦은 단말(노트북 등)에 같은 VLAN을 고정해 줄 수 있다 |
| 3 | IP Based | IP 대역 | IP 변경이나 DHCP 환경에서는 관리 부담이 크다 |
| 4 | Policy Based | 사용자, 역할, 트래픽 유형 등 정책 | 세밀하게 제어할 수 있으나 관리가 복잡하다 |

{% hint style="info" %}
NOTE: Switch Based를 제외한 방식은 사용자 이동, IP 변경 같은 환경 변화에 즉시 반영하기 어려워 실제 운영 환경에서는 잘 쓰지 않는 편이다.
{% endhint %}

### 2.2 VLAN 번호

| 번호 | 구분 | 범위 | 비고 |
|---|---|---|---|
| 1 | 전체 | 1~4094 | 0과 4095는 예약돼 쓰지 못한다 |
| 2 | 일반 범위 | 1~1005 | VLAN 1은 기본(default) VLAN이다. 삭제하거나 이름을 바꿀 수 없다. 1002~1005는 Token Ring, FDDI용으로 예약돼 있어 삭제할 수 없다 |
| 3 | 확장 범위 | 1006~4094 | VTP 버전 1, 2는 광고하지 않는다. 확인 필요 |

### 2.3 포트 종류

| 번호 | 종류 | 설명 |
|---|---|---|
| 1 | Access 포트 | 한 VLAN에만 속한다. PC, 서버 같은 단말을 연결한다. 프레임에 태그를 붙이지 않는다 |
| 2 | Trunk 포트 | 여러 VLAN의 프레임을 한 링크로 함께 나른다. 스위치끼리, 스위치와 라우터를 연결한다 |

### 2.4 802.1Q 트렁크

| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 표준 | IEEE 802.1Q |
| 2 | 태그 | 이더넷 프레임에 4바이트 태그를 넣는다. TPID `0x8100`(2바이트)과 TCI(2바이트)로 구성된다. TCI는 우선순위 3비트, DEI 1비트, VLAN ID 12비트다 |
| 3 | Native VLAN | 트렁크에서 태그를 붙이지 않고 보내는 VLAN이다. 기본값은 VLAN 1이다. 양쪽 끝의 Native VLAN이 같아야 한다 |

## 3. 동작 원리

1. 단말이 Access 포트로 프레임을 보낸다.
2. 스위치가 그 포트의 VLAN 번호를 프레임에 붙여 같은 VLAN의 포트로만 전달한다.
3. 다른 스위치로 가야 하면 트렁크 포트로 내보낼 때 802.1Q 태그(VLAN ID)를 붙인다.
4. 받는 스위치는 태그의 VLAN ID를 보고 같은 VLAN의 Access 포트로 전달하고 태그를 뗀다.
5. 다른 VLAN으로 가는 패킷은 게이트웨이(라우터 또는 L3 스위치)가 라우팅한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| VLAN | Virtual LAN |
| Access / Trunk | 한 VLAN용 포트 / 여러 VLAN을 나르는 포트 |
| 802.1Q | VLAN 태그 표준 |
| Native VLAN | 트렁크에서 태그 없이 보내는 VLAN |
| Inter-VLAN 라우팅 | VLAN 사이의 통신을 라우팅하는 것 |
