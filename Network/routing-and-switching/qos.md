## 1. 목적

회선이 혼잡하면 패킷이 지연되거나 버려진다. QoS(Quality of Service)는 트래픽 종류별로 처리 우선순위를 달리해 음성·영상 같은 지연에 민감한 트래픽을 보호한다.

## 2. 구성 요소

| 측정 항목 | 설명 | 민감한 트래픽 예 |
|---|---|---|
| 대역폭 | 단위 시간당 전송량 | 영상 스트리밍 |
| 지연(delay) | 전달에 걸리는 시간 | 음성 통화 |
| 지터(jitter) | 지연의 변동 | 음성·화상 회의 |
| 손실(loss) | 버려지는 패킷 비율 | 대부분 |

| 표시 필드 | 위치 | 설명 |
|---|---|---|
| CoS | 802.1Q VLAN 태그의 3비트 | 계층 2 우선순위(0~7) |
| DSCP | IP 헤더 ToS 필드의 상위 6비트 | 계층 3 우선순위. EF는 음성용으로 관례적으로 쓴다 |

## 3. 동작 원리

1. 분류(classification): 포트, 주소, 프로토콜, 기존 표시값으로 트래픽을 구분한다.
2. 표시(marking): 분류 결과를 DSCP나 CoS 값으로 패킷에 기록한다.
3. 큐잉(queuing): 인터페이스가 혼잡할 때 우선순위가 높은 큐를 먼저 내보낸다. 우선순위 큐(PQ), 가중 공정 큐(WFQ) 같은 방식이 있다.
4. 폴리싱·셰이핑: 폴리싱은 한도를 넘는 트래픽을 버리거나 표시를 낮추고, 셰이핑은 버퍼에 두었다가 한도에 맞춰 천천히 내보낸다.

{% hint style="info" %}
NOTE: QoS는 회선이 혼잡할 때만 효과가 있다. 회선이 남아돌면 큐잉은 차이를 만들지 않는다. 표시값은 경로 중간 장비가 신뢰하도록 설정되어야 유지된다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| DSCP | Differentiated Services Code Point |
| CoS | Class of Service |
| 지터 | 패킷 도착 간격의 변동 |
| 셰이핑 / 폴리싱 | 초과 트래픽을 지연시키는 방식 / 버리는 방식 |
