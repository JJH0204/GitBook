## 1. 목적

SNMP(Simple Network Management Protocol)는 라우터, 스위치, 서버 같은 장비의 상태를 수집하고 설정을 관리하는 프로토콜이다. 관리 시스템(NMS)이 장비의 CPU 사용률, 인터페이스 트래픽, 오류 수를 주기적으로 읽어 감시한다.

## 2. 구성 요소

| 구성 요소 | 역할 |
|---|---|
| NMS | 장비에 질의하고 결과를 모아 보여 주는 관리 시스템 |
| 에이전트 | 관리 대상 장비에서 동작하며 NMS의 요청에 답한다 |
| MIB | 장비가 제공하는 관리 정보의 목록(트리 구조) |
| OID | MIB 안의 항목 하나를 가리키는 점으로 구분한 번호 |

| 항목 | 내용 |
|---|---|
| 전송 | UDP. 에이전트는 161번 포트, 트랩 수신은 162번 포트 |
| 주요 동작 | Get(값 읽기), Set(값 쓰기), Trap(장비가 먼저 알림) |

| 버전 | 인증·암호화 |
|---|---|
| v1, v2c | 커뮤니티 문자열(암호와 비슷한 값)을 평문으로 보냄. 암호화 없음 |
| v3 | 사용자 인증과 암호화를 지원 |

## 3. 동작 원리

1. NMS가 에이전트에 OID를 지정해 Get 요청을 보낸다.
2. 에이전트가 해당 값을 응답한다.
3. 임계값을 넘는 등 이벤트가 생기면 에이전트가 NMS에 Trap을 보낸다.
4. NMS가 값을 시간별로 기록해 그래프와 경보를 만든다.

## 4. 보안 관점

- 기본 커뮤니티 문자열(`public`, `private` 등)을 그대로 두지 않는다.
- 쓰기(Set)가 필요 없으면 읽기 전용으로 둔다.
- 가능하면 v3를 쓰고, 에이전트가 응답할 NMS 주소를 ACL로 제한한다.
- 관리망을 일반 사용자 망과 분리한다.
