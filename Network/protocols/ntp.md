## 1. 목적

로그 비교, 인증서 유효 기간 확인, Kerberos 인증 같은 작업은 장비 시계가 서로 맞아야 정상 동작한다. NTP(Network Time Protocol)는 네트워크로 시계를 맞추는 프로토콜이다.

## 2. 구성 요소

| 요소 | 설명 |
|---|---|
| 포트 | UDP 123 |
| 기준 시각원 | GPS 수신기, 원자 시계 같은 정밀 시계. stratum 0 |
| stratum | 기준 시각원까지의 거리. stratum 0 시계에 직접 연결된 서버가 1, 그 서버에서 받으면 2. 숫자가 클수록 멀다. 최대 15이고 16은 동기화 안 됨을 뜻한다 |
| 서버·클라이언트 | 클라이언트가 서버에 시각을 묻고 자기 시계를 조정한다 |
| 피어 | 같은 계층끼리 서로 시각을 비교하는 관계 |

## 3. 동작 원리

1. 클라이언트가 요청을 보내며 송신 시각(T1)을 담는다.
2. 서버가 수신 시각(T2)과 응답 송신 시각(T3)을 담아 응답한다.
3. 클라이언트가 응답 수신 시각(T4)을 기록한다.
4. 왕복 지연은 (T4 - T1) - (T3 - T2), 시계 오차는 ((T2 - T1) + (T3 - T4)) / 2 로 추정한다.
5. 오차가 크면 시계를 한 번에 맞추고, 작으면 시계 속도를 조금씩 바꿔 서서히 맞춘다. 서버 여러 대를 비교해 이상한 서버는 배제한다.

{% hint style="warning" %}
CAUTION: 외부에서 오는 UDP 123 요청에 응답하도록 열어 두면 반사 증폭 공격에 이용될 수 있다. 내부 NTP 서버는 허용한 대역에서만 질의받도록 제한한다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| NTP | Network Time Protocol |
| SNTP | NTP를 단순화한 클라이언트용 버전. 서버 선택·필터링을 생략한다 |
| offset | 내 시계와 서버 시계의 차이 |
| 슬루(slew) | 시계 속도를 조절해 서서히 맞추는 방식 |
| 스텝(step) | 시각을 한 번에 바꾸는 방식 |
