## 1. 목적

UDP(User Datagram Protocol)는 전송 계층의 비연결형 프로토콜이다. [TCP](tcp.md)와 달리 연결 설정과 데이터 수신 확인 없이 데이터를 주고받는다. 그래서 TCP보다 속도가 빠르다.

## 2. 구성 요소

| 항목 | UDP | TCP |
|---|---|---|
| 연결 방식 | 비연결형 | 연결형 |
| 확인 응답·재전송 | 없음 | 있음 |
| 순서 보장 | 없음 | 있음 |
| 전송 단위 | 데이터그램 | 세그먼트 |
| 대표 사용처 | DNS 질의, VoIP, 온라인 게임 | 웹, 이메일, 파일 전송 |

## 3. 동작 원리

1. 응용 프로그램이 UDP에 데이터를 넘긴다.
2. UDP가 출발지 포트, 목적지 포트, 길이, 체크섬으로 이루어진 헤더를 붙여 IP로 보낸다.
3. 수신 측 UDP가 목적지 포트의 프로세스에 데이터를 넘긴다.
4. 유실과 순서 변경은 응용 프로그램이 처리한다.
