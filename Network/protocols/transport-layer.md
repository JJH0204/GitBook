# 전송 계층 개요 (Transport Layer)

| 개정 | R1 (2026-11-18) |

## 1. 목적

전송 계층은 계층 구조의 네트워크에서 송신 프로세스와 수신 프로세스를 연결하는 통신 서비스를 제공한다. OSI 7계층의 4계층이고, TCP/IP 4계층 모델의 3계층이다.

## 2. 구성 요소

### 2.1 제공 서비스

| 서비스 | 설명 | TCP | UDP |
|---|---|---|---|
| 연결 지향 데이터 스트림 | 연결을 맺고 바이트 스트림으로 전달한다 | 제공 | 제공 안 함 |
| 신뢰성 | 유실과 순서 변경을 확인 응답과 재전송으로 보정한다 | 제공 | 제공 안 함 |
| 흐름 제어 | 수신 측이 처리할 수 있는 만큼만 보낸다 | 제공 | 제공 안 함 |
| 다중화 | 포트 번호로 한 호스트의 여러 프로세스를 구분한다 | 제공 | 제공 |

{% hint style="info" %}
NOTE: 원본은 서비스 이름만 나열했다. TCP와 UDP별 제공 여부 열은 일반 개념으로 새로 채웠다.
{% endhint %}

| UDP | 비연결형, 신뢰성 미제공 | [udp.md](udp.md) (NET-PRT-005-DO) |

## 3. 동작 원리

1. 응용 프로그램이 데이터를 전송 계층에 넘긴다.
2. 전송 계층이 출발지 포트와 목적지 포트를 헤더에 붙인다.
3. 인터넷 계층(IP)이 호스트 사이로 전달한다.
4. 수신 측 전송 계층이 목적지 포트를 보고 해당 프로세스에 데이터를 넘긴다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 다중화 (Multiplexing) | 여러 응용 프로그램의 데이터를 하나의 하위 계층으로 보내는 것 |
| 흐름 제어 (Flow control) | 송신 속도를 수신 측 처리 능력에 맞추는 것 |
| 포트 | 호스트 안에서 프로세스를 구분하는 16비트 번호. [port.md](port.md) 참조 |
