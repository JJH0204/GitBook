# 네트워크 기본 구성도

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | NET-FND-002-DO |
| 유형 | D&O (개념) |
| 목적 | 가정 네트워크의 기본 구성과 IP 주소, 포트, 공유기의 역할을 우편 시스템에 비유해 설명한다 |
| 확인 상태 | 미검증 (원본 페이지와 일반 개념을 정리한 것이며 출처를 다시 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 원본은 구성도 그림의 글자만 평문으로 남아 있어 순서와 관계가 불분명했다. 아래 구성도는 글자를 바탕으로 다시 그린 것이므로 원본 그림과 다를 수 있다. 원본에는 외부 IP 예시 `59.23.xxx.xx`와 내부 IP 예시 `192.9.64.xxx`가 있었다. 실제 공인 주소로 보이는 값은 문서용 예시 대역(`203.0.113.0/24`)으로, `192.9.x.x`는 사설 대역 `192.168.9.x`로 바꿨다. `192.9.0.0` 대역은 사설 주소가 아니기 때문이다.
{% endhint %}

## 1. 목적

집에서 인터넷에 접속할 때 데이터는 모뎀, 공유기, 각 기기, 기기 안의 프로그램 순서로 전달된다. 이 문서는 이 구조에서 IP 주소와 포트가 각각 무엇을 식별하는지 정리한다.

## 2. 구성 요소

### 2.1 장비와 주소

| 번호 | 구성 요소 | 역할 | 주소 예시 |
|---|---|---|---|
| 1 | 인터넷 | 외부 네트워크 | |
| 2 | 모뎀 | 통신 사업자 회선과 집 안 네트워크를 연결한다 | 외부 IP `203.0.113.10` |
| 3 | 공유기 | 여러 기기를 하나의 내부 대역으로 묶고 외부 IP를 공유한다 | 내부 IP `192.168.9.1` |
| 4 | PC, 휴대 기기 | 내부 IP를 받아 통신한다 | `192.168.9.38`, `192.168.9.72` |
| 5 | 프로그램 | 포트를 열어 데이터를 수신한다 | 포트 `22`, `2000` |

### 2.2 우편 시스템 비유

| 번호 | 오프라인 우편 | 온라인 통신 | 예시 |
|---|---|---|---|
| 1 | 보내는 대상의 주소(건물) | 외부 IP 주소 | `203.0.113.10` |
| 2 | 상세 주소(동·호수) | 내부 IP 주소 | `192.168.9.38` |
| 3 | 받는 사람 | 포트로 식별되는 프로그램 | 포트 `22` |

### 2.3 외부 IP와 내부 IP

| 번호 | 구분 | 설명 |
|---|---|---|
| 1 | 외부 IP | 인터넷에서 보이는 대표 IP다. 통신 사업자가 할당한다 |
| 2 | 내부 IP | 공유기 안쪽에서 기기를 서로 구분하는 IP다. 공유기가 할당한다 |
| 3 | 구분하는 이유 | IPv4 주소 범위는 `0.0.0.0`~`255.255.255.255`(약 43억 개)다. 전 세계 모든 기기에 각각 할당하기에 부족하다. 대표 IP 하나를 공유하고 내부 기기는 개별 IP를 쓰면 주소를 아낄 수 있다 |

### 2.4 포트

포트(port)는 데이터를 받을 프로그램을 식별하는 번호다. 프로그램이 포트를 열면 그 포트로 들어온 데이터를 받는다. 포트 번호는 0~65535 범위다.

### 2.5 공유기 사용 여부에 따른 내부 IP 할당

| 번호 | 연결 방식 | 비유 | 설명 |
|---|---|---|---|
| 1 | 공유기 사용 | 아파트 | 여러 기기를 같은 대역(예: `192.168.9.0/24`)에 묶어 한 번에 관리한다 |
| 2 | 모뎀에 직접 연결 | 단독 주택 | 기기가 통신 사업자가 정한 주소를 직접 받는다. 내 주소로 이웃 주소를 알 수 없다 |

{% hint style="info" %}
NOTE: 모뎀에 직접 연결했을 때의 주소 할당은 통신 사업자와 모뎀 종류(모뎀이 공유기 기능을 겸하는지)에 따라 다르다. 원본도 "아닐 수도 있다"고 적었다. 확인 필요.
{% endhint %}

## 3. 동작 원리

```
인터넷
  |
모뎀 (외부 IP 203.0.113.10)
  |
공유기 (내부 192.168.9.1, NAT)
  |-- PC 1 (192.168.9.38)  -- 프로그램 1 (포트 22), 프로그램 2 (포트 2000)
  |-- PC 2 (192.168.9.72)
```

1. 외부에서 온 데이터는 외부 IP로 모뎀과 공유기에 도착한다.
2. 공유기는 NAT(Network Address Translation, 주소 변환)로 내부 IP를 가진 기기를 찾아 전달한다.
3. 기기는 데이터의 목적지 포트를 확인해 그 포트를 연 프로그램에 넘긴다.
4. 프로그램은 같은 경로의 역순으로 응답을 보낸다.

`127.0.0.1`은 기기 자신을 가리키는 루프백(loopback) 주소다. 외부로 나가지 않고 같은 기기 안에서만 통신한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| IP | Internet Protocol. 네트워크 통신에 쓰는 식별 번호 체계 |
| NAT | Network Address Translation. 내부 IP와 외부 IP를 서로 변환하는 기능 |
| 패킷(packet) | 네트워크 계층에서 전송하는 데이터 단위 |
| 루프백(loopback) | 자기 자신을 가리키는 주소 (`127.0.0.1`) |
