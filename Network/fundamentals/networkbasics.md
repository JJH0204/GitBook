프로그램은 오프라인의 우편 시스템 처럼 PC의 특정 포트를 활성화 시켜 해당 포트로 데이터(패킷)을 수신하고 송신 하는 방식으로 외부와 통신한다.

IP : 네트워크 통신에 사용되는 식별번호 외부 IP 와 내부 IP 로 구분 why?

외부

내부

0.0.0.0 \~ 255.255.255.255 범위로 표현할 수 있는 IP 는 수량이 제한적이라 전세계의 모든 PC에 각자 IP 를 할당할 수 있는 수준이 아니다. 대표 IP (외부에 표시되는 IP)를 할당하고 내부 PC 또는 모바일 장치들이 서로를 식별할 수 있도록 개별 IP 를 생성하도록 해 제한적인 IP 수량을 효율적으로 사용한다.

Port(포트)란 패킷을 수신할 대상 프로그램이라 이해하면 쉽다. 패킷을 수신할 프로그램이 데이터를 수신할 수 있도록 port를 활성화 하여 해당 port로 수신한 데이터를 프로그램이 수신할 수 있도록 한다. "데이터의 수신자(프로그램)을 식별하는 번호"라 이해하면 될 것 같다.

내부 IP 할당 규칙 공유기 사용 여부에 따라 달라진다. (아닐 수도 있다) 공유기를 비유하자면 아파트라 할 수 있다. 공유기를 사용하면 아파트처럼 여러 기기를 동일한 대역에 묶어 한번에 관리할 수 있다. 공유기를 사용하지 않고 직접 모뎀에 연결할 경우 단독 주택처럼 주소지가 임의로 지정되어 관리된다. (내 집 주소를 안다고 옆집 주소를 유추할 수는 없다.) 공유기 사용 여부가 공동 주택과 단독 주택을 구분하는 기준이 된다.
