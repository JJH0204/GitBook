## 1. 목적

이더넷(Ethernet, IEEE 802.3)은 유선 LAN의 데이터 링크 계층 표준이다. 데이터는 프레임(frame) 단위로 전달되고, 프레임의 출발지·목적지는 MAC(Media Access Control) 주소로 표시한다.

## 2. 구성 요소

### 2.1 이더넷 II 프레임 필드

| 순서 | 필드 | 크기 | 설명 |
|---|---|---|---|
| 1 | 목적지 MAC | 6바이트 | 받을 장치 |
| 2 | 출발지 MAC | 6바이트 | 보낸 장치 |
| 3 | 타입(EtherType) | 2바이트 | 상위 프로토콜. IPv4 `0x0800`, ARP `0x0806`, IPv6 `0x86DD` |
| 4 | 페이로드 | 46~1500바이트 | 상위 계층 데이터. 일반 MTU는 1500바이트 |
| 5 | FCS | 4바이트 | 오류 검출용 CRC 값 |

프리앰블(7바이트)과 SFD(1바이트)는 프레임 앞에 붙는 동기화용 신호이며 프레임 크기에 보통 포함하지 않는다.

### 2.2 MAC 주소

| 항목 | 내용 |
|---|---|
| 길이 | 48비트(6바이트). 16진수 두 자리씩 `aa:bb:cc:dd:ee:ff` 또는 `aa-bb-cc-dd-ee-ff`로 표기 |
| 앞 3바이트 | OUI. 제조사 식별 값 |
| 뒤 3바이트 | 제조사가 정한 장치 식별 값 |
| 브로드캐스트 | `ff:ff:ff:ff:ff:ff`. 같은 LAN의 모든 장치 |
| 멀티캐스트 | 첫 바이트의 최하위 비트가 1 |

## 3. 동작 원리

1. 송신 장치가 IP 패킷에 이더넷 헤더(목적지·출발지 MAC, 타입)와 FCS를 붙여 프레임을 만든다.
2. 스위치가 목적지 MAC을 보고 해당 포트로만 프레임을 보낸다. 모르는 MAC이면 들어온 포트를 뺀 모든 포트로 보낸다.
3. 수신 장치가 FCS를 검사하고, 오류가 있으면 프레임을 버린다.
4. 목적지 MAC이 자기 것이거나 브로드캐스트면 타입 필드를 보고 상위 프로토콜에 넘긴다.

MAC 주소는 같은 링크(LAN) 안에서만 의미가 있다. 라우터를 지날 때마다 프레임은 새로 만들어지고 MAC 주소가 바뀌지만, IP 주소는 유지된다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| OUI | Organizationally Unique Identifier. MAC 앞 3바이트 |
| MTU | Maximum Transmission Unit. 한 번에 보낼 수 있는 최대 페이로드 크기 |
| FCS | Frame Check Sequence. 프레임 오류 검출 값 |
