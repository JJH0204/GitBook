## 1. 목적

토폴로지(topology)는 네트워크의 망 형태를 뜻한다. 장비들이 어떻게 연결돼 있는지, 데이터가 어떻게 흘러가는지를 구조로 표현한다.

## 2. 구성 요소

### 2.1 분류

| 번호 | 분류 | 기준 | 설명 |
|---|---|---|---|
| 1 | 물리(Physical) 토폴로지 | 노드의 연결 형태 | 케이블과 장비가 실제로 배치된 모양이다 |
| 2 | 논리(Logical) 토폴로지 | 데이터를 전송하는 방식 | 데이터가 장비 사이를 흐르는 경로다 |

노드(node)는 네트워크에 참여하는 시스템 또는 장치다.

### 2.2 대표 연결 형태

| 형태 | 구조 | 장점 | 단점 |
|---|---|---|---|
| 스타(star) | 중앙 장비(스위치 또는 허브)에 모든 노드가 1:1로 연결된다 | 한 노드의 고장이 다른 노드에 영향을 주지 않는다. 노드 추가가 쉽다 | 중앙 장비가 고장 나면 전체가 멈춘다 |
| 버스(bus) | 하나의 공용 케이블(백본)에 모든 노드가 연결된다 | 케이블이 적게 든다 | 케이블이 끊기면 전체가 영향을 받는다. 노드가 늘면 충돌이 늘어난다 |
| 링(ring) | 각 노드가 양옆 두 노드와 연결돼 고리 모양을 이룬다 | 데이터가 한 방향으로 순서대로 돈다 | 한 지점이 끊기면 전체 고리가 영향을 받는다(이중 링으로 보완) |
| 메시(mesh) | 노드가 여러 노드와 직접 연결된다. 모든 노드가 서로 연결되면 풀 메시다 | 경로가 여러 개라 장애에 강하다 | 연결 수가 많아 비용이 크다. 풀 메시는 노드 n개에 n(n-1)/2개의 연결이 필요하다 |

{% hint style="info" %}
NOTE: 스타와 버스를 묶은 트리(tree), 여러 형태를 섞은 하이브리드(hybrid) 형태도 있다. 허브를 쓴 이더넷은 물리적으로 스타 형태이지만 모든 포트로 신호가 퍼지므로 논리적으로는 버스처럼 동작한다. 이처럼 물리 토폴로지와 논리 토폴로지가 다를 수 있다. 확인 필요.
{% endhint %}

## 3. 동작 원리

```
스타            버스                    링              메시(풀, 4노드)
   A            A   B   C   D          A --- B         A --- B
   |            |   |   |   |          |     |         | \ / |
B--S--C       ======================   D --- C         | / \ |
   |                                                    D --- C
   D
```

1. 물리 토폴로지는 케이블과 장비를 어떻게 배치하느냐로 정해진다.
2. 논리 토폴로지는 노드가 매체를 어떻게 나눠 쓰고 데이터를 어떻게 전달하느냐로 정해진다.
3. 현재 유선 LAN은 대부분 스위치를 중심으로 한 스타 형태다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 노드(node) | 네트워크에 참여하는 시스템 또는 장치 |
| 백본(backbone) | 버스 토폴로지에서 노드를 연결하는 공용 케이블 |
| 풀 메시(full mesh) | 모든 노드가 서로 직접 연결된 형태 |
