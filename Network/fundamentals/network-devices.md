## 1. 목적

네트워크 장비는 동작하는 계층에 따라 구분한다. 어느 계층의 주소를 보고 전달하는지 알면 충돌 도메인과 브로드캐스트 도메인이 어디서 나뉘는지 알 수 있다.

## 2. 구성 요소

| 장비 | 계층 | 전달 기준 | 충돌 도메인 | 브로드캐스트 도메인 |
|---|---|---|---|---|
| 리피터 | 1 (물리) | 없음. 신호 증폭·재생 | 나누지 않음 | 나누지 않음 |
| 허브 | 1 (물리) | 없음. 받은 신호를 다른 모든 포트로 복사 | 나누지 않음 | 나누지 않음 |
| 스위치(L2) | 2 (데이터 링크) | 목적지 MAC 주소 | 포트마다 분리 | 나누지 않음(VLAN으로 분리 가능) |
| 라우터 | 3 (네트워크) | 목적지 IP 주소 | 포트마다 분리 | 인터페이스마다 분리 |
| L3 스위치 | 2~3 | MAC 주소와 IP 주소 | 포트마다 분리 | VLAN·인터페이스마다 분리 |

## 3. 동작 원리

### 3.1 스위치

1. 프레임이 들어오면 출발지 MAC 주소와 들어온 포트를 MAC 주소 테이블에 기록한다.
2. 목적지 MAC이 테이블에 있으면 해당 포트로만 보낸다.
3. 없거나 브로드캐스트이면 들어온 포트를 뺀 모든 포트로 보낸다(플러딩).

### 3.2 라우터

1. 패킷의 목적지 IP를 라우팅 테이블에서 가장 길게 일치하는(longest prefix) 경로와 비교한다.
2. 일치한 경로의 다음 홉으로 보내며, 이때 새 이더넷 프레임을 만든다.
3. 경로가 없으면 기본 경로(default route)로 보내고, 그것도 없으면 버린다.

### 3.3 구분 요약

- 같은 네트워크 안의 장치끼리는 스위치가 MAC 주소로 연결한다.
- 서로 다른 네트워크 사이는 라우터가 IP 주소로 연결한다.
- 허브는 현재 거의 쓰지 않는다. 스위치로 대체되었다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 충돌 도메인 | 프레임 충돌이 영향을 주는 범위. 허브 환경에서 문제가 되었다 |
| 브로드캐스트 도메인 | 브로드캐스트가 전달되는 범위 |
| 플러딩 | 목적지를 모를 때 모든 포트로 보내는 동작 |
