## 1. 목적

OSI 7계층 모델(Open Systems Interconnection reference model)은 국제 표준화 기구(ISO)가 정의한 모델이다. 네트워크 통신 과정을 7개 계층으로 나누어, 계층마다 역할을 분리해 설명한다. 이 모델은 실제 프로토콜 구현보다 개념 설명과 장애 위치 파악에 쓴다. 실제 인터넷은 TCP/IP 모델을 따른다.

## 2. 구성 요소

### 2.1 계층 요약

| 계층 | 명칭 | 역할 | PDU | 주요 프로토콜·규격 | 주요 장비 |
|---|---|---|---|---|---|
| 7 | 응용 계층 (Application) | 사용자와 네트워크의 접점. 응용 서비스를 제공한다 | 데이터 | HTTP, FTP, SMTP, DNS | |
| 6 | 표현 계층 (Presentation) | 데이터 형식 변환, 암호화·복호화, 압축 | 데이터 | JPEG, MP3, ASCII, TLS, SSL | |
| 5 | 세션 계층 (Session) | 통신 세션의 설정·유지·종료 관리 | 데이터 | NetBIOS, RPC, PPTP | |
| 4 | 전송 계층 (Transport) | 포트 기반 프로세스 간 전송, 흐름·오류 제어 | 세그먼트 (TCP), 데이터그램 (UDP) | TCP, UDP | |
| 3 | 네트워크 계층 (Network) | IP 주소 기반 경로 선택(라우팅) | 패킷 | IP, ICMP, ARP | 라우터 |
| 2 | 데이터 링크 계층 (Data Link) | MAC 주소 기반 직접 연결된 장치 간 전송, 오류 감지 | 프레임 | 이더넷, Wi-Fi (IEEE 802.11) | 스위치, 브리지 |
| 1 | 물리 계층 (Physical) | 전기·광·무선 신호로 비트 전송 | 비트 | RS-232, IEEE 802.11 (물리 규격) | 케이블, 리피터, 허브 |

{% hint style="info" %}
NOTE: 원본 표의 "테이터 링크 계층"은 오타라 "데이터 링크 계층"으로 고쳤다. 원본에 없던 PDU 열은 새로 추가했다.
{% endhint %}

### 2.2 계층 상세

| 계층 | 세부 기능 | 비고 |
|---|---|---|
| 1 물리 | 데이터를 전기 신호(이진수)로 변환해 전송한다. 케이블, 전파, 광신호 같은 물리적 연결을 다룬다. 전송 속도, 전송 방식(직렬·병렬), 전송 매체를 정한다 | 광케이블과 동축 케이블은 장비가 아니라 전송 매체다. IEEE 802.11은 물리 계층과 데이터 링크 계층에 걸친 규격이다 |
| 2 데이터 링크 | 물리 계층에서 받은 비트를 프레임으로 묶는다. 직접 연결된 장치 간 전송과 흐름 제어를 한다. 오류 감지(패리티 검사, CRC) 기능을 제공한다 | 프로토콜 예: 이더넷, Wi-Fi. MAC은 프로토콜이 아니라 주소 체계다 |
| 3 네트워크 | IP 주소(논리 주소)로 목적지를 지정하고 최적 경로를 찾아 패킷을 라우팅한다 | ARP는 IP 주소를 MAC 주소로 바꾼다. 2계층과 3계층 사이의 프로토콜로 설명하는 교재도 있다. 확인 필요 |
| 4 전송 | 포트 번호로 프로세스 간 데이터를 전송한다. 흐름 제어와 오류 제어를 한다. TCP는 신뢰성 있는 연결(손실 복구)을, UDP는 빠른 비연결 전송을 제공한다 | |
| 5 세션 | 클라이언트와 서버 사이의 세션을 만들고 동기화하며 종료한다. 중복 전송 방지와 복구를 지원한다 | |
| 6 표현 | 시스템 간 데이터 표현 방식을 통일한다. 인코딩·디코딩, 암호화·복호화, 압축을 한다. 파일 형식 예: ASCII, JPEG, PNG, MP3, MP4 | TLS를 6계층으로 분류하는 것은 관례다. 실제 구현은 4계층과 7계층 사이에서 동작한다. 확인 필요 |
| 7 응용 | 사용자가 직접 쓰는 응용 서비스(웹 브라우저, 이메일, 파일 전송)를 제공한다 | |

### 2.3 장비와 계층의 대응

| 장비 | 계층 | 동작 기준 |
|---|---|---|
| 리피터, 허브 | 1 | 신호를 증폭하거나 모든 포트로 전달한다 |
| 브리지, L2 스위치 | 2 | MAC 주소 |
| 라우터 | 3 | IP 주소 |

{% hint style="info" %}
NOTE: L3 스위치는 3계층 기능을 포함한다. 이 표는 기본 대응만 정리했다.
{% endhint %}

### 2.4 전송 계층 포트 번호 예시

| 서비스 | 프로토콜 | 포트 번호 | 비고 |
|---|---|---|---|
| HTTP | TCP | 80 | |
| HTTPS | TCP | 443 | |

## 3. 동작 원리

송신 측에서는 7계층에서 1계층으로 내려가고, 수신 측에서는 1계층에서 7계층으로 올라간다.

```
송신 측                          수신 측
7 응용      데이터               7 응용
6 표현      데이터               6 표현
5 세션      데이터               5 세션
4 전송      세그먼트             4 전송
3 네트워크  패킷                 3 네트워크
2 데이터링크 프레임              2 데이터 링크
1 물리      비트  ---- 회선 ---> 1 물리
```

1. 송신 측 각 계층은 아래 계층으로 넘기며 자기 계층의 헤더를 덧붙인다(캡슐화).
2. 1계층이 비트 신호로 변환해 회선으로 보낸다.
3. 수신 측 각 계층은 위 계층으로 올리며 자기 계층의 헤더를 읽고 뗀다(역캡슐화).
4. 각 계층은 독립적으로 동작하며 인접한 계층과만 데이터를 주고받는다.

### OSI 7계층과 TCP/IP 4계층 비교

OSI 7계층은 개념 모델이고, TCP/IP는 실제 인터넷에서 쓰이는 모델이다. 두 모델의 대응은 NET-FND-006-DO의 대응표에 있다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| ISO | International Organization for Standardization. 국제 표준화 기구 |
| PDU | Protocol Data Unit. 계층별 데이터 단위 |
| MAC | Media Access Control. 2계층 주소 |
| CRC | Cyclic Redundancy Check. 오류 감지 방식 |
| TLS / SSL | Transport Layer Security / Secure Sockets Layer. 암호화 프로토콜 |
