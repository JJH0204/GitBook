## 1. 목적

무선 LAN은 IEEE 802.11 표준으로 전파를 이용해 LAN을 구성한다. 유선 이더넷과 같은 상위 계층(IP)을 쓰며, 데이터 링크 계층 이하만 다르다.

## 2. 구성 요소

| 구성 요소 | 설명 |
|---|---|
| AP | Access Point. 무선 단말을 유선망에 연결하는 장치 |
| SSID | 무선망 이름 |
| 단말(STA) | 노트북, 스마트폰 등 무선 접속 장치 |
| 무선 공유기 | AP, 스위치, 라우터를 한 장치에 합친 것 |

| 주파수 | 특징 |
|---|---|
| 2.4GHz | 도달 거리가 길고 벽에 강하다. 사용 장치가 많아 간섭이 크고 속도가 낮다 |
| 5GHz | 속도가 높고 간섭이 적다. 도달 거리가 짧다 |
| 6GHz | Wi-Fi 6E 이후 사용. 간섭이 적고 도달 거리가 짧다 |

| 명칭 | 표준 | 비고 |
|---|---|---|
| Wi-Fi 4 | 802.11n | 2.4GHz, 5GHz |
| Wi-Fi 5 | 802.11ac | 5GHz |
| Wi-Fi 6 | 802.11ax | 2.4GHz, 5GHz (6E는 6GHz 추가) |

| 보안 방식 | 평가 |
|---|---|
| WEP | 취약해 쓰지 않는다 |
| WPA2 | 널리 쓰며 AES 기반 암호화 사용 |
| WPA3 | WPA2보다 강화된 최신 방식 |

## 3. 동작 원리

1. AP가 SSID를 비콘 프레임으로 주기적으로 알린다.
2. 단말이 SSID를 선택해 인증과 연결(결합)을 한다.
3. 보안 방식에 따라 키를 협상하고 이후 데이터를 암호화한다.
4. 무선은 모든 장치가 같은 전파를 나눠 쓰는 공유 매체이므로, 보내기 전에 매체가 비었는지 확인하는 CSMA/CA 방식으로 충돌을 피한다. 유선 이더넷의 충돌 감지(CSMA/CD)와 다르다.
5. 단말이 IP 주소를 받는 과정은 유선과 같다([DHCP](../ip-addressing-and-nat/dhcp.md)).

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| CSMA/CA | 충돌 회피 방식의 매체 접근 제어 |
| WPA | Wi-Fi Protected Access |
