# UTP 케이블 배선 (UTP Cabling)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | NET-FND-008-DO |
| 유형 | D&O (개념) |
| 목적 | UTP 케이블의 국제 표준 배선(T568A, T568B)과 다이렉트·크로스 연결 형태를 설명한다 |
| 확인 상태 | 미검증 (원본 페이지와 일반 네트워크 교재 지식을 정리한 것이며 출처를 다시 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 원본에서 정정한 곳은 "비고"와 NOTE에 표시했다. 케이블을 직접 만드는 절차는 NET-FND-009-MP로 분리했다.
{% endhint %}

## 1. 목적

UTP(Unshielded Twisted Pair)는 차폐하지 않은 꼬임쌍 케이블이다. 8개 선이 4쌍으로 꼬여 있고, 양 끝에 RJ-45 커넥터를 달아 이더넷 장비를 연결한다. 이 문서는 커넥터 핀에 선을 배열하는 두 표준과 연결 형태를 정리한다.

## 2. 구성 요소

### 2.1 연결 형태

| 번호 | 형태 | 정의 | 용도 | 비고 |
|---|---|---|---|---|
| 1 | 다이렉트(Direct, 스트레이트) | 양쪽 커넥터의 배선 표준이 같다 (568A-568A 또는 568B-568B) | 서로 다른 종류의 장비 연결 (PC-스위치, PC-공유기) | 원본은 "이동 장비간"이라고 적었다. 오타로 보여 "이종 장비"로 정정했다. 확인 필요 |
| 2 | 크로스(Cross) | 양쪽 커넥터의 배선 표준이 다르다 (한쪽 568A, 다른 쪽 568B) | 같은 종류의 장비 연결 (PC-PC, 스위치-스위치) | |

{% hint style="info" %}
NOTE: 최근 장비 대부분은 Auto MDI/MDI-X 기능으로 케이블 종류를 자동 인식하므로 크로스 케이블이 필요한 경우는 드물다.
{% endhint %}

### 2.2 배선 표준 (핀 번호별 선 색)

| 표준 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T568A | 흰녹 | 녹 | 흰주 | 파 | 흰파 | 주 | 흰갈 | 갈 |
| T568B | 흰주 | 주 | 흰녹 | 파 | 흰파 | 녹 | 흰갈 | 갈 |

흰녹은 흰색 바탕에 녹색 줄이 있는 선이다. 흰주, 흰파, 흰갈도 같은 방식이다. 두 표준의 차이는 녹색 쌍과 주황색 쌍(1, 2, 3, 6번 핀)의 위치뿐이다.

### 2.3 통신에 쓰는 핀

| 번호 | 규격 | 사용하는 핀 | 비고 |
|---|---|---|---|
| 1 | 10BASE-T, 100BASE-T (Fast Ethernet) | 1, 2, 3, 6번 | 1, 2번이 송신, 3, 6번이 수신이다 |
| 2 | 1000BASE-T (Gigabit Ethernet) 이상 | 8개 핀 모두 | |

{% hint style="info" %}
NOTE: 원본은 "1, 2, 3, 6번 핀만 통신에 사용된다"고 적었다. 이는 10/100 Mbps 이더넷에만 해당하므로 규격별로 구분해 정정했다. 확인 필요.
{% endhint %}

## 3. 동작 원리

1. 송신 장비는 1, 2번 핀(송신 쌍)으로 신호를 내보낸다.
2. 수신 장비는 3, 6번 핀(수신 쌍)으로 신호를 받아야 한다.
3. 서로 다른 종류의 장비(PC와 스위치)는 송신·수신 핀이 반대로 배치돼 있어, 양쪽 배선이 같은 다이렉트 케이블로 연결된다.
4. 같은 종류의 장비끼리는 송신·수신 핀이 같은 위치라, 크로스 케이블로 1, 2번과 3, 6번을 맞바꿔 연결해야 한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| UTP | Unshielded Twisted Pair. 비차폐 꼬임쌍 케이블 |
| RJ-45 | 8핀 이더넷 커넥터 |
| T568A / T568B | 핀 배열 표준(TIA/EIA-568) |
| Auto MDI/MDI-X | 케이블 종류에 맞춰 송수신 핀을 자동으로 바꾸는 기능 |
