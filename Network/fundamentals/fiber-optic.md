## 1. 목적

광케이블은 빛으로 신호를 보낸다. 전기 신호를 쓰는 UTP보다 먼 거리와 높은 대역폭에 유리하고 전자기 간섭을 받지 않는다.

## 2. 구성 요소

| 구분 | 멀티모드(MMF) | 싱글모드(SMF) |
|---|---|---|
| 코어 지름 | 50 µm 또는 62.5 µm | 약 9 µm |
| 광원 | LED 또는 VCSEL(레이저) | 레이저 |
| 용도 | 건물·데이터센터 내부 등 단거리 | 건물 사이·도시 간 등 장거리 |
| 피복 색(관례) | 오렌지·아쿠아 등 | 노란색 |

| 항목 | UTP | 광케이블 |
|---|---|---|
| 신호 | 전기 | 빛 |
| 일반 최대 거리 | 100 m | 수백 m(MMF)~수십 km(SMF) |
| 전자기 간섭 | 받음 | 받지 않음 |
| 전원 공급(PoE) | 가능 | 불가 |
| 연결 | RJ-45 | LC, SC 같은 커넥터와 SFP 계열 트랜시버 |

## 3. 동작 원리

1. 송신 트랜시버가 전기 신호를 빛으로 바꿔 코어에 넣는다.
2. 빛은 코어와 클래딩의 굴절률 차이로 전반사하며 코어를 따라 진행한다.
3. 수신 트랜시버가 빛을 전기 신호로 되돌린다.
4. 송신용과 수신용 가닥이 따로이므로 한 링크에 보통 두 가닥을 쓴다.

{% hint style="danger" %}
WARNING: 레이저 광원이 켜진 상태에서 케이블 끝이나 포트를 눈으로 들여다보지 않는다. 눈에 보이지 않는 적외선이라도 시력을 손상시킬 수 있다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 트랜시버와 케이블은 모드(MMF/SMF)와 파장이 맞아야 한다. 끝면에 먼지가 있으면 손실이 커지므로 연결 전 청소한다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| MMF / SMF | 멀티모드 / 싱글모드 광섬유 |
| SFP | 스위치 포트에 꽂는 교체형 트랜시버 모듈 |
| LC, SC | 광케이블 커넥터 형식 |
| 클래딩 | 코어를 감싸 빛을 가두는 층 |
