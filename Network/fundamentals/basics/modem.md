## 1. 목적

모뎀(Modem)은 변조기(Modulator)와 복조기(Demodulator)를 합친 말이다. 디지털 데이터를 회선에 맞는 신호로 바꿔 보내고(변조), 받은 신호를 다시 디지털 데이터로 되돌린다(복조). 이 문서는 모뎀의 신호 변환 과정과 변조 방식을 정리한다.

## 2. 구성 요소

### 2.1 모뎀의 정의

| 번호 | 항목 | 내용 | 비고 |
|---|---|---|---|
| 1 | 기능 | 디지털 데이터를 신호로 변조하고, 수신한 신호를 디지털 데이터로 복조한다 | 원본은 "아날로그 신호"로 한정했다. 광회선처럼 아날로그 전기 신호가 아닌 경우도 있어 "신호"로 정정했다. 확인 필요 |
| 2 | 사용처 | 전화선, DSL, 케이블, 광통신 등 | |
| 3 | 변조 방식 | ASK, FSK, PSK, QAM 등 | |
| 4 | 고속 방식 | OFDM, QAM 같은 고속 변조 방식이 최신 통신에서 쓰인다 | 아래 2.3 참조 |

### 2.2 주요 변조 방식

| 번호 | 변조 방식 | 설명 | 특징 |
|---|---|---|---|
| 1 | ASK (Amplitude Shift Keying, 진폭 편이 변조) | 신호의 진폭을 바꿔 데이터를 표현한다 | 단순하지만 잡음(노이즈)의 영향을 받기 쉽다. 사용 빈도가 낮다 |
| 2 | FSK (Frequency Shift Keying, 주파수 편이 변조) | 주파수를 바꿔 데이터를 표현한다 | 초기 모뎀 방식이다. 속도가 낮다. ASK보다 잡음 영향이 적다 |
| 3 | PSK (Phase Shift Keying, 위상 편이 변조) | 위상을 바꿔 데이터를 표현한다 | 잡음에 강하고 효율이 좋다. 현대 디지털 통신에 널리 쓰인다 |
| 4 | QAM (Quadrature Amplitude Modulation, 직교 진폭 변조) | 진폭과 위상 변화를 함께 써서 데이터를 표현한다 | 한 번에 많은 비트를 보내 고속 전송이 가능하다. 케이블 모뎀, 디지털 TV, Wi-Fi, 4G/5G에 쓰인다 |

### 2.3 연결 방식별 신호 방식

| 번호 | 연결 방식 | 신호 방식 | 비고 |
|---|---|---|---|
| 1 | DSL 모뎀 | DMT(OFDM의 한 형태)와 QAM | 원본은 OFDM, QAM으로 적었다. ADSL은 DMT 방식이다 |
| 2 | 케이블 모뎀 | QAM | 상향 전송에는 QPSK를 쓰기도 한다 (DOCSIS 규격). 확인 필요 |
| 3 | 광통신 (FTTH) | 광 신호의 세기를 켜고 끄는 방식(OOK 계열) 등 | 원본은 OFDM, QAM, PSK로 적었다. 가정용 FTTH(예: GPON)는 이 방식이 아니므로 정정했다. 확인 필요 |
| 4 | Wi-Fi (802.11a/g/n/ac/ax) | OFDM과 QAM | 802.11b는 OFDM이 아닌 DSSS를 쓴다. 원본은 Wi-Fi를 모뎀 목록에 함께 적었으나 Wi-Fi는 모뎀이 아니라 무선 접속 기술이다 |
| 5 | 5G | OFDM과 QAM | 5G도 모뎀 장치가 아니라 이동통신 방식이다. 원본은 광통신 항목에 함께 적었다 |

{% hint style="info" %}
NOTE: 원본은 광통신(FTTH)과 5G를 한 항목으로 묶었다. 두 기술은 신호 방식이 서로 달라 분리했다.
{% endhint %}

### 2.4 모뎀의 변천사

| 번호 | 시대 | 기술 | 변조 방식 | 속도 |
|---|---|---|---|---|
| 1 | 1960~1970년대 | 전화선 기반 아날로그 모뎀 | FSK | 300 bps~1,200 bps대 |
| 2 | 1980년대 | 고속 다중 변조 모뎀 | PSK, QAM | 2,400 bps~14.4 kbps대 |
| 3 | 1990년대 | 56k 모뎀, DSL, 케이블 모뎀 | QAM, DMT | 56 kbps~수 Mbps |
| 4 | 2000년대 이후 | 광통신, LTE, 5G | OFDM, QAM | 수십~수백 Mbps 이상 |

{% hint style="info" %}
NOTE: 원본은 1960~70년대 속도를 "300~2400 bps", 1980년대를 "9600 bps~56 kbps", 1990년대를 "1~10 Mbps"로 적었다. 56 kbps 모뎀은 1990년대 후반 규격이고 PCM 방식을 쓴다. 시대별 속도 범위는 대략의 값으로 고쳤다. 정확한 규격별 속도는 확인 필요.
{% endhint %}

## 3. 동작 원리

모뎀은 송신과 수신에서 반대 방향의 변환을 한다.

### 3.1 송신 (디지털에서 신호로)

1. 컴퓨터가 0과 1로 된 이진 데이터를 모뎀에 보낸다.
2. 모뎀이 데이터에 따라 반송파의 진폭, 주파수, 위상을 바꾼다(변조).
3. 변조된 신호가 회선(전화선, 동축 케이블, 광케이블 등)으로 나간다.

### 3.2 수신 (신호에서 디지털로)

1. 회선으로 들어온 신호를 모뎀이 받는다.
2. 모뎀이 진폭, 주파수, 위상의 변화를 읽어 비트로 되돌린다(복조).
3. 모뎀이 이진 데이터를 컴퓨터에 전달한다.

```
컴퓨터 --디지털--> [모뎀: 변조] --신호--> 회선 --신호--> [모뎀: 복조] --디지털--> 컴퓨터
```

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| Modem | Modulator + Demodulator. 변조와 복조를 하는 장치 |
| 변조 / 복조 | 데이터를 신호에 싣는 일 / 신호에서 데이터를 꺼내는 일 |
| 반송파 | 데이터를 싣는 기준 신호 |
| ASK, FSK, PSK, QAM | 진폭, 주파수, 위상, 진폭+위상을 이용한 변조 방식 |
| OFDM | Orthogonal Frequency Division Multiplexing. 직교 주파수 분할 다중화 |
| DMT | Discrete Multi-Tone. ADSL에서 쓰는 OFDM 계열 방식 |
| DSL | Digital Subscriber Line. 전화선을 쓰는 디지털 가입자 회선 |
| FTTH | Fiber To The Home. 광케이블을 가정까지 연결하는 방식 |
| DOCSIS | 케이블 모뎀 규격 |
| bps | bits per second. 초당 전송 비트 수 |
