## 1. 목적

LAN(Local Area Network)은 건물이나 구내처럼 좁은 범위의 네트워크다. WAN(Wide Area Network)은 떨어진 LAN끼리 연결하는 넓은 범위의 네트워크다. 이 문서는 둘을 같은 기준으로 비교한다.

## 2. 구성 요소

### 2.1 LAN과 WAN 비교

| 번호 | 구분 | LAN | WAN |
|---|---|---|---|
| 1 | 범위 | 건물이나 작은 지역 안으로 제한된다 | 도시, 국가, 대륙에 걸친 넓은 지역이다 |
| 2 | 속도 | 일반적으로 전송 속도가 높다 | LAN보다 상대적으로 낮다 |
| 3 | 관리 | 단일 조직이나 개인이 관리한다 | 여러 조직이나 정부, 여러 서비스 제공자가 관리한다 |
| 4 | 비용 | 설치와 유지 보수 비용이 상대적으로 낮다 | 광범위한 구축과 유지에 더 많은 비용이 든다 |
| 5 | 사용 예 | 사무실 건물, 학교, 가정 내 네트워크 | 인터넷, 대규모 기업의 글로벌 네트워크 |
| 6 | 연결 장비 | NIC(랜카드), 스위치(Switch), 꼬임쌍선 케이블(T/P Cable) | 라우터(Router) |
| 7 | 통신 프로토콜 | 이더넷(Ethernet, IEEE 802.3) | IP(Internet Protocol) |
| 8 | 통신 주소 | MAC 주소 (48비트, 16진수 12자리) | IP 주소 (IPv4는 32비트, `A.B.C.D`) |

### 2.2 LAN

| 번호 | 항목 | 내용 | 비고 |
|---|---|---|---|
| 1 | 정의 | 통신 주체 자신을 포함한 같은 네트워크다. 비교적 좁은 범위로 구성한다 | |
| 2 | 연결 방법 | LAN 장비로 연결한다 | |
| 3 | 비용 특성 | 구축 비용은 들지만 통신과 유지 보수 비용은 낮다 | |
| 4 | 이더넷 속도 | Ethernet 10 Mbps, FastEthernet 100 Mbps, GigabitEthernet 1,000 Mbps | 현재는 10 Gbps 이상 규격도 쓴다. 원본에 없던 내용이다 |
| 5 | MAC 주소 표기 | 예: `HH-HH-HH-HH-HH-HH` (H는 16진수 한 자리) | 운영체제에 따라 `:` 구분도 쓴다 |

### 2.3 WAN

| 번호 | 항목 | 내용 | 비고 |
|---|---|---|---|
| 1 | 정의 | 자신이 포함되지 않은 외부 네트워크다. 떨어진 LAN과 LAN을 연결한다 | |
| 2 | 연결 방법 | WAN 장비(라우터)로 연결한다 | |
| 3 | 비용 특성 | 통신 사업자(ISP)의 회선을 임대해 쓰므로 구축 비용은 낮다. 통신과 유지 보수 비용은 높다 | |
| 4 | IP 주소 관리 | 공인 IP 주소는 IANA가 최상위에서 관리한다. 실제 할당은 지역 인터넷 레지스트리(RIR)와 ISP를 거친다 | 원본은 "IP 프로토콜을 IANA가 관리"로 적었다. IP 주소 자원 관리로 정정했다. 확인 필요 |

{% hint style="info" %}
NOTE: 원본은 이더넷을 "IEEE에서 지정한 LAN 구간 표준 프로토콜"이라고 적었다. 이더넷은 IEEE 802.3 표준이다. 원본은 LAN의 범위를 "건물 단위"에 한정하지 않았으나, 일반적으로 한 건물이나 캠퍼스 안을 뜻한다.
{% endhint %}

## 3. 동작 원리

같은 LAN 안의 통신과 LAN 밖의 통신은 사용하는 주소가 다르다.

1. 송신 장치가 목적지 IP 주소와 자신의 서브넷을 비교한다.
2. 같은 LAN이면 목적지의 MAC 주소를 찾아 스위치를 거쳐 직접 보낸다.
3. 다른 LAN이면 기본 게이트웨이(보통 라우터)로 보낸다.
4. 라우터가 WAN 회선을 거쳐 목적지 LAN의 라우터로 전달한다.

```
[PC] - [스위치] - [라우터] ==== WAN(ISP 회선) ==== [라우터] - [스위치] - [서버]
 └─────── LAN ───────┘                              └─────── LAN ───────┘
```

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| LAN | Local Area Network. 좁은 범위의 네트워크 |
| WAN | Wide Area Network. 떨어진 LAN을 잇는 넓은 범위의 네트워크 |
| NIC | Network Interface Card. 랜카드 |
| T/P Cable | Twisted Pair Cable. 꼬임쌍선 케이블 |
| MAC | Media Access Control. LAN 구간에서 쓰는 48비트 하드웨어 주소 |
| ISP | Internet Service Provider. 인터넷 서비스 제공자 |
| IANA | Internet Assigned Numbers Authority. IP 주소 등 인터넷 번호 자원을 관리하는 기관 |
