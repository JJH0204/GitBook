# 네트워크 기초 (Basics)

네트워크의 가장 기본이 되는 개념과 장비를 정리한다. 문서 번호(Task ID)는 `NET-BAS-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| NET-BAS-001-DO | 개념 | [LAN과 WAN 비교](lanandwan.md) | LAN과 WAN의 범위, 장비, 프로토콜, 주소 차이를 이해한다 |
| NET-BAS-002-DO | 개념 | [인터넷 연결 유형 구성도](internetconnectiontypeinfo.md) | 모뎀 직결과 공유기 사용 구성에서 IP 대역이 어떻게 달라지는지 이해한다 |
| NET-BAS-003-MP | 절차 | [LAN 환경 구축 실습](lanenvsetup.md) | 스위치 한 대로 PC 세 대를 묶고 IP를 설정해 통신을 확인한다 |
| NET-BAS-004-DO | 개념 | [모뎀 (Modem)](modem.md) | 모뎀의 변조와 복조, 변조 방식, 연결 방식별 신호 방식을 이해한다 |

## 읽는 순서

1. NET-BAS-001-DO로 LAN과 WAN의 차이를 본다.
2. NET-BAS-004-DO로 모뎀이 하는 일을 본다.
3. NET-BAS-002-DO로 인터넷 연결 구성을 본다.
4. NET-BAS-003-MP로 LAN을 직접 구성한다.
