## 1. 목적

서버가 스토리지(저장 장치)를 연결하는 방식은 DAS, NAS, SAN으로 나눈다. 연결 위치와 접근 단위가 다르다.

## 2. 구성 요소

### 2.1 방식 비교

| 구분 | DAS | NAS | SAN |
|---|---|---|---|
| 풀 네임 | Direct Attached Storage | Network Attached Storage | Storage Area Network |
| 연결 | 서버에 직접 연결한다 | 일반 네트워크(이더넷)로 연결한다 | 전용 스토리지 네트워크(FC 또는 iSCSI)로 연결한다 |
| 접근 단위 | 블록 | 파일 | 블록 |
| 프로토콜 | SATA, SAS | SMB, NFS | Fibre Channel, iSCSI |
| 서버가 보는 모습 | 로컬 디스크 | 공유 폴더 | 로컬 디스크처럼 보이는 볼륨(LUN) |
| 공유 | 어렵다 | 쉽다(여러 사용자가 같은 파일을 쓴다) | 여러 서버가 각자 볼륨을 쓴다 |
| 비용·복잡도 | 낮다 | 중간 | 높다 |
| 주 용도 | 단일 서버, 개인 PC | 파일 공유, 백업 | 데이터베이스, 가상화 |

## 3. 동작 원리

- NAS: 클라이언트가 파일 이름으로 요청하면 NAS가 파일 시스템을 관리하며 파일을 돌려준다.
- SAN: 서버가 블록 단위로 직접 읽고 쓴다. 파일 시스템은 서버가 관리한다.

내부 디스크는 RAID로 묶어 쓰는 경우가 많다([raid.md](raid.md)).

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| LUN | Logical Unit Number. SAN이 서버에 제공하는 논리 볼륨 |
| FC | Fibre Channel. 스토리지용 고속 네트워크 |
| iSCSI | IP 네트워크로 SCSI 블록 접근을 전달하는 프로토콜 |
| 블록 | 디스크의 고정 크기 저장 단위 |
