# 12일차 · 리눅스 서버 구축

> 2단계 · 서버 구축 및 활용 — 상위: [네트워크 2](../README.md)
> 이전: [11일차 · 서버 보안](../day-11/README.md) · 다음: [13일차 · Git 과 GitHub](../day-13/README.md)

9일차에 서버를 **한 대** 만들고 **SSH 서버 하나**를 세웠다.
10일차에 **서버 = 포트를 열고 기다리는 프로그램**임을 `ss` 로 확인했고, 11일차에 그 문을 **지키는 법**(방화벽 · ACL)을 배웠다.

오늘은 **문을 여러 개 연다.** 8일차 패킷트레이서 `Server0` 에서 **체크박스 하나**로 켰던 것들 —
DNS · FTP · Mail · Proxy — 를 **리눅스에서 손으로** 세운다.

> 🗣 **오늘의 핵심 메시지: "서버 종류는 달라도, 세우는 순서는 똑같다."**
> **① 설치 → ② 설정 → ③ 기동 → ④ 확인 → ⑤ 개방 → ⑥ 검증** — 이 여섯 단계를 **여섯 번 반복**하는 날이다.

| 질문 | 오늘의 답 | 노트 |
|------|-----------|------|
| 서버를 세운다는 게 **무슨 일**인가? | **여섯 단계** — 오늘 하루의 뼈대 ⭐ | 1 |
| 9일차 SSH 는 **설정도 안 보고** 켰는데? | `sshd_config` · **공개키 인증** · `scp` · `sftp` | 2 |
| `scp` 가 있는데 왜 **FTP** 를? | 연결이 **둘**이라 방화벽·NAT 와 부딪친다 · **평문의 증거** ⭐ | 3 |
| 매번 **복사**하는 게 맞나? | **NFS** — 폴더째 붙여 쓴다 (마운트) | 4 |
| `/etc/hosts` 를 PC 100대에 적을 건가? | **DNS 서버(bind9)** — 이제 **대답하는 쪽**이 된다 ⭐ | 5 |
| 방금 적은 **MX 레코드**는 뭐 하는 건가? | **메일의 한살이** — SMTP · POP3 · IMAP | 6 |
| 회사에서 특정 사이트는 왜 막히나? | **프록시** — 7계층에서 보고 판단한다 | 7 |
| 안 되면 **어디부터** 볼까? | 표 한 장 + **5단계 점검** | 8 |

## 🎯 오늘의 목표

- 리눅스 서버 구축의 **여섯 단계**를 순서대로 적용해 서비스를 세운다
- **`systemctl` · `ss` · `journalctl`** 을 세트로 써서 **기동 → 확인 → 로그**를 돌린다
- `sshd_config` 를 고쳐 SSH 를 **단단하게** 하고, **공개키 인증**으로 로그인한다
- **vsftpd** 로 FTP 서버를 세우고, **제어 연결 / 데이터 연결**과 **패시브 모드**를 설명한다
- `tcpdump` 로 **평문 프로토콜의 비밀번호 노출을 직접 목격**하고, SFTP 와 비교한다 ⭐
- **NFS** 로 폴더를 공유하고 **마운트** 개념을 잡는다
- **bind9** 로 내 도메인의 존 파일을 작성하고 **`dig`** 로 검증한다 ⭐
- **메일의 한살이**(SMTP · MX · POP3/IMAP)를 설명하고, `nc` 로 메일 한 통을 보낸다
- **프록시**(포워드/리버스)를 구분하고, squid 로 **캐시와 차단**을 확인한다
- 서비스가 안 될 때 **`localhost 는 되나요?`** 로 문제를 절반으로 쪼갠다

## 📝 진행 메모

- 🚨 **선행 확인 — 11일차에서 `ufw` 를 못 했다**(6 · 7 · 8번 미진행) → [11일차 실제 진행](../day-11/README.md)
  - 그래서 **`ufw` 를 오늘 1번 절(⑤ 개방)에서 처음 켠다.** 11일차 6번 노트의 핵심이 [여기로 흡수](lesson-1.md)됐다

  - ⚠️ VM 어댑터는 **브릿지** — 매 수업 **IP 가 바뀔 수 있다.** `ip a` 로 먼저 확인

- ⚠️ **진도가 하루씩 밀려 있다**(9일차 실제 진행 기준). 11일차 뒷부분이 12일차로 넘어오면 **오늘 6(메일) · 7(프록시)을 이론으로 압축**하고 3 · 5 를 지킨다
