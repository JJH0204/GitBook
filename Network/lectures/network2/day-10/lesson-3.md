# 3. 사용자 · 권한 · sudo — 아무나 지우면 안 된다

> 상위: [10일차 · 서버 기초](README.md)

## 🎯 학습 목표

- **root** 와 일반 사용자의 차이, **`sudo`** 의 역할을 안다
- `ls -l` 의 **권한 10글자**(`-rwxr-xr--`)를 읽는다
- `chmod` 로 권한을 **숫자(755 · 644)** 와 **기호(u+x)** 로 바꾼다
- **`apt`** 로 프로그램을 설치 · 업데이트한다

→ 리눅스는 **"누가 · 어떤 파일을 · 무엇까지 할 수 있는지"** 를 파일마다 정해 둔다 = **권한**

## 📖 ① root 와 sudo — 마스터키는 잠깐만 빌린다

| | 일반 사용자 (`student`) | 관리자 (**root**) |
|---|---|---|
| 프롬프트 | `$` | **`#`** |
| 할 수 있는 일 | **내 홈** 안의 일 | **전부** (시스템 삭제까지) |

```bash
cat /etc/shadow                  # ❌ Permission denied — 비밀번호 파일은 root 만
sudo cat /etc/shadow             # ✅ 내 비밀번호를 한 번 더 묻고 → 관리자 권한으로 실행
```

- **`sudo`** = **S**uper**u**ser **Do** — **"이 명령 하나만** 관리자로 실행"
- 우분투는 설치 때 만든 사용자에게 `sudo` 자격을 준다 (root 로 직접 로그인하는 건 막아 둠)
- 한 번 비밀번호를 치면 **15분간** 다시 안 묻는다

> 💡 **비유: 관리실 마스터키.** 평소에는 **내 방 열쇠**만 들고 다닌다. 공용 설비를 고칠 때만 관리실에서 **마스터키를 잠깐 빌리고(sudo), 이름을 적고(로그), 돌려준다.**
> 마스터키를 **항상 들고 다니면**(root 로 로그인) 실수 한 번이 건물 전체를 무너뜨린다.

> 📌 **1단계 회수**: 시스코 `enable` 과 같은 발상이다. `Router>` 에서 `enable` 해야 `Router#` 이 되듯, 리눅스는 **명령마다 `sudo`** 를 붙인다.
> 8일차에 `enable secret` 으로 **관리자 모드에 비밀번호**를 걸었다 → 리눅스 `sudo` 도 비밀번호를 묻는다.

> ⚠️ `sudo` 는 **"확실할 때만"**. 특히 AI 가 알려준 `sudo rm ...` 은 [5_AI로_명령어_검증](lesson-5.md) 의 체크리스트를 거친다.

## 📖 ② 권한 10글자 읽기 ⭐

```bash
$ ls -l
-rwxr-xr-- 1 student student  120 Sep 20 10:00 run.sh
drwxr-xr-x 2 student student 4096 Sep 20 10:00 lab
```

```
 -  rwx  r-x  r--    student  student
 ┬  ─┬─  ─┬─  ─┬─    ───┬───  ───┬───
 │   │    │    │        │        └ 그룹 (group)
 │   │    │    │        └───────── 주인 (user / owner)
 │   │    │    └── 나머지 모두 (others) : 읽기만
 │   │    └─────── 그룹 : 읽기 · 실행
 │   └──────────── 주인 : 읽기 · 쓰기 · 실행
 └──────────────── 종류 : - 파일 · d 디렉터리 · l 링크
```

| 글자 | 파일에서 | 디렉터리에서 | 숫자 |
|------|----------|--------------|------|
| **r** (read) | 내용 **읽기** | 목록 **보기** (`ls`) | **4** |
| **w** (write) | 내용 **고치기** | 안에 파일 **만들기 · 지우기** | **2** |
| **x** (execute) | **실행** | 안으로 **들어가기** (`cd`) | **1** |
| `-` | 없음 | 없음 | 0 |

> 💡 **비유: 공유 문서의 권한 설정.** 구글 문서의 **소유자 · 편집자 · 뷰어** 와 같다.
> 리눅스는 대상이 **주인 · 그룹 · 나머지** 셋이고, 각각에 **읽기 · 쓰기 · 실행**을 켜고 끈다.

## 📖 ③ 권한 바꾸기 — `chmod` · `chown`

### 숫자 방식 — 세 자리 = 주인 · 그룹 · 나머지

| 숫자 | = | 글자 | 흔한 쓰임 |
|------|---|------|-----------|
| **7** | 4+2+1 | `rwx` | |
| **6** | 4+2 | `rw-` | |
| **5** | 4+1 | `r-x` | |
| **4** | 4 | `r--` | |
| **755** | | `rwxr-xr-x` | **실행 파일 · 디렉터리** (주인만 수정, 모두 실행) |
| **644** | | `rw-r--r--` | **일반 파일** (주인만 수정, 모두 읽기) |
| **600** | | `rw-------` | **비밀 파일** (SSH 키 · 비밀번호) — 주인만 |

```bash
chmod 755 run.sh          # 숫자로
chmod u+x run.sh          # 기호로: user 에게 + execute   (g 그룹 · o 나머지 · a 전부)
chmod o-r secret.txt      # others 에게서 read 빼기
```

- 서브넷팅에서 **2진수 비트**를 켜고 끄던 것과 같다 → `rwx` = `111` = 7 · `r-x` = `101` = 5 → [3_Bit_Byte_문자코드](../../network1/day-01/lesson-3.md)

### 주인 바꾸기 — `chown`

```bash
sudo chown root:root run.sh      # 주인:그룹 → root 로 (남의 파일을 바꾸니 sudo)
```

> ⚠️ **`chmod 777`** (모두에게 전부 허용) 은 **"안 되니까 일단 777"** 의 대명사다. 보안 구멍 → 11일차 서버 보안에서 다시.

## 📖 ④ 프로그램 설치 — `apt`

9일차에 `sudo apt install openssh-server` 로 SSH 서버를 깔았다. 그때 이유 없이 붙인 **`sudo`** 의 정체가 ① 이고, 이번엔 **`apt`** 를 제대로 본다.

리눅스는 프로그램을 **웹에서 exe 로 받지 않는다.** 공식 **저장소(창고)** 에서 받는다.

| 명령 | 뜻 |
|------|----|
| `sudo apt update` | 창고의 **최신 목록**을 받아온다 (설치는 안 함) |
| `sudo apt upgrade` | 깔린 프로그램을 **최신으로** |
| **`sudo apt install 이름`** | 설치 (`-y` = 묻지 말고 yes) |
| `sudo apt remove 이름` | 삭제 |
| `apt search 단어` | 찾기 |

```bash
sudo apt update
sudo apt install -y tree
tree ~                    # 홈 디렉터리를 나무 모양으로
```

> 💡 **비유: 스마트폰 앱스토어.** `update` = 스토어 목록 새로고침 · `install` = 설치 버튼. 검증된 창고에서만 받으니 안전하다.

- 왜 `sudo`? → 프로그램은 **`/usr/bin` 같은 시스템 디렉터리**에 깔린다 = 남의(root) 방 → 마스터키 필요
- 12일차 서버 구축 = 사실상 **`sudo apt install 서버프로그램` + 설정 파일 수정** 의 반복이다

## 🧪 질문 / 실습

- 실습 STEP 3 → [0_실습_명령어_모음](commands.md)
- "`-rw-r--r--` 을 숫자로?" → **644**

- "디렉터리에 `r` 은 있는데 `x` 가 없으면?" → 목록은 보이는데 **들어갈 수(`cd`)는 없다**
- "`apt install` 앞에 `sudo` 를 안 붙이면?" → `Permission denied` (시스템 폴더에 못 쓴다)
- "`sudo` 와 시스코 `enable` 의 공통점?" → **관리자 권한으로 올라가기** + **비밀번호로 보호**

## 📝 강의 메모

- **"신입이 `/etc` 를 지우면?"** 으로 열면 권한의 필요성이 바로 전달된다
- 권한 10글자는 **칠판에 3칸으로 쪼개서** — `rwx | r-x | r--` 로 끊어 읽는 연습만 반복
- 숫자 권한은 **2진수 비트 켜기**(1일차) 로 연결 → `r=4 w=2 x=1` 만 외우면 나머지는 덧셈
- `755` · `644` · `600` **세 개만** 외우게 한다
- `apt update` 는 강의실 동시 접속으로 느릴 수 있다 → 다 같이 한 번에 치게 하고 기다리는 동안 권한 문제 풀이
