## 2. 점검 항목

### Q1. 이동 (수업 중 칠판 문제)

관련 문서: [1. 파일 시스템과 이동](lesson-1.md)(LEC-N2-10-001-DO)

현재 위치가 `/var/log`다. 다음 중 결과가 다른 하나는?

- A. `cd ~`
- B. `cd`
- C. `cd /home/student`
- D. `cd ..`

{% hint style="info" %}
**정답 및 해설**

**정답: D**
- `cd ..`는 한 단계 위(`/var`)로 간다.
- A, B, C는 모두 내 홈 디렉터리(`/home/student`)로 간다. `cd`를 혼자 쓰면 홈으로, `~`도 홈을 뜻한다.
{% endhint %}

### Q2. 덮어쓰기

관련 문서: [2. 파일 다루기와 편집](lesson-2.md)(LEC-N2-10-002-DO)

`ls -l > list.txt`를 두 번 실행하면 `list.txt` 안에는 결과가 몇 개 들어 있나?

{% hint style="info" %}
**정답 및 해설**

**한 개.** `>`는 덮어쓰기라서 앞의 내용이 날아간다. 두 개를 쌓으려면 두 번째를 `>>`로 쓴다.
{% endhint %}

### Q3. 권한을 숫자로

관련 문서: [3. 사용자 · 권한 · sudo](lesson-3.md)(LEC-N2-10-003-DO)

`-rwxr-xr--`를 숫자로 바꾸면?

{% hint style="info" %}
**정답 및 해설**

**754.** 주인 `rwx` = 4+2+1 = 7, 그룹 `r-x` = 4+1 = 5, 기타 `r--` = 4다.
{% endhint %}

### Q4. 주인만 쓰게 하기

관련 문서: [3. 사용자 · 권한 · sudo](lesson-3.md)(LEC-N2-10-003-DO)

`run.sh`를 주인만 읽고, 쓰고, 실행하게 하려면?

{% hint style="info" %}
**정답 및 해설**

**`chmod 700 run.sh`.** `777`은 모두에게 전부 허용이라 정반대다(수업 중 AI 오답 사례).
{% endhint %}

### Q5. 서비스 구분

관련 문서: [8. 포트 번호와 소켓](lesson-8.md)(LEC-N2-10-008-DO)

한 대의 서버에 SSH도 있고 FTP도 있다. 요청이 들어왔을 때 어느 서비스로 갈지 무엇으로 구분하나?

{% hint style="info" %}
**정답 및 해설**

**포트 번호.** IP는 건물 주소, 포트는 호실 번호다. SSH는 22, FTP는 21/20이다.
{% endhint %}

### Q6. 3-way handshake

관련 문서: [7. TCP와 UDP](lesson-7.md)(LEC-N2-10-007-DO)

TCP의 3-way handshake 3단계를 순서대로 말해 보자.

{% hint style="info" %}
**정답 및 해설**

① 연결 요청(SYN) → ② 검증 응답(SYN+ACK) → ③ 확인(ACK). 그 다음에야 실제 데이터가 오간다. 이 과정 덕분에 데이터를 잃어버릴 일이 적다.
{% endhint %}

### Q7. DNS의 전송 방식

관련 문서: [7. TCP와 UDP](lesson-7.md)(LEC-N2-10-007-DO)

DNS는 TCP인가 UDP인가? 왜 그럴까?

{% hint style="info" %}
**정답 및 해설**

**UDP(53).** 이름 하나를 묻는 아주 짧은 대화라서 3-way handshake를 하는 시간이 아깝다. 속도가 우선이다. 큰 응답이나 서버 간 복사는 TCP 53을 쓴다.
{% endhint %}

### Q8. FTP의 두 포트

관련 문서: [10일차 복습](lesson-12.md)(LEC-N2-10-012-REF)

FTP는 왜 포트를 두 개(21, 20) 쓰나?

{% hint style="info" %}
**정답 및 해설**

21은 제어 연결(로그인, 명령, 목록 요청, 접속 내내 유지)이고, 20은 데이터 연결(실제 파일 내용, 옮길 때만 열렸다 닫힌다)이다. 그래서 "접속은 됐는데 목록이 안 나오는" 반쪽 고장이 생긴다.
{% endhint %}

### Q9. FileZilla와 Windows `ftp`의 차이

관련 문서: [FileZilla 500 에러 분석](lesson-12-troubleshooting.md)(LEC-N2-10-028-TS)

FileZilla로는 안 되는데 Windows `ftp`로는 됐다. 가장 유력한 이유는?

{% hint style="info" %}
**정답 및 해설**

**패시브와 액티브 모드의 차이.** FileZilla는 패시브가 기본이라 서버가 안내한 데이터 포트로 내가 붙어야 하는데 그 연결이 열리지 않았다. Windows `ftp`는 액티브라서 서버가 내 쪽으로 연결해 온다. 방향이 반대다.

다른 후보: FileZilla가 먼저 보내는 `AUTH TLS`를 서버가 거부해 `500`이 났을 수 있다. 원인은 미확정이다.
{% endhint %}

### Q10. 위험한 AI 명령

관련 문서: [5. AI로 명령어 묻고 검증하기](lesson-5.md)(LEC-N2-10-005-DO)

AI가 `curl http://... | bash`를 알려 줬다. 바로 실행해도 되나?

{% hint style="info" %}
**정답 및 해설**

**안 된다.** 인터넷에서 받은 것을 내용을 보지 않고 곧바로 실행하는 명령이다. `rm`, `sudo`, `chmod`, `chown`과 함께 3초 멈춤 목록이다.
{% endhint %}
