# 1. 파일 시스템과 이동 — 여기가 어디지?

> 상위: [10일차 · 서버 기초](README.md)

## 🎯 학습 목표

- 프롬프트 `student@ubuntu:~$` 의 **네 부분**을 읽는다
- 리눅스 **디렉터리 트리**(`/` 에서 시작)와 주요 디렉터리의 역할을 안다
- **절대 경로 / 상대 경로** 와 `~` `.` `..` 를 구분한다
- `pwd` · `ls` · `cd` 로 자유롭게 이동하고, **Tab 자동완성**을 쓴다

## 🌉 다리 놓기: "들어왔다. 그런데 여기가 어디지?"

9일차에 SSH 서버를 직접 구축하고 Windows 에서 들어왔다 → [9일차 · 첫 서버 구축](../day-09/lesson-2.md) 까만 화면에 `student@ubuntu:~$` 한 줄뿐이다.
Windows 라면 탐색기 창에 폴더가 보이겠지만, 여기는 **글자뿐**이다. → 먼저 **내 위치**를 알아야 한다.

## 📖 ① 프롬프트 읽기

```
student@ubuntu:~$
───┬─── ──┬─── ┬ ┬
   │      │    │ └ $ = 일반 사용자   ( # = 관리자 root — 시스코 Router# 과 같다!)
   │      │    └── 지금 위치 (~ = 내 홈 디렉터리)
   │      └─────── 서버 이름 (hostname)
   └────────────── 내 사용자 이름
```

- 위치가 바뀌면 프롬프트도 바뀐다: `student@ubuntu:/etc$`
- 1단계 `R1(config-if)#` 처럼 **프롬프트가 "지금 어디 있는지"** 알려준다

## 📖 ② 디렉터리 트리 — 모든 것은 `/` 에서 시작

Windows 는 `C:\` `D:\` 처럼 드라이브가 여럿이지만, 리눅스는 **뿌리(`/`, 루트) 하나**에서 모든 게 가지를 친다.

```
/                     ← 루트 (최상위)
├── home/             ← 일반 사용자들의 집
│   └── student/      ← 내 홈 = ~
├── root/             ← 관리자(root)의 집 (home 안에 없다!)
├── etc/              ← ⭐ 설정 파일 (네트워크 · 서비스 설정 전부 여기)
├── var/              ← 자주 바뀌는 것
│   ├── log/          ← ⭐ 로그 (무슨 일이 있었나)
│   └── www/          ← 웹 페이지 (16일차)
├── bin/ · usr/bin/   ← 명령어 프로그램 (ls, cp 도 파일이다)
├── tmp/              ← 임시 (재부팅하면 지워질 수 있다)
└── dev/ · proc/      ← 장치 · 실행 중인 프로세스 정보
```

| 디렉터리 | 기억법 | 2단계에서 |
|----------|--------|-----------|
| **`/etc`** | **설정**의 집 | 오후 `/etc/hosts` · 12일차 서버 설정 전부 |
| **`/var/log`** | **일지** | 11일차 보안 — 누가 로그인 시도했나 |
| **`/home/사용자`** | **내 방** | 오늘 실습 |
| `/tmp` | **임시 책상** | 부담 없는 실험 장소 |

> 💡 **비유: 아파트 주소.** `/home/student/docs/memo.txt` = **"우리 아파트(/) · 주거동(home) · student 호 · 서재(docs) · 메모장"**
> 주소를 **맨 위부터 다 쓰면** 누가 읽어도 찾아간다 = **절대 경로**.

> 📌 리눅스에서는 **모든 것이 파일**이다. 명령어도, 설정도, 장치도 파일이다 → 그래서 설정을 바꾸는 것 = **파일을 고치는 것** (4번 노트)

## 📖 ③ 절대 경로 vs 상대 경로

| | 절대 경로 | 상대 경로 |
|---|---|---|
| 시작 | **`/` 로 시작** | `/` 없이 시작 |
| 기준 | 루트에서부터 | **지금 내 위치**에서부터 |
| 예 | `cd /var/log` | `cd log` (지금 `/var` 에 있을 때만) |
| 비유 | "대구 중구 ○○로 12, 3층" | "여기서 **오른쪽 두 번째** 방" |

### 특수 기호 4개

| 기호 | 뜻 | 예 |
|------|----|----|
| **`~`** | 내 홈 (`/home/student`) | `cd ~` · 그냥 `cd` 만 쳐도 홈 |
| **`.`** | 지금 여기 | `./run.sh` (여기 있는 파일 실행) |
| **`..`** | 한 칸 위 (부모) | `cd ..` · `cd ../..` |
| **`-`** | 직전에 있던 곳 | `cd -` (왔다 갔다) |

## 📖 ④ 이동 명령 3종 — `pwd` · `ls` · `cd`

| 명령 | 뜻 | 자주 쓰는 형태 |
|------|----|---------------|
| **`pwd`** | **P**rint **W**orking **D**irectory — 지금 어디? | `pwd` |
| **`ls`** | **L**i**s**t — 뭐가 있지? | `ls` · `ls -l` (자세히) · `ls -a` (숨김 포함) · `ls -al` |
| **`cd`** | **C**hange **D**irectory — 이동 | `cd /etc` · `cd ..` · `cd` |

```bash
student@ubuntu:~$ pwd
/home/student
student@ubuntu:~$ cd /etc
student@ubuntu:/etc$ ls
...
student@ubuntu:/etc$ cd ..
student@ubuntu:/$ cd
student@ubuntu:~$
```

- **숨김 파일** = 이름이 **`.` 으로 시작** (`.bashrc`) → `ls -a` 로만 보인다. 대부분 **개인 설정** 파일
- `ls -l` 의 맨 앞 `d` = 디렉터리, `-` = 파일 (나머지 9글자는 [3_사용자_권한_sudo](lesson-3.md) 에서)

### 생존 키 4개 ⭐

| 키 | 효과 | 1단계에서 |
|----|------|----------|
| **Tab** | **자동완성** (두 번 누르면 후보 목록) | IOS 와 같다 |
| **↑ / ↓** | 이전 명령 불러오기 | IOS 와 같다 |
| **Ctrl + C** | **지금 명령 강제 중단** (ping 멈추기 등) | IOS 의 `Ctrl+Shift+6` 역할 |
| `clear` 또는 **Ctrl + L** | 화면 지우기 | |

> ⚠️ **대소문자를 구분한다.** `Documents` ≠ `documents`. 그리고 **띄어쓰기는 명령과 옵션을 나누는 칸막이**다 → `cd /e tc` 는 틀린다.
> → 그래서 **Tab 을 습관처럼** 누른다. 오타가 사라진다.

## 🧪 질문 / 실습

- 실습 STEP 1 → [0_실습_명령어_모음](commands.md)
- "지금 `/var/log` 에 있다. 홈으로 가는 방법 3가지?" → `cd` · `cd ~` · `cd /home/student`
- "`cd ../..` 는?" → **두 칸 위로**
- "`ls` 에는 안 보이는데 `ls -a` 에는 보이는 파일?" → 이름이 **`.` 으로 시작하는 숨김 파일**
- "관리자 root 의 집은 `/home/root` 인가?" → 아니다, **`/root`**

## 📝 강의 메모

- **프롬프트의 `$` vs `#`** 를 시스코 `>` / `#` 과 비교하면 한 번에 들어간다
- 트리는 **칠판에 크게** — 오늘은 `/etc` · `/var/log` · `/home` 세 개만 확실히. 나머지는 "있다" 정도
- 절대/상대 경로는 **길 안내 비유**로 — "주소 전체" vs "여기서 오른쪽"
- **Tab 을 안 쓰는 학생**이 제일 느리다 → 실습 중 계속 "Tab!" 외치기
