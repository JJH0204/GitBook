## 1. 프롬프트 읽기

```
student@ubuntu:~$
───┬─── ──┬─── ┬ ┬
   │      │    │ └ $ = 일반 사용자   ( # = 관리자 root — 시스코 Router# 과 같다)
   │      │    └── 지금 위치 (~ = 내 홈 디렉터리)
   │      └─────── 서버 이름 (hostname)
   └────────────── 내 사용자 이름
```

- 위치가 바뀌면 프롬프트도 바뀐다: `student@ubuntu:/etc$`
- 1단계의 `R1(config-if)#`처럼 프롬프트가 지금 어디에 있는지 알려 준다.

## 2. 디렉터리 트리 — 모든 것은 `/`에서 시작

Windows는 `C:\`, `D:\`처럼 드라이브가 여럿이다. 리눅스는 뿌리(`/`, 루트) 하나에서 모든 것이 가지를 친다.

```
/                     ← 루트 (최상위)
├── home/             ← 일반 사용자들의 집
│   └── student/      ← 내 홈 = ~
├── root/             ← 관리자(root)의 집 (home 안에 없다)
├── etc/              ← 설정 파일 (네트워크·서비스 설정 전부 여기)
├── var/              ← 자주 바뀌는 것
│   ├── log/          ← 로그 (무슨 일이 있었나)
│   └── www/          ← 웹 페이지 (16일차)
├── bin/ · usr/bin/   ← 명령어 프로그램 (ls, cp도 파일이다)
├── tmp/              ← 임시 (재부팅하면 지워질 수 있다)
└── dev/ · proc/      ← 장치 · 실행 중인 프로세스 정보
```

| 디렉터리 | 기억법 | 2단계에서 |
|---|---|---|
| `/etc` | 설정의 집 | 오후 `/etc/hosts`, 12일차 서버 설정 전부 |
| `/var/log` | 일지 | 11일차 보안 — 누가 로그인을 시도했나 |
| `/home/<사용자>` | 내 방 | 오늘 실습 |
| `/tmp` | 임시 책상 | 부담 없는 실험 장소 |

{% hint style="info" %}
NOTE: 아파트 주소에 비유한다. `/home/student/docs/memo.txt`는 "우리 아파트(`/`), 주거동(`home`), student 호, 서재(`docs`), 메모장"이다. 주소를 맨 위부터 다 쓰면 누가 읽어도 찾아간다. 이것이 절대 경로다.
{% endhint %}

{% hint style="info" %}
NOTE: 리눅스에서는 모든 것이 파일이다. 명령어, 설정, 장치가 모두 파일이다. 그래서 설정을 바꾸는 것은 파일을 고치는 것이다. → [4. 리눅스의 네트워크](lesson-4.md)
{% endhint %}

## 3. 절대 경로와 상대 경로

| | 절대 경로 | 상대 경로 |
|---|---|---|
| 시작 | `/`로 시작한다 | `/` 없이 시작한다 |
| 기준 | 루트에서부터 | 지금 내 위치에서부터 |
| 예 | `cd /var/log` | `cd log` (지금 `/var`에 있을 때만) |
| 비유 | "대구 중구 ○○로 12, 3층" | "여기서 오른쪽 두 번째 방" |

### 특수 기호 4개

| 기호 | 뜻 | 예 |
|---|---|---|
| `~` | 내 홈(`/home/student`) | `cd ~`. 그냥 `cd`만 입력해도 홈으로 간다 |
| `.` | 지금 여기 | `./run.sh` (여기 있는 파일 실행) |
| `..` | 한 칸 위(부모) | `cd ..`, `cd ../..` |
| `-` | 직전에 있던 곳 | `cd -` (왔다 갔다) |

## 4. 이동 명령 3종 — `pwd` · `ls` · `cd`

| 명령 | 뜻 | 자주 쓰는 형태 |
|---|---|---|
| `pwd` | **P**rint **W**orking **D**irectory — 지금 어디인가 | `pwd` |
| `ls` | **L**i**s**t — 무엇이 있는가 | `ls`, `ls -l`(자세히), `ls -a`(숨김 포함), `ls -al` |
| `cd` | **C**hange **D**irectory — 이동 | `cd /etc`, `cd ..`, `cd` |

```bash
student@ubuntu:~$ pwd
/home/student
student@ubuntu:~$ cd /etc
student@ubuntu:/etc$ ls
...
student@ubuntu:/etc$ cd ..
student@ubuntu:/$ cd
student@ubuntu:~$
```

- 숨김 파일은 이름이 `.`으로 시작한다(`.bashrc`). `ls -a`로만 보인다. 대부분 개인 설정 파일이다.
- `ls -l`의 맨 앞 `d`는 디렉터리, `-`는 파일이다. 나머지 9글자는 [3. 사용자 · 권한 · sudo](lesson-3.md)에서 다룬다.

### 생존 키 4개

| 키 | 효과 | 1단계에서 |
|---|---|---|
| Tab | 자동완성 (두 번 누르면 후보 목록) | IOS와 같다 |
| ↑ / ↓ | 이전 명령 불러오기 | IOS와 같다 |
| Ctrl + C | 지금 명령 강제 중단 (`ping` 멈추기 등) | IOS의 `Ctrl+Shift+6` 역할 |
| `clear` 또는 Ctrl + L | 화면 지우기 | |

{% hint style="warning" %}
CAUTION: 대소문자를 구분한다. `Documents`와 `documents`는 다르다. 띄어쓰기는 명령과 옵션을 나누는 칸막이다. `cd /e tc`는 틀린다. 그래서 Tab을 습관처럼 누른다. 오타가 사라진다.
{% endhint %}

## 5. 확인 질문

- 지금 `/var/log`에 있다. 홈으로 가는 방법 3가지는? → `cd`, `cd ~`, `cd /home/student`
- `cd ../..`는? → 두 칸 위로 간다.
- `ls`에는 안 보이고 `ls -a`에는 보이는 파일은? → 이름이 `.`으로 시작하는 숨김 파일이다.
- 관리자 root의 집은 `/home/root`인가? → 아니다. `/root`다.

## 6. 약어·용어

| 용어 | 뜻 |
|---|---|
| 루트(`/`) | 디렉터리 트리의 최상위 |
| 홈 디렉터리(`~`) | 사용자별 개인 디렉터리. 일반 사용자는 `/home/<사용자>` |
| 절대 경로 | `/`부터 시작하는 전체 경로 |
| 상대 경로 | 현재 위치 기준 경로 |
| 프롬프트 | 명령을 입력하는 줄 앞의 `사용자@서버:위치$` 표시 |
| hostname | 서버 이름 |

## 진행 메모

- 프롬프트의 `$`와 `#`를 시스코의 `>`와 `#`에 비교하면 한 번에 들어간다.
- 트리는 칠판에 크게 그린다. 오늘은 `/etc`, `/var/log`, `/home` 세 개만 확실히 다룬다. 나머지는 "있다" 정도로 넘긴다.
- 절대 경로와 상대 경로는 길 안내 비유로 설명한다. "주소 전체"와 "여기서 오른쪽"이다.
- Tab을 쓰지 않는 학생이 가장 느리다. 실습 중 계속 "Tab!"을 외친다.
