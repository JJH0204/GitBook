## 5. 절차

### A. 내 위치와 내 방 확인

1. (5-A-01) `pwd`를 입력한다. → 결과: `/home/student`
2. (5-A-02) `ls`를 입력한다. → 결과: 출력이 비어 있다.
3. (5-A-03) `ls -a`를 입력한다. → 결과: 숨김 파일(`.bashrc` 등)이 보인다.
4. (5-A-04) `ls -al`을 입력한다. → 결과: 숨김 파일이 자세히 보인다.

### B. 트리 여행 (Tab을 계속 누른다)

1. (5-B-01) `cd /`를 입력한다. → 결과: 프롬프트가 `/`로 바뀐다.
2. (5-B-02) `ls`를 입력한다. → 결과: `bin etc home root tmp var ...`가 보인다.
3. (5-B-03) `cd /etc`를 입력한다. → 결과: 설정의 집이다.
4. (5-B-04) `ls`를 입력한다. → 결과: 설정 파일이 많이 보인다.
5. (5-B-05) `cat hostname`을 입력한다. 상대 경로다. 지금 `/etc`에 있기 때문이다. → 결과: 서버 이름이 출력된다.
6. (5-B-06) `cat /etc/hostname`을 입력한다. 절대 경로다. → 결과: 어디서든 같은 결과가 나온다.
7. (5-B-07) `cd /var/log`를 입력한 뒤 `ls`를 입력한다. → 결과: 일지의 집이다. 로그 파일이 보인다.
8. (5-B-08) `cd ..`를 입력한다. → 결과: 한 칸 위인 `/var`로 간다.
9. (5-B-09) `pwd`를 입력한다. → 결과: `/var`
10. (5-B-10) `cd -`를 입력한다. → 결과: 직전 위치인 `/var/log`로 간다.
11. (5-B-11) `cd`를 입력한다. → 결과: 홈으로 간다.
12. (5-B-12) `pwd`를 입력한다. → 결과: `/home/student`

### C. 생존 키 연습

1. (5-C-01) `ping 127.0.0.1`을 입력한다. → 결과: 끝나지 않고 계속 출력된다.
2. (5-C-02) Ctrl + C를 누른다. → 결과: `ping`이 멈추고 통계가 나온다.
3. (5-C-03) ↑ 키를 눌러 방금 입력한 명령을 불러온다. → 결과: 이전 명령이 입력 줄에 나타난다.
4. (5-C-04) `cd /e`까지 입력하고 Tab을 누른다. → 결과: `cd /etc/`로 자동완성된다.
5. (5-C-05) `clear`를 입력한다. → 결과: 화면이 지워진다.
