## 5. 절차

### A. 실험실 만들기

1. (5-A-01) `cd ~`를 입력한다. → 결과: 홈으로 이동한다.
2. (5-A-02) `mkdir lab`을 입력한다. → 결과: 오류 없이 끝난다.
3. (5-A-03) `cd lab`을 입력한다. → 결과: 프롬프트가 `~/lab`으로 바뀐다.
4. (5-A-04) `mkdir -p docs/2026/09`를 입력한다. → 결과: 중간 디렉터리까지 한 번에 만들어진다.
5. (5-A-05) `touch memo.txt`를 입력한다. → 결과: 빈 파일이 만들어진다.
6. (5-A-06) `ls -l`을 입력한다. → 결과: `docs`(디렉터리)와 `memo.txt`(0바이트)가 보인다.

### B. 쓰고 읽기 (리다이렉션)

1. (5-B-01) `echo "첫째 줄" > memo.txt`를 입력한다. → 결과: 오류 없이 끝난다.
2. (5-B-02) `echo "둘째 줄" >> memo.txt`를 입력한다. → 결과: 오류 없이 끝난다.
3. (5-B-03) `cat memo.txt`를 입력한다. → 결과: 2줄이 보인다.
4. (5-B-04) `echo "덮어버림" > memo.txt`를 입력한다. 다시 `>`를 쓰는 것이 핵심이다.
5. (5-B-05) `cat memo.txt`를 입력한다. → 결과: `덮어버림` 1줄만 남았다.

### C. nano로 편집

1. (5-C-01) `nano memo.txt`를 입력한다. → 결과: nano 편집 화면이 열린다.
2. (5-C-02) 아래 3줄을 입력한다. `192.168.x.x`는 내 VM 주소로 바꾼다.

```
hostname ubuntu
ip 192.168.x.x
gateway 192.168.0.1
```

3. (5-C-03) Ctrl+O를 누르고 Enter를 누른다. → 결과: 파일이 저장된다.
4. (5-C-04) Ctrl+X를 누른다. → 결과: 셸로 돌아온다.
5. (5-C-05) `cat memo.txt`를 입력한다. → 결과: 입력한 3줄이 보인다.

### D. 복사 · 이동 · 이름 바꾸기 · 삭제

1. (5-D-01) `cp memo.txt memo.bak`을 입력한다. 설정 고치기 전 백업 습관이다. → 결과: `memo.bak`이 생긴다.
2. (5-D-02) `mv memo.bak docs/`를 입력한다. → 결과: `memo.bak`이 `docs/`로 이동한다.
3. (5-D-03) `mv memo.txt server.txt`를 입력한다. → 결과: 이름이 `server.txt`로 바뀐다.
4. (5-D-04) `ls -R`을 입력한다. → 결과: 하위까지 목록이 보인다.
5. (5-D-05) `cp -r docs docs_copy`를 입력한다. 디렉터리 복사는 `-r`이다. → 결과: `docs_copy`가 생긴다.
6. (5-D-06) `pwd`로 `~/lab`인지 확인한 뒤 `rm -r docs_copy`를 입력한다. → 결과: `docs_copy`가 사라진다. 휴지통이 없으므로 복구할 수 없다.
7. (5-D-07) `ls`를 입력한다. → 결과: `docs`, `server.txt`만 보인다.

### E. 긴 출력 걸러내기 (파이프, grep)

1. (5-E-01) `grep gateway server.txt`를 입력한다. → 결과: gateway가 든 줄만 나온다.
2. (5-E-02) `ls /etc | grep net`을 입력한다. → 결과: `/etc` 중 net이 들어간 이름만 나온다.
3. (5-E-03) `ls -l /etc | less`를 입력한다. → 결과: 목록을 넘겨 볼 수 있다. Space는 다음, `b`는 이전, `q`는 종료다.
4. (5-E-04) `tail -n 5 /etc/passwd`를 입력한다. → 결과: 마지막 5줄이 나온다.
5. (5-E-05) `grep student /etc/passwd`를 입력한다. → 결과: 내 계정 정보 한 줄이 나온다.
6. (5-E-06) `history | tail -n 10`을 입력한다. → 결과: 방금 입력한 명령 10개가 나온다.

{% hint style="info" %}
NOTE: 시스코 `show running-config | include hostname`은 리눅스 `cat <파일> | grep hostname`과 같다.
{% endhint %}

## 7. 복구

1. (7-01) 실습 파일을 정리하려면 `rm -r ~/lab`을 입력한다. 이후 STEP 3이 `~/lab`을 쓰므로 STEP 3을 마친 뒤에 입력한다.
2. (7-02) 파일을 잘못 덮어썼으면 `~/lab/docs/memo.bak`처럼 백업해 둔 파일에서 `cp`로 되돌린다. 백업이 없으면 복구할 수 없다.
