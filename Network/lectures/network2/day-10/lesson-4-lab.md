## 5. 절차

### A. IP, 마스크, MAC, 게이트웨이 찾기

1. (5-A-01) `ip a`를 입력한다. → 결과: `lo`와 `enp0s3`의 정보가 나온다.
2. (5-A-02) `ip -br a`를 입력한다. → 결과: 한 줄 요약이 나온다(`show ip int brief`와 비슷하다).
3. (5-A-03) `ip route`를 입력한다. → 결과: `default via <게이트웨이>` 줄이 나온다.
4. (5-A-04) `ip neigh`를 입력한다. → 결과: ARP 표가 나온다(3일차).
5. (5-A-05) 아래 메모 칸을 채운다. → 결과: 5칸이 모두 찬다.

```
IP ______ / 마스크 ______ / MAC ______ / 게이트웨이 ______ / dynamic? ______
```

### B. 가까운 곳부터 차례로 확인

1. (5-B-01) `ping -c 4 192.168.0.1`을 입력한다. ① 게이트웨이(강의실 공유기)다. → 결과: 4개 응답이 온다.
2. (5-B-02) `ping -c 4 8.8.8.8`을 입력한다. ② 인터넷 IP다. → 결과: 4개 응답이 온다.
3. (5-B-03) `ping -c 4 google.com`을 입력한다. ③ 이름이며 DNS를 거친다. → 결과: 4개 응답이 온다.
4. (5-B-04) `resolvectl status | grep "DNS Servers"`를 입력한다. → 결과: 내 DNS 서버 주소가 나온다.

### C. Windows와 비교 (보너스)

1. (5-C-01) Windows PowerShell에서 `ipconfig`를 입력한다. → 결과: 기본 게이트웨이가 보인다.
2. (5-C-02) 5-A-03의 게이트웨이와 비교한다. → 결과: 같으면 브릿지가 제대로 된 것이다.

## 6. 기능 확인
