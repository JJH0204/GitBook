## 학습 목표

오전 — 리눅스 기본 명령

- 리눅스 디렉터리 트리와 절대·상대 경로를 이해하고 자유롭게 이동한다.
- 파일과 디렉터리를 만들고, 복사, 이동, 삭제하고, `nano`로 편집한다.
- 파이프 `|`와 `grep`으로 긴 출력에서 원하는 줄만 뽑는다.
- `ls -l`의 권한 10글자를 읽고 `chmod`로 바꾼다.
- `ip a`, `ip route`, `ping`으로 1단계에서 배운 IP와 게이트웨이를 리눅스에서 찾는다.
- AI에게 명령어를 묻고, 출력을 직접 해석하고 검증한다.

오후 — 서버 기초

- 서버는 포트를 열고 기다리는 프로그램임을 `ss`로 확인한다.
- TCP와 UDP의 차이를 설명하고, 3-way handshake를 `tcpdump`로 직접 본다.
- Well-known 포트를 외우고, IP + 포트 = 소켓을 이해한다.
- NAT(PAT)와 포트포워딩을 설명하고 VirtualBox 설정의 정체를 안다.
- 리눅스에서 DNS(`/etc/hosts`, `dig`)와 DHCP(임대 시간, netplan)를 확인한다.

## 오늘의 실습 환경 — 9일차 VM 그대로

오전에는 PowerShell 창 하나로 SSH한다. 오후에는 창 3개(서버 창, 클라이언트 창, 관찰 창)를 쓴다.

```
        [ 강의실 공유기 192.168.0.1 ]
                   │  ← 브릿지: VM이 직접 IP를 받는다
   ┌───────────────┼───────────────┐
 Windows           │           옆자리 PC
  창① ② ③ ssh student@192.168.x.x
  브라우저 http://192.168.x.x:8080
                   └── Ubuntu VM 192.168.x.x
```

{% hint style="warning" %}
CAUTION: 브릿지와 DHCP 때문에 VM 주소가 매주 바뀔 수 있다. 수업 시작마다 `ip a`로 확인한다.
{% endhint %}

## 진행 메모

- 오전은 "9일차에 들어온 서버, 이제 안에서 일해 봅시다"로 연다.
  - 비유: 디렉터리 트리는 아파트 동·호수 주소, `rm`은 파쇄기, 파이프는 컨베이어 벨트, `sudo`는 관리실 마스터키다.
  - 가장 반가운 회수: 시스코 `| include`는 리눅스 `| grep`, 시스코 `enable`은 리눅스 `sudo`다.
  - 오전 마지막(4번)에 각자의 IP와 게이트웨이를 칠판에 적게 하고 답은 오후로 미룬다.
- 오후는 "9일차에 그냥 따라 한 것들"로 연다. 칠판에 각자 IP, 게이트웨이, `port 22`를 적어 두고 하나씩 지운다.
- 오늘의 핵심 질문: "내 VM은 사설 IP인데 어떻게 인터넷에 나갔을까?" → NAT. "내 Windows에서는 왜 바로 들어가졌을까?" → 브릿지라 같은 동네였다. 집 밖에서 들어오려면 포트포워딩이다. 이 둘이 한 쌍이라는 것을 잡으면 오늘이 끝난다.
- 오후 비유: 서버는 가게 문 열고 기다리는 점원, TCP는 등기우편, UDP는 전단지, IP는 건물, 포트는 호실, NAT는 회사 대표번호, 포트포워딩은 내선 연결이다.
- 최대 병목은 세 가지다.
  1. 오전: Tab을 쓰지 않는다. 대소문자. `>`로 덮어써서 파일을 날린다.
  2. 오후: 창 3개의 역할을 혼동한다. 칠판에 ① 서버, ② 클라, ③ 관찰을 적는다.
  3. 오후: `python3 -m http.server`를 띄운 창에서 다른 명령을 치려 한다. 그 창은 서버가 점유 중이다.
- 오늘의 회수 지점:
  1. 9일차 `systemctl status ssh`의 `Server listening on 0.0.0.0 port 22` → 오후 `ss`의 `:22 LISTEN`
  2. 9일차 브릿지 어댑터와 받은 IP → DHCP, NAT, (집 밖에서라면) 포트포워딩
  3. 2일차 사설 IP와 NAT 맛보기("회사 대표번호") → 오늘 본편 → [3. 공인 IP와 사설 IP](../../network1/day-02/lesson-3.md)
  4. 1일차 OSI 4계층(전송) → TCP/UDP → [6. 프로토콜과 OSI 7계층](../../network1/day-01/lesson-6.md)
