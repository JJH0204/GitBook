# 10일차 · 서버 기초

> 2단계 · 서버 구축 및 활용 — 상위: [네트워크 2](../README.md)
> 이전: [9일차 · 리눅스 설명](../day-09/README.md) · 다음: [11일차 · 서버 보안](../day-11/README.md)

9일차에 리눅스 서버를 한 대 만들고, **SSH 서버를 직접 구축**해서 Windows 에서 들어갔다.
오늘은 두 덩어리다.

- 🌅 **오전 — 들어온 서버 안에서 일하는 법** (9일차 이월): 돌아다니고 · 파일을 만지고 · 권한을 다루고 · 네트워크를 확인하고 · AI 에게 묻고 검증한다
- 🌇 **오후 — 서버가 요청을 받는다는 것**: 9일차에 **그냥 따라 한 것들**의 정체를 밝힌다
  1. 서버 주소 **`192.168.x.x`** 는 **누가** 줬지? 게이트웨이 **`192.168.0.1`** 은 누구지?
  2. 내 Windows 에서 **그 주소로 바로** SSH 가 된 이유는? (**브릿지**)
  3. `systemctl status ssh` 의 **`Server listening on 0.0.0.0 port 22`** — 22 는 뭐지?

| 질문 | 오늘의 답 | 노트 |
|------|-----------|------|
| 🌅 들어왔다. **여기가 어디지?** | 파일 시스템 트리 · 경로 · `pwd` `ls` `cd` | 1 |
| 🌅 파일을 **만들고 · 옮기고 · 고치고 · 찾기** | `mkdir` `cp` `mv` `rm` `cat` `nano` · 파이프 `\|` · `grep` | 2 |
| 🌅 아무나 **지워도** 되는가 | 사용자 · **권한(rwx)** · `sudo` · `apt` | 3 |
| 🌅 이 서버의 **네트워크**는? | `ip a` · `ip route` · `ping` — **1단계 `ipconfig` 의 리눅스판** | 4 |
| 🌅 명령어를 **AI 에게 물어봐도** 되나? | 된다. 단, **출력은 내가 해석하고 검증**한다 | 5 |
| 🌇 서버란 **무엇**인가? | 요청을 **기다렸다가 응답하는 프로그램** | 6 |
| 🌇 요청은 **어떻게 운반**되나? | **TCP**(등기우편) 또는 **UDP**(전단지) | 7 |
| 🌇 한 서버에 서비스가 여럿이면? | **포트 번호** (IP = 건물, 포트 = 호실) | 8 |
| 🌇 사설 IP 서버는 어떻게 인터넷에? 밖에서 어떻게 들어오나? | **NAT** · **포트포워딩** ← 떡밥 1 · 2 회수 | 9 |
| 🌇 주소와 이름은 **누가** 알려주나? | **DHCP** · **DNS** — 리눅스 쪽에서 | 10 |

> 📌 원래 10일차였던 **무선랜 · PT 공유기 실습**은 분량 때문에 **11일차 앞부분**으로 옮겼다 → [11일차](../day-11/README.md)

## 🎯 오늘의 목표

**🌅 오전 — 리눅스 기본 명령**
- 리눅스 **디렉터리 트리**와 **절대/상대 경로**를 이해하고 자유롭게 이동한다
- 파일 · 디렉터리를 만들고 · 복사 · 이동 · 삭제하고, **`nano`** 로 편집한다
- **파이프 `|`** 와 **`grep`** 으로 긴 출력에서 원하는 줄만 뽑는다
- `ls -l` 의 **권한 10글자**를 읽고, `chmod` 로 바꾼다
- `ip a` · `ip route` · `ping` 으로 **1단계에서 배운 IP · 게이트웨이**를 리눅스에서 찾는다
- 🤖 **AI 에게 명령어를 묻고, 출력을 직접 해석 · 검증**한다

**🌇 오후 — 서버 기초**
- 서버 = **포트를 열고 기다리는 프로그램**임을 `ss` 로 확인한다
- **TCP 와 UDP** 의 차이를 설명하고, **3-way handshake** 를 `tcpdump` 로 직접 본다
- **Well-known 포트**를 외우고, **IP + 포트 = 소켓** 을 이해한다
- **NAT(PAT)** 와 **포트포워딩**을 설명하고, VirtualBox 설정의 정체를 안다
- 리눅스에서 **DNS**(`/etc/hosts` · `dig`) 와 **DHCP**(임대 시간 · netplan) 를 확인한다

## 🧪 오늘의 실습 환경 — 9일차 VM 그대로

**🌅 오전** — PowerShell **창 하나**로 SSH. **🌇 오후** — **창 3개**(서버 창 · 클라이언트 창 · 관찰 창)

```
        [ 강의실 공유기 192.168.0.1 ]
                   │  ← 브릿지: VM 이 직접 IP 를 받는다
   ┌───────────────┼───────────────┐
 🪟 Windows        │           옆자리 PC
  창① ② ③ ssh student@192.168.x.x
  🌐 브라우저 http://192.168.x.x:8080
                   └── 🐧 Ubuntu VM 192.168.x.x
```

> ⚠️ **브릿지 + DHCP** 라 VM 주소가 **매주 바뀔 수 있다.** 수업 시작마다 `ip a` 로 확인한다.

## 📝 진행 메모

- **오전**은 **"9일차에 들어온 서버, 이제 안에서 일해 봅시다"** 로 연다
  - 비유: **디렉터리 트리 = 아파트 동·호수 주소** · **`rm` = 파쇄기** · **파이프 = 컨베이어 벨트** · **sudo = 관리실 마스터키**
  - 가장 반가운 회수: 시스코 **`| include`** = 리눅스 **`| grep`** · 시스코 **`enable`** = 리눅스 **`sudo`**
  - 오전 마지막(4번)에 **각자의 IP · 게이트웨이**를 칠판에 적게 하고 **답은 오후로**
- **오후**는 **"9일차에 그냥 따라 한 것들"** 로 연다 — 칠판에 **각자 IP** · **게이트웨이** · `port 22` 를 적어두고 **하나씩 지운다**
- 🗣 **오늘의 핵심 질문**: **"내 VM 은 사설 IP 인데, 어떻게 인터넷에 나갔을까?"**
  → **NAT**. 그리고 **"내 Windows 에서는 왜 바로 들어가졌을까?"** → **브릿지라 같은 동네**였다
  → 집 밖에서 들어오려면? **포트포워딩**. 이 둘이 **한 쌍**이라는 걸 잡으면 오늘 끝
- 오후 비유: **서버 = 가게 문 열고 기다리는 점원** · **TCP = 등기우편 / UDP = 전단지** · **IP = 건물 / 포트 = 호실** · **NAT = 회사 대표번호, 포트포워딩 = 내선 연결**
- ⚠️ 최대 병목
  1. 오전: **Tab 을 안 쓴다** · 대소문자 · `>` 로 덮어써서 파일 날림
  2. 오후: **창 3개** 역할 혼동 → 칠판에 **① 서버 ② 클라 ③ 관찰**
  3. 오후: `python3 -m http.server` 를 띄운 창에서 **다른 명령을 치려 한다** → 그 창은 **서버가 점유 중**
- **오늘의 회수 지점**
  1. 9일차 **`systemctl status ssh` → `Server listening on 0.0.0.0 port 22`** → 오후 `ss` 의 `:22 LISTEN`
