## 5. 절차

### A. 포트표 읽기

1. (5-A-01) 창 ②에서 다음 명령을 입력한다.

```bash
grep -w -E "ftp|ssh|telnet|domain|http|https|snmp" /etc/services
```

→ 결과: 각 서비스의 포트와 프로토콜이 나온다. `domain 53/tcp`와 `domain 53/udp`가 모두 있다(DNS는 둘 다). `ssh 22/tcp`가 있다.

### B. 1023 이하는 root만

1. (5-B-01) 창 ②에서 `python3 -m http.server 80`을 입력한다. → 결과: `PermissionError`가 나온다. Well-known 포트다.
2. (5-B-02) 혹시 서버가 떠 있으면 Ctrl + C를 누른다. → 결과: 프롬프트로 돌아온다.

### C. 내 SSH 연결들 (소켓 4개 값)

1. (5-C-01) 창 ③에서 `ss -tn | grep :22`를 입력한다. → 결과: 아래와 같이 연결 3개가 나온다.

```
ESTAB 0 0  192.168.0.42:22   192.168.0.7:50514     ← 창 ①
ESTAB 0 0  192.168.0.42:22   192.168.0.7:50522     ← 창 ②   (상대 포트가 다르다 → 안 섞인다)
ESTAB 0 0  192.168.0.42:22   192.168.0.7:50530     ← 창 ③
```

2. (5-C-02) 상대 주소를 Windows `ipconfig`의 IP와 비교한다. → 결과: 전부 내 Windows IP와 같다. 브릿지라서 중간에 바뀌지 않는다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `/etc/services` 조회 | DNS가 tcp, udp 두 줄 | 두 줄을 봤다 |
| 2 | 80번 서버 실행 | `PermissionError` | 거절된다 |
| 3 | `ss -tn \| grep :22` | 같은 22번에 상대 포트가 다른 연결 3개 | 상대 포트로 구분됨을 설명한다 |
