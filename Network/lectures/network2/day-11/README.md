## 학습 목표

**이월: 공유기**

- 집 공유기 = 라우터 + NAT + 스위치 + DHCP가 한 상자에 들어 있음을 이해한다.
- 패킷트레이서로 공유기 네트워크(유선)를 만들고 NAT 변환을 시뮬레이션으로 확인한다.
- 밖에서 먼저는 들어올 수 없다는 것을 확인하고, 그것이 NAT의 부수 효과임을 안다.

**서버 보안**

- 공격 표면이 무엇인지 알고 `ss -tuln`으로 내 서버의 표면을 센다.
- 최소 권한과 기본 거부(default deny)를 설명한다.
- 표준과 확장 ACL을 작성하고 적용하며, 암묵적 deny any를 실패로 확인한다.
- `ufw`로 포트를 열고 닫고, `enable` 전에 22번을 먼저 여는 이유를 안다.
- 통신이 안 될 때 ① LISTEN → ② 로컬 → ③ 방화벽 → ④ 경로 순으로 좁힌다.

## 읽는 순서

1. LEC-N2-11-001-DO를 읽고 LEC-N2-11-002-MP를 수행한다. 필요하면 LEC-N2-11-003-MP(선택)와 LEC-N2-11-004-TS를 본다.
2. LEC-N2-11-005-DO를 읽고 LEC-N2-11-006-MP를 수행한다.
3. LEC-N2-11-007-DO, LEC-N2-11-008-MP, LEC-N2-11-009-DO, LEC-N2-11-010-MP 순서로 ACL을 배우고 실습한다.
4. LEC-N2-11-011-DO와 LEC-N2-11-012-MP로 ufw를 배우고 실습한다. 12일차의 전제이므로 빼지 않는다.
5. LEC-N2-11-013-DO와 LEC-N2-11-014-MP로 최소 개방을 설계한다.
6. LEC-N2-11-015-TS로 네 단계 좁히기를 익히고 LEC-N2-11-016-MP로 마무리한다.
7. LEC-N2-11-017-INS로 하루를 마무리한다. 실습 중에는 LEC-N2-11-018-REF를 띄워 둔다.

## 진행 메모

- 10일차에 DNS와 DHCP(10번)를 못 했으면 공유기 실습 앞에 붙인다.
- 무선랜 제외: WRT300N을 쓰되 `Wireless` 탭은 건너뛴다. Laptop과 Smartphone도 놓지 않는다.
- WRT300N GUI는 PT 버전마다 조금 다르다. 수업 전에 리허설한다. 특히 `Static DNS` 칸 위치와 포트포워딩 메뉴를 본다.
- 오늘의 수미상관: 3번에서 "옆자리가 내 서버에 들어온다"를 보여 주고, 6번에서 "이제 못 들어온다"로 닫는다.
- `ufw enable` 순서 함정은 미리 경고하고 복구 경로를 칠판에 적어 둔다. 복구 경로는 VirtualBox 창 → 로그인 → `sudo ufw disable`이다.
- 마무리 체크리스트를 반드시 같이 실행한다. 특히 `sudo ufw allow 22/tcp`다. 하지 않으면 다음 주에 아무도 못 들어온다.
- 12일차로 넘길 상태: 방화벽을 켜 둔 채로 끝낸다. 12일차 6단계의 5번째 개방(`ufw allow`)이 실감 난다.
- 발표용 Excalidraw 드로잉은 아직 없다(3층 방어와 네 단계 좁히기는 판서).
- 각 문서의 `강의 메모` 중 수업 운영 팁(도입 멘트, 회수 지점, 시간 배분)은 다음과 같다.
  1. 3번 도입: "지금까지 우리는 계속 열기만 했다. 오늘은 처음으로 닫는다." 옆자리 SSH는 말로 설명하지 말고 먼저 시켜서 놀라게 한다.
  2. 4번 도입: "오늘 아침 NAT에서 쓴 `access-list 1`이 오늘의 주인공이다." 암묵적 deny any는 반드시 실패로 체험시킨다.
  3. 5번 도입: "웹은 되고 SSH만 막아 달라. 표준으로 되는가." 인사팀 웹 허용과 SSH 거부를 두 눈으로 보게 한다.
  4. 6번: 11일차의 핵심이자 12일차의 전제다. 짝을 미리 정하고 서로의 IP를 칠판에 적게 한다.
  5. 7번: "종이 먼저"를 습관으로 심는다. DB 포트 이야기는 겁을 주되 짧게 한다.
  6. 8번: 네 단계 좁히기를 칠판에 적고 사진을 찍게 한다.
  7. 회수 지점: 10일차 `chmod 777` → 방화벽 없음(최소 권한), 10일차 `ss`의 LISTEN → 공격 표면, 5일차 OSPF 와일드카드 → ACL 와일드카드.
  8. 6번에서 vsftpd를 껐다면 12일차 FTP 절에서 다시 켠다(① 설치는 건너뛰고 ③ 기동부터).
