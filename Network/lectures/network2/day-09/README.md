# 9일차 · 리눅스 설명

> 2단계 · 서버 구축 및 활용 — 상위: [네트워크 2](../README.md)
> 이전: [8일차 · 네트워크 장비에서의 서버 설정](../../network1/day-08/README.md) · 다음: [10일차 · 서버 기초](../day-10/README.md)

8일차에 회사망에 **서비스**를 올렸다. SSH · DHCP · DNS · FTP ... 전부 패킷트레이서의 **Server0** 에서 **체크박스를 켜서** 만들었다.
그런데 진짜 회사의 서버실에 있는 서버는 체크박스가 없다. 그 안에서 돌아가는 건 대부분 **리눅스**다.
→ 2단계는 **그 서버를 직접 만든다.** 첫날은 **서버의 운영체제를 설치하고 · 첫 서버(SSH)를 직접 구축하고 · 접속하는 날**이다.

| 질문 | 오늘의 답 | 노트 |
|------|-----------|------|
| 서버는 왜 **리눅스**를 쓰나? | 무료 · 안정 · 원격 관리 · **화면이 필요 없다** | 1 |
| 내 PC 에 서버를 어떻게 **한 대 더** 놓나? | **가상머신**(VirtualBox) + 우분투 설치 | 2 |
| 첫 **서버**는? | `apt` 로 **openssh-server** 설치 → `systemctl` 로 켜기 → **Windows 에서 SSH 접속** | 2 |

> 📌 **실제 진행(2026-09-19)**: 설치 · SSH 서버 구축 · 접속 · 첫 명령 몇 개까지 했다.

## 🎯 오늘의 목표

- 서버가 **리눅스**를 쓰는 이유와 **커널 · 쉘 · 배포판**을 구분한다
- **호스트 · 게스트 · 하이퍼바이저**를 구분하고, VirtualBox 에 **Ubuntu Server 24.04 LTS** 를 설치한다
- **패키지 관리자(`apt`)** 로 **openssh-server** 를 설치하고, `systemctl` 로 **켜고 · 자동 시작 · 상태 확인**한다
- Windows 터미널에서 **SSH 로 접속**하고, 명령의 모양 **`명령어 [옵션] [대상]`** 을 안다

## 🧪 오늘의 실습 환경

```
┌──────────── 내 Windows PC (호스트) ────────────────────┐
│                                                        │
│  Windows 터미널 ── ssh student@192.168.x.x ──┐         │
│                                              │         │
│                   ┌──────────────▼───────────────┐     │
│                   │  VirtualBox VM (게스트)       │     │
│                   │  Ubuntu Server 24.04 LTS     │     │
│                   │  192.168.x.x (브릿지 어댑터)  │     │
│                   └──────────────────────────────┘     │
└────────────────────────────────────────────────────────┘
```

| 항목 | 값 |
|------|-----|
| 가상화 | **VirtualBox 7.x** |
| OS | **Ubuntu Server 24.04 LTS** (화면 없는 서버판) |
| VM 사양 | CPU 2 · RAM 2048MB · 디스크 25GB |
| 네트워크 | **브릿지 어댑터** — 강의실 공유기에서 IP 를 직접 받는다 |
| SSH | 설치 후 **직접 구축** (`apt install openssh-server` · `systemctl enable --now ssh`) |

- 🚨 **사양이 부족하거나 VirtualBox 가 안 되는 PC** → Plan B **WSL** ([2번 노트](lesson-2.md))

## 📝 진행 메모

- **"8일차 Server0 에서 DNS 체크박스를 켰죠. 그 체크박스 뒤에는 무엇이 있었을까?"** 로 연다 → 서비스 = 프로그램 → 그 프로그램이 도는 OS = 리눅스
- 🗣 **오늘의 핵심 질문**: **"서버에는 왜 모니터가 없을까?"** → 서버는 **멀리서(SSH)** 관리한다
- SSH 를 설치 화면에서 체크하지 않고 **설치 후 직접 구축**했다 → **"첫 서버 구축"** 경험이 됐다. `status` 의 `Server listening on 0.0.0.0 port 22` 는 **10일차 오후(포트 · LISTEN)** 에서 회수
- 비유: **커널 = 엔진 · 쉘 = 운전대 · 배포판 = 완성차 브랜드** · **VM = 집 안의 원룸** · **apt = 앱스토어**
- 📌 **떡밥**: VM 이 받은 `192.168.x.x` 는 **누가 줬나** → **10일차 DHCP** 에서 회수
- ⚠️ **브릿지**라 VM 주소가 **매주 바뀔 수 있다.** 수업 시작마다 `ip a` 확인을 습관으로
- 📌 브릿지 선택이 **11일차 서버 보안**의 출발점이다 (교실의 다른 PC 가 내 서버에 닿는다)
- 📌 **VM 은 끄지 말고 저장**하거나 `sudo poweroff` — 다음 주에 **같은 VM 을 계속 쓴다** (9 → 10 → 11 → 12일차)
