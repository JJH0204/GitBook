# 1. 운영체제와 리눅스 — 서버는 왜 리눅스일까

> 상위: [9일차 · 리눅스 설명](README.md)

## 🎯 학습 목표

- **운영체제(OS)** 가 하는 일을 한 문장으로 말한다
- **커널 · 쉘 · 배포판** 을 구분한다
- 서버가 **리눅스**를 쓰는 이유 4가지를 안다
- **GUI 와 CLI** 의 차이를 알고, 서버가 CLI 를 쓰는 이유를 1단계 경험과 연결한다

## 🌉 다리 놓기: "Server0 의 체크박스 뒤에는 무엇이 있었을까?"

8일차에 패킷트레이서 Server0 의 `Services` 탭에서 DNS · DHCP · FTP 를 **클릭 한 번**으로 켰다. → [6_서버설정_실습](../../network1/day-08/lesson-6.md)
진짜 서버에는 그런 탭이 없다. DNS 를 켠다는 건 사실 **"DNS 프로그램을 실행한다"** 는 뜻이다.
그 프로그램이 돌아가려면 **CPU · 메모리 · 디스크 · 네트워크 카드를 관리해 주는 누군가**가 있어야 한다. → **운영체제**다.

## 📖 ① 운영체제 — 하드웨어와 프로그램 사이의 관리인

```
  사용자  ──▶  프로그램 (웹서버 · DNS · 카톡 · 게임)
                 │  "파일 좀 읽어줘" "패킷 좀 보내줘"
                 ▼
           ┌─ 운영체제 (OS) ─┐   ← 자원을 나눠주고 · 순서를 정하고 · 지켜준다
           └────────┬────────┘
                    ▼
     하드웨어 (CPU · 메모리 · 디스크 · 랜카드)
```

- 프로그램은 하드웨어를 **직접 만지지 않는다.** 운영체제에게 **부탁**한다
- 예: 웹서버가 "80번 포트로 오는 요청 받아줘" → OS 가 랜카드에서 받아 넘겨준다 (포트는 10일차에 → [포트 번호](../day-10/lesson-8.md))

> 💡 **비유: 건물 관리실.** 입주자(프로그램)는 전기 · 수도 · 엘리베이터(하드웨어)를 직접 고치지 않는다.
> 관리실(OS)에 요청하고, 관리실은 **누가 얼마나 쓸지 나누고 · 싸움을 말린다.**

### 대표 운영체제

| OS | 주로 어디서 | 특징 |
|----|------------|------|
| Windows | 개인 PC · 회사 사무용 | GUI 중심, 유료 |
| macOS | 맥 | 유닉스 계열 |
| Android / iOS | 스마트폰 | Android 는 **리눅스 커널** 위에서 돈다 |
| **Linux** | **서버 · 클라우드 · 네트워크 장비 · IoT** | 무료 · 오픈소스 |
| (Cisco IOS) | 1단계에서 만진 **라우터 · 스위치** | 장비 전용 OS |

> 📌 사실 1단계 내내 **운영체제에 명령을 치고 있었다.** 시스코 IOS 도 OS 다. 오늘은 OS 만 **리눅스로 바뀐다.**

## 📖 ② 리눅스의 구조 — 커널 · 쉘 · 배포판

```
   ┌──────────────── 배포판 (Ubuntu, Rocky, Debian ...) ────────────────┐
   │                                                                     │
   │    사용자 ── 명령 ──▶ [ 쉘 bash ] ── 번역 ──▶ [ 커널 Linux ] ──▶ 하드웨어 │
   │                                                                     │
   │    + 기본 프로그램들 (ls, cp, nano ...) + 설치 도구(apt) + 설정          │
   └─────────────────────────────────────────────────────────────────────┘
```

| 부분 | 역할 | 비유 |
|------|------|------|
| **커널** (Kernel) | 하드웨어를 직접 관리하는 **심장부** | 자동차 **엔진** |
| **쉘** (Shell, 보통 `bash`) | 내가 친 명령을 커널에 전달하는 **통역사** | **운전대 · 페달** |
| **배포판** (Distribution) | 커널 + 쉘 + 프로그램을 **묶어 포장한 완성품** | **완성차 브랜드** (현대 · 기아) |

- **"리눅스"** 는 원래 **커널의 이름**이다 (1991년 리누스 토르발스)
- 우리가 설치하는 건 **배포판** — 같은 엔진(커널)을 쓰지만 회사마다 포장이 다르다

### 배포판 두 갈래

| 계열 | 배포판 | 설치 명령 | 주로 |
|------|--------|-----------|------|
| **Debian 계열** | **Ubuntu** · Debian | `apt` | 클라우드 · 개발 · **이 수업** |
| **Red Hat 계열** | RHEL · **Rocky** · CentOS(종료) | `dnf` (예전 `yum`) | 기업 · 공공 서버 |

- 명령어의 **90% 는 같다.** 다른 건 주로 **프로그램 설치 명령**과 일부 설정 파일 위치
- 참고 교재 *이것이 리눅스다* 는 Rocky(Red Hat 계열)를 쓴다 → 설치 명령만 `dnf` ↔ `apt` 로 바꿔 읽으면 된다
- 버전 이름의 **LTS** (Long Term Support) = **5년 이상 보안 업데이트** 보장 → 서버는 LTS 를 쓴다 (`24.04` = 2024년 4월판)

## 📖 ③ 서버는 왜 리눅스일까

| 이유 | 설명 |
|------|------|
| **무료 · 오픈소스** | 서버 1,000대에 라이선스비가 0원. 코드가 공개돼 있어 누구나 검사 · 수정 |
| **안정성** | 재부팅 없이 **몇 년씩** 도는 서버가 흔하다 |
| **가볍다** | 화면(GUI) 없이 설치 가능 → 메모리 · CPU 를 **서비스에 몰아준다** |
| **원격 관리** | 처음부터 **SSH 로 멀리서** 관리하도록 만들어졌다 |

- 전 세계 웹서버 · 클라우드(AWS · 네이버 클라우드) · 도커 컨테이너의 **대부분이 리눅스**
- 14일차 **Docker** · 16일차 **네이버 클라우드** 도 리눅스 위에서 한다 → 오늘 배우는 명령이 끝까지 쓰인다

## 📖 ④ GUI vs CLI — 서버에는 왜 모니터가 없을까

| | **GUI** (Graphical) | **CLI** (Command Line) |
|---|---|---|
| 방식 | 마우스로 클릭 | **글자로 명령** |
| 장점 | 배우기 쉽다 | **빠르고 · 가볍고 · 기록 · 자동화 · 원격** 이 쉽다 |
| 1단계 예 | PT 의 `Config` 탭 · Server `Services` 탭 | 라우터 · 스위치 **CLI 탭** |

> 🗣 **"서버실 사진을 보면 서버가 수백 대인데 모니터는 한두 대뿐입니다. 왜일까요?"**
> → 서버는 **멀리서 SSH 로** 들어가 관리한다. 글자만 오가면 되니 **화면이 필요 없다.**
> → 1단계에서 스위치에 **모니터를 꽂은 적이 없었다.** 콘솔 케이블 → Telnet → **SSH** 로 들어갔다. 리눅스 서버도 똑같다.

- 그래서 오늘은 **Ubuntu Server**(화면 없는 판)를 설치하고, **Windows 에서 SSH 로 접속**해서 일한다
- CLI 명령은 **복사 · 붙여넣기 · 기록 · 스크립트** 가 된다 → "클릭 20번"은 전달이 어렵지만 "명령 3줄"은 카톡으로도 보낸다

### 1단계 CLI 와 비교 — 이미 반은 안다

| 시스코 IOS (1단계) | 리눅스 (오늘) | 뜻 |
|---|---|---|
| `Router>` / `Router#` | `student@ubuntu:~$` / `root@ubuntu:~#` | 프롬프트. **`#` = 관리자** 는 둘이 같다! |
| `enable` | `sudo` | 관리자 권한 |
| `?` | `--help` · `man` | 도움말 |
| **Tab** 자동완성 | **Tab** 자동완성 | 똑같다 |
| `show ip interface brief` | `ip a` · `ip -br a` | 인터페이스 · IP 확인 |
| `show ip route` | `ip route` | 라우팅 테이블 |
| `ping` | `ping` | 똑같다 (단, 리눅스는 **Ctrl+C** 로 멈춘다) |

- "리눅스와 우분투는 같은 것인가?" → 리눅스 = **커널(엔진)**, 우분투 = **배포판(완성차)**
- "`apt` 와 `dnf` 의 차이?" → 계열이 다를 뿐 **같은 일**(프로그램 설치)

## 📝 강의 메모

- **"Server0 체크박스 뒤에는?"** 으로 열어서 **"서비스 = 프로그램, 프로그램은 OS 위에서"** 로 연결
- 커널/쉘/배포판은 **자동차 비유 하나로** — 외울 필요 없고 "리눅스 = 엔진 이름" 만 남기면 된다
- **프롬프트 `#` = 관리자** 가 IOS 와 리눅스에서 똑같다는 걸 강조하면 반가워한다
- 이 노트는 **설치 대기 시간**에 한다 — 슬라이드 없이 칠판 그림(엔진 · 운전대 · 완성차)으로 충분
