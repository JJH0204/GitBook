## 학습 목표

- 링크 스테이트(OSPF)가 RIP과 무엇이 다른지 설명한다.
- OSPF의 코스트, Area, 이웃(Hello) 개념을 안다.
- 와일드카드 마스크를 계산한다.
- EIGRP의 특징을 알고 세 프로토콜을 표로 비교한다.

## 이전 학습과의 연결

RIP은 1Mbps 1홉을 1Gbps 2홉보다 좋다고 판단했다. → [2. RIP](lesson-2.md)(LEC-N1-05-002-DO) 게다가 15홉을 넘지 못하고 소식이 도는 데 30초씩 걸린다.

그럼 어떻게 해야 하는가.

1. 대역폭까지 보고 판단해야 한다.
2. 이웃 말만 믿지 말고 내가 직접 지도를 보고 계산해야 한다.
3. 변화가 생기면 30초를 기다리지 말고 즉시 알려야 한다.

이 셋을 해결한 것이 OSPF(그리고 EIGRP)다.

## 1. 구성 요소

### 1.1 코스트(Cost) — OSPF의 메트릭

코스트 = 기준 대역폭(100Mbps) ÷ 인터페이스 대역폭. 작을수록 좋다.

| 회선 | 대역폭 | 코스트 |
|---|---|---|
| 시리얼 | 1.544Mbps | 64 |
| 이더넷 | 10Mbps | 10 |
| 패스트이더넷 | 100Mbps | 1 |
| 기가비트 | 1Gbps | 1 (기본 계산으로는 구분하지 못한다) |

- 경로 전체의 코스트는 거쳐 가는 인터페이스 코스트의 합이다.
- 기본 기준값이 100Mbps이므로 기가 이상은 전부 1이 된다. 실무에서는 `auto-cost reference-bandwidth`로 기준을 올린다(참고).
- RIP은 홉이 적은 쪽을, OSPF는 코스트가 낮은, 즉 빠른 쪽을 고른다.

### 1.2 Area(영역)

- 라우터가 수백 대면 지도가 너무 커지고 계산이 무거워진다.
- 그래서 망을 Area로 쪼개고 영역 안에서만 상세한 지도를 공유한다.
- Area 0은 백본(중심)이다. 다른 모든 영역은 Area 0에 붙어야 한다.
- 실습은 규모가 작으므로 전부 `area 0` 하나로 쓴다. 영역 설계는 CCNA 심화 주제다.

### 1.3 와일드카드 마스크

```
router ospf 1
 network 192.168.10.0 0.0.0.255 area 0
```

{% hint style="danger" %}
WARNING: 여기 들어가는 값은 서브넷 마스크가 아니라 와일드카드 마스크다. 오늘 최대의 함정이다. `network 192.168.10.0 255.255.255.0 area 0`처럼 입력하면 동작하지 않는다. 실습에서 이웃이 맺어지지 않는 원인 1위다.
{% endhint %}

계산법: 255에서 서브넷 마스크를 뺀다.

| 서브넷 마스크 | 와일드카드 |
|---|---|
| 255.255.255.0 (/24) | 0.0.0.255 |
| 255.255.255.128 (/25) | 0.0.0.127 |
| 255.255.255.252 (/30) | 0.0.0.3 |
| 255.255.0.0 (/16) | 0.0.255.255 |

- `0`은 반드시 같아야 하는 자리, `255`는 아무거나 괜찮은 자리다.
- 서브넷 마스크와 정확히 반대로 읽는다(0과 1을 뒤집는다).

### 1.4 `router ospf 1`의 `1`

- 프로세스 ID다. 이 장비 안에서만 의미가 있는 번호다.
- 이웃과 같을 필요가 없다. R1이 1, R2가 5여도 이웃이 맺어진다.
- 반면 `area` 번호는 반드시 같아야 이웃이 된다.

### 1.5 EIGRP

EIGRP는 Enhanced Interior Gateway Routing Protocol의 약자다.

- 시스코가 개발했다(2013년 일부 공개 표준화). 시스코 장비 위주 환경에서 강력하다.
- 성격은 고급 디스턴스 벡터(하이브리드)다. 이웃에게 배우지만 RIP보다 훨씬 똑똑하다.
- 메트릭은 대역폭 + 지연(기본)이다. 대역폭, 지연, 신뢰도, 부하를 조합할 수 있다.
- DUAL 알고리즘이 미리 계산해 둔 백업 경로(Feasible Successor)를 갖는다. 주 경로가 죽으면 재계산 없이 즉시 전환하므로 셋 중 수렴이 가장 빠르다.
- AD는 90(셋 중 가장 신뢰)이다. 내부 90, 외부 170이다.
- 설정이 OSPF보다 간단하다(`router eigrp 100` + `network`).

비유: RIP은 옆집에 물어보기, OSPF는 지도 펴고 계산하기, EIGRP는 자주 가는 길의 우회로를 미리 외워 둔 베테랑 기사다.

{% hint style="warning" %}
CAUTION: `router eigrp 100`의 100은 AS 번호이며 이웃과 반드시 같아야 한다. OSPF 프로세스 ID와 헷갈리기 쉽다. 시험 단골이다.
{% endhint %}

## 2. 동작 원리

### 2.1 OSPF 동작 3단계

OSPF는 Open Shortest Path First(개방형 최단 경로 우선)의 약자다.

| 단계 | 하는 일 | 만드는 것 |
|---|---|---|
| 1. 이웃 맺기 | `Hello` 패킷을 10초마다 주고받는다 | 이웃 테이블 |
| 2. 지도 공유 | 내 링크 상태(LSA)를 모두에게 퍼뜨린다 | LSDB(지도) |
| 3. 길 계산 | 지도를 놓고 다익스트라(SPF)로 최단 경로를 계산한다 | 라우팅 테이블 |

비유: RIP은 "옆집이 3정거장이래"였다. OSPF는 모두가 같은 지도를 갖고 각자 그 지도 위에서 자기 기준 최단 경로를 계산한다.

- 핵심: 영역 안의 모든 라우터가 똑같은 지도(LSDB)를 갖는다. 그래서 판단이 일관된다.
- 소식은 주기적으로 전부 보내는 것이 아니라 변화가 있을 때만 보낸다. 대역폭을 아끼고 빠르다.
- 이웃이 죽었는지는 Dead 타이머(기본 40초)로 판단한다. RIP의 180초보다 훨씬 빠르다.

## 3. 세 프로토콜 비교

오늘의 핵심 표다.

| | RIP | OSPF | EIGRP |
|---|---|---|---|
| 방식 | 디스턴스 벡터 | 링크 스테이트 | 하이브리드 |
| 비유 | 옆집에 물어보기 | 지도 펴고 계산 | 우회로 외운 기사 |
| 메트릭 | 홉 수 | 코스트(대역폭) | 대역폭 + 지연 |
| 최대 규모 | 15홉 | 사실상 제한 없음 | 매우 큼 |
| 표준 | 개방형 | 개방형(표준) | 시스코(일부 공개) |
| 규모 | 소 | 대 | 중·대 |
| 수렴 | 느림 | 빠름 | 매우 빠름 |
| 갱신 | 30초마다 전체 | 변화 시에만 | 변화 시에만 |
| AD | 120 | 110 | 90 |
| 설정 | 가장 쉬움 | 와일드카드가 까다로움 | 쉬움 |

한 줄 요약: RIP은 단순·소규모, OSPF는 표준·대규모, EIGRP는 시스코·빠름이다.

**어떤 것을 고를까 — 실무 판단**

| 상황 | 선택 |
|---|---|
| 여러 회사 장비가 섞인 큰 망 | OSPF(표준이라 어디서나 된다) |
| 전부 시스코 장비 | EIGRP(설정이 쉽고 수렴이 빠르다) |
| 라우터 2~3대 소규모 | 정적도 충분하다 |
| 인터넷 사업자 간 연결 | BGP(7·8일차 이후 범위, 이름만) |

## 5. 강의 메모

- 암기보다 "홉만 보나 / 대역폭까지 보나 / 지도를 그리나"의 관점 차이로 설명한다.
- 비유 3종(옆집, 지도, 베테랑 기사)을 칠판에 나란히 써 두면 비교표가 저절로 채워진다.
- 와일드카드 마스크는 반드시 손으로 계산시켜 본다(255 − 마스크). 실습 최대 병목이다.
- Area는 "Area 0이 중심" 정도만 다룬다. 영역 설계는 CCNA 심화라고 선을 긋는다.
- EIGRP는 패킷트레이서 실습 없이 표로만 다룬다(시간 관계, 시스코 전용). 궁금해하는 학생에게는 `router eigrp 100` + `network`만 보여 줘도 충분하다.
- 다음: 직접 설정해 본다. → [4. 라우팅 프로토콜 실습](lesson-4.md), 명령은 [0. 실습 명령어](commands.md).

## 6. 약어·용어

| 용어 | 뜻 |
|---|---|
| OSPF | Open Shortest Path First. 링크 스테이트 방식의 개방형 표준 프로토콜 |
| EIGRP | Enhanced Interior Gateway Routing Protocol. 시스코의 하이브리드 프로토콜 |
| LSA | Link State Advertisement. 링크 상태 광고 |
| LSDB | Link State Database. 링크 상태 데이터베이스(지도) |
| SPF | Shortest Path First. 다익스트라 최단 경로 알고리즘 |
| Area | OSPF에서 망을 나눈 영역. Area 0이 백본 |
| 와일드카드 마스크 | 서브넷 마스크를 뒤집은 값. `0`은 일치해야 하는 자리 |
| DUAL | Diffusing Update Algorithm. EIGRP의 경로 계산 알고리즘 |
| Feasible Successor | EIGRP가 미리 계산해 둔 백업 경로 |
| 프로세스 ID | OSPF 프로세스를 구분하는 장비 내부 번호 |
| AS 번호 | EIGRP에서 이웃과 같아야 하는 번호 |
