## 2. 읽는 법

- 코드 블록 하나는 한 장비에서 끊지 않고 이어서 입력하는 한 덩어리다.
- `#` 뒤 글자는 설명이다. 입력하지 않아도 된다.
- PC는 `Desktop` > `Command Prompt`에서, 스위치·라우터는 장비 클릭 후 `CLI` 탭에서 입력한다.
- PC 창에서 `show ip route`를, 장비 창에서 `ipconfig`를 입력해도 동작하지 않는다.
- 4일차 CLI 기본기는 [4일차 실습 명령어](../day-04/commands.md)를 본다.

## 3. 공통 토폴로지

```
[PC0]──[SW1]──[R1]══════[R2]══════[R3]──[SW2]──[PC2]
 .10.1         20.0/24       50.0/24        .30.1
 192.168.10.0/24                        192.168.30.0/24
```

| 장비 | G0/0 | G0/1 |
|---|---|---|
| R1 | 192.168.10.254 (PC0 쪽) | 192.168.20.1 |
| R2 | 192.168.50.1 | 192.168.20.2 |
| R3 | 192.168.30.254 (PC2 쪽) | 192.168.50.2 |

- PC0: IP `192.168.10.1`, 마스크 `255.255.255.0`, 게이트웨이 `192.168.10.254`
- PC2: IP `192.168.30.1`, 마스크 `255.255.255.0`, 게이트웨이 `192.168.30.254`
- 케이블: 라우터끼리 크로스오버, 라우터↔스위치·PC↔스위치는 다이렉트

## 4. 기다리는 시간

명령을 입력하자마자 경로가 생기지 않는다. RIP은 30초마다 정보를 주고받는다. 아무 일도 일어나지 않아 보여도 30초 기다린 뒤 `show ip route`를 다시 입력한다. `↑` 키로 이전 명령을 부르면 편하다.

| 기다리는 시간 | 상황 |
|---|---|
| 최대 30초 | RIP 경로가 새로 생기거나 사라질 때 |
| 몇 초 | OSPF 이웃이 맺어지고 경로가 생길 때 |

## 5. 명령 사전 (5일차에 새로 나온 것)

| 무엇 | 명령 | 모드 |
|---|---|---|
| RIP 시작 | `router rip` | `(config)#` |
| RIP 버전 2 | `version 2` | `(config-router)#` |
| 자동 요약 끄기 | `no auto-summary` | `(config-router)#` |
| 내 네트워크 알리기 | `network 192.168.10.0` | `(config-router)#` |
| OSPF 시작 | `router ospf 1` | `(config)#` |
| OSPF 네트워크 | `network 192.168.10.0 0.0.0.255 area 0` | `(config-router)#` |
| 프로토콜 끄기 | `no router rip` / `no router ospf 1` | `(config)#` |
| 학습된 경로만 보기 | `show ip route rip` / `show ip route ospf` | `#` |
| 어떤 프로토콜이 도는지 | `show ip protocols` | `#` |
| OSPF 이웃 확인 | `show ip ospf neighbor` | `#` |
| 대화 엿듣기 / 끄기 | `debug ip rip` / `undebug all` | `#` |

4일차 기본 명령(`enable`, `conf t`, `show ip int br`, `copy run start` 등)은 [4일차 실습 명령어](../day-04/commands.md)를 본다.

## 6. 사용 예 — 실습 순서별 명령 요약

| 단계 | 장비 | 명령 | 확인 |
|---|---|---|---|
| 인터페이스 | 각 라우터 | `ip address <주소> <마스크>`, `no shutdown` | `show ip interface brief` |
| RIPv2 | 각 라우터 | `router rip` → `version 2` → `no auto-summary` → `network <내 네트워크>` | `show ip protocols`, `show ip route rip` |
| 수렴 관찰 | R3 | `interface g0/0` → `shutdown` / `no shutdown` | R1의 `show ip route` |
| OSPF | 각 라우터 | `router ospf 1` → `network <네트워크> <와일드카드> area 0` | `show ip ospf neighbor`, `show ip route ospf` |
| AD 대결 | 각 라우터 | OSPF를 둔 채 RIP 추가 | `show ip route`, `show ip protocols` |
| 저장 | 각 라우터 | `copy running-config startup-config` | 파일은 `Ctrl + S` |

경로 한 줄 읽기:

```
R    192.168.50.0/24 [120/1] via 192.168.20.2, 00:00:12, GigabitEthernet0/1
─┬─                   ─┬─ ─┬─      ─────┬─────  ────┬───
 RIP이 알려 줌          AD  홉 수     다음 홉      12초 전에 들었다
```

## 7. 와일드카드 마스크 계산

OSPF의 `network` 뒤에 오는 것은 서브넷 마스크가 아니라 와일드카드 마스크다. 255에서 각 자리를 뺀다(255 − 서브넷 마스크).

| 서브넷 마스크 | 와일드카드 |
|---|---|
| 255.255.255.0 (/24) | 0.0.0.255 |
| 255.255.0.0 (/16) | 0.0.255.255 |
| 255.255.255.252 (/30) | 0.0.0.3 |
| 255.255.255.255 (한 대) | 0.0.0.0 |

- `0`인 자리는 반드시 같아야 하는 자리, `255`인 자리는 아무거나 괜찮은 자리다.
