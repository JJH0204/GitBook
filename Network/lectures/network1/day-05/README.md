# 5일차 · 라우팅 프로토콜

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

4일차엔 라우팅 테이블을 **손으로** 채웠다. 라우터 2대에 `ip route` 두 줄.
그러면서 마지막에 물었다 — **"라우터가 10대면 이걸 손으로 다 넣을 수 있을까?"**
→ [4일차](../day-04/README.md)

오늘은 그 답. 라우터끼리 **정보를 주고받아 테이블을 자동으로 채우는** 동적 라우팅이다.

## 🎯 오늘의 목표

- 정적 라우팅의 한계를 **숫자로** 이해하고, 동적 라우팅의 필요성을 안다
- **메트릭**(같은 프로토콜 안)과 **AD**(프로토콜 사이)의 역할 차이를 구분한다
- **수렴(Convergence)** 의 뜻을 알고, 회선 장애 시 자동 복구를 관찰한다
- RIP · OSPF · EIGRP 의 차이를 **관점 차이**로 설명한다
- 패킷트레이서에서 **RIPv2 와 OSPF 를 직접 설정**하고, 자동 학습된 경로를 확인한다
- **와일드카드 마스크**를 계산할 수 있다

## 🧪 오늘의 실습 — **매번 새 파일에 처음부터 만든다**

> 📌 **앞 회차 파일을 고쳐 쓰지 않는다.** 실습마다 새 파일에 그림을 새로 만든다.
> 설정이 섞이지 않아 원인을 찾기 쉽고, **처음부터 만드는 과정 자체가 연습**이 된다.

```
[PC0]──[SW1]──[R1]══════[R2]══════[R3]──[SW2]──[PC2]
 .10.1        20.0/24       50.0/24        .30.1
 192.168.10.0/24                       192.168.30.0/24
```

| 실습 | 단계 | 이 단계의 목적 | 시간 |
|------|------|----------------|------|
| **RIPv2** | 그림 만들기 | 라우터 3대 · PC 2대 · 인터페이스까지 | 25분 |
| | 먼저 실패 확인 | 경로가 없으면 못 간다 (동기 부여) | 5분 |
| | R1·R2 에 RIP ⭐ | "내 것만 신고" 로 길이 생긴다 | 20분 |
| | R3 에 RIP ⭐⭐ | 손 안 댄 R1 에 **경로가 저절로** | 25분 |
| | 끊었다 잇기 | **자동 수렴** 관찰 | 10분 |
| **OSPF** | 새 파일에 같은 그림 | 두 번째라 빠르다 | 15분 |
| | OSPF 설정 ⭐ | 와일드카드 · 빠른 수렴 | 20분 |
| (부록) | AD 대결 | RIP 을 얹으면 누가 이기나 | 15분 |

- **두 실습의 그림과 주소가 같다.** 바뀌는 건 **프로토콜 하나뿐**이라 차이가 그대로 드러난다
- 그림을 두 번 만드는 걸 부담스러워하는 학생에겐 **"두 번째는 5분"** 이라고 미리 말해줄 것

## ⏳ 오늘의 특별 공지 — **기다리는 실습이다**

> 🚨 실습 시작 **전에 반드시 공지할 것.**
> RIP 은 **30초 주기**라 명령을 쳐도 경로가 즉시 생기지 않는다.
> 이걸 안 알려주면 학생들이 "안 되는데요?" 하며 **설정을 지우고 다시 치느라** 시간을 다 쓴다.

## 📝 진행 메모

- **"정적=손으로, 동적=라우터가 알아서"** 의 대비로 시작한다
- 첫 5분에 **`n × (n-1)` 표를 칠판에 세어보게** 할 것 — 숫자로 체감시키는 게 제일 빠르다
- ⚠️ **최대 함정**: `network` 에 **목적지**를 적는 실수.
  "정적은 **가는 길**, 동적은 **내 것 신고**" 를 반복 각인
- ⚠️ **두 번째 함정**: OSPF 의 **와일드카드 마스크**. 손으로 계산시켜 볼 것 (255 − 마스크)
- 세 프로토콜은 암기보다 **디스턴스 벡터 vs 링크 스테이트** 큰 그림으로
- **오늘의 회수 지점**
  1. 4일차 "한쪽만 넣으면 실패" → **동적은 양쪽이 자동**
  2. 4일차 CCNA Q4(AD) → **AD 대결에서 RIP 을 켜도 `O` 만 남는 장면**
  3. 2일차 서브넷 마스크 → **와일드카드 마스크**
- **세 번째 라우터가 합류하는 장면에 시간을 몰아줄 것.** 오늘 수업의 값어치가 거기 다 있다
- 시간이 부족하면 **수렴 관찰을 생략**하고 OSPF 실습을 살릴 것 (AD 가 6일차의 전제)
- 6일차 밑밥: **"라우터마다 쓰는 말이 다르면 어떻게 될까?"** 로 마무리
