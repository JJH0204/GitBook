# 7일차 · 스위칭 심화 — VLAN · 트렁크 · EtherChannel

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

4~6일차는 **라우터**의 시간이었다. 손으로(정적) → 알아서(동적) → 말이 다른 구역 잇기(재분배).
→ [6일차](../day-06/README.md)

그동안 스위치는 **꽂기만 하면 되는 장비**였다. 그런데 앞에서 미뤄둔 숙제가 세 개 남아 있다.

| 미뤄둔 숙제 | 어디서 | 오늘의 답 |
|-------------|--------|-----------|
| "브로드캐스트 도메인을 나누려면? 라우터 **(또는 VLAN)**" | 3일차 | **VLAN** |
| "(예고) VLAN — 심화에서 다룸" | 4일차 | **VLAN · 트렁크** |
| "스위치 두 대를 선 두 줄로 이으면? → STP 가 하나를 막는다" | 4일차 | **EtherChannel** — 둘 다 쓴다 |

오늘은 **스위치를 제대로 다루는 날**이다. 회사 한 층을 부서별로 나누고, 층을 넘어 잇고, 선 두 줄을 하나로 묶는다.

## 🎯 오늘의 목표

- **VLAN** 으로 스위치 한 대를 여러 브로드캐스트 도메인으로 나눈다 (**1 VLAN = 1 서브넷**)
- **액세스 포트**와 **트렁크 포트**(802.1Q 태그)의 차이를 안다
- VLAN 끼리 통신하려면 **라우터가 필요한 이유**를 알고, **Router-on-a-stick** 을 구성한다
- 선 두 줄에서 **STP 가 막는 포트**를 `show spanning-tree` 로 찾는다
- **EtherChannel(LACP)** 로 두 선을 하나로 묶어 **대역폭 + 이중화**를 얻는다
- (여유) **루트 브리지 지명**과 **PortFast** 로 STP 를 다듬는다

## 🧪 오늘의 실습 — **새 파일에 처음부터**, 끝나면 **8일차용으로 저장**

```
                     [R1]
                      │ G0/0  (.10 · .20 두 개로 쪼갬)
                      │ trunk
                      │ Gi0/1
  PC0 ──Fa0/1──┐      │      ┌──Fa0/1── PC2
             [SW1]════════════[SW2]
  PC1 ──Fa0/2──┘ Fa0/23 ═══ Fa0/23 └──Fa0/2── PC3
                 Fa0/24 ═══ Fa0/24   ← STEP 4 에서 추가

   VLAN 10 영업 = 192.168.10.0/24 (PC0 · PC2)
   VLAN 20 개발 = 192.168.20.0/24 (PC1 · PC3)
```

| 단계 | 내용 | 이 단계의 목적 | 시간 |
|------|------|----------------|------|
| **준비** | 그림 만들기 (라우터 1 · 스위치 2 · PC 4) | 선 한 줄로 시작 | 15분 |
| **①** | VLAN 10 · 20 | 나눴더니 **같은 VLAN 도 못 넘는다** | 20분 |
| **②** | 트렁크 | 같은 VLAN 은 층을 넘는다 | 15분 |
| **③** ⭐ | Router-on-a-stick | 다른 VLAN 끼리 통신 | 20분 |
| **④** ⭐ | 두 번째 선 → STP → EtherChannel | 선 두 줄을 **둘 다** 쓴다 | 30분 |
| **⑤** | 루트 지명 · PortFast | 다듬기 (생략 가능) | 10분 |

- 오늘은 라우터가 **한 대**뿐이다. 대신 스위치 CLI 를 처음으로 **깊이** 만진다
- 🚨 **8일차는 이 파일 위에서 진행한다** → 끝나면 **`7일차_스위칭.pkt`** 저장 필수

## ⏳ 오늘은 **주황 점**을 자주 본다

> 🚨 선을 꽂거나 포트를 켤 때마다 **STP 확인 30초**. 특히 STEP 4 에서 두 번째 선의 **한쪽 끝은 계속 주황**이다 —
> **고장이 아니라 오늘의 관찰 대상**이라고 미리 공지할 것.

## 📝 진행 메모

- **상황극(코리아IT 2층 · 3층, 영업팀 · 개발팀)** 으로 시작해 끝까지 같은 무대를 쓴다
- 🗣 오늘을 끌고 가는 질문 세 개: **① 나눌 수 있나? ② 층을 넘어 이을 수 있나? ③ 선 두 줄을 둘 다 쓸 수 있나?**
- **실패 4연속이 설계다** — 같은 VLAN 도 안 됨 → 다른 VLAN 은 안 됨 → 태그 없이 IP 거절 → 선 하나가 논다.
  정답부터 치게 두지 말 것
- ⚠️ 최대 병목 두 가지
  1. **"VLAN 이 다르면 같은 스위치여도 안 된다"** — 여러 번 반복
  2. **Router-on-a-stick 에서 스위치 쪽 Gi0/1 트렁크를 빼먹는다** — "라우터만 보지 말고 스위치 문도"
- 비유 3종: **VLAN = 아파트 동별 단톡방 · 트렁크 태그 = 택배 송장 · EtherChannel = 2차선 두 개를 4차선 하나로**
- 루트 브리지는 **반장 선거**(추천이 없으면 출석번호 = MAC) — 옆 사람과 결과가 달라도 정상
- **오늘의 회수 지점**
  1. 3일차 "라우터 **(또는 VLAN)**" → **VLAN**
  2. 3일차 CCNA Q5 "(현실적으로는 VLAN)" → 오늘 CCNA Q1
  3. 4일차 "(예고) VLAN" · MAC 테이블의 **`Vlan 1`** → 전부 기본 VLAN 이었다
  4. 4일차 CCNA "선 두 줄" → **STP 가 막는다 → EtherChannel 로 둘 다**
  5. 3일차 **주황 점 30초** → 4일차 STP → 오늘 **PortFast** 로 없앤다
