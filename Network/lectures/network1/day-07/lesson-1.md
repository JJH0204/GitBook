## 학습 목표

- 스위치 하나가 통째로 하나의 브로드캐스트 도메인이어서 생기는 문제를 설명한다.
- VLAN이 스위치를 논리적으로 쪼갠다는 뜻을 이해한다.
- 1 VLAN = 1 서브넷 = 1 브로드캐스트 도메인 공식을 안다.
- 액세스 포트가 무엇이고 어떻게 VLAN에 넣는지 안다.
- `show vlan brief` 출력을 읽는다.

## 1. 구성 요소

### 상황극 — 코리아IT 2층 사무실

한 층에 영업팀과 개발팀이 섞여 앉아 있다. 스위치 한 대에 전부 꽂았다.

```
            [ SW1 — 24포트 ]
   영업 영업 개발 영업 개발 개발 영업 ...
```

| 문제 | 왜 생기나 |
|---|---|
| 브로드캐스트가 전 부서로 퍼진다 | 스위치 전체가 브로드캐스트 도메인 하나다. (1일차 [7_캐스트_유니_브로드_멀티](../day-01/lesson-7.md)) |
| 영업팀 PC가 개발 서버를 그냥 본다 | 같은 도메인 = 같은 동네이므로 막을 장치가 없다 |
| 사람이 늘수록 느려진다 | ARP·DHCP 같은 브로드캐스트가 사람 수만큼 늘어난다 |

해결책은 두 가지다.

1. 부서마다 스위치를 따로 산다. 비용이 들고, 자리를 바꾸면 케이블을 다시 뽑아 옮겨야 한다.
2. 스위치 한 대를 논리적으로 쪼갠다. 이것이 VLAN이다.

### VLAN (Virtual LAN)

VLAN은 스위치 한 대 안에 "가상의 스위치" 여러 대를 만드는 것이다.

```
      물리적으로는 한 대                   논리적으로는 두 대
   ┌──────────────────────┐          ┌──────────┐  ┌──────────┐
   │ 1  2  3  4  5  6  7 … │   ⇒     │ VLAN 10  │  │ VLAN 20  │
   │ 영 개 영 개 영 개 영   │          │ 영업     │  │ 개발     │
   └──────────────────────┘          └──────────┘  └──────────┘
                                       서로 못 본다 (벽이 생겼다)
```

- 같은 VLAN끼리만 프레임이 오간다. 브로드캐스트도 자기 VLAN 안에서만 퍼진다.
- 다른 VLAN은 다른 스위치에 꽂은 것처럼 완전히 분리된다.
- 자리를 바꿔도 케이블은 그대로 두고 포트의 VLAN 번호만 바꾼다.

{% hint style="info" %}
NOTE: 비유는 아파트 단톡방이다. 한 방에 전 세대를 넣으면 공지 하나에 모두의 폰이 울린다. 동별 단톡방(VLAN)을 따로 만들면 101동 공지는 101동에만 간다. 아파트(스위치)는 하나인데 방(VLAN)은 여러 개다. 1일차 카톡 단톡 비유의 확장이다.
{% endhint %}

### 오늘의 공식 — 1 VLAN = 1 서브넷

| VLAN | 이름 | 서브넷 | 게이트웨이 |
|---|---|---|---|
| 10 | 영업(SALES) | 192.168.10.0/24 | 192.168.10.254 |
| 20 | 개발(DEV) | 192.168.20.0/24 | 192.168.20.254 |

- 2일차 서브넷팅은 IP를 나눴다(3계층). → [4_서브넷팅](../day-02/lesson-4.md)
- 오늘 VLAN은 스위치를 나눈다(2계층).
- 실무에서는 둘을 짝으로 맞춘다. VLAN 하나에 서브넷 하나다.

질문: VLAN이 다르면 같은 스위치에 꽂혀 있어도 서로 통신이 될까? 답은 "안 된다"이다. 다른 브로드캐스트 도메인은 다른 네트워크이므로 라우터가 필요하다(4일차 원칙). → [2_트렁크와_VLAN간_라우팅](lesson-2.md)

### 포트의 두 종류

| 포트 종류 | 어디에 | 몇 개의 VLAN | 비유 |
|---|---|---|---|
| 액세스 | PC · 프린터 · 서버 | 하나 | 한 동의 현관문 |
| 트렁크 | 스위치↔스위치, 스위치↔라우터 | 여러 개 | 여러 동을 잇는 지하 통로 → [2_트렁크와_VLAN간_라우팅](lesson-2.md) |

- PC는 자기가 어느 VLAN인지 모른다. 스위치 포트가 정해 준다.
- 그래서 포트에 VLAN 번호를 붙인다. "이 포트로 들어오면 VLAN 10 소속"이라는 뜻이다.

### `show vlan brief` 출력

```
Switch# show vlan brief

VLAN Name                             Status    Ports
---- -------------------------------- --------- -------------------------------
1    default                          active    Fa0/3, Fa0/4, Fa0/5, Fa0/6
                                                ...  Gig0/1, Gig0/2
10   SALES                            active    Fa0/1
20   DEV                              active    Fa0/2
1002 fddi-default                     active
1003 token-ring-default               active
...
```

| 보이는 것 | 뜻 |
|---|---|
| VLAN 1 (default) | 공장 출하 상태. 모든 포트가 처음에는 VLAN 1이다. 4일차 MAC 테이블의 `Vlan 1`이 이것이다 |
| 10 SALES · Fa0/1 | 우리가 만든 VLAN과 소속 포트 |
| 1002~1005 | 옛 규격용 예약 번호. 무시한다 |

4일차 `show mac address-table`의 Vlan 칸이 전부 1이었던 이유가 이것이다. → [1_스위치_동작원리](../day-04/lesson-1.md)

## 2. 동작 원리

### 설정은 두 단계 — VLAN 만들기 → 포트에 넣기

```bash
vlan 10                              # 1) VLAN 만들기
 name SALES
vlan 20
 name DEV
 exit
interface fa0/1                      # 2) 포트에 넣기
 switchport mode access              #    이 포트는 액세스 포트다
 switchport access vlan 10           #    VLAN 10 소속이다
interface fa0/2
 switchport mode access
 switchport access vlan 20
```

{% hint style="info" %}
NOTE: VLAN을 만들지 않고 포트에 먼저 넣으면 시스코 장비가 VLAN을 자동으로 만든다(`% Access VLAN does not exist. Creating vlan 10`). 이름이 없어 헷갈리므로 만들고 넣는 순서를 지킨다.
{% endhint %}

### 프레임이 움직이는 방식

- 스위치는 프레임이 들어온 포트의 VLAN 번호를 기억한다.
- 그 프레임을 같은 VLAN에 속한 포트로만 내보낸다. 브로드캐스트와 플러딩도 같은 VLAN 포트에만 나간다.
- VLAN 10 PC가 ARP(브로드캐스트)를 보내면 VLAN 20 PC는 받지 못한다. 시뮬레이션 모드에서 ARP만 필터로 켜면 VLAN 10 포트로만 퍼지는 것이 보인다.
- 개발팀 한 명이 영업팀 자리로 옮기면 케이블을 옮기지 않는다. 그 포트의 VLAN 번호만 바꾼다.

## 4. 강의 메모

- 3일차 괄호 "(또는 VLAN)"과 4일차 "(예고) VLAN"을 회수하는 자리다. "그때 미뤄 둔 것, 오늘 합니다"로 시작한다.
- 비유는 아파트 단톡방이다. 아파트 = 스위치, 동별 단톡방 = VLAN. 1일차 카톡 비유와 이어진다.
- 1 VLAN = 1 서브넷을 칠판 한쪽에 계속 적어 둔다. 오늘 모든 실습이 이 공식 위에 선다.
- 학생들이 가장 헷갈리는 것: "VLAN이 다르면 같은 스위치여도 안 된다." 여러 번 반복한다.
- 트렁크 포트는 `show vlan brief`에서 사라진다. 다음 절에서 예고로 던져 둔다.

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| VLAN | Virtual LAN. 스위치 안에 논리적으로 만든 브로드캐스트 도메인 |
| 액세스 포트 | 하나의 VLAN에만 속하는 포트. PC·서버를 연결한다 |
| 트렁크 포트 | 여러 VLAN을 태그로 구분해 나르는 포트 |
| SVI | Switch Virtual Interface. VLAN의 가상 L3 인터페이스 |
| ARP | Address Resolution Protocol. IP로 MAC을 묻는 브로드캐스트 |
