# 1. VLAN — 스위치 한 대를 여러 대처럼

> 상위: [7일차 · 스위칭 심화](README.md)

## 🎯 학습 목표

- 스위치 하나가 **통째로 하나의 브로드캐스트 도메인**이라서 생기는 문제를 설명한다
- VLAN이 **스위치를 논리적으로 쪼갠다**는 뜻을 이해한다
- **1 VLAN = 1 서브넷 = 1 브로드캐스트 도메인** 공식을 안다
- **액세스 포트**가 무엇이고 어떻게 VLAN에 넣는지 안다
- `show vlan brief` 출력을 읽는다

## 📖 상황극 — 코리아IT 2층 사무실

한 층에 **영업팀**과 **개발팀**이 섞여 앉아 있다. 스위치 한 대에 전부 꽂았다.

```
            [ SW1 — 24포트 ]
   영업 영업 개발 영업 개발 개발 영업 ...
```

| 문제 | 왜 생기나 |
|------|-----------|
| 📢 **브로드캐스트가 전 부서로** 퍼진다 | 스위치 전체가 **브로드캐스트 도메인 하나** (1일차 [7_캐스트_유니_브로드_멀티](../day-01/lesson-7.md)) |
| 🔓 영업팀 PC가 **개발 서버를 그냥 본다** | 같은 도메인 = 같은 동네 = 막을 사람이 없다 |
| 🐢 사람이 늘수록 느려진다 | ARP·DHCP 같은 브로드캐스트가 **사람 수만큼** 늘어난다 |

**해결책 1 — 부서마다 스위치를 따로 산다**
→ 돈이 든다. 자리를 바꾸면 **케이블을 다시 뽑아 옮겨야** 한다.

**해결책 2 — 스위치 한 대를 논리적으로 쪼갠다** ⭐ = **VLAN**

## 📖 VLAN (Virtual LAN) 이란

> **VLAN = 스위치 한 대 안에 "가상의 스위치" 여러 대를 만드는 것**

```
      물리적으로는 한 대                   논리적으로는 두 대
   ┌──────────────────────┐          ┌──────────┐  ┌──────────┐
   │ 1  2  3  4  5  6  7 … │   ⇒     │ VLAN 10  │  │ VLAN 20  │
   │ 영 개 영 개 영 개 영   │          │ 영업     │  │ 개발     │
   └──────────────────────┘          └──────────┘  └──────────┘
                                       서로 못 본다 (벽이 생겼다)
```

- **같은 VLAN** 끼리만 프레임이 오간다 → 브로드캐스트도 **자기 VLAN 안에서만** 퍼진다
- **다른 VLAN** 은 **다른 스위치에 꽂은 것처럼** 완전히 분리된다
- 자리를 바꿔도 **케이블은 그대로**, 포트의 VLAN 번호만 바꾸면 끝

> 💡 **비유: 아파트 단톡방.** 한 방에 전 세대를 넣으면 공지 하나에 모두의 폰이 울린다.
> **동별 단톡방(VLAN)** 을 따로 만들면 101동 공지는 101동에만 간다.
> 아파트(스위치)는 하나인데 방(VLAN)은 여러 개 — 1일차 **카톡 단톡** 비유의 확장이다.

## 📖 오늘의 공식 — 1 VLAN = 1 서브넷

| VLAN | 이름 | 서브넷 | 게이트웨이 |
|------|------|--------|------------|
| **10** | 영업(SALES) | 192.168.10.0/24 | 192.168.10.254 |
| **20** | 개발(DEV) | 192.168.20.0/24 | 192.168.20.254 |

- 2일차 **서브넷팅은 IP 를 나눴다** (3계층) → [4_서브넷팅](../day-02/lesson-4.md)
- 오늘 **VLAN 은 스위치를 나눈다** (2계층)
- 실무에서는 **둘을 짝으로** 맞춘다: VLAN 하나에 서브넷 하나

> 🗣 **"VLAN 이 다르면 같은 스위치에 꽂혀 있어도 서로 통신이 될까요?"**
> → **안 된다.** 다른 브로드캐스트 도메인 = 다른 네트워크 → **라우터가 필요하다** (4일차 원칙)
> → 그 방법은 [2_트렁크와_VLAN간_라우팅](lesson-2.md)

## 📖 액세스 포트 — PC를 꽂는 포트

스위치 포트는 두 종류다. 오늘 먼저 만나는 건 **액세스(Access) 포트**.

| 포트 종류 | 어디에 | 몇 개의 VLAN | 비유 |
|-----------|--------|--------------|------|
| **액세스** | PC · 프린터 · 서버 | **딱 하나** | 한 동의 현관문 |
| **트렁크** | 스위치 ↔ 스위치, 스위치 ↔ 라우터 | **여러 개** | 여러 동을 잇는 지하 통로 → [2_트렁크와_VLAN간_라우팅](lesson-2.md) |

- PC는 **자기가 어느 VLAN인지 모른다.** 스위치 포트가 정해준다
- 그래서 **포트에 VLAN 번호를 붙인다** — "이 포트로 들어오면 VLAN 10 소속"

### 설정은 두 단계 — **VLAN 만들기 → 포트에 넣기**

```bash
vlan 10                              # ① VLAN 만들기
 name SALES
vlan 20
 name DEV
 exit
interface fa0/1                      # ② 포트에 넣기
 switchport mode access              #    이 포트는 액세스 포트다
 switchport access vlan 10           #    VLAN 10 소속이다
interface fa0/2
 switchport mode access
 switchport access vlan 20
```

> ⚠️ **VLAN 을 안 만들고 포트에 먼저 넣으면?** 시스코는 **자동으로 만들어 준다**
> (`% Access VLAN does not exist. Creating vlan 10`). 그래도 이름이 없어 헷갈리니 **만들고 넣는 습관**을 들인다.

## 📖 `show vlan brief` 읽기

```
Switch# show vlan brief

VLAN Name                             Status    Ports
---- -------------------------------- --------- -------------------------------
1    default                          active    Fa0/3, Fa0/4, Fa0/5, Fa0/6
                                                ...  Gig0/1, Gig0/2
10   SALES                            active    Fa0/1
20   DEV                              active    Fa0/2
1002 fddi-default                     active
1003 token-ring-default               active
...
```

| 보이는 것 | 뜻 |
|-----------|-----|
| **VLAN 1 (default)** | 공장 출하 상태 — **모든 포트가 처음엔 VLAN 1** (4일차 MAC 테이블의 `Vlan 1` 이 이것) |
| **10 SALES · Fa0/1** | 우리가 만든 VLAN 과 소속 포트 |
| **1002~1005** | 옛날 규격용 예약 번호 — 무시해도 된다 |

> 💡 4일차 `show mac address-table` 의 **Vlan 칸이 전부 1 이었던 이유**가 이제 풀린다. → [1_스위치_동작원리](../day-04/lesson-1.md)

## 📝 강의 메모

- **3일차 괄호 "(또는 VLAN)" 과 4일차 "(예고) VLAN" 을 회수하는 자리** → "그때 미뤄둔 거, 오늘입니다" 로 시작
- **비유는 아파트 단톡방** — 아파트 = 스위치, 동별 단톡방 = VLAN. 1일차 카톡 비유와 이어진다
