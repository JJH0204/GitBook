# 1. 과정 소개와 자격증

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LEC-N1-01-001-DO |
| 유형 | D&O (개념) |
| 목적 | 네트워크 1·2 과정의 전체 흐름과 준비할 수 있는 자격증을 안내한다 |
| 확인 상태 | 미검증 (자격증 주관 기관, 시험 구성, 시험 코드를 공식 사이트에서 다시 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 학습 목표

- 네트워크 1·2 과정의 전체 흐름과 목표를 이해한다.
- 이 과정으로 준비할 수 있는 자격증을 안내받는다.

## 1. 목적

과정 전체 지도와 자격증 목표를 먼저 보여 주어 이후 학습의 방향을 잡는다.

## 2. 구성 요소

### 2.1 과정 소개

과정명은 "네트워크 1, 2 — 패킷트레이서와 리눅스를 활용한 네트워크 기초이론과 실습"이다. 총 16일이다.

| 단계 | 회차 | 내용 | 핵심 도구 |
|---|---|---|---|
| 1단계 | 1~8일차 | 네트워크 기초 이론과 구성 | Cisco 패킷트레이서 |
| 2단계 | 9~16일차 | 리눅스 서버 구축과 활용 | 리눅스, Docker, 클라우드 |

- 이론, 시뮬레이터 실습, 실제 서버 구축 순으로 난이도를 쌓는다.
- 9일차부터는 AI 도구를 명령어 해석, 규칙 검토, 문서 작성에 함께 활용한다.
- 참고 교재: 후니의 쉽게 쓴 시스코 네트워킹, 모두의 네트워크 기초, 이것이 리눅스다.

### 2.2 자격증

| 자격증 | 주관 | 구성·범위 | 이 과정과의 관계 |
|---|---|---|---|
| 네트워크관리사 (2급) | 한국정보통신자격협회(ICQA) | 필기(네트워크 일반, TCP/IP, NOS, 네트워크 운용기기)와 실기(라우터·스위치 명령어 설정 등) | 패킷트레이서 실습(라우터·스위치 설정, 라우팅 프로토콜)이 실기와 직접 연결된다 |
| CCNA (Cisco Certified Network Associate) | Cisco (국제 공인 자격), 시험 코드 200-301 | 네트워크 기초, IP 연결·서비스, 보안 기초, 자동화 등 실무 중심 | 라우팅·스위칭, 서브넷팅, OSI 계층 이해가 핵심이므로 1단계 전체가 기반이 된다 |

{% hint style="warning" %}
CAUTION: 시험 과목, 응시료, 일정 등 세부 사항은 매년 바뀔 수 있다. 응시 전에 공식 사이트에서 최신 정보를 확인한다.
{% endhint %}

## 3. 동작 원리: 학습 흐름

1. 이론을 먼저 익힌다(1~8일차 앞부분).
2. 패킷트레이서로 시뮬레이션 실습을 한다(1~8일차).
3. 리눅스, Docker, 클라우드로 실제 서버를 구축한다(9~16일차).
