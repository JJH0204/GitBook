## 5. 절차

### A. 영문과 숫자 변환

1. (5-A-01) VS Code에서 `ascii_convert.py` 파일을 연다. → 결과: 스크립트가 편집 창에 표시된다.
2. (5-A-02) 오른쪽 위 `▶ (Run Python File)` 버튼을 누른다. 또는 터미널에 `python ascii_convert.py`를 입력한다. → 결과: 아래 터미널이 열리고 입력을 요구한다.
3. (5-A-03) 처음 실행하면 Microsoft Python 확장 설치 안내가 뜬다. 설치한다. → 결과: 안내가 사라지고 확장이 설치된다.
4. (5-A-04) 아래 터미널 영역을 클릭한다. → 결과: 터미널에 커서가 놓인다.
5. (5-A-05) `AB1`을 입력하고 Enter를 누른다. → 결과: 아래 표가 출력된다.

```
 문자 | 10진수 |  2진수(8bit) | 16진수
------+--------+--------------+-------
  A   |    65  |   01000001  |  0x41
  B   |    66  |   01000010  |  0x42
  1   |    49  |   00110001  |  0x31
```

6. (5-A-06) 출력의 `A` 행이 `65`, `01000001`인지 비교한다. → 결과: D&O 문서의 `A → 65 → 01000001` 예시와 같다.

### B. 한글 변환

1. (5-B-01) 스크립트를 다시 실행한다. → 결과: 입력을 요구한다.
2. (5-B-02) `가`를 입력하고 Enter를 누른다. → 결과: 아래 행이 출력된다.

```
  가   |  44032  |   1010110000000000  |  0xAC00
```

3. (5-B-03) 코드값 `44032`가 8비트 범위(0~255)를 넘는지 확인한다. → 결과: 넘는다. ASCII(1바이트)로는 한글을 담을 수 없다.
4. (5-B-04) 이 결과를 인코딩과 모지바케 개념으로 연결해 설명한다. 그래서 UTF-8 같은 인코딩이 필요하다.

{% hint style="info" %}
NOTE: 스크립트는 `ord()`(문자에서 코드), `format(n,"08b")`(2진수), `format(n,"02X")`(16진수)만 쓴다. 코드를 이해할 필요는 없다. 파이썬은 컴파일이 필요 없고 한글 출력도 잘 되어 입문 실습에 적합하다.
{% endhint %}

### C. 계산기로 교차 확인

1. (5-C-01) 계산기를 프로그래머 모드로 연다. → 결과: DEC, HEX, BIN 표시가 보인다.
2. (5-C-02) DEC로 `65`를 입력한다. → 결과: HEX `41`, BIN `0100 0001`이 표시된다.
3. (5-C-03) 구역 A, B의 출력과 계산기 값을 비교한다. → 결과: 값이 일치한다.

## 6. 기능 확인
