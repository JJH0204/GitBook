## 학습 목표

- 컴퓨터가 정보를 오직 0과 1로만 다룬다는 것을 이해한다.
- Bit에서 Byte로 묶을 때 표현할 수 있는 정보가 커지는 원리를 이해한다.
- 사람의 문자가 숫자(코드), 2진수 순서로 바뀌어 전송되는 과정을 이해한다.

## 1. 목적

### 1.1 다리 놓기: 연결은 했는데 무엇을 어떻게 보낼까

앞에서 네트워크는 장치들이 연결되어 정보를 주고받는 것이라고 했다. → [2. 네트워크란 무엇인가](lesson-2.md)(LEC-N1-01-002-DO)

질문 하나. 친구에게 "안녕"이라고 카톡을 보내면, 그 "안녕"이라는 글자가 그대로 전선을 타고 갈까?

- 컴퓨터와 전선이 이해하는 것은 두 가지뿐이다. 전기가 흐른다, 흐르지 않는다.
- 이를 숫자로 쓰면 1과 0이다.
- 글자, 사진, 음성 모두 컴퓨터끼리 주고받으려면 0과 1의 나열로 바꿔야 한다.

비유: 전등 스위치. 스위치 하나는 켜짐과 꺼짐 2가지 상태이며, 이것이 정보의 최소 한 조각이다. 스위치를 여러 개 늘어놓으면 표현할 수 있는 조합이 폭발적으로 늘어난다.

## 2. 구성 요소

### 2.1 Bit: 소통의 최소 단위

- Bit(비트)는 0 또는 1이며 데이터의 가장 작은 단위다(binary digit).
- 스위치 1개는 1 bit이며 2가지(2¹) 상태를 가진다.
- 스위치 2개는 4가지(2²), 3개는 8가지(2³)다. n개는 2ⁿ가지다.

### 2.2 Byte: 비트를 묶은 단위

- 비트 8개를 묶은 것이 1 Byte이며 2⁸ = 256가지를 표현한다.
- 8개로 묶은 이유는 문자 하나(영문, 숫자, 기호)를 표현하기에 적당했기 때문이다. 아래 문자 코드로 이어진다.

| 단위 | 크기 |
|---|---|
| 1 KB | 1024 Byte |
| 1 MB | 1024 KB |
| 1 GB | 1024 MB |

### 2.3 문자 코드

컴퓨터는 글자도 숫자로 바꿔 저장하고 전송한다. 문자와 숫자의 약속표가 문자 코드다.

| 코드 | 설명 |
|---|---|
| ASCII | 영문, 숫자, 기호를 7bit(0~127)로 표현한다. 예: `A`=65, `a`=97, `0`=48 |
| 유니코드 / UTF-8 | 전 세계 문자를 표현한다. 한글 `가` 같은 글자는 여러 바이트로 인코딩한다 |

### 2.4 진법

같은 값을 사람은 10진수로, 컴퓨터는 2진수로 다루고, 표기 편의를 위해 16진수를 쓴다.

| 진법 | 사용하는 곳 | 예시 |
|---|---|---|
| 2진수 | 컴퓨터 내부, 서브넷 마스크 | `11000000` |
| 10진수 | 사람이 읽는 IP | `192` |
| 16진수 | MAC 주소, IPv6 | `C0`, `FF` |

- 8 bit는 2진수 8자리이며 16진수 2자리와 같다.
- 2진수와 10진수의 변환 감각은 이후 IP와 서브넷의 기초 체력이다. → [4. 데이터는 어디로 갈까 — IP 주소](lesson-4.md)(LEC-N1-01-004-DO), [2일차 · IP와 서브넷](../day-02/README.md)

## 3. 동작 원리: "A"가 건너가는 과정

```
보내는 쪽:  'A'  →  (ASCII) 65  →  (2진수) 01000001  →  전선으로 전송 →
받는 쪽:  01000001  →  65  →  'A'  로 복원
```

- "안녕"도 각 글자가 유니코드 숫자, 2진수 순서로 바뀌어 전송되고 받는 쪽에서 다시 글자로 복원된다.
- 보내는 쪽과 받는 쪽의 인코딩이 다르면 글자가 깨진다(모지바케). 실무에서 자주 만나는 문제다.

### 3.1 bit와 Byte 구분

- 전송 속도는 보통 bps(bits per second)로 쓴다. 예: 100 Mbps.
- 파일 크기는 보통 Byte로 쓴다. 예: 100 MB.
- 100 Mbps는 이론상 약 12.5 MB/s다(8로 나눈다).
- 설명 포인트: "100M 인터넷인데 다운로드가 왜 12MB/s인가?"

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| Bit | binary digit. 0 또는 1 |
| Byte | 8 bit |
| ASCII | American Standard Code for Information Interchange. 7bit 문자 코드 |
| UTF-8 | 유니코드를 1~4바이트로 인코딩하는 방식 |
| 모지바케 | 인코딩 불일치로 글자가 깨지는 현상 |
| bps | bits per second. 초당 전송 비트 수 |
