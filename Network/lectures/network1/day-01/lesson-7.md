# 7. 유니 · 브로드 · 멀티캐스트

> 상위: [1일차 · 네트워크 기본](README.md)

## 🎯 학습 목표

- 전송 방식(캐스트)의 3가지를 구분한다
- 각 방식이 실제로 쓰이는 상황을 이해한다
- 브로드캐스트 도메인의 개념을 잡는다

## 🌉 다리 놓기: "꼭 한 명에게만 보내는 건 아니다"

앞에서 IP 주소로 **특정 한 대**를 콕 집어 데이터를 보낸다고 했다. → [4_어디로_보낼까_IP주소](lesson-4.md)

이렇게 **1:1로 보내는 게 유니캐스트**다. 그런데 늘 한 명에게만 보낼까?

- "우리 동네 사람 **전부**에게 알릴 일"이 있고 (전체)
- "관심 있는 **몇 명에게만** 보낼 일"도 있다 (그룹)

> 💡 카톡으로 치면 — **1:1 채팅 / 공지 전체 발송 / 단톡방**. 이 세 가지가 각각 유니·브로드·멀티캐스트.

## 📖 전송 방식(Cast)의 종류

| 방식 | 수신 대상 | 비유 | 예시 |
|------|-----------|------|------|
| **유니캐스트(Unicast)** | 1 → 1 (특정 한 대) | 1:1 전화 | 웹서핑, 파일 전송 대부분 |
| **브로드캐스트(Broadcast)** | 1 → 전체 (같은 네트워크 모두) | 확성기 방송 | ARP 요청, DHCP Discover |
| **멀티캐스트(Multicast)** | 1 → 그룹 (구독한 대상만) | 단체 채팅방 | 실시간 스트리밍, 라우팅 프로토콜(OSPF) |
| *(참고) 애니캐스트* | 1 → 가장 가까운 하나 | 가장 가까운 지점 안내 | DNS 루트 서버, CDN |

## 📖 조금 더 자세히

- **유니캐스트**: 목적지 IP가 특정 한 대. → [4_어디로_보낼까_IP주소](lesson-4.md)에서 배운 "주소로 한 대 찾기"가 바로 이것. 인터넷 트래픽의 대부분.
- **브로드캐스트**: 목적지 MAC `FF:FF:FF:FF:FF:FF`. 같은 네트워크(= [5_LAN_WAN_토폴로지](lesson-5.md)의 그 'LAN 동네') 전체가 수신 → 남발하면 성능 저하.
- **멀티캐스트**: 특정 그룹 주소를 구독한 장비만 수신. 대역폭 절약.

## 📖 브로드캐스트 도메인

- 브로드캐스트가 전달되는 범위 (= 하나의 '동네')
- **스위치**(2계층)는 브로드캐스트를 통과시킴 → 같은 도메인
- **라우터**(3계층)는 브로드캐스트를 막음 → 도메인 분리 ([6_프로토콜_OSI7계층](lesson-6.md)의 계층 관점과 연결)
- VLAN으로 브로드캐스트 도메인을 논리적으로 나눌 수 있음 (이후 심화)
- 장비별 동작은 3일차 → [3일차 · 네트워크 장비와 네트워크 토폴로지](../day-03/README.md)
