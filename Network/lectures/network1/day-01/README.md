| 개정 | R1 (2026-11-18) |

패킷트레이서로 실습에 들어가기 전에 네트워크의 기초 용어와 개념을 다지는 첫 시간이다. 문서 번호(Task ID)는 `LEC-N1-01-<번호>-<유형>` 형식이다.

## 학습 목표

- 네트워크 1·2 과정 전체 흐름과 취득 가능한 자격증을 안내한다.
- 네트워크가 무엇인지 일상 예시로 이해한다.
- 컴퓨터가 0과 1로 소통하는 원리(Bit, Byte)와 문자 코드를 이해한다.
- 데이터를 목적지에 보내기 위해 주소(IP)가 필요한 이유를 이해한다.
- LAN, WAN과 네트워크 토폴로지의 종류와 특징을 구분한다.
- 프로토콜의 개념과 OSI 7계층의 각 역할을 설명한다.
- 통신 방식(유니캐스트, 브로드캐스트, 멀티캐스트)의 차이를 구분한다.
