## 학습 목표

- 프로토콜의 개념과 필요성을 이해한다.
- OSI 7계층 각 계층의 역할, 대표 프로토콜, 장비를 설명한다.
- 지금까지 배운 개념(0과 1, IP, 망)이 어느 계층에 해당하는지 연결한다.

## 1. 목적

### 1.1 다리 놓기: 규칙이 같아야 말이 통한다

지금까지의 흐름은 다음과 같다.

1. 데이터를 0과 1로 바꾼다. → [3. Bit · Byte · 문자 코드](lesson-3.md)(LEC-N1-01-003-DO)
2. IP 주소로 목적지를 정한다. → [4. IP 주소](lesson-4.md)(LEC-N1-01-004-DO)
3. 망(LAN, WAN)을 통해 보낸다. → [5. LAN · WAN 과 네트워크 토폴로지](lesson-5.md)(LEC-N1-01-005-DO)

보내는 쪽과 받는 쪽이 같은 규칙을 쓰지 않으면 0과 1을 어디서 끊어 읽을지, 주소를 어디에 적을지 서로 몰라 통신이 안 된다. [2. 네트워크란 무엇인가](lesson-2.md)(LEC-N1-01-002-DO)의 3요소 중 마지막인 규약이 이것이며, 이 규약이 프로토콜이다.

### 1.2 프로토콜이란

- 서로 다른 장비가 통신하기 위해 미리 정한 통신 규약(약속)이다.
- 언어가 다르면 대화가 안 되듯, 규약이 같아야 데이터를 교환할 수 있다.
- 대표 프로토콜: TCP/IP, HTTP, FTP, Ethernet.

## 2. 구성 요소

### 2.1 OSI 7계층

통신이라는 복잡한 과정을 7단계로 나눈 표준 참조 모델이다. 문제가 생기면 몇 계층 문제인지 진단하는 기준이 된다.

| 계층 | 이름 | 역할 | 대표 프로토콜·기술 | 장비 | 데이터 단위(PDU) |
|---|---|---|---|---|---|
| 7 | 응용(Application) | 사용자 서비스 | HTTP, FTP, DNS, SMTP | - | Data |
| 6 | 표현(Presentation) | 인코딩, 암호화, 압축 | SSL/TLS, JPEG | - | Data |
| 5 | 세션(Session) | 연결 관리, 동기화 | 세션 관리 | - | Data |
| 4 | 전송(Transport) | 신뢰성, 포트, 흐름 제어 | TCP, UDP | - | Segment |
| 3 | 네트워크(Network) | 논리 주소, 경로 결정 | IP, ICMP, 라우팅 | 라우터 | Packet |
| 2 | 데이터링크(Data Link) | 물리 주소, 오류 검출 | Ethernet, MAC, ARP | 스위치, 브리지 | Frame |
| 1 | 물리(Physical) | 전기, 신호 전송 | 케이블, 전압 | 허브, 리피터 | Bit |

암기 팁(위에서 아래): **A**ll **P**eople **S**eem **T**o **N**eed **D**ata **P**rocessing.

### 2.2 우리가 배운 내용의 위치

- 1계층(물리)은 0과 1 신호다. [3. Bit · Byte · 문자 코드](lesson-3.md)의 그 비트가 전선을 타는 지점이다.
- 3계층(네트워크)은 IP 주소와 경로 결정이다. [4. IP 주소](lesson-4.md)가 이 계층이다.
- 2계층(데이터링크)은 MAC 주소(물리 주소)다. 3일차에서 자세히 다룬다.
- 오늘 배운 개념들이 계층이라는 서랍에 정리된다.

### 2.3 OSI 7계층과 TCP/IP 모델 비교

| OSI 7계층 | TCP/IP 4계층 |
|---|---|
| 7·6·5 응용, 표현, 세션 | 응용(Application) |
| 4 전송 | 전송(Transport) |
| 3 네트워크 | 인터넷(Internet) |
| 2·1 데이터링크, 물리 | 네트워크 접근(Network Access) |

OSI는 교육과 진단용 참조 모델이고, TCP/IP는 실제 인터넷이 쓰는 모델이다.

## 3. 동작 원리: 캡슐화 (Encapsulation)

- 데이터가 상위에서 하위 계층으로 내려가며 각 계층의 헤더가 덧붙는다.
- 흐름: Data, (L4) Segment, (L3) Packet, (L2) Frame, (L1) Bit.
- 받는 쪽은 반대로 역캡슐화(Decapsulation)를 한다.

편지 비유(2번, 4번 문서의 확장): 편지(Data)에 주소 봉투(IP)를 씌우고 다시 겉봉투(MAC)를 씌워 보낸다. 받는 쪽은 겉에서부터 하나씩 벗겨 읽는다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| OSI | Open Systems Interconnection. 통신을 7계층으로 나눈 참조 모델 |
| PDU | Protocol Data Unit. 계층별 데이터 단위 |
| TCP/IP | 실제 인터넷이 쓰는 4계층 모델 |
| 캡슐화 | 하위 계층으로 내려가며 헤더를 덧붙이는 과정 |
| 역캡슐화 | 수신 쪽에서 헤더를 순서대로 벗기는 과정 |
