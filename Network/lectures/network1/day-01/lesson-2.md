## 학습 목표

- "네트워크"를 일상의 언어로 한 문장으로 설명할 수 있다.
- 네트워크의 3요소(노드, 링크, 규약)를 이해한다.
- 매일 쓰는 서비스가 네트워크 위에서 돌아간다는 것을 체감한다.

## 1. 목적

### 1.1 도입: 오늘 아침에 이미 네트워크를 몇 번 썼을까

눈을 뜨자마자 한 일을 떠올려 보게 한다. 카톡 확인, 유튜브·인스타, 날씨 앱, 버스 도착 정보, 배달 주문, 인터넷 뱅킹, 지도 길찾기가 있다.

이 전부가 네트워크 위에서 일어난다. 너무 익숙해서 의식하지 못할 뿐이다.

### 1.2 네트워크의 정의

네트워크(Network)는 둘 이상의 장치가 서로 연결되어 정보와 자원을 주고받는 것이다.

- `net`(그물)과 `work`(엮다)가 합쳐진 말로, 서로 엮인 관계망을 뜻한다.
- 컴퓨터만의 개념이 아니다. 인맥 네트워크, 도로망, 전력망, 지하철 노선도도 네트워크다.
- 컴퓨터 네트워크는 그중 데이터를 주고받는 연결망이다.

## 2. 구성 요소

### 2.1 네트워크의 3요소

| 요소 | 뜻 | 일상 비유 (도로망) |
|---|---|---|
| 노드(Node) | 연결된 장치 (PC, 폰, 서버, 라우터 등) | 집, 건물, 도시 |
| 링크(Link) | 노드를 잇는 통로 (랜선, 와이파이, 광케이블) | 도로, 고속도로 |
| 규약(Protocol) | 주고받는 방법의 약속 | 교통 법규(신호, 차선) |

셋 중 하나만 빠져도 통신이 되지 않는다. 규약(프로토콜)은 [6. 프로토콜 · OSI 7계층](lesson-6.md)(LEC-N1-01-006-DO)에서 자세히 다룬다.

### 2.2 네트워크의 목적

1. 정보 공유: 메시지, 웹페이지, 영상(카톡, 유튜브).
2. 자원 공유: 프린터, 파일 서버, 저장 공간(회사 공용 폴더).
3. 처리 분담: 무거운 일은 서버가 하고 결과만 내 기기로 받는다(클라우드, AI 서비스).

핵심 한 줄: 혼자 다 갖지 않고 연결해서 나눠 쓴다.

## 3. 동작 원리: 편지 부치기

네트워크를 쉽게 떠올리는 멘탈 모델이다.

1. 내가 쓴 편지(데이터)를 준비한다.
2. 봉투에 주소를 적는다(IP).
3. 우체국과 집배원이 배달한다(라우터, 스위치).
4. 상대가 개봉한다(수신).

이 그림은 이후에 배울 IP, 장비, 계층 개념으로 그대로 이어진다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 노드(Node) | 네트워크에 연결된 장치 |
| 링크(Link) | 노드를 잇는 통로 |
| 규약(Protocol) | 통신 방법에 대한 약속 |
| 인터넷(Internet) | inter-network. 네트워크들을 연결한 거대한 네트워크 |
