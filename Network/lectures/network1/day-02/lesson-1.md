## 🎯 학습 목표

- IPv4 주소가 32비트(8비트×4)로 이루어졌음을 이해한다

- IPv6가 왜 등장했는지(주소 고갈) 안다

## 🌉 다리 놓기: "192.168.0.10, 이게 정확히 뭐지?"

1일차에 IP 주소는 결국 **2진수**라고 했다. → [4_어디로_보낼까_IP주소](../day-01/lesson-4.md)
오늘은 그 구조를 뜯어본다. (2진수 감각은 [3_Bit_Byte_문자코드](../day-01/lesson-3.md)에서 다진 그것!)

## 📖 IPv4 주소의 구조

```
   192   .   168   .    0    .   10
11000000 . 10101000 . 00000000 . 00001010
```

- **32비트** = 8비트씩 4덩어리(옥텟, octet)
- 각 옥텟 = 8비트 = **0 ~ 255** (2⁸ = 256가지)
- 사람이 읽기 쉽게 점(.)으로 구분 → **점 10진법(dotted decimal)**
- 총 주소 수 = 2³² ≈ **약 43억 개**

> 💡 "왜 255까지야?" → 8비트로 표현 가능한 최댓값이 `11111111` = 255이기 때문. (1일차 bit 이야기 그대로)

## 📖 IPv4의 한계 → IPv6의 등장

- 인터넷·스마트폰·IoT 폭증 → 43억 개로는 **부족**(주소 고갈)
- 임시 처방: 사설 IP + NAT → [3_공인IP와_사설IP](lesson-3.md)
- 근본 해결: **IPv6** (128비트)

| 구분   | IPv4                  | IPv6                         |
| ---- | --------------------- | ---------------------------- |
| 길이   | 32비트                  | 128비트                        |
| 표기   | 점 10진법 `192.168.0.10` | 콜론 16진법 `2001:0db8:...:7334` |
| 주소 수 | 약 43억                 | 사실상 무한(2¹²⁸)                 |
| 구분자  | 점(.)                  | 콜론(:)                        |

- IPv6는 16진수를 쓴다 → 1일차에서 16진수를 배운 이유! ([3_Bit_Byte_문자코드](../day-01/lesson-3.md))

### IPv6, 왜 저렇게 짧아 보이지? — 축약 규칙

128비트를 다 쓰면 너무 길다. 그래서 **줄여 쓰는 규칙**이 있다. 위 표의 `...` 자리가 바로 이것.

```
원본             2001:0db8:0000:0000:0000:ff00:0042:8329
                 └─ 16비트(4자리) × 8묶음 = 128비트

① 각 묶음 앞의 0 떼기   2001:db8:0:0:0:ff00:42:8329
② 0만 연속된 구간 → ::  2001:db8::ff00:42:8329
```

- `::` 는 **한 주소에 딱 한 번만** 쓸 수 있다 → 두 번 쓰면 어느 쪽이 몇 묶음인지 알 수 없기 때문
- 그래서 실제로 보는 IPv6는 짧아 보이지만, **속은 언제나 128비트**다

자주 마주치는 IPv6 주소:

| 주소 | 이름 | IPv4로 치면 |
|---|---|---|
| `::1` | 루프백 (나 자신) | `127.0.0.1` |
| `fe80::`로 시작 | 링크로컬 (같은 망 안에서만) | `169.254.x.x` → [3_공인IP와_사설IP](lesson-3.md) |
| `::` | 미지정 | `0.0.0.0` |

> 💡 `ipconfig`에 이미 `fe80::`로 시작하는 줄이 보일 것이다. **IPv6는 이미 내 PC에 켜져 있다.**

- IPv6 실제 사용/설정은 8일차 → [8일차 · 무선랜과 IPv6 맛보기](../day-08/lesson-5.md)

## 🧪 실습 / 질문

- 윈도우 `ipconfig` (또는 `ipconfig /all`)로 내 **IPv4 주소**와 **IPv6 주소**를 찾아본다
  - `fe80::`로 시작하는 줄을 찾아 "이게 링크로컬 IPv6"라고 짚어보기
- `192.168.0.10`을 2진수로 바꿔보기 → 각 옥텟을 8비트로
- **축약 연습**: `2001:0db8:0000:0000:0011:0000:0000:0001` 을 줄여보자
  - (답: `2001:db8:0:0:11::1` — `::`는 한 번뿐이라 **더 긴 0 구간**인 뒤쪽에 쓴다)

## 📝 강의 메모

- 옥텟 하나 = 8비트 = 0~255 를 확실히 각인 → 서브넷마스크·서브넷팅의 토대
- IPv6는 "존재와 이유" + **축약 읽는 법**까지만. 서브넷팅·설정 상세는 7일차로 위임
- `::` 한 번 제한은 반드시 이유(복원 불가)와 함께 → 규칙 암기가 아니라 납득으로
