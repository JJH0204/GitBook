## 5. 절차

### A. 한 개만 확인

1. (5-A-01) `192.168.1.10/26`의 네트워크 주소, 브로드캐스트, 호스트 범위를 손으로 계산한다. → 결과: 블록 크기 256 − 192 = 64, 네트워크 `192.168.1.0`, 브로드캐스트 `192.168.1.63`.
2. (5-A-02) 터미널에서 `python subnet_calc.py`를 실행한다. → 결과: 입력을 요구하는 화면이 나온다.
3. (5-A-03) 모드 `[1] 한 개만 확인`에서 `192.168.1.10/26`을 입력한다. → 결과: 아래와 같이 출력된다.

```
네트워크 주소    : 192.168.1.0
브로드캐스트     : 192.168.1.63
서브넷 마스크    : 255.255.255.192  (/26)
전체 주소 수     : 64
사용 가능 호스트 : 62개  (192.168.1.1 ~ 192.168.1.62)
└ 손계산 확인    : 블록 크기 = 256 - 192 = 64
```

4. (5-A-04) 5-A-01의 손계산 값과 출력을 대조한다. → 결과: 모든 값이 같다.

### B. 나눈 결과를 통째로 확인

1. (5-B-01) `192.168.1.0/24`를 `/26`으로 나눈 표를 손으로 만든다(4단계 사용). → 결과: 서브넷 4개의 네트워크 주소와 브로드캐스트가 적힌다.
2. (5-B-02) 모드 `[2] 나눈 결과를 통째로 확인`에서 `192.168.1.0/24 > /26`을 입력한다. → 결과: 아래와 같이 출력된다.

```
빌린 비트   : 2개   →  서브넷 2^2 = 4개
서브넷당    : 전체 64개 / 사용 가능 62개  (전체 - 2)

  #  네트워크 주소        사용 가능 호스트                    브로드캐스트
------------------------------------------------------------------------
  1  192.168.1.0/26       192.168.1.1 ~ 192.168.1.62         192.168.1.63
  2  192.168.1.64/26      192.168.1.65 ~ 192.168.1.126       192.168.1.127
  3  192.168.1.128/26     192.168.1.129 ~ 192.168.1.190      192.168.1.191
  4  192.168.1.192/26     192.168.1.193 ~ 192.168.1.254      192.168.1.255
```

3. (5-B-03) 5-B-01의 손계산 표와 출력을 한 줄씩 대조한다. → 결과: 4단계로 만든 표와 완전히 같다.

### C. 연습 문제 채점

1. (5-C-01) [서브넷팅](lesson-4.md)의 연습 문제 1~4를 손으로 푼다. → 결과: 각 문제의 답이 적힌다.
2. (5-C-02) 각 문제의 입력을 스크립트에 넣어 답을 대조한다. 예: `192.168.10.0/24 > /28`, `172.16.5.4/20`. → 결과: 손계산 답과 출력이 같다. 다르면 4단계를 다시 밟는다.
