## 1. 목적

동네와 호수의 경계는 누가 정하는가를 설명한다. 1일차에 IP = 네트워크부(동네) + 호스트부(몇 호)라고 배웠다. → [어디로 보낼까: IP 주소](../day-01/lesson-4.md)

32비트 중 어디까지가 동네이고 어디부터가 호수인지를 정하는 것이 클래스와 서브넷 마스크다.

## 2. 구성 요소

### 8비트 자릿값 표

오늘 나오는 숫자(클래스 범위, 서브넷 마스크)는 모두 이 표에서 나온다. 이 표 하나가 2일차의 열쇠다.

| 비트 자리 | 1번째 | 2번째 | 3번째 | 4번째 | 5번째 | 6번째 | 7번째 | 8번째 |
|---|---|---|---|---|---|---|---|---|
| 값 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

- 1이 켜진 자리의 값을 더하면 10진수가 된다.
- `11000000` = 128 + 64 = 192
- `11110000` = 128 + 64 + 32 + 16 = 240
- 8칸을 모두 켜면 128+64+32+16+8+4+2+1 = 255이다. 1번 문서에서 본 255다.

{% hint style="info" %}
NOTE: 오른쪽 끝부터 1, 2, 4, 8로 두 배씩 커진다. 외우지 않고 두 배씩 적어 나가면 된다.
{% endhint %}

클래스 범위도 이 표로 설명된다. A는 첫 비트가 `0`이라 128을 쓸 수 없어 최대 127이다. B는 `10`으로 시작(128~191)하고, C는 `110`으로 시작(192~223)한다.

### IP 클래스 (첫 옥텟으로 구분)

| 클래스 | 첫 옥텟 범위 | 네트워크부 | 기본 마스크 | 용도 |
|---|---|---|---|---|
| A | 0 ~ 127 | 앞 1옥텟 | 255.0.0.0 (/8) | 초대형(호스트 많음) |
| B | 128 ~ 191 | 앞 2옥텟 | 255.255.0.0 (/16) | 중형 |
| C | 192 ~ 223 | 앞 3옥텟 | 255.255.255.0 (/24) | 소형(호스트 최대 254) |
| D | 224 ~ 239 | 해당 없음 | 해당 없음 | 멀티캐스트 → [캐스트: 유니, 브로드, 멀티](../day-01/lesson-7.md) |
| E | 240 ~ 255 | 해당 없음 | 해당 없음 | 연구·예약 |

`192.168.0.10`은 첫 옥텟이 192이므로 C 클래스다.

{% hint style="warning" %}
CAUTION: 표의 `0 ~ 127`은 비트 패턴 기준 범위다. 실제로 쓰는 A 클래스는 `1 ~ 126`이다. `0.x.x.x`는 예약 대역이고, `127.x.x.x`는 루프백(자기 자신, `127.0.0.1`)이라 제외된다.
{% endhint %}

## 3. 동작 원리

### 서브넷 마스크 = 네트워크부와 호스트부의 경계선

마스크에서 1인 자리는 네트워크부, 0인 자리는 호스트부다.

```
IP    192.168.0.10  → 11000000.10101000.00000000.00001010
Mask  255.255.255.0 → 11111111.11111111.11111111.00000000
                       └──── 네트워크부 ────┘ └호스트부┘
```

- CIDR 표기는 1인 비트의 개수다. 255.255.255.0은 `/24`, 그 외에 `/16`, `/8`이 있다.
- `192.168.0.10/24`는 "앞 24비트가 네트워크, 나머지 8비트가 호스트"라는 뜻이다.

비유: 우편번호. 앞자리는 지역(네트워크부), 뒷자리는 세부 위치(호스트부)다. 마스크는 "앞 몇 자리까지가 지역인지" 알려 주는 규칙이다.

### 네트워크 주소 구하기: IP AND 마스크

그림만 그리고 끝내지 않고 둘을 겹쳐서 계산하면 네트워크 주소가 나온다. 규칙은 하나다.

{% hint style="info" %}
NOTE: 마스크가 1인 자리는 IP를 그대로 두고, 0인 자리는 전부 0으로 만든다. 이것이 비트 AND 연산이다(둘 다 1일 때만 1).
{% endhint %}

```
IP        192.168.0.10    →  11000000.10101000.00000000.00001010
Mask      255.255.255.0   →  11111111.11111111.11111111.00000000
──────────────────────────── AND ───────────────────────────────
Network   192.168.0.0     →  11000000.10101000.00000000.00000000
                                                        └호스트 자리가 통째로 0
```

- 호스트 자리(`00001010` = 10)가 지워졌다. 남은 것이 "동네 이름"인 네트워크 주소다.
- 같은 동네 사람은 IP가 달라도 결과가 같다. `.10`, `.77`, `.200` 모두 `192.168.0.0`이다.
- 호스트 부분을 가려서 네트워크만 남기므로 마스크(mask, 가림막)라고 부른다.

매번 2진수로 풀면 느리다. 실전에서는 블록 크기라는 지름길을 쓴다. → [서브넷팅](lesson-4.md)

### 마스크에 나오는 숫자

마스크의 1은 왼쪽부터 빈틈없이 채워진다(중간에 0이 끼어들 수 없다). 그래서 한 옥텟에 나올 수 있는 값은 아래가 전부다. 자릿값 표를 왼쪽부터 누적해서 더한 값이다.

| CIDR | 2진수 | 10진수 | 더해진 값 |
|---|---|---|---|
| /25 | `10000000` | 128 | 128 |
| /26 | `11000000` | 192 | +64 |
| /27 | `11100000` | 224 | +32 |
| /28 | `11110000` | 240 | +16 |
| /29 | `11111000` | 248 | +8 |
| /30 | `11111100` | 252 | +4 |
| /31 | `11111110` | 254 | +2 |
| /32 | `11111111` | 255 | +1 |

- `255.255.255.192`를 보면 "마지막 옥텟에서 2비트를 더 썼다 = /26"으로 바로 읽는다.
- `255.255.255.7` 같은 마스크는 존재할 수 없다. 7 = `00000111`이라 1이 왼쪽부터 채워져 있지 않다.

이 8개 숫자가 서브넷팅 계산의 출발점이다. → [서브넷팅](lesson-4.md)

## 4. 연습 문제

### 연습 1: 내 IP는 몇 클래스인가

1. `ipconfig`로 내 IPv4 주소를 확인하고 첫 옥텟을 본다. 예) `192.168.0.10` → 192 → C 클래스.
2. 다음 IP의 클래스를 답한다: `10.0.0.5` / `172.16.5.4` / `200.100.50.1`
   - 답: A / B / C

{% hint style="warning" %}
CAUTION: 루프백은 `127.x.x.x`(`127.0.0.1`)다. `172.16 ~ 172.31.x.x`는 루프백이 아니라 B 클래스 사설 대역이다. → [공인 IP와 사설 IP](lesson-3.md)
{% endhint %}

### 연습 2: 자릿값 표로 오가기

1. `192.168.0.10/24`의 네트워크 주소를 구한다. 답: `192.168.0.0` (AND 연산으로 확인한다)
2. 2진수를 10진수로 바꾼다.
   - `11100000` = ? 답: 128+64+32 = 224
   - `11111100` = ? 답: 252
3. 10진수 마스크를 CIDR로 바꾼다.
   - `255.255.255.240`은 /몇인가? 답: 240 = `11110000` → 4비트 → 24+4 = /28
   - `255.255.0.0`은 /몇인가? 답: /16

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| 네트워크부 / 호스트부 | IP 주소에서 동네를 나타내는 앞부분 / 그 안의 개별 장치를 나타내는 뒷부분 |
| 서브넷 마스크 | 네트워크부와 호스트부의 경계를 1과 0으로 나타낸 32비트 값 |
| CIDR | Classless Inter-Domain Routing. `/24`처럼 1의 개수로 마스크를 쓰는 표기 |
| AND 연산 | 두 비트가 모두 1일 때만 1이 되는 연산 |
| 루프백 | 자기 자신을 가리키는 주소(`127.0.0.1`) |

## 6. 강의 메모

- 자릿값 표(128 64 32 16 8 4 2 1)는 칠판 구석에 적어 두고 수업 내내 지우지 않는다. 4번 서브넷팅에서 계속 쓴다.
- "마스크의 1 = 고정(네트워크), 0 = 변함(호스트)"를 한 문장으로 각인시킨다.
- 마스크 8개 숫자는 암기가 아니라 누적 덧셈으로 그 자리에서 만들어 내게 한다(128 → +64 → +32 ...).
- 클래스는 개념 이해용이다. 실무는 클래스를 무시하고 마스크로 자유롭게 나눈다. → [서브넷팅](lesson-4.md)
