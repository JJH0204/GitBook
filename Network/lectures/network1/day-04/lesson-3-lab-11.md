## 5. 절차

### A. 라우팅 테이블 확인

1. (5-A-01) 라우터를 클릭하고 `CLI` 탭을 연다. → 결과: `Router>` 프롬프트가 보인다.
2. (5-A-02) `enable`을 입력한다. → 결과: `Router#` 프롬프트로 바뀐다.
3. (5-A-03) `show ip route`를 입력한다. → 결과: `C` 항목 2개가 보인다. IP를 준 인터페이스가 2개이기 때문이다.
4. (5-A-04) `show ip interface brief`를 입력한다. → 결과: 두 인터페이스가 모두 `up/up`이다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `show ip route`에서 `C`와 `L` 항목을 센다 | `C` 2개, `L` 2개 | 각 2개 |
| 2 | `show ip interface brief`에서 `Status`와 `Protocol`을 본다 | 둘 다 `up` | 두 인터페이스 모두 `up/up` |
| 3 | `C`와 `L`이 각각 무엇인지 말로 설명한다 | `C`는 직접 연결된 네트워크, `L`은 인터페이스 자신의 주소(`/32`) | 두 코드를 구분해 설명한다 |
