## 학습 목표

- 무선랜의 구성 요소(AP, SSID)와 유선과의 차이(CSMA/CA)를 안다.
- 무선 보안의 순서(WEP 금지, WPA2, WPA3)와 PSK, Enterprise를 구분한다.
- AP는 스위치 포트에 꽂히는 "무선 액세스 포트"라는 것을 이해한다(7일차 VLAN과 연결).
- IPv6 주소를 읽고 축약할 수 있고, 주요 주소 종류를 구분한다.

## 이전 학습과의 연결

오늘까지 만든 회사망은 유선이고 IPv4다. 현실에는 손님이 둘 더 있다.

1. 노트북과 폰은 케이블 없이 붙는다. → 무선랜
2. IPv4는 바닥났다(2일차). → IPv6. → [1_IP주소체계_IPv4와IPv6](../day-02/lesson-1.md)

## 1. 구성 요소

### 무선랜 — 전파로 늘린 LAN

| 요소 | 설명 |
|---|---|
| AP (Access Point) | 무선 기기를 유선 LAN에 이어주는 장치 |
| SSID | 무선 네트워크의 이름 (예: `KoreaIT`) |
| 무선 클라이언트 | 노트북, 폰 (무선 NIC) |

- AP는 스위치에 꽂힌다. 7일차 관점으로 보면 AP는 "전파로 된 액세스 포트"다.
- AP가 꽂힌 스위치 포트가 VLAN 10이면 무선으로 붙은 노트북도 VLAN 10 주민이 되어 DHCP로 `192.168.10.x`를 받는다.
- 실무에서는 SSID마다 VLAN을 다르게 준다. 예: "KoreaIT-직원" = VLAN 10, "KoreaIT-손님" = VLAN 30.

### 802.11 표준과 주파수

| 표준 | 통칭 | 주파수 |
|---|---|---|
| 802.11n | Wi-Fi 4 | 2.4 / 5 GHz |
| 802.11ac | Wi-Fi 5 | 5 GHz |
| 802.11ax | Wi-Fi 6 (6E는 6 GHz 추가) | 2.4 / 5 GHz |

- 2.4 GHz는 멀리 가지만 느리고 간섭이 많다. 5 GHz는 빠르지만 거리가 짧다.

### 무선 보안

| 방식 | 평가 | 한 줄 |
|---|---|---|
| WEP | 사용 금지 | 몇 분이면 뚫린다 |
| WPA | 과도기 | WEP 땜질용 |
| WPA2 | 표준 | AES 암호화 |
| WPA3 | 권장 | 더 강한 보호, 공용 Wi-Fi도 개별 암호화 |

| 인증 | 대상 | 방식 |
|---|---|---|
| Personal (PSK) | 가정, 소규모 | 비밀번호 하나를 모두가 공유 |
| Enterprise (802.1X) | 회사 | 사람마다 계정(RADIUS 서버). [4_포트보안](lesson-4.md)의 802.1X와 같은 것 |

{% hint style="warning" %}
CAUTION: SSID 숨김과 MAC 필터링은 보조 수단일 뿐이다. MAC은 위조할 수 있다([4_포트보안](lesson-4.md)의 한계와 같은 이유).
{% endhint %}

## 2. 동작 원리

### 유선과 다른 점 — 부딪칠까 봐 눈치를 본다

| 항목 | 유선 이더넷 (예전 허브) | 무선 |
|---|---|---|
| 방식 | CSMA/CD: 충돌을 감지 | CSMA/CA: 충돌을 회피 |
| 이유 | 선 위에서 충돌을 알 수 있다 | 공중에서는 충돌을 감지하기 어렵다 |
| 이중 | 스위치면 전이중 | 반이중: 전파를 나눠 쓴다 |

- 무선은 허브 시절로 돌아간 것과 비슷하다. 모두가 한 공기(전파)를 나눠 쓴다. 그래서 카페에 사람이 많으면 느려진다. (4일차 반이중 대 전이중 → [1_스위치_동작원리](../day-04/lesson-1.md))

### IPv6 — 128비트 새 주소

IPv6 주소는 128비트이며 16비트씩 8덩어리로 나누고, 콜론(`:`)으로 구분한다. 각 덩어리는 16진수 4자리다(1일차 16진수 → [3_Bit_Byte_문자코드](../day-01/lesson-3.md)).

```
2001:0db8:0000:0000:0000:0000:0000:0001
```

축약 규칙은 딱 두 개다.

1. 덩어리마다 앞자리 0을 생략한다: `0db8 → db8`, `0001 → 1`
2. 연속된 0 덩어리는 `::`로 줄인다. 전체에서 딱 한 번만 쓴다.

```
2001:0db8:0000:0000:0000:0000:0000:0001
2001:db8:0:0:0:0:0:1            ① 앞자리 0 생략
2001:db8::1                     ② 연속 0 을 :: 로
```

{% hint style="warning" %}
CAUTION: `::`를 두 번 쓰면 어느 쪽에 0이 몇 개인지 알 수 없다. 금지다.
{% endhint %}

### IPv6 주소 종류

| 종류 | 시작 | IPv4로 치면 |
|---|---|---|
| 글로벌 유니캐스트 | `2000::/3` (2나 3으로 시작) | 공인 IP |
| 링크 로컬 | `fe80::/10` | `169.254.x.x`. 단, IPv6는 항상 자동으로 생긴다 |
| 유니크 로컬 | `fc00::/7` | 사설 IP |
| 멀티캐스트 | `ff00::/8` | 멀티캐스트 |
| 루프백 | `::1` | `127.0.0.1` |

- IPv6에는 브로드캐스트가 없다. 멀티캐스트로 대신한다(1일차 캐스트 → [7_캐스트_유니_브로드_멀티](../day-01/lesson-7.md)).
- ARP도 없다. NDP(이웃 탐색)가 멀티캐스트로 한다.
- 서브넷은 보통 `/64`이고, 인터페이스 ID를 MAC으로 만드는 방식(EUI-64)도 있다(3일차 MAC).

### 전환 — 한동안은 둘 다

| 방식 | 뜻 |
|---|---|
| 듀얼 스택 | IPv4와 IPv6를 동시에 쓴다 (가장 흔함) |
| 터널링 | IPv6를 IPv4로 감싸서 전달한다 |
| 변환 (NAT64 등) | 서로 번역한다 |

## 3. 실습 연계와 확인 질문

- 맛보기 실습(선택)은 [무선랜과 IPv6 맛보기 실습](lesson-5-lab.md)에 있다.
- "무선인데 왜 VLAN 10 주소를 받았을까?" → AP가 꽂힌 포트가 VLAN 10이다. AP는 전파로 된 액세스 포트다.
- "스위치 설정을 하나도 안 바꿨는데 IPv6가 된다. 왜일까?" → 스위치는 2계층이라 MAC만 본다. 안에 든 것이 IPv4인지 IPv6인지 상관없다(1일차 OSI 계층 분리).

## 4. 강의 메모

- 15분 맛보기다. 시간이 없으면 표 두 개(보안 순서, 주소 종류)와 축약 예제 하나만 다룬다.
- 무선은 "AP = 전파로 된 액세스 포트" 한 문장으로 7일차에 붙인다. 이것이 오늘의 새 관점이다.
- IPv6는 실습 질문("스위치 설정을 안 바꿨는데?")이 핵심이다. OSI 계층 분리를 몸으로 느끼는 장면이다.
- 축약 연습 문제: `2001:0db8:0000:0000:0000:ff00:0042:8329` → `2001:db8::ff00:42:8329`
- `ipv6 unicast-routing` 누락은 라우터가 IPv6를 넘겨주지 않는 가장 흔한 실수다.
- 무선 개념과 실습은 10일차에 한 번 더 다룬다. → [10일차 · 서버 기초](../../network2/day-10/README.md)

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| AP | Access Point. 무선 접속 장치 |
| SSID | Service Set Identifier. 무선 네트워크 이름 |
| CSMA/CA | Carrier Sense Multiple Access with Collision Avoidance. 충돌 회피 방식 |
| WPA2 / WPA3 | Wi-Fi Protected Access. 무선 보안 표준 |
| PSK | Pre-Shared Key. 공유 비밀번호 방식 |
| RADIUS | 사용자 인증 서버 프로토콜 |
| NDP | Neighbor Discovery Protocol. IPv6의 이웃 탐색(ARP 대체) |
| EUI-64 | MAC 주소로 IPv6 인터페이스 ID를 만드는 방식 |
