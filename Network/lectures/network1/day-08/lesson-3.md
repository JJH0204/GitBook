# 3. SNMP · Proxy · FTP — 감시하고, 대신 가고, 파일을 나른다

> 상위: [8일차 · 네트워크 장비에서의 서버 설정](README.md)

## 🎯 학습 목표

- SNMP(감시) · Proxy(중계) · FTP(전송)의 역할을 구분한다
- 각 서비스의 **포트**와 **보안 대안**을 안다
- 패킷트레이서에서 **FTP 접속**과 **SNMP 조회**를 맛본다

## 🌉 다리 놓기: "들어가고(SSH), 주소 주고(DHCP), 이름 불렀다(DNS). 그다음은?"

회사망을 운영하려면 세 가지가 더 필요하다.

| 필요 | 서비스 |
|------|--------|
| 스위치가 **지금 괜찮은지** 매번 SSH 로 들어가 볼 순 없다 | **SNMP** — 원격 감시 |
| 직원들이 **이상한 사이트**에 가지 않게, 자주 가는 곳은 **빠르게** | **Proxy** — 대신 다녀오기 |
| 설정 파일 · 자료를 **서버와 주고받기** | **FTP** — 파일 전송 |

## 📖 SNMP — 관제실의 계기판

- **SNMP** (Simple Network Management Protocol): 장비 상태(트래픽 · 오류 · CPU · 포트 up/down)를 **원격으로 모니터링**
- 구성: **매니저**(관제 서버) ↔ **에이전트**(각 장비), 에이전트가 들고 있는 정보 창고 = **MIB**
- 포트 UDP **161**(매니저가 묻는다) / **162**(**트랩** — 장비가 먼저 "나 이상해!" 알림)

| 버전 | 인증 | 평가 |
|------|------|------|
| v1 · **v2c** | **커뮤니티 문자열**(사실상 평문 비밀번호, 기본 `public`) | 취약 — 실습용 |
| **v3** | 사용자 인증 + 암호화 | **실무 권장** |

> 💡 **비유: 관제실.** 관제실(매니저)이 각 장비(에이전트)의 **계기판(MIB)** 을 원격으로 들여다본다.
> 평소엔 관제실이 **물어보고(161)**, 사고가 나면 장비가 **먼저 비상벨(트랩, 162)** 을 누른다.

```bash
snmp-server community public ro          # "public" 을 아는 사람에게 읽기(ro)만 허락
```

> ⚠️ `rw`(읽기·쓰기)로 열면 커뮤니티 문자열을 아는 누구나 **설정을 바꿀 수 있다.** 실습에서도 **`ro`** 로.

## 📖 Proxy — 대신 다녀오는 심부름꾼

- **Proxy**: 클라이언트를 **대신해** 요청을 중계하는 서버

| 용도 | 설명 |
|------|------|
| **캐싱** | 자주 가는 페이지를 저장 → 두 번째부터 **빠르게** |
| **필터링** | 유해 · 업무 무관 사이트 **차단** |
| **접근 제어 · 기록** | 누가 어디에 갔는지 남긴다 |
| **익명화** | 바깥에서는 **프록시의 IP** 만 보인다 |

| 종류 | 누구를 대신하나 | 예 |
|------|------------------|-----|
| **포워드 프록시** | **클라이언트**(직원) | 회사 인터넷 필터 |
| **리버스 프록시** | **서버** | 웹서버 앞의 문지기 |

> 💡 **비유: 심부름꾼.** 직원이 직접 가게에 가지 않고 심부름꾼(프록시)에게 부탁한다.
> 심부름꾼은 **금지된 가게는 안 가고**, 자주 사오는 물건은 **창고에 쟁여둔다(캐시).**

> 📌 패킷트레이서에는 프록시 장비가 없다 → **개념만.** 실제 구축은 2단계 리눅스 → 12_리눅스서버구축

## 📖 FTP — 파일 전송

- **FTP** (File Transfer Protocol): 파일 **업로드(put) · 다운로드(get)**
- 포트 TCP **21**(제어 — 명령이 오가는 길) / **20**(데이터 — 파일이 오가는 길)
- ⚠️ **평문** — 아이디 · 비밀번호 · 파일 내용이 그대로 흐른다

| 평문 | 보안 대안 | 관계 |
|------|-----------|------|
| Telnet (23) | **SSH** (22) | [1_원격접속_Telnet과SSH](lesson-1.md) |
| FTP (20/21) | **SFTP**(SSH 위에서) · **FTPS**(TLS) | Telnet ↔ SSH 와 **같은 구도** |
| SNMP v2c | **SNMP v3** | 위 |

> 💡 네트워크 장비에서 FTP/TFTP 는 **설정 파일 백업 · IOS 이미지 업로드**에 쓴다.
> (`copy running-config tftp` 같은 명령 — 이름만)

**패킷트레이서 Server 는 FTP 가 기본으로 켜져 있다** (계정 `cisco` / 비밀번호 `cisco`)

```bash
C:\> ftp 192.168.10.10
Username: cisco
Password: cisco
ftp> dir                 # 서버에 있는 파일 목록
ftp> quit
```

## 📖 오늘의 서비스 · 포트 정리

| 서비스 | 포트 | 역할 | 보안 대안 |
|--------|------|------|-----------|
| **FTP** | TCP 20 / 21 | 파일 전송 (평문) | **SFTP / FTPS** |
| **SSH** | TCP 22 | 원격 접속 (암호화) | — |
| **Telnet** | TCP 23 | 원격 접속 (평문) | **SSH** |
| **DNS** | UDP/TCP 53 | 이름 ↔ IP | — |
| **DHCP** | UDP 67 / 68 | IP 자동 할당 | — |
| **HTTP** | TCP 80 | 웹 (평문) | **HTTPS 443** |
| **SNMP** | UDP 161 / 162 | 감시 · 트랩 | **v3** |

> 📌 **20 · 21 · 22 · 23 · 53 · 67/68 · 80 · 161/162** — 네트워크관리사 · CCNA 단골. 번호 순서대로 외우면 편하다.
> TCP / UDP 의 차이는 2단계 10일차에서 → [10일차 · 서버 기초](../../network2/day-10/README.md)

## 📝 강의 메모

- 세 서비스는 **"운영에 필요한 것"** 이라는 한 줄로 묶어서 짧게 — 오늘의 주연은 SSH · DHCP · 포트 보안이다
- **"평문 vs 암호화"** 짝(Telnet/SSH · FTP/SFTP · v2c/v3 · HTTP/HTTPS)을 표 하나로 반복 → 보안 감각 각인
- 포트 번호표는 **시험 단골** — 칠판에 번호순으로 적어두고 CCNA 시간에 다시 짚는다
- 프록시는 PT 에 없다 → 개념만. 12일차 리눅스에서 직접 구축한다
- 이 서비스들의 리눅스 서버 구축은 2단계 12일차 → 12_리눅스서버구축
