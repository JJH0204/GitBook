# 6일차 · 라우팅 프로토콜 심화 — 재분배

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

5일차에 RIP·OSPF·EIGRP 를 배웠고, 한 라우터에 **두 프로토콜을 동시에** 켜보기도 했다.
→ [5일차](../day-05/README.md)

그런데 현실의 망은 **구역마다 쓰는 말이 다르다.** 회사가 합병하거나, 부서마다 장비가 다르거나,
프로토콜을 갈아타는 중이거나. 서로 다른 프로토콜은 **상대의 경로를 모른다.**
오늘은 그 둘을 이어주는 **재분배(Redistribution)** 다.

## 🎯 오늘의 목표

- 프로토콜이 **자기 언어끼리만 통한다**는 사실을 이해한다 (같은 장비 안이어도!)
- 재분배가 필요한 상황과, 재분배가 일어나는 **위치(경계 라우터 = ASBR)** 를 안다
- **메트릭 불일치**와 **seed metric** 의 개념을 이해한다
- 재분배 명령을 **어느 프로세스 안에서** 치는지 헷갈리지 않는다
- 재분배의 위험(**루프 · 차선 경로**)을 이해한다
- 패킷트레이서로 **RIP ↔ OSPF 양방향 재분배**를 구성하고, `O E2` 경로를 확인한다

## 🧪 오늘의 실습 — **새 파일에 처음부터 만든다**

> 📌 **5일차 파일을 고쳐 쓰지 않는다.** 새 파일에 그림을 다시 만든다.
> 그림과 주소는 5일차와 **완전히 같다** — 세 번째라 손이 기억하고 있을 것이다.
> 바뀌는 건 **어느 구간이 무슨 말을 쓰는가** 뿐이다.

```
      ◀────── RIP 구역 ──────▶   ◀───── OSPF 구역 ─────▶
[PC0]──[SW1]──[R1]══════[R2]══════[R3]──[SW2]──[PC2]
 .10.1        20.0/24    ▲   50.0/24        .30.1
                         │
                  RIP + OSPF 를 둘 다 도는 라우터
                  = 통역사 = ASBR = 오늘의 주인공
```

| 단계 | 내용 | 이 단계의 목적 | 시간 |
|------|------|----------------|------|
| **준비** | 그림 만들기 | 인터페이스까지 up/up | 20분 |
| **①** | 구역 나누기 (RIP / OSPF) | 무대 만들기 | 25분 |
| **②** | **왜 안 되는지 확인** | R2 만 다 안다는 것을 눈으로 | 10분 |
| **③** ⭐ | **양방향 재분배** | seed metric 실패 → 성공 | 30분 |
| **④** | `E1` vs `E2` · `default-metric` | 정리와 심화 (생략 가능) | 15분 |

- 그림 만들기가 **세 번째**다 — 20분 안에 끝나야 정상
- **모든 재분배 명령은 R2 한 대에서만** — R1·R3 는 끝까지 손대지 않는다

## ⏳ 오늘도 **기다리는 실습**

> 🚨 RIP 쪽은 **최대 30초**를 기다려야 경로가 오간다. OSPF 쪽은 몇 초.
> 5일차에 이미 겪었지만 **한 번 더 공지**할 것.

## 📝 진행 메모

- **상황극(회사 합병)으로 시작**한다. "케이블은 붙었는데 왜 안 되죠?"
- 🗣 **"R2 는 다 아는데 왜 통신이 안 될까?"** — 이 질문 하나로 오늘 수업이 굴러간다.
  학생이 스스로 **"옮겨주지 않아서"** 라고 말하게 만드는 게 목표
- **②(실패 확인)를 절대 건너뛰지 말 것.** 성공부터 보면 필요성이 안 와닿는다
- **③의 "메트릭 없이 먼저 쳐보기"가 오늘의 명장면** — 실패를 먼저 겪게 한다
- ⚠️ **명령 위치 혼동**이 최대 병목 → **"받는 집에 들어가서, 어디서 가져올지 말한다"** 를 구호처럼
- ⚠️ **비대칭 주의**: RIP·EIGRP 는 seed metric **필수**, OSPF 는 기본 20 → "OSPF 는 되던데요?" 대비
- 위험(루프·차선 경로)은 **"왜 위험한지"만.** route-map·`distance` 는 **이름만** 예고
- 실무 난이도가 있는 주제 → **개념(왜/무엇) → 주의점 → 실습** 순으로 천천히
- **오늘의 회수 지점**
  1. 5일차 "메트릭은 같은 프로토콜끼리만" → **그래서 통역할 때 새로 정해줘야 한다**
  2. 4일차 "라우팅은 왕복" → **재분배도 양방향을 각각**
  3. 4일차 CCNA Q4(AD) → **재분배 시 AD 충돌 위험**
- 마무리: **4~6일차 라우팅 3부작 정리**
  → 손으로(정적) → 알아서(동적) → 말이 다른 구역 잇기(재분배)
