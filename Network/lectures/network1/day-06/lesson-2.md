## 1. 목적

"통역이 왜 까다로운가"에 답한다. 답은 프로토콜마다 최적 경로를 재는 자(尺)가 다르다는 것이다. → [1. 라우팅 프로토콜 개요](../day-05/lesson-1.md)

| 프로토콜 | 무엇으로 재나 | 값의 예 |
|---|---|---|
| RIP | 홉 수 | 3 |
| OSPF | 코스트(대역폭) | 20 |
| EIGRP | 대역폭 + 지연 | 28160 |

RIP의 "3홉"을 OSPF에게 그대로 넘기면 OSPF는 "3"이 무슨 뜻인지 모른다. 코스트 3인지 홉 3인지 단위가 없어 판단하지 못한다.

비유: "여기서 3정거장이에요"를 거리(km)로만 말하는 사람에게 전하려면 "3정거장"을 그대로 옮기면 안 된다. 받는 쪽 단위로 바꿔 줘야 한다.

## 2. 구성 요소

재분배 설정에 쓰는 요소는 다음과 같다.

| 요소 | 역할 | 비고 |
|---|---|---|
| `redistribute <주는 쪽>` | 어디서 경로를 가져올지 지정한다 | 받는 프로토콜 설정 안에서 친다 |
| `metric <값>` | 받는 쪽 단위로 새 메트릭(seed metric)을 정한다 | RIP, EIGRP는 필수 |
| `subnets` | 서브넷팅된 경로까지 넘긴다 | OSPF로 넘길 때만 쓴다 |
| `default-metric <값>` | 재분배 전체의 기본 메트릭을 정한다 | 재분배 줄이 여러 개일 때 |
| `metric-type 1` | OSPF External 타입을 E1로 바꾼다 | 기본은 E2 |

## 3. 동작 원리

### Seed Metric (씨앗 메트릭)

Seed Metric은 재분배할 때 넘겨받는 프로토콜이 쓸 메트릭 값을 관리자가 정해 주는 것이다.

- 원래 메트릭을 변환하는 것이 아니다. 버리고 새로 정한다.
- 그래서 거리 정보가 사라진다. 뒤에 나오는 차선 경로 부작용의 근본 원인이다.

```bash
router rip
 redistribute ospf 1 metric 3        ← "이 경로들은 RIP 세상에서 3홉짜리로 쳐라"
```

기본 seed metric은 프로토콜마다 다르다.

| 넘겨받는 쪽 | 기본 seed metric | 지정 필요 | 안 주면 |
|---|---|---|---|
| RIP | 무한대(∞) | 필수 | 광고되지 않는다 |
| EIGRP | 무한대(∞) | 필수 | 광고되지 않는다 |
| OSPF | 20 | 선택 | 20으로 동작한다 |
| BGP | IGP 메트릭 승계 | 선택 | 그대로 |

{% hint style="danger" %}
WARNING: "재분배 명령은 분명히 쳤는데 경로가 안 온다"의 1위 원인은 RIP 또는 EIGRP로 넘길 때 `metric`을 안 준 것이다. 무한대는 도달 불가이므로 광고 자체를 하지 않고, 상대는 아무 소식도 받지 못한다.
{% endhint %}

실습 ③에서 일부러 메트릭 없이 먼저 쳐서 실패를 보고, `metric 3`을 붙여 성공시킨다. → [3. 재분배 실습](lesson-3.md)

#### `default-metric`: 여러 줄을 한 번에

```bash
router rip
 default-metric 3          ← 이 프로세스로 들어오는 모든 재분배의 기본값
 redistribute ospf 1
 redistribute static
```

- 재분배 줄이 여러 개일 때 매번 `metric`을 쓰지 않아도 된다.
- 실무 습관은 `default-metric` 한 줄로 몰아 쓰는 것이다.

### 명령 위치: 받는 집에 들어가서, 어디서 가져올지 말한다

```
① 넣고 싶은 곳(받는 프로토콜)으로 들어간다     router ospf 1
② 어디서 가져올지 말한다                        redistribute rip subnets metric 20
```

{% hint style="warning" %}
CAUTION: 가장 흔한 실수는 주는 쪽에 들어가서 치는 것이다. "받는 집에 들어가서, 어디서 가져올지 말한다"로 외운다.
{% endhint %}

| 하고 싶은 것 | 들어가는 곳 | 치는 명령 |
|---|---|---|
| RIP 경로를 OSPF에 넣기 | `router ospf 1` | `redistribute rip subnets metric 20` |
| OSPF 경로를 RIP에 넣기 | `router rip` | `redistribute ospf 1 metric 3` |
| 정적 경로를 OSPF에 넣기 | `router ospf 1` | `redistribute static subnets metric 20` |
| 직접연결을 RIP에 넣기 | `router rip` | `redistribute connected metric 3` |

#### `subnets` 키워드

- OSPF로 재분배할 때만 쓰는 키워드다.
- 없으면 클래스풀 경로(A/B/C 기본 마스크)만 넘어가고 서브넷팅된 경로는 누락된다. 예: `172.16.1.0/24`는 B 클래스를 쪼갠 것이므로 `subnets`가 없으면 넘어가지 않는다.
- 이 수업의 실습은 `192.168.x.0/24`(C 클래스 기본 마스크)라 없어도 넘어간다. 그래도 항상 붙이는 습관을 들인다. 실무 대부분은 서브넷팅되어 있기 때문이다.

### 방향: 단방향과 양방향(상호)

| 구분 | 설명 | 위험도 |
|---|---|---|
| 단방향 | A에서 B로만 넘긴다 | 낮음 |
| 양방향(상호, mutual) | A와 B가 서로 넘긴다 | 높음 |

- 끝단끼리 ping이 되려면 결국 양방향이 필요하다. 라우팅은 왕복이다(4일차 회수).
- 실습에서도 두 방향을 각각 설정한다. 명령이 두 줄인 이유다.
- 위험한 것은 양방향 자체가 아니라 양방향 재분배 지점이 두 곳 이상일 때다.

### 재분배의 위험 3가지

#### ① 라우팅 루프

```
        ┌──[R2]──┐
[RIP]───┤        ├───[OSPF]
        └──[R4]──┘
     경계 라우터가 두 곳!
```

- R2가 RIP에서 OSPF로 넘긴 경로가 R4를 통해 다시 RIP으로 되돌아온다.
- 되돌아온 경로가 원래 것보다 AD가 낮아 보이면 라우터가 그것을 믿는다. 그러면 경로가 빙빙 돈다.
- 대응: 재분배 지점을 한 곳으로 줄인다. route-map으로 걸러 낸다. AD를 조정한다(`distance`).

#### ② 차선 경로 (Suboptimal Routing)

- seed metric은 원래 거리를 버리고 새로 매긴 값이다.
- 넘겨받는 쪽은 어느 목적지가 더 가까운지 구분하지 못한다(전부 같은 값).
- 그래서 더 먼 길을 고를 수 있다.

실습에서 R1이 30.0과 50.0을 둘 다 `[120/3]`으로 본다. 실제 거리가 다른데도 똑같이 3홉으로 보이는 것이 정보 손실의 실물이다.

#### ③ AD 충돌

- 같은 목적지를 여러 출처로 배우면 AD가 낮은 쪽만 테이블에 오른다.
- 그런데 그 경로가 내가 원한 경로가 아닐 수 있다.
- 대응: `distance` 명령으로 AD를 손으로 조정한다(심화, 이름만 소개한다).

실무 3원칙은 ① 재분배 지점 최소화, ② 필터(route-map)로 통제, ③ 필요 시 AD 조정이다. 셋 다 CCNP 수준 주제이므로 오늘은 "왜 위험한지"만 다룬다.

### `O E1`과 `O E2`

OSPF로 재분배된 경로에는 타입 번호가 붙는다.

| 구분 | `O E2` (기본값) | `O E1` |
|---|---|---|
| 코스트 계산 | seed metric 그대로(어디서 보든 같다) | seed metric + 내부 코스트 |
| 예 | 항상 `[110/20]` | `[110/21]`, `[110/23]` 등 위치마다 다르다 |
| 언제 좋은가 | 경계 라우터가 한 곳일 때 | 경계 라우터가 여러 곳이고 가까운 쪽을 고르고 싶을 때 |

E2는 외부까지의 거리만, E1은 외부까지의 거리에 거기까지 가는 내 거리를 더한 값이다. 통역사가 여럿이면 가까운 통역사를 골라야 하므로 E1이 유리하다.

실습 ④에서 `metric-type 1`로 바꿔 표시와 숫자가 둘 다 변하는 것을 확인한다. → [3. 재분배 실습](lesson-3.md)

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| Seed Metric | 재분배 시 관리자가 새로 정해 주는 메트릭 값 |
| `default-metric` | 재분배되는 모든 경로에 적용하는 기본 메트릭 |
| mutual redistribution | 양방향(상호) 재분배 |
| Suboptimal Routing | 차선 경로. 더 먼 길이 선택되는 현상 |
| AD | Administrative Distance. 출처별 신뢰도 |
| E1 / E2 | OSPF External 경로 타입 1 / 2 |

## 강의 메모

- "단위가 다르다, 통역할 땐 새 단위를 정해 줘야 한다(seed metric)"를 한 문장으로 각인시킨다.
- RIP·EIGRP는 필수, OSPF는 기본 20이라는 비대칭을 반드시 짚는다. "OSPF 쪽은 안 줘도 되던데요?"라는 질문이 반드시 나온다.
- 명령 위치 혼동이 실습 최대 병목이다. "받는 집에 들어가서"를 구호처럼 반복한다.
- 위험 3가지는 "왜 위험한지"만 다룬다. route-map과 distance는 이름만 예고하고 선을 긋는다.
- 차선 경로는 실습 결과(`[120/3]` 두 줄)를 가리키며 설명하면 말 없이도 전달된다.
