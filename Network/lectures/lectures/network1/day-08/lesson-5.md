# 5. (맛보기) 무선랜과 IPv6 — 선 없는 손님, 새 주소

> 상위: [8일차 · 네트워크 장비에서의 서버 설정](README.md)

## 🎯 학습 목표

- 무선랜의 구성 요소(**AP · SSID**)와 유선과의 차이(**CSMA/CA**)를 안다
- 무선 보안의 순서(**WEP ❌ → WPA2 → WPA3**)와 PSK / Enterprise 를 구분한다
- **AP 는 스위치 포트에 꽂히는 "무선 액세스 포트"** 라는 것을 이해한다 (7일차 VLAN 과 연결)
- IPv6 주소를 **읽고 축약**할 수 있고, 주요 **주소 종류**를 구분한다

## 📖 ① 무선랜 — 전파로 늘린 LAN

| 요소 | 설명 |
|------|------|
| **AP** (Access Point) | 무선 기기를 **유선 LAN 에 이어주는** 장치 |
| **SSID** | 무선 네트워크의 **이름** (예: `KoreaIT`) |
| **무선 클라이언트** | 노트북 · 폰 (무선 NIC) |

> 💡 **AP 는 스위치에 꽂힌다.** 7일차 관점으로 보면 AP 는 **"전파로 된 액세스 포트"** 다.
> AP 가 꽂힌 스위치 포트가 **VLAN 10** 이면, 무선으로 붙은 노트북도 **VLAN 10 주민** → DHCP 로 `192.168.10.x` 를 받는다.
> (실무에서는 SSID 마다 VLAN 을 달리 준다 — "KoreaIT-직원" = VLAN 10, "KoreaIT-손님" = VLAN 30)

### 802.11 표준 · 주파수

| 표준 | 통칭 | 주파수 |
|------|------|--------|
| 802.11n | Wi-Fi 4 | 2.4 / 5 GHz |
| 802.11ac | Wi-Fi 5 | 5 GHz |
| 802.11ax | Wi-Fi 6 (6E 는 6 GHz 추가) | 2.4 / 5 GHz |

- **2.4 GHz**: 멀리 가지만 느리고 간섭이 많다 · **5 GHz**: 빠르지만 거리가 짧다

### 유선과 다른 점 — 부딪칠까 봐 눈치 본다

| | 유선 이더넷 (예전 허브) | 무선 |
|---|---|---|
| 방식 | **CSMA/CD** — 충돌을 **감지** | **CSMA/CA** — 충돌을 **회피** |
| 이유 | 선 위에서 충돌을 알 수 있다 | 공중에선 충돌을 **감지하기 어렵다** |
| 이중 | 스위치면 전이중 | **반이중** — 전파를 **나눠 쓴다** |

> 💡 무선은 **허브 시절로 돌아간 것**과 비슷하다 — 모두가 한 공기(전파)를 나눠 쓴다.
> 그래서 **카페에 사람이 많으면 느려진다.** (4일차 반이중 vs 전이중 → [1_스위치_동작원리](../day-04/lesson-1.md))

### 무선 보안 — 전파는 벽을 넘는다

| 방식 | 평가 | 한 줄 |
|------|------|-------|
| **WEP** | ❌ 사용 금지 | 몇 분이면 뚫린다 |
| WPA | △ 과도기 | WEP 땜질용 |
| **WPA2** | ✅ 표준 | AES 암호화 |
| **WPA3** | ✅ 권장 | 더 강한 보호, 공용 Wi-Fi 도 개별 암호화 |

| 인증 | 대상 | 방식 |
|------|------|------|
| **Personal (PSK)** | 가정 · 소규모 | 비밀번호 **하나를 모두가 공유** |
| **Enterprise (802.1X)** | 회사 | **사람마다 계정** (RADIUS 서버) — [4_포트보안](lesson-4.md)의 802.1X 와 같은 것 |

- **SSID 숨김 · MAC 필터링**은 **보조 수단**일 뿐 — MAC 은 위조할 수 있다 ([4_포트보안](lesson-4.md)의 한계와 같은 이유)

## 📖 ② IPv6 — 128비트 새 주소

### 생김새

- **128비트** = 16비트씩 **8덩어리**, 콜론(`:`) 으로 구분, 각 덩어리는 **16진수 4자리** (1일차 16진수 → [3_Bit_Byte_문자코드](../day-01/lesson-3.md))

```
2001:0db8:0000:0000:0000:0000:0000:0001
```

### 축약 규칙 — 딱 두 개

1. 덩어리마다 **앞자리 0 생략**: `0db8 → db8` · `0001 → 1`
2. **연속된 0 덩어리**는 `::` 로 — **전체에서 딱 한 번**

```
2001:0db8:0000:0000:0000:0000:0000:0001
2001:db8:0:0:0:0:0:1            ① 앞자리 0 생략
2001:db8::1                     ② 연속 0 을 :: 로   ✅
```

> ⚠️ `::` 를 두 번 쓰면 **어느 쪽에 0 이 몇 개인지** 알 수 없다 → 금지

### 주소 종류

| 종류 | 시작 | IPv4 로 치면 |
|------|------|--------------|
| **글로벌 유니캐스트** | `2000::/3` (2·3 으로 시작) | 공인 IP |
| **링크 로컬** | `fe80::/10` | `169.254.x.x` — 단, IPv6 는 **항상 자동으로 생긴다** |
| 유니크 로컬 | `fc00::/7` | 사설 IP |
| **멀티캐스트** | `ff00::/8` | 멀티캐스트 |
| 루프백 | `::1` | `127.0.0.1` |

- **IPv6 에는 브로드캐스트가 없다** → 멀티캐스트로 대신한다 (1일차 캐스트 → [7_캐스트_유니_브로드_멀티](../day-01/lesson-7.md))
- ARP 도 없다 → **NDP**(이웃 탐색)가 멀티캐스트로 한다
- 서브넷은 보통 **`/64`** · 인터페이스 ID 를 **MAC 으로 만드는 방식(EUI-64)** 도 있다 (3일차 MAC)

### 전환 — 한동안은 둘 다

| 방식 | 뜻 |
|------|-----|
| **듀얼 스택** ⭐ | IPv4 · IPv6 **동시에** (가장 흔함) |
| 터널링 | IPv6 를 IPv4 로 **감싸서** 전달 |
| 변환 (NAT64 등) | 서로 **번역** |

## 🧪 맛보기 실습 (선택) — 오늘 회사망 그대로

> 🖐 명령은 → [8일차 대본 STEP 7](commands.md)

**A. 무선 노트북을 VLAN 10 에 붙인다**

1. **AccessPoint-PT** 를 SW2 **Fa0/3** 에 연결 → SW2 에서 Fa0/3 을 **액세스 VLAN 10** 으로
2. AP `Config → Port 1`: SSID `KoreaIT` · **WPA2-PSK** · 비밀번호 `example-password`
3. 노트북 **전원 끄기** → 유선 NIC 빼기 → **WPC300N** 장착 → 전원 켜기
4. 노트북 `Config → Wireless0`: 같은 SSID · WPA2-PSK · 비밀번호 → IP 는 **DHCP**
5. 🔎 노트북이 **`192.168.10.x`** 를 받는다 → R1 의 **VLAN10 풀**에서 온 것 → `ping www.student.local`

> 🗣 **"무선인데 왜 VLAN 10 주소를 받았죠?"** → AP 가 꽂힌 포트가 VLAN 10 이니까. **AP 는 전파로 된 액세스 포트.**

**B. 스위치는 IPv6 를 신경 쓰지 않는다**

1. PC0 · PC2 (둘 다 VLAN 10) 의 IP Configuration → IPv6 수동: `2001:db8:10::1/64` · `2001:db8:10::2/64`
2. PC0 에서 `ping 2001:db8:10::2` → **성공**
3. 🗣 **"스위치 설정은 하나도 안 바꿨는데 IPv6 가 됩니다. 왜죠?"**
   → 스위치는 **2계층**이다. MAC 만 보고, 안에 든 게 IPv4 든 IPv6 든 **상관없다** (1일차 OSI 계층 분리의 힘)
4. (여유) 라우터를 넘으려면 R1 에 `ipv6 unicast-routing` + 서브인터페이스에 `ipv6 address` → 대본 참고

## 📝 강의 메모

- **15분 맛보기**다. 시간이 없으면 표 두 개(보안 순서 · 주소 종류)와 축약 예제 하나만
- 무선은 **"AP = 전파로 된 액세스 포트"** 한 문장으로 7일차에 붙인다. 이게 오늘의 새 관점
- IPv6 는 **실습 B 의 질문**("스위치 설정을 안 바꿨는데?")이 핵심 — OSI 계층 분리를 몸으로 느끼는 장면
- 축약 연습 문제: `2001:0db8:0000:0000:0000:ff00:0042:8329` → **`2001:db8::ff00:42:8329`**
- ⚠️ `ipv6 unicast-routing` 누락 = 라우터가 IPv6 를 **넘겨주지 않는다** (가장 흔한 실수)
