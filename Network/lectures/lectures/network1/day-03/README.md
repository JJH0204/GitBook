# 3일차 · 네트워크 장비와 네트워크 토폴로지

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

2일차까지 IP로 네트워크를 **나누는** 법을 배웠다. → [2일차: IP와 서브넷](../day-02/README.md)
오늘은 그 네트워크를 **실제 장비로 연결**하고, **패킷트레이서로 직접 구성**해 본다. (1일차 OSI에서 예고한 계층별 장비·MAC이 여기서 등장!)

## 🎯 오늘의 목표

- 허브·리피터·스위치·라우터가 각각 어느 계층에서 무슨 일을 하는지 구분한다
- **충돌 도메인**과 **브로드캐스트 도메인**을 구분하고, 어느 장비가 무엇을 나누는지 안다
- 장비를 잇는 **케이블 종류**를 고르고 인터페이스 이름을 읽는다
- MAC 주소가 무엇이고, ARP가 IP를 MAC으로 바꾸는 과정을 이해한다
- **다른 네트워크로 보낼 때는 게이트웨이의 MAC을 찾는다**는 것을 안다
- ICMP(ping)로 통신 상태를 확인하고, **결과 메시지로 원인을 좁힌다**
- 패킷트레이서로 첫 네트워크를 구성하고 통신을 검증한다
