# 3. 컴퓨터는 어떻게 소통할까 — Bit · Byte · 문자 코드

> 상위: [1일차 · 네트워크 기본](README.md)

## 🎯 학습 목표

- 컴퓨터가 정보를 오직 **0과 1**로만 다룬다는 것을 이해한다
- Bit → Byte로 표현할 수 있는 정보가 커지는 원리를 이해한다
- 사람의 문자가 **숫자(코드) → 2진수**로 바뀌어 전송되는 과정을 이해한다

## 🌉 다리 놓기: "연결은 했는데, 뭘 어떻게 보내지?"

앞에서 네트워크는 *장치들이 연결되어 정보를 주고받는 것*이라고 했다. → [2_네트워크란_무엇인가](lesson-2.md)

그런데 질문 하나. **내가 친구에게 "안녕"이라고 카톡을 보내면, 그 "안녕"이라는 글자가 그대로 전선을 타고 갈까?**

- 컴퓨터와 전선이 이해하는 것은 딱 두 가지뿐 → **전기가 흐른다 / 안 흐른다**
- 이걸 숫자로 쓰면 **1 / 0**
- 그래서 글자든 사진이든 음성이든, 컴퓨터끼리 주고받으려면 **전부 0과 1의 나열로 바꿔야** 한다

> 💡 비유: **전등 스위치**. 하나는 켜짐/꺼짐 2가지 상태 = 정보의 최소 한 조각.
> 스위치를 여러 개 늘어놓으면 표현할 수 있는 조합이 폭발적으로 늘어난다.

## 📖 Bit — 소통의 최소 단위

- **Bit(비트)** = 0 또는 1, 데이터의 가장 작은 단위 (binary digit)
- 스위치 1개 = 1 bit = 2가지(2¹) 상태
- 스위치 2개 = 4가지(2²), 3개 = 8가지(2³) … n개 = **2ⁿ**가지

## 📖 Byte — 비트를 묶다

- 스위치(비트) 8개를 묶은 것이 **1 Byte** → 2⁸ = **256가지** 표현 가능
- 왜 하필 8개? 문자 하나(영문·숫자·기호)를 표현하기에 적당했기 때문 → 아래 문자 코드로 연결
- 데이터 크기 단위: 1 KB = 1024 Byte, 1 MB = 1024 KB, 1 GB = 1024 MB …

## 📖 예시로 보는 소통: "A"는 어떻게 건너갈까 (문자 코드)

컴퓨터는 글자도 **숫자로 바꿔** 저장·전송한다. 이 *문자 ↔ 숫자 약속표*가 **문자 코드**다.

```
보내는 쪽:  'A'  →  (ASCII) 65  →  (2진수) 01000001  →  전선으로 전송 →
받는 쪽:  01000001  →  65  →  'A'  로 복원 ✅
```

- **ASCII**: 영문·숫자·기호를 7bit(0~127)로 표현 (예: `A`=65, `a`=97, `0`=48)
- **유니코드 / UTF-8**: 전 세계 문자를 표현. 한글 `가` 같은 글자는 여러 바이트로 인코딩
- 보내는 쪽과 받는 쪽의 **인코딩이 다르면 글자가 깨진다**(모지바케) → 실무에서 자주 만나는 문제

> "안녕"도 결국 각 글자가 유니코드 숫자 → 2진수로 바뀌어 전송되고, 받는 쪽에서 다시 글자로 복원되는 것.

## 📖 진법 — 사람과 컴퓨터의 표기 차이

같은 값을 사람은 10진수로, 컴퓨터는 2진수로 다루고, 표기 편의를 위해 16진수를 쓴다.

| 진법 | 사용하는 곳 | 예시 |
|------|-------------|------|
| 2진수 | 컴퓨터 내부, 서브넷 마스크 | `11000000` |
| 10진수 | 사람이 읽는 IP | `192` |
| 16진수 | MAC 주소, IPv6 | `C0`, `FF` |

- 8 bit = 2진수 8자리 = 16진수 2자리
- 2진수 ↔ 10진수 변환 감각은 이후 IP·서브넷의 기초 체력 → 바로 다음 [4_어디로_보낼까_IP주소](lesson-4.md), 그리고 [2일차 · IP와 서브넷](../day-02/README.md)로 연결

### ⚠️ 자주 헷갈리는 포인트: bit vs Byte

- **전송 속도**는 보통 **bps**(bits per second) — 예: 100 Mbps
- **파일 크기**는 보통 **Byte** — 예: 100 MB
- 100 Mbps ≈ 이론상 12.5 MB/s (÷8) → "왜 100M 인터넷인데 다운로드는 12MB/s?" 설명 포인트

## 🧪 실습: 파이썬으로 문자 → 코드 변환 보기

손으로 변환하는 대신 **ascii_convert.py** 를 함께 돌려본다. 입력한 문자열의 각 글자를 *10진수 → 2진수(8bit) → 16진수*로 한 번에 보여준다.

> 📦 **파이썬·VS Code가 아직 없다면 먼저 설치** → [파이썬 · VS Code 설치 (10분)](../../setup/lesson-1.md)
> (설치 사고 대부분은 `Add python.exe to PATH` 체크 누락이다)

**VS Code에서 실행하기**
1. `ascii_convert.py` 파일을 연다
2. 오른쪽 위 **▶ (Run Python File)** 버튼 클릭 — 또는 터미널에 `python ascii_convert.py`
3. (처음이면 Microsoft **Python 확장** 설치 안내가 뜬다 → 설치)
4. 입력을 요구하면 **아래 터미널을 클릭한 뒤** 타이핑

입력 `AB1` → 출력:

```
 문자 | 10진수 |  2진수(8bit) | 16진수
------+--------+--------------+-------
  A   |    65  |   01000001  |  0x41
  B   |    66  |   01000010  |  0x42
  1   |    49  |   00110001  |  0x31
```

- 노트의 `A → 65 → 01000001` 예시가 **눈앞에서 그대로** 재현됨

**그다음, 한글을 입력해보자 (예: `가`)**

```
  가   |  44032  |   1010110000000000  |  0xAC00
```

- 코드값이 **8비트(0~255)를 훌쩍 넘는다** → ASCII(1바이트)로는 한글을 못 담는다
- 그래서 **UTF-8** 같은 인코딩이 필요! → 위에서 배운 *인코딩/모지바케* 이야기로 자연스럽게 연결

> 💡 파이썬은 컴파일이 필요 없고 한글 출력도 잘 돼서 입문 실습에 딱. `ord()`(문자→코드), `format(n,"08b")`(2진수), `format(n,"02X")`(16진수)만 알면 된다.
