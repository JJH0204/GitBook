# 1일차 · 네트워크 기본

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

패킷트레이서로 실습에 들어가기 전, 네트워크를 이해하는 데 필요한 **기초 용어와 개념**을 다지는 첫 시간.

## 🎯 오늘의 목표

- 네트워크 1·2 과정 전체 흐름과 취득 가능한 자격증을 안내한다
- **네트워크가 무엇인지** 일상 예시로 이해한다
- 컴퓨터가 0과 1로 소통하는 원리(Bit/Byte)와 문자 코드를 이해한다
- 데이터를 목적지에 보내기 위해 **주소(IP)**가 필요한 이유를 이해한다
- LAN/WAN과 네트워크 토폴로지의 종류·특징을 구분한다
- 프로토콜의 개념과 OSI 7계층의 각 역할을 설명한다
- 통신 방식(유니/브로드/멀티캐스트)의 차이를 구분한다
