# 네트워크 1 — 1단계 · 네트워크 기초와 구성

> 다음 단계: [네트워크 2](../network2/README.md)

*패킷트레이서와 리눅스를 활용한 네트워크 기초이론과 실습*

**도구:** Cisco 패킷트레이서 · **1~8일차**

## 회차별 노트

| 일차 | 주제 | 핵심 내용 |
|------|------|-----------|
| 1일차 | 네트워크 기본 | 자격증 소개, Bit/Byte, LAN/WAN, OSI 7계층, 캐스트 |
| 2일차 | IP와 서브넷 | IPv4/IPv6, IP 클래스, 서브넷 마스크, 서브넷팅 |
| 3일차 | 네트워크 장비와 토폴로지 | 허브/스위치/라우터, MAC/ARP/ICMP, PT 실습 |
| 4일차 | 스위치와 라우터 | 스위치·라우터 기본 동작 원리 |
| 5일차 | 라우팅 프로토콜 | 정적의 한계, 메트릭·AD, RIP / OSPF / EIGRP |
| 6일차 | 라우팅 프로토콜 심화 | 재분배(Redistribution), seed metric |
| 7일차 | 스위칭 심화 | VLAN, 트렁크, Router-on-a-stick, STP, EtherChannel |
| 8일차 | 네트워크 장비 서버 설정 | SSH, DHCP(릴레이), DNS, SNMP, Proxy, FTP, 포트 보안, 무선랜·IPv6 맛보기 |
