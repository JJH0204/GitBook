# 4일차 · 스위치와 라우터

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

3일차엔 장비가 **무엇인지**(계층·역할)를 봤다. → [3일차](../day-03/README.md)
오늘은 그 스위치·라우터가 **실제로 어떻게 동작하는지**(무엇을 보고 판단하고, 어떻게 표를 만드는지)를 파고든다.

## 🎯 오늘의 목표

- 스위치가 MAC 주소 테이블을 **학습**하고 프레임을 전달하는 원리를 이해한다
- **에이징**과 **루프 방지(STP)** 가 왜 필요한지 안다
- 라우터가 **라우팅 테이블**로 경로를 결정하는 원리를 이해한다
- `show ip route` 출력을 읽는다 (**코드 · AD · 메트릭**)
- Cisco IOS CLI 기본 모드와 명령으로 테이블을 직접 확인하고 **설정을 저장**한다
- **정적 경로를 설정해** 직접 연결되지 않은 네트워크를 잇는다
