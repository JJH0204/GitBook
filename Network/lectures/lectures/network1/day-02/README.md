# 2일차 · IP와 서브넷

> 1단계 · 네트워크 기초와 구성 — 상위: [네트워크 1](../README.md)

1일차에 "IP는 장치를 찾는 **주소**"라는 감을 잡았다. → [1일차: IP 주소](../day-01/lesson-4.md)
오늘은 그 주소를 **실제로 읽고, 구분하고, 나누는(서브넷팅)** 법을 배운다.

## 🎯 오늘의 목표

- IPv4 주소의 구조를 2진수로 이해하고, IPv6가 왜 필요한지 안다
- **8비트 자릿값 표**로 마스크 값을 읽고 쓴다 (128 64 32 16 8 4 2 1)
- IP 클래스(A/B/C)와 서브넷 마스크로 네트워크부/호스트부를 구분한다
- 공인 IP와 사설 IP의 차이, 집 공유기의 `192.168.x.x`를 이해한다
- **블록 크기(256 − 마스크)** 로 서브넷을 손으로 나누고, 호스트 수를 계산할 수 있다
- 두 IP가 **같은 네트워크인지 판별**해서 통신 가능 여부를 말할 수 있다
