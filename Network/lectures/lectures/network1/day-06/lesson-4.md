## Q1. 왜 통신이 안 되나 — [1_재분배란_무엇인가](lesson-1.md)

R2 runs **both RIP and OSPF**. R1 runs RIP only; R3 runs OSPF only.
All links are up and R2's routing table shows **every** network.
Still, a PC behind R1 cannot reach a PC behind R3. Why?
(R2 는 모든 경로를 아는데도 끝단끼리 통신이 안 된다. 왜?)

- A. R2 의 인터페이스가 down 상태여서
- B. **한 장비 안에 있어도 RIP 프로세스와 OSPF 프로세스는 서로 경로를 넘기지 않기 때문**
- C. AD 가 충돌해서 R2 가 경로를 버렸기 때문
- D. RIP 과 OSPF 는 같은 라우터에서 동시에 돌 수 없기 때문

{% hint style="success" %}
**정답 및 해설**

**정답: B**
- 프로토콜은 **자기 언어권하고만** 정보를 나눈다. **같은 장비 안이어도 마찬가지다** ⭐
- R2 는 왼쪽 소식도 알고 오른쪽 소식도 알지만, **옮겨주지 않는다** → **혼자만 안다**
- 그래서 R1 은 30.0 을, R3 은 10.0 을 **끝내 모른다** → 경로가 없으니 버린다
- D 가 오답인 이유: **동시에 돌 수 있다.** 오히려 그래야 재분배가 가능하다
- 통역사가 **가만히 있는 상태** — "통역해 주세요" 라고 시켜야 한다 = **재분배**
- 되짚기: **재분배 전 확인** 단계에서 세 라우터 테이블을 나란히 비교한 그 표
{% endhint %}

## Q2. 명령을 어디서 치나 — [2_재분배_원리와_주의점](lesson-2.md)

You want **RIP-learned routes to appear in OSPF**.
Under which process do you configure the `redistribute` command?
(RIP 경로를 OSPF 에 넣고 싶다. 어느 프로세스 안에서 설정하나?)

- A. `router rip` 안에서 `redistribute ospf 1`
- B. **`router ospf 1` 안에서 `redistribute rip subnets metric 20`**
- C. 전역 설정 모드에서 `redistribute rip into ospf`
- D. 인터페이스 설정 모드에서

{% hint style="success" %}
**정답 및 해설**

**정답: B**
- 공식: **"받는 집에 들어가서, 어디서 가져올지 말한다"**
- 넣고 싶은 곳 = **OSPF** → `router ospf 1` 로 들어간다
- 가져올 곳 = **RIP** → `redistribute rip`
- A 가 오답인 이유: 그건 **정반대 방향**(OSPF 경로를 RIP 에 넣기)이다
- ⚠️ **방향은 각각 설정한다.** 끝단끼리 ping 이 되려면 **두 줄이 다 필요**하다
  (라우팅은 왕복 — 4일차부터 계속 나온 그 원칙)
{% endhint %}

## Q3. 재분배했는데 왜 안 올까 ⭐ — [2_재분배_원리와_주의점](lesson-2.md)

An engineer configures `redistribute ospf 1` under `router rip`.
After waiting several minutes, the RIP routers still receive **nothing**.
What is the most likely cause?
(몇 분을 기다려도 RIP 쪽에 아무 경로도 오지 않는다. 가장 유력한 원인은?)

- A. OSPF 의 area 번호가 틀렸다
- B. **seed metric 을 지정하지 않아 무한대(∞)로 취급되어 광고되지 않는다**
- C. RIP 의 `version 2` 를 안 했다
- D. 재분배는 원래 몇 시간이 걸린다

{% hint style="success" %}
**정답 및 해설**

**정답: B**
- **RIP 과 EIGRP 는 seed metric 기본값이 무한대(∞)** — 즉 **도달 불가**
- 무한대인 경로는 **광고 자체를 하지 않는다** → 상대는 아무 소식도 못 받는다
- 해결: `redistribute ospf 1 metric 3` 또는 `default-metric 3`
- ⚠️ **비대칭에 주의**: **OSPF 는 기본값 20 이 있어서 안 줘도 동작한다.**
  "OSPF 쪽은 되던데요?" 가 여기서 나온다

| 받는 쪽 | 기본 seed metric | 지정 |
|---|---|---|
| RIP · EIGRP | **무한대(∞)** | ✅ 필수 |
| OSPF | 20 | 선택 |

- 되짚기: 실습에서 **일부러 메트릭 없이 쳐서** 실패를 본 그 장면
{% endhint %}

## Q4. 이 표시는 무슨 뜻인가 — [1_재분배란_무엇인가](lesson-1.md)

A router's table shows:
`O E2  192.168.10.0/24 [110/20] via 192.168.50.1`
What does **E2** tell you?
(`O E2` 의 `E2` 가 뜻하는 것은?)

- A. OSPF Area 2 에서 온 경로
- B. **OSPF 밖에서 재분배돼 들어온 외부 경로이며, 코스트가 seed metric 그대로 고정된다**
- C. 두 번째로 좋은 경로(백업)
- D. EIGRP 로 배운 경로

{% hint style="success" %}
**정답 및 해설**

**정답: B**
- **E = External.** OSPF 세상 **밖에서 재분배돼 들어온 손님**이라는 표식
- **2 = Type 2** → 코스트가 **seed metric 그대로**. 어느 라우터에서 봐도 **항상 20**
- **E1** 이면 **seed metric + 여기까지 오는 내부 코스트** → 위치마다 값이 다르다
- **기본값은 E2**
- A 가 오답인 이유: Area 는 `O IA`(Inter-Area) 로 따로 표시된다
- D 가 오답인 이유: EIGRP 외부 경로는 **`D EX`**
- 💡 경계 라우터가 **여러 곳**일 때 가까운 쪽을 고르려면 **E1** 이 유리하다
{% endhint %}

## Q5. 재분배가 왜 위험한가 — [2_재분배_원리와_주의점](lesson-2.md)

Two boundary routers perform **mutual redistribution** between RIP and OSPF.
What is the primary risk?
(경계 라우터 두 곳에서 상호 재분배를 했다. 가장 큰 위험은?)

- A. CPU 사용률이 100% 가 된다
- B. **경로가 한 도메인으로 나갔다가 다른 지점으로 되돌아와 라우팅 루프가 생길 수 있다**
- C. 라우터가 재부팅된다
- D. IP 주소가 중복된다

{% hint style="success" %}
**정답 및 해설**

**정답: B**
- 경계가 **한 곳**이면 나간 경로가 돌아올 길이 없다 → 안전
- 경계가 **두 곳 이상**이면, R2 로 나간 경로가 **R4 를 통해 되돌아온다**
- 되돌아온 경로가 **AD 가 낮아 보이면** 라우터가 그걸 믿는다 → **빙빙 돈다**
- 함께 오는 문제: **차선 경로**(seed metric 이 원래 거리를 지워버려 먼 길을 고름)
- 실무 3원칙: **① 재분배 지점 최소화 ② route-map 으로 필터 ③ `distance` 로 AD 조정**
  (②③ 은 CCNP 급 — 이름만 알아두면 충분)
- 되짚기: 실습에서 R1 이 30.0 과 50.0 을 **똑같이 `[120/3]`** 으로 본 그 화면이
  바로 **거리 정보가 사라진** 증거
{% endhint %}

## 📝 강의 메모

- Q1(왜 필요) → Q2(어디서) → Q3(왜 실패) → Q4(표시 읽기) → Q5(위험) — **오늘 흐름 그대로**
- **Q3 이 오늘의 최중요 문제.** 실습에서 직접 실패를 겪었으므로 정답률이 높다 →
  자신감을 주고, **RIP/EIGRP ↔ OSPF 의 비대칭**을 한 번 더 각인
- Q2 는 **"받는 집에 들어가서"** 구호를 학생이 소리 내어 말하게 할 것
- Q4 는 실제 출력 한 줄을 화면에 띄워놓고 **손가락으로 짚어가며** 읽힐 것
- Q5 는 그림(경계 라우터 2곳)을 칠판에 그려야 이해가 빠르다
- **4~6일차 라우팅 3부작이 오늘로 끝난다.** 마무리에 한 번 되짚어줄 것
  1. 4일차 — **손으로** 길을 넣는다 (정적)
  2. 5일차 — **라우터끼리** 알아서 채운다 (동적)
  3. 6일차 — **말이 다른 구역**을 잇는다 (재분배)
- 다음 예고: **"라우터는 끝났다. 이제 꽂기만 했던 스위치를 제대로 다뤄봅시다"** → [7일차](../day-07/README.md)
