10일차에 우리는 **계속 열기만 했다.** SSH 22번 · 연습용 웹서버 8000번 · FTP 21번.
오늘은 먼저 그 모든 것(DHCP · DNS · NAT · 포트포워딩)을 **한 상자에 담은 공유기**로 정리한 뒤,
**"열린 문에 아무나 들어오면?"** → **ACL · 방화벽**으로 넘어간다. **처음으로 닫는 날**이다.

| 질문 | 오늘의 답 | 노트 |
|------|-----------|------|
| 집 공유기 한 상자에 뭐가 들어 있나? | 라우터 + NAT + 스위치 + DHCP | 1 |
| 내 서버는 지금 **누구에게 열려 있나**? | **브릿지** — 교실 전체 ⚠️ | 3 |
| 라우터에서 **누구를** 막나? | **표준 ACL** (출발지만) | 4 |
| 라우터에서 **무엇을** 막나? | **확장 ACL** (목적지 + 포트) | 5 |
| 라우터가 없는 우리 교실은? | **`ufw`** — 서버 자신의 문지기 ⭐ | 6 |
| 그래서 **몇 개를** 열어야 하나? | 최소 개방 설계 — 종이 먼저 | 7 |
| 안 되면 **어디를** 보나? | 네 단계로 좁히기 | 8 |

## 🎯 오늘의 목표

**이월 — 공유기**
- **집 공유기 = 라우터 + NAT + 스위치 + DHCP** 가 한 상자에 들어 있음을 이해한다
- 패킷트레이서로 **공유기 네트워크(유선)** 를 만들고 **NAT 변환을 시뮬레이션으로 확인**한다
- **밖에서 먼저는 들어올 수 없다**는 것을 확인하고, 그것이 **NAT 의 부수 효과**임을 안다

**서버 보안**
- **공격 표면**이 무엇인지 알고, `ss -tuln` 으로 내 서버의 표면을 센다
- **최소 권한 · 기본 거부(default deny)** 를 설명한다
- **표준 / 확장 ACL** 을 작성하고 적용하며, **암묵적 deny any** 를 실패로 확인한다
- **`ufw`** 로 포트를 열고 닫고, **`enable` 전에 22번을 먼저 여는 이유**를 안다 ⚠️
- 통신이 안 될 때 **① LISTEN → ② 로컬 → ③ 방화벽 → ④ 경로** 순으로 좁힌다

## 📝 강의 메모

- 10일차에 **DNS · DHCP(10번)** 를 못 했으면 공유기 실습 **앞에** 붙인다
- 📌 **무선랜 제외**: WRT300N 을 쓰되 **Wireless 탭은 건너뛴다.** Laptop · Smartphone 도 놓지 않는다
- 📌 WRT300N GUI 는 PT 버전마다 조금 다르다 → **수업 전 리허설**, 특히 **Static DNS** 칸 위치와 **포트포워딩 메뉴**
- ⭐ **오늘의 수미상관**: 3번에서 **"옆자리가 내 서버에 들어온다"** 를 보여 주고, 6번에서 **"이제 못 들어온다"** 로 닫는다
- 🚨 **`ufw enable` 순서 함정**은 미리 경고 + 복구 경로를 칠판에 적어 둘 것
  → **VirtualBox 창 → 로그인 → `sudo ufw disable`**
- 🚨 **마무리 체크리스트**를 반드시 같이 실행 — 특히 **`sudo ufw allow 22/tcp`**. 안 하면 다음 주에 아무도 못 들어온다
- **12일차로 넘길 상태**: 방화벽을 **켜 둔 채로** 끝낸다 → 12일차 6단계의 **⑤ 개방(`ufw allow`)** 이 실감 난다
- 📌 발표용 Excalidraw 드로잉은 **아직 없다** (3층 방어 · 네 단계 좁히기는 판서)
