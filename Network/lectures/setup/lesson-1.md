# 파이썬 · VS Code 환경 구축 (Windows 기준)

> 상위: [실습 환경 구축](README.md)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | LEC-NS-00-001-MP |
| 목적 | Windows PC에 파이썬과 VS Code를 설치하고, VS Code의 ▶ 버튼으로 파이썬 파일을 실행할 수 있게 한다 |
| 적용 대상 | Windows 10/11, 파이썬 3.10 이상, VS Code, 인터넷 연결 |
| 소요 시간 | 약 10분 |
| 확인 상태 | 미검증 (원본 안내를 정리한 것이며 이번 재작성에서 설치해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 파이썬을 배우는 시간이 아니다. 손으로 계산한 결과를 눈으로 즉시 확인하는 도구로만 쓴다. 코드를 이해할 필요는 없고, ▶ 버튼을 눌러 실행할 수 있으면 충분하다.
{% endhint %}

## 2. 필요 장비와 자재

| 번호 | 이름 | 사양·버전 | 비고 |
|---|---|---|---|
| 1 | Windows PC | Windows 10/11 | 설치 권한이 있는 계정 |
| 2 | 파이썬 설치 파일 | 3.10 이상 | <https://www.python.org/downloads/> |
| 3 | VS Code 설치 파일 | 최신판 | <https://code.visualstudio.com/> |
| 4 | 강의 자료 폴더 | | 5-E에서 연다 |

이 강의의 코드는 표준 라이브러리(`ipaddress`)만 쓴다. 추가로 설치할 패키지(`pip install ...`)는 없다.

## 3. 안전 사항

{% hint style="danger" %}
WARNING: 설치 파일 첫 화면의 `Add python.exe to PATH` 체크박스를 반드시 켠다. 여기서 90%의 사고가 난다. 체크하지 않으면 터미널에서 `python` 명령을 찾지 못한다.
{% endhint %}

{% hint style="warning" %}
CAUTION: VS Code의 Code Runner 확장은 설치하지 않는다. 편해 보이지만 한글이 깨지고 `tempCodeRunnerFile.py` 같은 임시 파일을 만든다. Python 확장의 ▶ 버튼만 쓴다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | 설치 권한이 있다 | 관리자 계정 잠금이 아니다. 잠겨 있으면 강의장 관리자에게 사전 요청한다 |
| 2 | 인터넷에 접속된다 | 브라우저로 두 사이트가 열린다 |

## 5. 절차

전체 순서는 다음과 같다.

```
① 파이썬 설치        ② 설치 확인       ③ VS Code 설치
   (PATH 체크)          python --version

④ Python 확장 설치   ⑤ 강의 폴더 열기   ⑥ ▶ 눌러 실행
```

### A. 파이썬 설치

1. (5-A-01) <https://www.python.org/downloads/>를 연다. → 결과: `Download Python 3.x.x` 노란 버튼이 보인다.
2. (5-A-02) 버튼을 눌러 설치 파일을 내려받고 실행한다. → 결과: 설치 창이 열린다.
3. (5-A-03) 첫 화면 맨 아래의 `Add python.exe to PATH`를 체크한다. → 결과: 체크 표시가 보인다.
4. (5-A-04) `Install Now`를 누른다. → 결과: 설치가 끝나고 `Setup was successful`이 보인다.

버전은 3.10 이상이면 어느 것이든 된다.

{% hint style="info" %}
NOTE: PATH를 체크하지 않고 설치했다면 설치 파일을 다시 실행해 `Modify`를 누르고 `Add to environment variables`를 켠다. 또는 제거 후 재설치한다.
{% endhint %}

### B. 설치 확인

1. (5-B-01) `Win + R`을 누르고 `cmd`를 입력해 명령 프롬프트를 연다.
2. (5-B-02) 다음을 입력한다: `python --version` → 결과: `Python 3.13.x`처럼 버전이 나온다.

| 결과 | 상태 |
|---|---|
| `Python 3.13.x`처럼 버전이 나온다 | 정상 |
| `'python'은(는) 내부 또는 외부 명령...` | PATH 미설정. 5-A-03을 다시 한다 |
| Microsoft Store 창이 열린다 | Windows의 "앱 실행 별칭"이 가로챈 것이다. 아래 NOTE를 따른다 |

{% hint style="info" %}
NOTE: Microsoft Store가 열리면 `설정 > 앱 > 고급 앱 설정 > 앱 실행 별칭`에서 `python.exe`와 `python3.exe`를 끔으로 바꾼다.
{% endhint %}

### C. VS Code 설치

1. (5-C-01) <https://code.visualstudio.com/>를 열고 `Download for Windows`를 누른다. → 결과: 설치 파일이 내려받아진다.
2. (5-C-02) 설치 파일을 실행한다. 설치 중 `Code(으)로 열기 작업을 Windows 탐색기 파일/디렉터리 상황에 맞는 메뉴에 추가` 두 항목을 체크하면 편하다.
3. (5-C-03) 설치 후 VS Code를 실행한다. → 결과: VS Code 창이 열린다.

### D. Python 확장 설치

1. (5-D-01) 왼쪽 세로 막대에서 네모 4개 아이콘(확장, `Ctrl+Shift+X`)을 누른다. → 결과: 확장 목록이 열린다.
2. (5-D-02) `Python`을 검색해 Microsoft가 만든 것을 설치한다. → 결과: 파란 체크 표시가 보이고 `설치됨`으로 바뀐다.
3. (5-D-03) (선택) `Korean Language Pack`을 설치한다. → 결과: 메뉴가 한글로 바뀐다.

### E. 강의 폴더 열기

파일 하나가 아니라 폴더를 연다. VS Code는 폴더 단위로 동작한다.

1. (5-E-01) `파일 > 폴더 열기`에서 강의 자료 폴더를 고른다.
2. (5-E-02) "이 폴더에 있는 파일 작성자를 신뢰합니까?"에서 `예, 신뢰합니다`를 누른다. → 결과: 왼쪽 탐색기에 폴더의 파일이 보인다.

### F. 실행

1. (5-F-01) 왼쪽 탐색기에서 실행할 파일을 누른다(예: `subnet_calc.py`).
2. (5-F-02) 오른쪽 위 ▶(Run Python File) 버튼을 누른다. → 결과: 아래쪽 터미널 창에 결과가 나온다.
3. (5-F-03) 입력을 요구하면 터미널을 클릭한 뒤 값을 입력하고 `Enter`를 누른다. → 결과: 계산 결과가 출력된다.

{% hint style="info" %}
NOTE: 입력이 안 먹는다고 하는 학생 대부분은 터미널을 클릭하지 않은 것이다.
{% endhint %}

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `python --version` | `Python 3.x.x` | 3.10 이상이다 |
| 2 | VS Code에서 `ascii_convert.py` 실행 | 터미널에 결과 출력 | 오류 없이 끝난다 |

## 7. 복구

설치가 실패했을 때의 조치는 다음과 같다.

| 증상 | 원인 | 해결 |
|---|---|---|
| `'python'은(는) 내부 또는 외부 명령...` | PATH 미설정 | 설치 파일 실행 후 `Modify`, `Add to environment variables` |
| Microsoft Store가 열린다 | 앱 실행 별칭 | `설정 > 앱 > 고급 앱 설정 > 앱 실행 별칭`에서 python 끔 |
| ▶ 버튼이 보이지 않는다 | Python 확장 없음 | 5-D를 다시 한다 |
| 터미널에 한글이 `???`로 깨진다 | 콘솔 인코딩 | 터미널에 `chcp 65001`을 입력하고 다시 실행한다 |
| 입력해도 반응이 없다 | 터미널에 포커스 없음 | 터미널 영역을 클릭하고 입력한다 |
| 인터프리터를 찾지 못한다 | 선택 안 됨 | `Ctrl+Shift+P`, `Python: Select Interpreter`, 3.x 선택 |
| 파일을 저장하지 않고 실행했다 | 제목 옆 ●가 미저장 표시이다 | `Ctrl+S` 후 실행한다 |

한글 깨짐이 계속되면 VS Code 설정(`Ctrl+,`)의 `terminal.integrated.profiles` 대신, 터미널에서 매번 `chcp 65001`을 한 번 실행한다. 그 세션 동안 UTF-8로 동작한다.

설치를 되돌리려면 `설정 > 앱 > 설치된 앱`에서 Python과 Visual Studio Code를 제거한다.

## 강사 사전 점검

- [ ] 강의장 PC에 설치 권한이 있는지 미리 확인한다(관리자 계정 잠금이면 설치 자체가 불가능하다).
- [ ] 인터넷 차단 환경에 대비해 설치 파일(python, VS Code)을 USB에 미리 준비한다.
- [ ] 1일차 시작 전에 PC 1대에서 처음부터 끝까지 리허설한다(특히 PATH와 앱 실행 별칭).
- [ ] 설치가 끝난 학생은 `ascii_convert.py`를 돌려 동작 확인까지 시킨다.
- [ ] 설치가 안 되는 학생 대비로 강사 화면 시연으로 대체할 수 있게 준비한다(실습이 목적이 아니라 확인이 목적이다).
- [ ] `tempCodeRunnerFile.py` 같은 임시 파일이 생기면 삭제한다(Code Runner 확장 흔적).

설치는 1일차 3번 노트(문자 코드) 실습 직전에 하는 것이 자연스럽다. 파이썬 문법 설명은 하지 않는다. "계산기를 쓴다"는 감각으로 접근한다. 2일차 `subnet_calc.py`에서 다시 쓰므로, 1일차에 확실히 세팅해 두면 이후가 편하다.
