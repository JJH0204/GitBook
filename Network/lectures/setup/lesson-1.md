# 파이썬 · VS Code 환경 구축 (Windows 기준)

> 상위: [실습 환경 구축](README.md)

**언제 필요한가**: 1일차 [문자 코드 변환 실습](../network1/day-01/lesson-3.md)(`ascii_convert.py`), 2일차 [서브넷 계산 실습](../network1/day-02/lesson-4.md)(`subnet_calc.py`)

> 💡 **파이썬을 배우는 시간이 아니다.** 손으로 계산한 결과를 **눈으로 즉시 확인**하는 도구로만 쓴다.
> 코드를 이해할 필요는 없고, **▶ 버튼을 눌러 실행할 수 있으면 충분**하다.

---

## ✅ 전체 순서 (10분)

```
① 파이썬 설치        ② 설치 확인       ③ VS Code 설치
   (PATH 체크!)         python --version

④ Python 확장 설치   ⑤ 강의 폴더 열기   ⑥ ▶ 눌러 실행
```

---

## ① 파이썬 설치

1. <https://www.python.org/downloads/> 접속 → **Download Python 3.x.x** (노란 버튼)
2. 내려받은 설치 파일 실행
3. 🚨 **첫 화면 맨 아래 `Add python.exe to PATH` 체크박스를 반드시 켠다**
4. **Install Now** 클릭 → 완료

> ⚠️ **여기서 90%의 사고가 난다.** PATH를 체크하지 않으면 터미널에서 `python` 명령을 못 찾는다.
> 이미 체크 없이 설치했다면 → 설치 파일을 다시 실행 → **Modify** → **Add to environment variables** 켜기
> (또는 제거 후 재설치)

### 버전은?

- **3.10 이상이면 무엇이든 OK.** 이 강의의 코드는 표준 라이브러리(`ipaddress`)만 쓴다
- 추가로 설치할 패키지(`pip install ...`)는 **하나도 없다**

## ② 설치 확인

`Win + R` → `cmd` → 아래 입력:

```bash
python --version
```

| 결과 | 상태 |
|------|------|
| `Python 3.13.x` 처럼 버전이 나옴 | ✅ 정상 |
| `'python'은(는) 내부 또는 외부 명령...` | ❌ PATH 미설정 → ①의 🚨로 |
| **Microsoft Store 창이 열림** | ❌ 아래 참고 |

> ⚠️ **Microsoft Store가 열리는 경우** — 윈도우의 "앱 실행 별칭"이 가로채는 것이다.
> `설정` → `앱` → `고급 앱 설정` → **앱 실행 별칭** → `python.exe`, `python3.exe`를 **끔**으로

## ③ VS Code 설치

1. <https://code.visualstudio.com/> → **Download for Windows**
2. 설치 중 **"Code(으)로 열기 작업을 Windows 탐색기 파일/디렉터리 상황에 맞는 메뉴에 추가"** 두 개를 체크하면 편하다
3. 설치 후 실행

## ④ Python 확장 설치

1. VS Code 왼쪽 세로 막대에서 **네모 4개 아이콘**(확장, `Ctrl+Shift+X`) 클릭
2. `Python` 검색 → **Microsoft**가 만든 것 설치 (파란 체크 표시)
3. (선택) `Korean Language Pack` 설치 → 메뉴가 한글로 바뀐다

> 💡 **Code Runner 확장은 설치하지 않는다.** 편해 보이지만 한글이 깨지고 `tempCodeRunnerFile.py` 같은
> 임시 파일을 만든다. Python 확장의 **▶ 버튼**만 쓰면 된다.

## ⑤ 강의 폴더 열기

**파일 하나가 아니라 폴더를 연다.** (VS Code는 폴더 단위로 동작한다)

- `파일` → `폴더 열기` → 강의 자료 폴더 선택
- "이 폴더에 있는 파일 작성자를 신뢰합니까?" → **예, 신뢰합니다**

## ⑥ 실행

1. 왼쪽 탐색기에서 실행할 파일 클릭 (예: `subnet_calc.py`)
2. 오른쪽 위 **▶ (Run Python File)** 버튼 클릭
3. 아래쪽 **터미널** 창에 결과가 나온다
4. 입력을 요구하면 **터미널을 클릭한 뒤** 값을 타이핑하고 `Enter`

> 💡 입력이 안 먹는다고 하는 학생 대부분은 **터미널을 클릭하지 않은 것**이다.

## 🔧 자주 나는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| `'python'은(는) 내부 또는 외부 명령...` | PATH 미설정 | 설치 파일 → Modify → Add to environment variables |
| Microsoft Store가 열림 | 앱 실행 별칭 | 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭 → python 끄기 |
| ▶ 버튼이 안 보임 | Python 확장 없음 | ④ 다시 |
| 터미널에 한글이 `???`로 깨짐 | 콘솔 인코딩 | 터미널에 `chcp 65001` 입력 후 다시 실행 |
| 입력해도 반응 없음 | 터미널에 포커스 없음 | 터미널 영역을 **클릭**하고 입력 |
| 인터프리터를 못 찾음 | 선택 안 됨 | `Ctrl+Shift+P` → `Python: Select Interpreter` → 3.x 선택 |
| 파일을 저장 안 하고 실행 | — | `Ctrl+S` 후 실행 (제목 옆 ● 표시 = 미저장) |

### 한글 깨짐이 계속되면

VS Code 설정(`Ctrl+,`)에서 `terminal.integrated.profiles` 대신, 간단히 터미널에서 매번:

```bash
chcp 65001
```

를 한 번 실행하면 그 세션 동안 UTF-8로 동작한다.

## 🏫 강사용 사전 체크리스트

- [ ] **강의장 PC에 설치 권한이 있는지** 미리 확인 (관리자 계정 잠금이면 설치 자체가 불가)
- [ ] 인터넷 차단 환경 대비 → **설치 파일(python, VS Code)을 USB에 미리 준비**
- [ ] 1일차 시작 전 **PC 1대에서 처음부터 끝까지 리허설** (특히 PATH·앱 실행 별칭)
- [ ] 설치가 끝난 학생은 `ascii_convert.py`를 돌려 **동작 확인까지** 시키기
- [ ] 설치가 안 되는 학생 대비 → **강사 화면 시연으로 대체 가능**하도록 준비 (실습이 목적이 아니라 확인이 목적)
- [ ] `tempCodeRunnerFile.py` 같은 임시 파일이 생기면 삭제 (Code Runner 확장 흔적)

## 📝 메모

- 설치는 **1일차 3번 노트(문자 코드) 실습 직전**에 하는 것이 자연스럽다
- 파이썬 문법 설명은 하지 않는다 — "계산기를 쓴다"는 감각으로
- 2일차 `subnet_calc.py`에서 다시 쓰므로, 1일차에 확실히 세팅해두면 이후가 편하다
