# 실습 환경 구축

> 상위: [강의 (Lectures)](../README.md)

강의에서 쓰는 도구의 설치와 환경 구축 방법을 모아 둔 곳이다. 회차별 강의 노트에서 필요할 때 여기로 링크한다.

## 문서 목록과 읽는 순서

설치 안내는 해당 도구를 처음 쓰는 회차 직전에 한다. 미리 다 설치하게 하면 잊어버린다.

| 순서 | Task ID | 유형 | 문서 | 용도 | 쓰는 회차 |
|---|---|---|---|---|---|
| 1 | LEC-NS-00-001-MP | MP | [파이썬 · VS Code 환경 구축 (Windows 기준)](lesson-1.md) | 파이썬과 VS Code 설치, 실행 확인. 추가 패키지 없음 | 1일차(문자 코드), 2일차(서브넷 계산) |
| 2 | LEC-NS-00-002-MP | MP | [패킷트레이서 설치와 계정 만들기](lesson-2.md) | netacad 계정 가입, Packet Tracer 설치와 로그인 | 3~8일차 실습 전부 |

{% hint style="warning" %}
CAUTION: 패킷트레이서는 무료 계정 가입이 필요하다. 2일차 수업 끝에 미리 공지한다.
{% endhint %}
