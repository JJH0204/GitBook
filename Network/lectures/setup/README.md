# 🛠 실습 환경 구축

강의에서 쓰는 도구의 **설치·환경 구축 방법**을 모아둔 곳. 회차별 강의 노트에서 필요할 때 여기로 링크한다.

## 📑 목록

| 문서 | 쓰는 회차 | 비고 |
|------|----------|------|
| 파이썬 · VS Code 설치 | **1일차**(문자 코드), **2일차**(서브넷 계산) | Windows 기준 · 추가 패키지 없음 |
| 패킷트레이서 설치와 계정 만들기 | **3~8일차** 실습 전부 | 🚨 **무료 계정 가입 필요** → 2일차에 미리 공지 |

## 🗓 앞으로 추가할 것

- [ ] **VirtualBox + 우분투** / **WSL** (9일차부터)
- [ ] **Docker** (2단계 후반)
- [ ] 네이버 클라우드 계정

## 📝 메모

- 설치 안내는 **해당 도구를 처음 쓰는 회차 직전**에 배치 (미리 다 깔게 하면 잊어버린다)
- 강의장 PC 설치 권한 · 인터넷 차단 여부는 **매 회차 전 확인**
