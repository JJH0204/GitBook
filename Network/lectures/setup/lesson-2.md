# 패킷트레이서 설치와 계정 만들기

> 상위: [실습 환경 구축](README.md)

**언제 필요한가**: **3일차부터 8일차까지** 1단계 실습 전부
→ 첫 사용은 [3일차 실습](../network1/day-03/lesson-4.md)

> 🚨 **미리 안내해야 하는 도구다.** 파이썬과 달리 **무료 계정 가입이 필요**하고,
> 가입 → 메일 인증 → 다운로드까지 시간이 걸린다. **2일차 수업 끝에 미리 공지**할 것.

---

## ✅ 전체 순서

```
① Cisco Networking Academy 무료 계정 만들기
② 메일 인증
③ Packet Tracer 입문 코스 등록 (무료)
④ 설치 파일 내려받기 → 설치
⑤ 처음 실행 시 그 계정으로 로그인
```

## ① ~ ③ 계정과 코스

1. **<https://www.netacad.com>** 접속
2. 계정이 없으면 **회원가입**(무료) → 가입한 메일로 온 **인증 링크** 클릭
3. 사이트에서 **Packet Tracer** 를 검색해 **입문 코스**(Getting Started with Cisco Packet Tracer 등)에 **등록**
   - 이 코스에 등록해야 다운로드 페이지가 열린다
   - 코스를 수료할 필요는 없다. **등록만** 하면 된다

> ⚠️ 시스코 사이트는 개편이 잦다. 메뉴 이름이 노트와 다르면 **"Packet Tracer" 로 검색** → **Download** 를 찾으면 된다.

## ④ 내려받기 · 설치

> 🔗 **바로가기**: <https://www.netacad.com/resources/lab-downloads?courseLang=en-US>
> (로그인한 상태여야 목록이 보인다)

- 코스 안의 **Download Packet Tracer** 또는 위 다운로드 페이지에서 내 OS에 맞는 파일 선택
  - **Windows 64bit** 를 고르면 된다 (요즘 PC는 대부분 64bit)
- 내려받은 설치 파일 실행 → 기본값으로 **Next** 진행
- 설치 후 **재부팅**을 요구하면 해준다

## ⑤ 첫 실행 — 로그인

- 처음 실행하면 로그인 화면이 뜬다 → **①에서 만든 netacad 계정**으로 로그인
- 로그인하지 않으면 **게스트 모드**로 쓸 수 있지만
  - 저장 횟수가 제한되고, 일정 횟수 뒤에는 다시 로그인을 요구한다
  - **수업에서는 반드시 로그인해서 쓰자** (실습 파일을 계속 저장해야 하므로)

## 🔧 자주 나는 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| 다운로드 링크가 안 보임 | 코스 **등록**을 안 함 | 입문 코스에 등록 후 다시 접속 |
| 인증 메일이 안 옴 | 스팸함 / 오타 | 스팸함 확인 → 재발송 |
| 로그인이 안 됨 | 메일 인증 미완료 | 인증 링크부터 클릭 |
| 실행하면 로그인만 반복 | 게스트 사용 횟수 초과 | 계정으로 로그인 |
| 설치는 됐는데 실행이 안 됨 | 구버전 잔재 · 권한 | 제거 후 재설치, 관리자 권한으로 실행 |
| 회사·학원 PC에서 설치 불가 | 관리자 권한 없음 | 강의장 관리자에게 사전 요청 |

> → [복습 실습 Lab 1 — 화면 익히기](../network1/day-03/lesson-0.md)

## 🏫 강사용 사전 체크리스트

- [ ] **2일차 수업 끝에 가입을 미리 공지** (당일에 하면 30분이 날아간다)
- [ ] 강의장 PC의 **설치 권한** 확인 — 없으면 관리자에게 사전 요청
- [ ] 강의장 네트워크에서 netacad.com 접속·다운로드가 **막혀 있지 않은지** 확인
- [ ] 설치 파일을 **USB에 미리 준비** (인터넷 차단·저속 대비)
- [ ] 설치 못 한 학생 대비 → **2인 1조** 또는 강사 화면 시연으로 진행 가능하게
- [ ] 3일차 완성본 `.pkt` 을 강사가 미리 만들어 두기 (막힌 학생에게 배포용)

## 📝 메모

- 계정 가입이 최대 걸림돌이다 → **미리, 반복해서** 공지
- 버전 차이로 **라우터 모델과 인터페이스 이름**(`G0/0` vs `G0/0/0`)이 다를 수 있다
  → 실습에서는 `show ip interface brief` 로 확인하게 지도
- 4일차 이후 CLI 실습도 같은 프로그램을 계속 쓴다 → 3일차에 확실히 세팅
