## 3. 안전 사항

{% hint style="warning" %}
CAUTION: 로그인하지 않으면 게스트 모드로 쓸 수 있지만 저장 횟수가 제한되고, 일정 횟수 뒤에는 다시 로그인을 요구한다. 수업에서는 반드시 로그인해서 쓴다. 실습 파일을 계속 저장해야 한다.
{% endhint %}

{% hint style="info" %}
NOTE: 시스코 사이트는 개편이 잦다. 메뉴 이름이 이 문서와 다르면 `Packet Tracer`로 검색해 `Download`를 찾는다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | 설치 권한이 있다 | 회사나 학원 PC라면 관리자에게 사전 요청한다 |
| 2 | 메일을 확인할 수 있다 | 받은편지함이 열린다 |
| 3 | 사이트에 접속된다 | <https://www.netacad.com>이 열린다 |

## 5. 절차

전체 순서는 다음과 같다.

```
① Cisco Networking Academy 무료 계정 만들기
② 메일 인증
③ Packet Tracer 입문 코스 등록 (무료)
④ 설치 파일 내려받기 → 설치
⑤ 처음 실행 시 그 계정으로 로그인
```

### A. 계정과 코스

1. (5-A-01) <https://www.netacad.com>을 연다. → 결과: 사이트 첫 화면이 보인다.
2. (5-A-02) 계정이 없으면 회원가입(무료)을 한다. → 결과: 가입한 메일로 인증 링크가 온다.
3. (5-A-03) 메일의 인증 링크를 누른다. → 결과: 인증 완료 화면이 보인다.
4. (5-A-04) 사이트에서 `Packet Tracer`를 검색해 입문 코스(Getting Started with Cisco Packet Tracer 등)에 등록한다. → 결과: 코스가 내 목록에 보인다.

{% hint style="info" %}
NOTE: 이 코스에 등록해야 다운로드 페이지가 열린다. 코스를 수료할 필요는 없다. 등록만 하면 된다.
{% endhint %}

### B. 내려받기와 설치

바로가기: <https://www.netacad.com/resources/lab-downloads?courseLang=en-US>. 로그인한 상태여야 목록이 보인다.

1. (5-B-01) 코스 안의 `Download Packet Tracer` 또는 위 다운로드 페이지를 연다. → 결과: OS별 설치 파일 목록이 보인다.
2. (5-B-02) `Windows 64bit` 파일을 내려받는다(요즘 PC는 대부분 64bit이다). → 결과: 설치 파일이 내려받아진다.
3. (5-B-03) 설치 파일을 실행하고 기본값으로 `Next`를 눌러 진행한다. → 결과: 설치가 끝난다.
4. (5-B-04) 재부팅을 요구하면 재부팅한다.

### C. 첫 실행과 로그인

1. (5-C-01) Packet Tracer를 처음 실행한다. → 결과: 로그인 화면이 뜬다.
2. (5-C-02) 5-A에서 만든 netacad 계정으로 로그인한다. → 결과: 메인 화면이 열린다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | Packet Tracer 실행 | 로그인 상태로 메인 화면이 열린다 | 게스트 표시가 없다 |
| 2 | 새 프로젝트 만들기, 저장 | 저장이 된다 | 저장 횟수 제한 안내가 나오지 않는다 |
| 3 | 라우터의 인터페이스 이름 확인(`show ip interface brief`) | 인터페이스 목록 | `G0/0`인지 `G0/0/0`인지 기록한다 |

{% hint style="info" %}
NOTE: 버전 차이로 라우터 모델과 인터페이스 이름(`G0/0`과 `G0/0/0`)이 다를 수 있다. 실습에서는 `show ip interface brief`로 확인하게 지도한다. 4일차 이후 CLI 실습도 같은 프로그램을 계속 쓴다.
{% endhint %}

## 7. 복구

설치가 실패했을 때의 조치는 다음과 같다.

| 증상 | 원인 | 해결 |
|---|---|---|
| 다운로드 링크가 보이지 않는다 | 코스 등록을 하지 않았다 | 입문 코스에 등록한 뒤 다시 접속한다 |
| 인증 메일이 오지 않는다 | 스팸함 또는 오타 | 스팸함을 확인하고 재발송한다 |
| 로그인이 안 된다 | 메일 인증 미완료 | 인증 링크부터 누른다 |
| 실행하면 로그인만 반복된다 | 게스트 사용 횟수 초과 | 계정으로 로그인한다 |
| 설치는 됐는데 실행이 안 된다 | 구버전 잔재 또는 권한 | 제거 후 재설치하고 관리자 권한으로 실행한다 |
| 회사나 학원 PC에서 설치할 수 없다 | 관리자 권한 없음 | 강의장 관리자에게 사전 요청한다 |

설치를 되돌리려면 `설정 > 앱 > 설치된 앱`에서 Cisco Packet Tracer를 제거한다.

## 강사 사전 점검

- [ ] 2일차 수업 끝에 가입을 미리 공지한다(당일에 하면 30분이 날아간다).
- [ ] 강의장 PC의 설치 권한을 확인한다. 없으면 관리자에게 사전 요청한다.
- [ ] 강의장 네트워크에서 netacad.com 접속과 다운로드가 막혀 있지 않은지 확인한다.
- [ ] 설치 파일을 USB에 미리 준비한다(인터넷 차단과 저속에 대비한다).
- [ ] 설치하지 못한 학생 대비로 2인 1조 또는 강사 화면 시연으로 진행할 수 있게 한다.
- [ ] 3일차 완성본 `.pkt`를 강사가 미리 만들어 둔다(막힌 학생에게 배포한다).

계정 가입이 최대 걸림돌이다. 미리, 반복해서 공지한다. 4일차 이후 CLI 실습도 같은 프로그램을 계속 쓰므로 3일차에 확실히 세팅한다.
