## 1. 목적

NAT(Network Address Translation)는 라우터를 지나는 IP 패킷의 출발지·목적지 IP 주소와 TCP/UDP 포트 번호를 다시 써서, 사설 주소를 쓰는 호스트가 공인망(인터넷)과 통신하게 하는 기술이다. IPv4 주소 부족을 완화하려고 고안됐다. 하나의 공인 IP 주소를 여러 사설 호스트가 나눠 쓸 수 있다.

## 2. 구성 요소

### 2.1 NAT 종류

| 번호 | 종류 | 변환 방식 | 용도 |
|---|---|---|---|
| 1 | 정적 NAT | 사설 IP 하나를 공인 IP 하나에 고정으로 1:1 대응시킨다 | 외부에 공개하는 서버 |
| 2 | 동적 NAT | 공인 IP 풀(pool)에서 비어 있는 주소를 골라 1:1로 임시 대응시킨다 | 공인 IP가 여러 개일 때 |
| 3 | PAT(Port Address Translation) | 하나의 공인 IP를 여러 호스트가 공유하고 포트 번호로 구분한다. 오버로드(overload) 또는 NAPT라고도 한다 | 가정과 소규모 사무실의 공유기 |

### 2.2 장점과 단점

| 구분 | 내용 |
|---|---|
| 장점 | 인터넷의 공인 IP를 절약한다 |
| 장점 | 내부 주소를 외부에 드러내지 않는다 |
| 단점 | 호스트 간 통신이 복잡해진다. 외부에서 내부 호스트로 먼저 연결하기 어렵다 |
| 단점 | 변환 과정 때문에 네트워크 성능에 영향을 줄 수 있다 |

### 2.3 보안에 관한 주의

{% hint style="warning" %}
CAUTION: NAT는 주소를 바꾸는 기술이지 방화벽이 아니다. 외부가 먼저 시작한 연결이 변환 표에 없어서 막히는 부수 효과는 있으나, 보호는 방화벽 규칙으로 구성한다.
{% endhint %}

## 3. 동작 원리: PAT 변환 표 예

구성: 내부망 `192.168.10.0/24`, 라우터의 외부 인터페이스 공인 IP `203.0.113.5`(문서용 주소), 외부 서버 `198.51.100.20`.

1. 내부 PC가 외부 서버로 패킷을 보낸다.
2. 라우터가 출발지 주소와 포트를 공인 주소와 새 포트로 바꾸고 변환 표에 기록한다.
3. 외부 서버가 바뀐 주소로 응답한다.
4. 라우터가 변환 표를 보고 목적지를 원래 내부 주소와 포트로 되돌려 전달한다.

변환 표(라우터 내부):

| 내부 주소:포트 | 변환된 주소:포트 | 목적지 |
|---|---|---|
| `192.168.10.10:50001` | `203.0.113.5:40001` | `198.51.100.20:443` |
| `192.168.10.11:50001` | `203.0.113.5:40002` | `198.51.100.20:443` |
| `192.168.10.12:51234` | `203.0.113.5:40003` | `198.51.100.20:80` |

두 내부 PC가 같은 포트 `50001`을 써도 변환 후 포트가 다르므로(`40001`, `40002`) 응답을 구분할 수 있다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| NAT | Network Address Translation. IP 주소 변환 |
| PAT | Port Address Translation. 포트 번호까지 변환해 하나의 공인 IP를 공유 |
| 공인 IP | 인터넷에서 유일한 주소 |
| 사설 IP | 내부망에서만 쓰는 주소. 대역은 [IPv4 주소 대역 표](ipv4addressranges.md) 참조 |
