## 1. 목적

IPv4(Internet Protocol version 4)는 32비트 주소로 장치를 식별하는 IP 버전이다. 이 문서는 주소 한 개가 어떻게 구성되고 어떤 종류가 있는지 설명한다.

## 2. 구성 요소

### 2.1 주소 구조

| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 길이 | 32비트다 |
| 2 | 표기 | 8비트(옥텟, octet) 4개를 십진수로 쓰고 점으로 구분한다. 예: `192.168.10.5` |
| 3 | 옥텟 값 범위 | 1옥텟은 8비트이므로 0~255(256가지)다 |
| 4 | 표현 가능한 주소 | `0.0.0.0` ~ `255.255.255.255`, 전체 2^32 = 4,294,967,296개다 |
| 5 | 네트워크 부분 | 서브넷 마스크의 1 비트가 덮는 앞쪽 부분이다 |
| 6 | 호스트 부분 | 서브넷 마스크의 0 비트가 덮는 뒤쪽 부분이다 |
| 7 | 클래스 | 주소 맨 앞 비트로 A~E 클래스를 구분한다(클래스풀 방식). 지금은 [CIDR](cidr.md)을 쓴다 |

### 2.2 주소의 종류

| 번호 | 종류 | 설명 |
|---|---|---|
| 1 | 공인 IP | 인터넷에서 유일한 주소다. 지역 인터넷 레지스트리와 ISP를 거쳐 할당받는다 |
| 2 | 사설 IP | 내부망에서만 쓰는 주소다. 관리자가 임의로 할당할 수 있고 인터넷에서는 라우팅되지 않는다 |
| 3 | 네트워크 주소 | 호스트 부분이 모두 0인 주소다. 네트워크 자체를 가리키며 장치에 할당하지 않는다 |
| 4 | 브로드캐스트 주소 | 호스트 부분이 모두 1인 주소다. 같은 네트워크의 모든 장치에 보낸다. 장치에 할당하지 않는다 |
| 5 | 루프백 주소 | `127.0.0.0/8` 전체다. 호스트 자신을 가리키며 흔히 `127.0.0.1`을 쓴다 |

{% hint style="info" %}
NOTE: 원본은 "127.0.0.1은 사설망 할당용으로 쓸 수 없다"고 적었다. 루프백은 `127.0.0.1` 한 개가 아니라 `127.0.0.0/8` 대역 전체다. 이 대역은 사설망 주소로 할당하지 않는다.
{% endhint %}

## 3. 동작 원리

사설 IP를 쓰는 장치가 인터넷과 통신할 때는 NAT 장치(주로 라우터)가 출발지 주소를 공인 IP로 바꿔 준다. 변환 과정은 [NAT 동작 원리](network_address_translation.md)를 따른다.

1. 사설망의 장치가 외부 서버로 패킷을 보낸다.
2. 라우터가 출발지 사설 IP를 라우터의 공인 IP로 바꿔 내보낸다.
3. 응답이 돌아오면 라우터가 목적지를 원래의 사설 IP로 되돌려 전달한다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 옥텟 | 8비트 묶음. IPv4 주소의 한 구간 |
| 서브넷 마스크 | 네트워크 부분과 호스트 부분을 나누는 32비트 값 |
| 루프백 | 호스트가 자기 자신에게 보내는 주소 |
| NAT | Network Address Translation. 주소를 변환하는 기술 |
