# IPv4 주소 대역 표 (Address Ranges)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | NET-IPN-009-REF |
| 유형 | REF (표) |
| 목적 | IPv4 클래스별 범위, 사설 대역, 특수 목적 대역을 참조한다 |
| 확인 상태 | 미검증 (원본 페이지와 일반 지식을 정리한 것이며 출처를 다시 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 클래스별 주소 범위

| 클래스 | 맨 앞 비트 | 첫 옥텟 범위 | 기본 마스크 | 호스트 수(네트워크당) | 비고 |
|---|---|---|---|---|---|
| A | `0` | 0~127 | `255.0.0.0` (/8) | 16,777,214 | 0과 127은 특수 용도라 일반 네트워크는 1~126이다 |
| B | `10` | 128~191 | `255.255.0.0` (/16) | 65,534 | |
| C | `110` | 192~223 | `255.255.255.0` (/24) | 254 | |
| D | `1110` | 224~239 | 없음 | 해당 없음 | 멀티캐스트 |
| E | `1111` | 240~255 | 없음 | 해당 없음 | 예약 |

{% hint style="info" %}
NOTE: 클래스 구분은 과거 방식(클래스풀)이다. 오늘날에는 마스크 길이를 직접 지정하는 [CIDR](cidr.md)을 쓴다.
{% endhint %}

## 2. 사설 대역 (RFC 1918)

| CIDR | 범위 | 주소 수 | 옛 클래스 |
|---|---|---|---|
| `10.0.0.0/8` | `10.0.0.0` ~ `10.255.255.255` | 16,777,216 | A 한 개 |
| `172.16.0.0/12` | `172.16.0.0` ~ `172.31.255.255` | 1,048,576 | B 16개 |
| `192.168.0.0/16` | `192.168.0.0` ~ `192.168.255.255` | 65,536 | C 256개 |

## 3. 특수 목적 대역

| CIDR | 이름 | 용도 |
|---|---|---|
| `0.0.0.0/8` | 이 네트워크 | `0.0.0.0`은 "주소 없음" 또는 "모든 주소"를 뜻한다 |
| `127.0.0.0/8` | 루프백 | 호스트 자신. `127.0.0.1`을 흔히 쓴다 |
| `169.254.0.0/16` | 링크 로컬(APIPA) | DHCP 응답을 받지 못했을 때 장치가 스스로 정하는 주소다 |
| `100.64.0.0/10` | 공유 주소 공간 | 통신사 수준 NAT(CGNAT)용이다 |
| `192.0.2.0/24` | 문서용 (TEST-NET-1) | 문서와 예제에 쓴다 |
| `198.51.100.0/24` | 문서용 (TEST-NET-2) | 문서와 예제에 쓴다 |
| `203.0.113.0/24` | 문서용 (TEST-NET-3) | 문서와 예제에 쓴다 |
| `224.0.0.0/4` | 멀티캐스트 | 옛 클래스 D |
| `240.0.0.0/4` | 예약 | 옛 클래스 E |
| `255.255.255.255/32` | 제한된 브로드캐스트 | 라우터를 넘지 않는 브로드캐스트 |

## 4. 사용 예

주소 `172.20.5.9`는 `172.16.0.0/12` 범위(`172.16.x.x` ~ `172.31.x.x`) 안이므로 사설 주소다. 주소 `172.32.5.9`는 범위 밖이므로 공인 주소다.
