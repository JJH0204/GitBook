## 1. 목적

IPv6는 128비트 주소를 쓰는 IP 버전이다. IPv4의 주소 부족을 해소하려고 만들었다. 모든 시스템을 한 번에 바꾸는 비용이 크므로 IPv4와 함께 쓴다.

## 2. 구성 요소

### 2.1 주소 구조

| 번호 | 항목 | 내용 | 비고 |
|---|---|---|---|
| 1 | 길이 | 128비트다 | |
| 2 | 표기 | 16비트 묶음 8개를 16진수로 쓰고 `:`로 구분한다 | 원본은 이 묶음을 "옥텟"이라 적었다. 옥텟은 8비트이므로 16비트 묶음(그룹)으로 정정했다 |
| 3 | 프리픽스 | `/<길이>`로 네트워크 부분의 비트 수를 쓴다. 예: `/32`는 앞 32비트(2개 그룹)다 | 원본의 "두 옥텟을 넷마스크로 사용"을 정정했다 |

### 2.2 주소의 종류

| 번호 | 종류 | 대역 | 설명 | 비고 |
|---|---|---|---|---|
| 1 | 글로벌 유니캐스트 | `2000::/3` | 인터넷에서 유일한 주소다 | |
| 2 | 링크 로컬 | `fe80::/10` | 같은 링크 안에서만 쓴다. 라우터를 넘지 않는다 | |
| 3 | 사이트 로컬 | `fec0::/10` | 사이트 안에서 쓰던 주소다 | 사용 중단(RFC 3879)됐다. 같은 목적에는 유니크 로컬 `fc00::/7`을 쓴다 |
| 4 | 멀티캐스트 | `ff00::/8` | 그룹에 속한 장치들에게 보낸다 | |
| 5 | 문서용 | `2001:db8::/32` | 문서와 예제에 쓴다 | |

### 2.3 전송 방식

| 번호 | 방식 | 설명 | 비고 |
|---|---|---|---|
| 1 | 유니캐스트(unicast) | 한 장치에 보낸다 | 원본의 "unie"를 정정했다 |
| 2 | 멀티캐스트(multicast) | 그룹에 속한 여러 장치에 보낸다 | IPv6에는 브로드캐스트가 없다. 그 역할을 멀티캐스트가 한다 |
| 3 | 애니캐스트(anycast) | 같은 주소를 가진 여러 장치 중 가장 가까운 한 장치에 보낸다 | 원본은 "any (IPv4의 브로드캐스트)"라 적었다. 애니캐스트는 브로드캐스트가 아니므로 정정했다 |

### 2.4 IPv4와의 공존

| 번호 | 방식 | 설명 |
|---|---|---|
| 1 | 듀얼 스택(dual stack) | 한 장치가 IPv4와 IPv6를 동시에 쓴다. 원본의 "스택커블"을 정정했다 |
| 2 | 터널링 | IPv6 패킷을 IPv4 패킷 안에 담아 IPv4 망을 통과시킨다 |

## 3. 동작 원리: 주소 표기 축약

축약은 두 규칙을 쓴다.

1. 각 그룹 앞쪽의 0은 생략한다. 뒤쪽의 0은 생략하지 못한다.
2. 연속된 `0000` 그룹은 `::` 하나로 줄인다. `::`는 주소 한 개에 한 번만 쓴다.

### 예 1

원본: `2001:0db8:0eee:0000:0000:0000:0000:0000/48`

| 단계 | 결과 |
|---|---|
| 앞쪽 0 생략 | `2001:db8:eee:0:0:0:0:0` |
| 연속 0 그룹을 `::`로 | `2001:db8:eee::` |

최종: `2001:db8:eee::/48` (/48은 앞 3개 그룹이 네트워크 부분이다)

### 예 2

원본: `2001:0db8:1240:0000:0000:3fee:0000:0000/48`

| 단계 | 결과 |
|---|---|
| 앞쪽 0 생략 | `2001:db8:1240:0:0:3fee:0:0` |
| `0` 그룹 두 군데 중 하나만 `::`로 | `2001:db8:1240::3fee:0:0` |

최종: `2001:db8:1240::3fee:0:0/48`

{% hint style="info" %}
NOTE: `1240`의 뒤쪽 0은 생략하지 못한다. `:1240:`을 `:124:`로 줄이면 다른 값이 된다. `::`를 두 번 쓰면 몇 개 그룹이 줄었는지 알 수 없어 올바른 주소가 아니다. 길이가 같은 0 그룹이 둘이면 앞쪽을 `::`로 줄이는 것이 권장 표기다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| IPv6 | 128비트 주소를 쓰는 IP 버전 |
| 그룹 | 콜론으로 구분한 16비트(16진수 4자리) 묶음 |
| 프리픽스 | 주소 앞쪽의 네트워크 부분. `/<비트 수>`로 표기한다 |
| 듀얼 스택 | IPv4와 IPv6를 함께 쓰는 방식 |
