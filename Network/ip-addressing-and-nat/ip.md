## 1. 목적

IP(Internet Protocol)는 네트워크에서 장치를 식별하는 주소를 정하고, 그 주소를 기준으로 패킷을 목적지까지 전달하는 프로토콜이다. OSI 7계층의 3계층(네트워크 계층)에 해당한다. 현재 IPv4와 IPv6가 함께 쓰인다.

## 2. 구성 요소

| 번호 | 구성 요소 | 역할 | 상세 문서 |
|---|---|---|---|
| 1 | IP 주소 | 장치(인터페이스)를 식별하는 논리 주소다 | [IPv4 주소 체계](ipv4.md), [IPv6 주소 체계](ipv6.md) |
| 2 | 서브넷 마스크 | 주소를 네트워크 부분과 호스트 부분으로 나눈다 | [서브넷팅 계산](subnetting.md), [사이더 표기법](cidr.md) |
| 3 | 라우팅 | 패킷을 다른 네트워크로 전달할 경로를 정한다 | [게이트웨이 설정](gatewaysetup.md) |

## 3. 동작 원리

1. 송신 장치가 목적지 IP 주소와 자신의 서브넷 마스크를 비교한다.
2. 목적지가 같은 네트워크이면 직접 전달한다.
3. 목적지가 다른 네트워크이면 기본 게이트웨이로 보낸다.
4. 각 라우터가 목적지 주소를 보고 다음 경로를 정해 전달한다.

{% hint style="info" %}
NOTE: IP는 연결을 맺지 않고 전달을 보장하지 않는다(최선 노력 전달, best-effort). 신뢰성은 상위 계층(예: TCP)이 맡는다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| IP | Internet Protocol. 주소 지정과 패킷 전달을 맡는 3계층 프로토콜 |
| IPv4 | 주소 길이 32비트인 IP 버전 |
| IPv6 | 주소 길이 128비트인 IP 버전. IPv4의 주소 부족을 해소한다 |
| 서브넷 마스크 | 주소에서 네트워크 부분을 표시하는 값 |
