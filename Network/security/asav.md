## 1. 목적

ASAv(Adaptive Security Virtual Appliance)는 Cisco ASA 방화벽을 가상 머신으로 만든 제품이다. 가상 환경에서 방화벽 기능을 제공한다.

## 2. 구성 요소

### 2.1 특징

| 항목 | 내용 |
|---|---|
| 형태 | 가상화 장치(가상 머신 이미지) |
| 라이선스 | Cisco 라이선스가 필요하다(유료) |
| 기능 | 방화벽 기능과 라우팅 기능을 수행한다 |

### 2.2 관리 인터페이스(Management Interface)

| 항목 | 내용 |
|---|---|
| 용도 | 네트워크 구축에 쓰지 않는 전용 포트. 방화벽 장치 관리용이다 |
| 사용 방식 | 네트워크 구축 후 별도 관리 장치를 연결해 방화벽을 관리할 때 쓴다 |

### 2.3 방화벽 규칙 (보안 레벨)

ASA는 인터페이스마다 보안 레벨(0~100)을 지정한다. 숫자가 클수록 신뢰하는 네트워크다. 기본 규칙은 다음과 같다.

| 방향 | 기본 동작 |
|---|---|
| 보안 레벨이 낮은 네트워크에서 높은 네트워크로 | 모든 트래픽을 차단한다(허용하려면 ACL이 필요하다) |
| 보안 레벨이 높은 네트워크에서 낮은 네트워크로 | 허용한다 |
| 높은 곳에서 시작한 ICMP의 응답 | 기본으로 차단된다(ICMP 검사 기능을 켜야 응답이 돌아온다) |

{% hint style="info" %}
NOTE: 원본은 "ICMP 패킷은 제외"라고만 썼다. 상태 기반 검사로 TCP와 UDP의 응답은 자동으로 허용되지만 ICMP 응답은 ICMP 검사를 켜지 않으면 돌아오지 않는다. 장비 버전에서 확인이 필요하다.
{% endhint %}

## 3. 동작 원리

1. 트래픽이 한 인터페이스로 들어온다.
2. ASAv가 출발·도착 인터페이스의 보안 레벨을 비교한다.
3. 낮은 레벨에서 높은 레벨로 가는 트래픽은 ACL이 허용하지 않으면 차단한다.
4. 높은 레벨에서 낮은 레벨로 가는 트래픽은 허용하고, 응답 트래픽은 연결 상태 정보로 돌려보낸다.

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| ASAv | Adaptive Security Virtual Appliance |
| 보안 레벨 | 인터페이스의 신뢰 수준(0~100) |
| ICMP | Internet Control Message Protocol. ping이 쓰는 프로토콜 |
