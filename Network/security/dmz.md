## 1. 목적

DMZ(DeMilitarized Zone)는 외부(인터넷)에 공개하는 서버를 내부망과 분리해 두는 중간 구간이다. 공개 서버가 뚫려도 공격자가 곧바로 내부망에 닿지 못하게 하려는 구조다.

## 2. 구성 요소

| 구간 | 예시 장치 | 외부(인터넷)에서 접근 | 내부망에서 접근 |
|---|---|---|---|
| 외부(Outside) | 인터넷 | - | 허용(필요한 것만) |
| DMZ | 웹 서버, 메일 서버, DNS 서버 | 필요한 포트만 허용 | 필요한 포트만 허용 |
| 내부(Inside) | 업무 PC, 내부 DB | 차단 | - |

| 구성 방식 | 설명 |
|---|---|
| 단일 방화벽(3-leg) | 방화벽 하나에 외부·DMZ·내부 인터페이스를 둔다 |
| 이중 방화벽 | 외부와 DMZ 사이, DMZ와 내부 사이에 방화벽 둘을 둔다. 서로 다른 제품을 쓰면 우회가 어렵다 |

## 3. 동작 원리

1. 외부에서 온 요청은 DMZ의 공개 서버에 필요한 포트(예: TCP 443)만 허용한다.
2. 외부에서 내부망으로 직접 시작하는 연결은 차단한다.
3. DMZ 서버가 내부 DB 등에 접근해야 하면 필요한 출발지·포트만 허용한다.
4. DMZ에서 내부로 시작하는 연결은 최소로 제한한다. 공개 서버가 침해돼도 내부 확산을 막기 위해서다.
5. 내부망은 필요한 외부 접속(예: 웹)만 허용한다.

Cisco ASA 같은 장비는 인터페이스마다 보안 레벨을 두어 이를 구현한다. 낮은 레벨에서 높은 레벨로 가는 트래픽은 기본 차단이다([ASAv](asav.md) 참조).
