## 1. 목적

원본의 설명은 "스레드를 만들어 시스템을 마비시키는 DoS 프로그램"이다. 이 문서는 그 동작이 시스템에서 어떻게 나타나는지와 대응을 정리한다.

## 2. 구성 요소

| 요소 | 역할 |
|---|---|
| 스레드 생성 반복 | CPU 시간과 메모리를 소진한다 |
| 분석 관점 | 스레드 생성 API 호출이 반복문 안에 있는지 확인한다 |

## 3. 탐지·방어

| 관점 | 내용 |
|---|---|
| 흔적 | 특정 프로세스의 스레드 수와 CPU 사용률이 비정상적으로 증가한다 |
| 완화 | 프로세스별 자원 제한(스레드 수, 메모리)을 둔다 |
| 대응 | 의심 프로세스를 종료하고 실행 경로를 격리한다 |

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| DoS | Denial of Service, 서비스 거부 |
| 스레드 | 프로세스 안의 실행 단위 |
