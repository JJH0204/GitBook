## 일반적인 디버거 단축키 (보강, 미검증)

원본은 F2 한 줄만 있었고 도구 이름이 없다. 아래는 x64dbg, OllyDbg, IDA 디버거에서 흔히 쓰는 기본 단축키다. 도구와 버전에 따라 다르므로 사용하는 도구의 설정에서 확인한다.

| 키 | 동작 |
|---|---|
| F2 | 브레이크포인트 설정·해제 |
| F7 | 한 단계 실행 (함수 호출 안으로 들어간다) |
| F8 | 한 단계 실행 (함수 호출을 건너뛴다) |
| F9 | 다음 브레이크포인트까지 실행 |

## 개념

| 용어 | 뜻 |
|---|---|
| 소프트웨어 브레이크포인트 | 대상 주소의 명령을 중단용 명령(x86의 INT3, 바이트 0xCC)으로 바꿔 실행을 멈춘다 |
| 하드웨어 브레이크포인트 | CPU 디버그 레지스터로 실행·읽기·쓰기 시점에 멈춘다. 코드를 바꾸지 않으며 개수가 제한된다 |
| 조건부 브레이크포인트 | 지정한 조건이 참일 때만 멈춘다 |

악성코드는 INT3 삽입을 검사하는 식으로 디버깅을 탐지하기도 한다. 분석은 반드시 격리된 가상 머신에서 한다.
