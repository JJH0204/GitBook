# 모의해킹 팀 게임 시나리오

| 항목 | 내용 |
|---|---|
| Task ID | SEC-LAB-007-MP |
| 유형 | MP (환경 구성 계획) |
| 목적 | 팀 단위 모의해킹 실습에 쓸 취약한 대상 서버를 하루 안에 준비하고 탐지 장비와 연동 시험을 한다 |
| 적용 대상 | 허가받은 격리 실습 환경(자신이 소유·관리하는 VM), 호스트 전용 또는 내부 네트워크 |
| 소요 시간 | 약 1일 (원본 기준, 추정) |
| 확인 상태 | 미검증 (원본 메모를 정리한 것이며 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="info" %}
NOTE: 원본에 있던 계정 이름과 비밀번호는 삭제했다. 사용자 판단이 필요하다: 원본이 실습 과제의 준비 메모로 보이며, 세부 취약점 구성은 원본에 없다.
{% endhint %}

## 2. 필요 장비와 자재

| 번호 | 이름 | 사양 | 비고 |
|---|---|---|---|
| 1 | 대상 서버 VM | Ubuntu 16.04.7 | 원본 기준 |
| 2 | 탐지 장비 | Snort, Wazuh | 팀원이 구축한 탐지 머신 |
| 3 | 방화벽(WAF) | 원본에 구성 정보가 없다 | 확인 필요 |
| 4 | 네트워크 | 팀원이 쓰지 않는 사설 IP 1개 | 원본은 192.168.1.100 사용 |

## 3. 안전 사항

WARNING: 의도적으로 취약한 서버는 외부 네트워크에 연결하지 않는다. 호스트 전용 또는 내부 네트워크에서만 가동한다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | 대상 VM의 계정 `<계정>`과 비밀번호 `<비밀번호>`를 정하고 팀에 별도 채널로 공유한다 | 문서에 적지 않는다 |
| 2 | 사용할 IP `<대상 IP>`가 다른 장비와 겹치지 않는다 | 네트워크 목록 확인 |

## 5. 절차

**A. 대상 서버 구축**

1. (SUBTASK 5-A-01) Ubuntu 16.04.7 VM을 만들고 `<대상 IP>`를 설정한다. → 결과: 같은 네트워크의 다른 VM에서 연결된다.
2. (SUBTASK 5-A-02) 취약한 서비스 구성 하나를 정한다. → 결과: 구성 내용이 공략집에 기록된다. 구성은 원본에 없다.

**B. 공략집 작성과 공유**

1. (SUBTASK 5-B-01) 서버 구성과 예상 취약점, 풀이 경로를 공략집에 쓴다. → 결과: 공략집 파일이 생긴다.
2. (SUBTASK 5-B-02) 공략집을 팀 저장 위치에 공유한다. → 결과: 팀원이 열 수 있다.

**C. 탐지 장비 연동 시험**

1. (SUBTASK 5-C-01) 대상 서버의 트래픽이 Snort와 Wazuh에 도달하게 한다. → 결과: 탐지 장비 콘솔에 대상 서버 이벤트가 보인다.

## 6. 기능 확인
