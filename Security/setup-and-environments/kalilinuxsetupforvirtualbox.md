{% hint style="danger" %}
WARNING: 취약 VM은 인터넷에 직접 노출하지 않는다. 호스트 전용 또는 격리된 NAT 네트워크에서만 실행한다. 브리지 어댑터는 VM을 호스트와 같은 LAN에 노출하므로 취약 VM에는 쓰지 않는다.
{% endhint %}

## 5. 절차

**A. USB 컨트롤러 설정**

1. (SUBTASK 5-A-01) VM을 선택하고 `설정 > USB`를 연다.
2. (SUBTASK 5-A-02) USB 컨트롤러를 `USB 1.1`로 선택한다. → 결과: 선택이 저장된다.

{% hint style="warning" %}
CAUTION: USB 컨트롤러를 USB 2.0 이상으로 선택했을 때 오류가 나는 경우가 있다. 오류가 나면 USB 1.1로 변경한다.
{% endhint %}

**B. 네트워크 어댑터 설정**

1. (SUBTASK 5-B-01) `설정 > 네트워크 > 어댑터 1`을 연다.
2. (SUBTASK 5-B-02) `다음에 연결됨`을 `호스트 전용 어댑터` 또는 `NAT 네트워크`로 바꾼다. → 결과: 실습망 대역의 IP를 받을 수 있다.

{% hint style="info" %}
NOTE: 원본은 `어댑터 브릿지`(브리지)를 선택했다. 브리지는 VM이 호스트와 같은 대역의 LAN을 쓰게 하므로 외부 접근이 필요한 경우에만 쓴다. 이 문서는 격리를 위해 호스트 전용 또는 NAT 네트워크를 안내한다. 원본의 브리지 선택 의도는 확인 필요다.
{% endhint %}

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | VM을 부팅하고 `ip addr`를 실행한다 | IP가 보인다 | 실습망 대역(예: `192.168.56.x`) |
| 2 | USB 장치를 VM에 연결한다 | 오류 없이 인식된다 | 오류 메시지 없음 |

## 7. 복구

1. (SUBTASK 7-01) VM을 종료하고 `설정 > 네트워크 > 어댑터 1`에서 이전 연결 방식으로 되돌린다. → 결과: 이전 설정으로 돌아온다.
2. (SUBTASK 7-02) 설정 전 만든 스냅샷이 있으면 `<초기 상태>` 스냅샷으로 복원한다.
