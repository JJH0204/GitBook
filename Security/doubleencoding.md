# DoubleEncoding

개념 요약: 이미 URL 인코딩된 문자열에서 '%' 문자를 다시 인코딩하면 "한번 더 인코딩(double encoding)"이 됩니다. '%'는 인코딩 시 `%25`가 되므로, 기존의 인코딩 결과에서 `%`가 있는 모든 부분을 다시 `%25`로 바꿔주면 됩니다.

예시:

* '<' 는 한 번 인코딩하면 `%3c`
* 이 값을 다시 인코딩하면 `%` → `%25` 변환으로 `%253c`

간단한 변환 규칙:

* 원래: `<` → `%3c`
* 다시 인코딩: `%3c` → `%25` + `3c` → `%253c`
