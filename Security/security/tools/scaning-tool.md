# Scaning tool

https://nmap.org/

포트 범위

* 0-1023: 잘 알려진 포트 (Well-Known Ports)
* 1024-49151: 등록된(예약된) 포트
* 49152-65535: 비등록(사설) 포트

{% tabs %}
{% tab title="TCP Scan (-sT)" %}
-sT: TCP Connect 스캔 (기본 TCP 스캔 방식)

주요 변형(플래그)

* `-sS`: SYN 스캔
  * 절차 예시: kali -> SYN(80) -> target, target -> SYN+ACK(80) -> kali
  * TCP 응답에 따라 포트가 활성(열림)인지 판단. 응답이 없으면 비활성(닫힘)으로 간주.
* `-sN`: Null 스캔
  * 아무 플래그 없이 패킷 전송
* `-sF`: FIN 스캔
* `-sX`: XMas 스캔
  * 여러 플래그를 조합해 한 번에 전달
* `-sM`: (설명에선 `-xM`으로 표현) 둘 이상 플래그 조합 포함
* `-sA`: ACK 스캔
* `-sW`: Window 스캔 (window size)
  * 응답 윈도우 크기 정보를 이용하여 상태 판단
* `-sL`: 리스트 스캔 (idle / 목록)
  * 호스트 목록만 생성(실제로 패킷을 보내지 않는 옵션으로 호스트 이름 해석용)
{% endtab %}

{% tab title="UDP Scan (-sU)" %}
-sU: UDP 스캔

옵션

* `-F`: Fast (빠른 스캔, 포트 수 축소)
* `-r`: 순차적 스캔 (포트 순서 섞지 않음)
{% endtab %}

## Timing Option

스캔 속도/간격 관련 옵션(스캐닝이 공격처럼 보이지 않도록 딜레이 조정 등)

* 0: 매 5분 간격
* 1: 매 15초 간격
* 2: 매 0.4초 간격
* 3: 다중 대상에 대한 다중 탐색 (기본)
* 4: 정해진 시간(예: 5분) 동안
* 5: 대상 스캔 간격 75초

## NSE (Nmap Script Engine)

* 스크립트용 분류 예: 인증, 기본 스크립트(`-sC`, `-A`), 발견, 익스플로잇, DoS, 침투, 취약점 점검 등
* 새로운 스크립트/엔진은 https://nmap.org/ 에서 확인/설치 가능
* 취약점 점검 관련 스크립트는 `-vuln-` 접두어(또는 해당 스크립트명)으로 사용

{% hint style="info" %}
NSE 스크립트는 매우 다양하며, 스크립트 유형에 따라 스캔 결과가 달라질 수 있습니다. 기본적인 스캔과 스크립트 기반 스캔을 병행해서 사용하면 보다 풍부한 정보를 얻을 수 있습니다.
{% endhint %}

## 방화벽/IDS 우회 옵션

* `-f`: 패킷 세분화 (fragmentation)
* `--source-port`, `-g`: 출발지 포트(또는 IP) 위조
* `--data-length`: 패킷 데이터 길이 임의 조작
* `--scan-delay`: 스캔 간 딜레이 설정
* `-D`: 가짜(스푸핑) IP 생성 (decoy)

{% hint style="warning" %}
이러한 우회 옵션은 네트워크 보안 장비를 회피하기 위해 사용될 수 있으며, 허가되지 않은 대상에 대해 사용하면 불법입니다. 항상 적법한 허가를 받은 환경에서만 사용하세요.
{% endhint %}

요약(중복 정리)

* 포트 범위: 0-1023(Well-Known), 1024-49151(등록), 49152-65535(비등록/사설)
* TCP 스캔: `-sT` 및 다양한 플래그(`-sS`, `-sN`, `-sF`, `-sX`, `-sM`, `-sA`, `-sW`, `-sL`)
* UDP 스캔: `-sU` (`-F`, `-r` 등)
* 타이밍 옵션으로 스캔 속도/간격 제어 가능
* NSE: 인증, 발견, 익스플로잇, 취약점 점검 등 스크립트 지원
* 방화벽/IDS 우회 옵션 존재 (`-f`, `-g`, `--data-length`, `--scan-delay`, `-D`)
