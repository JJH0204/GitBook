# 메타스플로잇 (Metasploit)

## 목적

Metasploit은 취약점 점검(침투 테스트)용 프레임워크다. 이 문서는 프레임워크의 구성 개념과 콘솔(`msfconsole`) 기본 조작을 설명한다. 특정 취약점을 공격하는 명령과 페이로드는 다루지 않는다.

{% hint style="danger" %}
WARNING: Metasploit은 실제 공격 기능을 가진다. 자신이 소유·관리하거나 서면으로 허가받은 격리 실습 환경에서만 사용한다. 허가받지 않은 시스템에 쓰는 것은 불법이다.
{% endhint %}

{% hint style="info" %}
NOTE: 확인 상태: 미검증. 원본 페이지의 짧은 힌트와 일반 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다. 원본의 빈 절("명령어 리스트", "공격 도구 리스트")은 내용이 없어 옮기지 않았다.
{% endhint %}

## 구성 요소

| 구성 요소 | 역할 |
|---|---|
| msfconsole | 모듈을 검색·선택·설정하는 대화형 콘솔이다 |
| 모듈 | 기능 단위 부품이다. 종류에는 exploit, auxiliary, payload, post 등이 있다 |
| 모듈 옵션 | 모듈이 요구하는 설정값이다. `required`가 `yes`이면 반드시 입력한다 |
| 세션 | 모듈이 대상과 연결을 맺은 뒤 유지되는 연결이다. 콘솔에서 목록을 확인한다 |
| meterpreter | Metasploit의 고급 세션 유형이다. 이 문서는 사용법을 다루지 않는다 |

## 동작 원리

1. 사용자가 `search`로 모듈을 찾는다.
2. 사용자가 `use <모듈 경로>`로 모듈을 선택한다.
3. 사용자가 `show options`로 옵션을 확인하고 필수 값을 입력한다.
4. 모듈이 실행되고 결과가 콘솔에 표시된다.
5. 연결이 생기면 세션 목록에서 확인한다.

## 콘솔 기본 조작 (원본 내용)

| 항목 | 설명 |
|---|---|
| `exit` | 콘솔에서 나온다 |
| `back` | 선택한 모듈을 취소하고 이전 상태로 돌아온다 |
| 모듈 경로 입력 | 경로를 끝까지 입력하지 않아도 유일하게 구분되면 적용된다 (원본 기준, 확인 필요) |
| 로그 | 작업 과정을 로그로 남길 수 있다 |
| 세션 확인 | 연결된 세션 목록을 확인할 수 있다 |

## 모듈 등급 (Rank)

검색 결과의 등급은 익스플로잇 성공 가능성을 나타낸다. 원본은 `normal > good > great > excellent` 순으로 성공 확률이 높다고 적었다. 공식 등급에는 `excellent`가 가장 높고 그 아래 `great`, `good`, `normal`, `average`, `low`, `manual`이 있다 (확인 필요).

## 탐지·방어

| 항목 | 내용 |
|---|---|
| 원인 | 패치되지 않은 알려진 취약점, 약한 설정이 공격 모듈의 대상이 된다 |
| 완화 | 보안 패치를 적용하고 불필요한 서비스를 끈다. 알려진 취약점 점검에는 정기 스캔을 쓴다 |
| 로그 흔적 | 대상 서비스 로그에 비정상 요청이 반복된다. 서버에서 외부로 나가는 낯선 연결이 생긴다 (미검증) |

## 약어·용어

| 용어 | 뜻 |
|---|---|
| exploit | 취약점을 이용하는 모듈 |
| payload | 성공 후 대상에서 실행되는 코드 |
| auxiliary | 스캔 등 공격이 아닌 보조 모듈 |
| session | 대상과 유지되는 연결 |
