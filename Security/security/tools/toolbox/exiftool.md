# ExifTool 메타데이터 분석

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | SEC-TBX-002-MP |
| 목적 | ExifTool로 이미지 등 파일의 메타데이터를 확인하고 일부 또는 전부 삭제한다 |
| 적용 대상 | Linux(Kali 등) 또는 macOS, ExifTool 설치, 자신이 소유한 파일 |
| 소요 시간 | 약 10분 |
| 확인 상태 | 미검증 (원본의 짧은 목록과 ExifTool 일반 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 개요

메타데이터는 파일 안에 들어 있는 부가 정보다. 사진에는 촬영 기기, 촬영 시각, 위치(GPS) 등이 들어 있을 수 있다. ExifTool은 이 정보를 읽고, 수정하고, 삭제하는 명령줄 도구다.

* 사진을 촬영한 기종을 확인할 수 있다.
* 메타데이터를 수정할 수 있다.
* 메타데이터를 일부 또는 전부 삭제할 수 있다.

{% hint style="warning" %}
CAUTION: 메타데이터 영역은 텍스트를 담을 수 있어서, 업로드 검증이 부실한 서비스에서 악성 문자열을 숨기는 경로로 악용될 수 있다. 방어 관점에서는 업로드 파일의 메타데이터를 제거하고 내용을 다시 인코딩해 저장한다. 이 문서는 그런 문자열을 삽입하는 절차를 다루지 않는다.
{% endhint %}

## 2. 필요 장비와 자재

| 번호 | 이름 | 사양 | 비고 |
|---|---|---|---|
| 1 | ExifTool | Kali 등에는 `libimage-exiftool-perl` 패키지로 제공된다 | `exiftool -ver`로 버전을 확인한다 |
| 2 | 시험용 파일 | 자신이 촬영한 이미지 1개 | 원본 파일은 복사본으로 시험한다 |

## 3. 안전 사항

{% hint style="danger" %}
WARNING: 자신이 소유하지 않은 파일의 메타데이터를 수정하거나 삭제하지 않는다. 증거 자료나 타인 파일의 변조는 불법일 수 있다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 수정과 삭제 명령은 기본값으로 원본 파일을 `<파일명>_original`로 백업한다. 백업을 만들지 않는 `-overwrite_original` 옵션은 복사본에만 쓴다.
{% endhint %}

## 4. 준비

| 번호 | 항목 | 확인 방법 |
|---|---|---|
| 1 | ExifTool 설치를 확인한다: `exiftool -ver` | 버전 번호가 출력된다 |
| 2 | 시험용 파일을 복사한다: `cp <원본 파일> test.jpg` | `test.jpg`가 생긴다 |
| 3 | 매뉴얼을 확인한다: `man exiftool` | 도움말이 열린다 |

## 5. 절차

### A. 메타데이터 확인

1. (5-A-01) 전체 메타데이터를 출력한다: `exiftool test.jpg` → 결과: `Make`, `Camera Model Name`, `Create Date` 등 태그 목록이 출력된다. 파일에 해당 정보가 없으면 그 행은 없다.
2. (5-A-02) 특정 태그만 출력한다: `exiftool -Model test.jpg` → 결과: 촬영 기기 모델 한 줄이 출력된다.

### B. 메타데이터 수정

1. (5-B-01) 태그 값을 바꾼다: `exiftool -Artist=<작성자 이름> test.jpg` → 결과: `1 image files updated`가 출력되고 `test.jpg_original`이 생긴다.
2. (5-B-02) 바뀐 값을 확인한다: `exiftool -Artist test.jpg` → 결과: 입력한 값이 출력된다.

### C. 메타데이터 삭제

1. (5-C-01) 특정 태그를 삭제한다: `exiftool -Artist= test.jpg` → 결과: 태그 값이 비워진다.
2. (5-C-02) 모든 메타데이터를 삭제한다: `exiftool -all= test.jpg` → 결과: `1 image files updated`가 출력된다.

## 6. 기능 확인

| 번호 | 확인 동작 | 기대 결과 | 합격 기준 |
|---|---|---|---|
| 1 | `exiftool test.jpg` | 기기·시각·위치 태그가 없다 | 5-C-02 이후 `Make`, `Model`, `GPS` 태그가 출력되지 않는다 |
| 2 | `ls` | `test.jpg_original`이 남아 있다 | 원본 백업이 존재한다 |

## 7. 복구

1. (7-01) 변경을 취소하려면 백업을 되돌린다: `mv test.jpg_original test.jpg` → 결과: 원래 메타데이터가 돌아온다.
2. (7-02) 시험이 끝나면 `test.jpg`를 삭제한다.

## 8. 탐지·방어

| 항목 | 내용 |
|---|---|
| 원인 | 이미지 등 업로드 파일의 메타데이터가 검증 없이 저장·출력된다 |
| 완화 | 업로드 파일의 메타데이터를 제거하고 이미지를 다시 인코딩한다. 출력 시 이스케이프한다 |
| 개인정보 | 공개 전 `exiftool -all=`로 GPS와 기기 정보를 지운다 |
| 로그 흔적 | 업로드 요청 본문에 비정상 텍스트가 든 이미지가 보인다 (웹 서버·WAF 로그, 미검증) |
