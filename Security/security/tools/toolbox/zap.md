# OWASP ZAP 진단 도구

## 목적

ZAP(Zed Attack Proxy)은 OWASP가 개발한 웹 애플리케이션 취약점 진단 도구다. 프록시로 동작하면서 웹 취약점을 찾는다. 이 문서는 ZAP과 OWASP의 관계, 기능 개요, 진단 시 주의를 정리한다.

{% hint style="danger" %}
WARNING: ZAP의 능동 스캔은 대상에 공격성 요청을 대량으로 보낸다. 직접 운영하거나 서면으로 허가받은 대상(bWAPP, DVWA 같은 실습 앱 포함)에서만 실행한다. 허가받지 않은 사이트에 쓰는 것은 불법이다.
{% endhint %}

{% hint style="info" %}
NOTE: 확인 상태: 미검증. 원본의 짧은 메모와 ZAP 일반 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다.
{% endhint %}

## 구성 요소

| 기능 | 역할 |
|---|---|
| 프록시 | 브라우저와 서버 사이의 요청과 응답을 중계하고 보여 준다 |
| 수동(Passive) 스캔 | 오가는 트래픽을 분석만 한다. 대상에 추가 요청을 보내지 않는다 |
| 스파이더(Spider) | 링크를 따라가며 대상의 페이지 구조를 수집한다 |
| 능동(Active) 스캔 | 취약점을 찾으려고 변형된 요청을 직접 보낸다 |

[DVWA SQL Injection 문서](../../../dvwa/sql-injection.md)는 ZAP을 "프록시 도구이지만 취약점 점검이 가능한 도구"로 소개한다.

## 동작 원리

1. 브라우저의 프록시를 ZAP으로 지정한다.
2. 브라우저로 대상 사이트를 탐색하면 ZAP이 요청을 기록한다.
3. 수동 스캔이 기록된 트래픽에서 문제를 찾는다.
4. 능동 스캔을 하면 ZAP이 변형 요청을 보내 취약점을 찾는다.
5. 결과가 경고(Alert) 목록으로 표시된다.

## OWASP

원본 메모를 옮긴다.

* OWASP는 Top 10 가이드를 매년 발표한다 (실제 발표 주기는 2~4년이며 확인 필요).
* ZAP은 OWASP가 개발한다.
* 원본에 `cwe = casc = cve`라는 메모가 있다. 세 용어는 같은 것이 아니어서 옮기지 않았다. CWE는 취약점 유형 분류, CVE는 개별 취약점 식별 번호다.

## 탐지·방어

| 항목 | 내용 |
|---|---|
| 흔적 | 능동 스캔은 짧은 시간에 비정상 파라미터 요청을 대량으로 만든다. 웹 서버·WAF 로그와 도구 고유의 User-Agent로 보인다 (미검증) |
| 완화 | 스캔 결과의 경고를 입력 검증, 패치, 설정 변경으로 해결한다 |

## 약어·용어

| 용어 | 뜻 |
|---|---|
| ZAP | Zed Attack Proxy |
| CWE | Common Weakness Enumeration. 취약점 유형 분류 |
| CVE | Common Vulnerabilities and Exposures. 개별 취약점 번호 |
