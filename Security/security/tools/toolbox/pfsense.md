# pfSense 방화벽 솔루션

## 목적

pfSense는 방화벽 장치로 개발된 오픈소스 네트워크 솔루션이다. 지속적인 개발로 [VPN](https://krjaeh0.gitbook.io/j-log/network/security/vpn), 패킷 분석 도구 등 다른 기능도 수행할 수 있다.

{% hint style="info" %}
NOTE: 확인 상태: 미검증. 원본은 한 문장뿐이었다. 아래 표는 pfSense 일반 지식을 정리한 것이며 이 환경에서 실행해 확인하지 않았다. 설치와 설정 절차는 원본에 없어 쓰지 않았다.
{% endhint %}

## 구성 요소

| 기능 | 역할 |
|---|---|
| 방화벽 | 규칙에 따라 트래픽을 허용하거나 차단한다 |
| VPN | 원격 접속과 사이트 간 연결을 제공한다 |
| 패킷 분석 | 인터페이스를 지나는 패킷을 확인한다 (패킷 캡처 기능, 미검증) |

## 동작 원리

1. pfSense를 네트워크 경계(게이트웨이)에 둔다.
2. 모든 트래픽이 pfSense를 지난다.
3. 방화벽 규칙이 트래픽별로 허용 또는 차단을 정한다.

## 약어·용어

| 용어 | 뜻 |
|---|---|
| 방화벽 | 규칙으로 네트워크 트래픽을 통제하는 장치 |
| VPN | Virtual Private Network. 암호화된 가상 사설 통신망 |
