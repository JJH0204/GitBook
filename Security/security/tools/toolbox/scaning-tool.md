# Nmap 포트 스캐닝 도구

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | SEC-TBX-006-REF |
| 유형 | REF (옵션 표) |
| 목적 | Nmap의 포트 범위, 스캔 방식, 타이밍, NSE, 회피 관련 옵션을 참조한다 |
| 적용 대상 | Nmap 7.x 이상, Linux(Kali 등) |
| 확인 상태 | 미검증 (원본을 정리하고 틀린 서술을 일반 지식으로 정정했으며 이 환경에서 실행해 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="danger" %}
WARNING: 포트 스캔은 자신이 소유·관리하거나 서면으로 허가받은 대상에서만 한다. 허가받지 않은 시스템을 스캔하는 것은 불법이다. 실습은 격리된 실습망(VM)에서 한다.
{% endhint %}

공식 사이트: [https://nmap.org/](https://nmap.org/)

## 1. 포트 범위

| 범위 | 이름 |
|---|---|
| 0-1023 | 잘 알려진 포트 (Well-Known Ports) |
| 1024-49151 | 등록된 포트 (Registered Ports) |
| 49152-65535 | 동적·사설 포트 (Dynamic/Private Ports) |

## 2. TCP 스캔

`-sT`는 TCP Connect 스캔이다. 시스템의 연결 호출로 3-way handshake를 끝까지 수행한다. root 권한이 없을 때의 기본 TCP 스캔이다. root 권한이 있으면 기본값은 `-sS`다.

| 옵션 | 이름 | 설명 |
|---|---|---|
| `-sT` | Connect 스캔 | 연결을 끝까지 맺는다 |
| `-sS` | SYN 스캔 | SYN을 보내 SYN+ACK 응답이면 열림으로 본다. 연결을 완성하지 않는다. 예: kali → SYN(80) → 대상, 대상 → SYN+ACK(80) → kali |
| `-sN` | Null 스캔 | 플래그 없이 패킷을 보낸다 |
| `-sF` | FIN 스캔 | FIN 플래그만 보낸다 |
| `-sX` | Xmas 스캔 | FIN, PSH, URG 플래그를 함께 보낸다 |
| `-sM` | Maimon 스캔 | FIN+ACK 플래그를 보낸다 (원본은 `-xM`으로 잘못 적었다) |
| `-sA` | ACK 스캔 | ACK를 보내 방화벽 규칙을 파악한다. 열림 여부는 알 수 없다 |
| `-sW` | Window 스캔 | 응답의 윈도우 크기로 상태를 판단한다 |
| `-sL` | 리스트 스캔 | 대상 목록과 이름 조회만 한다. 패킷을 보내지 않는다 |

{% hint style="info" %}
NOTE: 응답이 없는 포트는 닫힘이 아니라 필터링(filtered)일 수 있다. 원본의 "응답이 없으면 닫힘" 서술을 정정했다.
{% endhint %}

## 3. UDP 스캔

| 옵션 | 설명 |
|---|---|
| `-sU` | UDP 스캔 |
| `-F` | 빠른 스캔. 스캔 포트 수를 줄인다 |
| `-r` | 포트를 무작위 순서가 아닌 순차로 스캔한다 |

## 4. 타이밍 템플릿 (`-T<0-5>`)

원본은 이 표를 "초 단위 간격"으로 잘못 적었다. 아래가 정정한 이름이다 (미검증).

| 옵션 | 이름 | 설명 |
|---|---|---|
| `-T0` | Paranoid | 가장 느리다. 탐지 회피용이며 프로브 간 약 5분 간격이다 |
| `-T1` | Sneaky | 느리다. 프로브 간 약 15초 간격이다 |
| `-T2` | Polite | 대역폭과 대상 부하를 줄인다. 프로브 간 약 0.4초 간격이다 |
| `-T3` | Normal | 기본값 |
| `-T4` | Aggressive | 빠르고 안정적인 네트워크용 |
| `-T5` | Insane | 가장 빠르다. 정확도가 떨어질 수 있다 |

## 5. NSE (Nmap Scripting Engine)

| 항목 | 설명 |
|---|---|
| 스크립트 분류 | auth, default, discovery, exploit, dos, intrusive, vuln 등 |
| `-sC` | 기본(default) 스크립트 실행 |
| `-A` | OS 탐지, 버전 탐지, 기본 스크립트, traceroute를 함께 실행 |
| `--script <이름 또는 분류>` | 지정한 스크립트 실행. 취약점 점검은 `vuln` 분류 또는 `-vuln-`이 들어간 스크립트 이름을 쓴다 |
| Nmap 데이터 경로 | `/usr/share/nmap` |

{% hint style="warning" %}
CAUTION: `exploit`, `dos`, `intrusive` 분류의 스크립트는 대상 서비스를 중단시키거나 변경할 수 있다. 허가받은 대상에서만 실행한다.
{% endhint %}

{% hint style="info" %}
NOTE: 스크립트 유형에 따라 결과가 달라진다. 기본 스캔과 스크립트 스캔을 함께 쓰면 정보가 더 많다.
{% endhint %}

## 6. 방화벽·IDS 회피 관련 옵션

이 옵션은 보안 장비의 탐지를 피하는 데 쓸 수 있다. 원본에 있던 내용을 방어 관점의 탐지 단서와 함께 정리한다.

{% hint style="danger" %}
WARNING: 허가받지 않은 대상에 회피 옵션을 쓰는 것은 불법이다. 허가받은 점검에서 방화벽·IDS의 탐지 능력을 시험할 때만 쓴다.
{% endhint %}

| 옵션 | 설명 | 방어 측 단서 |
|---|---|---|
| `-f` | 패킷을 조각(fragment)으로 나눠 보낸다 | 비정상적으로 작은 IP 조각이 IDS에 잡힌다 |
| `-g <포트>`, `--source-port <포트>` | 출발지 포트를 지정한다 (원본의 "IP 위조"는 정정) | 출발지 포트가 53 등 특정 값에 고정된 다수 연결 |
| `--data-length <수>` | 패킷에 임의 데이터를 덧붙여 길이를 바꾼다 | 스캔 패킷 길이가 표준과 다르다 |
| `--scan-delay <시간>` | 프로브 사이 지연을 둔다 | 느린 스캔은 시간 창을 길게 잡아야 탐지된다 |
| `-D <미끼 IP,...>` | 가짜 출발지 IP(decoy)를 섞는다 | 한 대상에 여러 출발지가 동시에 스캔한다 |

## 7. 탐지·방어

| 항목 | 내용 |
|---|---|
| 원인 | 불필요한 열린 포트와 서비스가 스캔으로 노출된다 |
| 완화 | 불필요한 서비스를 끈다. 방화벽 기본 차단 정책을 쓴다. 외부에서 보이는 포트를 최소화한다 |
| 로그 흔적 | 짧은 시간에 여러 포트로 접속 시도가 이어진다. 방화벽·IDS 로그의 포트 스캔 경보 (미검증) |
