## 1. 개념

현대의 네트워크 통신은 소켓을 통해 이뤄진다. 소켓은 통신의 가장 작은 단위다. 서버는 특정 포트로 서비스를 동작시키고, 클라이언트는 그 프로그램과 통신하려고 `nc`를 쓴다.

{% hint style="info" %}
NOTE: nc는 TCP/UDP 연결을 만들고 읽고 쓰는 범용 네트워크 유틸리티다. 텍스트 통신, 포트 스캔, 포트 포워딩, 리스닝 등에 쓴다.
{% endhint %}

## 2. 설치

```bash
sudo apt update && sudo apt install netcat
```

## 3. 기본 형식

```bash
nc <대상 호스트 또는 IP> <포트>
```

## 4. 주요 옵션

원본의 `nc` 사용법 출력에 나온 옵션 중 자주 쓰는 것만 정리한다. 구현마다 다르므로 `man nc`로 확인한다.

| 옵션 | 설명 |
|---|---|
| `-l` | 접속을 기다리는 리스닝 모드 |
| `-p <포트>` | 출발지 포트 지정 (구현에 따라 리스닝 포트 지정) |
| `-v` | 자세한 출력 |
| `-n` | 이름 조회 없이 숫자 IP만 사용 |
| `-u` | TCP 대신 UDP 사용 |
| `-z` | 데이터를 보내지 않고 열린 포트만 확인 (스캔) |
| `-w <초>` | 연결 제한 시간 |

## 5. 사용 예시

| 상황 | 설명 |
|---|---|
| 워게임 | 웹 서비스형 문제는 브라우저로 접속한다. ELF 바이너리가 서비스로 제공되는 문제는 `nc <서버> <포트>`로 접속해서 푼다 |
| 포트 개방 확인 | 허가받은 대상에서 `nc -zv <대상 IP> <포트>`로 포트가 열려 있는지 확인한다 |

## 6. 탐지·방어

| 항목 | 내용 |
|---|---|
| 위험 | 서버에 `nc`가 설치돼 있으면 공격자가 임의 연결에 쓸 수 있다 |
| 완화 | 서버에서 불필요한 도구를 제거한다. 외부로 나가는 연결을 방화벽으로 제한한다 |
| 로그 흔적 | 낯선 포트의 리스닝 소켓, 비정상 외부 연결이 `ss -tulpn` 등에 나타난다 (미검증) |
