## 1. 목적

IDS(Intrusion Detection System)는 네트워크 또는 호스트에서 일어나는 활동을 감시하다가 공격으로 의심되는 활동을 찾아 알리는 시스템이다. IDS는 탐지와 경고가 목적이며 트래픽을 직접 막지 않는다. 트래픽을 막는 기능까지 갖춘 장비는 IPS(Intrusion Prevention System)라고 한다.

## 2. 구성 요소

### 2.1 감시 위치에 따른 분류

| 구분 | 감시 대상 | 대표 도구 | 관련 문서 |
|---|---|---|---|
| NIDS (Network IDS) | 네트워크 구간을 지나는 패킷 | Snort, Suricata | [Snort](snort.md) (SEC-DEF-005-MP), [Suricata](suricata.md) (SEC-DEF-006-MP) |
| HIDS (Host IDS) | 한 호스트의 파일 변경, 로그, 프로세스 | OSSEC, Wazuh | [HIDS](hids.md) (SEC-DEF-002-MP), [Wazuh](wazuh.md) (SEC-DEF-007-MP) |

### 2.2 탐지 방식

| 방식 | 원리 | 장점 | 단점 |
|---|---|---|---|
| 시그니처(룰) 기반 | 알려진 공격 패턴과 일치하는지 비교한다 | 오탐이 적고 원인을 설명하기 쉽다 | 새로운 공격은 룰이 없으면 탐지하지 못한다 |
| 이상 징후 기반 | 평소 활동에서 벗어난 행위를 찾는다 | 알려지지 않은 공격도 찾을 수 있다 | 오탐이 많고 평소 기준을 먼저 학습해야 한다 |

### 2.3 IDS와 IPS

| 구분 | IDS | IPS |
|---|---|---|
| 동작 | 탐지하고 경고한다 | 탐지하고 차단한다 |
| 배치 | 미러링(SPAN) 포트 또는 탭에 연결한다 | 트래픽 경로 중간에 인라인으로 둔다 |
| 장애 영향 | 장비가 멈춰도 통신은 유지된다 | 오탐이나 장비 장애가 서비스 중단으로 이어질 수 있다 |

## 3. 동작 원리

1. 센서가 감시 구간의 패킷 또는 호스트 로그를 수집한다.
2. 수집한 데이터를 룰과 비교한다.
3. 일치하면 경고(alert)를 만들어 로그에 기록한다.
4. 관리자가 경고를 확인한다. 여러 장비의 경고를 한곳에 모으는 방법은 [SIEM](siem.md) (SEC-DEF-003-DO)을 따른다.

## 4. 약어와 용어

| 용어 | 뜻 |
|---|---|
| IDS | Intrusion Detection System. 침입 탐지 시스템 |
| IPS | Intrusion Prevention System. 침입 방지 시스템 |
| 룰(rule) | 탐지 조건을 적은 한 줄 규칙. 문법은 [Snort 룰 문법](snort-rule.md) (SEC-DEF-004-REF)을 따른다 |
| 오탐(false positive) | 정상 활동을 공격으로 잘못 경고하는 것 |
| 미탐(false negative) | 실제 공격을 경고하지 못하는 것 |
