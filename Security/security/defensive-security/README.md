# [생성형 AI] 방어 보안 (Defensive Security)

방어, 탐지, 대응 관점 자료의 그룹 안내다. 이 폴더의 문서 번호(Task ID)는 `SEC-DFR-<번호>-<유형>` 형식이다. 이 페이지는 안내용이므로 번호를 갖지 않는다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

공격을 막고 탐지하고 대응하는 방어 관점 자료의 입구다. 보안 운영을 처음 접하는 독자는 탐지 개념(IDS, SIEM)을 먼저 읽고 도구 문서와 사고 대응 절차로 이동한다. 이 영역은 개념과 방어 중심이며 공격 절차를 다루지 않는다.

## 핵심 용어

- IDS/IPS: 침입을 탐지(차단)하는 시스템
- SIEM: 여러 로그를 모아 상관 분석하는 시스템
- 로그: 시스템과 네트워크의 이벤트 기록
- 침해사고 대응: 탐지, 격리, 분석, 복구, 재발 방지의 흐름

## 선수 지식

네트워크와 리눅스 기본, 로그를 읽는 경험.

## 하위 그룹

| 그룹 | 용도 |
|---|---|
| [보안 방어 기술 (Defense)](defense/README.md) | IDS, HIDS, SIEM, Snort, Suricata, Wazuh, WAF, 방화벽, 패킷 분석, 침해 분석 문서를 찾는다 |

## 읽는 순서

1. [보안 방어 기술 (Defense)](defense/README.md)에서 필요한 도구나 주제를 고른다.
2. 탐지 개념이 필요하면 [IDS](defense/ids.md), [SIEM](defense/siem.md)부터 읽는다.
3. 침해 사고 대응이 목적이면 [침해사고 분석 및 대응 절차](defense/securityincidentanalysisresponse.md)를 연다.
