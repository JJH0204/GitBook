# 보안 이론 (Theory)

보안 기초 이론 4개 문서의 목차다. 문서 번호(Task ID)는 `SEC-FND-<번호>-<유형>` 형식이다.

## 문서 목록

| Task ID | 유형 | 문서 | 용도 |
|---|---|---|---|
| SEC-FND-001-DO | 개념 | [공개키 암호 시스템 (Public Key)](publickeysystem.md) | 비대칭 암호, 전자서명, 대표 알고리즘을 이해한다 |
| SEC-FND-002-DO | 개념 | [암호화 및 복호화 (Encryption)](encryptionndeencryption.md) | 암호화와 복호화의 기본 개념을 간단한 치환 예제로 이해한다 |
| SEC-FND-003-REF | 표 | [시스템 보안 이론 (System Security)](systemsecurity.md) | 시스템 보안 관련 문서의 위치를 찾는다 |
| SEC-FND-004-DO | 개념 | [AWS 클라우드 보안 (Cloud Security)](awscloudsecurity.md) | AWS 네트워크 격리, 방화벽, 로깅·탐지 서비스를 이해한다 |

## 읽는 순서

1. SEC-FND-002-DO로 암호화와 복호화의 기본 개념을 본다.
2. SEC-FND-001-DO로 공개키 암호와 전자서명을 본다.
3. SEC-FND-004-DO로 클라우드 환경의 보안 구성을 본다.
