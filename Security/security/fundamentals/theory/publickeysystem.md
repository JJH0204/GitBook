## 1. 목적

공개키 암호(비대칭 암호, Asymmetric Encryption)는 서로 다른 두 개의 키, 곧 공개키(public key)와 개인키(private key)를 쓰는 암호 방식이다. 공개키는 누구에게나 공개하고 개인키는 소유자만 보관한다. 미리 비밀 키를 나눠 갖지 않은 상대와도 안전하게 통신하거나 서명을 검증할 수 있다.

## 2. 구성 요소

### 2.1 키 쌍

| 구성 요소 | 공개 범위 | 암호화·복호화 용도 | 서명 용도 |
|---|---|---|---|
| 공개키 (public key) | 누구나 | 데이터를 암호화한다 | 서명을 검증한다 |
| 개인키 (private key) | 소유자만 | 공개키로 암호화된 데이터를 복호화한다 | 서명을 만든다 |

### 2.2 대칭키 암호와 비교

| 항목 | 대칭키 암호 (예: AES) | 공개키 암호 (예: RSA, ECC) |
|---|---|---|
| 키 개수 | 암호화와 복호화에 같은 키 1개 | 키 쌍 2개 |
| 속도 | 빠르다 | 느리다. 대용량 데이터 암호화에 쓰지 않는다 |
| 키 배포 | 비밀 키를 안전하게 전달해야 한다 | 공개키는 공개해도 된다 |
| 키 관리 | 통신 상대마다 비밀 키가 필요하다 | 공개키의 소유자를 보증해야 한다(인증서, PKI) |
| 전자서명 | 해당 없음 | 지원 |

### 2.3 대표 알고리즘

| 알고리즘 | 용도 | 특징 |
|---|---|---|
| RSA | 암호화, 서명 | 가장 널리 쓰는 알고리즘이다. 큰 수의 소인수분해가 어렵다는 점에 기반한다. 키 길이는 2048비트 이상을 권장한다 |
| ECC (타원 곡선 암호) | 암호화, 서명, 키 교환 | 타원 곡선 위의 이산 로그 문제에 기반한다. RSA보다 짧은 키로 비슷한 안전 수준을 제공한다(예: ECC 256비트는 RSA 3072비트와 비슷한 수준) |
| DSA | 서명 | 서명 전용 알고리즘이다. 암호화에는 쓰지 않는다. 타원 곡선 버전은 ECDSA다 |
| Diffie-Hellman (DH) | 키 교환 | 두 당사자가 공개 채널로 공유 비밀 값을 만드는 알고리즘이다. 데이터를 암호화하거나 서명하지는 않는다 |

## 3. 동작 원리

### 3.1 암호화와 복호화(기밀성)

1. 송신자가 수신자의 공개키로 데이터를 암호화한다.
2. 암호화된 데이터를 전송한다.
3. 수신자가 자신의 개인키로 복호화한다.
4. 개인키는 외부에 전달하지 않는다. 공개키만으로는 복호화할 수 없다.

### 3.2 전자서명(무결성, 인증, 부인 방지)

1. 송신자가 원문의 해시(예: SHA-256)를 계산한다.
2. 송신자가 해시 값을 자신의 개인키로 서명한다.
3. 원문과 서명을 함께 전송한다.
4. 수신자가 같은 해시 함수로 원문의 해시를 계산한다.
5. 수신자가 송신자의 공개키로 서명을 검증해 얻은 해시와 4번의 해시를 비교한다.
6. 두 값이 같으면 원문이 변조되지 않았고 서명자가 개인키 소유자임이 확인된다.

{% hint style="info" %}
NOTE: 전자서명은 "개인키로 서명하고 공개키로 검증"한다. 암호화는 "공개키로 암호화하고 개인키로 복호화"한다. 두 방향을 혼동하지 않는다.
{% endhint %}

### 3.3 하이브리드 방식

공개키 암호는 느리므로 실제 통신(HTTPS의 TLS 등)은 다음 순서로 둘을 섞어 쓴다.

1. 공개키 방식(또는 DH, ECDH 키 교환)으로 세션 키를 안전하게 합의한다.
2. 합의한 세션 키로 대칭키 암호(예: AES)를 사용해 실제 데이터를 암호화한다.

### 3.4 활용 예시

| 활용 | 설명 |
|---|---|
| HTTPS(TLS) | 서버 인증서로 서버를 인증하고 세션 키를 합의한다. 관련: [SSL 및 TLS 프로토콜](../../../../Network/security/ssl.md) |
| 전자서명·인증서 | 인증기관(CA)이 서버·사용자의 공개키에 서명해 소유자를 보증한다 |

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 대칭키 | 암호화와 복호화에 같은 키를 쓰는 방식의 키 |
| 해시(hash) | 임의 길이 입력을 고정 길이 값으로 바꾸는 일방향 함수. 복호화할 수 없다. 암호화와 다르다 |
| PKI | 공개키 기반 구조. 인증서의 발급·검증·폐기를 다룬다 |
| CA | 인증기관. 공개키 소유자를 보증하는 인증서를 발급한다 |
| ECC | Elliptic Curve Cryptography, 타원 곡선 암호 |
