## 1. 목적

암호화(encryption)는 읽을 수 있는 평문(plaintext)을 키(key)를 이용해 읽을 수 없는 암호문(ciphertext)으로 바꾸는 일이다. 복호화(decryption)는 올바른 키로 암호문을 평문으로 되돌리는 일이다. 이 문서는 문자 하나하나에 약속된 값을 적용하는 가장 단순한 치환 방식으로 두 과정을 보인다.

## 2. 구성 요소

### 2.1 기본 용어

| 용어 | 뜻 | 예제에서의 대응 |
|---|---|---|
| 평문 | 암호화 전 원본 | `q1w2e3r4` |
| 암호문 | 암호화 후 결과 | 각 문자 코드에 9를 곱한 문자열 |
| 키 | 변환에 쓰는 비밀 값 | 곱하는 값 `9` |
| 알고리즘 | 변환 규칙 | 문자 코드 × 9, 복호화는 ÷ 9 |

### 2.2 암호화와 해시의 차이

| 구분 | 암호화 | 해시 |
|---|---|---|
| 방향 | 양방향(키가 있으면 복호화 가능) | 일방향(원문 복원 불가) |
| 출력 길이 | 입력 길이에 비례 | 고정 길이 |
| 용도 | 기밀성 | 무결성 확인, 비밀번호 저장(솔트와 느린 해시 함수와 함께) |
| 예 | AES, RSA | SHA-256 |

### 2.3 실제로 쓰는 알고리즘

| 알고리즘 | 종류 | 상태 |
|---|---|---|
| AES | 대칭키 블록 암호 | 키 길이 128, 192, 256비트. 현재 표준이다 |
| DES | 대칭키 블록 암호 | 키 길이 56비트. 전수 조사로 깰 수 있어 쓰지 않는다 |
| RSA, ECC | 공개키 암호 | [공개키 암호 시스템 (Public Key)](publickeysystem.md) 참조 |
| MD5, SHA-1 | 해시 | 충돌이 찾아져 보안 용도로 쓰지 않는다 |
| SHA-256 | 해시 | SHA-2 계열. 현재 널리 쓴다 |

## 3. 동작 원리

### 3.1 문자 코드 곱셈 예제(원본)

원리는 다음 순서다.

1. 문자의 코드 값을 구한다(`ord()`).
2. 코드 값에 약속된 값 9를 곱한다.
3. 결과 값을 문자로 바꾼다(`chr()`). 이것이 암호문이다.
4. 복호화는 암호문 각 문자의 코드 값을 9로 나눈 몫으로 되돌린다(`//`).

```python
# 암호화 예제

print(chr(ord('A') * 9))

pw = "q1w2e3r4"

en_pw = ""

for i in pw:
    en_pw += chr(ord(i) * 9)

print("기존 비밀번호: %s" %pw)
print("암호화된 비밀번호: {pw}".format(pw=en_pw))

# 복호화 예제

de_pw = ""

for i in en_pw:
    de_pw += chr(ord(i) // 9) # // : 몫 연산자

print("암호화 해제된 비밀번호: {pw}".format(pw=de_pw))
```

출력 예시:

```
기존 비밀번호: q1w2e3r4
암호화된 비밀번호: ϹƹЯǂ΍ǋЂǔ
암호화 해제된 비밀번호: q1w2e3r4
```

### 3.2 입력값 암호화 예제(원본)

`input()`으로 받은 문자열의 각 문자 코드에 3을 곱하고 1을 더한다.

```python
# 입력 함수: input("출력할 메시지")

inputData = input("비밀번호: ")

temp = ""

for i in inputData:
    temp += chr(ord(i) * 3 + 1)

print("현재 비밀번호: {pw}\n암호화 후: {en_pw}".format(pw = inputData, en_pw = temp))
```

{% hint style="warning" %}
CAUTION: 위 예제는 학습용이다. 곱셈 값을 알면(또는 추측하면) 누구나 복호화할 수 있으며, 실제 비밀번호 보호에 쓰면 안 된다. 실제 시스템은 검증된 알고리즘(AES 등)을 쓰고, 비밀번호는 암호화가 아니라 솔트를 넣은 느린 해시로 저장한다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| ASCII | 문자를 숫자 코드로 대응시킨 표. `ord()`는 문자를 코드 값으로, `chr()`는 코드 값을 문자로 바꾼다 |
| 대칭키 암호 | 암호화와 복호화에 같은 키를 쓴다 |
| 솔트(salt) | 해시 전에 비밀번호에 덧붙이는 무작위 값 |
