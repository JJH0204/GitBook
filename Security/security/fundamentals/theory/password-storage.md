## 1. 목적

데이터베이스가 유출되어도 비밀번호가 곧바로 노출되지 않게 저장하는 방법을 정리한다. 이는 [무차별 대입 공격](../../offensive-security/pentest/brute-force/README.md) 중 오프라인 크래킹에 대한 핵심 방어다.

## 2. 구성 요소

### 2.1 저장 방식 비교

| 방식 | 평가 | 이유 |
|---|---|---|
| 평문 저장 | 금지 | 유출되면 그대로 쓸 수 있다 |
| 가역 암호화 | 부적절 | 키가 유출되면 모두 복호화된다. 서비스가 원문을 알 필요가 없다 |
| 빠른 해시(MD5, SHA-1, SHA-256 단독) | 부적절 | 계산이 너무 빨라 대량 시도가 쉽다. 같은 비밀번호는 같은 해시가 된다 |
| 솔트를 더한 빠른 해시 | 미흡 | 사전 계산 표는 막지만 계산 속도가 빠른 문제는 남는다 |
| 비밀번호 전용 해시(KDF) | 권장 | 의도적으로 느리고 메모리를 쓰며 솔트가 내장된다 |

### 2.2 비밀번호 전용 해시

| 알고리즘 | 특징 | 비고 |
|---|---|---|
| Argon2id | 시간, 메모리, 병렬도를 조절한다. 메모리 요구로 전용 하드웨어 공격을 어렵게 한다 | 새 시스템에서 우선 고려한다 |
| scrypt | 메모리 사용량으로 비용을 올린다 | 파이썬 표준 라이브러리에서 지원한다 |
| bcrypt | 비용 인자로 반복을 조절한다 | 입력이 72바이트까지만 반영된다 |
| PBKDF2 | 반복 횟수로 비용을 올린다 | 표준 규격과 호환성이 필요할 때 쓴다 |

매개변수는 장비 성능과 로그인 지연 허용치에 맞춰 정한다. OWASP Password Storage Cheat Sheet는 PBKDF2-HMAC-SHA256에 반복 600,000회, Argon2id에 메모리 19 MiB 이상·반복 2회·병렬도 1을 최소 기준으로 제시한 것으로 알고 있다(미검증, 개정될 수 있으므로 최신 문서를 확인한다).

### 2.3 보조 개념

| 개념 | 뜻 |
|---|---|
| 솔트(salt) | 사용자마다 다른 무작위 값. 같은 비밀번호가 같은 해시가 되지 않게 하고 사전 계산 표를 무력화한다. 해시와 함께 저장해도 된다 |
| 페퍼(pepper) | 모든 사용자에게 쓰는 비밀 값. 데이터베이스 밖(별도 키 저장소)에 둔다 |
| 상수 시간 비교 | 해시 비교 시간이 일치 길이에 따라 달라지지 않게 하는 비교 |

## 3. 동작 원리

1. 가입 시 무작위 솔트를 만든다.
2. 비밀번호와 솔트를 비밀번호 전용 해시에 넣어 결과를 얻는다.
3. 알고리즘, 매개변수, 솔트, 해시를 함께 저장한다.
4. 로그인 시 같은 매개변수로 입력값을 계산하고 상수 시간 비교로 대조한다.
5. 일치하면 인증 성공이다. 매개변수가 낡았으면 이 시점에 새 매개변수로 다시 저장한다.

## 4. 예시 (방어 구현)

파이썬 표준 라이브러리로 PBKDF2 해시를 만들고 비교하는 예시다.

```python
import hashlib, hmac, os

salt = os.urandom(16)
stored = hashlib.pbkdf2_hmac("sha256", "<비밀번호>".encode(), salt, 600000)
ok = hmac.compare_digest(
    stored,
    hashlib.pbkdf2_hmac("sha256", "<입력값>".encode(), salt, 600000),
)
```

`hashlib.pbkdf2_hmac`이 32바이트 값을 돌려주고 동일 입력의 비교가 참이 되는 것을 확인했다. 실제 서비스에서는 검증된 라이브러리의 Argon2id나 bcrypt를 쓴다.

## 5. 정책과 운영

| 항목 | 권고 |
|---|---|
| 길이 | 복잡한 조합 규칙보다 충분한 길이를 우선한다 |
| 유출 비밀번호 | 가입·변경 시 유출 목록에 있는 비밀번호를 거절한다 |
| 변경 주기 | 침해 증거가 없는 정기 강제 변경은 권장하지 않는다 (NIST SP 800-63B 취지, 미검증) |
| 다중 인증 | 비밀번호가 유출되어도 로그인을 막는다 |
| 유출 사고 | 해시 유출이 의심되면 사용자 비밀번호를 강제 초기화하고 알린다 |
