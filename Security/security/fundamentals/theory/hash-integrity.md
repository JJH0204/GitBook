## 1. 목적

해시 함수는 임의 길이의 입력을 고정 길이 값(다이제스트)으로 바꾸는 단방향 함수다. 파일이 변조되지 않았는지 확인하는 무결성 검증의 기본 도구다. 비밀번호 저장에 쓰는 방법은 [패스워드 저장과 해시 방어](password-storage.md)에 따로 있다.

## 2. 구성 요소

### 2.1 암호학적 해시의 성질

| 성질 | 뜻 |
|---|---|
| 결정성 | 같은 입력은 항상 같은 출력이다 |
| 단방향성 | 출력에서 입력을 되짚기 어렵다 |
| 충돌 저항성 | 같은 출력을 내는 서로 다른 입력을 찾기 어렵다 |
| 눈사태 효과 | 입력이 1비트만 달라도 출력이 크게 달라진다 |

### 2.2 알고리즘 상태

| 알고리즘 | 출력 길이 | 상태 |
|---|---|---|
| MD5 | 128비트 | 충돌이 공개적으로 만들어졌다. 보안 용도에 쓰지 않는다 |
| SHA-1 | 160비트 | 충돌이 실증되었다. 보안 용도에 쓰지 않는다 |
| SHA-256, SHA-512 (SHA-2) | 256, 512비트 | 현재 널리 쓰인다 |
| SHA-3 | 가변 | SHA-2와 다른 구조의 대안이다 |

### 2.3 해시, MAC, 전자서명

| 방식 | 키 | 보장 |
|---|---|---|
| 해시 | 없음 | 내용이 바뀌었는지 안다. 누가 만들었는지는 모른다 |
| MAC(HMAC) | 공유 비밀키 | 변조 탐지와 키 소유자 확인 |
| 전자서명 | 개인키와 공개키 | 변조 탐지, 작성자 확인, 부인 방지. [공개키 암호 시스템](publickeysystem.md) 참조 |

해시만으로는 해시 값 자체를 공격자가 함께 바꾸면 변조를 알 수 없다. 그래서 해시 값은 별도의 신뢰 경로(공식 사이트, 서명)로 받는다.

## 3. 눈사태 효과 확인

```python
import hashlib
print(hashlib.sha256(b"hello").hexdigest())
print(hashlib.sha256(b"hellp").hexdigest())
```

→ 결과: 두 줄의 64자리 16진수가 전혀 다르게 출력된다. `hello`의 값은 `2cf24dba...b9824`로 시작·끝난다.

```bash
echo -n hello | sha256sum
```

→ 결과: 위 `hello`와 같은 값이 출력된다. `-n`을 빼면 줄바꿈이 포함되어 값이 달라진다.

## 4. 무결성 점검 사용처와 방어

| 사용처 | 방법 | 주의 |
|---|---|---|
| 내려받은 파일 확인 | 배포처가 공개한 SHA-256과 `sha256sum <파일>` 결과 비교 | 해시를 같은 서버에서 받으면 신뢰가 약하다 |
| 파일 변조 탐지(FIM) | 중요 파일 해시를 기준선으로 저장하고 주기 비교 | 기준선 자체를 보호한다. [HIDS](../../defensive-security/defense/hids.md) 참조 |
| 로그 무결성 | 로그를 별도 서버로 전송하고 해시·서명을 남긴다 | 공격자는 침투 후 로컬 로그를 지울 수 있다 |
| 메시지 인증 | HMAC 사용 | 키 관리가 핵심이다 |

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| 다이제스트 | 해시 함수의 출력 값 |
| 충돌 | 서로 다른 입력이 같은 해시를 내는 경우 |
| 레인보 테이블 | 해시를 미리 계산해 둔 표. 솔트로 무력화한다 |
| FIM | 파일 무결성 점검 |
