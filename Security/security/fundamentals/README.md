# 보안 기초 (Fundamentals)

보안 기초 이론 문서의 목차다. 문서 번호(Task ID)는 `SEC-FND-<번호>-<유형>` 형식이다. 이 그룹의 문서는 하위 그룹 [보안 이론 (Theory)](theory/README.md)에 있다.

## 문서 목록

| 그룹 | 내용 | 링크 |
|---|---|---|
| 보안 이론 | 공개키 암호, 암호화·복호화, 시스템 보안, AWS 클라우드 보안 | [보안 이론 (Theory)](theory/README.md) |

## 읽는 순서

1. [보안 이론 (Theory)](theory/README.md)에서 주제를 고른다.
2. 암호 개념은 SEC-FND-001-DO, SEC-FND-002-DO 순서로 읽는다.
