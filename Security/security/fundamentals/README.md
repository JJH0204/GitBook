# [생성형 AI] 보안 기초 (Fundamentals)

보안 기초 이론 문서의 목차다. 문서 번호(Task ID)는 `SEC-FND-<번호>-<유형>` 형식이다. 이 그룹의 문서는 하위 그룹 [보안 이론 (Theory)](theory/README.md)에 있다.

## 작업 식별

| 항목 | 내용 |
|---|---|
| 유형 | 그룹 안내 (번호 없음) |
| 작성 | 생성형 AI 초안 (사람 검토 전) |
| 확인 상태 | 미검증 (이 환경에서 실행하지 않았고 링크된 문서의 존재만 확인했다) |
| 개정 | R2 (2026-11-19) |

## 이 영역의 소개

보안 이론의 출발점이다. 보안을 처음 공부하는 독자는 이 그룹에서 암호와 원칙을 익힌 뒤 방어, 웹, 악성코드 등 응용 그룹으로 간다. 세부 문서는 하위 그룹 보안 이론(Theory)에 있다.

## 핵심 용어

- 기밀성, 무결성, 가용성(CIA): 보안의 세 목표
- 대칭키, 공개키: 암호 방식의 두 갈래
- 해시: 임의 길이 입력을 고정 길이 값으로 바꾸는 단방향 함수
- 위협 모델링: 위협을 식별하고 대응을 설계하는 작업

## 선수 지식

컴퓨터와 네트워크의 기본 개념.
