## 1. 목적

메모리 결함([BOF](bof.md), [포맷 스트링](formatstringattack.md) 등)이 코드에 남아 있어도 악용이 어렵게 만드는 다층 방어를 정리한다. 가장 좋은 대책은 결함을 코드에서 없애는 것이며, 이 보호 기법은 그 뒤의 안전망이다.

## 2. 구성 요소

| 보호 기법 | 막는 것 | 방식 | 한계 |
|---|---|---|---|
| NX / DEP | 데이터 영역(스택, 힙)에서 코드 실행 | 메모리 쪽에 실행 권한을 주지 않는다 | 이미 있는 코드를 재사용하는 공격은 막지 못한다 |
| ASLR | 주소를 알아야 하는 공격 | 스택, 힙, 라이브러리 위치를 실행마다 무작위로 바꾼다 | 주소 정보가 노출되면 효과가 줄어든다 |
| PIE | 실행 파일 자체의 위치 예측 | 실행 파일을 위치 독립 코드로 만들어 ASLR이 적용되게 한다 | 마찬가지로 주소 노출에 약하다 |
| 스택 카나리 | 스택 버퍼 오버플로우 | 반환 주소 앞에 무작위 값을 두고 함수 종료 시 변조 여부를 검사한다 | 카나리 값 노출이나 반환 주소를 건드리지 않는 결함에는 소용없다 |
| RELRO | 전역 오프셋 테이블(GOT) 덮어쓰기 | 재배치 후 해당 영역을 읽기 전용으로 만든다. 전체(Full) RELRO는 시작 시 모든 심볼을 바인딩한다 | 시작 시간이 약간 늘어난다 |
| FORTIFY_SOURCE | 일부 문자열·메모리 함수의 범위 초과 | 컴파일 시 위험 함수를 길이 검사 버전으로 바꾼다 | 컴파일러 최적화(`-O`)가 필요하며 모든 호출을 보호하지는 않는다 |

{% hint style="info" %}
NOTE: 표의 "한계" 열은 방어 설계 시 한 가지 기법에 의존하지 말라는 근거다. 보호 기법을 우회하는 절차는 이 저장소에 쓰지 않는다.
{% endhint %}

## 3. 동작 원리와 확인 방법

### 3.1 ASLR 설정값

Linux에서 커널의 ASLR 설정은 `/proc/sys/kernel/randomize_va_space` 파일로 읽는다.

| 값 | 의미 |
|---|---|
| 0 | 끔 |
| 1 | 스택, 라이브러리 등을 무작위화 |
| 2 | 1에 더해 힙(brk 영역)도 무작위화 (대부분 배포판 기본값) |

`cat /proc/sys/kernel/randomize_va_space`를 실행하면 현재 값을 읽는다. 실습 환경(Ubuntu)에서 `2`를 확인했다. 실습 외 환경에서 이 값을 바꾸지 않는다.

### 3.2 컴파일 옵션과 결과 확인

보호를 켜는 GCC 옵션 예시다.

```
gcc -O2 -fstack-protector-strong -D_FORTIFY_SOURCE=2 -fPIE -pie -Wl,-z,relro,-z,now <소스 파일> -o <출력 파일>
```

생성한 실행 파일은 `readelf`로 확인한다.

| 확인 명령 | 보호 기법 | 기대 결과 |
|---|---|---|
| `readelf -h <파일>` | PIE | `Type`이 `DYN` |
| `readelf -lW <파일>` | NX, RELRO | `GNU_STACK`의 권한이 `RW`(실행 `E` 없음), `GNU_RELRO` 항목 존재 |
| `readelf -dW <파일>` | 전체 RELRO | `FLAGS`에 `BIND_NOW` |
| `readelf -sW <파일>` | 카나리 | `__stack_chk_fail` 심볼 존재 |

위 옵션으로 빌드한 단순 프로그램에서 `Type: DYN`, `GNU_STACK ... RW`, `GNU_RELRO` 항목, `BIND_NOW`를 확인했다. 그 프로그램은 위험한 지역 버퍼가 없어 `__stack_chk_fail` 심볼은 나타나지 않았다. 카나리는 컴파일러가 보호가 필요하다고 판단한 함수에만 들어간다. 배포판 컴파일러는 이 옵션 일부를 기본으로 켜기도 하므로 옵션 없이도 결과가 같을 수 있다.

## 4. 약어와 용어

| 용어 | 뜻 |
|---|---|
| NX | No-eXecute. 실행 불가 메모리 |
| DEP | Data Execution Prevention. Windows의 NX 구현 명칭 |
| ASLR | Address Space Layout Randomization |
| PIE | Position Independent Executable |
| RELRO | RELocation Read-Only |
| GOT | Global Offset Table. 동적 라이브러리 함수 주소 표 |
