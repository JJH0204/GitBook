## 개요

두 번째 달의 첫날이다. 첫 달에 회사 안의 길을 모두 만들었으니, 오늘은 회사를 바깥 세상과 잇는다. 직원은 PAT로 인터넷에 나가고, 고객은 포트 포워딩으로 쇼핑몰에 들어온다.

길을 여는 날이라 보안의 질문도 바뀐다. NAT는 주소를 숨기지만 막지는 않는다. 오늘 연 문이 새봄상사의 공격 표면이 되고, 이 문은 14일차의 사고 03으로 돌아온다. 그리고 오늘 두 번째 달의 침해사고 분석 보고서를 소개한다.

## 학습 목표

- 사설 주소와 공인 주소, NAT의 세 가지를 안다.
- PAT로 본사와 지사를 인터넷에 내보내고 변환 표를 읽는다.
- 1:1 정적 NAT가 서버의 모든 문을 연다는 것을 보고, 포트 포워딩으로 필요한 포트만 연다.
- 밖에서 보이는 회사의 모습(공격 표면)을 확인하고 공개 서비스 목록을 쓴다.
- 두 번째 달의 침해사고 분석 보고서가 무엇인지 안다.

### 새봄상사 9일차 작업 계획서

#### 1. 목표

- 본사와 지사 직원이 인터넷에 나갈 수 있게 한다.
- 계획서 3번 칸 "쇼핑몰은 누구나 접속한다. 그 밖의 서버는 밖에서 보이지 않아야 한다"를 설정으로 옮긴다.

#### 2. 작업 대상

| 대상 | 무엇을 |
|---|---|
| ISP-R1, NET-PC (새로) | 인터넷 쪽 장비. 모든 학생이 같은 주소 |
| HQ-R1 | Se0/0/1 인터넷 회선, 기본 경로, null 경로 두 줄, OSPF로 기본 경로 알리기, PAT, 포트 포워딩 |
| `02_설계/공개_서비스.md` (새로) | 연 문과 열지 않기로 한 문 |
| `03_구축/인터넷_연결.md` (새로) | 구성, NAT, 시험, 남은 위험 |

#### 3. 작업 내용

1. ISP-R1과 NET-PC를 놓고 HQ-R1 Se0/0/1과 잇는다.
2. 기본 경로와 null 경로를 넣고, OSPF로 지사에 기본 경로를 알린다.
3. 본사와 지사 대역을 PAT로 내보낸다. inside는 일곱 곳, outside는 하나다.
4. 쇼핑몰의 80, 443번만 203.0.113.10으로 포워딩한다.
5. 밖에서 쇼핑몰, FTP, ping, tracert를 확인한다.

#### 4. 확인 방법

| 확인할 것 | 방법 | 기대하는 결과 |
|---|---|---|
| 지사가 기본 경로를 안다 | BR-R1 `show ip route ospf` | `O*E2 0.0.0.0/0` |
| 직원이 나간다 | Sales-PC1, BR-PC1에서 `ping 198.51.100.10` | Reply |
| PAT로 바뀐다 | `show ip nat translations` | Inside global 203.0.113.2 |
| 고객이 쇼핑몰에 들어온다 | NET-PC 웹 브라우저 `http://203.0.113.10` | 쇼핑몰 화면 |
| 쇼핑몰 말고는 닫혀 있다 | NET-PC에서 `ftp 203.0.113.10` | 연결되지 않음 |
| 안쪽 주소가 안 보인다 | NET-PC에서 `tracert 203.0.113.10` | 192.168. 주소가 없음 |

#### 5. 되돌리는 방법

- NAT가 꼬이면 지우는 순서를 지킨다: `ip nat inside source` 줄, 포트의 `ip nat inside`/`outside`, ACL 순으로 지운다.
- 기본 경로 때문에 회사 안 통신이 이상하면 `show ip route`에서 null 경로와 기본 경로를 함께 본다.
- 인터넷 연결 전체를 끊어야 하면 HQ-R1 Se0/0/1을 `shutdown`한다. 회사 안 통신은 그대로다.

#### 6. 결과 (개인 실습이 끝날 때 채운다)

- 막힌 곳과 어떻게 풀었나:

## 수업 전에 확인할 것

- 패킷트레이서가 이름 붙인 표준 ACL을 NAT에 받는지(`ip nat inside source list NAT-INSIDE ...`). 안 되면 번호 ACL로 대본을 바꾼다.
- `ip nat inside source static tcp ...` 포트 포워딩과 `default-information originate`가 되는지.
- Server-PT에 FTP가 기본으로 켜져 있는지, 기본 계정(사용자 이름 `cisco`, 비밀번호 `<password>`)이 들어 있는지(3번 노트 시연).
- NET-PC의 tracert 3번째 줄에 무엇이 보이는지(답 없음, 또는 HQ-R1의 "닿을 수 없음").
- `show running-config | include nat`이 되는지(3번 노트 진행 요령).
- 강사 레퍼런스 저장소에 새봄상사의 9일차 작업 계획서, 인터넷 연결 기록, 공개 서비스 목록, 설정 두 개가 미리 커밋되어 있는지.
