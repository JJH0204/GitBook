# 2일차 주소 설계와 장비 접근 보안

> 상위: [네트워크 보안 강의계획서](../plan.md)
> 이전: [1일차 프로젝트 시작](../day-01/README.md)
> 다음: [3일차 스위칭과 VLAN](../day-03/README.md)

1일차에 새봄상사의 계획서에 이렇게 적었다. "부서마다 네트워크를 나눈다. 영업팀과 인사팀은 서로 통신할 일이 없다." 오늘은 이 문장을 처음으로 실제 설계로 바꾼다. 네트워크를 나누려면 먼저 주소를 나눠야 한다.

오늘이 끝나면 저장소에 세 가지가 더해진다. 첫 작업 계획서, 회사의 IP 주소 설계표, 그리고 처음 설정한 본사 라우터의 설정 파일이다. 라우터에는 들어오는 문이 세 개 있고, 오늘 그 문마다 잠금을 건다.

## 오늘 답할 질문

| 질문 | 오늘의 답 | 노트 |
|---|---|---|
| 데이터는 어떤 순서로 길을 가나? | 일곱 계층을 거치며 상자에 담기고 다시 풀린다 | 1 |
| 빨리 보낼까, 확실히 보낼까? | 확실히는 TCP, 빨리는 UDP. 서비스는 포트 번호로 구분한다 | 1 |
| 주소는 어떻게 생겼나? | 32비트를 네 칸으로 나눈 숫자. 마스크가 네트워크와 호스트를 가른다 | 2 |
| 부서마다 네트워크를 어떻게 나누나? | 마스크의 0을 1로 바꿔 쪼갠다(서브네팅) | 3 |
| 장비에는 누가 들어올 수 있나? | 콘솔, 원격, 관리자 모드의 세 문에 각각 잠금을 건다 | 4 |

## 학습 목표

- 오늘 할 일을 작업 계획서로 쓰고, 끝날 때 결과를 기록한다.
- OSI 7계층과 캡슐화를 택배에 빗대어 설명한다.
- TCP와 UDP의 차이, 포트 번호의 역할을 안다.
- 주소와 마스크로 네트워크 주소, 쓸 수 있는 주소, 브로드캐스트 주소를 구한다.
- 내 회사의 주소 설계표를 만든다.
- 시스코 라우터에 접근 보안을 설정하고, 설정을 저장해 커밋한다.

3. 17:45가 되어도 커밋이 없는 학생. 결과 칸이 비어 있어도 먼저 커밋하게 한다.

## 그림 목록

발표용 Excalidraw 그림이다. 프레임 하나가 슬라이드 한 장이고, Slideshow 스크립트가 프레임 이름의 번호 순서대로 넘긴다. 그림 파일은 이 저장소에 없다. 노트마다 끝의 그림 목록 절에 장과 절의 대응표가 있다.

| 노트 | 그림 | 장 수 | 교실에서 채울 캡처 자리 |
|---|---|---|---|
| README | 하루와 작업 계획서 | 2 | 없음 |
| 1 | 1. 계층과 TCP, UDP | 12 | 없음 |
| 2 | 2. IP 주소와 서브넷 마스크 | 11 | 없음 |

명령 출력(`ipconfig`, `netstat`, `git log`, `show` 명령, 텔넷)은 캡처 대신 글자로 넣었다. 교실 PC의 실제 화면과 값이 다르면 그 자리에서 고친다.

## 수업 전에 확인할 것

- 교실 PC의 패킷트레이서가 열리고 Cisco Networking Academy 로그인이 되는지
- 패킷트레이서 CLI 탭 아래의 Copy 버튼으로 설정 텍스트를 복사할 수 있는지, `terminal length 0`이 받아들여지는지
- 패킷트레이서 PC의 Command Prompt에서 `telnet`이 되는지, 다른 대역 실험의 답이 `Destination host unreachable`로 나오는지
- 1일차 끝에 자격 증명을 지운 PC라면 오늘 첫 push에서 로그인 창이 다시 뜨는지
- 강사 레퍼런스 저장소에 새봄상사의 2일차 작업 계획서, 설계표, HQ-R1 설정이 미리 커밋되어 있는지
