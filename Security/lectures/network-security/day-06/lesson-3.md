## 1. RIP과 그 흔적 걷어 내기

`no router rip`은 RIP 설정 덩어리를 지운다. 그런데 5일차에 포트마다 건 `ip rip authentication` 줄과 열쇠고리(key chain)는 포트와 장비 설정에 남는다. 남겨 둬도 동작에는 문제가 없지만, 설정 텍스트에 쓰지 않는 줄이 남으면 나중에 읽는 사람이 헷갈린다. 함께 지운다.

예비 정적 경로(관리 거리 250)도 지운다. OSPF는 예비 회선을 비용 64로 보고 스스로 예비로 쓰므로, 따로 예비 경로를 둘 이유가 없다.

| 지우는 것 | 이유 |
|---|---|
| `router rip` | OSPF로 바꾼다 |
| 포트의 `ip rip authentication` 줄, `key chain RIPKEY` | RIP의 흔적 |
| 예비 정적 경로 | OSPF가 예비 회선을 비용으로 다룬다 |

## 2. 루프백과 라우터 ID

```
interface loopback 0
 ip address 192.168.255.1 255.255.255.255
router ospf 1
 router-id 192.168.255.1
```

루프백 0에 /32 주소를 주고, `router-id`로 같은 값을 못 박는다. `router ospf 1`의 1은 이 라우터 안에서 OSPF 묶음을 구분하는 번호(프로세스 ID)일 뿐이라 상대 라우터와 같지 않아도 된다. 이 과목은 1로 통일한다.

## 3. 와일드카드 마스크와 network

OSPF의 `network`는 RIP과 달리 범위를 와일드카드 마스크로 정하고, 에어리어를 함께 적는다.

```
network 192.168.10.0 0.0.0.255 area 0
```

와일드카드 마스크는 서브넷 마스크를 뒤집은 모양이다. 0인 자리는 "반드시 같아야 함", 1인 자리는 "아무거나 됨"이다.

| 고르고 싶은 것 | 서브넷 마스크 | 와일드카드 마스크 |
|---|---|---|
| 192.168.10.0/24 전체 | 255.255.255.0 | 0.0.0.255 |
| 192.168.99.0 ~ .7 (/30 두 개) | 255.255.255.248 | 0.0.0.7 |
| 192.168.255.1 한 주소 | 255.255.255.255 | 0.0.0.0 |

255에서 서브넷 마스크의 각 칸을 빼면 와일드카드 마스크가 된다. 255 - 248 = 7이다.

`network`는 RIP처럼 이 범위에 주소가 있는 포트에서 OSPF를 켠다. 새봄상사 본사는 세 줄이다.

```
router ospf 1
 network 192.168.10.0 0.0.0.255 area 0
 network 192.168.99.0 0.0.0.7 area 0
 network 192.168.255.1 0.0.0.0 area 0
```

{% hint style="info" %}
NOTE: 10일차 ACL은 막을 범위를 이 와일드카드 마스크로 적는다. 오늘 익혀 두면 10일차가 쉬워진다.
{% endhint %}

## 4. 확인

이웃부터 본다.

```
HQ-R1#show ip ospf neighbor

Neighbor ID     Pri   State           Dead Time   Address         Interface
192.168.255.2     1   FULL/DR         00:00:35    192.168.99.2    GigabitEthernet0/1
192.168.255.2     0   FULL/  -        00:00:33    192.168.99.6    Serial0/0/0
```

| 칸 | 읽는 법 |
|---|---|
| Neighbor ID | 이웃의 라우터 ID. 지사 라우터의 루프백 |
| State FULL/DR | 이웃 맺기가 끝났고, 이 구간에서 상대가 대표(DR) |
| FULL/ - | 1대1 구간이라 대표가 없다 |
| Dead Time | 이 시간 안에 hello가 다시 와야 한다. 40초에서 줄어든다 |

이웃 한 라우터와 두 구간(주 회선, 예비 회선)으로 이웃이 되었다. 경로를 본다.

```
HQ-R1#show ip route ospf
O       192.168.20.0/27 [110/2] via 192.168.99.2, 00:01:12, GigabitEthernet0/1
O       192.168.255.2/32 [110/2] via 192.168.99.2, 00:01:12, GigabitEthernet0/1
```

`[110/2]`는 관리 거리 110, 비용 2다. 5일차 RIP과 달리 길이 하나뿐이다. 예비 회선 쪽은 비용이 65라 표에 오르지 않는다.

## 5. 창고 네트워크가 /32로 보인다

5일차에 지사 루프백 1로 만든 창고 네트워크(192.168.20.32/27)가 본사 경로표에 /27이 아니라 `192.168.20.33/32`로 보인다. OSPF는 루프백을 늘 한 주소짜리(/32)로 알리기 때문이다. 루프백으로 네트워크를 흉내 낼 때는, 마스크대로 알리라고 알려 준다.

```
BR-R1(config)#interface loopback 1
BR-R1(config-if)#ip ospf network point-to-point
```

잠시 뒤 본사에 `O 192.168.20.32/27`이 보인다. 같은 루프백이라도 RIP과 OSPF가 다르게 다룬다는 것을 기록에 적어 둔다.

## 6. 장애 시험

4일차, 5일차와 같은 시험이다. 지사 PC에서 `ping -t`를 걸고 본사 Gi0/1을 끈다.

| 시점 | 본사 경로표 |
|---|---|
| 끄기 전 | `O 192.168.20.0/27 [110/2] via 192.168.99.2, Gi0/1` |
| 끈 뒤 | `O 192.168.20.0/27 [110/65] via 192.168.99.6, Se0/0/0` |

예비 정적 경로 없이 OSPF가 스스로 예비 회선으로 넘어간다. 비용 65가 그 증거다. 빠진 ping 개수를 세어 4일차, 5일차와 비교한다.

포트를 직접 끈 시험이라 OSPF도 즉시 알아챈다. 중간 장비 고장이라면 dead 시간 40초 안에 알아챈다. RIP의 180~240초보다 빠르다.

## 약어·용어

| 용어 | 뜻 |
|---|---|
| 루프백(loopback) | 장비 안에 만드는 가상 포트. 꺼지지 않아 라우터 ID에 쓴다 |
| 프로세스 ID | `router ospf 1`의 1. 장비 안에서만 쓰는 구분 번호 |
| 와일드카드 마스크 | 서브넷 마스크를 뒤집은 값. 0은 반드시 같음, 1은 아무거나 |
| `network ... area` | 범위 안의 주소를 가진 포트에서 OSPF를 켜고 에어리어를 정하는 명령 |
| key chain | 인증 키를 담는 열쇠고리. 5일차 RIP 인증에 쓴 설정 |
| FULL/DR, FULL/ - | 이웃 상태. 이더넷에서는 대표가 보이고, 1대1 구간에서는 `-` |
| `[110/2]` | 경로표의 관리 거리 110, 비용 2 |

### 물어볼 것

- "255.255.255.248의 와일드카드 마스크는?" 0.0.0.7이다.
- "RIP 때와 달리 경로가 한 줄뿐인 이유는?" 주 회선의 비용(2)이 예비 회선(65)보다 싸기 때문이다.
- 두 번째 함께 생각해 보기의 답: OSPF가 정상일 때는 예비 정적 경로가 필요 없다. OSPF 설정이 실수로 지워지면 경로가 모두 사라진다. 큰 망에서는 마지막 안전망으로 아주 큰 관리 거리의 정적 경로를 남기기도 한다. 정답은 회사의 판단이고, 그 판단을 비교 기록에 적는 것이 중요하다.

### 자주 헷갈리는 것

| 헷갈리는 것 | 바로잡기 |
|---|---|
| `network 192.168.10.0 255.255.255.0 area 0` | 서브넷 마스크가 아니라 와일드카드 마스크(0.0.0.255)를 쓴다 |
| `router ospf 1`의 1을 양쪽이 맞춰야 한다 | 장비 안의 번호라 달라도 된다. 맞춰야 하는 것은 에어리어다 |
| 이웃이 안 보인다 | 양쪽 에어리어, 연결 구간 주소, 포트 상태를 본다. area mismatch 알림이 뜨는지 본다 |
| 루프백 네트워크가 /32로 보이면 잘못 설정한 것이다 | OSPF의 기본 동작이다. `ip ospf network point-to-point`로 마스크대로 알리게 한다 |

### 진행 요령

- RIP 흔적 지우기는 지루하지만, 설정 텍스트가 깨끗해야 오늘 저녁 `git diff`가 읽기 좋다는 것으로 동기를 준다.
- 와일드카드 마스크는 10일차에 다시 쓴다. 오늘 표 하나를 칠판에 남겨 둔다.
- `show ip ospf interface brief`가 패킷트레이서에서 되면 포트별 비용(1, 64)을 한눈에 보여 줄 수 있다. 안 되면 `show ip ospf interface gi0/1`의 Cost 줄을 본다.
