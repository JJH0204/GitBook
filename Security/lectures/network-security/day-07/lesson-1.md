## 학습 목표

- EIGRP가 AS 번호로 같은 구역을 묶는다는 것을 안다.
- EIGRP가 대역폭과 지연으로 길을 고르고, 예비 길을 미리 계산해 둔다는 것을 안다.
- EIGRP의 관리 거리 90(내부)과 170(외부)을 안다.
- EIGRP를 켜는 명령을 OSPF와 비교해 읽는다.

## 목적

6일차에 새봄상사는 OSPF로 바꿨다. 그런데 이번 달 새봄상사가 물류 회사 한결물류를 인수했다. 한결물류의 망은 오래전부터 EIGRP로 돌아가고 있다. 두 회사를 이으려면 먼저 상대 회사가 쓰는 EIGRP를 알아야 한다.

## 1. EIGRP는 무엇인가

EIGRP(Enhanced Interior Gateway Routing Protocol)는 시스코가 만든 동적 라우팅이다. 이웃과 경로를 주고받는 방식은 RIP과 닮았지만, RIP의 약점(홉 수만 봄, 느린 장애 감지)을 고친 것이다.

| | RIP | OSPF | EIGRP |
|---|---|---|---|
| 길을 고르는 기준 | 홉 수 | 회선 속도로 정한 비용 | 대역폭과 지연 |
| 장애를 알아채는 시간 | 180초 | 40초 | 15초 (hello 5초, hold 15초) |
| 관리 거리 | 120 | 110 | 90 (같은 구역 안), 170 (밖에서 들어온 경로) |
| 구역을 정하는 것 | 없다 | 에어리어 | AS 번호 |
| 만든 곳 | 표준 | 표준 | 시스코 (지금은 공개되었으나 주로 시스코 장비에서 쓴다) |

## 2. AS 번호

EIGRP는 `router eigrp 20`처럼 AS(Autonomous System) 번호로 시작한다. 같은 AS 번호를 쓰는 라우터끼리만 이웃이 된다. OSPF의 프로세스 번호(`router ospf 1`)는 장비 안의 번호라 달라도 되지만, EIGRP의 AS 번호는 이웃끼리 반드시 같아야 한다.

| 이웃이 되는 조건 | 다르면 |
|---|---|
| AS 번호 | 이웃이 되지 않는다 |
| 연결 구간의 네트워크 | 이웃이 되지 않는다 |
| 인증 | 이웃이 되지 않는다 |

한결물류는 AS 20을 쓴다. 새봄상사 본사 라우터가 한결물류와 이웃이 되려면 본사 라우터에도 `router eigrp 20`을 켜야 한다.

## 3. 대역폭과 지연으로 고르고, 예비 길을 미리 안다

EIGRP는 길 위의 가장 느린 회선의 대역폭과, 지나는 회선들의 지연을 합쳐 메트릭을 계산한다. 그래서 OSPF처럼 빠른 길을 고른다.

EIGRP의 특징은 가장 좋은 길과 함께, 조건을 만족하는 두 번째 길을 미리 계산해 둔다는 것이다. 가장 좋은 길이 끊기면 다시 계산할 필요 없이 바로 두 번째 길로 넘어간다. 내비게이션이 처음부터 우회로를 하나 잡아 두는 것과 같다.

| 이름 | 뜻 |
|---|---|
| 후계자(successor) | 지금 쓰는 가장 좋은 길 |
| 예비 후계자(feasible successor) | 미리 잡아 둔 우회로 |

## 4. EIGRP 켜기

```
router eigrp 20
 network 172.16.10.0 0.0.0.255
 network 192.168.99.8 0.0.0.3
 no auto-summary
```

OSPF처럼 와일드카드 마스크로 포트를 고르지만 에어리어는 없다. RIP처럼 경계에서 클래스 단위로 묶는 자동 요약이 있어 `no auto-summary`로 끈다. 최근 IOS에서는 처음부터 꺼져 있지만, 명시해 두면 어느 장비에서든 같게 동작한다.

경로표에서 EIGRP 경로는 D로 보인다.

| 표시 | 뜻 | 관리 거리 |
|---|---|---|
| D | 같은 AS 안에서 배운 경로 | 90 |
| D EX | 다른 곳에서 EIGRP로 들어온(재분배된) 경로 | 170 |

D EX는 3번 노트의 재분배에서 처음 본다.

## 약어·용어

| 용어 | 뜻 |
|---|---|
| EIGRP | Enhanced Interior Gateway Routing Protocol. 시스코가 만든 동적 라우팅 |
| AS(Autonomous System) 번호 | EIGRP에서 같은 구역을 묶는 번호. 이웃끼리 같아야 한다 |
| 메트릭(metric) | 경로의 좋고 나쁨을 나타내는 값. EIGRP는 대역폭과 지연으로 계산한다 |
| 후계자(successor) | 지금 쓰는 가장 좋은 길 |
| 예비 후계자(feasible successor) | 미리 계산해 둔 우회로 |
| D, D EX | 경로표에서 EIGRP 내부 경로(90), 외부 경로(170)의 표시 |
| 자동 요약(auto-summary) | 경계에서 경로를 클래스 단위로 묶는 기능. `no auto-summary`로 끈다 |

## 함께 생각해 보기

- 회사가 다른 회사를 인수했을 때, 상대 회사의 라우팅 방식을 하루아침에 우리 것으로 바꾸기 어려운 이유는 무엇일까.
- EIGRP가 우회로를 미리 계산해 둔다는 것은 1일차 CIA 중 무엇과 이어질까.

### 물어볼 것

- "OSPF의 `router ospf 1`과 EIGRP의 `router eigrp 20`에서 숫자의 뜻이 어떻게 다를까?" OSPF는 장비 안의 번호, EIGRP는 이웃끼리 맞춰야 하는 구역 번호다.
- 첫 번째 함께 생각해 보기의 답: 상대 회사의 망 전체를 한꺼번에 바꾸면 그날 상대 회사가 멈출 수 있다. 그래서 경계에서 두 방식을 잇고(재분배), 천천히 하나로 옮기는 것이 현실적이다.
- 두 번째 함께 생각해 보기의 답: 가용성이다. 장애 때 멈춤 시간이 짧아진다.

### 자주 헷갈리는 것

| 헷갈리는 것 | 바로잡기 |
|---|---|
| EIGRP도 에어리어를 적는다 | 에어리어는 OSPF의 것이다. EIGRP는 AS 번호로 구역을 정한다 |
| AS 번호는 아무 숫자나 되고 양쪽이 달라도 된다 | 이웃끼리는 반드시 같아야 한다 |
| D EX는 잘못된 경로다 | 다른 라우팅에서 재분배되어 들어온 경로라는 표시다 |

### 진행 요령

- EIGRP의 메트릭 공식(K 값)은 다루지 않는다. "대역폭과 지연"까지만 안다.
- 오늘의 주제는 EIGRP 자체보다, 서로 다른 두 망을 안전하게 잇는 재분배와 경계 필터다. 이 노트는 짧게 간다.
