## 학습 목표

- 재분배가 한 라우팅에서 배운 경로를 다른 라우팅에 전하는 일이라는 것을 안다.
- OSPF와 EIGRP 사이에 양방향 재분배를 걸고, 들어온 경로의 표시(O E2, D EX)를 읽는다.
- 재분배할 때 메트릭을 정해 줘야 하는 이유를 안다.
- 아무것도 거르지 않은 재분배가 무엇을 새게 하는지 확인한다.

## 목적

앞 노트에서 경계 라우터는 두 회사의 경로를 모두 알지만, OSPF와 EIGRP는 서로 경로를 전하지 않는다는 것을 보았다. 통역사가 두 나라 말을 다 알아들어도 옮겨 말해 주지 않으면 대화가 되지 않는다. 재분배는 경계 라우터가 통역을 시작하게 하는 설정이다.

## 1. 재분배: 들은 것을 옮겨 전한다

재분배(redistribution)는 한 라우팅에서 배운 경로를 다른 라우팅에 넣어 알리는 일이다. 방향마다 따로 설정한다.

| 방향 | 설정하는 곳 | 결과 |
|---|---|---|
| EIGRP에서 OSPF로 | `router ospf 1` 안 | 지사가 한결물류를 안다 |
| OSPF에서 EIGRP로 | `router eigrp 20` 안 | 한결물류가 새봄상사를 안다 |

## 2. 메트릭을 정해 줘야 한다

OSPF의 비용과 EIGRP의 메트릭은 서로 단위가 다르다. 홉 수를 킬로미터로 옮길 수 없는 것처럼, 한쪽의 값을 다른 쪽에서 그대로 쓸 수 없다. 그래서 재분배할 때 "이 경로를 들여올 때 메트릭을 얼마로 칠지"를 정해 준다.

```
router eigrp 20
 redistribute ospf 1 metric 100000 100 255 1 1500
router ospf 1
 redistribute eigrp 20 subnets
```

| 부분 | 뜻 |
|---|---|
| `metric 100000 100 255 1 1500` | EIGRP로 들일 때 쓸 값. 대역폭(kbps), 지연(10마이크로초 단위), 신뢰도, 부하, MTU |
| `subnets` | OSPF로 들일 때 /24 같은 클래스 단위가 아닌 /27 같은 쪼갠 네트워크도 들인다 |

EIGRP는 메트릭을 정해 주지 않으면 재분배한 경로를 아예 알리지 않는다. OSPF는 따로 정하지 않으면 비용 20으로 들인다.

## 3. 들어온 경로의 표시

지사 라우터의 경로표다.

```
BR-R1#show ip route ospf
O E2    172.16.10.0/24 [110/20] via 192.168.99.1, 00:00:12, GigabitEthernet0/1
```

| 표시 | 뜻 |
|---|---|
| O E2 | OSPF 밖에서 들어온(재분배된) 경로. 비용은 들어온 값(20) 그대로 |
| [110/20] | 관리 거리 110, 비용 20 |

한결물류 라우터의 경로표다.

```
LC-R1#show ip route eigrp
D EX    192.168.10.96/27 [170/51456] via 192.168.99.9, 00:00:20, GigabitEthernet0/1
```

D EX는 EIGRP 밖에서 들어온 경로이고, 관리 거리는 170이다. 같은 AS 안에서 배운 D(90)보다 덜 믿는다. 남의 구역에서 옮겨 온 말을 덜 믿는 것은 자연스럽다.

이제 한결물류 PC에서 새봄상사 서버로 ping이 된다. 지사 PC에서 한결물류 PC로도 된다.

## 4. 그런데 무엇이 넘어갔나

거르지 않고 재분배하면 OSPF가 아는 경로가 모두 EIGRP로 넘어간다. 한결물류 라우터의 경로표를 다시 본다.

| 한결물류가 알게 된 것 | 필요한가 |
|---|---|
| 192.168.10.96/27 서버 VLAN | 필요하다. 주문 관리 서버 |
| 192.168.10.0/27 영업팀 | 필요 없다 |
| 192.168.10.32/27 인사팀 | 필요 없다. 급여 자료가 있는 곳 |
| 192.168.10.128/27 장비 관리 | 절대 필요 없다 |
| 192.168.20.0/24 지사, 192.168.99.x 연결 구간, 192.168.255.x 루프백 | 필요 없다 |

인수한 지 한 달 된 회사가 새봄상사의 인사팀과 장비 관리 대역으로 가는 길을 모두 알게 되었다. 반대 방향도 문제다. 한결물류 쪽에서 무엇을 알리든 경계 라우터는 받아서 새봄상사 전체에 퍼뜨린다. 5일차의 가짜 장비가 이번에는 한결물류 망 안에 있을 수도 있다.

{% hint style="info" %}
NOTE: 다음 노트에서 경계 라우터가 무엇을 받고 무엇을 알릴지 고르게 한다.
{% endhint %}

## 5. 경계 라우터가 둘이면

새봄상사는 경계 라우터가 하나라 문제가 없지만, 두 회사를 두 곳에서 잇고 양쪽 모두 양방향 재분배를 걸면, 경로가 한쪽에서 다른 쪽으로 넘어갔다가 다시 돌아오는 고리가 생길 수 있다. 재분배는 꼭 필요한 곳 한 곳에서, 꼭 필요한 경로만 하는 것이 원칙이다.

## 약어·용어

| 용어 | 뜻 |
|---|---|
| 재분배(redistribution) | 한 라우팅에서 배운 경로를 다른 라우팅에 넣어 알리는 일 |
| O E2 | OSPF 밖에서 들어온 경로. 비용은 들어온 값 그대로 |
| D EX | EIGRP 밖에서 들어온 경로. 관리 거리 170 |
| `subnets` | OSPF 재분배에서 클래스 단위가 아닌 쪼갠 네트워크도 들이는 옵션 |
| 시드 메트릭 | 재분배할 때 들어오는 경로에 붙여 주는 메트릭 값 |

## 함께 생각해 보기

- 우리 회사가 다른 회사를 인수했다면, 그 회사가 알아도 되는 우리 네트워크는 어디까지인가.
- 관리 거리 170으로 들어온 경로(D EX)를 덜 믿는 것이 왜 안전한 쪽일까.

## 강의 메모

### 시간 배분 (35분)

| 절 | 시간 | 방식 |
|---|---|---|
| 목적, 1 재분배 | 5분 | 통역사 비유 |
| 2 메트릭 | 8분 | 대본 5번 |
| 3 표시 | 10분 | 대본 6번. 지사와 한결물류 경로표를 나란히 |
| 4 무엇이 넘어갔나 | 10분 | 표를 같이 채운다. 다음 노트로 넘기는 질문 |
| 5 경계가 둘이면 | 2분 | 말로만 |

### 물어볼 것

- "EIGRP로 재분배할 때 metric을 빼먹으면?" 경로가 알려지지 않는다. 한결물류의 경로표에 아무것도 생기지 않는다.
- "한결물류가 우리 인사팀으로 가는 길을 알면 무엇이 걱정인가?" 길을 안다는 것은 그쪽으로 패킷을 보낼 수 있다는 뜻이다.
- 두 번째 함께 생각해 보기의 답: 같은 목적지를 우리 구역 안에서도 알고 밖에서 옮겨 온 경로로도 알 때, 안에서 배운 것을 먼저 쓰게 된다. 밖에서 잘못 들어온 경로가 안의 경로를 덮는 일을 줄인다.

### 자주 헷갈리는 것

| 헷갈리는 것 | 바로잡기 |
|---|---|
| 재분배는 한 번 걸면 양쪽으로 된다 | 방향마다 따로 건다 |
| OSPF로 재분배했는데 /27이 안 들어간다 | `subnets`를 빠뜨렸다 |
| EIGRP로 재분배했는데 아무것도 안 넘어간다 | `metric`을 빠뜨렸다 |
| O E2의 비용 20은 실제 거리다 | 들어올 때 정한 값이 그대로 붙은 것이다 |

### 진행 요령

- 4번 절의 표는 일부러 거르지 않은 재분배로 "다 새는" 장면을 먼저 보게 하려는 것이다. 오늘의 핵심 장면이다.
- 메트릭 다섯 값의 의미는 외우게 하지 않는다. "EIGRP는 들일 때 값을 줘야 한다"만 남긴다.
