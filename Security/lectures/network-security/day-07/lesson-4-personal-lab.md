## 5. 절차

### A. 내 파일에 1~9번

1. (5-A-01) `_실습/새봄상사.pkt`를 저장하고 닫은 뒤 `configs/network.pkt`를 연다.
2. (5-A-02) [2-1 실습](lesson-2-lab.md)의 한결물류 장비와 설정을 그대로 넣는다. → 결과: LC-R1, LC-SW1, LC-PC1이 생긴다.
3. (5-A-03) 2~9번을 내 본사 라우터와 내 연결 대역으로 입력한다. → 결과: 내 파일에서 EIGRP 이웃과 재분배, 필터, 인증이 동작한다.
4. (5-A-04) TO-LC 목록에는 내 회사에서 한결물류가 써야 할 서버 VLAN을 적는다.

### B. 인수회사 연결 기록

1. (5-B-01) [4번 노트](lesson-4.md) 7번 절의 양식으로 `03_구축/인수회사_연결.md`를 쓴다. → 결과: 구성, 재분배, 시험, 남은 위험(경로 필터의 한계)이 들어 있다.
2. (5-B-02) `02_설계/IP_설계표.md`에 한결물류 연결 구간(/30)과 한결물류 대역(172.16.10.0/24, 우리가 관리하지 않음)을 더한다.

### C. 설정 텍스트

1. (5-C-01) `configs/`에 HQ-R1, BR-R1, LC-R1의 설정 텍스트를 저장한다. LC-R1은 새로 생기는 파일이다.
2. (5-C-02) 비밀번호와 EIGRP 키를 `<password>`, `<key>`로 바꾼다.
3. (5-C-03) 바뀐 줄을 확인한다: `git diff configs/HQ-R1.txt` → 결과: EIGRP 20, 재분배, 필터, 인증 줄이 더해진 것이 보인다.

## 7. 복구

1. (7-01) 재분배가 꼬이면 `no redistribute ...`로 그 줄만 지운다.
2. (7-02) 필터를 잘못 걸어 경로가 다 사라지면 `no distribute-list ...`를 입력하고, `redistribute`에서 `route-map`을 빼고 다시 건다.
3. (7-03) 한결물류와의 연결을 끊어야 하면 HQ-R1 Gi0/2를 `shutdown`한다. 새봄상사 망은 영향을 받지 않는다.
4. (7-04) 커밋을 취소하려면 push 전에 `git reset --soft HEAD~1`을 쓴다. 이미 push했다면 새 커밋으로 고친다.
