# 7일차 EIGRP와 재분배

> 상위: [네트워크 보안 강의계획서](../plan.md)

새봄상사가 물류 회사 한결물류를 인수했습니다. 한결물류는 EIGRP를 쓰고, 새봄상사는 OSPF를 씁니다. 오늘은 본사 라우터를 두 회사 사이의 경계 라우터로 세우고, 서로 다른 라우팅 사이에 경로를 옮겨 주는 재분배를 합니다.

거르지 않고 재분배하면 인수한 지 한 달 된 회사가 새봄상사의 인사팀과 장비 관리 대역까지 알게 됩니다. 그래서 경계에서 받을 것과 알릴 것을 고르고, 경로를 숨기는 것만으로는 부족하다는 것을 10일차로 넘깁니다.

## 학습 목표

- EIGRP의 AS 번호, 메트릭, 관리 거리(90, 170)를 압니다
- 인수한 회사를 잇고 경계 라우터의 역할을 설명합니다
- 양방향 재분배를 걸고 O E2, D EX를 읽습니다
- 신뢰 경계에서 prefix-list, distribute-list, route-map으로 경로를 거르고 EIGRP 인증을 겁니다
- 경로 필터와 패킷 필터(ACL)의 차이를 압니다

### 새봄상사 7일차 작업 계획서

#### 1. 목표

- 인수한 한결물류가 새봄상사의 주문 관리 서버를 쓸 수 있게 잇는다
- 한결물류에는 필요한 것만 알리고, 한결물류에서 온 경로가 새봄상사 경로표를 흔들지 못하게 한다

#### 2. 작업 대상

| 대상 | 무엇을 |
|------|--------|
| LC-R1, LC-SW1, LC-PC1 (새로) | 인수할 때 받은 설정 그대로 |
| HQ-R1 | Gi0/2 연결, EIGRP 20, 양방향 재분배, 경로 필터, EIGRP 인증 |
| `02_설계/IP_설계표.md` | 한결물류 연결 /30, 한결물류 대역 |
| `03_구축/인수회사_연결.md` | 구성, 재분배, 필터, 시험, 남은 위험 |

#### 3. 작업 내용

1. 한결물류 장비를 놓고 받은 설정을 넣는다
2. HQ-R1 Gi0/2로 잇고 EIGRP 20 이웃을 맺는다
3. 양방향 재분배를 걸고, 무엇이 넘어갔는지 확인한다
4. 받을 것(172.16.10.0/24)과 알릴 것(서버 VLAN)을 고른다
5. 연결 구간에 EIGRP 인증을 건다

#### 4. 확인 방법

| 확인할 것 | 방법 | 기대하는 결과 |
|-----------|------|---------------|
| EIGRP 이웃 | `show ip eigrp neighbors` | 192.168.99.10 |
| 지사가 한결물류를 안다 | BR-R1 `show ip route ospf` | `O E2 172.16.10.0/24` |
| 한결물류는 서버만 안다 | LC-R1 `show ip route eigrp` | `D EX 192.168.10.96/27` 한 줄 |
| 한결물류에서 서버로 간다 | LC-PC1에서 `ping 192.168.10.98` | Reply |
| 한결물류에서 인사팀으로 안 간다 | LC-PC1에서 `ping 192.168.10.34` | Destination host unreachable |
| 인증이 맞다 | 인증 뒤 `show ip eigrp neighbors` | 이웃이 그대로 |

#### 5. 되돌리는 방법

- 재분배가 꼬이면 `no redistribute ...` 로 그 줄만 지운다
- 필터를 잘못 걸어 경로가 다 사라지면 `no distribute-list ...`, `redistribute` 의 `route-map` 을 빼고 다시 건다
- 한결물류와의 연결을 끊어야 하면 HQ-R1 Gi0/2를 `shutdown` 한다. 새봄상사 망은 영향을 받지 않는다

#### 6. 결과 (개인 실습이 끝날 때 채운다)

- 한 일:
- 확인 결과:
- 막힌 곳과 어떻게 풀었나:
- 다음 회차에 이어서 할 일: 부서별 주소를 DHCP로 자동 할당하고, 게이트웨이를 이중화한다. 10일차에 Gi0/2로 들어오는 패킷을 서버 VLAN으로만 허락한다

## 수업 전에 확인할 것

- 패킷트레이서가 `ip prefix-list`, `distribute-list prefix ... in`, `route-map ... match ip address prefix-list` 를 받아들이는지. 안 되면 표준 ACL로 대신하는 대본을 쓴다
- `redistribute ospf 1 metric ...` 과 `redistribute eigrp 20 subnets` 뒤 O E2와 D EX가 보이는지
- `ip authentication mode eigrp 20 md5` 가 되는지
- /28 시연에서 HQ-R1에 D 192.168.10.96/28이 생기는지, 필터 뒤 사라지는지
- 강사 레퍼런스 저장소에 새봄상사의 7일차 작업 계획서, 인수회사 연결 문서, 설정 세 개가 미리 커밋되어 있는지
