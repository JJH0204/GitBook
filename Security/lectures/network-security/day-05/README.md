# 5일차 동적 라우팅 RIP

> 상위: [네트워크 보안 강의계획서](../plan.md)

4일차에 정적 경로의 한계 두 가지를 적었습니다. 네트워크가 늘 때마다 사람이 줄을 넣어야 하고, 중간 장비의 고장은 알아채지 못합니다. 오늘은 라우터끼리 경로를 알려 주는 동적 라우팅, 그중 가장 단순한 RIP으로 바꿉니다.

라우터끼리 서로를 믿는 구조에는 새로운 위험이 따릅니다. 오늘 강사가 영업팀 자리에 가짜 장비를 꽂아 거짓 경로 하나로 서버 통신을 빼앗는 장면을 보여 주고, passive-interface와 인증으로 막습니다. 저녁에는 정적 경로와 RIP을 같은 기준으로 비교한 문서를 남깁니다.

## 학습 목표

- 동적 라우팅이 필요한 이유와 RIP의 동작(30초, 홉 수, 15홉)을 압니다
- 정적 경로를 RIPv2로 바꾸고, RIP이 회선 속도를 모르는 문제를 passive-interface로 다룹니다
- 거짓 경로 광고의 원리를 알고, passive-interface와 인증의 차이를 구분합니다
- 정적과 RIP을 같은 기준으로 비교해 문서로 남깁니다

### 새봄상사 5일차 작업 계획서

#### 1. 목표

- 본사와 지사의 경로를 RIPv2로 바꿔, 지사에 네트워크가 늘어도 본사가 저절로 알게 한다
- 동적 라우팅이 거짓 경로를 받아들이지 않게 한다 (계획서 4번 칸 "장비 설정의 무결성")

#### 2. 작업 대상

| 대상 | 무엇을 |
|------|--------|
| HQ-R1, BR-R1 | 주 정적 경로 삭제, RIPv2, passive-interface, 인증 |
| HQ-R1 | 예비 경로를 /24로 |
| BR-R1 | 창고 네트워크(루프백 1, 192.168.20.32/27) |
| `03_구축/라우팅_비교.md` | 정적과 RIP 비교와 시험 결과 |

#### 3. 작업 내용

1. 주 회선의 정적 경로 두 줄을 지운다(예비 경로는 남긴다)
2. 두 라우터에 RIPv2를 켠다
3. 예비 회선을 passive로 둔다
4. 지사에 창고 네트워크를 만들어 저절로 퍼지는지 본다
5. 장애 시험을 하고, 예비 경로를 /24로 바꾼다
6. 사무실 쪽 포트를 passive로 두고, RIP이 켜진 포트에 모두 인증을 건다

#### 4. 확인 방법

| 확인할 것 | 방법 | 기대하는 결과 |
|-----------|------|---------------|
| RIP 경로가 들어왔다 | `show ip route rip` | R 192.168.20.0/27 [120/1] |
| 예비 회선은 RIP을 타지 않는다 | `show ip route rip` | R 줄이 Gi0/1 하나 |
| 새 네트워크가 퍼진다 | 창고를 만들고 본사에서 `show ip route rip` | R 192.168.20.32/27 |
| 장애 때 넘어간다 | 주 회선 shutdown 중 `ping -t` | 몇 개 빠진 뒤 Reply, 창고까지 |
| 인증이 맞다 | 인증 뒤 `show ip route rip` | 지사 경로가 그대로 있다 |

#### 5. 되돌리는 방법

- 인증을 거는 동안 지사 경로가 잠시 사라진다. 양쪽에 다 걸 때까지 기다리고, 끝내 안 돌아오면 `no ip rip authentication mode md5` 로 양쪽을 푼다
- RIP이 꼬이면 `no router rip` 으로 지우고, `configs/` 의 4일차 설정에서 정적 경로를 다시 넣는다

#### 6. 결과 (개인 실습이 끝날 때 채운다)
