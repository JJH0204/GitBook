## 5. 절차

### A. 내 회사 VLAN 설계 (8분)

1. (5-A-01) `02_설계/IP_설계표.md`를 연다. → 결과: 2일차 설계표가 보인다.
2. (5-A-02) 표에 VLAN 칸을 더한다. 부서 이름은 영어 대문자로 정한다. → 결과: 아래 열이 모두 있다.

```markdown
| 위치 | 네트워크 | VLAN | VLAN 이름 | 대역 | 게이트웨이 | 스위치와 포트 | 인원과 장비 | 쓰는 날 |
```

3. (5-A-03) `99` 장비 관리, `900` native, `999` 쓰지 않는 포트의 번호를 정한다. 새봄상사와 같은 번호를 써도 된다. → 결과: 설계표에 세 번호가 적힌다.

### B. 내 회사 파일에 같은 설정 (25분)

1. (5-B-01) `_실습/새봄상사.pkt`를 저장하고 닫은 뒤 `configs/network.pkt`를 연다. → 결과: 내 회사 토폴로지가 열린다.
2. (5-B-02) 실습 [1-1](lesson-1-lab.md), [2-1](lesson-2-lab.md), [3-1](lesson-3-lab.md), [4-1](lesson-4-lab.md)의 설정을 내 설계표의 VLAN 이름과 주소로 입력한다. VLAN 번호(10, 20, 30, 40, 99, 900, 999)는 새봄상사와 같아도 된다. → 결과: 각 실습의 기능 확인 표를 통과한다.
3. (5-B-03) 부서 이름은 내 회사 부서로 짓는다. 예: `name ACCOUNTING`. → 결과: `show vlan brief`에 내 부서 이름이 나온다.
4. (5-B-04) [3-1 실습](lesson-3-lab.md)의 확인 표를 내 주소로 다시 해 본다. → 결과: 같은 VLAN은 통하고 다른 VLAN은 라우터를 지난다.

### C. 구성도와 설정 텍스트 (12분)

1. (5-C-01) 패킷트레이서 화면을 캡처한다(Win+Shift+S). → 결과: 캡처가 클립보드에 들어간다.
2. (5-C-02) VS Code에서 `02_설계/구성도.md`를 만들고 캡처를 붙여 넣는다(Ctrl+V). → 결과: 같은 폴더에 그림 파일이 생기고 마크다운에 링크가 들어간다.
3. (5-C-03) 그림 아래에 장비와 포트, VLAN을 표로 적는다. → 결과: 표가 저장된다.
4. (5-C-04) 장비 세 대에서 `terminal length 0`과 `show running-config`로 설정을 뽑아 `configs/HQ-R1.txt`, `configs/HQ-SW1.txt`, `configs/HQ-SW2.txt`에 저장한다. 비밀번호 자리는 `<password>`로 바꾼다. → 결과: 설정 텍스트 세 개가 생긴다.
5. (5-C-05) 아래를 입력한다. → 결과: Gi0/0의 주소가 빠지고 서브인터페이스가 생긴 줄이 보인다.

```bash

```

### D. 결과 기록과 커밋 (8분)

1. (5-D-01) `00_작업계획/03일차.md`의 결과 칸을 채운다. → 결과: 한 일, 확인 결과, 막힌 곳, 다음 회차에 이어서 할 일이 적힌다. 10일차에 막을 통신 목록을 포함한다.
2. (5-D-02) README 진행 현황에 한 줄을 더한다. → 결과: 표에 3일차 줄이 생긴다.

```markdown
| 3 | 부서별 VLAN, 트렁크, VLAN 사이 라우팅, 스위치 보안 | [작업 계획서](00_작업계획/03일차.md), [구성도](02_설계/구성도.md), [설정](configs/) |
```

```bash

git push
```

## 7. 복구

1. (7-01) 패킷트레이서 파일을 마지막 커밋으로 되돌린다: `git restore configs/network.pkt` → 결과: 마지막 커밋의 판으로 돌아간다.
