## 3. 안전 사항

{% hint style="danger" %}
WARNING: 설정 텍스트(`configs/*.txt`)를 커밋하기 전에 `enable secret`, `password` 줄과 HSRP 인증 `key-string`의 값을 `<password>`로 바꾼다. 공개 저장소에 올린 비밀번호는 지워도 커밋 기록에 남는다.
{% endhint %}

{% hint style="warning" %}
CAUTION: 가짜 DHCP 서버 시연(8번)은 하지 않는다. 더 해 볼 것에서 해 본 경우에도 기록의 시험 칸을 채운 뒤 가짜 서버를 지운다. 가짜 서버를 `configs/network.pkt`에 남기지 않는다.
{% endhint %}

{% hint style="info" %}
NOTE: 기록에는 실제 회사 이름, 개인 이메일, 실제 공인 IP를 쓰지 않는다. 주소는 사설 주소만 쓴다.
{% endhint %}

## 5. 절차

### A. 내 파일에 1~10번

1. (5-A-01) `_실습/새봄상사.pkt`를 저장하고 닫은 뒤 `configs/network.pkt`를 연다.
2. (5-A-02) 1~7번과 9, 10번을 내 회사의 설계로 입력한다. 8번 가짜 서버 시연은 하지 않는다. → 결과: 직원 PC가 DHCP로 주소를 받고, `show standby brief`에서 L3 스위치가 Active, 라우터가 Standby다.
3. (5-A-03) 풀과 제외 주소는 내 VLAN 대역마다 계산한다. 블록의 마지막 두 주소를 라우터와 L3 스위치에 남긴다.
4. (5-A-04) 지점이 없으면 3번(릴레이)을 건너뛴다. 기록에 "지점이 생기면 릴레이"라고 적는다.
5. (5-A-05) 장애 시험(7번)에서 끊긴 횟수를 센다. → 결과: 끊긴 횟수 숫자가 메모에 있다.
6. (5-A-06) 스누핑의 믿는 포트가 스위치마다 하나씩 있는지 확인한다. → 결과: 스누핑 뒤에도 PC가 주소를 받는다.

### B. 주소 할당과 이중화 기록

1. (5-B-01) [4번 노트](lesson-4.md) 7번 절의 양식으로 `03_구축/주소할당과_이중화.md`를 쓴다. 장애 시험의 끊긴 횟수를 꼭 적는다. → 결과: 파일에 풀, 이중화, 장애 시험, 보안, 남은 위험 절이 있다.
2. (5-B-02) `02_설계/IP_설계표.md`에 VLAN마다 가상 주소, 라우터와 L3 스위치의 실제 주소, DHCP 범위를 더한다.
3. (5-B-03) `02_설계/구성도.md`의 캡처를 HQ-DSW1이 보이게 다시 붙인다.
4. (5-B-04) `02_설계/스위치_보안_점검표.md`가 있으면 4번 노트 6번 절의 세 줄을 더한다.

### C. 설정 텍스트

1. (5-C-01) `configs/`에 여섯 장비의 설정 텍스트를 저장한다: HQ-R1, BR-R1, HQ-DSW1(새로), HQ-SW1, HQ-SW2, BR-SW1. → 결과: 여섯 파일이 있다.
2. (5-C-02) 각 파일의 `enable secret`, `password`, `key-string` 값을 `<password>`로 바꾼다. → 결과: 실제 비밀번호가 파일에 없다.

### D. 결과 기록과 커밋

1. (5-D-01) `00_작업계획/08일차.md`의 결과 칸을 채운다: 한 일, 확인 결과, 막힌 곳과 푼 방법, 다음 회차에 이어서 할 일.
2. (5-D-02) README의 진행 현황에 한 줄을 더한다.

```markdown
| 8 | DHCP와 릴레이, L3 스위치와 HSRP, 스누핑과 HSRP 인증 | [작업 계획서](00_작업계획/08일차.md), [주소 할당과 이중화](03_구축/주소할당과_이중화.md), [설정](configs/) |
```

3. (5-D-03) 커밋하고 올린다. → 결과: GitHub 저장소에서 파일이 보인다.

```bash
git add .
git commit -m "8일차: DHCP, 게이트웨이 이중화, 스누핑"
git push
```

## 7. 복구

1. (7-01) 이중화가 꼬이면 [3-1 실습](lesson-3-lab.md)의 복구 절차로 3일차 모습으로 돌린다.
2. (7-02) 스누핑 뒤 주소를 못 받으면 `no ip dhcp snooping`으로 끄고 믿는 포트부터 다시 본다.
3. (7-03) DHCP가 꼬이면 PC를 고정 주소로 되돌린다.
4. (7-04) 비밀번호가 든 설정 텍스트를 이미 push했으면 사용 중인 비밀번호를 바꾸고 강사에게 알린다.
5. (7-05) 커밋 전이라면 `git restore <파일 이름>`으로 파일을 되돌린다.
