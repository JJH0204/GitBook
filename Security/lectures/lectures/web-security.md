## 🎯 과정 개요

웹이 **어떻게 동작하는지(Client–Server–DB)** 공격자 관점에서 분해하고, **OWASP Top 10** 주요 취약점을 **의도적 취약 실습 머신**에서 직접 재현·점검한 뒤, **WAF·진단 보고서**로 방어 쪽을 완성한다. "입력을 믿으면 뚫린다"를 몸으로 익히는 과정.

* **대상**: 비전공 입문자 포함. **선수과목 없음**(순환 과정)
* **윤리·법 고지**: 모든 실습은 **본인이 구축한 취약 랩(DVWA·WebGoat 등)** 한정. 허가 없는 외부 사이트 점검은 **불법**임을 매 실습 전 고지.
* **도구**: DVWA · bWAPP · OWASP Juice Shop · WebGoat · Burp Suite · OWASP ZAP · sqlmap · ModSecurity

## 🧭 운영 방식

* **2개월 / 주말 / 16일 / 1일 4시간**. 1교시(원리·시연) + 2교시(실습 재현) + 방어 포인트 정리.
* **1일차 첫 교시 = 오리엔테이션**: 과정·평가·윤리 고지, 웹 보안 큰 그림, 실습 환경 구축.
* 각 취약점은 **"재현 → 왜 생기나 → 어떻게 막나(입력검증·인코딩·설정)"** 3단으로 마무리.
