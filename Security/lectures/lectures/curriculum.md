## 1. 과정 개요

정보보안을 **네트워크 → 시스템 → 웹** 세 축으로 나누어, 각 축에서 **① 어떻게 동작하는가 → ② 어떻게 지키는가 → ③ 공격자 관점에서 어떻게 점검하는가**를 실습 중심으로 익힌다. 모든 공격 기법은 **본인이 구축한 인가된 랩** 안에서 **진단·방어 관점**으로만 다룬다.

| 항목     | 내용                                               |
| ------ | ------------------------------------------------ |
| 과정 구성  | 네트워크 보안 · 시스템 보안 · 웹 어플리케이션 보안 (3과목)             |
| 운영 방식  | **순환제** — 어느 과목으로 시작하든 한 바퀴 돌아 3과목 모두 수강 후 수료    |
| 과목당 기간 | **2개월 / 주말(토·일) / 총 16일 / 1일 4시간(14:00\~18:00)** |
| 대상     | 비전공 입문자 포함, **선수과목 없음**(각 과목 자기완결형)              |
| 언어     | 한국어                                              |

## 2. 순환 구조와 오리엔테이션

```
┌───────────────┐      ┌───────────────┐      ┌───────────────┐
│  네트워크 보안   │ ──▶ │   시스템 보안    │ ──▶ │     웹 보안     │ ──┐
└───────────────┘      └───────────────┘      └───────────────┘   │
        ▲                                                          │
        └──────────────────────────────────────────────────────────┘
  예) 네트워크 보안 시작 → … → 웹 보안까지 / 시스템 보안 시작 → … → 네트워크 보안까지
```

* 과목마다 **신규 입문자 + 다른 과목에서 넘어온 수강생**이 섞인다.
* → **각 과목 1일차 첫 교시는 반드시 오리엔테이션**: 과정·평가·실습환경·(웹) 윤리/법 고지 + 입문 눈높이 맞추기.
* → 각 과목은 **앞 과목 수강을 전제하지 않도록** 필요한 기초를 자체적으로 깔고 시작한다.

## 3. 공통 운영 원칙

* **구성**: 1교시 이론·시연 → 2교시 따라하기 실습 → 회차 점검(퀴즈/미니 과제).
* **실습 환경**: VirtualBox 기반 VM + 패킷트레이서/GNS3 + 의도적 취약 실습 머신(Metasploitable2·DVWA·WebGoat 등).
* **윤리·법**: 허가 없는 외부 시스템 점검은 불법 — 실습은 **자가 구축 랩 한정**, 공격은 전부 방어 설계로 환원.
* **평가(공통)**: 출석·실습 참여 + 회차별 점검 + 과목 말 **종합 미니 프로젝트/리포트**.
