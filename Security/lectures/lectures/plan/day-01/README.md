# 1일차 프로젝트 시작

> 상위: [네트워크 보안 강의계획서](../) 다음: [2일차 주소 설계와 장비 접근 보안](../day-02/)

네트워크 보안 과목의 첫날입니다. 오늘은 장비를 하나도 켜지 않습니다. 대신 두 달 동안 만들 것을 정하고, 그것을 담을 그릇을 만듭니다.

수업이 끝나면 학생마다 GitHub 저장소가 하나씩 생깁니다. 그 안에는 각자 정한 가상 회사의 프로젝트 계획서가 첫 커밋으로 들어 있습니다. 2일차부터는 매 회차 배운 기술을 이 회사에 적용하고, 그 결과를 같은 저장소에 쌓습니다.

## 오늘 답할 질문

| 질문               | 오늘의 답                                  | 노트 |

| 두 달 뒤에 무엇을 가져가나? | 가상 회사의 네트워크를 설계하고 지킨 기록이 담긴 GitHub 저장소 | 1  |
| 정보보안은 무엇을 지키나?   | 기밀성, 무결성, 가용성                          | 2  |
| 얼마나 지키나?         | 위험을 0으로 만들 수는 없다. 받아들일 수 있는 수준까지 낮춘다   | 2  |
| 보안은 어디서부터 생각하나?  | 무엇을 만드는가, 무엇이 잘못될 수 있는가를 먼저 묻는다        | 2  |
| 기록은 어디에 남기나?     | 내 PC의 Git으로 기록하고 GitHub에 올린다           | 3  |
| 무엇을 만들까?         | 내 회사를 정하고 프로젝트 계획서를 쓴다                 | 4  |

## 학습 목표

* 두 달 동안 진행할 개인 프로젝트의 모습을 압니다
* 기밀성, 무결성, 가용성을 우리 회사의 예로 설명합니다
* 자산, 위협, 취약점, 위험을 구분합니다
* GitHub에 저장소를 만들고 첫 커밋을 올립니다
* 내 회사의 프로젝트 계획서를 씁니다

## 개인 실습 (17:00\~18:00)

내 회사의 계획서와 README를 쓰고 커밋합니다. 순서와 시간은 [4번 노트](lesson-4.md)의 3번 절에 있습니다. 강사는 4번 노트 강의 메모의 순서대로 한 사람씩 봅니다.

수업이 끝나기 전에 아래를 확인합니다.

* [ ] 내 GitHub 저장소에 `README.md` 와 `01_요구사항/프로젝트_계획서.md` 가 보인다
* [ ] `git log` 에 내가 쓴 커밋이 있고, Author 줄의 이메일이 noreply 주소다
* [ ] 저장소 주소를 강사에게 알려 주었다
* [ ] 교실 PC를 같이 쓴다면 자격 증명을 지웠다

마치기 전에 2일차를 안내합니다. 2일차 첫 30분에 첫 작업 계획서를 씁니다. 양식은 4번 노트의 10번 절에 있습니다.

## 오늘 저장소에 생기는 것

```
my-netsec-project/
├── README.md                    프로젝트 표지와 진행 현황 (GitHub가 만든 것을 고친다)
└── 01_요구사항/
    └── 프로젝트_계획서.md        새로 만든다
```

커밋은 세 개가 됩니다. GitHub가 저장소를 만들며 남긴 것, 계획서, README 수정입니다.

## 수업 전에 확인할 것

* 교실 네트워크에서 github.com 접속과 push가 되는지. 학원 방화벽이 막으면 오늘 수업의 절반이 멈춥니다.
* 첫 push 때 GitHub 로그인 창이 뜨는지. Git for Windows에 들어 있는 Git Credential Manager가 띄웁니다.
* `git config --global core.quotepath false` 뒤에 `git status`에서 한글 폴더 이름이 제대로 보이는지.
* 강사 레퍼런스 저장소(새봄상사)를 미리 만들어 두고, README와 계획서가 커밋된 화면을 보여 줄 수 있는지.
* 2번 노트의 사고 사례 세 건을 기사로 다시 확인하고 캡처해 두었는지. 정보통신망법 제48조를 국가법령정보센터에서 한 번 더 열어 보았는지.
