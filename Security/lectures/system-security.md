코리아 IT 아카데미 대구 주말반 강사용 문서다.

## 과정 개요

리눅스 서버를 직접 세우고(계정, 권한, 서비스), 단단하게 만들고(하드닝, 로그, 탐지), 공격자 관점에서 점검(모의해킹)하는 세 축을 한 대의 VM 환경에서 익힌다. 서버를 올릴 줄 아는 사람이 그 서버를 지킬 줄 아는 사람으로 넘어가는 과정이다.

| 항목 | 내용 |
|---|---|
| 대상 | 비전공 입문자 포함. 선수과목 없음(순환 과정) |
| 교재 축 | 이것이 우분투 리눅스다 3판(Ubuntu 24.04), 정보보안개론(시스템, 보안관리) |
| 도구 | VirtualBox, Ubuntu/Rocky Server, Kali, Nmap, Metasploit(실습용), Snort/Suricata, OSSEC, Graylog/Wazuh |

## 운영 방식

- 2개월, 주말, 16일, 1일 4시간이다. 같은 VM 세트를 과정 내내 이어 쓴다.
- 1일차 첫 교시는 오리엔테이션이다. 과정과 평가 안내, 시스템 보안 큰 그림, VM 설치 준비를 다룬다.

{% hint style="danger" %}
WARNING: 모의해킹과 취약점 공격은 의도적 취약 머신(Metasploitable2, CTF VM)에만 수행한다. 허가받지 않은 시스템에 수행하는 것은 불법이다. 인가된 랩 안에서 방어 관점으로만 진행한다.
{% endhint %}
