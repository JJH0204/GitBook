## 2. 순환 구조와 오리엔테이션

```
┌───────────────┐      ┌───────────────┐      ┌───────────────┐
│  네트워크 보안   │ ──▶ │   시스템 보안    │ ──▶ │     웹 보안     │ ──┐
└───────────────┘      └───────────────┘      └───────────────┘   │
        ▲                                                          │
        └──────────────────────────────────────────────────────────┘
  예) 네트워크 보안 시작 → … → 웹 보안까지 / 시스템 보안 시작 → … → 네트워크 보안까지
```

- 과목마다 신규 입문자와 다른 과목에서 넘어온 수강생이 섞인다.
- 따라서 각 과목 1일차 첫 교시는 반드시 오리엔테이션이다. 과정, 평가, 실습환경, (웹) 윤리·법 고지를 다루고 입문 눈높이를 맞춘다.
- 각 과목은 앞 과목 수강을 전제하지 않는다. 필요한 기초를 자체적으로 깔고 시작한다.

## 3. 공통 운영 원칙

- **구성**: 1교시 이론·시연, 2교시 따라하기 실습, 회차 점검(퀴즈 또는 미니 과제).
- **실습 환경**: VirtualBox 기반 VM, 패킷트레이서와 GNS3, 의도적 취약 실습 머신(Metasploitable2, DVWA, WebGoat 등).
- **윤리·법**: 허가 없는 외부 시스템 점검은 불법이다. 실습은 자가 구축 랩에 한정하고, 공격은 전부 방어 설계로 환원한다.
- **평가(공통)**: 출석과 실습 참여, 회차별 점검, 과목 말 종합 미니 프로젝트 또는 리포트.
