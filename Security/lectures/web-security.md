## 과정 개요

웹이 어떻게 동작하는지(Client, Server, DB)를 공격자 관점에서 분해한다. OWASP Top 10 주요 취약점을 의도적 취약 실습 머신에서 직접 재현·점검한 뒤, WAF와 진단 보고서로 방어 쪽을 완성한다. 입력을 믿으면 뚫린다는 점을 직접 익히는 과정이다.

| 항목 | 내용 |
|---|---|
| 대상 | 비전공 입문자 포함. 선수과목 없음(순환 과정) |
| 도구 | DVWA, bWAPP, OWASP Juice Shop, WebGoat, Burp Suite, OWASP ZAP, sqlmap, ModSecurity |

{% hint style="danger" %}
WARNING: 모든 실습은 본인이 구축한 취약 랩(DVWA, WebGoat 등)에서만 수행한다. 허가 없는 외부 사이트 점검은 불법이다. 이 점을 매 실습 전에 고지한다.
{% endhint %}

## 운영 방식

- 2개월, 주말, 16일, 1일 4시간이다. 1교시는 원리와 시연, 2교시는 실습 재현, 마지막은 방어 포인트 정리다.
- 1일차 첫 교시는 오리엔테이션이다. 과정, 평가, 윤리 고지, 웹 보안 큰 그림, 실습 환경 구축을 다룬다.
- 각 취약점은 재현, 왜 생기나, 어떻게 막나(입력 검증, 인코딩, 설정)의 3단으로 마무리한다.

## 주차별 계획 (16일)

| 일차 | 주제 | 핵심 내용 | 실습 |
|---|---|---|---|
| 1 | OT, 웹 보안 기초 | 과정·윤리 안내, 웹 동작 원리(Front/Back/Server/DB), HTTP/HTTPS, 공격자 관점 | 실습 VM, 브라우저 세팅 |
| 2 | 실습 환경, 프록시 | DVWA/bWAPP/Juice Shop/WebGoat 구축, 웹 프록시(Burp/ZAP) 개념 | 프록시로 요청 가로채기 |
| 3 | 정찰, OWASP Top 10 | 정보 수집, 디렉토리·파라미터 탐색, OWASP Top 10 개관 | 대상 앱 매핑 |
| 4 | XSS 1(Reflected) | 입력 반사, 스크립트 실행 원리, 출력 인코딩 방어 | DVWA Reflected XSS |
| 5 | XSS 2(Stored/DOM) | 저장형과 DOM 기반 차이, 세션 탈취 흐름, CSP와 인코딩 방어 | Stored XSS 재현·차단 |
| 6 | SQL Injection 1(수동) | DB 질의 구조, 수동 점검, 파라미터 바인딩 방어 | 수동 SQLi 점검 |
| 7 | SQL Injection 2(자동, Blind) | sqlmap 자동화, Blind와 심화 기법, 방어(Prepared Statement) | sqlmap 실습 |
| 8 | 인증, 세션, CSRF | 세션 취약점(A2), CSRF 원리와 토큰 방어 | CSRF 재현, 토큰 적용 |
| 9 | 명령어·파일 인클루전 | Command Injection, LFI/RFI, 경로 조작 | DVWA Command/File Inclusion |
| 10 | 파일 업로드, 웹셸 | 업로드 취약점, 웹셸 동작·탐지, 확장자·MIME·업로드 정책 | 업로드 우회·차단 |
| 11 | 인가, API, 정보노출 | 인가 우회, 오픈 리다이렉트, API 취약점, 민감정보 노출(A6) | 권한 우회 점검 |
| 12 | 전송구간, 서버측 | SSL/TLS 취약점(Heartbleed, POODLE 등), XST, SSRF/XXE | 취약 구성 재현 |
| 13 | WAF 방어 | ModSecurity 룰, OWASP CRS, XSS/SQLi 차단, IP 차단 룰 | WAF 룰 적용, 우회 테스트 |
| 14 | 실전 워크스루 | 취약 웹 머신 종합 공략(교육용: Natas, 워드프레스, Deface류) | 교육용 머신 풀이 |
| 15 | 진단, 인증제도 | 웹 취약점 진단 절차, 보고서 작성, ISMS-P 개요 | 진단 보고서 작성 |
| 16 | 종합 모의진단, 평가 | 대상 앱 전체 진단 후 리포트 미니 프로젝트, 수료 평가 | 종합 진단 프로젝트 |
