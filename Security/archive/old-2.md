## 1. 증상

원본이 기록한 화면의 HTML은 다음과 같다.

```html
<!--|
2024-10-23 09:11:00
-->
<h2>Restricted area</h2>Hello stranger. Your IP is logging...<!-- if you access admin.php i will kick your ass -->
```

| 항목 | 내용 |
|---|---|
| 화면 | `Restricted area`와 IP 기록 안내가 표시된다 |
| 소스 주석 | 접속 시각과 `admin.php`에 접근하지 말라는 문구가 있다 |

## 2. 가능 원인

| 번호 | 추정 | 근거 |
|---|---|---|
| 1 | 최초 접속 시간을 쿠키로 저장한다 | 원본 메모 |
| 2 | 쿠키 값이 SQL 질의에 쓰이며 블라인드 SQL 인젝션이 가능하다 | 원본 메모("블라인드 sql injection") |

## 3. 격리 절차

원본에는 다음 두 줄의 메모만 있다.

1. (3-01) 최초 접속 시간이 쿠키에 저장되는 것을 확인한다.
2. (3-02) 블라인드 SQL 인젝션을 스크립트로 자동화하는 방법을 생각한다.

구체적인 입력값, 스크립트, 결과는 원본에 없다.

## 4. 탐지·방어

이 절은 원본에 없던 일반 지식이며 미검증이다.

- 원인: 쿠키 값을 검증 없이 SQL 문자열에 붙인다.
- 완화: 매개변수화된 질의(prepared statement)를 쓰고 쿠키를 신뢰하지 않는다.
- 로그 흔적: 같은 클라이언트가 짧은 간격으로 쿠키 값만 바꿔 반복 요청한다. 응답 시간이나 응답 내용이 조건에 따라 달라진다.
