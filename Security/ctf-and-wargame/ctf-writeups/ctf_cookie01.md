이미지 파일을 업로드 하면 파일의 명칭이 바뀌어 업로드 된다.

파일을 업로드 하는 과정을 proxy로 잡아 보았다.

shellscript 파일을 업로드 하는데 성공했다. 스크립트.php.jpg 로 파일 이름 변경하고 웹 소스코드에서 업로드 가능한 파일 크기를 늘렸다.

클릭 해도 다른 이미지 파일과 달리 반응이 없다.

페이지에서 이미지를 선택했을 때 실행되는 함수의 형태가 주석으로 보여지고 있다.(개발자가 실수한 것 같다.)

html 소스에서 이미지의 가로,세로 값을 넣으니 눌렀을 때 반응이 출력 되었다.

파일 이름이 바뀌어서 원하는 대로 스크립트 실행이 안된다. 파일을 저장할 때 무슨 규칙으로 파일 이름을 생성하는지 알아내야 할 것 같다.

파일 업로드 후 바꼈다.

업로드 하기 전 쿠키 값이 파일 이름으로 적용되었다.

쿠키 값에 내가 원하는 파일 이름을 넣어 놓으면 원하는 파일 이름으로 스크립트도 실행할 수 있지 않을까?

쿠키 값을 script.php.txt로 바꿨다. -> script.php 라는 파일이 되었으면 좋겠다.

업로드 후에 반응이 없다.

에러가 표시 안됬다면 정상적으로 업로드는 된 것 같은데 그렇다면 스크립트를 실행할 방법은 없을까?

여기에 view 라는 함수의 사용법이 주석으로 적혀 있다.

브라우저 콘솔에서 원하는 파일을 출력할 수는 있었다. view() 의 소스코드를 확인해볼 필요가 있을 것 같다.

파일이름을 조금 바꾸면 완벽하게 실행할 수 있을 것 같다.
