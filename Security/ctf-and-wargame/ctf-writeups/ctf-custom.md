# CTF 커스텀 시나리오 설계

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | SEC-WUP-002-DO |
| 유형 | D&O (개념, 설계안) |
| 목적 | 윈도우 PC에서 리눅스 서버로 이어지는 자체 제작 CTF 시나리오의 구성을 설명한다 |
| 확인 상태 | 미검증 (원본의 설계안을 정리한 것이며 구축하지 않았다) |
| 개정 | R1 (2026-11-18) |

{% hint style="danger" %}
WARNING: 이 시나리오의 취약한 PC와 서버는 인터넷과 분리된 격리망에만 구축한다. 취약한 환경을 외부에 노출하면 실제 공격에 악용된다.
{% endhint %}

## 1. 목적

윈도우 PC의 취약점으로 침투해 SSH 키를 얻고, 그 키로 리눅스 게임 서버에 접속해 유저 정보를 탈취하는 CTF를 설계한다. 대상은 보안 전문가와 화이트 해커 지망생이다. 시나리오의 회사와 서버는 가상이다.

## 2. 구성 요소

### 2.1 시나리오 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 윈도우 PC와 리눅스 서버 해킹 기반 CTF |
| 배경 | 게임 회사 사무실의 윈도우 PC에서 SSH 키를 얻어 게임 서버에 침투한다 |
| 주요 기술 | 윈도우 취약점 공격, SSH 키 추출, 리눅스 서버 취약점 공격, 데이터 탈취 |
| 환경 | 윈도우 PC(관계자 업무용), 리눅스 서버(게임 서버) |

### 2.2 윈도우 PC

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 또는 Windows Server 2019 |
| 소프트웨어 | Office, Slack, 이메일 클라이언트 등 사무 환경 |
| 취약점 | EternalBlue(MS17-010), RDP 취약 설정, Mimikatz 등을 통한 자격 증명 덤프 |
| Flag(SSH 키) 위치 | `.ssh` 폴더의 개인 키, 메모장·Excel에 저장한 암호화 파일, 이메일 첨부 파일 |

### 2.3 리눅스 서버

| 항목 | 내용 |
|---|---|
| 운영체제 | Ubuntu 20.04 또는 CentOS 7 |
| 역할 | 게임 유저 정보를 저장하는 서버 |
| 유저 정보 위치 | MySQL 데이터베이스 또는 텍스트 파일 |
| 취약점 | 미패치 서버 소프트웨어, 잘못된 권한 설정, SQL 인젝션 |

### 2.4 네트워크와 로깅

| 항목 | 내용 |
|---|---|
| 네트워크 | 두 시스템은 같은 네트워크에 두고 SSH 접근을 허용한다. 방화벽으로 특정 포트만 연다 |
| 로깅 | 윈도우 이벤트 로그와 리눅스 `auth.log`를 켜서 참가자 활동을 추적한다 |

### 2.5 역할 분담

| 역할 | 업무 |
|---|---|
| 기획 | 시나리오 작성, 환경 구성 기획 |
| 개발 | 윈도우·리눅스 환경 설정, 취약점 추가 |
| 테스트 | 환경 테스트, 오류 수정 |
| 운영 | CTF 진행, 모니터링 |

## 3. 동작 원리

### 3.1 참가자 진행 순서

1. 윈도우 PC의 취약점을 찾아 침투하고 관리자 권한을 얻는다.
2. SSH 키 또는 Flag를 찾는다.
3. SSH 키로 리눅스 서버에 접속하고 게임 서버에 접근한다.
4. 유저 정보를 탈취해 제출한다(최종 목표).

### 3.2 준비 일정(예상)

| 단계 | 기간 | 내용 |
|---|---|---|
| 환경 구축 | 1주 | 윈도우 PC·리눅스 서버 설정, 취약점 추가, 네트워크 구성 |
| 테스트와 검증 | 1주 | 단계별 시나리오 테스트, 오류 수정 |
| CTF 실행 | 1일 | 시나리오 배포와 진행 |

### 3.3 기대 효과

- 실제와 유사한 환경에서 정보보안 기술력을 키운다.
- 윈도우와 리눅스 취약점을 함께 학습한다.
- 팀워크와 문제 해결 능력을 키운다.
