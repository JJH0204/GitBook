## 1. 목적

Webhacking.kr은 웹 취약점을 다루는 워게임이다. 문제 대부분이 PHP 코드 분석을 요구하므로 먼저 PHP 이해도를 올린다.

## 2. 구성 요소

| 학습 단계 | 내용 | 얻는 능력 |
|---|---|---|
| 1 | 게시판 만들기 (클론 코딩) | PHP로 입력 처리, DB 조회, 세션 사용 흐름을 직접 구현한다 |
| 2 | PHP 게임 만들기 | 서버 코드의 상태 관리와 검증 로직을 직접 작성한다 |

## 3. 동작 원리

1. 클론 코딩으로 서버 코드가 입력을 어떻게 처리하는지 안다.
2. 문제의 소스를 읽고 검증이 빠진 지점을 찾는다.
3. 찾은 지점을 허용된 문제 범위 안에서 시험한다.
4. 풀이를 [라이트업 작성 가이드](write-up.md)(SEC-CTF-008-DO)에 따라 정리한다.

관련 문서: [워게임 개요](wargame.md) (SEC-CTF-001-DO)

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| 클론 코딩 | 기존 서비스의 기능을 직접 따라 구현하는 학습 방법 |
| 입력 검증 | 사용자 입력이 기대한 형식인지 서버에서 확인하는 절차 |
