# Bandit 워게임 (OverTheWire)

## 작업 식별

| 항목 | 내용 |
|---|---|
| Task ID | SEC-CTF-002-DO |
| 유형 | D&O (개념, 플랫폼 소개) |
| 목적 | OverTheWire Bandit 워게임의 구조와 진행 규칙을 설명한다 |
| 확인 상태 | 미검증 (원본 페이지와 일반 지식을 정리한 것이며 플랫폼 현황을 다시 확인하지 않았다) |
| 개정 | R1 (2026-11-18) |

## 1. 목적

Bandit은 OverTheWire가 제공하는 입문용 워게임이다. 리눅스 명령어와 SSH 접속을 익히는 데 쓴다. 각 레벨의 목표는 다음 레벨 계정의 비밀번호를 찾는 것이다.

## 2. 구성 요소

| 항목 | 내용 |
|---|---|
| 공식 페이지 | [Bandit](https://overthewire.org/wargames/bandit/) |
| 접속 방식 | SSH. 포트는 2220이다 |
| 계정 | 레벨마다 `bandit<레벨 번호>` 형식이다 |
| 풀이 문서 | [Bandit Level 01~10 풀이](level-01-10.md) (SEC-CTF-006-TS), [Bandit Level 10~20 풀이](level_10-20.md) (SEC-CTF-007-TS) |

## 3. 동작 원리

1. 레벨 0 계정으로 SSH 접속한다.
2. 레벨 목표를 읽고 비밀번호가 있는 파일이나 서비스를 찾는다.
3. 찾은 비밀번호로 다음 레벨 계정에 SSH 접속한다.
4. 레벨마다 2~3을 반복한다.

{% hint style="info" %}
NOTE: 비밀번호는 서버가 저장하지 않는다. 풀이자가 로컬 PC의 메모 파일에 직접 저장한다. 레벨 비밀번호는 바뀔 수 있으므로 풀이 방법도 함께 기록한다.
{% endhint %}

## 4. 약어·용어

| 용어 | 뜻 |
|---|---|
| SSH | 원격 셸 접속 프로토콜 |
| 레벨 | Bandit의 단계. 레벨 0에서 시작한다 |
