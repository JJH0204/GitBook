## 1. 목적

bWAPP의 `htmli_current_url.php`는 현재 요청 URL을 화면에 출력한다. 쿼리가 아니라 URL의 경로 부분에 든 값도 출력되므로, 출력 대상이 되는 모든 요청 요소를 이스케이프해야 함을 이해한다.

## 2. 구성 요소

| 번호 | 요소 | 설명 |
|---|---|---|
| 1 | 요청 줄 | `GET /bWAPP/htmli_current_url.php HTTP/1.1` |
| 2 | 경로 뒤에 덧붙는 값 | 서버가 경로 뒤의 `/…` 부분을 무시하고 같은 스크립트를 실행하지만, 출력 시에는 그 부분도 포함된다 |
| 3 | 인코딩된 형태 | 브라우저는 `<h1>hello</h1>`를 `%3ch1%3ehello%3c%2fh1%3e`로 보낸다 |

## 3. 동작 원리

1. 요청 URL의 경로 뒤에 `/<h1>hello</h1>` 형태의 값을 붙인다.
2. 서버는 해당 스크립트를 실행하고 현재 URL을 응답에 출력한다.
3. 출력 시 이스케이프하지 않으면 브라우저가 그 부분을 태그로 해석한다.
4. 사용자 입력은 폼 값뿐 아니라 URL, 헤더, 쿠키도 포함한다.

## 4. 탐지·방어

| 방어 | 내용 |
|---|---|
| 출력 이스케이프 | URL을 출력할 때도 `htmlspecialchars()`를 적용한다 |
| 경로 정규화 | 정의되지 않은 경로 뒤 값(`PATH_INFO`)은 404로 처리한다 |
| 로그 흔적 | 요청 경로에 `%3c`, `%3e`, `<`가 포함된 접속 기록 |

## 5. 약어와 용어

| 용어 | 뜻 |
|---|---|
| PATH_INFO | 스크립트 이름 뒤에 붙은 경로 값 |
