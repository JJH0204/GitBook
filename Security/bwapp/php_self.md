## 1. 목적

`$_SERVER['PHP_SELF']`는 현재 실행 중인 PHP 파일의 경로를 담는 변수다. 폼의 `action`에 이 값을 쓰는 코드가 흔한데, 값에 요청 URL의 경로 뒤 부분이 포함되어 사용자가 바꿀 수 있다는 점이 문제다. 원본은 변수 설명 한 줄만 있었고, 나머지는 일반 지식으로 보충했다(미검증).

## 2. 구성 요소

| 번호 | 요소 | 설명 |
|---|---|---|
| 1 | `$_SERVER['PHP_SELF']` | 현재 스크립트의 경로. 경로 뒤에 덧붙은 값(`PATH_INFO`)도 포함된다 |
| 2 | `$_SERVER['SCRIPT_NAME']` | 스크립트 경로만 담는다. 덧붙은 값은 포함하지 않는다 |

## 3. 동작 원리

1. 코드가 `<form action="<?php echo $_SERVER['PHP_SELF']; ?>">`처럼 출력한다.
2. 요청 URL의 경로 뒤에 덧붙인 값이 이 출력에 들어간다.
3. 이스케이프하지 않으면 속성 문맥을 벗어나 반사형 XSS가 된다.
4. 이 항목은 [A3 반사형 XSS 실습](a3-cross-site-scripting.md)의 하위 항목이다.

## 4. 탐지·방어

| 방어 | 내용 |
|---|---|
| 출력 이스케이프 | `htmlspecialchars($_SERVER['PHP_SELF'], ENT_QUOTES)`로 출력한다 |
| 대체 | `action`을 비우거나(자기 자신에게 전송) `SCRIPT_NAME`을 쓴다 |
| 로그 흔적 | 스크립트 이름 뒤에 `/` 와 `%3c`, `%22` 등이 붙은 요청 |

## 5. 약어와 용어

| 용어 | 뜻 |
|---|---|
| PHP_SELF | 현재 스크립트의 경로를 담는 서버 변수 |
| PATH_INFO | 스크립트 이름 뒤에 붙은 경로 값 |
