## 1. 목적

페이지가 `<iframe>`의 주소와 크기를 URL 매개변수(`ParamUrl`, `ParamWidth`, `ParamHeight`)로 받을 때, 입력이 속성 문맥을 벗어나 다른 태그가 삽입되는 원리를 이해한다.

{% hint style="info" %}
NOTE: 원본의 요청 예시는 실습 서버 주소가 든 삽입용 URL이어서 옮기지 않았다. 원본의 스크립트 수정 지시도 옮기지 않았다.
{% endhint %}

## 2. 구성 요소

| 번호 | 요소 | 설명 |
|---|---|---|
| 1 | `ParamUrl` | iframe의 `src`가 되는 값. 기본값은 `robots.txt` |
| 2 | `ParamWidth`, `ParamHeight` | iframe의 크기 |
| 3 | high 수준 | 삽입이 동작하지 않는다 |

## 3. 동작 원리

1. 서버가 매개변수 값을 `<iframe src="값" ...>`에 끼워 출력한다.
2. 값에 따옴표와 태그 종료 문자열이 있으면 속성과 태그가 거기서 끝나고 뒤의 내용이 별도 태그로 해석된다.
3. 삽입된 iframe은 다른 출처의 페이지를 보여줄 수 있다. 사용자를 속이는 가짜 로그인 화면을 보여주는 피싱에 쓰일 수 있다.

## 4. 탐지·방어

| 방어 | 내용 |
|---|---|
| 속성 이스케이프 | 값을 `htmlspecialchars($값, ENT_QUOTES)`로 출력해 따옴표가 속성을 끝내지 못하게 한다 |
| 허용 목록 | `src`는 서버가 정한 주소 목록 중에서만 고르게 한다 |
| 숫자 검증 | 너비와 높이는 정수만 허용한다 |
| 헤더 | 자기 페이지가 남의 iframe에 들어가지 않게 `X-Frame-Options` 또는 CSP `frame-ancestors`를 쓴다 |
| 로그 흔적 | 쿼리에 `%22`, `%3e`, `iframe`이 포함된 요청 |

## 5. 약어와 용어

| 용어 | 뜻 |
|---|---|
| iframe | 페이지 안에 다른 페이지를 넣는 태그 |
| 피싱 | 가짜 화면으로 정보를 빼내는 공격 |
