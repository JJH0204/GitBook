## 1. 목적

서버가 사용자가 지정한 경로의 파일을 코드로 불러오는 기능(`include` 등)을 악용하는 취약점을 정리한다. 불러오는 대상이 서버 내부 파일이면 로컬 파일 인클루전(LFI), 외부 서버의 파일이면 원격 파일 인클루전(RFI)이다.

| 구성 | 설명 |
|---|---|
| 취약 지점 | 파일 경로를 요청 매개변수로 받아 `include`/`require`에 넘기는 코드 |
| 필요 조건 | PHP에서 URL을 파일처럼 읽는 설정(`allow_url_include`)이 켜져 있어야 RFI가 된다. 기본값은 꺼짐이다 (미검증) |
| 영향 | 외부에서 가져온 코드가 서버 권한으로 실행된다 |

## 3. 동작 원리

1. 코드가 `include($_GET['page'])`처럼 입력을 경로로 쓴다.
2. 입력이 외부 URL이면 서버가 그 내용을 가져온다.
3. 가져온 내용이 PHP 코드로 평가된다. 실행되는 코드가 서버 밖에서 정해진다.

## 4. 탐지·방어

| 구분 | 내용 |
|---|---|
| 근본 대책 | 파일 경로를 입력으로 받지 않는다. 허용 목록(고정된 이름과 파일의 매핑)으로만 포함한다 |
| PHP 설정 | `allow_url_include`를 끈다. `allow_url_fopen`도 필요하지 않으면 끈다 |
| 입력 검증 | 경로 구분자, `://`, `..`가 든 값을 거부한다 |
| 네트워크 | 웹 서버에서 외부로 나가는 HTTP 연결을 제한한다 |
| 로그 흔적 | 접근 로그의 매개변수 값에 `http://`, `https://`, `ftp://`(또는 `%3A%2F%2F`)가 보이고, 서버가 외부 주소로 아웃바운드 요청을 보낸다 |

## 5. 약어와 용어

| 용어 | 뜻 |
|---|---|
| RFI | Remote File Inclusion. 원격 파일 인클루전 |
| LFI | Local File Inclusion. 서버 내부 파일 인클루전 |
