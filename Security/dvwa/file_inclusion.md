## 1. 목적

파일 인클루전은 사용자가 준 값으로 서버가 포함(include)할 파일을 정하는 기능에서, 값을 확인하지 않아 의도하지 않은 파일이 실행·출력되는 취약점이다. 서버 안의 파일이면 LFI(Local File Inclusion), 외부 URL의 파일이면 RFI(Remote File Inclusion)다.

## 2. 구성 요소

| 구분 | 설명 |
|---|---|
| LFI | 서버 내부 경로를 지정한다. 경로 구분자(`/`)를 처리하지 않으면 가능하다 |
| RFI | `http://`, `https://` 주소를 지정한다. 원격 포함이 허용되어 있어야 한다 |
| 취약 원인 | `file` 파라미터 값을 검증 없이 `include`에 쓴다 |

## 3. 수준별 방어 관찰

| 수준(추정) | 방어 | 한계 |
|---|---|---|
| low | 값 검증 없이 바로 실행한다 | LFI·RFI 모두 가능 |
| medium | `http://`, `https://` 문자열을 제거해 RFI를 막는다 | 대소문자 혼용(`Http`, `HTTP`)을 모두 같은 프로토콜로 인식하므로 대소문자 구분 필터는 우회된다. `/`를 처리하지 않아 LFI는 가능하다 |
| high | `file`로 시작하는지, 또는 `include.php`인지 검사한다 | `file`로 시작하는 프로토콜 표기는 막지 못한다 |
| impossible | 실행할 파일을 고정 목록으로 지정한다 | 목록 밖의 값은 거부된다 |

## 4. 탐지·방어 (일부 미검증)

| 방어 | 설명 |
|---|---|
| 허용 목록 | 포함 가능한 파일을 고정 목록으로 두고, 값은 목록의 키로만 받는다 |
| 원격 포함 비활성화 | PHP `allow_url_include`를 Off로 한다 |
| 경로 정규화 | 경로를 정규화해 지정 디렉터리 밖이면 거부한다 |
| 파일 권한 | 웹 서버 계정이 읽을 수 있는 파일을 최소화한다 |
| 로그 | `file` 파라미터에 상위 경로 표기, URL 스킴, 시스템 파일 이름이 나타나면 흔적이다 |

## 5. 약어·용어

| 용어 | 뜻 |
|---|---|
| LFI | 로컬 파일 포함 |
| RFI | 원격 파일 포함 |
| 허용 목록 | 허용할 값만 정의하고 나머지는 거부하는 방식 |
