| 적용 대상 | 허가받은 격리 실습 환경(자신이 소유·관리하는 VM 또는 의도적 취약 앱) |

## 3. 안전 사항

{% hint style="danger" %}
WARNING: 허가받지 않은 시스템에 이 절차를 수행하는 것은 불법이다. 격리된 실습망에서만 수행한다. DVWA는 의도적 취약 앱이므로 외부 네트워크에 노출하지 않는다.
{% endhint %}

## 5. 절차

**A. VM 접속**

1. (SUBTASK 5-A-01) 실습 VM 콘솔에 관리자 계정 `<관리자 계정>`으로 로그인한다. → 결과: 셸 프롬프트가 나타난다.

**B. 네트워크 설정**

1. (SUBTASK 5-B-01) VM 네트워크를 호스트 전용 또는 내부망으로 설정한다. → 결과: 실습 PC와 같은 사설 대역(예: 192.168.x.x)의 IP가 부여된다.
2. (SUBTASK 5-B-02) VM의 IP를 확인한다. → 결과: `<DVWA IP>`를 얻는다.

**C. DVWA 로그인**

1. (SUBTASK 5-C-01) 브라우저에서 `http://<DVWA IP>/` 를 연다. → 결과: DVWA 로그인 화면이 나타난다.
2. (SUBTASK 5-C-02) DVWA 기본 계정(`<기본 계정>`)으로 로그인한다. → 결과: DVWA 메인 화면이 나타난다.
