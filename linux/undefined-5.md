# 기타 명령어

| 명령어                                                               | 설명                                                                                                                                                                                       | 옵션                                                                        | 사용 방법           | 예제                                                  |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | --------------- | --------------------------------------------------- |
| `cal`                                                             | 현재 시간 기준 달력 출력                                                                                                                                                                           | <p><code>-j</code>: 1월 1일부터 날짜수를 계산해서 출력<br><code>-y</code>: 올해 달력 출력</p> | `cal '옵션' '년도'` | <p><code>cal</code><br><code>cal -y 2000</code></p> |
| `clear`                                                           | 터미널 내용 지움                                                                                                                                                                                |                                                                           | `clear`         |                                                     |
| `string`                                                          |                                                                                                                                                                                          |                                                                           |                 |                                                     |
| `base64`                                                          |                                                                                                                                                                                          |                                                                           |                 |                                                     |
| `tr`                                                              |                                                                                                                                                                                          |                                                                           |                 |                                                     |
| `mktemp`                                                          |                                                                                                                                                                                          |                                                                           |                 |                                                     |
| `date`                                                            | 시스템의 날짜 시간 표시 및 변경                                                                                                                                                                       |                                                                           |                 |                                                     |
| `tty`                                                             | 현재 사용하고 있는 단말기의 경로 파일명을 출력                                                                                                                                                               |                                                                           |                 |                                                     |
| `time`                                                            | <p>프로그램이 수행되는데 걸리는 시간을 측정해서 출력<br><code>real</code>: 총 수행 시간<br><code>user</code>: 유저가 사용자 영역에서 보낸 시간<br><code>sys</code>: 시스템 호출 실행에 걸린 시간</p>                                          |                                                                           | `time '명령어'`    | `time cat /etc/passwd`                              |
| `wall`                                                            | 로그인 된 모든 사용자들에게 터미널을 통해 메시지를 전달하는 명령어                                                                                                                                                    |                                                                           | `wall '문장'`     |                                                     |
| `write`                                                           | 해당 사용자에게 메시지를 사용하는 명령어                                                                                                                                                                   |                                                                           | `write '계정명'`   |                                                     |
| `history`                                                         | <p>명령어 사용 기록을 확인할 수 있는 명령어<br>현재 메모리에 저장 중인 기록을 출력한다.<br>더 과거의 기록을 확인하려면 <code>.bash_history</code>에 저장된 데이터를 참조해야 된다. (이 파일도 데이터를 저장하는 시점이 시스템 종료 때라서 종료 전에 메모리를 청소하면 기록할 수 없게 된다.)</p> | `-c`: 메모리에 저장된 명령어 사용 기록을 삭제                                              |                 |                                                     |
| `tree`                                                            | 디렉토리 계층 구조 출력                                                                                                                                                                            |                                                                           |                 |                                                     |
| [`chmod`](/broken/pages/c791254e6986f8e0d487bfd5a70e47ee7d0dfc44) | 파일/디렉토리 권한 수정                                                                                                                                                                            |                                                                           |                 |                                                     |
| `su`                                                              | 사용자 전환                                                                                                                                                                                   | `-` : 사용자의 홈 디렉토리로 이동                                                     |                 | `su - [사용자이름]`                                      |
| `exit`                                                            | 사용자 로그아웃                                                                                                                                                                                 |                                                                           |                 | `exit`                                              |
