# 시스템 종료 명령어

| 명령어      | 설명                                  | 옵션                           | 사용 방법                 | 예제                                                                                                                                |
| -------- | ----------------------------------- | ---------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| shutdown | <p>시스템 종료 또는 재부팅<br>root 권한만 가능</p> | <p>-r: 재부팅<br>-h: 시스템 종료</p> | `shutdown '옵션' '시간값'` | <p><code>shutdown -h now</code> : 즉시 종료<br><code>shutdown -h +5</code> : 5분 뒤 종료<br><code>shutdown -r 10:00</code> : 10시에 재부팅</p> |
| init     | shutdown과 동일                        |                              | `init [[런레벨]]`        | `init 0` : 즉시 종료                                                                                                                  |
| reboot   | 시스템 재부팅                             | -f: 강제                       | `reboot '옵션'`         | `reboot -f`                                                                                                                       |
| halt     | 시스템 종료                              | -f: 강제                       | `halt '옵션'`           | `halt -f`                                                                                                                         |
