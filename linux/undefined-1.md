# 도움말관련명령어

| 명령어     | 설명                                                          | 옵션                                                                                                                                         | 사용 방법              | 예제                                                                                |
| ------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------ | --------------------------------------------------------------------------------- |
| man     | 명령어 사용 매뉴얼 출력                                               | <p><code>-h</code>: 사용법 출력<br><code>-k</code>: apropos와 동일<br><code>-w</code>: man 실행 시 호출되는 '메뉴얼 페이지' 파일의 위치 출력 (<code>--path</code>)</p> | `man '옵션' '명령어'`   | <p><code>man -h ls</code><br><code>man -w ls</code><br><code>man -k ls</code></p> |
| info    | <p>명령어 사용법, 옵션 등 표시<br>man 과 유사</p>                         |                                                                                                                                            | `info '명령어'`       | `info cal`                                                                        |
| whatis  | <p>명령어에 대한 기능을 간략히 출력<br>yum install man 으로 패키지 설치 후 사용</p> |                                                                                                                                            | `whatis '명령어'`     | `whatis cal`                                                                      |
| manpath | man 명령이 참조할 매뉴얼 페이지 경로 표시                                   |                                                                                                                                            | `manpath`          | `manpath`                                                                         |
| whereis | 찾는 명령어의 실행파일 절대 경로, 소스, 설정파일 및 매뉴얼 페이지를 찾아 출력               |                                                                                                                                            | `whereis '명령어'`    | `whereis ls`                                                                      |
| apropos | man 페이지 설정에서 지정한 키워드를 포함하고 있는 명령어 목록 출력                     |                                                                                                                                            | `apropos '찾는 키워드'` | `apropos system`                                                                  |
