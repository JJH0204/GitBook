# 네트워크 관련 명령어

| 명령어          | 설명                                                                                                                                                                       | 옵션                                                                             | 사용 방법                                                          | 예제                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ | -------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `ping`       | 네트워크 연결을 확인                                                                                                                                                              | <p><code>-c</code>: 요청 횟수<br><code>-i</code>: 초<br><code>-s</code>: 패킷 사이즈</p> | `ping '옵션' '대상'`                                               | <p><code>ping -c 5 -s 32 8.8.8.8</code><br>32 바이트 크기의 패킷을 5회 8.8.8.8 주소로 보낸다.</p> |
| `traceroute` | <p>목적지 호스트까지 경로를 표시, 구간의 정보를 기록<br>목적지 호스트까지 패킷 전송 지역을 측정 또는 경로 상 장애가 있는 경우 위치 파악 가능<br><code>yum -y install traceroute</code>로 설치<br>(<code>-y</code>: 모든 물음에 y 답변)</p> |                                                                                | `traceroute '주소 또는 ip'`                                        | `traceroute 8.8.8.8`                                                              |
| `nslookup`   | <p>도메인 명으로 ip 조회 또는 ip로 도메인 조회<br><code>yum install bind-utils</code> 로 설치</p>                                                                                           | <p><code>-type=A</code>: 호스트 ip주소<br><code>-type=NS</code>: 도메인 네임서버정보</p>     | `nslookup '도메인 또는 ip'`                                         | `nslookup 8.8.8.8`                                                                |
| `dig`        | <p><code>nslookup</code>과 유사<br>호스트 명으로 ip 조회 또는 그 반대</p>                                                                                                                |                                                                                | `dig '도메인 또는 ip'`                                              | `dig 8.8.8.8`                                                                     |
| `host`       | 호스트 명을 알고 있는데 ip를 모르거나 그 반대에 사용                                                                                                                                          |                                                                                | `host '도메인 또는 ip'`                                             | `host 8.8.8.8`                                                                    |
| `hostname`   | 시스템 이름을 확인                                                                                                                                                               |                                                                                | <p><code>cat /ect/hostname</code><br><code>hostname</code></p> |                                                                                   |
