# 사용자 조회 명령어

| 명령어      | 설명                                                                    |  옵션 |    사용 방법    | 예제        |
| -------- | --------------------------------------------------------------------- | :-: | :---------: | --------- |
| `users`  | 현재 로그인 한 사용자 이름 출력                                                    |     |   `users`   |           |
| `who`    | <p>현재 로그인 한 사용자 조회<br><code>users</code> 보다 더 상세한 정보</p>              |     |    `who`    |           |
| `w`      | <p>현재 로그인 한 사용자 정보 출력<br><code>who</code> 보다 더 상세한 정보</p>             |     |     `w`     |           |
| `id`     | <p>사용자 계정의 uid, gid, group을 확인<br>uid는 1000번부터 저장(root는 0)</p>        |     | `id '사용자명'` | `id root` |
| `groups` | <p>사용자 계정이 속한 그룹 확인<br>현재 생성된 그룹은 <code>/etc/group</code> 파일에서 확인</p> |     |   `groups`  |           |
